To find all pairs of positive integers $(x, y)$ such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we first simplify the expression for $a_n$. The sequence is defined as:
$$ a_n = \gcd \left( x^n + y, (y-x) \left( \sum_{i=0}^{n-1} y^i x^{n-i-1} - 1 \right) \right) $$

**Case 1: $x = y$.**
When $x = y$, the term $(y-x)$ is zero, so the second argument of the $\gcd$ is $0$. Thus:
$$ a_n = \gcd(x^n + x, 0) = x^n + x $$
For $x = 1$, $a_n = 1^n + 1 = 2$ for all $n \in \mathbb{N}$. This is a constant sequence, so the limit exists and is equal to $2$.
For $x > 1$, $a_n = x^n + x \to \infty$ as $n \to \infty$, so the limit does not exist.
Thus, for $x = y$, the only solution is $(1, 1)$.

**Case 2: $x \neq y$.**
When $x \neq y$, the summation is a geometric series:
$$ \sum_{i=0}^{n-1} y^i x^{n-i-1} = \frac{y^n - x^n}{y-x} $$
Substituting this into the expression for $a_n$:
$$ a_n = \gcd \left( x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) \right) = \gcd(x^n + y, y^n - x^n - y + x) $$
Using the property $\gcd(A, B) = \gcd(A, A+B)$:
$$ a_n = \gcd(x^n + y, (y^n - x^n - y + x) + (x^n + y)) = \gcd(x^n + y, y^n + x) $$
Let $g_n = \gcd(x^n + y, y^n + x)$. We analyze the convergence of $g_n$.

If $x=1$ and $y > 1$, then $g_n = \gcd(1+y, y^n+1)$. Since $y \equiv -1 \pmod{y+1}$, we have $y^n+1 \equiv (-1)^n+1 \pmod{y+1}$. Thus, $g_n = y+1$ if $n$ is odd, and $g_n = \gcd(y+1, 2)$ if $n$ is even. Since $y > 1$, $y+1 > 2$, so $g_n$ oscillates between $y+1$ and either $1$ or $2$. The limit does not exist. Similarly, $y=1$ and $x > 1$ yields no solutions.

If $x, y > 1$ and $x \neq y$, assume for contradiction that $g_n$ converges to a limit $L$. Since $g_n$ is a sequence of integers, it must be eventually constant, so $g_n = L$ for all $n \ge N$.
Then $L$ must divide $x^n + y$ and $x^{n+1} + y$ for all $n \ge N$. Thus $L$ divides their difference:
$$ L \mid x(x^n + y) - (x^{n+1} + y) = xy - y = y(x-1) $$
Similarly, $L$ must divide $y(y^n + x) - (y^{n+1} + x) = yx - x = x(y-1)$.
Thus $L \mid \gcd(y(x-1), x(y-1))$. This implies $L \mid (xy-y) - (xy-x) = x-y$.
Since $L \mid x-y$, we have $x \equiv y \pmod L$. Then $x^n + y \equiv y^n + y \pmod L$. Since $L \mid x^n + y$, we have $L \mid y^n + y$ for all $n \ge N$.
Then $L \mid (y^{n+1} + y) - (y^n + y) = y^n(y-1)$.
Let $d = \gcd(x, y)$. For any prime $p \mid L$, if $p \mid y$, then $p \mid x$ because $L \mid x-y$. Thus $p \mid d$.
If $p \nmid y$, then $L \mid y^n(y-1)$ implies $p \mid y-1$. Then $y \equiv 1 \pmod p$. Since $L \mid x-y$, $x \equiv 1 \pmod p$.
Then $x^n + y \equiv 1^n + 1 = 2 \pmod p$. Since $L \mid x^n + y$, we have $p \mid 2$, so $p=2$.
Thus, the only prime factors of $L$ are the prime factors of $d$ and possibly $p=2$.

If $p$ is a prime factor of $d$, then for $n$ sufficiently large, $v_p(x^n) > v_p(y)$ and $v_p(y^n) > v_p(x)$.
Then $v_p(x^n + y) = v_p(y)$ and $v_p(y^n + x) = v_p(x)$.
Thus $v_p(g_n) = \min(v_p(x), v_p(y)) = v_p(d)$ for all $n \ge N$.
This means the part of $L$ consisting of prime factors of $d$ must be exactly $d$.
If $L$ has a factor of $2$ not in $d$, then $x$ and $y$ must be odd.
Then $x^n \equiv -y \pmod L$ for all $n \ge N$ implies $x^n \equiv x^{n+1} \pmod L$, so $x^n(x-1) \equiv 0 \pmod L$.
Since $x$ is odd, $x-1$ must be even. If $L$ contains a factor $2^k$, then $2^k \mid x-1$.
Then $x \equiv 1 \pmod{2^k}$, so $x^n \equiv 1 \pmod{2^k}$.
Then $1 \equiv -y \pmod{2^k}$, so $y \equiv -1 \pmod{2^k}$.
Also $y^n \equiv -x \pmod{2^k}$ for all $n \ge N$, so $(-1)^n \equiv -x \pmod{2^k}$ for all $n \ge N$.
This is only possible if $2^k \mid 2$, so $k \le 1$.
Thus $L$ must be $d$ or $2d$.

However, $g_n$ cannot be eventually constant for $x \neq y$. If $g_n = L$, then $x^n \equiv -y \pmod L$ for all $n \ge N$.
If $L=1$, then $g_n=1$ for all $n \ge N$. But for $x, y > 1, x \neq y$, $g_n$ is not eventually 1; for any $x, y$, there exist infinitely many $n$ such that $g_n > 1$.
If $L > 1$, the condition $x^n \equiv -y \pmod L$ for all $n \ge N$ implies $x^n \equiv x^{n+1} \pmod L$, which forces $L \mid x^n(x-1)$. As shown, this limits $L$ to $d$ or $2d$. But for $x \neq y$, $g_n$ does not remain constant. For example, if $d$ is even, $g_n = d \cdot \gcd(d^{n-1}a^n+b, d^{n-1}b^n+a)$. The term $\gcd(d^{n-1}a^n+b, d^{n-1}b^n+a)$ cannot be eventually constant because the values $d^{n-1}a^n+b \pmod p$ vary with $n$ for primes $p$ not dividing $d$.

The only pair of positive integers for which the limit exists is $(1, 1)$.
