    *   *Potential Function $S$:*
        $S = \sum_p \sum_i v_p(x_i)$.
        New values for $m, n$: $g = \gcd(m, n)$, $l = \text{lcm}(m, n)/\gcd(m, n)$.
        $v_p(g) = \min(v_p(m), v_p(n))$.
        $v_p(l) = \max(v_p(m), v_p(n)) - \min(v_p(m), v_p(n)) = |v_p(m) - v_p(n)|$.
        Sum of new valuations for prime $p$: $\min(a, b) + |a-b| = \max(a, b)$.
        Change $\Delta S_p = \max(a, b) - (a+b) = -\min(a, b)$.
        Total change $\Delta S = \sum_p -\min(v_p(m), v_p(n)) = -\Omega(\gcd(m, n))$.
        If $\gcd(m, n) > 1$, $\Delta S \le -1$.
        If $\gcd(m, n) = 1$, $\Delta S = 0$, but the number of integers $> 1$ decreases by 1 (since $g=1$ and $l=mn > 1$).
        This is a perfectly valid termination argument.

    *   *Invariance of $g_p$:*

        Does $\gcd(a, b) = \gcd(\min(a, b), |a-b|)$?
        Assume $a \le b$. Then $\min(a, b) = a$ and $|a-b| = b-a$.
        $\gcd(a, b) = \gcd(a, b-a)$ is the fundamental step of the Euclidean algorithm.
        Thus, the $\gcd$ of the set of valuations for each prime $p$ is invariant.
