    *   Game: Mulan cuts a triangle $T$ into $T_1, T_2$ by a line from a vertex to the opposite side. Shan-Yu discards one. Mulan wins if $T$ has an angle exactly $\theta$.
    *   Solution Claim: $\theta = 180^\circ/n$ for $n \in \{2, 3, \dots\}$.
    *   Solution Logic:
        1.  Winning set $W$: Triangles with an angle in $S = \{k\theta \mid k \in \mathbb{Z}, 0 < k\theta < 180^\circ\}$.
        2.  Sufficiency: If $180^\circ = n\theta$, any triangle $T$ is in $W$.

            *   $n \ge 3$: If $A > \theta$, find $k$ such that $C < k\theta < C+A$. Cut $\alpha = 180^\circ - B - k\theta$. Resulting triangles $T_1, T_2$ have angles $k\theta$ and $(n-k)\theta$ respectively.

    *   If the interval is $(179^\circ, 179.5^\circ)$ and $\theta=60^\circ$, the multiples are $60, 120$. Neither is in the interval.
