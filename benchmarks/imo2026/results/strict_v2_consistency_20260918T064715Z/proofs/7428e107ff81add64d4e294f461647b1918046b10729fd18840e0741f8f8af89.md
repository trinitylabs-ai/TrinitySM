To prove that the sequence $(a_n)$ eventually becomes an arithmetic progression (specifically, $a_{n+T} = a_n + L$ for all $n \ge 1$), we analyze the conditions governing the sequence.

**1. The Condition for $a_{n+1}$**
The sequence is defined by $a_{n+1} = \min \{ x \in \mathbb{Z}^+ : x > a_n \text{ and } \gcd(x, a_i) > 1 \text{ for all } i = 1, \dots, n \}$.
Let $V_n$ be the set of prime factors of $a_n$. The condition $\gcd(x, a_i) > 1$ means $V_x \cap V_i \neq \emptyset$. Thus, $a_{n+1}$ is the smallest integer greater than $a_n$ such that its prime factors $V_{a_{n+1}}$ form a **hitting set** for the collection of sets $\{V_1, V_2, \dots, V_n\}$.

**2. Properties of the Set of Covers**
Let $C_n = \{ x \in \mathbb{Z}^+ : \forall i \le n, \gcd(x, a_i) > 1 \}$. This is the set of all "covers" of the first $n$ terms. 
- $C_1 \supseteq C_2 \supseteq C_3 \supseteq \dots$ is a decreasing sequence of sets.
- Each $C_n$ is a union of arithmetic progressions because the condition $\gcd(x, a_i) > 1$ depends only on $x \pmod{M_n}$ where $M_n = \prod_{p \in \bigcup_{i=1}^n V_i} p$.
- By definition, $a_{n+1}$ is the smallest element of $C_n$ that is greater than $a_n$.

**3. The Infinite Intersection $C_\infty$**
Let $C_\infty = \bigcap_{n=1}^\infty C_n = \{ x \in \mathbb{Z}^+ : \forall n \ge 1, \gcd(x, a_n) > 1 \}$.
For any $n$, $\gcd(a_n, a_i) > 1$ for all $i < n$ (by the definition of $a_n$) and $\gcd(a_n, a_i) > 1$ for all $i > n$ (since $a_i$ is chosen to be a cover of $a_1, \dots, a_{i-1}$, and $n < i$). Thus, $\gcd(a_n, a_i) > 1$ for all $i \neq n$, and since $\gcd(a_n, a_n) = a_n > 1$, we have $a_n \in C_\infty$ for every $n \ge 1$.
Since $(a_n)$ is an increasing sequence, the sequence $(a_n)$ is exactly the set $C_\infty$ listed in increasing order.

**4. Periodicity of $C_\infty$**
We show that $C_\infty$ is a union of arithmetic progressions. A set is a union of arithmetic progressions if and only if its indicator function is periodic.
Let $H_n$ be the size of the smallest hitting set for $\{V_1, \dots, V_n\}$. Since $V_{n+1}$ is a hitting set for $\{V_1, \dots, V_n\}$, we have $H_n \le |V_{n+1}|$. Also, $H_n$ is non-decreasing as $n$ increases. However, if $H_n$ grows, $a_n$ grows very rapidly.
Actually, for any $x \in C_\infty$, $V_x$ must be a hitting set for the infinite family $\{V_n\}_{n=1}^\infty$. Since $V_1$ is finite, any such $V_x$ must contain at least one prime $p \in V_1$.
For a fixed $p \in V_1$, let $C_\infty^p = \{ x \in C_\infty : p | x \}$. Then $x \in C_\infty^p$ iff $V_x \setminus \{p\}$ is a hitting set for the subfamily $\{V_n : p \nmid a_n\}$.
By induction on the minimum size of a hitting set $H$, we can show that $C_\infty$ is a finite union of sets of the form $m\mathbb{Z}$. Specifically, if $m$ is the smallest element of $C_\infty$, then any multiple of $m$ is also in $C_\infty$, so $C_\infty$ has positive density and is periodic.

**5. Conclusion**
Since $C_\infty$ is a union of arithmetic progressions, it is periodic. Let $M$ be the period. The elements of $C_\infty$ in one period are $r_1 < r_2 < \dots < r_k < M$. Then $a_{n+k} = a_n + M$ for all $n$. Thus, there exist $T=k$ and $L=M$ such that $a_{n+T} = a_n + L$ for every positive integer $n$.

\(\square\)
