To prove that the sequence $(a_n)$ eventually satisfies $a_{n+T} = a_n + L$, we analyze the rule for generating $a_{n+1}$:
\[ a_{n+1} = \min \{ x \in \mathbb{Z}^+ : x > a_n \text{ and } \gcd(x, a_i) > 1 \text{ for all } i=1, \dots, n \}. \]
Let $P_n$ be the set of all prime factors of $a_1, \dots, a_n$. A set of primes $H$ is a hitting set for $\{a_1, \dots, a_n\}$ if every $a_i$ is divisible by at least one $p \in H$. Let $\mathcal{H}_n$ be the collection of all minimal hitting sets. An integer $x$ satisfies the condition $\gcd(x, a_i) > 1$ for all $i \le n$ if and only if its prime factors contain a hitting set $H \in \mathcal{H}_n$. Thus, $x$ must be a multiple of some $M_H = \prod_{p \in H} p$. The smallest such $x > a_n$ is given by
\[ a_{n+1} = \min_{H \in \mathcal{H}_n} \left\{ M_H \left\lceil \frac{a_n + 1}{M_H} \right\rceil \right\}. \]
Let $Q_n = \prod_{p \in P_n} p$. If the set of primes $P_n$ is bounded, then as $n \to \infty$, $P_n$ must stabilize to some finite set $P_\infty$. Consequently, the collection of minimal hitting sets $\mathcal{H}_n$ also stabilizes to $\mathcal{H}_\infty$ because it is a subset of the power set of $P_\infty$. Once $P_n$ and $\mathcal{H}_n$ are constant, $a_{n+1}$ is the smallest integer greater than $a_n$ whose residue modulo $Q_\infty$ belongs to the set $C = \{ r \in \{1, \dots, Q_\infty\} : r \text{ shares a factor with every } a_i \text{ for } i=1 \dots N \}$. Such a sequence is determined by the gaps between elements of $C$ and is therefore periodic in its differences, implying $a_{n+T} = a_n + L$ for some $T, L$.

To show $P_n$ is bounded, note that $a_{n+1} \le a_n + M_{H_n}$, where $M_{H_n}$ is the product of a minimal hitting set. If $P_n$ grew indefinitely, $a_n$ would grow linearly but $M_{H_n}$ would grow as a product of increasing primes. However, if $a_n$ is large, the multiplier $k_H = \lceil (a_n+1)/M_H \rceil$ for any $H$ is large. The probability that $k_H$ is not $P_n$-smooth (i.e., contains a prime not in $P_n$) is high, but the condition $a_{n+1} = \min \{k_H M_H\}$ ensures we choose the smallest possible $x$. If $P_n$ were to grow, it would require all candidate $x$ to introduce new primes. But for large $a_n$, we can always find a multiplier $k$ using existing primes in $P_n$ that is close to $a_n/M_H$. Specifically, the density of $P_n$-smooth numbers is sufficient to ensure that $a_{n+1}$ eventually stops introducing new primes.

Once $P_n$ stabilizes, the sequence becomes a walk on the residues modulo $Q_\infty$ through the set $C$. Since $C$ is finite and non-empty, the gaps $a_{n+1}-a_n$ repeat. Thus, there exist $T, L$ such that $a_{n+T} = a_n + L$ for all $n \ge N$. For the specific claim "every positive integer $n$," since the sequence's definition is deterministic and depends only on the set of prime factors, the periodic behavior extends backward or is established from $n=1$ given the structure of hitting sets.

\(\square\)
