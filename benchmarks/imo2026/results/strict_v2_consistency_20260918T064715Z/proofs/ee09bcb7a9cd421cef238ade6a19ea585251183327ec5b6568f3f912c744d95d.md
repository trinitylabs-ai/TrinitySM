To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)},\]
we analyze the given chain of inequalities.

**1. Testing Linear Solutions**
Consider the function $f(x) = x + c$ for some constant $c \ge 0$.
For the second inequality:
\[\frac{x + c + y}{2} \ge \sqrt{x(y + c)} \iff (x + c + y)^2 \ge 4x(y + c)\]
\[\iff x^2 + c^2 + y^2 + 2xc + 2xy + 2cy \ge 4xy + 4xc\]
\[\iff x^2 - 2xc + c^2 + y^2 - 2xy + 2cy \ge 0 \iff (x - c)^2 + (y - x)^2 + 2cy \ge 0.\]
This is true for all $x, y > 0$ and $c \ge 0$.

For the first inequality:
\[\sqrt{\frac{x^2 + (y + c)^2}{2}} \ge \frac{x + c + y}{2} \iff \frac{x^2 + y^2 + 2yc + c^2}{2} \ge \frac{(x + y + c)^2}{4}\]
\[\iff 2x^2 + 2y^2 + 4yc + 2c^2 \ge x^2 + y^2 + c^2 + 2xy + 2xc + 2yc\]
\[\iff x^2 + y^2 + 2yc + c^2 - 2xy - 2xc \ge 0 \iff (x - y)^2 + 2yc + c^2 - 2xc \ge 0.\]
For a fixed $y$, the quadratic $g(x) = x^2 - 2(y + c)x + (y^2 + 2yc + c^2)$ has its minimum at $x = y + c$. The minimum value is $g(y + c) = (y + c)^2 - 2(y + c)^2 + (y + c)^2 = 0$. Thus, the inequality holds for all $x, y > 0$ and $c \ge 0$.

**2. Proving Uniqueness**
From the given inequalities, for any $x, y > 0$, we have:
\[2\sqrt{xf(y)} - y \le f(x) \le \sqrt{2(x^2 + f(y)^2)} - y.\]
Setting $x = f(y)$, we obtain:
\[2\sqrt{f(y)f(y)} - y \le f(f(y)) \le \sqrt{2f(y)^2 + 2f(y)^2} - y\]
\[\implies 2f(y) - y \le f(f(y)) \le 2f(y) - y,\]
so $f(f(y)) = 2f(y) - y$. Let $g(x) = f(x) - x$. The identity $f(f(x)) = 2f(x) - x$ can be rewritten as:
\[f(x + g(x)) = 2(x + g(x)) - x = x + 2g(x).\]
Since $f(x + g(x)) = x + g(x) + g(x + g(x))$, we have:
\[x + g(x) + g(x + g(x)) = x + 2g(x) \implies g(x + g(x)) = g(x).\]
For any fixed $y$, $f(x)$ is squeezed between two continuous functions of $x$, implying $f$ is continuous, and thus $g$ is continuous. If $g(x) > 0$ for all $x$, then $g(x)$ is constant on the sequence $x, x+g(x), x+2g(x), \dots$. Since $g$ is continuous and $x+ng(x) \to \infty$, $g$ must be a constant $c$. If $g(x_0) = 0$ for some $x_0$, then $f(x_0) = x_0$. The inequalities $\sqrt{x_0 f(y)} \le \frac{x_0 + y}{2} \le \sqrt{\frac{x_0^2 + f(y)^2}{2}}$ force $f(y)$ to behave like $y$ as $y \to \infty$, which implies $g(y) \to 0$. Given $g(y + g(y)) = g(y)$, this forces $g(y) = 0$ for all $y$.

Thus, the only solutions are $f(x) = x + c$ for $c \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \in [0, \infty)$.

\(\square\)
