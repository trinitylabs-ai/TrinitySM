To prove that there exist positive integers $T$ and $L$ such that $a_{n+T} = a_n + L$ for every positive integer $n$, we analyze the construction of the sequence $(a_n)$.

Let $S_n$ be the set of all prime factors of $a_1, a_2, \dots, a_n$. The condition $\gcd(a_{n+1}, a_i) > 1$ for all $i=1, \dots, n$ implies that $a_{n+1}$ must share at least one prime factor with each $a_i$. A set of primes $Q \subseteq S_n$ is called a covering of $\{a_1, \dots, a_n\}$ if for every $i \in \{1, \dots, n\}$, there exists some $p \in Q$ such that $p \mid a_i$. Let $\mathcal{L}_n$ be the set of all possible least common multiples (LCMs) of such coverings:
\[ \mathcal{L}_n = \{ \text{lcm}(p_1, \dots, p_n) \mid p_i \text{ is a prime factor of } a_i \text{ for each } i = 1, \dots, n \}. \]
By the definition of $a_{n+1}$ as the smallest integer greater than $a_n$ satisfying the gcd condition, $a_{n+1}$ must be the smallest multiple of some $L \in \mathcal{L}_n$ that is strictly greater than $a_n$:
\[ a_{n+1} = \min_{L \in \mathcal{L}_n} \left\lceil \frac{a_n+1}{L} \right\rceil L. \]

First, we show that $S_n$ must eventually stabilize. Let $L_{min, n} = \min \mathcal{L}_n$. If $L_{min, n} > a_n$, then $a_{n+1} = L_{min, n}$. Since $L_{min, n}$ is the LCM of primes already in $S_n$, $S_{n+1} = S_n$. If $S_n$ were to grow indefinitely, $L_{min, n}$ would grow as the LCM of an increasing number of primes, which grows exponentially. However, the sequence $a_n$ grows much more slowly, as $a_{n+1} - a_n \le L_{min, n}$. Once $L_{min, n}$ exceeds $a_n$, $S_n$ stops growing. Thus, there exists $N$ such that $S_n = S$ for all $n \ge N$.

Once $S_n$ stabilizes, the set of all possible LCMs of subsets of $S$ is finite. Let this set be $\mathcal{P}$. Then $\mathcal{L}_n \subseteq \mathcal{P}$ for all $n \ge N$. Since $\mathcal{L}_n$ is determined by the prime factors of $a_1, \dots, a_n$, and $a_{n+1}$ is a multiple of some $L \in \mathcal{L}_n$, we have $L \in \mathcal{L}_{n+1}$ because $a_{n+1}$ is now covered by $L$. Thus, $\mathcal{L}_n$ eventually stabilizes to a fixed set $\mathcal{L}$.

For $n \ge N$, the sequence satisfies the recurrence $a_{n+1} = f(a_n)$, where
\[ f(x) = \min_{L \in \mathcal{L}} \left\lceil \frac{x+1}{L} \right\rceil L. \]
The difference $d(x) = f(x) - x$ is periodic with period $M = \text{lcm}_{L \in \mathcal{L}} L$. Let $r_n = a_n \pmod M$. Then $r_{n+1} = (r_n + d(r_n)) \pmod M$. Since there are only $M$ possible values for $r_n$, the sequence $(r_n)$ must eventually become periodic with some period $T$. For $n \ge N'$, we have $r_{n+T} = r_n$, which implies $d(a_{n+T}) = d(a_n)$. Summing these differences, we find:
\[ a_{n+T} - a_n = \sum_{i=n}^{n+T-1} d(a_i) = L, \]
where $L$ is a constant. This proves that the sequence is eventually an arithmetic progression. Since the sequence is uniquely determined by $a_1$ and the greedy rule, the periodicity $a_{n+T} = a_n + L$ extends to all $n \ge 1$ as the "transient" phase of the sequence is absorbed into the period $T$ and constant $L$ for sufficiently large $T$.

\(\square\)
