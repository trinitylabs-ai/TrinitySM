To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for all $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we analyze the two inequalities separately.

**1. Right Inequality: $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$**
This inequality can be rewritten as:
\[ f(x) + y \ge 2\sqrt{x f(y)} \]
Squaring both sides (since both are positive):
\[ f(x)^2 + 2yf(x) + y^2 \ge 4xf(y) \quad (*) \]
If we set $x = y$, we get $f(x)^2 + 2xf(x) + x^2 \ge 4xf(x)$, which simplifies to $(f(x) - x)^2 \ge 0$. This is always true for any $f(x)$, so it provides no immediate constraint on $f(x)$.

**2. Left Inequality: $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$**
Squaring both sides:
\[ \frac{x^2 + f(y)^2}{2} \ge \frac{f(x)^2 + 2yf(x) + y^2}{4} \]
\[ 2x^2 + 2f(y)^2 \ge f(x)^2 + 2yf(x) + y^2 \quad (**) \]
Setting $x = y$ here gives $2x^2 + 2f(x)^2 \ge f(x)^2 + 2xf(x) + x^2$, which simplifies to $f(x)^2 - 2xf(x) + x^2 \ge 0$, or $(f(x) - x)^2 \ge 0$. Again, this is always true.

**3. Combining the Inequalities**
From the right inequality, we have $(f(x) + y)^2 \ge 4xf(y)$. Substituting this into the left inequality $(**)$:
\[ 2x^2 + 2f(y)^2 \ge (f(x) + y)^2 \ge 4xf(y) \]
The outer inequality $2x^2 + 2f(y)^2 \ge 4xf(y)$ simplifies to $2(x - f(y))^2 \ge 0$, which is always true.

**4. Testing Linear Functions**
Suppose $f(x) = ax$ for some $a > 0$.
The right inequality $\frac{ax + y}{2} \ge \sqrt{x(ay)}$ is $\frac{ax + y}{2} \ge \sqrt{axy}$. Squaring gives $a^2x^2 + 2axy + y^2 \ge 4axy$, so $(ax - y)^2 \ge 0$, which holds for all $a$.
The left inequality $\sqrt{\frac{x^2 + (ay)^2}{2}} \ge \frac{ax + y}{2}$ requires $2x^2 + 2a^2y^2 \ge (ax + y)^2 = a^2x^2 + 2axy + y^2$.
Rearranging: $(2-a^2)x^2 - 2axy + (2a^2-1)y^2 \ge 0$.
For this to hold for all $x, y > 0$, the discriminant of the quadratic in $x$ must be non-positive:
\[ D = (2ay)^2 - 4(2-a^2)(2a^2-1)y^2 \le 0 \]
\[ 4a^2 - 4(4a^2 - 2 - 2a^4 + a^2) \le 0 \implies a^2 - 5a^2 + 2 + 2a^4 \le 0 \implies 2a^4 - 4a^2 + 2 \le 0 \]
\[ 2(a^2 - 1)^2 \le 0 \]
This only holds if $a^2 = 1$, and since $a > 0$, we must have $a = 1$. Thus, $f(x) = x$ is the only linear solution.

**5. General Solution**
For any $x, y$, we have $f(x) \ge 2\sqrt{xf(y)} - y$ and $f(x) \le \sqrt{2x^2 + 2f(y)^2} - y$.
If $f(y) = y$, then $f(x) \ge 2\sqrt{xy} - y$ and $f(x) \le \sqrt{2x^2 + 2y^2} - y$.
Taking the supremum over $y$ for the lower bound and the infimum over $y$ for the upper bound:
$\sup_{y>0} (2\sqrt{xy} - y) = x$ (at $y=x$) and $\inf_{y>0} (\sqrt{2x^2 + 2y^2} - y) = x$ (at $y=x$).
Thus, $x \le f(x) \le x$, forcing $f(x) = x$.

The function $f(x) = x$ satisfies the original conditions as it reduces to the RMS-AM-GM inequalities: $\sqrt{\frac{x^2 + y^2}{2}} \ge \frac{x + y}{2} \ge \sqrt{xy}$.

Final Answer: The only such function is $f(x) = x$. \(\square\)
