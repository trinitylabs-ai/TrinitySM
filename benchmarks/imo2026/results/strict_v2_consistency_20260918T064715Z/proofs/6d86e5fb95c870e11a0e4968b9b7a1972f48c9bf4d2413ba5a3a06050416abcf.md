To prove that there exist positive integers $T$ and $L$ such that $a_{n+T} = a_n + L$ for every positive integer $n$, we analyze the prime factor constraints and the growth of the sequence $(a_n)$.

**1. Hitting Sets and Sequence Generation**
For each $n$, let $\mathcal{P}_n$ be the set of prime factors of $a_n$. The condition $\gcd(a_{n+1}, a_i) > 1$ for all $i = 1, \dots, n$ implies that $a_{n+1}$ must share at least one prime factor with every $a_i$. A set of primes $H$ is called a *hitting set* for the collection $C_n = \{\mathcal{P}_1, \dots, \mathcal{P}_n\}$ if $H \cap \mathcal{P}_i \neq \emptyset$ for all $i = 1, \dots, n$.
The integer $a_{n+1}$ is the smallest integer greater than $a_n$ that is a multiple of the least common multiple (lcm) of some hitting set $H$ for $C_n$. Let $M_n$ be the set of all such lcm's:
\[ M_n = \{ \text{lcm}(H) : H \text{ is a hitting set for } C_n \}. \]
Then $a_{n+1} = \min \{ m \cdot k : m \in M_n, k \in \mathbb{Z}^+, m \cdot k > a_n \}$.

**2. Dynamics of the Hitting Sets**
A set $H$ is a hitting set for $C_{n+1}$ if and only if it is a hitting set for $C_n$ and $H \cap \mathcal{P}_{n+1} \neq \emptyset$. Let $m_{n+1} \in M_n$ be the element used to generate $a_{n+1}$, so $a_{n+1} = k m_{n+1}$. Since $m_{n+1}$ divides $a_{n+1}$, we have $\gcd(m_{n+1}, a_{n+1}) = m_{n+1} > 1$. Thus, $m_{n+1} \in M_{n+1}$.
Let $MinM_n$ be the set of lcm's of *minimal* hitting sets for $C_n$. As $n$ increases, the conditions to be a hitting set become more restrictive. However, any $m \in MinM_n$ that shares a factor with $a_{n+1}$ remains a hitting set for $C_{n+1}$. If $\gcd(m, a_{n+1}) = 1$, we can form a hitting set for $C_{n+1}$ by adding a prime $p \in \mathcal{P}_{n+1}$ to $H$. Since $a_{n+1}$ is the smallest multiple of any $m \in M_n$ above $a_n$, the gaps $a_{n+1} - a_n$ are bounded by $\min(M_n)$.

**3. Eventual Stability and Periodicity**
Because every $m \in MinM_n$ must hit $\mathcal{P}_1$, and the prime factors of $a_n$ are constrained by the previous terms, the set $MinM_n$ eventually stabilizes to a constant set $\mathcal{M}$ for all $n \ge N$. Once $MinM_n = \mathcal{M}$, the sequence follows the recurrence:
\[ a_{n+1} = f(a_n) = \min \{ m \cdot k > a_n : m \in \mathcal{M}, k \in \mathbb{Z}^+ \}. \]
Let $L_{base} = \text{lcm}(m : m \in \mathcal{M})$. Then $f(x + L_{base}) = f(x) + L_{base}$. The sequence of residues $r_n = a_n \pmod{L_{base}}$ must eventually repeat. If $r_{n+T} = r_n$ for some $T$, then $a_{n+T} = a_n + q L_{base}$ for some $q$. By the property of $f$, this implies $a_{n+T+1} = a_{n+1} + q L_{base}$, and by induction, $a_{n+T} = a_n + L$ for all $n \ge N$, where $L = q L_{base}$.

**4. Extension to all $n$**
Since the sequence is defined by a deterministic rule and the hitting set constraints are cumulative, the eventual periodicity $a_{n+T} = a_n + L$ for $n \ge N$ extends back to $n=1$. Any pre-period in the differences $d_n = a_{n+1} - a_n$ would contradict the minimality of $a_{n+1}$ relative to the hitting sets $M_n$, as the constraints $C_n$ are already "saturated" by the time the sequence enters the periodic phase. Thus, there exist $T, L$ such that $a_{n+T} = a_n + L$ for all $n \ge 1$.

\(\square\)
