To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we proceed as follows.

First, we test the candidate solution $f(x) = x + a$ for some constant $a \ge 0$.
Substituting $f(x) = x + a$ into the inequalities:
1. The second inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ becomes $\frac{x + a + y}{2} \ge \sqrt{x(y + a)}$. By the AM-GM inequality, $\frac{x + (y + a)}{2} \ge \sqrt{x(y + a)}$, which holds for all $x, y > 0$ and $a \ge 0$.
2. The first inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$ becomes $\sqrt{\frac{x^2 + (y + a)^2}{2}} \ge \frac{x + a + y}{2}$. This is the RMS-AM inequality for the positive numbers $x$ and $y + a$, which holds for all $x, y > 0$ and $a \ge 0$.
Since $f(x) = x + a > 0$ for all $x > 0$ when $a \ge 0$, $f(x) = x + a$ is a solution for any $a \in [0, \infty)$.

To prove these are the only solutions, fix $y > 0$ and let $z = f(y)$. The given inequality is:
\[ \sqrt{\frac{x^2 + z^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{xz} \quad \text{for all } x > 0. \]
Setting $x = z$, we have:
\[ \sqrt{\frac{z^2 + z^2}{2}} \ge \frac{f(z) + y}{2} \ge \sqrt{z \cdot z} \implies z \ge \frac{f(z) + y}{2} \ge z. \]
Thus, $\frac{f(z) + y}{2} = z$, which implies $f(z) = 2z - y$. Since $z = f(y)$, we have the functional equation:
\[ f(f(y)) = 2f(y) - y. \]
Let $a(x) = f(x) - x$. Then $f(y) = y + a(y)$. The functional equation becomes:
\[ f(y) + a(f(y)) = 2f(y) - y \implies a(f(y)) = f(y) - y = a(y). \]
Now, rewrite the original inequality using $a(x)$ and $a(y)$. Let $z = f(y) = y + a(y)$. The inequality $\sqrt{\frac{x^2 + z^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{xz}$ can be compared to the standard RMS-AM-GM inequalities $\sqrt{\frac{x^2 + z^2}{2}} \ge \frac{x + z}{2} \ge \sqrt{xz}$.
The middle term of our inequality is:
\[ \frac{f(x) + y}{2} = \frac{x + a(x) + y}{2} = \frac{x + y + a(x)}{2}. \]
The standard Arithmetic Mean is $\frac{x + z}{2} = \frac{x + y + a(y)}{2}$. The difference is:
\[ \frac{f(x) + y}{2} - \frac{x + z}{2} = \frac{a(x) - a(y)}{2}. \]
Thus, we have:
\[ \text{RMS}(x, z) \ge \text{AM}(x, z) + \frac{a(x) - a(y)}{2} \ge \text{GM}(x, z). \]
From the first part, $\frac{a(x) - a(y)}{2} \le \text{RMS}(x, z) - \text{AM}(x, z)$.
For any fixed $x, y$, this must hold for $z = f(y)$. As we vary $y$, $z$ varies over the image of $f$. Since $f(x) = x + a(x)$ and $a(x) \ge 0$ (as $f(f(y)) = 2f(y) - y$ implies $f_n(y) = n(f(y)-y) + y > 0$ for all $n$, so $f(y) \ge y$), the image of $f$ contains an interval.
The minimum of $\text{RMS}(x, z) - \text{AM}(x, z)$ over $z > 0$ is $0$, achieved at $z = x$.
Since $a(x) - a(y) \le 2(\text{RMS}(x, z) - \text{AM}(x, z))$ for all $z \in \text{Im}(f)$, and $\text{Im}(f)$ is an interval, we can take $z$ arbitrarily close to $x$, implying:
\[ a(x) - a(y) \le 0 \implies a(x) \le a(y) \quad \text{for all } x, y > 0. \]
This forces $a(x)$ to be a constant $a$. Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $a \ge 0$.

The solutions are $f(x) = x + a$ for any $a \ge 0$.

\(\square\)
