To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we analyze the two inequalities.

**1. Analysis of the Right Inequality**
The inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ can be rewritten as:
\[ f(x) + y \ge 2\sqrt{x f(y)} \quad (*) \]
For any fixed $y$, this must hold for all $x > 0$. This provides a lower bound for $f(x)$:
\[ f(x) \ge 2\sqrt{x f(y)} - y \]
Taking the supremum over all $y > 0$, we have $f(x) \ge \sup_{y > 0} (2\sqrt{x f(y)} - y)$.

**2. Analysis of the Left Inequality**
The inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$ can be rewritten as:
\[ 2x^2 + 2f(y)^2 \ge (f(x) + y)^2 \quad (**) \]
Rearranging for $f(x)$, we obtain:
\[ f(x) \le \sqrt{2x^2 + 2f(y)^2} - y \]
Taking the infimum over all $y > 0$, we have $f(x) \le \inf_{y > 0} (\sqrt{2x^2 + 2f(y)^2} - y)$.

**3. Determining the Function $f$**
Combining the bounds, we have:
\[ \sup_{y > 0} (2\sqrt{x f(y)} - y) \le f(x) \le \inf_{y > 0} (\sqrt{2x^2 + 2f(y)^2} - y) \]
Let $f(x) = x + c(x)$. If $f(y) = y + c$ for some constant $c \ge 0$, then:
- $\sup_{y > 0} (2\sqrt{x(y+c)} - y)$ occurs at $y = x-c$ (for $x > c$), yielding $2x - (x-c) = x+c$.
- $\inf_{y > 0} (\sqrt{2x^2 + 2(y+c)^2} - y)$ occurs at $y = x-c$ (for $x > c$), yielding $2x - (x-c) = x+c$.
This suggests $f(x) = x + c$.

To prove this is the only form, note that $f$ is bounded between two continuous functions of $x$, so $f$ is continuous. Since $f(x) \ge 2\sqrt{x f(y)} - y$, as $x \to \infty$, $f(x) \to \infty$. Thus, $f$ takes all values in $(a, \infty)$ where $a = \inf f$. For any $x > a$, there exists $y$ such that $f(y) = x$. Substituting $f(y)=x$ into the bounds:
\[ 2\sqrt{x \cdot x} - y \le f(x) \le \sqrt{2x^2 + 2x^2} - y \implies 2x - y \le f(x) \le 2x - y \]
Thus $f(x) = 2x - y$. Since $f(y) = x$, we have $f(x) - x = x - y = f(y) - y$. This implies $f(x) - x$ is a constant $c$ for all $x > a$. Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $c \ge 0$. The domain of the constant $c$ can be extended to all $x \in (0, a]$ by using the original inequalities with $y > a$.

**4. Verification**
Let $f(x) = x + c$ for $c \ge 0$.
- Right: $\frac{x+c+y}{2} \ge \sqrt{x(y+c)} \iff (x+y+c)^2 \ge 4x(y+c) \iff (x-y)^2 + c^2 + 2yc - 2xc \ge 0$.
- Left: $2x^2 + 2(y+c)^2 \ge (x+y+c)^2 \iff 2x^2 + 2y^2 + 4yc + 2c^2 \ge x^2 + y^2 + c^2 + 2xy + 2xc + 2yc \iff (x-y)^2 + c^2 + 2yc - 2xc \ge 0$.
Both reduce to $g(x) = x^2 - 2(y+c)x + (y^2 + 2yc + c^2) \ge 0$. The vertex is at $x = y+c$, where $g(y+c) = 0$. Thus, the inequalities hold for all $x, y > 0$ and $c \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \ge 0$. \(\square\)
