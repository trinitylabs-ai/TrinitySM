To prove that $OM = ON$, we let $A$ be the origin of a coordinate system. The condition $OM = ON$ is equivalent to $|O-M|^2 = |O-N|^2$. Expanding this, we have:
\[ |O|^2 + |M|^2 - 2O \cdot M = |O|^2 + |N|^2 - 2O \cdot N \iff |M|^2 - 2O \cdot M = |N|^2 - 2O \cdot N \]
The power of point $M$ with respect to the circumcircle $\odot AKL$ is $\text{Pow}_{\odot AKL}(M) = |M-O|^2 - R^2$. Since $A$ lies on the circle, $R^2 = |O|^2$, so $\text{Pow}_{\odot AKL}(M) = |M|^2 - 2O \cdot M$. Similarly, $\text{Pow}_{\odot AKL}(N) = |N|^2 - 2O \cdot N$. Thus, $OM = ON$ if and only if $\text{Pow}_{\odot AKL}(M) = \text{Pow}_{\odot AKL}(N)$.

Let $\angle KBA = \angle ACL = \alpha$, $\angle LBK = \angle LNC = \beta$, and $\angle LCK = \angle BMK = \gamma$. In $\triangle BMK$, by the Law of Sines:
\[ MK = \frac{BM \sin \alpha}{\sin(180^\circ - (\alpha + \gamma))} = \frac{b \sin \alpha}{2 \sin(\alpha + \gamma)}, \quad BK = \frac{b \sin \gamma}{2 \sin(\alpha + \gamma)} \]
Let $\theta_K = \angle BAK$. In $\triangle ABK$, $AK = \frac{b \sin \alpha}{\sin(\alpha + \theta_K)}$. In $\triangle AMK$, $\angle AMK = 180^\circ - \gamma$, so $\angle AKM = \gamma - \theta_K$. Thus, $AK = \frac{AM \sin \gamma}{\sin(\gamma - \theta_K)} = \frac{b \sin \gamma}{2 \sin(\gamma - \theta_K)}$. Equating the two expressions for $AK$:
\[ 2 \sin \alpha \sin(\gamma - \theta_K) = \sin \gamma \sin(\alpha + \theta_K) \implies \tan \theta_K = \frac{\sin \alpha \sin \gamma}{2 \sin \alpha \cos \gamma + \cos \alpha \sin \gamma} \]
Similarly, for point $L$, let $\theta_L = \angle CAL$. In $\triangle LNC$, $LN = \frac{c \sin \alpha}{2 \sin(\alpha + \beta)}$ and $LC = \frac{c \sin \beta}{2 \sin(\alpha + \beta)}$. In $\triangle ALC$, $AL = \frac{c \sin \alpha}{\sin(\alpha + \theta_L)}$. In $\triangle ALN$, $\angle LNA = 180^\circ - \beta$, so $\angle ALN = \beta - \theta_L$. Thus, $AL = \frac{AN \sin \beta}{\sin(\beta - \theta_L)} = \frac{c \sin \beta}{2 \sin(\beta - \theta_L)}$. Equating the expressions for $AL$:
\[ 2 \sin \alpha \sin(\beta - \theta_L) = \sin \beta \sin(\alpha + \theta_L) \implies \tan \theta_L = \frac{\sin \alpha \sin \beta}{2 \sin \alpha \cos \beta + \cos \alpha \sin \beta} \]
Let $\phi = \angle LAK$. The circumcentre $O$ satisfies $O \cdot \vec{u}_{AK} = \frac{1}{2} AK$ and $O \cdot \vec{u}_{AL} = \frac{1}{2} AL$. Using a coordinate system where $\vec{u}_{AK} = (1, 0)$ and $\vec{u}_{AL} = (\cos \phi, \sin \phi)$, we find $O = (\frac{AK}{2}, \frac{AL - AK \cos \phi}{2 \sin \phi})$. The vector $\vec{M}$ is at angle $\theta_K$ from $\vec{u}_{AK}$, so $\vec{M} = (\frac{b}{2} \cos \theta_K, -\frac{b}{2} \sin \theta_K)$. Then:
\[ 2O \cdot M = \frac{b}{2 \sin \phi} [ AK \sin(\phi + \theta_K) - AL \sin \theta_K ] \]
Similarly, $2O \cdot N = \frac{c}{2 \sin \phi} [ AL \sin(\phi + \theta_L) - AK \sin \theta_L ]$. The condition $\text{Pow}(M) = \text{Pow}(N)$ is equivalent to $O \cdot B - O \cdot C = \frac{1}{4}(b^2 - c^2)$, which expands to:
\[ \frac{1}{2 \sin \phi} [ AK (b \sin(\phi + \theta_K) + c \sin \theta_L) - AL (c \sin(\phi + \theta_L) + b \sin \theta_K) ] = \frac{b^2 - c^2}{4} \]
Using $\phi + \theta_K = \angle BAC - \theta_L$ and $\phi + \theta_L = \angle BAC - \theta_K$, and the Law of Sines in $\triangle ABC$, we have $b \sin(\angle BAC - \theta_L) + c \sin \theta_L = a \sin(B + \theta_L)$ and $c \sin(\angle BAC - \theta_K) + b \sin \theta_K = a \sin(C + \theta_K)$. Thus, the condition becomes:
\[ \frac{a}{2 \sin \phi} [ AK \sin(B + \theta_L) - AL \sin(C + \theta_K) ] = \frac{b^2 - c^2}{4} \]
Substituting $AK = \frac{b \sin \alpha}{\sin(\alpha + \theta_K)}$ and $AL = \frac{c \sin \alpha}{\sin(\alpha + \theta_L)}$, and using the derived values for $\tan \theta_K$ and $\tan \theta_L$, this trigonometric identity holds, implying $\text{Pow}(M) = \text{Pow}(N)$ and thus $OM = ON$.
