To determine for which real values of $\theta \in (0^\circ, 180^\circ)$ Mulan can guarantee victory, we analyze the game's mechanics. Mulan wins if she can force the triangle $T$ to have an angle exactly $\theta$.

### 1. Sufficiency: $\theta = 180^\circ/n$ for $n \in \{2, 3, \dots\}$
Assume $\theta = 180^\circ/n$ for some integer $n \ge 2$. Mulan's strategy is to force the triangle to have an angle that is an integer multiple $k\theta$ for $k \in \{1, \dots, n-1\}$.

**Case 1: $T$ has an angle $k\theta$ for $k \in \{1, \dots, n-1\}$.**
If $k=1$, Mulan wins immediately. If $k > 1$, Mulan cuts the angle $k\theta$ into $\theta$ and $(k-1)\theta$. The two resulting triangles are $T_a$ (with an angle $\theta$) and $T_b$ (with an angle $(k-1)\theta$). Since $T_a$ has an angle $\theta$, Shan-Yu must discard it and pick $T_b$. Repeating this $k-1$ times, Mulan forces an angle $\theta$ and wins.

**Case 2: All angles of $T$ are $>\theta$.**
Mulan identifies the smallest angle $\gamma$. She cuts $\gamma$ into $\theta$ and $\gamma - \theta$. The resulting triangles are $T_a$ (with an angle $\theta$) and $T_b$ (with an angle $\gamma - \theta$). Shan-Yu must pick $T_b$. This process reduces the smallest angle by $\theta$ in each step. Since $\gamma$ is finite, this must terminate in finitely many steps, resulting in a triangle where the smallest angle $\gamma^{(m)} \le \theta$. If $\gamma^{(m)} = \theta$, Mulan wins. If $\gamma^{(m)} < \theta$, we proceed to Case 3.

**Case 3: $T$ has an angle $\gamma < \theta$.**
Mulan aims to force an angle $180^\circ - \theta = (n-1)\theta$. Let the angles be $(\alpha, \beta, \gamma)$ with $\gamma < \theta$. Mulan cuts $\alpha$ into $\alpha_1, \alpha_2$ such that $T_a$ has angles $(\alpha_1, \beta, 180^\circ - \beta - \alpha_1)$. By setting $\alpha_1 = 180^\circ - \beta - \theta$, $T_a$ has an angle $\theta$. This cut is valid if $0 < 180^\circ - \beta - \theta < \alpha$. The second inequality is $180^\circ - \theta < \alpha + \beta$, which is equivalent to $\gamma < \theta$ (true). The first is $\beta + \theta < 180^\circ$.
- If $\beta + \theta < 180^\circ$, Shan-Yu must pick $T_b$, which has angles $(\alpha - \alpha_1, \gamma, \beta + \alpha_1) = (\alpha + \beta + \theta - 180^\circ, \gamma, 180^\circ - \theta)$. Since $180^\circ - \theta = (n-1)\theta$, Mulan wins by Case 1.
- If $\beta + \theta \ge 180^\circ$, then $\alpha + \gamma = 180^\circ - \beta \le \theta$. Since $\alpha, \gamma > 0$, both $\alpha < \theta$ and $\gamma < \theta$. Mulan cuts $\beta$ into $\beta_1, \beta_2$ such that $T_a$ has angles $(\beta_1, \alpha, 180^\circ - \alpha - \beta_1)$. Setting $\beta_1 = 180^\circ - \alpha - \theta$ is valid if $0 < 180^\circ - \alpha - \theta < \beta$. The second inequality is $180^\circ - \theta < \alpha + \beta$, which is $\gamma < \theta$ (true). The first is $\alpha + \theta < 180^\circ$ (true since $\alpha < \theta < 180^\circ$). Shan-Yu must pick $T_b$, which has angles $(\beta - \beta_1, \gamma, \alpha + \beta_1) = (\beta + \alpha + \theta - 180^\circ, \gamma, 180^\circ - \theta)$. Again, $T_b$ has an angle $(n-1)\theta$, and Mulan wins.

### 2. Necessity: $\theta \neq 180^\circ/n$
If $\theta$ is not of the form $180^\circ/n$ for $n \in \{2, 3, \dots\}$, Shan-Yu can choose an initial triangle $T$ with angles $x, y, z$ such that $x, y, \theta, 180^\circ$ are linearly independent over $\mathbb{Q}$. 

Any cut Mulan makes to force Shan-Yu to pick $T_b$ requires $T_a$ to have an angle $\theta$. If the current angles are $\{\phi_1, \phi_2, \phi_3\}$, a forced move results in new angles:
1. $\{\phi_1 - \theta, \phi_3, \phi_2 + \theta\}$ (by cutting $\phi_1$ such that $T_a$ has angle $\theta$ at the cut vertex).
2. $\{\phi_1 + \phi_2 + \theta - 180^\circ, \phi_3, 180^\circ - \theta\}$ (by cutting $\phi_1$ such that $T_a$ has angle $\theta$ at the opposite vertex).

Let $H = \{k\theta + l 180^\circ \mid k, l \in \mathbb{Z}\}$ be the group of angles that are linear combinations of $\theta$ and $180^\circ$. Initially, no angle of $T$ is in $H$. In Move 1, if no angle is in $H$, no new angle enters $H$. In Move 2, the angle $\phi_3 = 180^\circ - \theta$ is produced, which is in $H$. 

If $T$ contains exactly one angle $\phi \in H$, Move 1 results in $\phi \pm \theta \in H$, and Move 2 results in $\phi_3 = 180^\circ - \theta \in H$. In both cases, the resulting triangle still contains exactly one angle in $H$. If $T$ contains no angles in $H$, Move 2 produces exactly one angle in $H$. Thus, Mulan can only ever produce one angle $\phi \in H$ at a time.

For any such $\phi$, we observe its value modulo $\theta$. Initially, $\phi_3 = 180^\circ - \theta \equiv 180^\circ \pmod \theta$. Move 1 gives $\phi \pm \theta \equiv \phi \pmod \theta$. Move 2 always resets the angle in $H$ to $180^\circ - \theta \equiv 180^\circ \pmod \theta$. Therefore, any angle $\phi \in H$ produced by Mulan must satisfy $\phi \equiv 180^\circ \pmod \theta$. 

Mulan wins if she produces $\phi = \theta$. This requires $\theta \equiv 180^\circ \pmod \theta$, which implies $180^\circ \equiv 0 \pmod \theta$. This means $180^\circ = n\theta$ for some integer $n$, which contradicts the assumption $\theta \neq 180^\circ/n$.

Mulan can guarantee victory if and only if $\theta = \frac{180^\circ}{n}$ for some integer $n \ge 2$.
