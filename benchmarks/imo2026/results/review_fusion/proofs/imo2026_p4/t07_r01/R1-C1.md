To determine for which real values of $\theta \in (0^\circ, 180^\circ)$ Mulan can guarantee victory, we analyze the game's mechanics. Let the angles of the current triangle $T$ be $A, B, C$. Mulan's move consists of choosing a vertex (say $A$) and a point $P$ on the opposite side $BC$, dividing $\angle A$ into $\alpha$ and $\beta$ ($\alpha + \beta = A$). The resulting triangles are $T_1$ with angles $(\alpha, B, 180^\circ - \alpha - B)$ and $T_2$ with angles $(\beta, C, 180^\circ - \beta - C)$. Shan-Yu then chooses which triangle to keep.

**1. Sufficient Condition: $\theta = 180^\circ/k$ for $k \in \{2, 3, \dots\}$**
If $\theta = 180^\circ/k$, Mulan can force a win using the following strategy:
- **Case $k=2$ ($\theta=90^\circ$):** Mulan picks $P$ such that $AP \perp BC$. Then $\angle APC = \angle APB = 90^\circ$. Regardless of Shan-Yu's choice, the new triangle has an angle of $90^\circ$. Mulan wins in one step.
- **Case $k \ge 3$:** Mulan's goal is to force an angle that is a multiple of $\theta$.
    - First, Mulan ensures the triangle has an angle strictly less than $\theta$. If all angles $A, B, C \ge \theta$, she repeatedly chooses an angle $A > \theta$ and cuts $\alpha = \theta$. The resulting triangle $T_1$ has an angle $\theta$, so Shan-Yu must pick $T_2$ with angles $(A-\theta, C, 180^\circ - A + \theta - C)$. This process must terminate because $A$ is finite and decreases by $\theta$ in each step. The process ends when Mulan either hits $\theta$ exactly (winning immediately) or obtains an angle $C' < \theta$.
    - Once $T$ has an angle $C' < \theta$, Mulan picks vertex $A$ such that $B < 180^\circ - \theta$. (This is always possible: if $B \ge 180^\circ - \theta$, then $A+C' = 180^\circ - B \le \theta$, implying $A < \theta$, so she can cut from vertex $B$ instead). She sets $\alpha = 180^\circ - B - \theta$. Since $C' < \theta$, we have $\alpha = 180^\circ - B - \theta < 180^\circ - B - C' = A$, and since $B < 180^\circ - \theta$, we have $\alpha > 0$. Thus $\alpha$ is a valid cut.
    - $T_1$ has an angle $180^\circ - \alpha - B = \theta$, so Shan-Yu must pick $T_2$. The angles of $T_2$ are $(\beta, C', 180^\circ - \beta - C')$. Since $\beta = A - \alpha = A - (180^\circ - B - \theta) = A + B + \theta - 180^\circ = \theta - C'$, the angles of $T_2$ are $(\theta - C', C', 180^\circ - \theta)$.
    - Since $180^\circ = k\theta$, the angle $180^\circ - \theta = (k-1)\theta$.
    - If $T$ has an angle $n\theta$ for $n \ge 2$, Mulan cuts it into $\theta$ and $(n-1)\theta$. $T_1$ has $\theta$, so Shan-Yu must pick $T_2$. If $n > 2$, $T_2$ has angle $(n-1)\theta$; if $n=2$, both triangles have angle $\theta$. Repeating this, Mulan forces an angle of $2\theta$, then splits it into $\theta$ and $\theta$, guaranteeing victory.

**2. Necessary Condition: $\theta = 180^\circ/k$**
Suppose $180^\circ/\theta$ is not an integer. Shan-Yu can prevent Mulan from winning by ensuring that no angle of $T$ is ever a multiple of $\theta$. Initially, Shan-Yu chooses $T$ such that $A, B, C$ are not multiples of $\theta$.
- Suppose the current angles $A, B, C$ are not multiples of $\theta$. Mulan cuts $A$ into $\alpha, \beta$. For Mulan to force a multiple of $\theta$ in both $T_1$ and $T_2$, we must have:
    1. $\alpha = n\theta$ or $180^\circ - \alpha - B = n\theta$ for some $n \in \mathbb{Z}^+$.
    2. $\beta = m\theta$ or $180^\circ - \beta - C = m\theta$ for some $m \in \mathbb{Z}^+$.
- We check the four possible combinations:
    - If $\alpha = n\theta$ and $\beta = m\theta$, then $A = \alpha + \beta = (n+m)\theta$, contradicting that $A$ is not a multiple of $\theta$.
    - If $\alpha = n\theta$ and $180^\circ - \beta - C = m\theta$, then $180^\circ - (A - n\theta) - C = m\theta \implies 180^\circ - (A+C) + n\theta = m\theta \implies B + n\theta = m\theta \implies B = (m-n)\theta$, contradicting that $B$ is not a multiple of $\theta$.
    - If $180^\circ - \alpha - B = n\theta$ and $\beta = m\theta$, then $\alpha = 180^\circ - B - n\theta$, so $A - (180^\circ - B - n\theta) = m\theta \implies A+B+n\theta - 180^\circ = m\theta \implies 180^\circ - C + n\theta - 180^\circ = m\theta \implies C = (n-m)\theta$, contradicting that $C$ is not a multiple of $\theta$.
    - If $180^\circ - \alpha - B = n\theta$ and $180^\circ - \beta - C = m\theta$, then $\alpha = 180^\circ - B - n\theta$ and $\beta = 180^\circ - C - m\theta$. Thus $A = \alpha + \beta = 360^\circ - (B+C) - (n+m)\theta = 360^\circ - (180^\circ - A) - (n+m)\theta = 180^\circ + A - (n+m)\theta$, which implies $180^\circ = (n+m)\theta$, contradicting that $180^\circ/\theta$ is not an integer.
- Thus, Shan-Yu can always choose a triangle that contains no multiple of $\theta$. Specifically, no angle will ever be $\theta$.

Mulan can guarantee victory if and only if $\theta = 180^\circ/k$ for some integer $k \ge 2$.

The real values of $\theta$ are $\theta = \frac{180^\circ}{k}$ for $k \in \{2, 3, 4, \dots\}$.

\(\square\)
