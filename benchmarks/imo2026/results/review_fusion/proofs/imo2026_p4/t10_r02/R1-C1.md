To determine for which real values of $\theta \in (0^\circ, 180^\circ)$ Mulan can guarantee victory, we analyze the game's dynamics. Mulan wins if she can force the triangle $T$ to have an angle exactly equal to $\theta$.

Let $W_\theta = \{ n\theta \pmod{180^\circ} \mid n \in \mathbb{Z} \} \setminus \{0^\circ\}$. We claim that Mulan can guarantee victory if and only if $\theta \in \mathbb{Q} \cdot 180^\circ$ and $\theta \le 90^\circ$.

### 1. Winning States
First, we show that if a triangle $T$ has an angle $\alpha \in W_\theta$, Mulan can force a win.
If $\alpha = \theta$, Mulan wins immediately.
If $\alpha > \theta$, Mulan cuts $\alpha$ into $\theta$ and $\alpha - \theta$. The resulting triangles are $T_1$ (containing $\theta$) and $T_2$ (containing $\alpha - \theta$). Since $\alpha \in W_\theta$, we have $\alpha - \theta \in W_\theta$. Shan-Yu must discard $T_1$ to avoid immediate loss, so the new triangle $T$ has an angle $\alpha - \theta \in W_\theta$. This process reduces the angle in $W_\theta$ until it equals $\theta$.
If $\alpha < \theta$, let $\beta$ and $\gamma$ be the other angles of $T$. Since $\alpha + \beta + \gamma = 180^\circ$, we have $\beta + \gamma = 180^\circ - \alpha$. Mulan cuts $\beta$ into $\phi = \theta$ and $\beta - \theta$. If $\beta \le \theta$, she can instead cut $\beta$ into $\phi = \theta - \alpha$ and $\beta - \phi$ to force an angle in $W_\theta$. More generally, if $\alpha \in W_\theta$, then $180^\circ - \alpha \in W_\theta$. By cutting $\beta$ into $\phi = \theta$, $T_1$ has $\theta$ and $T_2$ has angles $(\gamma, \beta - \theta, 180^\circ - \gamma - \beta + \theta) = (\gamma, \beta - \theta, \alpha + \theta)$. Since $\alpha \in W_\theta$, $\alpha + \theta \in W_\theta$. Shan-Yu must keep $T_2$, which increases the angle in $W_\theta$ until it exceeds $\theta$, at which point the reduction strategy applies.

### 2. Forcing $W_\theta$ for $\theta \in \mathbb{Q} \cdot 180^\circ \cap (0^\circ, 90^\circ]$
If $\theta \in \mathbb{Q} \cdot 180^\circ$, $W_\theta$ is a finite set. We show Mulan can force an angle into $W_\theta$ from any $T_0 = (\alpha, \beta, \gamma)$.
If $T$ has an angle $\gamma > \theta$, Mulan cuts $\alpha$ into $\phi = 180^\circ - \beta - \theta$ and $\alpha - \phi$. This cut is valid if $0 < 180^\circ - \beta - \theta < \alpha$, which is equivalent to $\gamma > \theta$ and $\beta + \theta < 180^\circ$. Since $\gamma > \theta$, $\alpha + \beta = 180^\circ - \gamma < 180^\circ - \theta$, so $\beta + \theta < 180^\circ$ is guaranteed.
The resulting triangles are $T_1$ (with angles $\beta, 180^\circ - \beta - \theta, \theta$) and $T_2$ (with angles $\gamma, \alpha + \beta + \theta - 180^\circ, 180^\circ - \theta$). $T_1$ contains $\theta$, and $T_2$ contains $180^\circ - \theta \in W_\theta$. Thus, Mulan forces an angle into $W_\theta$.

If all angles of $T$ are $\le \theta$, then $3\theta \ge 180^\circ$, so $\theta \ge 60^\circ$. If $\theta = 90^\circ$, Mulan cuts the altitude from any vertex, creating two right triangles, and wins immediately. If $60^\circ \le \theta < 90^\circ$ and all angles are $\le \theta$, Mulan can cut $\alpha$ into $\phi = \theta + \epsilon + \gamma + \alpha - 180^\circ$ for a small $\epsilon > 0$. This creates an angle $\theta + \epsilon > \theta$ in $T_2$, and $T_1$ also has an angle $180^\circ - \theta - \epsilon > \theta$ (since $2\theta < 180^\circ$). Thus, Mulan forces an angle $>\theta$, reducing the game to the previous case.

### 3. Non-Winning Values
If $\theta > 90^\circ$, $W_\theta = \{\theta\}$. Shan-Yu can choose $T_0$ to be scalene with no angle $\theta$. Mulan can only force $\theta$ if she can make both $T_1$ and $T_2$ contain $\theta$. For $T_1$ to have $\theta$, $\phi = \theta$ or $180^\circ - \beta - \phi = \theta$. If $\phi = \theta$, $T_2$ has angles $(\gamma, \alpha - \theta, \beta + \theta - \gamma)$. For $T_2$ to have $\theta$, we need $\alpha - \theta = \theta$ (impossible since $2\theta > 180^\circ$) or $\beta + \theta - \gamma = \theta \implies \beta = \gamma$. By choosing $T_0$ scalene, Shan-Yu prevents this.
If $\theta \notin \mathbb{Q} \cdot 180^\circ$, $W_\theta$ is dense but does not contain any angle of $T_0$ if Shan-Yu chooses $\alpha, \beta, \gamma$ to be algebraically independent over $\mathbb{Q}(\theta, 180^\circ)$. Mulan cannot force an angle into $W_\theta$ because creating an angle in $W_\theta$ in $T_1$ would require $T_2$ to already have an angle in $W_\theta$ to prevent Shan-Yu from simply discarding the winning branch.

The values of $\theta$ for which Mulan can guarantee victory are $\theta \in \mathbb{Q} \cdot 180^\circ \cap (0^\circ, 90^\circ]$.
