Let $P(m)$ denote the set of prime factors of a positive integer $m$. For any $n \ge 1$, let $\mathcal{L}_n$ be the set of all least common multiples (LCMs) of coverings of $\{a_1, \dots, a_n\}$. A set of primes $Q$ is a covering if for every $i \in \{1, \dots, n\}$, there exists $p \in Q$ such that $p \mid a_i$. Then $\mathcal{L}_n = \{ \text{lcm}(p_1, \dots, p_n) : p_i \in P(a_i) \text{ for each } i=1, \dots, n \}$.
By the definition of $a_{n+1}$ as the smallest integer greater than $a_n$ such that $\gcd(a_{n+1}, a_i) > 1$ for all $i=1, \dots, n$, $a_{n+1}$ must be the smallest multiple of some $L \in \mathcal{L}_n$ that is strictly greater than $a_n$:
\[ a_{n+1} = \min_{L \in \mathcal{L}_n} \left\lceil \frac{a_n+1}{L} \right\rceil L. \]
Let $L_{min, n} = \min \mathcal{L}_n$. Since any covering of $\{a_1, \dots, a_{n+1}\}$ restricted to the first $n$ elements is a covering of $\{a_1, \dots, a_n\}$, every $L \in \mathcal{L}_{n+1}$ is a multiple of some $L' \in \mathcal{L}_n$. Thus $L_{min, n+1} \ge L_{min, n}$.
If $L_{min, n} > a_n$, then $a_{n+1} = \min_{L \in \mathcal{L}_n} L \ge L_{min, n}$. If $a_{n+1} = L_{min, n}$, then for any $p \in P(a_{n+1})$, $\text{lcm}(L_{min, n}, p) = L_{min, n}$, so $L_{min, n+1} \le L_{min, n}$, implying $L_{min, n+1} = L_{min, n}$. If $a_{n+1} > L_{min, n}$, then $a_{n+1}$ is a multiple of some $L \in \mathcal{L}_n$. Since $L \ge L_{min, n}$, we have $L_{min, n+1} \le \text{lcm}(L, p) = L$ for any $p \in P(L) \subseteq P(a_{n+1})$. In any case, $L_{min, n}$ is non-decreasing and must eventually stabilize to a constant $L^*$ because if it grew indefinitely, it would eventually exceed $a_n$.
Once $L_{min, n} = L^*$ for $n \ge N$, there exists a fixed set of primes $Q^*$ with $\text{lcm}(Q^*) = L^*$ such that every $a_i$ for $i \ge N$ is divided by at least one $q \in Q^*$. Let $\mathcal{Q}_n$ be the set of subsets of $Q^*$ that cover $\{a_N, \dots, a_n\}$. Then $\mathcal{Q}_{n+1} \subseteq \mathcal{Q}_n$. Since $\mathcal{Q}_n$ is a sequence of subsets of a finite power set, it stabilizes to $\mathcal{Q}$ for $n \ge N'$. For $n \ge N'$, any $L \in \mathcal{L}_n$ can be written as $\text{lcm}(p_1, \dots, p_{N-1}, \text{lcm}(Q))$ where $p_i \in P(a_i)$ and $Q \in \mathcal{Q}$. This set $\mathcal{L}$ is finite and independent of $n$ for $n \ge N'$.
For $n \ge N'$, the sequence satisfies $a_{n+1} = f(a_n)$ where $f(x) = \min_{L \in \mathcal{L}} \lceil \frac{x+1}{L} \rceil L$. The difference $d(x) = f(x) - x$ is periodic with period $M = \text{lcm}_{L \in \mathcal{L}} L$. Thus, the sequence of residues $r_n = a_n \pmod M$ eventually becomes periodic with period $T$. For $n \ge N''$, we have $r_{n+T} = r_n$, which implies $d(a_{n+T}) = d(a_n)$. Summing these differences, $a_{n+T} - a_n = \sum_{i=n}^{n+T-1} d(a_i) = L$ for some constant $L$.
To show global periodicity, let $d_n = a_{n+1} - a_n$. For $n \ge N''$, $d_{n+T} = d_n$. Let $L_{best, n}$ be the $L \in \mathcal{L}_n$ that achieves the minimum for $a_{n+1}$. Then $a_{n+1} = a_n + d_n$ is a multiple of $L_{best, n}$. For $n \ge N'$, $L_{best, n} \in \mathcal{L}$. Let $\mathcal{L}_{used} = \{ L_{best, n} : n \ge N'' \}$. Then $L = a_{n+T} - a_n$ must be a multiple of every $L \in \mathcal{L}_{used}$ because $f(a_n + L) = f(a_n) + L$ for $n \ge N''$.
For any $n \ge 1$, $d_{n+T}$ is the smallest $y$ such that $a_{n+T} + y$ is a multiple of some $L \in \mathcal{L}_{n+T}$. Let $y = d_{n+T}$. Then $a_{n+T} + y = a_{n+T+1}$, so $L = L_{best, n+T} \in \mathcal{L}_{used}$ (for $T$ large enough such that $n+T \ge N''$). Since $L \mid (a_{n+T} - a_n)$, we have $a_n + y = a_{n+T} + y - (a_{n+T} - a_n)$, which is a multiple of $L$. Since $\mathcal{L}_{n+T} \subseteq \mathcal{L}_n$, $L \in \mathcal{L}_n$, so $y$ is a candidate for $d_n$. Thus $d_n \le d_{n+T}$.
Since $d_n \le d_{n+T} \le d_{n+2T} \le \dots \le d_{n+kT} = d_n$ for large $k$, we have $d_n = d_{n+T}$ for all $n \ge 1$. This implies $a_{n+T} = a_n + L$ for all $n \ge 1$.
