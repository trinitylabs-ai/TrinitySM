Let $\mathcal{P}(m)$ denote the set of prime factors of a positive integer $m$. The condition $\gcd(a_{n+1}, a_i) > 1$ for all $i = 1, \dots, n$ is equivalent to $\mathcal{P}(a_{n+1}) \cap \mathcal{P}(a_i) \neq \emptyset$ for all $i \in \{1, \dots, n\}$. Let $S_n = \mathcal{P}(a_n)$ and let $\mathcal{G}_n$ be the set of minimal elements of $\{S_1, \dots, S_n\}$ under set inclusion. An integer $x$ satisfies $\gcd(x, a_i) > 1$ for all $i \le n$ if and only if $\mathcal{P}(x)$ is a hitting set for $\mathcal{G}_n$ (i.e., $\mathcal{P}(x) \cap S \neq \emptyset$ for all $S \in \mathcal{G}_n$).

First, we show by induction that $\mathcal{G}_n$ is an intersecting family (i.e., for all $S, S' \in \mathcal{G}_n$, $S \cap S' \neq \emptyset$). For $n=1$, $\mathcal{G}_1 = \{S_1\}$, which is trivially intersecting. Assume $\mathcal{G}_n$ is intersecting. By definition, $a_{n+1}$ is the smallest integer $x > a_n$ such that $\mathcal{P}(x)$ hits every $S \in \mathcal{G}_n$. Thus $S_{n+1} \cap S \neq \emptyset$ for all $S \in \mathcal{G}_n$. Since any $S' \in \mathcal{G}_{n+1}$ is either an element of $\mathcal{G}_n$ or is $S_{n+1}$ (or a subset of $S_{n+1}$ if we only keep minimal elements), any two elements of $\mathcal{G}_{n+1}$ intersect.

A key property of intersecting families is that every $S \in \mathcal{G}_n$ is itself a hitting set for $\mathcal{G}_n$. Let $\mathcal{H}(\mathcal{G}_n)$ be the set of minimal hitting sets of $\mathcal{G}_n$. Any hitting set of $\mathcal{G}_n$ must contain some $H \in \mathcal{H}(\mathcal{G}_n)$. The smallest integer $x > a_n$ hitting $\mathcal{G}_n$ is $a_{n+1} = \min_{H \in \mathcal{H}(\mathcal{G}_n)} M_H \lceil (a_n+1)/M_H \rceil$, where $M_H = \prod_{p \in H} p$. Let $H^*$ be the minimal hitting set that achieves this minimum. Then $S_{n+1} = \mathcal{P}(k) \cup H^*$ for some $k \ge 1$.

For $S_{n+1}$ to be a minimal element of $\mathcal{G}_{n+1}$, it must not contain any $S \in \mathcal{G}_n$. Since $H^* \subseteq S_{n+1}$, this requires $H^*$ to not contain any $S \in \mathcal{G}_n$. However, if $H^*$ is a minimal hitting set and $S \in \mathcal{G}_n$ is a hitting set, then $S \subseteq H^*$ implies $S = H^*$. Thus, $S_{n+1}$ can be a minimal element only if $H^* \notin \mathcal{G}_n$ or $S_{n+1} = H^*$.

Crucially, any minimal hitting set $H$ of $\mathcal{G}_n$ satisfies $H \subseteq \bigcup \mathcal{G}_n$. This is because for every $p \in H$, there must exist $S \in \mathcal{G}_n$ such that $H \cap S = \{p\}$, implying $p \in S$. Since there are only finitely many subsets of any finite set $\bigcup \mathcal{G}_n$, and the process of adding minimal hitting sets to $\mathcal{G}_n$ and removing their supersets replaces elements with smaller sets, the family $\mathcal{G}_n$ must eventually stabilize. Thus, there exists $N$ such that $\mathcal{G}_n = \mathcal{G}$ for all $n \ge N$.

Let $C = \{x \in \mathbb{Z}^+ \mid \mathcal{P}(x) \text{ hits } \mathcal{G}\}$. The condition $x \in C$ is equivalent to $\gcd(x, \prod_{p \in S} p) > 1$ for all $S \in \mathcal{G}$. This property depends only on $x \pmod{M}$ where $M = \prod_{p \in \bigcup \mathcal{G}} p$. Thus, $C$ is a union of congruence classes modulo $M$. Let these classes be $r_1 < r_2 < \dots < r_T$ in $\{0, \dots, M-1\}$. The sequence of elements of $C$ in increasing order satisfies $c_{n+T} = c_n + M$.

We now show that $(a_n)_{n \ge 1}$ is a tail of the sequence $(c_k)$. First, we show $a_n \in C$ for all $n \ge 1$. Since $\mathcal{G}$ is the limit of $\mathcal{G}_n$, any $S \in \mathcal{G}$ is a subset of some $S_i$ for $i \le N$. Since $\mathcal{G}_N$ is an intersecting family, any $S \in \mathcal{G}$ is a hitting set for $\mathcal{G}_N$. Since $S_k$ is a superset of some $S' \in \mathcal{G}_N$, and $S$ hits $S'$, it follows that $S \cap S_k \neq \emptyset$. Thus $a_k \in C$ for all $k \ge 1$.

Since $a_{n+1}$ is the smallest integer $> a_n$ hitting $\mathcal{G}_n$, and $C$ is the set of integers hitting $\mathcal{G}$, and $\mathcal{G}_n$ is "easier" to hit than $\mathcal{G}$ (meaning $C \subseteq \{x \mid \mathcal{P}(x) \text{ hits } \mathcal{G}_n\}$), $a_{n+1}$ must be the smallest integer $> a_n$ hitting $\mathcal{G}$. If there were an $x \in C$ such that $a_n < x < a_{n+1}$, then $x$ would also hit $\mathcal{G}_n$, contradicting the definition of $a_{n+1}$. Thus, $(a_n)$ are consecutive elements of $C$ starting from $a_1$.

Setting $L = M$, we have $a_{n+T} = a_n + L$ for all $n \ge 1$.
