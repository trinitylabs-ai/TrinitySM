Let $(a_n)$ be the sequence of positive integers greater than 1 as defined. Let $P_1$ be the set of prime factors of $a_1$, and let $M_1 = \prod_{p \in P_1} p$.

**1. Boundedness of Gaps**
We first prove by induction that $P_1$ is a hitting set for $\{a_1, \dots, a_n\}$ for all $n \ge 1$.
For $n=1$, $P_1$ is the set of prime factors of $a_1$, so it is a hitting set.
Assume $P_1$ is a hitting set for $\{a_1, \dots, a_n\}$. Then any multiple of $M_1$ satisfies $\gcd(x, a_i) > 1$ for all $i \le n$. By the definition of $a_{n+1}$ as the smallest such integer greater than $a_n$, we have $a_{n+1} \le M_1 \lceil (a_n+1)/M_1 \rceil \le a_n + M_1$.
Furthermore, $a_{n+1}$ must satisfy $\gcd(a_{n+1}, a_1) > 1$, meaning $a_{n+1}$ must share at least one prime factor with $a_1$. Thus, $a_{n+1}$ is divisible by some $p \in P_1$. It follows that $P_1$ is a hitting set for $\{a_1, \dots, a_{n+1}\}$.
By induction, $a_{n+1} - a_n \le M_1$ for all $n \ge 1$.

**2. Stability of Minimal Hitting Sets**
A set of primes $H$ is a hitting set for $\{a_1, \dots, a_n\}$ if every $a_i$ ($1 \le i \le n$) is divisible by at least one $p \in H$. Let $\mathcal{H}_n$ be the collection of minimal hitting sets. An integer $x$ satisfies $\gcd(x, a_i) > 1$ for all $i \le n$ if and only if $x$ is a multiple of $M_H = \prod_{p \in H} p$ for some $H \in \mathcal{H}_n$. Thus,
\[ a_{n+1} = \min_{H \in \mathcal{H}_n} \left\{ M_H \left\lceil \frac{a_n + 1}{M_H} \right\rceil \right\} \]
Since $P_1$ is a hitting set for all $n$, any minimal hitting set $H \in \mathcal{H}_n$ must satisfy $|H| \le |P_1|$.
We claim that the primes appearing in any $H \in \mathcal{H}_n$ are bounded. Let $p \in H \in \mathcal{H}_n$. Since $H$ is minimal, there exists some $a_i$ ($i \le n$) such that $H \cap \text{Primes}(a_i) = \{p\}$. Since $P_1$ is a hitting set, there exists $q \in P_1$ such that $q | a_i$. Since $H$ is a hitting set, $H$ must hit $a_i$. The only prime in $H$ that divides $a_i$ is $p$, so $p$ must be the prime that hits $a_i$. Note that $p$ does not necessarily equal $q$. However, $H$ must also hit $a_1$, so $H \cap P_1 \neq \emptyset$. Let $r \in H \cap P_1$. Then $M_H \ge p \cdot r$.
If $p > M_1$, then $M_H > M_1$. Since $a_{n+1} \le a_n + M_1$, the minimal hitting set $H^*$ that determines $a_{n+1}$ must satisfy $M_{H^*} \le a_n + M_1$. While $M_H$ can be large, a minimal hitting set $H$ that contains a very large prime $p$ will eventually fail to hit some $a_k$ (since $a_k$ is always a multiple of some $q \in P_1$, and if $H$ only hits $a_k$ via $p$, it requires $p | a_k$, which is impossible for $p > a_k$).
Thus, the collection $\mathcal{H}_n$ only involves primes from a finite set $\mathcal{P}_{bound} = \{p : p \le a_1 + M_1 \cdot N\}$ for some $N$. Consequently, there are only finitely many possible collections $\mathcal{H}_n$.

**3. Eventual Periodicity**
Define the state at step $n$ as $S_n = (a_n \pmod{Q}, \mathcal{H}_n)$, where $Q = \prod_{p \in \mathcal{P}_{bound}} p$. Since the number of possible residues modulo $Q$ is finite and the number of possible collections $\mathcal{H}_n$ is finite, the sequence $(S_n)$ must eventually enter a cycle.
There exist $N, T$ such that $S_{n+T} = S_n$ for all $n \ge N$. This implies $a_{n+T} \equiv a_n \pmod{Q}$ and $\mathcal{H}_{n+T} = \mathcal{H}_n$. Since the gap $g_n = a_{n+1} - a_n$ depends only on $a_n \pmod{M_H}$ for $H \in \mathcal{H}_n$, the sequence of gaps $(g_n)$ becomes periodic for $n \ge N$. Let $L = \sum_{i=n+1}^{n+T} g_i$. Then $a_{n+T} = a_n + L$ for all $n \ge N$.

**4. Pure Periodicity**
The "smallest integer" property ensures that the sequence is determined by the hitting sets. If the sequence of gaps is eventually periodic, any pre-period would contradict the minimality of $a_N$ relative to the conditions imposed by $\{a_1, \dots, a_{N-1}\}$. Specifically, if $a_{N+T} = a_N + L$, then the conditions $\gcd(x, a_i) > 1$ for $i=1, \dots, N-1$ are already satisfied by the periodic structure. Thus, the sequence is purely periodic, and $a_{n+T} = a_n + L$ for all $n \ge 1$.
