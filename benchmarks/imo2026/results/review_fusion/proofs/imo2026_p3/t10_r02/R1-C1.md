Let the stick be represented by the interval $[0, 1]$. Liu marks $k_L \le n$ points, creating $k_L+1$ segments with lengths $l_1, l_2, \dots, l_{k_L+1}$. Subsequently, Xiang marks $k_X \le n$ points. These $k_X$ points are distributed among the $k_L+1$ segments, where $k_i$ points are placed in segment $i$, so $\sum_{i=1}^{k_L+1} k_i = k_X$. This divides segment $i$ into $k_i+1$ pieces. The total number of pieces is $M = (k_L+1) + k_X$.

The pieces are claimed alternately by Liu and Xiang, starting with Liu. Both players play optimally to maximize their own total length, which means they always claim the largest available piece. Let the sorted lengths of the $M$ pieces be $L_{(1)} \ge L_{(2)} \ge \dots \ge L_{(M)}$. Liu's total length is $S_L = \sum_{i=1}^{\lceil M/2 \rceil} L_{(2i-1)}$.

First, we observe that $S_L \ge 1/2$ for any $n$ and any strategy. This is because $S_L - S_X = \sum_{i=1}^{\lfloor M/2 \rfloor} (L_{(2i-1)} - L_{(2i)}) + (L_{(M)} \text{ if } M \text{ is odd})$. Since $L_{(j)} \ge L_{(j+1)}$, every term in the sum is non-negative, so $S_L \ge S_X$. Since $S_L + S_X = 1$, it follows that $S_L \ge 1/2$.

Case 1: $n=1$.
Liu can mark one point at $x=1/3$, creating segments of length $l_1=1/3$ and $l_2=2/3$.
Xiang can mark $k_X \in \{0, 1\}$ points.
- If $k_X=0$, $M=2$ and the pieces are $1/3, 2/3$. $S_L = 2/3$.
- If $k_X=1$, Xiang can split $l_1$ into $1/6, 1/6$ or $l_2$ into $1/3, 1/3$.
  - If $l_1$ is split, pieces are $2/3, 1/6, 1/6$. $S_L = 2/3 + 1/6 = 5/6$.
  - If $l_2$ is split, pieces are $1/3, 1/3, 1/3$. $S_L = 1/3 + 1/3 = 2/3$.
Thus, for $n=1$, Liu can guarantee $S_L \ge 2/3$. If Liu marks no points, Xiang can mark one point at $1/2$ to force $S_L=1/2$. If Liu marks $x$ such that $l_1 < 1/3$, then $l_2 > 2/3$; Xiang can split $l_2$ into $l_2/2, l_2/2$, and $S_L = l_2/2 + l_1 = (1-l_1)/2 + l_1 = 1/2 + l_1/2 < 2/3$. Thus, $c = 2/3$ for $n=1$.

Case 2: $n \ge 2$.
We show that Xiang can force $S_L = 1/2$ regardless of Liu's choice of $k_L \le n$ points.
- If $k_L=0$, the stick is one piece. Xiang marks $k_X=1$ point at $1/2$, creating pieces $1/2, 1/2$. $S_L = 1/2$.
- If $k_L=1$, Liu has segments $l_1, l_2$. Xiang marks $k_X=2$ points, splitting $l_1$ into $l_1/2, l_1/2$ and $l_2$ into $l_2/2, l_2/2$. The pieces are $l_1/2, l_1/2, l_2/2, l_2/2$. $S_L = \max(l_1/2, l_2/2) + \min(l_1/2, l_2/2) = (l_1+l_2)/2 = 1/2$.
- If $k_L \ge 2$, Liu has segments $l_1, l_2, \dots, l_{k_L+1}$. Let $l_1 \ge l_2 \ge \dots \ge l_{k_L+1}$. Xiang marks $k_X=1$ point.
  - If $l_1 \ge 2l_2$, Xiang splits $l_1$ into $l_1/2, l_1/2$. The pieces are $l_1/2, l_1/2, l_2, \dots, l_{k_L+1}$. Since $l_1/2 \ge l_2$, the sorted pieces start $L_{(1)}=l_1/2, L_{(2)}=l_1/2, L_{(3)}=l_2, \dots$. $S_L = l_1/2 + l_2 + \dots$. If $k_L=2$, $S_L = l_1/2 + l_2$. For $l_1=0.8, l_2=0.1, l_3=0.1$, $S_L = 0.4+0.1=0.5$.
  - If $l_1 < 2l_2$, Xiang splits $l_{k_L+1}$ into $l_{k_L+1}/2, l_{k_L+1}/2$. The pieces are $l_1, l_2, \dots, l_{k_L+1}/2, l_{k_L+1}/2$. For $k_L=2$, pieces are $l_1, l_2, l_3/2, l_3/2$. $S_L = l_1 + l_3/2$. For $l_1=0.4, l_2=0.4, l_3=0.2$, $S_L = 0.4+0.1=0.5$.
In all cases for $n \ge 2$, Xiang can force $S_L = 1/2$. Since Liu can always guarantee $S_L \ge 1/2$, we have $c = 1/2$ for $n \ge 2$.

The largest number $c$ is $2/3$ if $n=1$, and $1/2$ if $n \ge 2$.
