To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we analyze the given inequalities.

**1. Simplification of the inequalities**
The right inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ can be squared (since both sides are positive):
\[ (f(x) + y)^2 \ge 4x f(y). \quad (1) \]
The left inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$ can also be squared:
\[ \frac{x^2 + f(y)^2}{2} \ge \frac{(f(x) + y)^2}{4} \implies 2x^2 + 2f(y)^2 \ge (f(x) + y)^2. \quad (2) \]
Combining these, we have the chain:
\[ 4x f(y) \le (f(x) + y)^2 \le 2x^2 + 2f(y)^2. \]

**2. Testing $f(x) = x + c$**
Let $f(x) = x + c$ for some constant $c$. For $f$ to map $\mathbb{R}_{>0}$ to $\mathbb{R}_{>0}$, we must have $x + c > 0$ for all $x > 0$, which implies $c \ge 0$.
Substituting $f(x) = x + c$ into the inequalities:
The right inequality becomes $\frac{x + c + y}{2} \ge \sqrt{x(y + c)}$. Squaring both sides gives $\frac{(x + y + c)^2}{4} \ge x(y + c)$, which simplifies to $(x - (y + c))^2 \ge 0$. This is true for all $x, y > 0$ and $c \ge 0$.
The left inequality becomes $\sqrt{\frac{x^2 + (y + c)^2}{2}} \ge \frac{x + c + y}{2}$. This is the Root Mean Square-Arithmetic Mean (RMS-AM) inequality for the positive values $x$ and $y + c$, which is always true.
Thus, $f(x) = x + c$ for any $c \ge 0$ is a solution.

**3. Proving uniqueness**
Let $R_f$ be the range of $f$. For any $y \in \mathbb{R}_{>0}$, let $x = f(y)$. Substituting this into the chain $4x f(y) \le (f(x) + y)^2 \le 2x^2 + 2f(y)^2$ yields:
\[ 4f(y)^2 \le (f(f(y)) + y)^2 \le 2f(y)^2 + 2f(y)^2 = 4f(y)^2. \]
This forces $(f(f(y)) + y)^2 = 4f(y)^2$. Since $f(x), y > 0$, we have $f(f(y)) + y = 2f(y)$, which simplifies to:
\[ f(f(y)) - f(y) = f(y) - y. \]
Let $\epsilon(x) = f(x) - x$. The equation above becomes $\epsilon(f(y)) = \epsilon(y)$ for all $y \in \mathbb{R}_{>0}$.
Furthermore, the sequence $a_n$ defined by $a_0 = y$ and $a_{n+1} = f(a_n)$ satisfies $a_{n+1} - a_n = a_n - a_{n-1} = \epsilon(y)$. Thus $a_n = y + n\epsilon(y)$. Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $y + n\epsilon(y) > 0$ for all $n \in \mathbb{N}$, which implies $\epsilon(y) \ge 0$ for all $y > 0$. Thus $f(x) \ge x$ for all $x > 0$.

Now, for any $x \in \mathbb{R}_{>0}$ and any $z \in R_f$, there exists $y$ such that $f(y) = z$. Then $y = z - \epsilon(z)$. Substituting $f(y) = z$ and $y = z - \epsilon(z)$ into (1) and (2):
\[ 4xz \le (f(x) + z - \epsilon(z))^2 \le 2x^2 + 2z^2. \]
Taking the square root and rearranging gives:
\[ 2\sqrt{xz} - z + \epsilon(z) \le f(x) \le \sqrt{2x^2 + 2z^2} - z + \epsilon(z). \]
Restrict $x$ to the range $R_f$. Then $f(x) = x + \epsilon(x)$. The inequality becomes:
\[ 2\sqrt{xz} - z + \epsilon(z) \le x + \epsilon(x) \le \sqrt{2x^2 + 2z^2} - z + \epsilon(z). \]
From the left side, we have $\epsilon(z) - \epsilon(x) \le x + z - 2\sqrt{xz} = (\sqrt{x} - \sqrt{z})^2$.
By symmetry, swapping $x$ and $z$ (both in $R_f$) gives $\epsilon(x) - \epsilon(z) \le (\sqrt{z} - \sqrt{x})^2$.
Thus, for all $x, z \in R_f$, we have $|\epsilon(x) - \epsilon(z)| \le (\sqrt{x} - \sqrt{z})^2$.

For any $z \in R_f$, the squeeze $2\sqrt{xz} - z + \epsilon(z) \le f(x) \le \sqrt{2x^2 + 2z^2} - z + \epsilon(z)$ implies that $f$ is continuous at $x = z$. Since $f$ is continuous at every point in its range $R_f$, and $f(y) \ge y$ implies $f$ is injective (if $f(y_1)=f(y_2)$, then $f(f(y_1))=f(f(y_2)) \implies 2f(y_1)-y_1=2f(y_2)-y_2 \implies y_1=y_2$), $f$ must be strictly increasing.
If $f$ had a jump discontinuity at $x_0$ with $f(x_0^+) - f(x_0^-) = \delta > 0$, then the identity $f(f(y)) = 2f(y) - y$ implies that the jump at $f^{(n)}(x_0)$ would be $2^n \delta$. However, the bound $f(x) \le \sqrt{2x^2 + 2z^2} - z + \epsilon(z)$ grows only linearly with $x$ for large $x$, whereas $f^{(n)}(x_0)$ grows linearly with $n$. Exponential growth of the jump $2^n \delta$ cannot be bounded by linear growth in $n$. Thus, $f$ must be continuous on $\mathbb{R}_{>0}$.

Since $f$ is continuous and strictly increasing, $R_f$ is an interval. Let $\phi(u) = \epsilon(u^2)$ for $u \in \{\sqrt{x} : x \in R_f\}$. The condition $|\phi(u) - \phi(v)| \le (u - v)^2$ for all $u, v$ in an interval implies that $\phi$ is constant. Thus $\epsilon(x) = c$ for all $x \in R_f$.
Finally, for any $y \in \mathbb{R}_{>0}$, $f(y) \in R_f$, so $\epsilon(f(y)) = c$. Since $\epsilon(y) = \epsilon(f(y))$, we have $\epsilon(y) = c$ for all $y \in \mathbb{R}_{>0}$.
Thus $f(x) = x + c$ for some constant $c \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \ge 0$.
