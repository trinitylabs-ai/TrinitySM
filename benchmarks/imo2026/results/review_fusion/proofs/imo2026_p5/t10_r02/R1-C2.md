To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we analyze the given inequalities.

**1. Simplification of the inequalities**
The right inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ can be squared since both sides are positive:
\[ (f(x) + y)^2 \ge 4x f(y). \quad (1) \]
The left inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$ can be squared:
\[ \frac{x^2 + f(y)^2}{2} \ge \frac{(f(x) + y)^2}{4} \implies 2x^2 + 2f(y)^2 \ge (f(x) + y)^2. \quad (2) \]
Combining these, we have the chain:
\[ 4x f(y) \le (f(x) + y)^2 \le 2x^2 + 2f(y)^2. \]

**2. Functional properties**
For any $y \in \mathbb{R}_{>0}$, let $x = f(y)$. Substituting this into the chain:
\[ 4f(y)^2 \le (f(f(y)) + y)^2 \le 2f(y)^2 + 2f(y)^2 = 4f(y)^2. \]
This forces $(f(f(y)) + y)^2 = 4f(y)^2$. Since $f(x), y > 0$, we must have $f(f(y)) + y = 2f(y)$.
Let $\epsilon(x) = f(x) - x$. The equation $f(f(y)) - f(y) = f(y) - y$ becomes $\epsilon(f(y)) = \epsilon(y)$.
Consider the sequence $a_0 = y$ and $a_{n+1} = f(a_n)$. Then $a_{n+1} - a_n = \epsilon(a_n) = \epsilon(a_{n-1}) = \dots = \epsilon(y)$.
Thus $a_n = y + n\epsilon(y)$. Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $y + n\epsilon(y) > 0$ for all $n \in \mathbb{N}$, which implies $\epsilon(y) \ge 0$ for all $y > 0$. Thus $f(x) \ge x$ for all $x > 0$.

**3. Analysis of $\epsilon$ on the range $R_f$**
Let $R_f$ be the range of $f$. For any $x, z \in R_f$, let $f(y) = z$. Then $y = z - \epsilon(z)$.
Substituting $f(y) = z$ and $y = z - \epsilon(z)$ into (1) and (2):
\[ 4xz \le (f(x) + z - \epsilon(z))^2 \le 2x^2 + 2z^2. \]
If $x \in R_f$, then $f(x) = x + \epsilon(x)$, so:
\[ 4xz \le (x + \epsilon(x) + z - \epsilon(z))^2 \le 2x^2 + 2z^2. \]
From the left side, $2\sqrt{xz} \le x + z + \epsilon(x) - \epsilon(z)$, so $\epsilon(z) - \epsilon(x) \le x + z - 2\sqrt{xz} = (\sqrt{x} - \sqrt{z})^2$.
From the right side, $x + z + \epsilon(x) - \epsilon(z) \le \sqrt{2x^2 + 2z^2}$.
Thus $\epsilon(x) - \epsilon(z) \le \sqrt{2x^2 + 2z^2} - (x + z) = \frac{(x-z)^2}{\sqrt{2x^2 + 2z^2} + x + z}$.
Since $\sqrt{2x^2 + 2z^2} \ge 2\sqrt{xz}$, we have $\frac{(x-z)^2}{\sqrt{2x^2 + 2z^2} + x + z} \le \frac{(x-z)^2}{2\sqrt{xz} + x + z} = (\sqrt{x} - \sqrt{z})^2$.
Therefore, for all $x, z \in R_f$, we have $|\epsilon(x) - \epsilon(z)| \le (\sqrt{x} - \sqrt{z})^2$.

**4. Constancy of $\epsilon$**
Let $S = \{x \in R_f : \epsilon(x) > 0\}$. If $S$ is non-empty, let $x, z \in S$ with $\epsilon(x) = c_x$ and $\epsilon(z) = c_z$.
The sequence $x_n = x + nc_x$ is in $S$ for all $n \in \mathbb{N}$. Similarly, $z_m = z + mc_z \in S$.
Then $|c_x - c_z| \le (\sqrt{x + nc_x} - \sqrt{z + mc_z})^2$.
If $c_x/c_z = p/q$ is rational, choosing $n=qk, m=pk$ gives $|c_x - c_z| \le \frac{(x-z)^2}{(\sqrt{x+qkc_x} + \sqrt{z+pkc_z})^2} \to 0$ as $k \to \infty$.
If $c_x/c_z$ is irrational, the set $\{nc_x - mc_z : n, m \in \mathbb{N}\}$ is dense in $\mathbb{R}$, so we can choose $n, m$ such that $|x + nc_x - (z + mc_z)| \le 1$, and the RHS again tends to 0 as $n, m \to \infty$.
Thus $\epsilon(x) = c$ for all $x \in S$ for some constant $c > 0$.

If there exists $x_0 \in R_f$ such that $\epsilon(x_0) = 0$, then for all $z \in S$, $c \le (\sqrt{x_0} - \sqrt{z})^2$.
This implies $\sqrt{z} \notin (\sqrt{x_0} - \sqrt{c}, \sqrt{x_0} + \sqrt{c})$.
However, for any $z \in S$, the sequence $s_n = \sqrt{z + nc}$ satisfies $s_{n+1} - s_n = \frac{c}{\sqrt{z+(n+1)c} + \sqrt{z+nc}} \to 0$ as $n \to \infty$.
Since $s_n \to \infty$, the sequence must eventually enter the interval $(\sqrt{x_0} - \sqrt{c}, \sqrt{x_0} + \sqrt{c})$, which is a contradiction.
Thus, either $S = \emptyset$ (so $\epsilon(x) = 0$ for all $x \in R_f$) or $S = R_f$ (so $\epsilon(x) = c$ for all $x \in R_f$).
In either case, $\epsilon$ is constant on $R_f$. Since $\epsilon(y) = \epsilon(f(y))$ and $f(y) \in R_f$, we have $\epsilon(y) = c$ for all $y \in \mathbb{R}_{>0}$ for some constant $c \ge 0$.

**5. Verification**
Substituting $f(x) = x + c$ into the original inequalities:
The right inequality is $\frac{x+c+y}{2} \ge \sqrt{x(y+c)}$, which is equivalent to $\frac{(x + (y+c))^2}{4} \ge x(y+c) \iff (x - (y+c))^2 \ge 0$.
The left inequality is $\sqrt{\frac{x^2 + (y+c)^2}{2}} \ge \frac{x+c+y}{2}$, which is the Root Mean Square-Arithmetic Mean (RMS-AM) inequality for $x$ and $y+c$.
Both are true for all $x, y > 0$ and $c \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \ge 0$.
