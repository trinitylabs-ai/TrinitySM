To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we proceed as follows.

First, we test the candidate solution $f(x) = x + a$ for some constant $a \ge 0$.
Substituting $f(x) = x + a$ into the inequalities:
1. The second inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ becomes $\frac{x + a + y}{2} \ge \sqrt{x(y + a)}$. By the AM-GM inequality, $\frac{x + (y + a)}{2} \ge \sqrt{x(y + a)}$, which holds for all $x, y > 0$ and $a \ge 0$.
2. The first inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$ becomes $\sqrt{\frac{x^2 + (y + a)^2}{2}} \ge \frac{x + a + y}{2}$. This is the RMS-AM inequality for the positive numbers $x$ and $y + a$, which holds for all $x, y > 0$ and $a \ge 0$.
Since $f(x) = x + a > 0$ for all $x > 0$ when $a \ge 0$, $f(x) = x + a$ is a solution for any $a \in [0, \infty)$.

To prove these are the only solutions, fix $y > 0$ and let $z = f(y)$. The given inequality is:
\[ \sqrt{\frac{x^2 + z^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{xz} \quad \text{for all } x > 0. \]
Setting $x = z$, we have:
\[ \sqrt{\frac{z^2 + z^2}{2}} \ge \frac{f(z) + y}{2} \ge \sqrt{z \cdot z} \implies z \ge \frac{f(z) + y}{2} \ge z. \]
Thus, $\frac{f(z) + y}{2} = z$, which implies $f(z) = 2z - y$. Since $z = f(y)$, we have the functional equation:
\[ f(f(y)) = 2f(y) - y. \]
Let $a(x) = f(x) - x$. Then $f(y) = y + a(y)$. The functional equation becomes:
\[ f(f(y)) = 2f(y) - y \implies f(y) + a(f(y)) = 2f(y) - y \implies a(f(y)) = f(y) - y = a(y). \]
Since $f^{(n)}(y) = y + na(y)$ for all $n \in \mathbb{N}$, and $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $y + na(y) > 0$ for all $n$, which implies $a(y) \ge 0$ for all $y > 0$.

Now, rewrite the original inequalities using $a(x)$ and $a(y)$. Let $z = f(y)$. Then $y = z - a(y) = z - a(z)$.
The second inequality $\frac{f(x) + y}{2} \ge \sqrt{xz}$ becomes:
\[ \frac{x + a(x) + z - a(z)}{2} \ge \sqrt{xz} \implies a(x) - a(z) \ge 2\sqrt{xz} - (x + z) = -(\sqrt{x} - \sqrt{z})^2. \]
The first inequality $\sqrt{\frac{x^2 + z^2}{2}} \ge \frac{f(x) + y}{2}$ becomes:
\[ \sqrt{\frac{x^2 + z^2}{2}} \ge \frac{x + a(x) + z - a(z)}{2} \implies a(x) - a(z) \le \sqrt{2(x^2 + z^2)} - (x + z). \]
Using the identity $\sqrt{2(x^2 + z^2)} - (x + z) = \frac{2(x^2 + z^2) - (x + z)^2}{\sqrt{2(x^2 + z^2)} + (x + z)} = \frac{(x - z)^2}{\sqrt{2(x^2 + z^2)} + (x + z)}$, we have for all $x > 0$ and $z \in \text{Im}(f)$:
\[ -(\sqrt{x} - \sqrt{z})^2 \le a(x) - a(z) \le \frac{(x - z)^2}{\sqrt{2(x^2 + z^2)} + (x + z)}. \]
If $x, z \in \text{Im}(f)$, then by symmetry we have:
\[ |a(x) - a(z)| \le \frac{(x - z)^2}{\sqrt{2(x^2 + z^2)} + (x + z)}. \]
This inequality implies that $a$ is constant on any connected component of $\text{Im}(f)$. Let $S = \text{Im}(f)$. For any $z \in S$, the inequality $-(\sqrt{x} - \sqrt{z})^2 \le a(x) - a(z) \le \frac{(x - z)^2}{\sqrt{2(x^2 + z^2)} + (x + z)}$ implies that $\lim_{x \to z} a(x) = a(z)$, so $a$ is continuous at every point of $S$.
Since $a(x) = a(f(x))$ and $f(x) \in S$, $a(x)$ must take values from the set of constants $\{C_I\}$ associated with the connected components $I$ of $S$. Because $a$ is continuous at every point of $S$, it must be locally constant at every point of $S$. Since $f(x) = x + a(x)$, $a$ is also locally constant on $\mathbb{R}_{>0}$. Because $\mathbb{R}_{>0}$ is connected, $a(x)$ must be a constant $C$.
As $f(x) = x + C > 0$ for $x > 0$, we must have $C \ge 0$.

The solutions are $f(x) = x + a$ for any $a \ge 0$.
