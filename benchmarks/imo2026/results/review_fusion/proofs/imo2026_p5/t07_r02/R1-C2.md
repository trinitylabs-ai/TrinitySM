To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)},\]
we analyze the given chain of inequalities.

**1. Testing Linear Solutions**
Consider the function $f(x) = x + c$ for some constant $c \ge 0$.
For the second inequality:
\[\frac{x + c + y}{2} \ge \sqrt{x(y + c)} \iff (x + y + c)^2 \ge 4x(y + c)\]
\[\iff x^2 + y^2 + c^2 + 2xy + 2xc + 2yc \ge 4xy + 4xc\]
\[\iff x^2 - 2xy + y^2 - 2xc + 2yc + c^2 \ge 0 \iff (x - y - c)^2 \ge 0.\]
This is true for all $x, y > 0$ and $c \ge 0$.

For the first inequality:
\[\sqrt{\frac{x^2 + (y + c)^2}{2}} \ge \frac{x + y + c}{2}.\]
This is a direct application of the Root Mean Square-Arithmetic Mean (RMS-AM) inequality for the values $x$ and $y+c$. Thus, it holds for all $x, y > 0$ and $c \ge 0$.

**2. Proving Uniqueness**
From the given inequalities, for any $x, y > 0$, we have:
\[2\sqrt{xf(y)} - y \le f(x) \le \sqrt{2(x^2 + f(y)^2)} - y.\]
Setting $x = f(y)$, we obtain:
\[2\sqrt{f(y)f(y)} - y \le f(f(y)) \le \sqrt{2(f(y)^2 + f(y)^2)} - y\]
\[\implies 2f(y) - y \le f(f(y)) \le 2f(y) - y,\]
so $f(f(y)) = 2f(y) - y$. Let $g(x) = f(x) - x$. The identity $f(f(x)) = 2f(x) - x$ implies:
\[f(x + g(x)) = 2(x + g(x)) - x = x + 2g(x).\]
Since $f(x + g(x)) = x + g(x) + g(x + g(x))$, we have:
\[x + g(x) + g(x + g(x)) = x + 2g(x) \implies g(f(x)) = g(x).\]
By induction, $f^{(n)}(x) = x + n g(x)$ for all $n \in \mathbb{N}$. Since the codomain of $f$ is $\mathbb{R}_{>0}$, we must have $x + n g(x) > 0$ for all $n \in \mathbb{N}$ and $x > 0$, which implies $g(x) \ge 0$ for all $x > 0$.

Now, we use the bounds on $f(x)$ to analyze $g(x)$.
From $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$, we have:
\[g(x) \ge 2\sqrt{x f(y)} - x - y.\]
For a fixed $y$, let $h_y(x) = 2\sqrt{x f(y)} - x - y$. This function $h_y(x)$ attains its maximum value at $x = f(y)$, where $h_y(f(y)) = 2f(y) - f(y) - y = f(y) - y = g(y)$. Thus, for any $x, y > 0$, $g(x) \ge h_y(x)$.
Specifically, for $x = f(y) + \epsilon$, we have:
\[g(f(y) + \epsilon) \ge 2\sqrt{(f(y) + \epsilon)f(y)} - (f(y) + \epsilon) - y = 2f(y)\sqrt{1 + \frac{\epsilon}{f(y)}} - f(y) - \epsilon - y.\]
Using the Taylor expansion $\sqrt{1+u} = 1 + \frac{u}{2} - \frac{u^2}{8} + O(u^3)$, we find:
\[g(f(y) + \epsilon) \ge 2f(y)\left(1 + \frac{\epsilon}{2f(y)} - \frac{\epsilon^2}{8f(y)^2} + O\left(\frac{\epsilon^3}{f(y)^3}\right)\right) - f(y) - \epsilon - y = g(y) - \frac{\epsilon^2}{4f(y)} + O(\epsilon^3).\]

Similarly, from $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$, we have:
\[g(x) \le \sqrt{2(x^2 + f(y)^2)} - x - y.\]
For $x = f(y) + \epsilon$, we have:
\[g(f(y) + \epsilon) \le \sqrt{2((f(y) + \epsilon)^2 + f(y)^2)} - (f(y) + \epsilon) - y = \sqrt{4f(y)^2 + 4f(y)\epsilon + 2\epsilon^2} - f(y) - \epsilon - y.\]
Using $\sqrt{1+u} = 1 + \frac{u}{2} - \frac{u^2}{8} + O(u^3)$, we find:
\[g(f(y) + \epsilon) \le 2f(y)\left(1 + \frac{1}{2}\left(\frac{\epsilon}{f(y)} + \frac{\epsilon^2}{2f(y)^2}\right) - \frac{1}{8}\left(\frac{\epsilon}{f(y)} + \frac{\epsilon^2}{2f(y)^2}\right)^2 + O\left(\frac{\epsilon^3}{f(y)^3}\right)\right) - f(y) - \epsilon - y\]
\[= 2f(y) + \epsilon + \frac{\epsilon^2}{2f(y)} - \frac{\epsilon^2}{4f(y)} + O(\epsilon^3) - f(y) - \epsilon - y = g(y) + \frac{\epsilon^2}{4f(y)} + O(\epsilon^3).\]
Combining these, we have $|g(f(y) + \epsilon) - g(y)| \le \frac{\epsilon^2}{4f(y)} + O(\epsilon^3)$. This implies that $g$ is differentiable at every point $s$ in the range of $f$, and $g'(s) = 0$.

To show $g$ is constant on $\mathbb{R}_{>0}$, we first note that $g$ is continuous. For any $y > 0$, the bounds $h_y(x) \le g(x) \le k_y(x)$ (where $k_y(x) = \sqrt{2(x^2 + f(y)^2)} - x - y$) both approach $g(y)$ as $x \to f(y)$, so $g$ is continuous at every $s \in \text{Im}(f)$. Since $g(y) = g(f(y))$ and $f(y) = y + g(y)$, the continuity of $g$ at $f(y)$ implies continuity at $y$.

Now, for any $y > 0$, let $s = f(y)$ and $h(\epsilon) = g(y + \epsilon) - g(y)$. Then
\[h(\epsilon) = g(f(y + \epsilon)) - g(f(y)) = g(s + \epsilon + h(\epsilon)) - g(s).\]
Since $g'(s) = 0$ and $|g(s + \delta) - g(s)| \le C_s \delta^2$ for small $\delta$, we have:
\[|h(\epsilon)| \le C_s (\epsilon + h(\epsilon))^2.\]
For small $\epsilon$, the inequality $C_s h^2 + (2C_s \epsilon - 1) h + C_s \epsilon^2 \ge 0$ (for $h > 0$) implies that $h(\epsilon)$ must be near the smaller root $h \approx C_s \epsilon^2$ because $h(\epsilon) \to 0$ as $\epsilon \to 0$. Thus $|h(\epsilon)| = O(\epsilon^2)$, which means $\lim_{\epsilon \to 0} \frac{g(y + \epsilon) - g(y)}{\epsilon} = 0$.
Thus $g'(y) = 0$ for all $y > 0$, meaning $g(x)$ is a constant $c \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \in [0, \infty)$.
