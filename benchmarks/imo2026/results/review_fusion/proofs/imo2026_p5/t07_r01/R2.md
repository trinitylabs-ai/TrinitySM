Let $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ be a function such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}. \]
The given inequalities can be rewritten as:
(1) $f(x) + y \ge 2\sqrt{x f(y)}$
(2) $(f(x) + y)^2 \le 2x^2 + 2f(y)^2$

Suppose there exists $y$ such that $f(y) = x$. Substituting $f(y) = x$ into (1) and (2), we have:
From (1), $f(x) + y \ge 2\sqrt{x \cdot x} = 2x$, so $f(x) \ge 2x - y$.
From (2), $(f(x) + y)^2 \le 2x^2 + 2x^2 = 4x^2$, so $f(x) + y \le 2x$, which means $f(x) \le 2x - y$.
Thus, if $f(y) = x$, then $f(x) = 2x - y$.

Let $g(x) = f(x) - x$. The condition $f(y) = x \implies f(x) = 2x - y$ implies:
$g(x) = f(x) - x = (2x - y) - x = x - y = f(y) - y = g(y)$.
Thus, for any $y > 0$, $g(f(y)) = g(y)$. This implies $f(f(y)) = f(y) + g(f(y)) = f(y) + g(y) = 2f(y) - y$.
By induction, the $n$-th iterate of $f$ is $f^{(n)}(y) = y + n g(y)$. Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $f^{(n)}(y) > 0$ for all $n \in \mathbb{N}$, which implies $g(y) \ge 0$ for all $y > 0$.

Let $S$ be the range of $f$. For any $z \in S$, there exists $y > 0$ such that $f(y) = z$. Then $y = z - g(y) = z - g(z)$ because $g(f(y)) = g(y)$.
Substituting $y = z - g(z)$ into (1) and (2):
(1) $f(x) + z - g(z) \ge 2\sqrt{xz} \implies x + g(x) + z - g(z) \ge 2\sqrt{xz} \implies g(x) - g(z) \ge -(\sqrt{x} - \sqrt{z})^2$.
(2) $(f(x) + z - g(z))^2 \le 2x^2 + 2z^2 \implies x + g(x) + z - g(z) \le \sqrt{2x^2 + 2z^2} \implies g(x) - g(z) \le \sqrt{2x^2 + 2z^2} - (x+z)$.

From (1), $g(x) - g(z) \ge -(\sqrt{x} - \sqrt{z})^2$ for all $x, z \in S$. By symmetry, $g(z) - g(x) \ge -(\sqrt{z} - \sqrt{x})^2$, so $|g(x) - g(z)| \le (\sqrt{x} - \sqrt{z})^2$ for all $x, z \in S$.

Let $x, z \in S$. Then $f^{(n)}(x) = x + n g(x) \in S$ and $f^{(m)}(z) = z + m g(z) \in S$ for all $n, m \in \mathbb{N}$.
The inequality $|g(u) - g(v)| \le (\sqrt{u} - \sqrt{v})^2$ must hold for $u = x + n g(x)$ and $v = z + m g(z)$.
If $g(x) = c_x > 0$ and $g(z) = c_z > 0$, we can choose $m_n = \lfloor \frac{x + n c_x - z}{c_z} \rfloor$. Then $0 \le x + n c_x - (z + m_n c_z) < c_z$.
As $n \to \infty$, the term $(\sqrt{x + n c_x} - \sqrt{z + m_n c_z})^2 \to 0$.
Thus $|c_x - c_z| \le 0$, so $c_x = c_z$.
This shows that $g$ is constant on the set $S_+ = \{x \in S : g(x) > 0\}$. Let this constant be $c > 0$.

Now consider $S_0 = \{x \in S : g(x) = 0\}$. If $S_0$ is non-empty, let $w \in S_0$. For any $x \in S_+$, we must have $|g(x) - g(w)| \le (\sqrt{x} - \sqrt{w})^2$, which simplifies to $c \le (\sqrt{x} - \sqrt{w})^2$.
For any $y \in \mathbb{R}_{>0}$, $f(y) \in S$ and $g(f(y)) = g(y)$. Let $A = \{y \in \mathbb{R}_{>0} : g(y) = c\}$ and $B = \{y \in \mathbb{R}_{>0} : g(y) = 0\}$.
If $y \in A$, then $f(y) = y + c \in S_+$. Thus $c \le (\sqrt{y+c} - \sqrt{w})^2$ for all $y \in A$ and $w \in B$.
This implies $y+c \ge (\sqrt{w} + \sqrt{c})^2 = w + c + 2\sqrt{wc}$ or $y+c \le (\sqrt{w} - \sqrt{c})^2 = w + c - 2\sqrt{wc}$.
Thus $y \ge w + 2\sqrt{wc}$ or $y \le w - 2\sqrt{wc}$.
This means $A \cap (w - 2\sqrt{wc}, w + 2\sqrt{wc}) = \emptyset$, so $(w - 2\sqrt{wc}, w + 2\sqrt{wc}) \cap \mathbb{R}_{>0} \subseteq B$.
If $B$ is non-empty, let $w_0 \in B$. Then $B$ contains an interval $I_0$. For any $w \in B$, $B$ contains $(w - 2\sqrt{wc}, w + 2\sqrt{wc}) \cap \mathbb{R}_{>0}$. By iterating this expansion, $B$ must be $\mathbb{R}_{>0}$.
If $B = \mathbb{R}_{>0}$, then $g(y) = 0$ for all $y$, so $c = 0$.
Thus, either $g(y) = 0$ for all $y$ or $g(y) = c$ for all $y$.
In either case, $f(x) = x + c$ for some constant $c \ge 0$.

Verification:
For $f(x) = x + c$ with $c \ge 0$:
$\frac{x+c+y}{2} \ge \sqrt{x(y+c)} \iff (x - (y+c))^2 \ge 0$.
$\sqrt{\frac{x^2 + (y+c)^2}{2}} \ge \frac{x+c+y}{2} \iff 2x^2 + 2(y+c)^2 \ge (x+y+c)^2 \iff (x - (y+c))^2 \ge 0$.
Both are true for all $x, y > 0, c \ge 0$.
The functions are $f(x) = x + c$ for any constant $c \ge 0$.
