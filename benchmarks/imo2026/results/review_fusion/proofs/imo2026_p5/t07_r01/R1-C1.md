Let $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ be a function such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}. \]
The given inequalities can be rewritten as:
(1) $f(x) + y \ge 2\sqrt{x f(y)}$
(2) $(f(x) + y)^2 \le 2x^2 + 2f(y)^2$

Suppose there exists $y$ such that $f(y) = x$. Substituting $f(y) = x$ into (1) and (2), we have:
From (1), $f(x) + y \ge 2\sqrt{x \cdot x} = 2x$, so $f(x) \ge 2x - y$.
From (2), $(f(x) + y)^2 \le 2x^2 + 2x^2 = 4x^2$, so $f(x) + y \le 2x$, which means $f(x) \le 2x - y$.
Thus, if $f(y) = x$, then $f(x) = 2x - y$.
Let $g(x) = f(x) - x$. The condition $f(y) = x \implies f(x) = 2x - y$ implies:
$g(x) = f(x) - x = (2x - y) - x = x - y = f(y) - y = g(y)$.
Thus, for any $y > 0$, $g(f(y)) = g(y)$. This implies $f(f(y)) = f(y) + g(f(y)) = f(y) + g(y) = 2f(y) - y$.
By induction, the $n$-th iterate of $f$ is $f^{(n)}(y) = y + n g(y)$. Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $f^{(n)}(y) > 0$ for all $n \in \mathbb{N}$, which implies $g(y) \ge 0$ for all $y > 0$.

Let $S$ be the range of $f$. For any $z \in S$, there exists $y > 0$ such that $f(y) = z$. Then $y = z - g(y) = z - g(z)$ because $g(f(y)) = g(y)$.
Substituting $y = z - g(z)$ into (1) and (2):
(1) $f(x) + z - g(z) \ge 2\sqrt{xz} \implies x + g(x) + z - g(z) \ge 2\sqrt{xz} \implies g(x) - g(z) \ge 2\sqrt{xz} - (x+z) = -(\sqrt{x} - \sqrt{z})^2$.
(2) $(f(x) + z - g(z))^2 \le 2x^2 + 2z^2 \implies x + g(x) + z - g(z) \le \sqrt{2x^2 + 2z^2} \implies g(x) - g(z) \le \sqrt{2x^2 + 2z^2} - (x+z)$.

For any $x, z \in S$, we have $g(x) - g(z) \ge -(\sqrt{x} - \sqrt{z})^2$ and $g(z) - g(x) \ge -(\sqrt{z} - \sqrt{x})^2$.
Thus, $|g(x) - g(z)| \le (\sqrt{x} - \sqrt{z})^2$ for all $x, z \in S$.
Let $x, z \in S$. Then $f^{(n)}(x) \in S$ and $f^{(n)}(z) \in S$ for all $n \in \mathbb{N}$.
Using the inequality $|g(u) - g(v)| \le (\sqrt{u} - \sqrt{v})^2$ with $u = f^{(n)}(x) = x + n g(x)$ and $v = f^{(n)}(z) = z + n g(z)$, we have:
$|g(x) - g(z)| \le (\sqrt{x + n g(x)} - \sqrt{z + n g(z)})^2$.
If $g(x) = g(z) = c$, the right side is $(\sqrt{x+nc} - \sqrt{z+nc})^2 = \frac{(x-z)^2}{(\sqrt{x+nc} + \sqrt{z+nc})^2}$, which tends to 0 as $n \to \infty$.
If $g(x) \neq g(z)$, let $g(x) = c_x$ and $g(z) = c_z$. The right side is:
$(\sqrt{n}(\sqrt{c_x + x/n} - \sqrt{c_z + z/n}))^2 = n (\sqrt{c_x} - \sqrt{c_z} + O(1/n))^2$, which tends to $\infty$ as $n \to \infty$.
However, the inequality $|g(x) - g(z)| \le (\sqrt{x+nc_x} - \sqrt{z+nc_z})^2$ must hold for all $n \in \mathbb{N}$.
If $c_x \neq c_z$, then for sufficiently large $n$, the right side is very large, which is not a contradiction.
But we can use $x, z \in S$ and $g(f(x)) = g(x)$.
For any $x, z \in S$, $|g(x) - g(z)| \le (\sqrt{x} - \sqrt{z})^2$.
As $z \to x$ within $S$, $g(z) \to g(x)$, so $g$ is continuous on $S$.
The inequality $|g(x) - g(z)| \le (\sqrt{x} - \sqrt{z})^2$ implies that for any $x \in S$, the derivative $g'(x) = 0$ because $|g'(x)| \le \lim_{z \to x} \frac{(\sqrt{z} - \sqrt{x})^2}{z - x} = \lim_{z \to x} \frac{1}{(\sqrt{z} + \sqrt{x})^2} \cdot \frac{z-x}{z-x} \cdot \frac{z-x}{(\sqrt{z}+\sqrt{x})^2} = 0$.
Thus $g(x) = c$ for all $x \in S$.
Now, for any $y \in \mathbb{R}_{>0}$, $f(y) \in S$, so $g(f(y)) = c$.
Since $g(f(y)) = g(y)$, we have $g(y) = c$ for all $y \in \mathbb{R}_{>0}$.
Thus $f(x) = x + c$ for some constant $c \ge 0$.

Verification:
For $f(x) = x + c$ with $c \ge 0$:
Right inequality: $\frac{x+c+y}{2} \ge \sqrt{x(y+c)} \iff (x+y+c)^2 \ge 4x(y+c) \iff (x - (y+c))^2 \ge 0$.
Left inequality: $\sqrt{\frac{x^2 + (y+c)^2}{2}} \ge \frac{x+c+y}{2} \iff 2x^2 + 2(y+c)^2 \ge (x+y+c)^2 \iff (x - (y+c))^2 \ge 0$.
Both are true for all $x, y > 0, c \ge 0$.
The functions are $f(x) = x + c$ for any constant $c \ge 0$.
