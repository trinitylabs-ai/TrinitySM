Let $n$ be a positive integer. Liu Bang first marks $n$ points on a stick of length 1, creating $n+1$ intervals $a_1, a_2, \dots, a_{n+1}$. Then Xiang Yu marks $n$ points. The stick is cut at all marked points, producing a collection of pieces $l_{(1)} \ge l_{(2)} \ge \dots \ge l_{(k)}$, where $k \le 2n+1$. Liu and Xiang claim pieces greedily, with Liu moving first. Liu's total length is $L = \sum_{i \text{ odd}} l_{(i)}$ and Xiang's is $S = \sum_{i \text{ even}} l_{(i)}$. We seek the largest $c$ such that Liu can guarantee $L \ge c$.

Liu's strategy is to mark $n$ points such that the $n+1$ intervals are equal: $a_1 = a_2 = \dots = a_{n+1} = \frac{1}{n+1}$.
Xiang Yu places $k_i$ points in interval $a_i$, where $\sum_{i=1}^{n+1} k_i \le n$. This divides each $a_i$ into $k_i+1$ pieces $b_{i,1} \ge b_{i,2} \ge \dots \ge b_{i,k_i+1}$. The total number of pieces is $N = \sum (k_i+1) \le 2n+1$.
Xiang's total length is $S = \sum_{j=1}^{\lfloor N/2 \rfloor} l_{(2j)}$. We know that $L - S = \sum_{j=1}^{\lfloor N/2 \rfloor} (l_{(2j-1)} - l_{(2j)}) + l_{(N \text{ if } N \text{ is odd})}$.

To maximize $S$, Xiang wants to make the pieces as equal as possible. If all $N$ pieces were equal to $1/N$, then $S = \lfloor N/2 \rfloor / N$. For $N=2n+1$, this gives $S = n/(2n+1)$.
We analyze Xiang's possible distributions of cuts $k_i$.
If Xiang distributes his cuts such that $k_i \in \{0, 1\}$ for all $i$, then $N = (n+1) + n = 2n+1$. Each interval $a_i$ is split into either 1 or 2 pieces. If $k_i=1$, $a_i$ is split into $b_{i,1}, b_{i,2}$. If $k_i=0$, $a_i$ is a single piece.
The pieces are $n$ pieces of size $1/(n+1)$ (from $k_i=0$) and $2n$ pieces from $k_i=1$. Wait, if $k_i=1$ for $n$ intervals, we have $n$ pieces of size $1/(n+1)$ and $2n$ pieces $b_{i,1}, b_{i,2}$. Total pieces $N = 1 + 2n$.
The $n$ pieces of size $1/(n+1)$ are the largest. Thus $l_{(1)} = \dots = l_{(n)} = 1/(n+1)$.
Then $S = l_{(2)} + l_{(4)} + \dots + l_{(2\lfloor n/2 \rfloor)} + \dots$.
The first $\lfloor n/2 \rfloor$ terms of $S$ are $1/(n+1)$. The remaining terms are from the $b_{i,j}$ pieces.
If $n=2$, $l_{(1)}=l_{(2)}=1/3$. $S = l_{(2)} + l_{(4)} = 1/3 + b_{i,j} \le 1/3 + 1/6 = 1/2$.
Wait, if $k_i=1$ for $n$ intervals, then $n$ intervals are split into 2 pieces and 1 is not.
Pieces: $1/(n+1)$ (one piece), and $b_{i,1}, b_{i,2}$ for $i=1 \dots n$.
The largest piece is $l_{(1)} = 1/(n+1)$.
Then $S = l_{(2)} + l_{(4)} + \dots + l_{(2n)}$.
Since $b_{i,1} + b_{i,2} = 1/(n+1)$, we have $l_{(2)} + l_{(3)} \le 1/(n+1)$, $l_{(4)} + l_{(5)} \le 1/(n+1)$, etc.
$S = l_{(2)} + l_{(4)} + \dots + l_{(2n)} \le \frac{1}{2} \sum_{i=1}^n (b_{i,1} + b_{i,2}) = \frac{1}{2} \frac{n}{n+1} = \frac{n}{2n+2}$.
For $n=2$, $S \le 2/6 = 1/3$. For $n=1$, $S \le 1/4$.

If Xiang concentrates cuts in one interval $a_1$, then $k_1=n$ and $k_i=0$ for $i > 1$.
The pieces are $n$ pieces of size $1/(n+1)$ and $n+1$ pieces $b_{1,j}$ from $a_1$.
Sorted: $l_{(1)} = \dots = l_{(n)} = 1/(n+1)$, then $b_{1,1}, \dots, b_{1,n+1}$.
$S = l_{(2)} + l_{(4)} + \dots + l_{(2\lfloor n/2 \rfloor)} + l_{(n+1 \text{ or } n+2)} + \dots$.
The first $\lfloor n/2 \rfloor$ terms are $1/(n+1)$.
The remaining terms are from $b_{1,j}$. The sum of all $b_{1,j}$ is $1/(n+1)$.
Thus $S \le \lfloor n/2 \rfloor \frac{1}{n+1} + \frac{1}{n+1} = \frac{\lfloor n/2 \rfloor + 1}{n+1}$.
For $n=1$, $S \le (0+1)/2 = 1/2$. (Wait, $n=1 \implies a_1=a_2=1/2$. $k_1=1 \implies$ pieces $b_{1,1}, b_{1,2}, 1/2$. Sorted $1/2, b_{1,1}, b_{1,2}$. $S = b_{1,1} \le 1/2$. $L \ge 1/2$. But $c=2/3$ for $n=1$. So $a_i=1/(n+1)$ is not optimal for $n=1$).

Re-evaluating $n=1$: Liu marks $x_1=1/3$. Intervals $1/3, 2/3$.
If Xiang marks $y_1 \in [0, 1/3]$, pieces are $y_1, 1/3-y_1, 2/3$. $S = \max(y_1, 1/3-y_1) \le 1/3$.
If Xiang marks $y_1 \in [1/3, 1]$, pieces are $1/3, y_1-1/3, 1-y_1$. $S = \text{median}(1/3, y_1-1/3, 1-y_1) \le 1/3$.
Thus $S \le 1/3$, $L \ge 2/3$. This matches $c = \frac{n+1}{2n+1}$.

For general $n$, Liu marks $n$ points to create intervals $a_1, \dots, a_{n+1}$ with $a_i = \frac{2}{2n+1}$ for $i=1 \dots n$ and $a_{n+1} = \frac{1}{2n+1}$.
If Xiang puts all $n$ cuts in $a_1$, pieces are $b_{1,1}, \dots, b_{1,n+1}, a_2, \dots, a_{n+1}$.
Sorted: $a_2, \dots, a_n, \max(b_{1,1}, a_{n+1}), \dots$.
$S = l_{(2)} + l_{(4)} + \dots$.
The first $n-1$ pieces are $a_2, \dots, a_n$ (each $2/(2n+1)$) and $a_{n+1} = 1/(2n+1)$.
If $b_{1,j}$ are small, $l_{(1)} \dots l_{(n)}$ are $a_2 \dots a_{n+1}$.
$S = a_3 + a_5 + \dots + b_{1,2} + \dots \approx \frac{n-1}{2} \frac{2}{2n+1} + 0 = \frac{n-1}{2n+1}$.
If $b_{1,1}$ is large, $l_{(1)} = b_{1,1}, l_{(2)} = a_2, \dots$.
$S = a_2 + a_4 + \dots \approx \frac{n}{2} \frac{2}{2n+1} = \frac{n}{2n+1}$.
In all cases, $S \le \frac{n}{2n+1}$.
Thus $L \ge 1 - \frac{n}{2n+1} = \frac{n+1}{2n+1}$.
Xiang can ensure $S \ge \frac{n}{2n+1}$ by splitting each $a_i$ ($i \le n$) into two pieces of size $1/(2n+1)$.
Then all $2n+1$ pieces are $1/(2n+1)$, and $S = n/(2n+1)$.
Thus $c = \frac{n+1}{2n+1}$.
