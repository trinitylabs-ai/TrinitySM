To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we first test the candidate $f(x) = x + c$ for $c \ge 0$.
The right inequality $\frac{x+c+y}{2} \ge \sqrt{x(y+c)}$ is equivalent to $(x+c+y)^2 \ge 4x(y+c)$, which simplifies to $x^2 + (y+c)^2 + 2x(y+c) \ge 4x(y+c)$, or $(x - (y+c))^2 \ge 0$.
The left inequality $\sqrt{\frac{x^2 + (y+c)^2}{2}} \ge \frac{x+y+c}{2}$ is equivalent to $\frac{x^2 + (y+c)^2}{2} \ge \frac{(x+y+c)^2}{4}$, which simplifies to $2x^2 + 2(y+c)^2 \ge x^2 + (y+c)^2 + 2x(y+c)$, or $(x - (y+c))^2 \ge 0$.
Both are satisfied for all $x, y > 0$ and $c \ge 0$.

Now we prove these are the only solutions.
Substituting $x = f(y)$ into the given inequalities, we have:
\[ \sqrt{\frac{f(y)^2 + f(y)^2}{2}} \ge \frac{f(f(y)) + y}{2} \ge \sqrt{f(y) f(y)} \implies f(y) \ge \frac{f(f(y)) + y}{2} \ge f(y). \]
Thus, $f(f(y)) = 2f(y) - y$ for all $y > 0$.
Let $g(x) = f(x) - x$. The identity $f(f(y)) = 2f(y) - y$ implies $f(f(y)) - f(y) = f(y) - y$, so $g(f(y)) = g(y)$.
For any $y > 0$, the sequence $x_n = f^{(n)}(y)$ satisfies $x_{n+1} = 2x_n - x_{n-1}$ with $x_0 = y$ and $x_1 = f(y)$. The general solution is $x_n = y + n g(y)$. Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $y + n g(y) > 0$ for all $n \ge 0$ and $y > 0$, which implies $g(y) \ge 0$ for all $y > 0$.

From the right inequality, $(f(x) + y)^2 \ge 4x f(y)$. Substituting $f(x) = x + g(x)$ and $f(y) = y + g(y)$, we get:
\[ (x + g(x) + y)^2 \ge 4x(y + g(y)) \implies 4x g(y) \le (x + g(x) + y)^2 - 4xy = (y - (x - g(x)))^2 + 4xg(x). \]
Thus, $g(y) \le \frac{(y - (x - g(x)))^2}{4x} + g(x)$ for all $x, y > 0$.
Let $L = \limsup_{y \to \infty} g(y)$. If $g(x) > 0$, consider the orbit $x_n = x + ng(x)$. Since $g(x_n) = g(x)$, we have
\[ g(y) \le \frac{(y - (x_n - g(x_n)))^2}{4x_n} + g(x_n) = \frac{(y - (x + (n-1)g(x)))^2}{4(x + ng(x))} + g(x). \]
For any $y > x$, we can choose $n \in \mathbb{N}$ such that $x + (n-1)g(x) \le y < x + ng(x)$. Then $(y - (x + (n-1)g(x)))^2 \le g(x)^2$ and $x + ng(x) > y$, so $g(y) \le \frac{g(x)^2}{4y} + g(x)$.
Taking the limit as $y \to \infty$, we find $L \le g(x)$. Since $g(x_n) = g(x)$ for all $n$ and $x_n \to \infty$, we also have $L \ge g(x)$. Thus, for any $x > 0$, either $g(x) = 0$ or $g(x) = L$.

Let $S = \{x \in \mathbb{R}_{>0} : g(x) = L\}$. If $S = \emptyset$, then $g(x) = 0$ for all $x$. If $S = \mathbb{R}_{>0}$, then $g(x) = L$ for all $x$. Suppose $S$ is a proper non-empty subset of $\mathbb{R}_{>0}$. Let $x \notin S$ and $y \in S$. Then $g(x) = 0$ and $g(y) = L$. The right inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ becomes $\frac{x+y}{2} \ge \sqrt{x(y+L)}$, which simplifies to $(x+y)^2 \ge 4x(y+L)$, or $x^2 - 2x(y+2L) + y^2 \ge 0$.
This implies $x$ cannot lie in the interval $I_y = (y+2L-2\sqrt{yL+L^2}, y+2L+2\sqrt{yL+L^2})$. Since $x \notin S$ was arbitrary, $I_y \subset S$ for all $y \in S$.
The left endpoint of $I_y$ is $L_y = (\sqrt{y+L} - \sqrt{L})^2$. Since $L_y < y$ for all $y > 0$, if $S$ is non-empty, it contains values arbitrarily close to $0$. Let $y_0 \in S$. Then $S_1 = I_{y_0} \subset S$. Let $S_{n+1} = \bigcup_{y \in S_n} I_y$. Then $S_n$ is an interval $(L_n, R_n)$ where $L_{n+1} = L_{L_n}$ and $R_{n+1} = R_{R_n}$. The sequence $L_n$ converges to $0$ and $R_n$ converges to $\infty$. Thus $S = \mathbb{R}_{>0}$.

In all cases, $g(x) = c$ for some constant $c \ge 0$, so $f(x) = x + c$.
The functions satisfying the condition are $f(x) = x + c$ for any constant $c \ge 0$.
