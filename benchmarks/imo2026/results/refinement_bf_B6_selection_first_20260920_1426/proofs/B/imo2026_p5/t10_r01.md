To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for all $x, y > 0$,
$$\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)},$$
we first test the candidate solution $f(x) = x + c$ for some constant $c \ge 0$.
For $f(x) = x + c$, the given inequalities become:
$$\sqrt{\frac{x^2 + (y + c)^2}{2}} \ge \frac{x + c + y}{2} \ge \sqrt{x(y + c)}.$$
The right-hand side is the AM-GM inequality for $x$ and $y+c$, and the left-hand side is the RMS-AM inequality for $x$ and $y+c$. Both hold for all $x, y > 0$ and $c \ge 0$. Since the codomain is $\mathbb{R}_{>0}$, $f(x) = x+c$ is a valid solution for any $c \ge 0$.

To prove uniqueness, consider the case where $x = f(y)$. The given inequality becomes:
$$\sqrt{\frac{f(y)^2 + f(y)^2}{2}} \ge \frac{f(f(y)) + y}{2} \ge \sqrt{f(y) f(y)} \implies f(y) \ge \frac{f(f(y)) + y}{2} \ge f(y).$$
This forces $\frac{f(f(y)) + y}{2} = f(y)$, or $f(f(y)) - 2f(y) + y = 0$.
For any $y_0 > 0$, let $y_{n+1} = f(y_n)$. The sequence satisfies the linear recurrence $y_{n+2} - 2y_{n+1} + y_n = 0$, which has the general solution $y_n = y_0 + n(f(y_0) - y_0)$. Since the codomain of $f$ is $\mathbb{R}_{>0}$, we must have $y_n > 0$ for all $n \in \mathbb{N}$, which implies $f(y_0) - y_0 \ge 0$.
Let $g(x) = f(x) - x \ge 0$. From $f(f(x)) = 2f(x) - x$, we have $f(x) + g(f(x)) = 2f(x) - x$, so $g(f(x)) = f(x) - x = g(x)$. Since $f(x) = x + g(x)$, we have $g(x + g(x)) = g(x)$.

Squaring the right-hand side inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$:
$$(x + g(x) + y)^2 \ge 4x(y + g(y)) \implies (x - y)^2 + g(x)^2 + 2(x + y)g(x) \ge 4xg(y).$$
Let $S$ be the range of $g$. For any $c_1, c_2 \in S$ such that $c_1, c_2 > 0$, let $g(y_1) = c_1$ and $g(y_2) = c_2$. Since $g(x + g(x)) = g(x)$, we have $g(y_1 + nc_1) = c_1$ and $g(y_2 + mc_2) = c_2$ for all $n, m \in \mathbb{N}$.
Let $x = y_1 + nc_1$ and $y = y_2 + mc_2$. Choosing $m = \lfloor nc_1/c_2 \rfloor$, we have $0 \le nc_1 - mc_2 < c_2$. Dividing the inequality by $n$ and taking $n \to \infty$:
$$\lim_{n \to \infty} \frac{(nc_1 - mc_2 + y_1 - y_2)^2 + c_1^2 + 2(y_1 + nc_1 + y_2 + mc_2)c_1}{n} \ge \lim_{n \to \infty} \frac{4(y_1 + nc_1)c_2}{n}$$
$$0 + 0 + 2c_1^2 + 2c_1^2 \ge 4c_1c_2 \implies 4c_1^2 \ge 4c_1c_2 \implies c_1 \ge c_2.$$
By swapping the roles of $c_1$ and $c_2$, we similarly obtain $c_2 \ge c_1$. Thus, $c_1 = c_2$. This implies that $S$ can contain at most one positive value. Thus, $S \subseteq \{0, c\}$ for some $c > 0$.

Suppose $S = \{0, c\}$ with $c > 0$. Let $A = \{x \mid g(x) = 0\}$ and $B = \{x \mid g(x) = c\}$. Assume both $A$ and $B$ are non-empty.
Squaring the left-hand side inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$:
$$2x^2 + 2(y + g(y))^2 \ge (x + g(x) + y)^2 \implies (x - y)^2 + 4yg(y) + 2g(y)^2 \ge 2xg(x) + g(x)^2 + 2yg(x).$$
For $x \in B$ and $y \in A$, this simplifies to $(x - y)^2 \ge 2xc + c^2 + 2yc$, which is $x^2 - 2(y + c)x + y^2 - 2cy - c^2 \ge 0$.
For a fixed $y \in A$, let $Q_y(x) = x^2 - 2(y + c)x + y^2 - 2cy - c^2$. The roots of $Q_y(x) = 0$ are $x = y + c \pm \sqrt{4yc + 2c^2}$. Since $Q_y(x) < 0$ for $x \in (y + c - \sqrt{4yc + 2c^2}, y + c + \sqrt{4yc + 2c^2})$, and $Q_y(x) \ge 0$ for all $x \in B$, the interval $I_y = (y + c - \sqrt{4yc + 2c^2}, y + c + \sqrt{4yc + 2c^2})$ must be disjoint from $B$. Note that $y \in I_y$ because $y + c - \sqrt{4yc + 2c^2} < y \iff c < \sqrt{4yc + 2c^2} \iff c^2 < 4yc + 2c^2$, which is true for $y, c > 0$. Thus $I_y \subseteq A$, and $A$ is open.

Similarly, for $x \in B$ and $y \in A$, we have $y^2 - 2(x + c)y + x^2 - 2cx - c^2 \ge 0$. For a fixed $x \in B$, let $Q_x(y) = y^2 - 2(x + c)y + x^2 - 2cx - c^2$. The roots are $y = x + c \pm \sqrt{4xc + 2c^2}$. The interval $J_x = (x + c - \sqrt{4xc + 2c^2}, x + c + \sqrt{4xc + 2c^2})$ must be disjoint from $A$. Since $x \in J_x$ (by the same logic as above), we have $J_x \subseteq B$, and $B$ is open.
Since $A$ and $B$ are disjoint open sets whose union is $\mathbb{R}_{>0}$, and $\mathbb{R}_{>0}$ is connected, one of them must be empty. This contradicts the assumption that both are non-empty. Thus, $g(x)$ must be a constant $c \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \ge 0$.
