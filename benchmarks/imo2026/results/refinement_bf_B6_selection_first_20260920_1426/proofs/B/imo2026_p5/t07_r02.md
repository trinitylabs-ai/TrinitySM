To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
$$\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)},$$
we proceed as follows.

**1. Deriving a functional equation**
Let $x = f(y)$. The given chain of inequalities becomes:
$$\sqrt{\frac{f(y)^2 + f(y)^2}{2}} \ge \frac{f(f(y)) + y}{2} \ge \sqrt{f(y) f(y)} \implies f(y) \ge \frac{f(f(y)) + y}{2} \ge f(y).$$
This forces $\frac{f(f(y)) + y}{2} = f(y)$, or $f(f(y)) = 2f(y) - y$ for all $y > 0$.
Let $c(x) = f(x) - x$. Then $f(f(y)) = f(y) + c(f(y))$. Substituting this into the equation above:
$$f(y) + c(f(y)) = 2f(y) - y \implies c(f(y)) = f(y) - y = c(y).$$
Thus, $c(f(y)) = c(y)$ for all $y > 0$. Furthermore, since $f(f(y)) = 2f(y) - y$, the sequence defined by $a_0 = x$ and $a_{n+1} = f(a_n)$ satisfies the linear recurrence $a_{n+1} - a_n = a_n - a_{n-1} = c(x)$, so $a_n = x + n c(x)$. Since $f(x) > 0$ for all $x > 0$, we must have $x + n c(x) > 0$ for all $n \in \mathbb{N}$, which implies $c(x) \ge 0$ for all $x > 0$.

**2. Analyzing the range of $f$**
Consider the first inequality $\frac{f(x) + y}{2} \le \sqrt{\frac{x^2 + f(y)^2}{2}}$. Squaring both sides:
$$(f(x) + y)^2 \le 2x^2 + 2f(y)^2.$$
Let $z = f(y)$. Then $y = z - c(y) = z - c(z)$ since $c(f(y)) = c(y)$. Substituting these into the inequality:
$$(f(x) + z - c(z))^2 \le 2x^2 + 2z^2 \implies f(x) + z - c(z) \le \sqrt{2x^2 + 2z^2}.$$
Substituting $f(x) = x + c(x)$:
$$x + c(x) + z - c(z) \le \sqrt{2x^2 + 2z^2} \implies c(x) - c(z) \le \sqrt{2x^2 + 2z^2} - (x + z).$$
The right side is $\frac{2x^2 + 2z^2 - (x+z)^2}{\sqrt{2x^2 + 2z^2} + x + z} = \frac{(x-z)^2}{\sqrt{2x^2 + 2z^2} + x + z}$. Thus, for all $x > 0$ and $z \in \text{Im}(f)$:
$$c(x) - c(z) \le \frac{(x-z)^2}{\sqrt{2x^2 + 2z^2} + x + z}.$$
If $z_1, z_2 \in \text{Im}(f)$, then by the above inequality:
$$c(z_1) - c(z_2) \le \frac{(z_1 - z_2)^2}{\sqrt{2z_1^2 + 2z_2^2} + z_1 + z_2}.$$
Symmetrically, since $z_2$ is also in $\text{Im}(f)$:
$$c(z_2) - c(z_1) \le \frac{(z_2 - z_1)^2}{\sqrt{2z_2^2 + 2z_1^2} + z_2 + z_1}.$$
Together, these imply that for all $z_1, z_2 \in \text{Im}(f)$:
$$|c(z_1) - c(z_2)| \le \frac{(z_1 - z_2)^2}{\sqrt{2z_1^2 + 2z_2^2} + z_1 + z_2}.$$

**3. Concluding $c(x)$ is constant**
Let $z \in \text{Im}(f)$. Then $z_n = f^{(n)}(z) = z + n c(z)$ is also in $\text{Im}(f)$ for all $n \in \mathbb{N}$.
Suppose there exist $z, w \in \text{Im}(f)$ such that $c(z) > 0$ and $c(w) > 0$. Let $C = c(z)$ and $D = c(w)$. For any $n \in \mathbb{N}$, we can choose $m \in \mathbb{N}$ such that $w_m = w + mD$ satisfies $|z_n - w_m| \le D$. Substituting these into the derived bound:
$$|C - D| = |c(z_n) - c(w_m)| \le \frac{D^2}{\sqrt{2z_n^2 + 2w_m^2} + z_n + w_m}.$$
As $n \to \infty$, $z_n \to \infty$ and $w_m \to \infty$, so the denominator grows linearly while the numerator remains constant, forcing $|C - D| = 0$. Thus, $c(z)$ can take at most one positive value $C$ on $\text{Im}(f)$.
For any $x \in \mathbb{R}_{>0}$, $f(x) \in \text{Im}(f)$. Since $c(x) = c(f(x))$, it follows that $c(x) \in \{0, C\}$ for some $C \ge 0$.
Let $S_0 = \{x \in \mathbb{R}_{>0} : c(x) = 0\}$ and $S_C = \{x \in \mathbb{R}_{>0} : c(x) = C\}$. Suppose both $S_0$ and $S_C$ are non-empty. For any $x \in S_C$ and $y \in S_0$, the inequality $(f(x) + y)^2 \le 2x^2 + 2f(y)^2$ becomes:
$$(x + C + y)^2 \le 2x^2 + 2y^2 \implies x^2 + y^2 + C^2 + 2xy + 2xC + 2yC \le 2x^2 + 2y^2 \implies (x - y)^2 - 2C(x + y) - C^2 \ge 0.$$
Solving the quadratic $(x - y)^2 - 2C(x + y) - C^2 = 0$ for $x$ gives roots $x = y + C \pm \sqrt{4yC + 2C^2}$. The inequality is violated on the open interval $J_y = (y + C - \sqrt{4yC + 2C^2}, y + C + \sqrt{4yC + 2C^2})$.
Since $x \in S_C \implies x \notin J_y$, and $y \in J_y$ (because $y + C - \sqrt{4yC + 2C^2} < y \iff C < \sqrt{4yC + 2C^2} \iff C^2 < 4yC + 2C^2$, which is true for $y, C > 0$), $J_y$ is an open neighborhood of $y$ containing no elements of $S_C$. Thus $S_0$ is open.
Similarly, for a fixed $x \in S_C$, the inequality $(x - y)^2 - 2C(x + y) - C^2 \ge 0$ is violated for $y \in J_x = (x + C - \sqrt{4xC + 2C^2}, x + C + \sqrt{4xC + 2C^2})$. Since $x \in J_x$ and $y \in S_0 \implies y \notin J_x$, $J_x$ is an open neighborhood of $x$ containing no elements of $S_0$. Thus $S_C$ is open.
This partitions the connected space $\mathbb{R}_{>0}$ into two disjoint non-empty open sets, which is a contradiction. Therefore, either $S_0$ or $S_C$ must be empty, meaning $c(x)$ is a constant $C \ge 0$ for all $x > 0$.

**4. Verification**
Substituting $f(x) = x + C$ into the original inequalities:
- $\sqrt{\frac{x^2 + (y+C)^2}{2}} \ge \frac{x+C+y}{2} \iff 2x^2 + 2(y+C)^2 \ge (x+y+C)^2 \iff (x - (y+C))^2 \ge 0$.
- $\frac{x+C+y}{2} \ge \sqrt{x(y+C)} \iff (x+y+C)^2 \ge 4x(y+C) \iff (x - (y+C))^2 \ge 0$.
Both are satisfied for any $C \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \ge 0$.
