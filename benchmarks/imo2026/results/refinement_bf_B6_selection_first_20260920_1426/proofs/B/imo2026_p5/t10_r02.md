To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we define $A(x, y) = \sqrt{\frac{x^2 + f(y)^2}{2}}$, $B(x, y) = \frac{f(x) + y}{2}$, and $C(x, y) = \sqrt{x f(y)}$. The given condition is $A \ge B \ge C$.

**1. Derivation of a Functional Equation**
Note that $A^2 - C^2 = \frac{x^2 + f(y)^2}{2} - x f(y) = \frac{1}{2}(x - f(y))^2$.
If we choose $x = f(y)$, then $A^2 - C^2 = 0$, which implies $A = C$. Since $A \ge B \ge C$, we must have $A = B = C$.
Substituting $x = f(y)$ into $B = A$, we obtain:
\[ \frac{f(f(y)) + y}{2} = \sqrt{\frac{f(y)^2 + f(y)^2}{2}} = f(y) \implies f(f(y)) = 2f(y) - y \]
for all $y \in \mathbb{R}_{>0}$.

**2. Analysis of the Growth of $f$**
Let $g(x) = f(x) - x$. The functional equation $f(f(y)) = 2f(y) - y$ can be rewritten as:
\[ f(f(y)) - f(y) = f(y) - y \implies g(f(y)) = g(y). \]
By induction, $g(f^{(n)}(y)) = g(y)$ for all $n \in \mathbb{N}$, where $f^{(n)}$ denotes the $n$-th iteration of $f$.
The sequence $f^{(n)}(y)$ satisfies the linear recurrence $f^{(n+1)}(y) = 2f^{(n)}(y) - f^{(n-1)}(y)$ with $f^{(0)}(y) = y$ and $f^{(1)}(y) = f(y)$. The general solution is $f^{(n)}(y) = n(f(y) - y) + y = n g(y) + y$.
Since the codomain of $f$ is $\mathbb{R}_{>0}$, we must have $f^{(n)}(y) > 0$ for all $n \in \mathbb{N}$ and $y > 0$. This implies $g(y) \ge 0$ for all $y \in \mathbb{R}_{>0}$.

**3. Establishing the Range of $g$**
From the given inequality $B \ge C$, we have:
\[ \frac{f(x) + y}{2} \ge \sqrt{x f(y)} \implies f(x) \ge 2\sqrt{x f(y)} - y. \]
Substituting $f(x) = x + g(x)$ and $f(y) = z$, so $y = z - g(y)$, we get:
\[ x + g(x) \ge 2\sqrt{xz} - (z - g(y)) = 2\sqrt{xz} - z + g(y) \]
\[ g(x) \ge g(y) - (x - 2\sqrt{xz} + z) = g(y) - (\sqrt{x} - \sqrt{z})^2. \]
This holds for all $x > 0$ and all $z$ in the image of $f$.
Let $C = \sup_{y > 0} g(y)$. If $C = 0$, then $g(y) = 0$ for all $y$, so $f(x) = x$.
If $C > 0$, let $c$ be any value in the image of $g$. There exists $y_0$ such that $g(y_0) = c$. Let $z_n = f^{(n)}(y_0) = y_0 + nc$. Then $g(z_n) = c$.
For any $x \ge y_0$, pick $n$ such that $z_n \le x < z_{n+1} = z_n + c$. Then:
\[ g(x) \ge c - (\sqrt{x} - \sqrt{z_n})^2 = c - \frac{(x - z_n)^2}{(\sqrt{x} + \sqrt{z_n})^2} > c - \frac{c^2}{(\sqrt{x} + \sqrt{z_n})^2}. \]
As $x \to \infty$, $z_n \to \infty$, so $\liminf_{x \to \infty} g(x) \ge c$. Since this holds for all $c \in \text{Im}(g)$, we have $\liminf_{x \to \infty} g(x) \ge C$. Since $g(x) \le C$, it follows that $\lim_{x \to \infty} g(x) = C$.
For any $y$ such that $g(y) > 0$, $f^{(n)}(y) \to \infty$ as $n \to \infty$. Since $g(y) = g(f^{(n)}(y))$, we have:
\[ g(y) = \lim_{n \to \infty} g(f^{(n)}(y)) = C. \]
Thus, for every $y \in \mathbb{R}_{>0}$, either $g(y) = 0$ or $g(y) = C$.

**4. Ruling out Mixed Values**
Suppose there exist $x_0, y_0$ such that $g(x_0) = C > 0$ and $g(y_0) = 0$.
Let $S_C = \{y : g(y) = C\}$ and $S_0 = \{y : g(y) = 0\}$.
For any $x \in S_C$ and $y \in S_0$, the inequality $A \ge B$ gives:
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \implies \sqrt{\frac{x^2 + y^2}{2}} \ge \frac{x + C + y}{2} \]
\[ 2x^2 + 2y^2 \ge (x + y + C)^2 = x^2 + y^2 + C^2 + 2xy + 2xC + 2yC \]
\[ (x - y)^2 \ge 2C(x + y) + C^2. \]
This inequality implies that $x$ cannot lie in the interval $I_y = (y + C - \sqrt{4yC + 2C^2}, y + C + \sqrt{4yC + 2C^2})$. Similarly, $y$ cannot lie in the interval $I_x = (x + C - \sqrt{4xC + 2C^2}, x + C + \sqrt{4xC + 2C^2})$.
Assume without loss of generality $y_0 < x_0$. Let $S = \{ z \in [y_0, x_0] : z \in S_0 \}$. $S$ is non-empty and bounded above, so let $s = \sup S$. Since $S_0 \cup S_C = \mathbb{R}_{>0}$, $s$ must belong to $S_0$ or $S_C$.
If $s \in S_0$, then for any $x \in S_C$, $x \notin I_s$. However, $I_s$ contains the interval $(s, s + \epsilon)$ for some $\epsilon > 0$ because $s + C + \sqrt{4sC + 2C^2} > s$ and $s + C - \sqrt{4sC + 2C^2} < s$ (since $C < \sqrt{4sC + 2C^2} \iff C^2 < 4sC + 2C^2$). Since $s = \sup S$ in $[y_0, x_0]$, any $x \in (s, x_0]$ must be in $S_C$. Picking $x \in (s, \min(x_0, s + \epsilon))$ yields a contradiction.
If $s \in S_C$, then for any $y \in S_0$, $y \notin I_s$. However, $I_s$ contains the interval $(s - \delta, s)$ for some $\delta > 0$ because $s + C - \sqrt{4sC + 2C^2} < s$. Since $s = \sup S$, there exist $y \in S_0$ arbitrarily close to $s$ from the left. Picking $y \in S_0 \cap (s - \delta, s)$ yields a contradiction.
Thus, $g(y)$ must be a constant $c \ge 0$.

**5. Final Verification**
If $f(x) = x + c$ for $c \ge 0$, then:
$\frac{f(x) + y}{2} = \frac{x + c + y}{2}$ and $\sqrt{x f(y)} = \sqrt{x(y + c)}$.
Let $u = x$ and $v = y + c$. Then $\frac{u+v}{2} \ge \sqrt{uv}$ is the standard AM-GM inequality, which holds for all $x, y, c > 0$.
Also, $\sqrt{\frac{x^2 + (y + c)^2}{2}} \ge \frac{x + y + c}{2}$ is the Root-Mean-Square $\ge$ Arithmetic-Mean inequality, which holds for all $x, y+c > 0$.
Both inequalities hold for all $x, y > 0$ and $c \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \ge 0$.
