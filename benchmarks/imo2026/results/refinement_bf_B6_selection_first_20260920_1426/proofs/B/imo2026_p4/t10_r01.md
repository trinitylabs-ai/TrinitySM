To determine the values of $\theta \in (0^\circ, 180^\circ)$ for which Mulan can guarantee victory in finitely many steps, we analyze the conditions under which she can force the triangle $T$ to possess an angle of exactly $\theta$.

Let the angles of the current triangle $T$ be $A, B, C$. Mulan chooses a vertex (say $A$) and a point $P$ on the opposite side $BC$. Let $\phi = \angle APB$. As $P$ moves from $B$ to $C$, $\phi$ varies continuously in the interval $(C, 180^\circ - B)$. The two resulting triangles are:
- $T_1$ with angles $(B, 180^\circ - B - \phi, \phi)$
- $T_2$ with angles $(C, \phi - C, 180^\circ - \phi)$

Mulan can force an angle $\alpha$ to appear in the next triangle regardless of Shan-Yu's choice if she can choose $\phi \in (C, 180^\circ - B)$ such that both $T_1$ and $T_2$ possess an angle $\alpha$. This occurs if:
1. $\phi = \alpha$ and $180^\circ - \phi = \alpha$, which implies $\alpha = 90^\circ$.
2. $180^\circ - B - \phi = \alpha$ and $\phi - C = \alpha$, which implies $180^\circ - (B + C) = 2\alpha \implies A = 2\alpha$.
Other combinations (e.g., $\phi = \alpha$ and $\phi - C = \alpha$) imply $C=0$ or $B=0$, which are impossible. Thus, Mulan can force an angle $\alpha$ if $\alpha = 90^\circ$ or if $T$ already contains an angle $2\alpha$.

Let $F = \{ 90^\circ / 2^k \mid k \in \{0, 1, 2, \dots\} \}$. Mulan can always force $90^\circ$ in one step (unless $T$ is already a right triangle). Once she has $90^\circ$, she can force $45^\circ, 22.5^\circ, \dots$ using the $A=2\alpha$ rule. Thus, Mulan can force any angle in $F$.

Let $S_\theta = \{ 2^k \theta \mid k \ge 0 \} \cap (0^\circ, 180^\circ)$. Mulan wins if she can force any angle in $S_\theta$. If she forces $2^k \theta$, she can force $2^{k-1} \theta, \dots, \theta$ in $k$ subsequent steps.
Mulan can force an angle in $S_\theta$ if she can choose $\phi \in (C, 180^\circ - B)$ such that both $T_1$ and $T_2$ have angles in $S_\theta$. Let $\theta_1, \theta_2 \in S_\theta$. This happens if:
- $\phi = \theta_1$ and $180^\circ - \phi = \theta_2 \implies \theta_1 + \theta_2 = 180^\circ$.
- $180^\circ - B - \phi = \theta_1$ and $\phi - C = \theta_2 \implies A = \theta_1 + \theta_2$.
- $\phi = \theta_1$ and $\phi - C = \theta_2 \implies C = \theta_1 - \theta_2$.
- $180^\circ - B - \phi = \theta_1$ and $180^\circ - \phi = \theta_2 \implies B = \theta_2 - \theta_1$.

If $\theta = \frac{180^\circ}{2^p + 2^q}$ for some $p \ge q \ge 0$, then $\theta_1 = 2^p \theta$ and $\theta_2 = 2^q \theta$ satisfy $\theta_1 + \theta_2 = 180^\circ$. Mulan can force $A=90^\circ$ and pick $\phi = \theta_1$. Since $C < \theta_1 < 180^\circ - B$ is possible (as $\theta_1 < 180^\circ$), she can force an angle in $S_\theta$ and thus win.

If $\theta = \frac{180^\circ}{2^p - 2^q}$ for some $p > q \ge 1$, then $\theta_1 = 2^{p-1} \theta$ and $\theta_2 = 2^{q-1} \theta$ satisfy $\theta_1 - \theta_2 = \frac{180^\circ(2^{p-1} - 2^{q-1})}{2^p - 2^q} = \frac{180^\circ}{2} = 90^\circ$. Mulan can force $B = 90^\circ$ and pick $\phi = 180^\circ - \theta_1$. Then $T_2$ has $180^\circ - \phi = \theta_1 \in S_\theta$ and $T_1$ has $180^\circ - B - \phi = 180^\circ - 90^\circ - (180^\circ - \theta_1) = \theta_1 - 90^\circ = \theta_2 \in S_\theta$. This is possible if $\phi \in (C, 180^\circ - B)$, which simplifies to $C < 180^\circ - \theta_1 < 90^\circ$. Since she can force $A=90^\circ$, $C$ can be made arbitrarily small and $180^\circ - \theta_1 < 90^\circ$ is $\theta_1 > 90^\circ$, which is $2^{p-1} \frac{180^\circ}{2^p - 2^q} > 90^\circ \iff 2^p > 2^p - 2^q$, which is always true.

Conversely, if Mulan can guarantee victory, she must be able to force an angle in $S_\theta$ from any initial $T$. The only angles she can force from an arbitrary $T$ are in $F$. Thus, she must be able to force $\theta_1, \theta_2 \in S_\theta$ such that $\theta_1 + \theta_2 = 180^\circ$ or $\theta_1 \pm \theta_2 \in F$.
If $\theta_1 + \theta_2 = 180^\circ$, then $(2^m + 2^n)\theta = 180^\circ \implies \theta = \frac{180^\circ}{2^m + 2^n}$.
If $\theta_1 \pm \theta_2 = 90^\circ / 2^k$, then $(2^m \pm 2^n)\theta = \frac{90^\circ}{2^k} \implies \theta = \frac{180^\circ}{2^{k+1}(2^m \pm 2^n)}$.
If the sign is $+$, $\theta = \frac{180^\circ}{2^{k+1+m} + 2^{k+1+n}}$, which is the "plus" form.
If the sign is $-$, $\theta = \frac{180^\circ}{2^{k+1+m} - 2^{k+1+n}}$, which is the "minus" form with $q = k+1+n \ge 1$.

Mulan can guarantee victory if and only if $\theta = \frac{180^\circ}{2^p + 2^q}$ for some $p \ge q \ge 0$ or $\theta = \frac{180^\circ}{2^p - 2^q}$ for some $p > q \ge 1$.
