We claim that Mulan can guarantee victory in finitely many steps if and only if $\theta = 180^\circ/N$ for some integer $N \ge 2$.

Let $W_\theta = \{n\theta \mid n \in \mathbb{N}, n\theta < 180^\circ\}$ be the set of positive integer multiples of $\theta$ that are less than $180^\circ$.

First, we show that if a triangle $T$ has at least one angle $\phi \in W_\theta$, Mulan can force a win. Let $\phi = n\theta$. If $n=1$, then $\phi = \theta$ and Mulan wins immediately. If $n > 1$, Mulan chooses the vertex $V$ with angle $\phi$ and makes a cut that splits $\phi$ into $\theta$ and $(n-1)\theta$. The resulting triangles $T_1$ and $T_2$ will have angles $(\alpha, \theta, 180^\circ - \alpha - \theta)$ and $(\beta, (n-1)\theta, 180^\circ - \beta - (n-1)\theta)$ respectively. If Shan-Yu keeps $T_1$, Mulan wins. If Shan-Yu keeps $T_2$, the new triangle has an angle $(n-1)\theta \in W_\theta$. By repeating this process at most $n-1$ times, Mulan forces a triangle with an angle $\theta$.

Next, we show that if $\theta = 180^\circ/N$ for some integer $N \ge 2$, Mulan can force a win from any starting triangle $T$. If $T$ already has an angle in $W_\theta$, she wins by the previous argument. Otherwise, suppose $T$ has angles $A, B, C \notin W_\theta$. Mulan can win in one move if she can make a cut such that both resulting triangles $T_1$ and $T_2$ possess angles in $W_\theta$.
Let the cut be from vertex $A$ to point $P$ on $BC$, with $\angle BAP = \alpha$. The angles of the resulting triangles are:
$T_1: (B, \alpha, 180^\circ - B - \alpha)$
$T_2: (C, A - \alpha, B + \alpha)$

Case 1: $N=2$ ($\theta = 90^\circ$). Here $W_{90} = \{90^\circ\}$.
If $T$ is acute, Mulan cuts from $A$ with $\alpha = 90^\circ - B$. Then $T_1$ has angle $180^\circ - B - (90^\circ - B) = 90^\circ$ and $T_2$ has angle $B + (90^\circ - B) = 90^\circ$. This cut is valid since $0 < 90^\circ - B < A$ is equivalent to $B < 90^\circ$ and $A+B > 90^\circ$ (which is $C < 90^\circ$), both of which are true for an acute triangle.
If $T$ is obtuse, let $C > 90^\circ$. Mulan cuts from $C$ to $AB$ with $\alpha = 90^\circ - A$. Then the resulting triangles have angles $(A, 90^\circ - A, 90^\circ)$ and $(B, C - (90^\circ - A), 90^\circ)$. This cut is valid since $0 < 90^\circ - A < C$ is equivalent to $A < 90^\circ$ and $A+C > 90^\circ$ (which is $B < 90^\circ$), both of which are true since $C$ is the only obtuse angle.

Case 2: $N \ge 3$ ($\theta \le 60^\circ$).
Mulan chooses the largest angle $A$ (so $A \ge 60^\circ \ge \theta$) and makes a cut with $\alpha = m\theta - B$ for some integer $m$. Then $B + \alpha = m\theta$ and $180^\circ - B - \alpha = 180^\circ - m\theta = (N-m)\theta$. Both are in $W_\theta$ if $1 \le m \le N-1$.
For the cut to be valid, we need $0 < m\theta - B < A$, or $B < m\theta < B+A$. Since $A \ge \theta$ and $B \notin W_\theta$, the interval $(B, B+A)$ must contain a multiple of $\theta$. Specifically, let $B = q\theta + r$ with $0 < r < \theta$. Then $(q+1)\theta$ is a multiple of $\theta$ and $B < (q+1)\theta < B + \theta \le B+A$. Since $B+A < 180^\circ = N\theta$, we have $m = q+1 \le N-1$. Thus, Mulan can always force both $T_1$ and $T_2$ to have angles in $W_\theta$.

Finally, we show that if $\theta \neq 180^\circ/N$ for any $N \in \mathbb{N}$, Mulan cannot guarantee victory. Suppose $T$ has no angle in $W_\theta$. For any cut from $A$ with angle $\alpha$, $T_1$ has an angle in $W_\theta$ if and only if $\alpha \in W_\theta$ or $180^\circ - B - \alpha \in W_\theta$. $T_2$ has an angle in $W_\theta$ if and only if $A - \alpha \in W_\theta$ or $B + \alpha \in W_\theta$.
If Mulan can force a win, she must make both $T_1$ and $T_2$ have angles in $W_\theta$. Checking the possible combinations:
1. $\alpha = n\theta$ and $A - \alpha = m\theta \implies A = (n+m)\theta \in W_\theta$.
2. $\alpha = n\theta$ and $B + \alpha = m\theta \implies B = (m-n)\theta \in W_\theta$.
3. $180^\circ - B - \alpha = n\theta$ and $A - \alpha = m\theta \implies 180^\circ - (A+B) = C = (n-m)\theta \in W_\theta$.
4. $180^\circ - B - \alpha = n\theta$ and $B + \alpha = m\theta \implies 180^\circ = (n+m)\theta$.
Since $A, B, C \notin W_\theta$ and $180^\circ$ is not a multiple of $\theta$, none of these can occur. Thus, Shan-Yu can always discard the triangle containing an angle in $W_\theta$ (if one exists), ensuring the remaining triangle never has an angle in $W_\theta$. Since $\theta \in W_\theta$, Mulan can never win.

The real values of $\theta$ for which Mulan can guarantee victory are $\theta = \frac{180^\circ}{N}$ for integers $N \ge 2$.
