We wish to determine all $\theta \in (0^\circ, 180^\circ)$ such that Mulan can guarantee victory in finitely many steps. We claim that Mulan can guarantee victory if and only if $\theta = \frac{180^\circ}{n}$ for some integer $n \geq 2$.

### 1. Sufficiency: $\theta = \frac{180^\circ}{n}$ for $n \in \{2, 3, \dots\}$
Suppose $\theta = \frac{180^\circ}{n}$. Mulan's strategy is to force the triangle $T$ to contain an angle that is a multiple of $\theta$, specifically $m\theta$ for some $m \in \{1, 2, \dots, n-1\}$.

First, Mulan ensures that $T$ contains an angle that is a multiple of $\theta$. Let the angles of the current triangle $T$ be $\alpha, \beta, \gamma$. If any angle is already a multiple of $\theta$, this step is complete. Otherwise, we consider the case where no angle is a multiple of $\theta$. Since $\alpha + \beta + \gamma = 180^\circ = n\theta$, we have two possibilities:
- If $n \geq 3$, then at least one angle must be $\geq \theta$. If all were strictly less than $\theta$, then $\alpha + \beta + \gamma < 3\theta \leq n\theta$, which is a contradiction.
- If $n = 2$, then $\theta = 90^\circ$. If any angle is $\geq 90^\circ$, we proceed as below. If all angles are strictly less than $90^\circ$, then $\gamma < 90^\circ < 180^\circ - \beta$ since $\beta < 90^\circ$.

Let $\alpha$ be an angle such that $\alpha \geq \theta$ (or if $n=2$ and the triangle is acute, the interval logic below still holds). Mulan makes a cut from the vertex $A$ (with angle $\alpha$) to a point $P$ on the opposite side $BC$. As $P$ moves from $C$ to $B$, the angle $\angle APB$ varies continuously from $\gamma$ to $180^\circ - \beta$. The length of this interval is $(180^\circ - \beta) - \gamma = \alpha$. 
If $\alpha > \theta$, the interval $(\gamma, 180^\circ - \beta)$ has length greater than $\theta$ and must contain at least one multiple of $\theta$. If $\alpha = \theta$, the interval is $(\gamma, \gamma + \theta)$; since $\gamma$ is not a multiple of $\theta$, this interval contains exactly one multiple of $\theta$. In either case, Mulan can choose $P$ such that $\angle APB = m\theta$ for some $m \in \{1, \dots, n-1\}$. The two resulting triangles $T_1$ and $T_2$ have angles $m\theta$ and $180^\circ - m\theta = (n-m)\theta$ at $P$, respectively. Since both are multiples of $\theta$, no matter which triangle Shan-Yu keeps, the new triangle $T$ contains an angle that is a multiple of $\theta$.

Once $T$ contains an angle $m\theta$ for $m \in \{2, \dots, n-1\}$, Mulan can force the next triangle to contain $(m-1)\theta$. Let $\angle A = m\theta$. She chooses $P$ on $BC$ such that $\angle BAP = \theta$. This is possible since $m\theta > \theta$. The resulting triangles are $T_1$ (containing $\theta$) and $T_2$ (containing $\angle CAP = (m-1)\theta$). If Shan-Yu picks $T_1$, Mulan wins immediately. If he picks $T_2$, the new triangle contains the angle $(m-1)\theta$. By repeating this descent process, Mulan eventually forces $m=1$, meaning the triangle contains $\theta$, and she wins.

### 2. Necessity: $\theta \neq \frac{180^\circ}{n}$ for all $n \in \{2, 3, \dots\}$
Suppose $180^\circ$ is not a multiple of $\theta$. Shan-Yu's strategy is to maintain the invariant that no angle of $T$ is a multiple of $\theta$.

Initially, Shan-Yu chooses $T_0$ such that none of its angles are multiples of $\theta$. This is always possible because the set of multiples $\{m\theta \mid m \in \mathbb{Z}\}$ is countable, while the space of possible triangles is continuous.

Suppose the current triangle $T$ has angles $\alpha, \beta, \gamma$, none of which are multiples of $\theta$. Mulan makes a cut from vertex $A$ to a point $P$ on $BC$. Let $\angle BAP = x$. The two resulting triangles $T_1$ and $T_2$ have angles:
$T_1: \{\beta, x, 180^\circ - \beta - x\}$
$T_2: \{\gamma, \alpha - x, \beta + x\}$

For $T_1$ to have an angle that is a multiple of $\theta$, we must have $x = m\theta$ or $180^\circ - \beta - x = k\theta$.
For $T_2$ to have an angle that is a multiple of $\theta$, we must have $\alpha - x = j\theta$ or $\beta + x = l\theta$.

We check if Mulan can force both $T_1$ and $T_2$ to have a multiple of $\theta$:
1. If $x = m\theta$, then $T_2$ has angles $\{\gamma, \alpha - m\theta, \beta + m\theta\}$. Since $\alpha, \beta, \gamma$ are not multiples of $\theta$, none of these are multiples of $\theta$.
2. If $180^\circ - \beta - x = k\theta$, then $x = 180^\circ - \beta - k\theta$. $T_2$ has angles $\{\gamma, \alpha - (180^\circ - \beta - k\theta), \beta + (180^\circ - \beta - k\theta)\}$.
   - $\gamma$ is not a multiple.
   - $\alpha + \beta - 180^\circ + k\theta = (180^\circ - \gamma) - 180^\circ + k\theta = k\theta - \gamma$, which is a multiple if and only if $\gamma$ is a multiple.
   - $180^\circ - k\theta$ is a multiple if and only if $180^\circ$ is a multiple of $\theta$, which is false by assumption.

Thus, if no angle of $T$ is a multiple of $\theta$, then for any cut Mulan makes, at most one of the resulting triangles contains an angle that is a multiple of $\theta$. Shan-Yu always discards the triangle containing the multiple (if it exists). Consequently, $T$ never contains an angle that is a multiple of $\theta$, and since $\theta$ is a multiple of itself, Mulan can never win.

Mulan can guarantee victory if and only if $\theta = \frac{180^\circ}{n}$ for some integer $n \geq 2$.
