Let $S_n$ be the set of prime factors of $a_n$ for $n \ge 1$. The condition $\gcd(x, a_i) > 1$ for all $i = 1, \dots, n$ is equivalent to the condition that the set of prime factors of $x$ is a hitting set for the collection $\mathcal{S}_n = \{ S_1, S_2, \dots, S_n \}$. A hitting set for $\mathcal{S}_n$ is a set of primes $P$ such that $P \cap S_i \neq \emptyset$ for all $i = 1, \dots, n$.

Let $V_n = \{ x \in \mathbb{Z}^+ : \gcd(x, a_i) > 1 \text{ for all } i = 1, \dots, n \}$. The sequence is defined by $a_{n+1} = \min \{ x \in \mathbb{Z}^+ : x > a_n \text{ and } x \in V_n \}$. Note that $V_1 \supseteq V_2 \supseteq V_3 \dots$ because the conditions are nested.

A set $H$ is a minimal hitting set for $\mathcal{S}_n$ if it is a hitting set and no proper subset of $H$ is a hitting set. Let $\mathcal{H}_n$ be the collection of all minimal hitting sets of $\mathcal{S}_n$. Then $x \in V_n$ if and only if the set of prime factors of $x$ contains some $H \in \mathcal{H}_n$. Let $M(H) = \prod_{p \in H} p$. Then $x \in V_n$ if and only if $x$ is a multiple of $M(H)$ for some $H \in \mathcal{H}_n$. Thus, $V_n$ is a union of ideals:
$$V_n = \bigcup_{H \in \mathcal{H}_n} M(H) \mathbb{Z}.$$
Since $S_1$ is a hitting set for $\mathcal{S}_n$, every minimal hitting set $H \in \mathcal{H}_n$ satisfies $|H| \le |S_1|$.

We prove by induction on $k = |S_1|$ that $V_n$ eventually stabilizes.
Base Case ($k=1$): Let $S_1 = \{p\}$. Since $\gcd(a_i, a_1) > 1$ for all $i \ge 1$, $p$ must divide every $a_i$. Thus, for any $x$, $\gcd(x, a_i) > 1$ for all $i \le n$ if and only if $p | x$. Thus $V_n = p\mathbb{Z}$ for all $n \ge 1$, which is stable.

Inductive Step: Assume that for any sequence $(b_n)$ defined by the same rule where $b_1$ has fewer than $k$ prime factors, the corresponding $V$-sets stabilize. Let $|S_1| = k$.
Decompose $V_n$ into slices based on the prime factors of $a_1$:
$$V_n = \bigcup_{p \in S_1} V_{n, p}, \quad \text{where } V_{n, p} = \{ x \in V_n : p | x \}.$$
For a fixed $p \in S_1$, $x \in V_{n, p}$ if and only if $x = py$ and $\gcd(py, a_i) > 1$ for all $i \le n$. This condition is automatically satisfied if $p | a_i$. If $p \nmid a_i$, we require $\gcd(y, a_i) > 1$. Let $I_{n, p} = \{ i \le n : p \nmid a_i \}$. Then:
$$V_{n, p} = p \cdot W_{n, p}, \quad \text{where } W_{n, p} = \{ y \in \mathbb{Z}^+ : \gcd(y, a_i) > 1 \text{ for all } i \in I_{n, p} \}.$$
The set $W_{n, p}$ is the $V$-set associated with the collection $\mathcal{S}_{n, p} = \{ S_i : i \in I_{n, p} \}$. Since $S_1$ is a hitting set for $\mathcal{S}_n$ and $p \notin S_i$ for $i \in I_{n, p}$, the set $S_1 \setminus \{p\}$ must be a hitting set for $\mathcal{S}_{n, p}$. Because $|S_1 \setminus \{p\}| = k-1$, the inductive hypothesis implies that $W_{n, p}$ stabilizes as $n \to \infty$. Since $V_n$ is a finite union of sets $V_{n, p}$, and each $V_{n, p} = p \cdot W_{n, p}$ stabilizes, the set $V_n$ must also stabilize to some $V_N$ for all $n \ge N$.

Once $V_n$ stabilizes to $V_N$, the sequence $a_n$ for $n \ge N$ consists of the elements of $V_N$ in increasing order. Let $V_N = \{ v_1, v_2, v_3, \dots \}$ with $v_1 < v_2 < \dots$. Since $V_N$ is a union of finitely many ideals $M(H)\mathbb{Z}$, it is periodic with period $L = \text{lcm}_{H \in \mathcal{H}_N} M(H)$. Thus, there exists $T$ (the number of elements of $V_N$ in one period) such that $v_{m+T} = v_m + L$ for all $m \ge 1$. For $n \ge N$, $a_n = v_{n-N+k}$ for some $k$. Then $a_{n+T} = v_{n+T-N+k} = v_{n-N+k} + L = a_n + L$ for all $n \ge N$.

Finally, we show this periodicity extends to $n=1$. For all $i \ge 1$, $\gcd(a_1, a_i) > 1$ by definition. Thus $a_1 \in V_n$ for all $n$, and specifically $a_1 \in V_N$. Since $V_N = V_{N-1}$, $a_N$ is the smallest element of $V_N$ greater than $a_{N-1}$. Since $a_N \in V_N$ and $a_{N-1} \in V_N$, $a_{N-1}$ must be the element of $V_N$ immediately preceding $a_N$. By induction, $a_n$ are the elements of $V_N$ in increasing order for all $n \ge 1$. Thus $a_{n+T} = a_n + L$ for all $n \ge 1$.
