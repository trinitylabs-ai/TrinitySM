Let $Q_n$ denote the set of prime factors of $a_n$. The condition $\gcd(a_{n+1}, a_i) > 1$ for all $i=1, \dots, n$ implies that $Q_{n+1}$ is a hitting set for the family of sets $\mathcal{F}_n = \{Q_1, \dots, Q_n\}$. Let $M_n$ be the set of products of primes in minimal hitting sets of $\mathcal{F}_n$. Then $a_{n+1}$ is the smallest integer greater than $a_n$ that is a multiple of at least one $m \in M_n$:
\[ a_{n+1} = \min_{m \in M_n} \left\{ m \left\lceil \frac{a_n+1}{m} \right\rceil \right\} \]
Let $m_{min}(n) = \min M_n$. Any minimal hitting set of $\mathcal{F}_{n+1}$ must contain a minimal hitting set of $\mathcal{F}_n$ as a subset, so $m_{min}(n+1) \ge m_{min}(n)$. Since every $Q_i$ shares at least one prime factor with $Q_1$, the set $Q_1$ is itself a hitting set for $\mathcal{F}_n$ for all $n$. Thus, $M_n$ always contains at least one element $m \le \prod_{p \in Q_1} p$. Consequently, $m_{min}(n)$ is a non-decreasing sequence of positive integers bounded above, so it must stabilize to a constant $m^*$ for $n \ge N$.

For $n \ge N$, $m^* \in M_n$. Any minimal hitting set $H$ of $\mathcal{F}_n$ must satisfy $|H| \le |Q_1|$ because $Q_1$ is a hitting set. Since $M_n$ is a subset of the products of at most $|Q_1|$ primes from the set $P_n = \bigcup_{i=1}^n Q_i$, and any $m \in M_n$ that fails to hit $Q_{n+1}$ must be replaced by a multiple $m \cdot p$ (where $p \in Q_{n+1}$) to remain a hitting set, and since $m \cdot p \le \prod_{p \in Q_1} p$, this process of increasing $m$ must terminate. Thus, the set $M_n$ must stabilize to a constant set $M^*$ for $n \ge N'$.

For $n \ge N'$, let $g(a) = \min_{m \in M^*} \{ m \lceil (a+1)/m \rceil \}$. Then $a_{n+1} = g(a_n)$. Let $L = \text{lcm}_{m \in M^*} m$. Note that $g(a+L) = \min_{m \in M^*} \{ m \lceil (a+L+1)/m \rceil \} = \min_{m \in M^*} \{ m (\lceil (a+1)/m \rceil + L/m) \} = g(a) + L$.
The sequence $x_n = a_n \pmod L$ satisfies $x_{n+1} = g(a_n) \pmod L = g(x_n) \pmod L$. Since $x_n$ takes values in the finite set $\{0, 1, \dots, L-1\}$, it must eventually become periodic. Thus, there exist $T$ and $k$ such that $a_{n+T} \equiv a_n \pmod L$ for all $n \ge N''$. Since $a_n$ is strictly increasing, $a_{n+T} = a_n + k_n L$ for some $k_n \ge 1$. Then $a_{n+T+1} = g(a_{n+T}) = g(a_n + k_n L) = g(a_n) + k_n L = a_{n+1} + k_n L$. This implies $k_n$ is a constant $k$. Let $L_{new} = kL$. Then $a_{n+T} = a_n + L_{new}$ for all $n \ge N''$.

To extend this to $n=1$, let $C = \text{lcm}(a_1, \dots, a_{N''-1})$. Replace $L_{new}$ with $L' = L_{new} \cdot C$ and $T$ with $T' = T \cdot C$. Then $a_{n+T'} = a_n + L'$ for $n \ge N''$. We use backwards induction. For $m = N'', N''-1, \dots, 2$, suppose $a_{n+T'} = a_n + L'$ for $n \ge m$. Consider $x = a_{m-1} + L'$. For $i < m$, $\gcd(x, a_i) = \gcd(a_{m-1} + L', a_i) = \gcd(a_{m-1}, a_i) > 1$ because $L'$ is a multiple of $a_i$. For $m \le i < m-1+T'$, $\gcd(x, a_i) = \gcd(a_{m-1} + L', a_{i-T'} + L') = \gcd(a_{m-1}, a_{i-T'}) > 1$ because $i-T' < m-1$. Thus $x$ is a candidate for $a_{m-1+T'}$. If there were a smaller candidate $y$ such that $a_{m-1} + L' < y < a_m + L'$, then $y-L'$ would be a candidate for $a_m$ such that $a_{m-1} < y-L' < a_m$, contradicting the minimality of $a_m$. Thus $a_{m-1+T'} = a_{m-1} + L'$. By induction, $a_{n+T'} = a_n + L'$ for all $n \ge 1$.
