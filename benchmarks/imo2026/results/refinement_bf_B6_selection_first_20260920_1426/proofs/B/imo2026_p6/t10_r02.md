Let $\mathcal{P}(m)$ denote the set of prime factors of a positive integer $m$. For any $n \ge 1$, let $\mathcal{F}_n = \{\mathcal{P}(a_1), \dots, \mathcal{P}(a_n)\}$. We define $\mathcal{G}_n$ to be the collection of minimal elements of $\mathcal{F}_n$ under inclusion. An integer $x$ satisfies $\gcd(x, a_i) > 1$ for all $i=1, \dots, n$ if and only if $\mathcal{P}(x) \cap S \neq \emptyset$ for every $S \in \mathcal{G}_n$. Such a set $\mathcal{P}(x)$ is called a hitting set for $\mathcal{G}_n$.

By the definition of the sequence, $a_{n+1}$ is the smallest integer $x > a_n$ such that $\mathcal{P}(x)$ is a hitting set for $\mathcal{G}_n$. Let $C_n = \{x \in \mathbb{Z}^+ \mid \mathcal{P}(x) \text{ hits } \mathcal{G}_n\}$. Then $a_{n+1} = \min \{x \in C_n \mid x > a_n\}$. The family $\mathcal{G}_{n+1}$ is the collection of minimal elements of $\mathcal{G}_n \cup \{\mathcal{P}(a_{n+1})\}$.

First, we observe that $\mathcal{P}(a_1)$ is a hitting set for $\mathcal{G}_n$ for all $n \ge 1$. Indeed, every $S \in \mathcal{G}_n$ is a subset of some $\mathcal{P}(a_i)$ for $i \le n$, and since $\gcd(a_1, a_i) > 1$, $\mathcal{P}(a_1) \cap \mathcal{P}(a_i) \neq \emptyset$. By induction, $\mathcal{G}_n$ is an intersecting family (any two $S, S' \in \mathcal{G}_n$ have $S \cap S' \neq \emptyset$). Since $\mathcal{P}(a_1)$ is a hitting set for $\mathcal{G}_n$, any minimal hitting set $S$ of $\mathcal{G}_n$ satisfies $|S| \le |\mathcal{P}(a_1)|$. Let $m = |\mathcal{P}(a_1)|$. Every $S \in \mathcal{G}_n$ is a minimal hitting set of $\mathcal{G}_{n-1}$, so $|S| \le m$ for all $S \in \mathcal{G}_n$.

A known result in extremal set theory states that for any fixed $m$, there are only finitely many isomorphism classes of intersecting families of sets of size at most $m$. Let $\delta(C_n)$ be the density of the set $C_n$. If $\mathcal{G}_{n+1} \neq \mathcal{G}_n$, then $\mathcal{P}(a_{n+1})$ does not contain any $S \in \mathcal{G}_n$, which implies $C_{n+1} \subsetneq C_n$ and thus $\delta(C_{n+1}) < \delta(C_n)$. Since $\delta(C_n)$ is a non-increasing sequence bounded below by $\delta(\{x \mid \mathcal{P}(x) \supseteq \mathcal{P}(a_1)\}) = 1/M_{\mathcal{P}(a_1)} > 0$, and because the number of possible structures of $\mathcal{G}_n$ is finite, the sequence of families $\mathcal{G}_n$ must stabilize. Thus, there exists $N$ such that $\mathcal{G}_n = \mathcal{G}$ for all $n \ge N$.

Once $\mathcal{G}_n$ stabilizes to $\mathcal{G}$, the sequence $(a_n)_{n \ge N}$ consists of the integers in increasing order that belong to the set $C = \{ x \in \mathbb{Z}^+ \mid \mathcal{P}(x) \text{ hits } \mathcal{G} \}$. An integer $x$ is in $C$ if and only if $\gcd(x, \prod_{p \in S} p) > 1$ for every $S \in \mathcal{G}$. This property depends only on the residue of $x$ modulo $M = \prod_{p \in \bigcup \mathcal{G}} p$. Thus, $C$ is a union of $k$ congruence classes $r_1 < r_2 < \dots < r_k$ modulo $M$. The elements of $C$ are $qM + r_j$ for $q \ge 0$ and $j \in \{1, \dots, k\}$, which implies $a_{n+k} = a_n + M$ for all $n \ge N$.

Finally, we show this periodicity holds for all $n \ge 1$. Since $\mathcal{P}(a_1)$ hits every $S \in \mathcal{G}$, $a_1 \in C$. Because $C \subseteq C_n$ for all $n$, the sequence $a_{n+1} = \min \{x \in C_n \mid x > a_n\}$ satisfies $a_{n+1} \le \min \{x \in C \mid x > a_n\}$. Let $c_1 < c_2 < \dots$ be the elements of $C$ in increasing order. Since $a_1 \in C$, let $a_1 = c_j$. Then $a_2 \le c_{j+1}$, $a_3 \le c_{j+2}$, and in general $a_n \le c_{j+n-1}$. However, for $n \ge N$, we know $a_n$ are the elements of $C$ in increasing order, so $a_n = c_{j+n-1}$ for $n \ge N$. This implies $a_n = c_{j+n-1}$ for all $n \ge 1$, as any deviation $a_i < c_{j+i-1}$ would result in $a_N < c_{j+N-1}$. Consequently, $a_{n+k} = a_n + M$ for all $n \ge 1$.

Setting $T=k$ and $L=M$, we have $a_{n+T} = a_n + L$ for every positive integer $n$.
