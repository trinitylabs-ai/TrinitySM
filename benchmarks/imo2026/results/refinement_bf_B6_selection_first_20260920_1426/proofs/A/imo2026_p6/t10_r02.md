Let $\mathcal{P}(m)$ denote the set of prime factors of a positive integer $m > 1$. The condition $\gcd(x, a_i) > 1$ for all $i = 1, \dots, n$ is equivalent to $\mathcal{P}(x) \cap \mathcal{P}(a_i) \neq \emptyset$ for all $i = 1, \dots, n$. Let $C_n = \{ x \in \mathbb{Z}^+ \mid \forall i \in \{1, \dots, n\}, \gcd(x, a_i) > 1 \}$. By the definition of the sequence, $a_{n+1} = \min \{ x \in C_n \mid x > a_n \}$.

Note that $C_1 \supseteq C_2 \supseteq C_3 \dots$ is a nested sequence of sets. Since $\gcd(a_1, a_i) > 1$ for all $i \ge 1$ (by the definition of $a_i$ for $i > 1$), the set $S_1 = \mathcal{P}(a_1)$ is a hitting set for the family $\{S_i \mid i \ge 1\}$ where $S_i = \mathcal{P}(a_i)$. Let $M = \prod_{p \in S_1} p$. Any multiple of $M$ is an element of $C_n$ for all $n \ge 1$. Consequently, for any $n$, the interval $(a_n, a_n + M]$ contains at least one element of $C_n$ (namely, the smallest multiple of $M$ greater than $a_n$). Thus, $a_{n+1} \le a_n + M$ for all $n \ge 1$, meaning the sequence has bounded gaps.

Let $C = \bigcap_{n=1}^\infty C_n = \{ x \in \mathbb{Z}^+ \mid \forall i \ge 1, \gcd(x, a_i) > 1 \}$. Since $a_n \in C_{n-1}$ by definition and $\gcd(a_n, a_m) > 1$ for all $m > n$ by the definition of $a_m$, it follows that $a_n \in C$ for all $n \ge 1$.

We now prove that the set of all primes $P = \bigcup_{n=1}^\infty S_n$ is finite. Suppose for contradiction that $P$ is infinite. Let $P_n = \bigcup_{i=1}^n S_i$. For $n$ sufficiently large such that $a_n > M$, consider any prime factor $p$ of $a_{n+1}$. If $p \notin P_n$, then $p$ does not divide any $a_i$ for $i \le n$. Thus, $a_{n+1}/p$ still satisfies $\gcd(a_{n+1}/p, a_i) = \gcd(a_{n+1}, a_i) > 1$ for all $i \le n$, so $a_{n+1}/p \in C_n$. By the minimality of $a_{n+1}$ as the smallest element of $C_n$ greater than $a_n$, we must have $a_{n+1}/p \le a_n$.

Since $a_{n+1} \le a_n + M$, we have $a_{n+1}/p \le (a_n + M)/p$. If $p > a_n + M$, then $a_{n+1}/p < 1$, which is impossible. If $p \le a_n + M$, then $a_{n+1}/p$ is an integer. If $a_{n+1}/p = 1$, then $a_{n+1} = p$. But $a_{n+1}$ must hit $S_1$, so $p \in S_1 \subseteq P_n$, contradicting $p \notin P_n$. Thus $a_{n+1}/p \ge 2$, which implies $p \le (a_n + M)/2$. 

However, if $P$ is infinite, there must exist some $n$ such that $a_{n+1}$ is divisible by a prime $p > a_n + M$. But we just showed $a_{n+1} \le a_n + M$. More generally, if $p \notin P_n$, then $a_{n+1}$ must be a multiple of $p$ and some $y \in C_n$ with $y \le a_n$. But there is always an element $y' \in C_n$ in the interval $(a_n, a_n + M]$. If $p$ is very large, $p \cdot y$ will exceed $a_n + M$, so $a_{n+1}$ would be $y'$ instead. Specifically, if $p > a_n + M$, then $p \cdot y > a_n + M \ge a_{n+1}$, so $a_{n+1}$ cannot be a multiple of $p$. If $M < p \le a_n + M$, then $a_{n+1}/p \le (a_n + M)/p < 2$ for $a_n$ large enough, implying $a_{n+1} = p$, which we already saw is impossible. Thus, for $n$ sufficiently large, $S_{n+1} \subseteq P_n$, and $P$ is finite.

Since $P$ is finite, the condition $x \in C$ is a finite intersection of conditions of the form $\bigvee_{p \in S_i} (p|x)$. This defines $C$ as a union of congruence classes modulo $L = \prod_{p \in P} p$, and thus $C$ is periodic.

Since $C_n$ is a nested sequence of sets and $C = \bigcap C_n$, and since $P$ is finite, the constraints $\gcd(x, a_i) > 1$ become redundant once all minimal hitting sets of $\{S_i\}$ have appeared. Thus, $C_n = C$ for all $n \ge N$ for some $N$. For $n \ge N$, $a_{n+1}$ is the smallest element of $C$ greater than $a_n$. Thus, the sequence $(a_n)$ eventually enumerates the elements of $C$ in increasing order. For a periodic set $C$, the sequence of its elements $x_k$ satisfies $x_{k+T} = x_k + L$ for some $T, L$. Since $a_1$ is the first element of $C$ and the sequence is determined by $a_1$ and the rule $a_{n+1} = \min \{ x \in C_n \mid x > a_n \}$, this periodicity holds for all $n \ge 1$.
