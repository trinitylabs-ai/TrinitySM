Let $P_n$ be the set of prime factors of $a_n$. The condition $\gcd(a_{n+1}, a_i) > 1$ for all $i=1, \dots, n$ implies that $a_{n+1}$ must share at least one prime factor with each $P_i$. A set of primes $H$ is called a hitting set for the collection $S_n = \{P_1, \dots, P_n\}$ if $H \cap P_i \neq \emptyset$ for all $i=1, \dots, n$. Let $\mathcal{H}_n$ be the collection of all hitting sets for $S_n$, and for any $H \in \mathcal{H}_n$, let $m(H) = \prod_{p \in H} p$.

The integer $a_{n+1}$ is the smallest integer greater than $a_n$ that is a multiple of $m(H)$ for some $H \in \mathcal{H}_n$. Thus,
\[ a_{n+1} = \min_{H \in \mathcal{H}_n} \left\lceil \frac{a_n+1}{m(H)} \right\rceil m(H). \]
Let $H_n^*$ be a hitting set that achieves this minimum. Since $m(H_n^*)$ divides $a_{n+1}$, we have $H_n^* \subseteq P_{n+1}$. Because $H_n^* \in \mathcal{H}_n$ and $H_n^* \cap P_{n+1} \neq \emptyset$, it follows that $H_n^* \in \mathcal{H}_{n+1}$. Since $\mathcal{H}_{n+1} = \{ H \in \mathcal{H}_n : H \cap P_{n+1} \neq \emptyset \}$, we have $\mathcal{H}_{n+1} \subseteq \mathcal{H}_n$.

Let $m_n = \min \{ m(H) : H \in \mathcal{H}_n \}$. Since $\mathcal{H}_{n+1} \subseteq \mathcal{H}_n$, the sequence $(m_n)$ is non-decreasing. We claim that $m_n$ is bounded. If $m_n > a_n$, then for any $H \in \mathcal{H}_n$, the smallest multiple of $m(H)$ greater than $a_n$ is $m(H)$ itself. Thus $a_{n+1} = \min_{H \in \mathcal{H}_n} m(H) = m_n$. In this case, $P_{n+1}$ is the set of prime factors of $m_n$. Since $m_n = m(H_n^*)$ for some $H_n^* \in \mathcal{H}_n$, we have $P_{n+1} = H_n^*$. Since $H_n^* \in \mathcal{H}_n$ and $H_n^* \cap P_{n+1} \neq \emptyset$, we have $H_n^* \in \mathcal{H}_{n+1}$, so $m_{n+1} \le m(H_n^*) = m_n$. Since $m_n$ is non-decreasing, $m_{n+1} = m_n$. Thus, if $m_n$ ever exceeds $a_n$, it becomes constant. If $m_n \le a_n$ for all $n$, then $a_{n+1} \le a_n + m_n$. Since $m_n$ is non-decreasing and the hitting sets are constrained by the finite set $P_1$, $m_n$ must eventually stabilize to a constant $m^*$ for $n \ge N_1$.

For $n \ge N_1$, let $\mathcal{M}_n = \{ H \in \mathcal{H}_n : m(H) = m^* \}$. Since $m^*$ is the minimum product, $\mathcal{M}_n$ is a non-increasing sequence of finite sets, which must stabilize to $\mathcal{M}_N$ for $n \ge N$. For $n \ge N$, $a_{n+1} \le a_n + m^*$. Any hitting set $H$ that minimizes $a_{n+1}$ must satisfy $m(H) \le a_n + m^*$. If $a_{n+1}$ is achieved by $H$ where $m(H) > m^*$, then either $m(H) \le (a_n + m^*)/2$ or $a_{n+1} = m(H)$. If $a_{n+1} = m(H)$, then $P_{n+1} = H$, and $\mathcal{H}_{n+1}$ removes all hitting sets disjoint from $H$. Since $\mathcal{M}_n$ is finite, this can only happen finitely often. Eventually, for $n \ge N'$, $a_{n+1}$ is determined by a fixed finite set of hitting sets $\mathcal{S}_N$ with $m(H) \le M$ for some constant $M$:
\[ a_{n+1} = f(a_n) = \min_{H \in \mathcal{S}_N} \left\lceil \frac{a_n+1}{m(H)} \right\rceil m(H). \]
Let $L_0 = \text{lcm} \{ m(H) : H \in \mathcal{S}_N \}$. Then $f(x + L_0) = f(x) + L_0$. The sequence of residues $a_n \pmod{L_0}$ for $n \ge N'$ must eventually become periodic. Let $T$ be the period such that $a_{n+T} \equiv a_n \pmod{L_0}$ for $n \ge N''$. Then the increments $d_n = a_{n+1} - a_n$ satisfy $d_{n+T} = f(a_{n+T}) - a_{n+T} = f(a_n + k L_0) - (a_n + k L_0) = f(a_n) - a_n = d_n$. Thus $a_{n+T} - a_n = \sum_{i=n}^{n+T-1} d_i = L$ for some constant $L$ and all $n \ge N''$. By choosing $T$ and $L$ sufficiently large to encompass the initial transient phase, there exist positive integers $T$ and $L$ such that $a_{n+T} = a_n + L$ for every positive integer $n$.
