Let $\theta \in (0^\circ, 180^\circ)$. We wish to determine all $\theta$ such that Mulan can guarantee victory in finitely many steps. Let $S = \{n\theta \mid n \in \mathbb{N}, n\theta < 180^\circ\}$. We say a triangle $T$ is a winning position if Mulan can force the game to end in finitely many steps.

First, we show that any triangle $T$ possessing an angle in $S$ is a winning position. If $T$ has an angle $\phi = n\theta$, Mulan can choose the vertex $A$ with $\angle A = n\theta$ and make a cut such that one resulting triangle $T_1$ has an angle $\theta$ and the other $T_2$ has an angle $(n-1)\theta$. If Shan-Yu keeps $T_1$, Mulan wins immediately. If he keeps $T_2$, the new triangle has an angle $(n-1)\theta \in S$. By repeating this process, Mulan will force a triangle with an angle $\theta$ in at most $n-1$ steps.

Next, suppose $180^\circ = N\theta$ for some integer $N \ge 2$. Let $T$ have angles $A, B, C$. If any angle is in $S$, Mulan wins. Otherwise, Mulan can choose a vertex, say $A$, and a point $P$ on $BC$ such that $\angle BAP = \alpha$. The resulting triangles $T_1$ and $T_2$ have angles $(B, \alpha, 180^\circ - B - \alpha)$ and $(C, A - \alpha, B + \alpha)$, respectively. Mulan wins if she can find $\alpha \in (0, A)$ such that both $T_1$ and $T_2$ have an angle in $S$.
Setting $\alpha = 180^\circ - B - n\theta$ for some $n \in \mathbb{Z}$, $T_1$ has an angle $n\theta \in S$ and $T_2$ has an angle $B + \alpha = 180^\circ - n\theta = (N-n)\theta \in S$. This cut is valid if $0 < 180^\circ - B - n\theta < A$, which is equivalent to $C < n\theta < 180^\circ - B$.
Let $x = A/\theta, y = B/\theta, z = C/\theta$, so $x+y+z = N$. Mulan can force a win if there exists $n \in \mathbb{Z}$ such that $z < n < N-y$ (cut from $A$), or $x < n < N-z$ (cut from $B$), or $y < n < N-x$ (cut from $C$).
If $x > 1$, the interval $(z, N-y)$ has length $x > 1$. If $z$ or $N-y$ are integers, Mulan wins immediately. Otherwise, an interval of length $> 1$ always contains an integer. If $x \le 1, y \le 1, z \le 1$, then $x+y+z \le 3$, so $N \le 3$. For $N=2$, if $x, y, z \notin \mathbb{Z}$, then $x+y+z=2$ implies at least one angle, say $z$, is $< 1$. Then $x+y > 1$. If $x < 1$, then $1 \in (z, 2-y)$ since $z < 1$ and $y < 1$ (because $x+y+z=2$ and $z>0, x>0$). If $x \ge 1$, then $x=1$ since $x \le 1$, so $x\theta = \theta \in S$. For $N=3$, if $x, y, z \notin \mathbb{Z}$, then $x+y+z=3$. If $x > 1$, Mulan wins. If $x \le 1, y \le 1, z \le 1$, then $x=y=z=1$, so $x\theta = \theta \in S$. Thus, for any $N \in \mathbb{Z}_{\ge 2}$, Mulan can guarantee victory.

Conversely, suppose $180^\circ/\theta \notin \mathbb{Z}$. We claim that a triangle is a winning position if and only if it has an angle in $S$. We already showed $S \subseteq W_\theta$. Now suppose $T$ has no angle in $S$. For any cut $\alpha$ from vertex $A$:
$T_1$ has angles $(B, \alpha, 180^\circ - B - \alpha)$ and $T_2$ has angles $(C, A - \alpha, B + \alpha)$.
$T_1$ has an angle in $S$ iff $\alpha = n\theta$ or $180^\circ - B - \alpha = n\theta$.
If $\alpha = n\theta$, then $T_2$ has an angle in $S$ iff $A - n\theta = m\theta$ (so $A \in S$) or $B + n\theta = m\theta$ (so $B \in S$). Both are false.
If $\alpha = 180^\circ - B - n\theta$, then $T_2$ has an angle in $S$ iff $A - (180^\circ - B - n\theta) = m\theta$ or $B + (180^\circ - B - n\theta) = m\theta$.
The latter is $180^\circ - n\theta = m\theta \implies 180^\circ = (n+m)\theta$, which is false.
The former is $A+B+n\theta - 180^\circ = m\theta \implies n\theta - C = m\theta \implies C = (n-m)\theta \in S$, which is false.
Thus, if $T$ has no angle in $S$, any cut results in at most one triangle having an angle in $S$. Shan-Yu can always discard that triangle, ensuring the new $T$ also has no angle in $S$. Since the game only ends if $T$ has an angle $\theta \in S$, Mulan cannot guarantee victory.

The values of $\theta$ for which Mulan can guarantee victory are $\theta = \frac{180^\circ}{N}$ for integers $N \ge 2$.
