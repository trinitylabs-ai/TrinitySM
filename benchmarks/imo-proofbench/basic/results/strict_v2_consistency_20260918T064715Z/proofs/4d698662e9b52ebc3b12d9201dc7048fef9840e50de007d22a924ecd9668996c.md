To prove that $2x+2y+1$ is a perfect square for positive integers $x, y$ satisfying $2x^2 + x = 3y^2 + y$, we proceed as follows:

### 1. Transformation to a Pell-like Equation
We begin by rearranging the given equation $2x^2 + x = 3y^2 + y$. Multiplying both sides by 8 gives:
\[ 16x^2 + 8x = 24y^2 + 8y \]
Adding 1 to both sides to complete the square on the left:
\[ 16x^2 + 8x + 1 = 24y^2 + 8y + 1 \implies (4x+1)^2 = 24y^2 + 8y + 1 \]
Let $u = 4x+1$. Then $u^2 = 24y^2 + 8y + 1$. Multiplying this equation by 3, we obtain:
\[ 3u^2 = 72y^2 + 24y + 3 = 2(36y^2 + 12y + 1) + 1 = 2(6y+1)^2 + 1 \]
Let $v = 6y+1$. The equation simplifies to:
\[ 3u^2 - 2v^2 = 1 \]
Since $x$ and $y$ are positive integers, $u$ and $v$ must be positive integers satisfying $u \equiv 1 \pmod 4$ and $v \equiv 1 \pmod 6$.

### 2. Solving the Pell-like Equation
The equation $3u^2 - 2v^2 = 1$ is a Pell-like equation. The fundamental solution is $(u_0, v_0) = (1, 1)$. The fundamental solution to the associated Pell equation $X^2 - 6Y^2 = 1$ is $(X, Y) = (5, 2)$. All positive solutions $(u_n, v_n)$ are generated by the relation:
\[ u_n\sqrt{3} + v_n\sqrt{2} = (1\sqrt{3} + 1\sqrt{2})(5 + 2\sqrt{6})^n \]
This yields the recurrence relations:
\[ u_{n+1} = 5u_n + 4v_n, \quad v_{n+1} = 6u_n + 5v_n \]
We check the conditions for $x$ and $y$ to be integers:
- Modulo 4: $u_{n+1} \equiv u_n + 0 \equiv u_n \pmod 4$. Since $u_0 = 1$, $u_n \equiv 1 \pmod 4$ for all $n \ge 0$.
- Modulo 6: $v_{n+1} \equiv 0 + 5v_n \equiv -v_n \pmod 6$. Since $v_0 = 1$, we have $v_n \equiv (-1)^n \pmod 6$.
For $y = \frac{v_n-1}{6}$ to be an integer, we must have $v_n \equiv 1 \pmod 6$, which requires $n$ to be even. Let $n = 2k$ for some integer $k \ge 0$.

### 3. Proving $2x+2y+1$ is a Square
We express $2x + 2y + 1$ in terms of $u_n$ and $v_n$:
\[ 2x + 2y + 1 = 2\left(\frac{u_n-1}{4}\right) + 2\left(\frac{v_n-1}{6}\right) + 1 = \frac{u_n-1}{2} + \frac{v_n-1}{3} + 1 = \frac{3u_n + 2v_n + 1}{6} \]
Let $\lambda = 5 + 2\sqrt{6}$ and $\bar{\lambda} = 5 - 2\sqrt{6}$. The Binet formulas for $u_n$ and $v_n$ are:
\[ u_n = \frac{3+\sqrt{6}}{6}\lambda^n + \frac{3-\sqrt{6}}{6}\bar{\lambda}^n, \quad v_n = \frac{2+\sqrt{6}}{4}\lambda^n + \frac{2-\sqrt{6}}{4}\bar{\lambda}^n \]
For $n=2k$, we calculate $3u_{2k} + 2v_{2k}$:
\[ 3u_{2k} + 2v_{2k} = \left(3\frac{3+\sqrt{6}}{6} + 2\frac{2+\sqrt{6}}{4}\right)\lambda^{2k} + \left(3\frac{3-\sqrt{6}}{6} + 2\frac{2-\sqrt{6}}{4}\right)\bar{\lambda}^{2k} \]
\[ = \left(\frac{3+\sqrt{6}}{2} + \frac{2+\sqrt{6}}{2}\right)\lambda^{2k} + \left(\frac{3-\sqrt{6}}{2} + \frac{2-\sqrt{6}}{2}\right)\bar{\lambda}^{2k} = \frac{5+2\sqrt{6}}{2}\lambda^{2k} + \frac{5-2\sqrt{6}}{2}\bar{\lambda}^{2k} \]
Since $5 \pm 2\sqrt{6} = \lambda$ and $\bar{\lambda}$ respectively:
\[ 3u_{2k} + 2v_{2k} = \frac{\lambda^{2k+1} + \bar{\lambda}^{2k+1}}{2} \]
Thus, $2x + 2y + 1 = \frac{\lambda^{2k+1} + \bar{\lambda}^{2k+1} + 2}{12}$. Now consider $u_k^2$:
\[ u_k^2 = \left(\frac{3+\sqrt{6}}{6}\lambda^k + \frac{3-\sqrt{6}}{6}\bar{\lambda}^k\right)^2 = \frac{(3+\sqrt{6})^2}{36}\lambda^{2k} + \frac{(3-\sqrt{6})^2}{36}\bar{\lambda}^{2k} + 2\frac{(3+\sqrt{6})(3-\sqrt{6})}{36}(\lambda\bar{\lambda})^k \]
Using $\lambda\bar{\lambda} = (5+2\sqrt{6})(5-2\sqrt{6}) = 1$ and $(3 \pm \sqrt{6})^2 = 15 \pm 6\sqrt{6}$:
\[ u_k^2 = \frac{15+6\sqrt{6}}{36}\lambda^{2k} + \frac{15-6\sqrt{6}}{36}\bar{\lambda}^{2k} + \frac{6}{36} = \frac{5+2\sqrt{6}}{12}\lambda^{2k} + \frac{5-2\sqrt{6}}{12}\bar{\lambda}^{2k} + \frac{1}{6} \]
\[ = \frac{\lambda^{2k+1} + \bar{\lambda}^{2k+1} + 2}{12} \]
Comparing the two expressions, we see that $2x + 2y + 1 = u_k^2$. Since $u_k$ is an integer, $2x+2y+1$ is a perfect square. \(\square\)
