We want to find the minimum number of triples $(i, j, k)$ such that $x_i + x_j + x_k \ge 0$, given $\sum x_i = 0$.

Thus, the number of triples $A$ is:
\[ A = \binom{17}{2} = \frac{17 \times 16}{2} = 136 \]
