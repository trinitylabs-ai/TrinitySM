To find all pairs of positive integers $(x, y)$ such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we first simplify the expression for $a_n$.

The sequence is defined as:
$$a_n = \gcd \left( x^n + y, \, (y-x)\left(\sum_{i=0}^{n-1} y^i x^{n-i-1} - 1\right) \right)$$
The summation is a geometric series: $\sum_{i=0}^{n-1} y^i x^{n-i-1} = \frac{y^n - x^n}{y-x}$ if $x \neq y$.
If $x = y$, the sum is $\sum_{i=0}^{n-1} x^{n-1} = n x^{n-1}$. In this case:
$$a_n = \gcd(x^n + x, (x-x)(n x^{n-1} - 1)) = \gcd(x^n + x, 0) = x^n + x$$
For $\lim_{n \to \infty} a_n$ to exist, $x^n + x$ must be eventually constant, which occurs if and only if $x = 1$. If $x = 1$, then $a_n = 1^n + 1 = 2$ for all $n$, so the limit exists. Thus, $(x, y) = (1, 1)$ is a solution.

If $x \neq y$, the expression for $a_n$ becomes:
$$a_n = \gcd(x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right)) = \gcd(x^n + y, y^n - x^n - (y-x)) = \gcd(x^n + y, y^n - x^n - y + x)$$
Using the property $\gcd(A, B) = \gcd(A, A+B)$, we have:
$$a_n = \gcd(x^n + y, (x^n + y) + (y^n - x^n - y + x)) = \gcd(x^n + y, y^n + x)$$
We analyze the behavior of $a_n = \gcd(x^n + y, y^n + x)$ for $x \neq y$.

1.  **Case $x=1, y > 1$**: $a_n = \gcd(1 + y, y^n + 1)$.
    If $n$ is odd, $y+1$ divides $y^n + 1$, so $a_n = y+1$.
    If $n$ is even, $y^n + 1 = (y^n - 1) + 2$. Since $y+1$ divides $y^n - 1$ for even $n$, $a_n = \gcd(y+1, 2)$.
    For the limit to exist, we must have $y+1 = \gcd(y+1, 2)$, which implies $y+1 \le 2$, so $y=1$, contradicting $x \neq y$.

2.  **Case $x > 1, y = 1$**: Symmetric to the above, no solutions.

3.  **Case $x > 1, y > 1, x \neq y$**:
    If $a_n$ converges to a limit $C$, then $a_n = C$ for all $n \ge N$. This implies $C$ divides both $x^n + y$ and $x^{n+1} + y$. Thus, $C$ must divide $(x^{n+1} + y) - x(x^n + y) = y(1-x)$. Similarly, $C$ must divide $x(1-y)$.
    If $C > 1$, let $p$ be a prime divisor of $C$. Then $x^n \equiv -y \pmod p$ and $x^{n+1} \equiv -y \pmod p$ for $n \ge N$. This implies $x(-y) \equiv -y \pmod p$, so $y(x-1) \equiv 0 \pmod p$. Since $p$ is prime, $p|y$ or $p|x-1$.
    - If $p|y$, then $x^n \equiv -y \equiv 0 \pmod p$, so $p|x$. If $p|x$ and $p|y$, $a_n = \gcd(x^n+y, y^n+x)$ will fluctuate based on the powers of $p$ dividing $x$ and $y$. For example, if $x=2, y=4$, $a_n = \gcd(2^n+4, 4^n+2)$, which is 6 for $n=1$, 2 for $n=2$, 6 for $n=3$, 2 for $n=4$, etc.
    - If $p|x-1$, then $x \equiv 1 \pmod p$. Thus $x^n \equiv 1 \pmod p$, so $1 \equiv -y \pmod p$. Also $y^n \equiv -x \equiv -1 \pmod p$. Since $y \equiv -1 \pmod p$, $y^n \equiv (-1)^n \pmod p$. For $(-1)^n \equiv -1 \pmod p$ to hold for all $n \ge N$, we must have $p=2$.
    If $p=2$ is the only prime divisor of $C$, then $C=2^k$. For $a_n$ to be eventually $2^k$, $x$ and $y$ must be odd. However, as shown in the examples (e.g., $x=3, y=5$), $a_n$ fluctuates significantly for odd $n$ and even $n$. Specifically, if $x, y$ are odd, $a_n$ is always even, but $a_n$ will be larger than 2 for certain $n$ and equal to 2 for others.

Thus, the only pair $(x, y)$ for which the limit exists is $(1, 1)$.

The limit of the sequence exists if and only if $x=1$ and $y=1$.
