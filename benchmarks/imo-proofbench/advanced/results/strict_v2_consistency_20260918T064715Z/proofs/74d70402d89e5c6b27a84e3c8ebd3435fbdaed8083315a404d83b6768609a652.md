To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that the equation
\[
f(x-f(xy)) = f(x)f(1-y)
\]
holds for all $x, y \in \mathbb{Z}$, we proceed as follows:

**1. Constant Solutions:**
Assume $f(x) = c$ for all $x \in \mathbb{Z}$. Substituting into the equation gives $c = c \cdot c$, so $c = c^2$, which implies $c=0$ or $c=1$.
Thus, $f(x) = 0$ and $f(x) = 1$ are both solutions.

**2. Non-Constant Solutions:**
Assume $f$ is not constant. 
If $f(0) = b \neq 0$, then substituting $x=0$ into the original equation yields $f(-f(0)) = f(0)f(1-y)$, which means $f(-b) = b f(1-y)$. Since $b \neq 0$, $f(1-y) = f(-b)/b$ for all $y$, which implies $f$ is a constant. Thus, we must have $f(0) = 0$.

Now substitute $y=1$: $f(x-f(x)) = f(x)f(0) = 0$ for all $x$.
Substitute $x=1$: $f(1-f(y)) = f(1)f(1-y)$.
Let $f(1) = c$. Then $f(1-f(y)) = cf(1-y)$.
Substitute $y=0$ into this: $f(1-f(0)) = cf(1)$, so $f(1) = c^2$, which means $c = c^2$. Since $f$ is not the zero function, $c \neq 0$, so $c = 1$. Thus, $f(1) = 1$.

**3. Testing Linear Solutions:**
Try $f(x) = ax+b$. Since $f(0)=0$, we have $b=0$. $f(1)=1$ implies $a=1$.
Check $f(x) = x$:
LHS: $f(x-f(xy)) = f(x-xy) = x-xy$.
RHS: $f(x)f(1-y) = x(1-y) = x-xy$.
So $f(x) = x$ is a solution.

**4. Testing Binary Solutions:**
Suppose $f(x) \in \{0, 1\}$ for all $x$. 
Since $f(0)=0$ and $f(1)=1$, let's test $f(x) = x \pmod 2$ (i.e., $f(x)=0$ if $x$ is even and $f(x)=1$ if $x$ is odd).
- If $x$ is even: $f(x) = 0$, so RHS is $0$. LHS is $f(\text{even}-f(xy))$. Since $xy$ is even, $f(xy)=0$, so $f(\text{even}-0) = 0$.
- If $x$ is odd: $f(x) = 1$.
  - If $y$ is even, $1-y$ is odd, so RHS is $1 \cdot 1 = 1$. LHS is $f(\text{odd}-f(\text{even})) = f(\text{odd}-0) = 1$.
  - If $y$ is odd, $1-y$ is even, so RHS is $1 \cdot 0 = 0$. LHS is $f(\text{odd}-f(\text{odd})) = f(\text{odd}-1) = f(\text{even}) = 0$.
Thus, $f(x) = x \pmod 2$ is a solution.

**5. Verification of Other Possibilities:**
We check if any other binary solutions $f: \mathbb{Z} \to \{0, 1\}$ exist. If $f(x) \in \{0, 1\}$, $f(1)=1, f(0)=0$ implies $f(x) + f(1-x) = 1$. For $x \in S_0 = \{z \mid f(z)=0\}$, $f(x-f(xy)) = 0$. If $f(xy)=1$, then $x-1 \in S_0$. If $x \in S_0 \implies xy \in S_0$ for all $y$, then $S_0$ is an ideal $n\mathbb{Z}$. Checking $n=2$ gave $f(x)=x \pmod 2$. For $n > 2$, $f(1-f(2)) = f(1-1) = f(0) = 0$, but $f(1)f(1-2) = 1 \cdot f(-1) = 1 \cdot 1 = 1$, so it fails.

The complete set of solutions is $f(x)=0$, $f(x)=1$, $f(x)=x$, and $f(x) = \begin{cases} 0 & x \text{ is even} \\ 1 & x \text{ is odd} \end{cases}$.

\(\square\)
