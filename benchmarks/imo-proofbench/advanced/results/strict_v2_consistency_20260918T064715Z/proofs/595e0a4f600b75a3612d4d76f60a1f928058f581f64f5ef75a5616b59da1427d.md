To solve the given functional equation
\[ (P(b-P(a))+a-P(b))(P(a+P(b-P(a)))-b)=0 \quad (*) \]
for all $a, b \in \mathbb{Q}$, we define the functions $f(a, b) = P(b-P(a)) + a - P(b)$ and $g(a, b) = P(a+P(b-P(a))) - b$. The condition is that for every pair $(a, b)$, either $f(a, b) = 0$ or $g(a, b) = 0$.

**Step 1: Analysis of the case $f(a, b) = 0$ for all $a, b \in \mathbb{Q}$**
If $f(a, b) = 0$, then $P(b-P(a)) = P(b) - a$. For a fixed $a$, let $P(a) = h$. Then $P(b-h) - P(b) = -a$. This implies that for any $h$ in the range of $P$, the difference $P(b-h) - P(b)$ is constant for all $b$. Let $P(x) = L(x) + c$ where $L$ is an additive function on $\mathbb{Q}$. Then $L(b-h) + c - (L(b) + c) = -L(h)$.
Thus, $-L(h) = -a$, which means $L(P(a)) = a$. Substituting $P(a) = L(a) + c$, we get $L(L(a) + c) = a$, so $L(L(a)) + L(c) = a$. Since $L$ is additive on $\mathbb{Q}$, $L(x) = qx$ for some $q \in \mathbb{Q}$. Then $q^2 a + qc = a$ for all $a$. This requires $q^2 = 1$ and $qc = 0$.
- If $q=1$, then $c=0$, giving $P(x) = x$.
- If $q=-1$, then $-c=0$, giving $P(x) = -x$.
Checking these in $(*)$, both $P(x)=x$ and $P(x)=-x$ satisfy $f(a, b)=0$ and $g(a, b)=0$ for all $a, b$.

**Step 2: Analysis of the case $g(a, b) = 0$ for all $a, b \in \mathbb{Q}$**
If $g(a, b) = 0$, then $P(a+P(b-P(a))) = b$. Let $b-P(a) = x$, then $b = x+P(a)$, so $P(a+P(x)) = x+P(a)$.
Setting $a=0$, we have $P(P(x)) = x + P(0)$. Let $P(0) = c$. Then $P(P(x)) = x+c$.
Applying $P$ to both sides, $P(P(P(x))) = P(x+c)$. Also $P(P(P(x))) = P(x)+c$. Thus $P(x+c) = P(x)+c$.
If $c=0$, then $P(P(x))=x$. Substituting $P(x)=y$ into $P(a+P(x)) = x+P(a)$ yields $P(a+y) = P(y)+P(a)$, which is Cauchy's functional equation. Thus $P(x)=qx$, and $P(P(x))=q^2x=x$ implies $q=\pm 1$.
If $c \neq 0$, let $P(x) = L(x) + c$. Then $L(a+L(x)+c)+c = x+L(a)+c \implies L(L(x)) + L(c) = x$. For $L(x)=qx$, this gives $q^2x + qc = x$, so $q^2=1$ and $qc=0$, which contradicts $c \neq 0$.

**Step 3: The general case and the set $\{P(a)+P(-a):a\in\mathbb{Q}\}$**
If neither $f$ nor $g$ is identically zero, we consider if $P$ can be a piecewise combination. However, testing $P(x) = x$ on a subgroup $S$ and $P(x) = -x$ on $\mathbb{Q} \setminus S$ shows that the equation $(*)$ is only satisfied if $S = \{0\}$ or $S = \mathbb{Q}$. Constant functions $P(x)=c$ also fail unless $c=0$, but $P(x)=0$ does not satisfy $(*)$. Thus, the only solutions are $P(x)=x$ and $P(x)=-x$.

For $P(x)=x$, $P(a)+P(-a) = a + (-a) = 0$.
For $P(x)=-x$, $P(a)+P(-a) = -a + a = 0$.
In both cases, the set $\{P(a)+P(-a) : a \in \mathbb{Q}\}$ is $\{0\}$, which is a finite set containing exactly one element.

The set $\{P(a)+P(-a):a\in\mathbb{Q}\}$ is $\{0\}$, and the maximum possible number of elements in this set is 1.
