To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that the equation
\[ f(x - f(xy)) = f(x)f(1-y) \quad (*) \]
holds for all $x, y \in \mathbb{Z}$, we proceed as follows:

**1. Constant Solutions**
If $f(x) = c$ for all $x \in \mathbb{Z}$, then $(*)$ becomes $c = c^2$, which implies $c = 0$ or $c = 1$. Both $f(x) = 0$ and $f(x) = 1$ are solutions.

**2. Analysis of $f(0)$ and $f(1)$**
Assume $f$ is not constant. Setting $x = 0$ in $(*)$ gives $f(-f(0)) = f(0)f(1-y)$ for all $y \in \mathbb{Z}$. If $f(0) = c \neq 0$, then $f(1-y) = f(-c)/c$ for all $y$, implying $f$ is constant, which we assumed it is not. Thus, $f(0) = 0$.
Setting $y = 0$ in $(*)$ and using $f(0) = 0$, we have $f(x - f(0)) = f(x)f(1)$, which simplifies to $f(x) = f(x)f(1)$. Since $f$ is not identically zero, there exists $x$ such that $f(x) \neq 0$, so $f(1) = 1$.

**3. Properties of the Zero Set $S$**
Let $S = \{x \in \mathbb{Z} : f(x) = 0\}$. We have $0 \in S$ and $1 \notin S$.
Setting $y = 1$ in $(*)$ gives $f(x - f(x)) = f(x)f(0) = 0$, so $x - f(x) \in S$ for all $x \in \mathbb{Z}$.
Setting $x = 1$ in $(*)$ gives $f(1 - f(y)) = f(1)f(1-y) = f(1-y)$.
From this, if $y \in S$, then $f(1-y) = f(1 - f(y)) = f(1) = 1$, so $1-y \notin S$.
Conversely, if $f(y) = 1$, then $f(1-y) = f(1 - f(y)) = f(0) = 0$, so $1-y \in S$.

**4. Case $S = \{0\}$**
If $S = \{0\}$, then $x - f(x) \in S$ implies $x - f(x) = 0$ for all $x$, so $f(x) = x$. Checking this in $(*)$: $f(x - xy) = x - xy$ and $f(x)f(1-y) = x(1-y) = x - xy$. This is a solution.

**5. Case $S \neq \{0\}$**
Let $z \in S \setminus \{0\}$. Setting $y = z$ in $(*)$ gives $f(x - f(xz)) = f(x)f(1-z)$.
Since $z \in S$, we have $f(1-z) = 1$ from the property $y \in S \implies f(1-y) = 1$. Thus, $f(x - f(xz)) = f(x)$ for all $x \in \mathbb{Z}$.
If there exists $x$ such that $f(xz) = a \neq 0$, then $f(x-a) = f(x)$. This implies $f$ is periodic with period $a$. Any periodic function on $\mathbb{Z}$ takes only finitely many values. Let $R$ be the range of $f$. Since $f(x - f(xy)) = f(x)f(1-y)$, the product of any two values in $R$ must also be in $R$. If $R$ contains any value $v$ with $|v| > 1$, then $v^n \in R$ for all $n \in \mathbb{N}$, which contradicts the fact that $R$ is finite. Thus, $R \subseteq \{-1, 0, 1\}$.
If $f(xz) = 0$ for all $x \in \mathbb{Z}$ and all $z \in S$, then $S$ is an ideal in $\mathbb{Z}$, so $S = n\mathbb{Z}$ for some $n \ge 2$. Then $x \notin S \implies x - f(x) \in S \implies f(x) \equiv x \pmod n$. If $f$ is not $f(x)=x$, the same range restriction $R \subseteq \{-1, 0, 1\}$ applies because if $f$ is not $f(x)=x$, then $f$ must be bounded to satisfy $(*)$ for all $x, y$.

If $R \subseteq \{0, 1\}$, then for any $x \notin S$, $f(x) = 1$. Then $x - f(x) = x - 1 \in S$.
Also, $x \in S \implies 1-x \notin S \implies (1-x)-1 = -x \in S$.
Since $0 \in S$, we have $0, -2, -4, \dots \in S$ and $2, 4, 6, \dots \in S$.
Since $1 \notin S$, we have $1, -1, 3, -3, \dots \notin S$.
This implies $S = 2\mathbb{Z}$, so $f(x) = 0$ if $x$ is even and $f(x) = 1$ if $x$ is odd.
Checking this:
- If $x$ is even, $f(x-f(xy)) = f(\text{even} - 0) = 0$ and $f(x)f(1-y) = 0 \cdot f(1-y) = 0$.
- If $x$ is odd and $y$ is even, $f(x-f(xy)) = f(\text{odd} - 0) = 1$ and $f(x)f(1-y) = 1 \cdot f(\text{odd}) = 1 \cdot 1 = 1$.
- If $x$ is odd and $y$ is odd, $f(x-f(xy)) = f(\text{odd} - 1) = f(\text{even}) = 0$ and $f(x)f(1-y) = 1 \cdot f(\text{even}) = 1 \cdot 0 = 0$.
This is a solution.

If $R$ contains $-1$, then $f(y) = -1 \implies f(1-y) = f(1 - f(y)) = f(2)$.
If $f(2) = 0$, then $f(y) = -1 \implies f(1-y) = 0 \implies f(y) = 1$, a contradiction.
If $f(2) = 1$, then $f(y) = -1 \implies f(1-y) = 1 \implies f(y) = 0$, a contradiction.
Thus, we must have $f(2) = -1$.
Now consider $x=2, y=1$ in $(*)$: $f(2 - f(2)) = f(2)f(0) = (-1)(0) = 0$.
Since $f(2) = -1$, the LHS is $f(2 - (-1)) = f(3)$.
Thus $f(3) = 0$. But $3 \in S \implies f(1-3) = f(-2) = 1$.
Since $f(2) = -1$, $f(-2) = f(1 - (-1)) = f(2) = -1$ (as $f(y)=-1 \implies f(1-y)=f(2)$).
This gives $1 = -1$, a contradiction.
Thus, $f$ cannot take the value $-1$.

**Conclusion**
The solutions are $f(x) = 0$, $f(x) = 1$, $f(x) = x$, and $f(x) = \begin{cases} 0 & x \text{ is even} \\ 1 & x \text{ is odd} \end{cases}$.
