To find all pairs of positive integers $(x, y)$ such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we first simplify the expression for $a_n$. The sequence is defined as
\[ a_n = \gcd \left( x^n + y, (y-x)\left(\sum_{i=0}^{n-1} y^i x^{n-i-1} - 1\right) \right). \]

**Case 1: $x = y$.**
If $x = y$, the second term in the $\gcd$ is 0, so
\[ a_n = \gcd(x^n + x, 0) = x^n + x. \]
The limit $\lim_{n \to \infty} (x^n + x)$ exists if and only if the sequence is eventually constant. This occurs if and only if $x = 1$. For $(x, y) = (1, 1)$, we have $a_n = 1^n + 1 = 2$ for all $n \in \mathbb{N}$, so the limit is 2.

**Case 2: $x \neq y$.**
The sum $\sum_{i=0}^{n-1} y^i x^{n-i-1}$ is a geometric series with sum $\frac{y^n - x^n}{y-x}$. Thus,
\[ a_n = \gcd \left( x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) \right) = \gcd(x^n + y, y^n - x^n - (y-x)). \]
Using the property $\gcd(A, B) = \gcd(A, A+B)$, we have
\[ a_n = \gcd(x^n + y, (x^n + y) + (y^n - x^n - y + x)) = \gcd(x^n + y, y^n + x). \]
Suppose the limit $\lim_{n \to \infty} a_n$ exists. Since $a_n$ are integers, the sequence must be eventually constant, say $a_n = L$ for all $n \ge N$. If $L > 1$, let $p$ be a prime divisor of $L$. Then for all $n \ge N$,
\[ x^n \equiv -y \pmod p \quad \text{and} \quad y^n \equiv -x \pmod p. \]
From $x^N \equiv -y \pmod p$ and $x^{N+1} \equiv -y \pmod p$, we obtain $x^{N+1} - x^N \equiv 0 \pmod p$, which implies $x^N(x-1) \equiv 0 \pmod p$.
- If $p \mid x$, then $0 \equiv -y \pmod p$, so $p \mid y$.
- If $p \nmid x$, then $x \equiv 1 \pmod p$. Then $x^N \equiv 1 \equiv -y \pmod p$, so $y \equiv -1 \pmod p$.
Similarly, from $y^n \equiv -x \pmod p$:
- If $p \mid y$, then $p \mid x$.
- If $p \nmid y$, then $y \equiv 1 \pmod p$. Then $y^N \equiv 1 \equiv -x \pmod p$, so $x \equiv -1 \pmod p$.

If $p$ does not divide $x$ and $y$, we must have $x \equiv 1 \pmod p$ and $y \equiv -1 \pmod p$, and simultaneously $y \equiv 1 \pmod p$ and $x \equiv -1 \pmod p$. This implies $1 \equiv -1 \pmod p$, so $p = 2$. Thus, any prime divisor $p$ of $L$ must either divide both $x$ and $y$ or be $p = 2$.

However, if $x \neq y$, the sequence $a_n = \gcd(x^n + y, y^n + x)$ is generally not constant. Note that $a_1 = x+y$. If $a_n$ were constant, then $L = x+y$. For $n=2$, we would need $x+y \mid x^2+y$ and $x+y \mid y^2+x$.
The condition $x+y \mid x^2+y$ implies $x+y \mid x^2+y - (x-y)(x+y) = x^2+y - (x^2-y^2) = y^2+y$.
Since $y^2+y = y(x+y) - y(x-1)$, this requires $x+y \mid y(x-1)$.
If $x=1, y=2$, then $a_1 = 3$ and $a_2 = \gcd(3, 5) = 1$.
If $x=2, y=1$, then $a_1 = 3$ and $a_2 = \gcd(5, 3) = 1$.
If $x > 1, y > 1$ and $x \neq y$, let $p$ be a prime divisor of $x+y$. If $p \nmid x$, then $x \equiv -y \pmod p$ and $y \equiv -x \pmod p$, so $n=1$ is a solution to $x^n \equiv -y \pmod p$ and $y^n \equiv -x \pmod p$. Because these powers are periodic modulo $p$, $a_n$ will be divisible by $p$ for infinitely many $n$. If $a_n$ were eventually constant $L$, then $L$ would have to be divisible by every such $p$ for every $n \ge N$. But $a_n$ cannot be constant if $x \neq y$ because $x^n+y$ grows at a different rate than $y^n+x$, and the $\gcd$ will fluctuate.

Thus, the only pair $(x, y)$ of positive integers for which the limit exists is $(1, 1)$.

\(\square\)
