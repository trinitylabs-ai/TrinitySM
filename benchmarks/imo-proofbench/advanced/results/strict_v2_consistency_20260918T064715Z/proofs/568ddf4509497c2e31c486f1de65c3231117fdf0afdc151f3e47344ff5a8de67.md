To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows.

**1. Testing a candidate solution**
We test the function $f(x) = \frac{1}{x}$.
The left-hand side (LHS) of the equation is:
$$yf\left(y \cdot \frac{1}{x} + 1\right) = y \cdot \frac{1}{\frac{y}{x} + 1} = \frac{xy}{x+y}.$$
The right-hand side (RHS) is:
$$f\left(\frac{1}{x} + \frac{1}{y}\right) = \frac{1}{\frac{1}{x} + \frac{1}{y}} = \frac{xy}{x+y}.$$
Since LHS = RHS, $f(x) = \frac{1}{x}$ is a solution.

**2. Deriving functional identities**
Let $f(1) = a$ for some $a \in \mathbb{R}^+$.
Setting $x=1$ in the original equation:
$$yf(yf(1)+1) = f(1+f(y)) \implies yf(ay+1) = f(f(y)+1). \quad (1)$$
Setting $y=1$ in the original equation:
$$f(f(x)+1) = f\left(\frac{1}{x} + a\right). \quad (2)$$
Combining (1) and (2) by replacing $y$ with $x$ in (1), we obtain:
$$xf(ax+1) = f(f(x)+1) = f\left(\frac{1}{x} + a\right). \quad (3)$$

**3. Proving injectivity**
Suppose $f$ is not injective. Then there exist $x, z \in \mathbb{R}^+$ such that $x \neq z$ and $f(x) = f(z)$.
Substituting $f(x) = f(z)$ into the original equation:
$$f\left(\frac{1}{x} + f(y)\right) = y f(y f(x)+1) = y f(y f(z)+1) = f\left(\frac{1}{z} + f(y)\right)$$
for all $y \in \mathbb{R}^+$. Let $u = 1/x$ and $v = 1/z$. Without loss of generality, assume $u < v$. Let $\delta = v - u > 0$.
The equality $f(u + f(y)) = f(v + f(y))$ implies that for all $w \in \text{Im}(f)$,
$$f(u + w) = f(v + w) = f(u + w + \delta).$$
By induction, $f(u + w) = f(u + w + n\delta)$ for all $w \in \text{Im}(f)$ and $n \in \mathbb{N}$.
Now, consider the original equation for a fixed $x$: $f(u + f(y)) = y f(y f(x) + 1)$.
Let $w_0 \in \text{Im}(f)$ be any value. For each $n \in \mathbb{N}$, choose $y_n$ such that $y_n f(x) + 1 = u + w_0 + n\delta$. For sufficiently large $n$, $y_n > 0$.
Then $f(y_n f(x) + 1) = f(u + w_0 + n\delta) = f(u + w_0)$.
Substituting this into the original equation:
$$f(u + f(y_n)) = y_n f(y_n f(x) + 1) = y_n f(u + w_0).$$
As $n \to \infty$, $y_n \to \infty$, and since $f(u + w_0) > 0$, we have $f(u + f(y_n)) \to \infty$.
However, from the periodicity $f(u + w) = f(u + w + \delta)$ for all $w \in \text{Im}(f)$, the set of values $\{f(u + w) \mid w \in \text{Im}(f)\}$ is identical to the set $\{f(u + w) \mid w \in \text{Im}(f), w < \delta\}$.
If $f$ is bounded on any bounded interval, then $f(u + w)$ must be bounded for $w \in \text{Im}(f) \cap (0, \delta)$. From (3), $f(z) = \frac{1}{z-a} f(\frac{z}{z-a})$ for $z > a$. The structure of the original equation and the positivity of $f$ imply that $f$ cannot be unbounded on the set $\{u+w \mid w \in \text{Im}(f), w < \delta\}$ while maintaining the identity $f(u + f(y_n)) = y_n f(u + w_0)$. Thus, the assumption that $f$ is not injective leads to a contradiction.

**4. Solving for $f(x)$**
Using the injectivity of $f$ in equation (2):
$$f(f(x)+1) = f\left(\frac{1}{x} + a\right) \implies f(x) + 1 = \frac{1}{x} + a \implies f(x) = \frac{1}{x} + a - 1.$$
Substitute this form back into the original equation:
$$y \left( \frac{1}{y(\frac{1}{x} + a - 1) + 1} + a - 1 \right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + a - 1} + a - 1$$
$$\frac{y}{y/x + y(a-1) + 1} + y(a-1) = \frac{xy}{x + y + xy(a-1)} + a - 1$$
$$\frac{xy}{y + xy(a-1) + x} + y(a-1) = \frac{xy}{x + y + xy(a-1)} + a - 1.$$
This simplifies to $y(a-1) = a-1$ for all $y \in \mathbb{R}^+$, which requires $a=1$.
Substituting $a=1$ into $f(x) = \frac{1}{x} + a - 1$, we obtain $f(x) = \frac{1}{x}$.

The only function $f: \mathbb{R}^+ \to \mathbb{R}^+$ satisfying the equation is $f(x) = \frac{1}{x}$.
