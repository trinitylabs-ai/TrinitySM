To prove that there exist two real-coefficient polynomials $P(x)$ and $Q(x)$ satisfying the given condition, we construct an explicit example.

Consider polynomials of the form $P(x) = (x+a)^n + k$ and $Q(x) = x^2 + bx + c$. We seek constants $a, b, c, k \in \mathbb{R}$ and an integer $n \ge 2024$ such that for all $x \in \mathbb{R}$:
\[ P(Q(x)-x-1) = Q(P(x)) \]

First, we compute the left-hand side (LHS) of the equation:
\[ Q(x)-x-1 = x^2 + bx + c - x - 1 = x^2 + (b-1)x + (c-1) \]
Then,
\[ P(Q(x)-x-1) = (x^2 + (b-1)x + (c-1) + a)^n + k \]
To simplify this expression, we require the quadratic inside the parentheses to be a perfect square of the form $(x+a)^2 = x^2 + 2ax + a^2$. Comparing coefficients:
1. $b-1 = 2a \implies b = 2a + 1$
2. $c-1+a = a^2 \implies c = a^2 - a + 1$

With these conditions, the LHS becomes:
\[ P(Q(x)-x-1) = ((x+a)^2)^n + k = (x+a)^{2n} + k \]

Next, we compute the right-hand side (RHS):
\[ Q(P(x)) = P(x)^2 + bP(x) + c \]
Completing the square for $Q(y) = y^2 + by + c$, we have:
\[ Q(y) = \left(y + \frac{b}{2}\right)^2 + c - \frac{b^2}{4} \]
Substituting $y = P(x) = (x+a)^n + k$:
\[ Q(P(x)) = \left((x+a)^n + k + \frac{b}{2}\right)^2 + c - \frac{b^2}{4} \]
To make the RHS match the LHS, the term inside the square must be simply $(x+a)^n$. Thus, we require:
3. $k + \frac{b}{2} = 0 \implies k = -\frac{b}{2}$

Under this condition, the RHS simplifies to:
\[ Q(P(x)) = ((x+a)^n)^2 + c - \frac{b^2}{4} = (x+a)^{2n} + c - \frac{b^2}{4} \]
Equating the constant terms of the LHS and RHS:
4. $k = c - \frac{b^2}{4}$

We now solve for $a, b, c, k$. From (1) and (3), $b = 2a+1$ and $k = -a - \frac{1}{2}$. Substitute these and (2) into (4):
\[ -a - \frac{1}{2} = (a^2 - a + 1) - \frac{(2a+1)^2}{4} \]
Multiplying by 4 to clear denominators:
\[ -4a - 2 = 4a^2 - 4a + 4 - (4a^2 + 4a + 1) \]
\[ -4a - 2 = -4a + 3 \]
This leads to $-2 = 3$, a contradiction. This implies our initial assumption that $Q(x)$ is a monic quadratic may need adjustment. Let's re-evaluate the constants using $b = \frac{7}{2}$.
If $b = \frac{7}{2}$, then $a = \frac{b-1}{2} = \frac{5}{4}$.
From (2), $c = a^2 - a + 1 = \frac{25}{16} - \frac{5}{4} + 1 = \frac{25-20+16}{16} = \frac{21}{16}$.
From (3), $k = -\frac{b}{2} = -\frac{7}{4}$.
Check condition (4): $c - \frac{b^2}{4} = \frac{21}{16} - \frac{49/4}{4} = \frac{21-49}{16} = -\frac{28}{16} = -\frac{7}{4}$.
Since $k = -\frac{7}{4}$, condition (4) is satisfied.

Thus, we define:
\[ P(x) = \left(x + \frac{5}{4}\right)^n - \frac{7}{4} \quad \text{and} \quad Q(x) = x^2 + \frac{7}{2}x + \frac{21}{16} \]
For any $n \ge 2024$, $\deg(P) = n \ge 2024$ and $\deg(Q) = 2 \ge 2$. Both have real coefficients.
Verification:
$Q(x)-x-1 = x^2 + \frac{5}{2}x + \frac{5}{16} = (x + \frac{5}{4})^2 - \frac{25}{16} + \frac{5}{16} = (x + \frac{5}{4})^2 - \frac{5}{4}$.
$P(Q(x)-x-1) = ((x + \frac{5}{4})^2 - \frac{5}{4} + \frac{5}{4})^n - \frac{7}{4} = (x + \frac{5}{4})^{2n} - \frac{7}{4}$.
$Q(P(x)) = (P(x) + \frac{7}{4})^2 + \frac{21}{16} - \frac{49}{16} = ((x + \frac{5}{4})^n - \frac{7}{4} + \frac{7}{4})^2 - \frac{7}{4} = (x + \frac{5}{4})^{2n} - \frac{7}{4}$.
The condition $P(Q(x)-x-1) = Q(P(x))$ is satisfied for all $x \in \mathbb{R}$.

\(\square\)
