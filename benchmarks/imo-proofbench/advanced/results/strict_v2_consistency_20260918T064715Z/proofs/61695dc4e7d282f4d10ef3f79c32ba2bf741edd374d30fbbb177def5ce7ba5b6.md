To solve the given functional equation
\[ (P(b-P(a))+a-P(b))(P(a+P(b-P(a)))-b)=0 \]
for all $a, b \in \mathbb{Q}$, let $X(a, b) = P(b-P(a)) + a - P(b)$ and $Y(a, b) = P(a+P(b-P(a))) - b$. The condition is $X(a, b) Y(a, b) = 0$ for all $a, b \in \mathbb{Q}$.

First, we test linear functions of the form $P(x) = mx + c$.
Calculating $P(b-P(a))$:
\[ P(b-P(a)) = m(b - (ma+c)) + c = mb - m^2a - mc + c. \]
Then,
\[ X(a, b) = (mb - m^2a - mc + c) + a - (mb+c) = (1-m^2)a - mc. \]
And
\[ Y(a, b) = P(a + mb - m^2a - mc + c) - b = m(a + mb - m^2a - mc + c) + c - b \]
\[ Y(a, b) = (m-m^3)a + (m^2-1)b - m^2c + mc + c. \]
For $X(a, b)Y(a, b) = 0$ to hold for all $a, b$, either $X \equiv 0$ or $Y \equiv 0$ (since they are linear in $a$ and $b$).
If $X \equiv 0$, then $1-m^2 = 0$ and $mc = 0$, which implies $m = \pm 1$ and $c = 0$.
If $Y \equiv 0$, then $m-m^3 = 0$, $m^2-1 = 0$, and $-m^2c + mc + c = 0$. This also implies $m = \pm 1$ and $c = 0$.
Thus, the only linear solutions are $P(x) = x$ and $P(x) = -x$.

Now we consider if any other solutions exist. Suppose $X(a, b) = 0$ for all $a, b$. Then $P(b-P(a)) = P(b) - a$.
Let $P(0) = c$. For $a=0$, $P(b-c) = P(b)$, so $P$ is periodic with period $c$.
Substituting $b=P(a)$, we get $P(0) = P(P(a)) - a$, so $P(P(a)) = a+c$.
If $c \neq 0$, the periodicity $P(b-c) = P(b)$ contradicts the fact that for a fixed $b$, $P(b-P(a)) - P(b) = -a$ must take all rational values as $a$ varies. Thus $c=0$.
With $P(0)=0$ and $P(P(a))=a$, we have $P(b-P(a)) = P(b) - a$.
Setting $b=0$ gives $P(-P(a)) = -a$. Since $P(P(a))=a$, let $P(a)=x$, then $P(-x) = -P(x)$, so $P$ is odd.
Then $P(b-P(a)) = P(b) + P(-a)$. Let $P(a)=x, P(b)=y$. Then $P(y-x) = y-P(x)$.
Setting $y=x$ gives $P(0) = x-P(x)$, so $P(x)=x$.
Setting $y=0$ gives $P(-x) = -P(x)$, which is already known.
If we check $P(x)=-x$, $P(b-P(a)) = P(b+a) = -b-a$ and $P(b)-a = -b-a$, so $P(x)=-x$ also satisfies $X \equiv 0$.

Similarly, if $Y \equiv 0$, we have $P(a+P(b-P(a))) = b$. Testing $P(x)=x$ and $P(x)=-x$ shows both satisfy this. Constant functions $P(x)=c$ fail as $X=a$ and $Y=c-b$, so $XY=a(c-b) \neq 0$.

For both $P(x)=x$ and $P(x)=-x$, we have:
\[ P(a) + P(-a) = a + (-a) = 0 \quad \text{or} \quad P(a) + P(-a) = -a + a = 0. \]
In either case, the set $\{P(a) + P(-a) : a \in \mathbb{Q}\} = \{0\}$.
This set is finite and contains exactly 1 element.

The maximum possible number of elements in the set is 1. \(\square\)
