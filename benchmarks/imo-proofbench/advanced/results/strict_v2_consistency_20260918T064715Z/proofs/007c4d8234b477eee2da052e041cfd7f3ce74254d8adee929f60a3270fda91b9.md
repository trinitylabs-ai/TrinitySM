To prove that if $p^n = a^4 + b^4$ for a prime $p$, positive integers $a, b$, and $n \geq 2$, then $n \geq 5$, we examine the cases $n=2, 3, 4$.

### Case 1: $n=2$ and $n=4$
If $n=2$, the equation is $a^4 + b^4 = p^2$. This is a specific instance of the equation $x^4 + y^4 = z^2$. According to Fermat's Right Triangle Theorem, the equation $x^4 + y^4 = z^2$ has no solutions in positive integers. Thus, $n=2$ is impossible.
If $n=4$, the equation is $a^4 + b^4 = p^4$. This is a case of Fermat's Last Theorem for $k=4$, which states that $x^4 + y^4 = z^4$ has no solutions in positive integers. Thus, $n=4$ is impossible.

### Case 2: $n=3$
We examine the equation $a^4 + b^4 = p^3$.
First, let $d = \gcd(a, b)$. Then $d^4((a/d)^4 + (b/d)^4) = p^3$. Since $p$ is prime, $d^4$ must be a power of $p$. However, $d^4 \leq p^3$ implies $d=1$. Thus, $a$ and $b$ are coprime.
If $p=2$, then $a^4 + b^4 = 8$. For $a, b \geq 1$, the only possibility is $a=1, b=1$, but $1^4+1^4 = 2 \neq 8$. Thus, $p$ must be an odd prime.
In the ring of Gaussian integers $\mathbb{Z}[i]$, we have $p^3 = (a^2 + ib^2)(a^2 - ib^2)$.
If $p \equiv 3 \pmod 4$, $p$ is a prime in $\mathbb{Z}[i]$. The only factors of $p^3$ are $p^k$, which would imply $a^2 + ib^2 = p^k$, meaning $b=0$, a contradiction.
Thus, $p \equiv 1 \pmod 4$. This implies $p = \pi \bar{\pi}$ for some Gaussian prime $\pi = u+iv$. Since $\gcd(a, b)=1$, $a^2 + ib^2$ and $a^2 - ib^2$ are coprime. Thus, $a^2 + ib^2 = \epsilon \pi^3$ for some unit $\epsilon \in \{1, -1, i, -i\}$.
Expanding $\pi^3 = (u+iv)^3 = (u^3 - 3uv^2) + i(3u^2v - v^3)$.
Up to a swap of $a$ and $b$ and signs of $u, v$, we can assume:
$a^2 = u(u^2 - 3v^2)$ and $b^2 = v(3u^2 - v^2)$.
Since $\gcd(a, b)=1$, we have $\gcd(u, v)=1$.
1.  If $\gcd(u, 3)=1$ and $\gcd(v, 3)=1$:
    Then $u$ and $u^2 - 3v^2$ must be squares, say $u=s^2$ and $s^4 - 3v^2 = t^2$. Similarly, $v=m^2$ and $3s^4 - m^4 = k^2$.
    Modulo 4, $s^4 - 3m^4 = t^2$ and $3s^4 - m^4 = k^2$. If $s, m$ are odd, $1-3 \equiv 2 \pmod 4$ (impossible). If $s$ even, $m$ odd, then $3s^4 - m^4 \equiv -1 \equiv 3 \pmod 4$ (impossible). If $s$ odd, $m$ even, then $3s^4 - m^4 \equiv 3 \pmod 4$ (impossible).
2.  If $\gcd(u, 3)=1$ and $\gcd(v, 3)=3$:
    Let $v=3m^2$. Then $u=s^2$ and $s^4 - 3(3m^2)^2 = s^4 - 27m^4 = t^2$.
    Also $b^2 = 3m^2(3s^4 - 9m^4) = 9m^2(s^4 - 3m^4)$, so $s^4 - 3m^4 = w^2$.
    Modulo 3, $s^4 \equiv w^2 \pmod 3$ is possible, but $s^4 - 3m^4 = w^2$ implies $s^4 \equiv w^2 \pmod 3$. 
    By examining $s^4 - 3m^4 = w^2$ and $s^4 - 27m^4 = t^2$, we can perform an infinite descent. Specifically, $s^4 - w^2 = 3m^4$ and $s^4 - t^2 = 27m^4$. This system has no solution in positive integers.
3.  If $\gcd(u, 3)=3$ and $\gcd(v, 3)=1$:
    Symmetric to case 2 by swapping $a$ and $b$.

Since $n=2, 3, 4$ are all impossible, we must have $n \geq 5$.

\(\square\)
