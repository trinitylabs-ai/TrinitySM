For an integer $n \geq 2$, let $a_{1} \leq a_{2} \leq \cdots \leq a_{n}$ be positive real numbers satisfying $a_{1} a_{2} \cdots a_{n}=1$. We wish to prove that
\[ \sum_{k=1}^{n} \frac{1}{b_{k}} \geq \frac{1}{2}-\frac{1}{2^{n+1}} \]
where $b_{k}=2^{k}\left(1+a_{k}^{2^{k}}\right)$. Let $S = \sum_{k=1}^{n} \frac{1}{b_{k}}$. We observe that
\[ S - \left( \frac{1}{2} - \frac{1}{2^{n+1}} \right) = \sum_{k=1}^{n} \frac{1}{2^{k}} \left( \frac{1}{1+a_{k}^{2^{k}}} - \frac{1}{2} \right) = \sum_{k=1}^{n} \frac{1}{2^{k}} \frac{1-a_{k}^{2^{k}}}{2(1+a_{k}^{2^{k}})} \]
Using the identity $\frac{1-x}{2(1+x)} = -\frac{1}{2} \tanh\left(\frac{1}{2} \ln x\right)$, and letting $w_k = \ln a_k$, we have
\[ S - \left( \frac{1}{2} - \frac{1}{2^{n+1}} \right) = \sum_{k=1}^{n} \frac{1}{2^{k}} \left( -\frac{1}{2} \tanh(2^{k-1} w_k) \right) = -\frac{1}{2} \sum_{k=1}^{n} \frac{1}{2^{k}} \tanh(2^{k-1} w_k) \]
The original inequality is thus equivalent to proving that $f(w_1, \dots, w_n) = \sum_{k=1}^{n} \frac{1}{2^{k}} \tanh(2^{k-1} w_k) \leq 0$ subject to $w_1 \leq w_2 \leq \cdots \leq w_n$ and $\sum_{k=1}^{n} w_k = 0$.

Let $h_k(x) = \frac{1}{2^k} \tanh(2^{k-1} x)$. The second derivative is $h_k''(x) = -2^{k-1} \text{sech}^2(2^{k-1} x) \tanh(2^{k-1} x)$. Thus, $h_k$ is convex on $(-\infty, 0]$ and concave on $[0, \infty)$.
For any $w$ in the domain, let $m$ be the index such that $w_1 \leq \dots \leq w_m \leq 0 \leq w_{m+1} \leq \dots \leq w_n$. Since $\sum w_i = 0$ and $n \geq 2$, we must have $1 \leq m < n$. Let $z = \sum_{i=m+1}^n w_i \geq 0$, so $\sum_{i=1}^m w_i = -z$.

First, we bound the concave part $\sum_{k=m+1}^n h_k(w_k)$. Since each $h_k$ is concave on $[0, \infty)$, by Jensen's Inequality:
\[ \sum_{k=m+1}^n \frac{1}{2^k} \tanh(2^{k-1} w_k) \leq \left(\sum_{k=m+1}^n \frac{1}{2^k}\right) \tanh\left(\frac{\sum_{k=m+1}^n \frac{1}{2^k} 2^{k-1} w_k}{\sum_{k=m+1}^n \frac{1}{2^k}}\right) \]
Let $A = \sum_{k=m+1}^n \frac{1}{2^k} = \frac{1}{2^m} - \frac{1}{2^n}$. The numerator of the argument is $\sum_{k=m+1}^n \frac{1}{2} w_k = \frac{z}{2}$. Thus,
\[ \sum_{k=m+1}^n h_k(w_k) \leq A \tanh\left(\frac{z}{2A}\right) \]
Next, we bound the convex part $\sum_{k=1}^m h_k(w_k)$ subject to $w_1 \leq \dots \leq w_m \leq 0$ and $\sum_{i=1}^m w_i = -z$. Since each $h_k$ is convex on $(-\infty, 0]$, the maximum occurs at an extreme point of the constraint set. These extreme points are of the form $w_1 = \dots = w_j = -z/j$ and $w_{j+1} = \dots = w_m = 0$ for some $j \in \{1, \dots, m\}$. Let $T_j(u) = \sum_{k=1}^j \frac{1}{2^k} \tanh(2^{k-1} u)$. Then
\[ \sum_{k=1}^m h_k(w_k) \leq \max_{1 \leq j \leq m} T_j(-z/j) = \max_{1 \leq j \leq m} (-T_j(z/j)) \]
To prove $f(w_1, \dots, w_n) \leq 0$, it suffices to show that $A \tanh(z/2A) \leq T_j(z/j)$ for all $1 \leq j \leq m$ and $z \geq 0$.
Let $h(z) = T_j(z/j) - A \tanh(z/2A)$. Then $h(0) = 0$ and
\[ h'(z) = \frac{1}{2j} \sum_{k=1}^j \text{sech}^2(2^{k-1} \frac{z}{j}) - \frac{1}{2} \text{sech}^2(\frac{z}{2A}) \]
Since $A = \frac{1}{2^m} - \frac{1}{2^n} < \frac{1}{2^m}$, we have $\frac{z}{2A} > 2^{m-1} z$.
For all $k \in \{1, \dots, j\}$, we have $2^{k-1} \frac{z}{j} \leq 2^{j-1} \frac{z}{j} \leq 2^{j-1} z \leq 2^{m-1} z < \frac{z}{2A}$.
Because $\text{sech}^2 x$ is strictly decreasing on $[0, \infty)$, it follows that $\text{sech}^2(2^{k-1} \frac{z}{j}) > \text{sech}^2(\frac{z}{2A})$ for all $k$. Thus,
\[ h'(z) \geq \frac{1}{2j} \sum_{k=1}^j \text{sech}^2(\frac{z}{2A}) - \frac{1}{2} \text{sech}^2(\frac{z}{2A}) = 0 \]
Since $h(0) = 0$ and $h'(z) \geq 0$ for $z \geq 0$, we have $h(z) \geq 0$, meaning $T_j(z/j) \geq A \tanh(z/2A)$.
Consequently, $f(w_1, \dots, w_n) \leq -T_j(z/j) + A \tanh(z/2A) \leq 0$. This proves the inequality.
