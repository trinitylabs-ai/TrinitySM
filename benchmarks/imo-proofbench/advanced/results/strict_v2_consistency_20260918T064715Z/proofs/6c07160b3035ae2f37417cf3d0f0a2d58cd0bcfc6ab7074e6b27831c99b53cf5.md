To determine all positive integers $k$ such that $S_k(n) = \frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^k$ is an integer for every positive integer $n$, we examine the condition:
\[ A_k(n) = \sum_{i=0}^{n} \binom{n}{i}^k \equiv 0 \pmod{n+1} \]

**1. Necessary Condition**
Consider $n=2$, so $n+1=3$. The condition requires:
\[ A_k(2) = \binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2 + 2^k \equiv 0 \pmod 3 \]
This implies $2^k \equiv -2 \equiv 1 \pmod 3$. Since $2^1 \equiv 2 \pmod 3$ and $2^2 \equiv 1 \pmod 3$, the power $2^k \equiv 1 \pmod 3$ holds if and only if $k$ is even. Thus, $k$ must be even.

**2. Sufficient Condition**
Let $k$ be any even positive integer. We wish to prove that $A_k(n) \equiv 0 \pmod{n+1}$ for all $n \ge 1$. Let $m = n+1$. We need to show $\sum_{i=0}^{m-1} \binom{m-1}{i}^k \equiv 0 \pmod m$. It is sufficient to prove this for $m = p^r$ for any prime $p$ and integer $r \ge 1$.
Consider the binomial coefficient $\binom{p^r-1}{i}$ in the ring of $p$-adic integers $\mathbb{Z}_p$:
\[ \binom{p^r-1}{i} = \prod_{j=1}^i \frac{p^r-j}{j} = \prod_{j=1}^i \left(\frac{p^r}{j} - 1\right) \]
Let $v_p(j)$ be the $p$-adic valuation of $j$. Since $j \le i \le p^r-1$, we have $v_p(j) \le r-1$. Thus $\frac{p^r}{j} = p^{r-v_p(j)} \cdot m_j^{-1}$ for some $m_j$ coprime to $p$, which implies $\frac{p^r}{j} \equiv 0 \pmod p$.
Consequently, $\binom{p^r-1}{i} \equiv \prod_{j=1}^i (-1) = (-1)^i \pmod p$. Since $k$ is even, we have:
\[ \binom{p^r-1}{i}^k \equiv ((-1)^i)^k = 1 \pmod p \]
Summing over $i$ from $0$ to $p^r-1$:
\[ A_k(p^r-1) = \sum_{i=0}^{p^r-1} \binom{p^r-1}{i}^k \equiv \sum_{i=0}^{p^r-1} 1 = p^r \equiv 0 \pmod p \]
To prove $A_k(p^r-1) \equiv 0 \pmod{p^r}$, we note that $\binom{p^r-1}{i} = (-1)^i \prod_{j=1}^i (1 - \frac{p^r}{j})$. For even $k$:
\[ \binom{p^r-1}{i}^k = \prod_{j=1}^i \left(1 - \frac{p^r}{j}\right)^k \equiv \prod_{j=1}^i \left(1 - \frac{kp^r}{j}\right) \equiv 1 - k \sum_{j=1}^i \frac{p^r}{j} \pmod{p^{2r}} \]
Summing this expression over $i$:
\[ A_k(p^r-1) \equiv \sum_{i=0}^{p^r-1} \left(1 - k \sum_{j=1}^i \frac{p^r}{j}\right) = p^r - k \sum_{j=1}^{p^r-1} (p^r-j)\frac{p^r}{j} = p^r - k \sum_{j=1}^{p^r-1} \left(\frac{p^{2r}}{j} - p^r\right) \]
\[ A_k(p^r-1) \equiv p^r + k(p^r-1)p^r = p^r + kp^{2r} - kp^r = (1-k)p^r \pmod{p^{2r}} \]
Since $(1-k)p^r$ is a multiple of $p^r$, we conclude $A_k(p^r-1) \equiv 0 \pmod{p^r}$. By the Chinese Remainder Theorem, $A_k(m-1) \equiv 0 \pmod m$ for all $m$.

Thus, the condition is satisfied if and only if $k$ is even.

The positive integers $k$ are all even positive integers. \(\square\)
