To find all functions $f: \mathbb{Z} \to \mathbb{Z}$ such that the equation $f(x - f(xy)) = f(x)f(1-y)$ holds for all $x, y \in \mathbb{Z}$, we proceed as follows:

**1. Constant Solutions**
Let $f(x) = c$ for all $x \in \mathbb{Z}$. The equation becomes $c = c \cdot c = c^2$. This implies $c^2 - c = 0$, so $c(c-1) = 0$, which gives $c=0$ or $c=1$.
- If $f(x) = 0$, then $0 = 0 \cdot 0$ holds for all $x, y$.
- If $f(x) = 1$, then $1 = 1 \cdot 1$ holds for all $x, y$.
Thus, $f(x) = 0$ and $f(x) = 1$ are solutions.

**2. Non-Constant Solutions**
Assume $f$ is not constant.
- Setting $x=0$ in the original equation: $f(-f(0)) = f(0)f(1-y)$. If $f(0) \neq 0$, then $f(1-y)$ is a constant for all $y$, meaning $f$ is constant, which contradicts our assumption. Thus, we must have $f(0) = 0$.
- Setting $y=0$ in the original equation: $f(x - f(0)) = f(x)f(1)$. Since $f(0)=0$, this becomes $f(x) = f(x)f(1)$. Since $f$ is not constant, there exists $x$ such that $f(x) \neq 0$, so we must have $f(1) = 1$.
- Setting $y=1$ in the original equation: $f(x - f(x)) = f(x)f(0) = 0$ for all $x \in \mathbb{Z}$.
- Setting $x=1$ in the original equation: $f(1 - f(y)) = f(1)f(1-y) = f(1-y)$.

**3. Testing Linear and Periodic Forms**
- If $f(x) = x$, then $f(x - f(xy)) = x - xy$ and $f(x)f(1-y) = x(1-y) = x - xy$. This is a solution.
- If $f(x) = x \pmod 2$ (defined as $f(x) = 0$ if $x$ is even and $f(x) = 1$ if $x$ is odd):
  - If $x$ is even, $f(x) = 0$, and the equation becomes $f(x - f(xy)) = 0 \cdot f(1-y) = 0$. Since $x$ is even, $x - f(xy)$ is even if $f(xy)=0$ and odd if $f(xy)=1$. However, if $x$ is even, $xy$ is always even, so $f(xy)=0$ and $f(x-0) = f(x) = 0$. This holds.
  - If $x$ is odd, $f(x) = 1$, and the equation becomes $f(x - f(xy)) = f(1-y)$.
    - If $y$ is even, $xy$ is even, so $f(xy)=0$. LHS: $f(x-0) = f(x) = 1$. RHS: $f(1-\text{even}) = f(\text{odd}) = 1$.
    - If $y$ is odd, $xy$ is odd, so $f(xy)=1$. LHS: $f(x-1) = f(\text{even}) = 0$. RHS: $f(1-\text{odd}) = f(\text{even}) = 0$.
  This is also a solution.

**4. Verification of Uniqueness**
Suppose $f(x) \in \{0, 1\}$ for all $x$. Let $S = \{x \in \mathbb{Z} : f(x) = 0\}$. Then $0 \in S$ and $1 \notin S$. The condition $f(1-f(y)) = f(1-y)$ implies $y \in S \iff 1-y \notin S$. The condition $f(x-f(xy)) = f(x)f(1-y)$ implies that if $x \in S$, then $x-f(xy) \in S$ for all $y$. If $x \notin S$, then $f(x-f(xy)) = f(1-y)$. For $x \notin S$ and $y \notin S$, we have $f(x-f(xy)) = f(1-y) = 0$ (since $y \notin S \implies 1-y \in S$), so $x-f(xy) \in S$. Since $x \notin S$, we must have $f(xy)=1$, meaning $xy \notin S$. Thus $S^c$ is closed under multiplication. The only set $S^c$ that is closed under multiplication and satisfies $x \in S^c \iff 1-x \notin S^c$ is the set of odd integers.

Comparing all derived possibilities, the functions that satisfy the equation are $f(x)=0$, $f(x)=1$, $f(x)=x$, and $f(x) = x \pmod 2$.

The solutions are $f(n)=0$, $f(n)=1$, $f(n)=n$, and $f(n) = \begin{cases} 0 & \text{if } n \text{ is even} \\ 1 & \text{if } n \text{ is odd} \end{cases}$. \(\square\)
