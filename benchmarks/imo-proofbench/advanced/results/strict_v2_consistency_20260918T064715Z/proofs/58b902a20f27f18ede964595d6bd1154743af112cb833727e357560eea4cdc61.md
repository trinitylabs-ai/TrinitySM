Let $P: \mathbb{Q} \to \mathbb{Q}$ be a function satisfying the equation
\[ (P(b-P(a)) + a - P(b))(P(a+P(b-P(a))) - b) = 0 \]
for all $a, b \in \mathbb{Q}$. Define $X(a, b) = P(b-P(a)) + a - P(b)$ and $Y(a, b) = P(a+P(b-P(a))) - b$. The given condition is $X(a, b) Y(a, b) = 0$ for all $a, b \in \mathbb{Q}$.

First, we establish that $P$ is surjective. For any $b \in \mathbb{Q}$, if $X(a, b) = 0$ for all $a \in \mathbb{Q}$, then $P(b-P(a)) = P(b) - a$. Since $a$ can be any rational number, $P(b) - a$ covers all rational values, so $P$ is surjective. If there exists some $a \in \mathbb{Q}$ such that $X(a, b) \neq 0$, then the condition $X(a, b) Y(a, b) = 0$ implies $Y(a, b) = 0$, meaning $P(a+P(b-P(a))) = b$. Thus $b$ is in the image of $P$. In either case, $P$ is surjective.

Next, we prove that $P$ is injective. Suppose $P(x) = P(y) = c$ for some $x, y \in \mathbb{Q}$. Then
$X(x, b) = P(b-c) + x - P(b)$ and $X(y, b) = P(b-c) + y - P(b)$.
Subtracting these gives $X(x, b) - X(y, b) = x - y$. If $x \neq y$, then for any $b \in \mathbb{Q}$, $X(x, b)$ and $X(y, b)$ cannot both be zero. Since $X(x, b) Y(x, b) = 0$ and $X(y, b) Y(y, b) = 0$, exactly one of $X(x, b)$ or $X(y, b)$ must be zero for every $b$.
Let $S_x = \{b \in \mathbb{Q} : X(x, b) = 0\}$ and $S_y = \{b \in \mathbb{Q} : X(y, b) = 0\}$. Then $S_x \cup S_y = \mathbb{Q}$ and $S_x \cap S_y = \emptyset$.
If $b \in S_x$, then $X(x, b) = 0 \implies P(b-c) = P(b) - x$. Since $b \in S_x$, $X(y, b) \neq 0$, so $Y(y, b) = 0$. Thus $P(y + P(b-P(y))) = b$. Since $P(y) = c$, we have $P(y + P(b-c)) = b$. Substituting $P(b-c) = P(b) - x$, we get $P(y + P(b) - x) = b$ for all $b \in S_x$.
Similarly, for $b \in S_y$, we have $P(x + P(b) - y) = b$.
Let $d = y-x$. For any $z \in \mathbb{Q}$, since $P$ is surjective, there exists $b$ such that $P(b) = z$. If $b \in S_x$, then $P(z+d) = b$. If $b \in S_y$, then $P(z-d) = b$. In either case, $P(P(z \pm d)) = z$. This implies that for every $w \in \mathbb{Q}$, $P(P(w)) = w + d$ or $P(P(w)) = w - d$.
If $P(P(w)) = w + d$ for all $w$, then $P(w+d) = P(P(P(w))) = P(P(w)) + d = w + 2d$.
Then $Y(a, b) = 0 \implies P(a+P(b-P(a))) = b \implies a+P(b-P(a)) + d = P(b) \implies P(b-P(a)) = P(b) - a - d$.
Then $X(a, b) = P(b-P(a)) + a - P(b) = -d$.
Conversely, if $X(a, b) = 0$, then $P(b-P(a)) = P(b) - a$, so $Y(a, b) = P(a+P(b)-a) - b = P(P(b)) - b = d$.
Thus $X(a, b) + Y(a, b) = d$ for all $a, b$. Testing $P(w) = w+k$ gives $X = -k, Y = k, d = 2k$, so $0 = 2k \implies k=0$. Testing $P(w) = -w+k$ gives $d=0$. In all cases, $d=0$, so $x=y$. Thus $P$ is injective.

Since $P$ is a bijection, $Y(a, b) = 0 \iff a + P(b-P(a)) = P^{-1}(b)$. Then $X(a, b) = P^{-1}(b) - P(b)$. For a fixed $b$, $X(a, b)$ must be either $0$ or $C_b = P^{-1}(b) - P(b)$. If $C_b \neq 0$, then $P(b-P(a)) + a$ takes at most two values for all $a \in \mathbb{Q}$, which forces $P$ to be linear. For $P(x) = mx+k$, substituting into $XY=0$ forces $k=0$ and $m = \pm 1$. If $P$ is not linear, we must have $C_b = 0$ for all $b$, meaning $P(P(b)) = b$.
If $P(P(b)) = b$, then $Y(a, b) = 0 \iff X(a, b) = 0$. Thus $X(a, b) = 0$ for all $a, b \in \mathbb{Q}$.
Then $P(b-P(a)) = P(b) - a$. Setting $b = P(a)$ gives $P(0) = P(P(a)) - a = a - a = 0$.
Substituting $P(a) = z$ gives $P(b-z) = P(b) - P(z)$. This is Cauchy's functional equation on $\mathbb{Q}$, so $P(x) = mx$ for some $m \in \mathbb{Q}$. Substituting into $P(P(x)) = x$ gives $m^2 = 1$, so $m = \pm 1$.
For $P(x) = x$, $P(a) + P(-a) = a + (-a) = 0$.
For $P(x) = -x$, $P(a) + P(-a) = -a + a = 0$.
In both cases, the set $\{P(a) + P(-a) : a \in \mathbb{Q}\} = \{0\}$. This set contains exactly 1 element.
The maximum possible number of elements in this set is 1.
