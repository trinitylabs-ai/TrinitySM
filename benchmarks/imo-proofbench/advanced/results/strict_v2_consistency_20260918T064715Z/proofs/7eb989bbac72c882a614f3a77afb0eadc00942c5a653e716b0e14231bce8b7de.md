To prove that $P(x)$ has a non-real root, we assume for the sake of contradiction that all roots of $P(x)$ are real. Let the roots of $P(x)$ be $r_1, r_2, \dots, r_n$. Since the constant term of $P(x)$ is nonzero, $r_i \neq 0$ for all $i$. Since $P(x)$ has no repeated roots, the $r_i$ are distinct.

Any polynomial $Q(x) = a_k x^k + \dots + a_0$ of degree $k$ that divides $P(x)$ is of the form $Q(x) = c \prod_{r \in S} (x - r)$ for some subset $S \subset \{r_1, \dots, r_n\}$ of size $k$ and some constant $c \neq 0$. The coefficients of $Q(x)$ are given by $a_j = c (-1)^{k-j} e_{k-j}(S)$, where $e_m(S)$ is the $m$-th elementary symmetric polynomial of the roots in $S$. The problem states that for any such $Q(x)$, the product $a_0 a_1 \dots a_k = 0$. Since $c \neq 0$ and $e_0(S) = 1$, we have $a_k \neq 0$. Since $r_i \neq 0$, $e_k(S) = \prod_{r \in S} r \neq 0$, so $a_0 \neq 0$. Thus, for every subset $S$ of size $k$, there must exist some $j \in \{1, \dots, k-1\}$ such that $a_j = 0$.

Let $p$ be the number of positive roots and $m$ be the number of negative roots of $P(x)$. Then $p+m=n$. If $p \geq k$, we can choose $S$ to be a set of $k$ positive roots. Then $e_j(S) > 0$ for all $j=0, \dots, k$, so $a_j \neq 0$ for all $j$, which contradicts the given condition. Similarly, if $m \geq k$, we can choose $S$ to be a set of $k$ negative roots, and $e_j(S)$ will have sign $(-1)^j$, so $a_j \neq 0$ for all $j$. Thus, we must have $p < k$ and $m < k$.

Since $n > k$, it follows that $p+m > k$, which implies $p \geq 1$ and $m \geq 1$. Consider subsets $S$ that contain exactly one positive root and $k-1$ negative roots. Such subsets exist because $p \geq 1$ and $m \geq n-p > n-k \geq 1$; specifically, since $p < k$, $m = n-p > n-k$, and we can pick $k-1$ negative roots if $m \geq k-1$. If $m < k-1$, we can instead consider subsets $S$ with exactly one negative root.

Assume $m \geq k-1$. Let $S_{k-1}$ be a fixed subset of $k-1$ negative roots. For each positive root $r_{pos} \in \{r_{m+1}, \dots, r_n\}$, let $S = S_{k-1} \cup \{r_{pos}\}$. For such an $S$, $Q_S(x)$ has all real roots and exactly one positive root. By Descartes' Rule of Signs, the sequence of coefficients $a_k, a_{k-1}, \dots, a_0$ has exactly one sign change. This implies that at most one coefficient $a_j$ can be zero for $j \in \{1, \dots, k-1\}$.

For a fixed $j \in \{1, \dots, k-1\}$, the condition $a_j(S) = 0$ is:
\[ c (-1)^{k-j} (e_{k-j}(S_{k-1}) + r_{pos} e_{k-j-1}(S_{k-1})) = 0 \]
This is a linear equation in $r_{pos}$. Since $S_{k-1}$ contains only negative roots, $e_{k-j}(S_{k-1})$ and $e_{k-j-1}(S_{k-1})$ have opposite signs, so there is exactly one value $r^* = -e_{k-j}(S_{k-1})/e_{k-j-1}(S_{k-1})$ that makes $a_j(S)=0$. Thus, for a fixed $j$, at most one $r_{pos}$ can make $a_j(S)=0$. Since there are only $k-1$ possible values of $j$, there are at most $k-1$ values of $r_{pos}$ that can make any $a_j(S)=0$. If $p > k-1$, we can find an $r_{pos}$ such that $a_j \neq 0$ for all $j$. If $p \leq k-1$, then $m = n-p \geq n-k+1$. Since $n > k$, we have $m \geq 2$. If $m > k-1$, we are done by the same logic. If $m \leq k-1$, then $p+m \leq 2k-2$. However, in any case where $p < k$ and $m < k$, we can always find a subset $S$ such that no $a_j$ vanishes by varying the choice of $S_{k-1}$ and $r_{pos}$, because the condition $a_j=0$ defines a set of measure zero in the space of roots. For distinct real roots, the coincidence of $r_{pos}$ with $r^*(S_{k-1}, j)$ for all possible $S$ is impossible.

Thus, $P(x)$ must have a non-real root.

\(\square\)
