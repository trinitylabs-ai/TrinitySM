**Proof:**

We determine all pairs of positive integers $(x, y)$ for which the limit of the sequence $(a_n)_{n \ge 1}$ exists, where
$$ a_n = \gcd \left( x^n +y , \, (y-x)\left(\sum_{i=0}^{n-1} y^i x^{n-i-1} - 1\right) \right). $$

**Case 1: $x = y$.**
The summation simplifies to $\sum_{i=0}^{n-1} x^{n-1} = n x^{n-1}$. The second argument of the gcd becomes $(x-x)(n x^{n-1} - 1) = 0$. Thus,
$$ a_n = \gcd(x^n + x, 0) = x^n + x. $$
If $x = 1$, then $a_n = 1^n + 1 = 2$ for all $n$, so the sequence is constant and the limit exists.
If $x > 1$, then $a_n \to \infty$ as $n \to \infty$, so the limit does not exist.
Hence, $(1, 1)$ is a solution.

**Case 2: $x \neq y$.**
The summation is a geometric series: $\sum_{i=0}^{n-1} y^i x^{n-i-1} = \frac{y^n - x^n}{y-x}$. Substituting this into the definition of $a_n$ yields
$$ a_n = \gcd\left(x^n + y, (y-x)\left(\frac{y^n - x^n}{y-x} - 1\right)\right) = \gcd(x^n + y, y^n - x^n - y + x). $$
Using the identity $\gcd(A, B) = \gcd(A, A+B)$, we simplify the expression:
$$ a_n = \gcd(x^n + y, (y^n - x^n - y + x) + (x^n + y)) = \gcd(x^n + y, y^n + x). $$
Let $g_n = a_n$. Since $g_n$ is a sequence of positive integers, $\lim_{n \to \infty} g_n$ exists if and only if $g_n$ is eventually constant.

**Subcase 2.1: One of $x, y$ equals 1.**
Assume $x = 1$ and $y > 1$. Then $g_n = \gcd(1+y, y^n+1)$.
Since $y \equiv -1 \pmod{y+1}$, we have $y^n + 1 \equiv (-1)^n + 1 \pmod{y+1}$.
If $n$ is odd, $y^n+1 \equiv 0 \pmod{y+1}$, so $g_n = y+1$.
If $n$ is even, $y^n+1 \equiv 2 \pmod{y+1}$, so $g_n = \gcd(y+1, 2)$.
Because $y > 1$, we have $y+1 > 2$, so $g_n$ oscillates between $y+1$ and $1$ or $2$. The limit does not exist. By symmetry, if $y = 1$ and $x > 1$, the limit does not exist.

**Subcase 2.2: $x, y > 1$ and $x \neq y$.**
We prove that $g_n$ cannot be eventually constant. Suppose for contradiction that $g_n = L$ for all $n \ge N$.
Then $L \mid x^n + y$ and $L \mid y^n + x$ for all $n \ge N$. Consider the linear combinations:
$$ x(x^n + y) - (x^{n+1} + y) = xy - y = y(x-1), $$
$$ y(y^n + x) - (y^{n+1} + x) = yx - x = x(y-1). $$
Thus, $L \mid y(x-1)$ and $L \mid x(y-1)$. It follows that
$$ L \mid y(x-1) - x(y-1) = xy - y - xy + x = x - y. $$
Hence, $L \le |x - y|$.

To demonstrate that this bound is violated, we first examine the specific pair $(x, y) = (2, 3)$. Here $g_n = \gcd(2^n+3, 3^n+2)$. We analyze divisibility by $M = 5$. Note that $2+3=5$.
For integer values of the constants, let M = 5 >= 2. For every positive integer n congruent to 1 modulo phi(M), M divides each of (2)^n + (3); (3)^n + (2). There are infinitely many such positive exponents.
Citing Appendix A, this certifies that for all $n \equiv 1 \pmod 4$, $5 \mid 2^n+3$ and $5 \mid 3^n+2$. Consequently, $g_n \ge 5$ for infinitely many $n$. Since any eventual constant $L$ must satisfy $L \mid 2-3 = -1$, implying $L=1$, the fact that $g_n \ge 5$ infinitely often directly contradicts eventual constancy for this pair. This concrete verification aligns with the general mechanism derived below, where $M=a+b$ and $\phi(M)$ govern the infinite subsequence of exponents.

We now generalize this mechanism to all distinct $x, y > 1$. Let $d = \gcd(x, y)$, and write $x = da$, $y = db$ with $\gcd(a, b) = 1$. Then
$$ g_n = \gcd(da^n + db, db^n + da) = d \gcd(a^n + b, b^n + a). $$
Let $M = a + b$. Since $\gcd(a, b) = 1$, we have $\gcd(a, M) = \gcd(a, a+b) = 1$ and $\gcd(b, M) = 1$. Thus, $a$ and $b$ are units modulo $M$.
By Euler's theorem, $a^{\phi(M)} \equiv 1 \pmod M$ and $b^{\phi(M)} \equiv 1 \pmod M$.
For any $n \equiv 1 \pmod{\phi(M)}$, we have $a^n \equiv a \pmod M$ and $b^n \equiv b \pmod M$.
Consequently,
$$ a^n + b \equiv a + b \equiv 0 \pmod M, \quad b^n + a \equiv b + a \equiv 0 \pmod M. $$
This implies $M \mid \gcd(a^n + b, b^n + a)$ for all $n \equiv 1 \pmod{\phi(M)}$. Since there are infinitely many such exponents, we obtain
$$ g_n \ge dM = d(a+b) = x + y $$
for infinitely many $n$.
Because $x, y > 0$, we strictly have $x + y > |x - y|$. Thus, $g_n$ takes values strictly greater than $|x - y|$ infinitely often, contradicting the necessary condition $L \le |x - y|$ for eventual constancy.

Therefore, $g_n$ is never eventually constant for $x \neq y > 1$, and the limit does not exist in this case.

Combining all cases, the limit of the sequence $(a_n)$ exists if and only if $(x, y) = (1, 1)$. $\square$
