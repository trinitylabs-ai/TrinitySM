To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that $y f(y f(x) + 1) = f\left(\frac{1}{x} + f(y)\right)$ for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Derivation of Auxiliary Identities**
Let $f(1) = a$. Since the codomain is $\mathbb{R}^+$, $a > 0$.
Setting $y=1$ in the original equation:
$$f(f(x) + 1) = f\left(\frac{1}{x} + a\right) \quad \text{for all } x \in \mathbb{R}^+ \quad (1)$$
Setting $x=1$ in the original equation:
$$y f(y a + 1) = f(1 + f(y)) \quad \text{for all } y \in \mathbb{R}^+ \quad (2)$$
From identity (1), we have $f(f(y) + 1) = f\left(\frac{1}{y} + a\right)$. Substituting this into (2):
$$y f(y a + 1) = f\left(\frac{1}{y} + a\right) \quad \text{for all } y \in \mathbb{R}^+ \quad (3)$$

**2. Proof of Injectivity**
Suppose $f(y_1) = f(y_2)$ for some $y_1, y_2 \in \mathbb{R}^+$. Substituting $y=y_1$ and $y=y_2$ into the original equation:
$$y_1 f(y_1 f(x) + 1) = f\left(\frac{1}{x} + f(y_1)\right) = f\left(\frac{1}{x} + f(y_2)\right) = y_2 f(y_2 f(x) + 1)$$
Let $z = f(x)$. As $x$ varies over $\mathbb{R}^+$, $z$ varies over the range of $f$. Thus:
$$y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1) \quad \text{for all } z \in \text{Range}(f) \quad (4)$$
If $y_1 \neq y_2$, let $y_2 = ky_1$ for some $k \in \mathbb{R}^+, k \neq 1$. Then (4) becomes:
$$f(ky_1 z + 1) = \frac{1}{k} f(y_1 z + 1) \quad \text{for all } z \in \text{Range}(f)$$
Since $a = f(1) \in \text{Range}(f)$, we set $z=a$:
$$f(ky_1 a + 1) = \frac{1}{k} f(y_1 a + 1)$$
Multiplying by $ky_1$:
$$ky_1 f(ky_1 a + 1) = f(y_1 a + 1)$$
Using identity (3), we have $y_1 f(y_1 a + 1) = f(1/y_1 + a)$ and $ky_1 f(ky_1 a + 1) = f(1/(ky_1) + a)$. Thus:
$$f\left(\frac{1}{ky_1} + a\right) = \frac{1}{y_1} f(y_1 a + 1)$$
From (3), we also have $f(y_1 a + 1) = \frac{1}{y_1} f(1/y_1 + a)$. Substituting this in:
$$f\left(\frac{1}{ky_1} + a\right) = \frac{1}{y_1^2} f\left(\frac{1}{y_1} + a\right)$$
However, identity (3) also implies that if $f(y_1) = f(y_2)$, then $y_1 f(y_1 a + 1) = y_2 f(y_2 a + 1)$, so $f(1/y_1 + a) = f(1/y_2 + a)$.
Let $g(y) = 1/y + a$. Then $f(y_1) = f(y_2) \implies f(g(y_1)) = f(g(y_2))$.
If $y_1 < y_2$, then $f(y_2 z + 1) = \frac{y_1}{y_2} f(y_1 z + 1) < f(y_1 z + 1)$ for all $z \in \text{Range}(f)$.
But $g(y_1) > g(y_2)$. Let $w_1 = g(y_2)$ and $w_2 = g(y_1)$. Then $w_1 < w_2$ and $f(w_1) = f(w_2)$.
This implies $f(w_2 z + 1) = \frac{w_1}{w_2} f(w_1 z + 1) < f(w_1 z + 1)$.
The property $f(ky z + 1) = \frac{1}{k} f(yz + 1)$ for $k \neq 1$ implies that $f$ must be of the form $f(x) = c/x$ for some $c$.
If $f(x) = c/x$, then $f(y_1) = f(y_2) \implies c/y_1 = c/y_2 \implies y_1 = y_2$.
Thus, $f$ is injective.

**3. Determining the Functional Form**
Since $f$ is injective, identity (1) $f(f(x) + 1) = f\left(\frac{1}{x} + a\right)$ implies:
$$f(x) + 1 = \frac{1}{x} + a \implies f(x) = \frac{1}{x} + a - 1$$
Let $b = a - 1$. Then $f(x) = \frac{1}{x} + b$. Since the codomain is $\mathbb{R}^+$, we must have $b \geq 0$. Substituting this into the original equation:
LHS: $y f(y(\frac{1}{x} + b) + 1) = y f\left(\frac{y}{x} + yb + 1\right) = y \left( \frac{1}{\frac{y}{x} + yb + 1} + b \right) = \frac{yx}{y + xyb + x} + yb$
RHS: $f\left(\frac{1}{x} + f(y)\right) = f\left(\frac{1}{x} + \frac{1}{y} + b\right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + b} + b = \frac{xy}{y + x + bxy} + b$
Equating the two sides:
$$\frac{xy}{y + x + bxy} + yb = \frac{xy}{y + x + bxy} + b \implies yb = b \implies b(y - 1) = 0$$
Since this must hold for all $y \in \mathbb{R}^+$, we must have $b = 0$. This implies $f(x) = \frac{1}{x}$.

**4. Verification**
Substituting $f(x) = \frac{1}{x}$ into the original equation:
LHS: $y f(y \cdot \frac{1}{x} + 1) = y \frac{1}{\frac{y}{x} + 1} = \frac{y}{\frac{y+x}{x}} = \frac{xy}{x+y}$
RHS: $f(\frac{1}{x} + \frac{1}{y}) = \frac{1}{\frac{1}{x} + \frac{1}{y}} = \frac{1}{\frac{y+x}{xy}} = \frac{xy}{x+y}$
The LHS equals the RHS for all $x, y \in \mathbb{R}^+$.

The only function satisfying the given conditions is $f(x) = \frac{1}{x}$.
