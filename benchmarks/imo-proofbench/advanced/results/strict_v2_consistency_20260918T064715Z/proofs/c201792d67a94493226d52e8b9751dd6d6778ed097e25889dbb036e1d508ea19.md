To find the properties of the function $P: \mathbb{Q} \to \mathbb{Q}$ satisfying the equation
\[ (P(b-P(a))+a-P(b))(P(a+P(b-P(a)))-b)=0 \]
for all $a, b \in \mathbb{Q}$, let $X(a, b) = P(b-P(a)) + a - P(b)$ and $Y(a, b) = P(a + P(b-P(a))) - b$. The condition is $X(a, b) Y(a, b) = 0$ for all $a, b \in \mathbb{Q}$.

First, we test linear functions $P(x) = cx + d$.
1. If $P(x) = x + d$:
   $P(b-P(a)) = b - (a+d) + d = b-a$.
   $X(a, b) = (b-a) + a - (b+d) = -d$.
   $Y(a, b) = P(a + (b-a)) - b = P(b) - b = (b+d) - b = d$.
   $X(a, b) Y(a, b) = (-d)(d) = -d^2$.
   For this to be $0$ for all $a, b$, we must have $d=0$, yielding $P(x) = x$.
2. If $P(x) = -x + d$:
   $P(b-P(a)) = -(b - (-a+d)) + d = -b - a + 2d$.
   $X(a, b) = (-b-a+2d) + a - (-b+d) = d$.
   $Y(a, b) = P(a + (-b-a+2d)) - b = P(2d-b) - b = -(2d-b) + d - b = -d$.
   $X(a, b) Y(a, b) = (d)(-d) = -d^2$.
   For this to be $0$ for all $a, b$, we must have $d=0$, yielding $P(x) = -x$.

For both $P(x) = x$ and $P(x) = -x$, the value $P(a) + P(-a)$ is $a + (-a) = 0$ and $-a + a = 0$ respectively. In these cases, the set $\{P(a) + P(-a) : a \in \mathbb{Q}\}$ is $\{0\}$, which has 1 element.

Now we consider if there are other solutions. If $X(a, b) = 0$ for all $a, b$, we have $P(b-P(a)) = P(b) - a$.
For $a=0$, $P(b-P(0)) = P(b)$. If $P(0) \neq 0$, $P$ is periodic with period $T = P(0)$. However, $P(b-P(a)) = P(b) - a$ implies that for a fixed $b$, $P(b-P(a))$ varies linearly with $a$. If $P$ is periodic, this is impossible unless $T=0$. Thus $P(0)=0$. Then $P(b-P(a)) = P(b) - a$, and taking $b=P(a)$ gives $P(0) = P(P(a)) - a \implies P(P(a)) = a$.
The relation $P(b-P(a)) = P(b) - a$ then becomes $P(b-P(a)) = P(b) - P(P(a))$. Let $P(a) = x$, then $P(b-x) = P(b) - P(x)$. This is Cauchy's functional equation on $\mathbb{Q}$, and since $P(P(x))=x$, the only solutions are $P(x) = x$ and $P(x) = -x$.
Similarly, if $Y(a, b) = 0$ for all $a, b$, we have $P(a+P(b-P(a))) = b$. Substituting $P(x) = cx+d$ into this also yields $P(x) = \pm x$.

For any non-linear polynomial $P(x)$ of degree $n > 1$, $Y(a, b)$ would be a polynomial in $b$ of degree $n^2$, making $Y(a, b) = 0$ impossible for all $b$ unless $P$ is linear. For constant functions $P(x) = c$, we get $X(a, b) Y(a, b) = a(c-b)$, which is not identically zero.

Since the only solutions are $P(x) = x$ and $P(x) = -x$, the sum $P(a) + P(-a)$ is always $0$ for all $a \in \mathbb{Q}$. Thus, the set $\{P(a) + P(-a) : a \in \mathbb{Q}\}$ is always $\{0\}$.

The set $\{P(a) + P(-a) : a \in \mathbb{Q}\}$ is $\{0\}$, which is finite. The maximum possible number of elements in this set is 1.

$\square$
