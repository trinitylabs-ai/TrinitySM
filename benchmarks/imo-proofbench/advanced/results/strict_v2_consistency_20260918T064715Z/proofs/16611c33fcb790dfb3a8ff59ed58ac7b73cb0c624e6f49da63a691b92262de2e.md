To prove that $n \geq 5$ for the equation $p^n = a^4 + b^4$, where $p$ is a prime and $a, b$ are positive integers with $n \geq 2$, we analyze the possible values of $n$.

### 1. Analysis of Even $n$
Suppose $n$ is even, say $n = 2k$ for some integer $k \geq 1$. The equation becomes:
\[ a^4 + b^4 = (p^k)^2 \]
This is a specific case of the equation $x^4 + y^4 = z^2$. According to Fermat's Last Theorem for $n=4$ (proven by Fermat using the method of infinite descent), the equation $x^4 + y^4 = z^2$ has no solutions in positive integers. Thus, $n$ cannot be even.

### 2. Analysis of $n=3$
Suppose $n=3$, so $a^4 + b^4 = p^3$. If $\gcd(a, b) = d$, then $d^4$ must divide $p^3$, which implies $d=1$ since $p$ is prime. Thus, $a$ and $b$ are coprime.
- If $p=2$, $a^4 + b^4 = 8$, which implies $a=b=1$, but $1+1=2 \neq 8$.
- If $p > 2$, we work in the Gaussian integers $\mathbb{Z}[i]$. The equation $a^4 + b^4 = p^3$ factors as $(a^2 + ib^2)(a^2 - ib^2) = p^3$.

**Case A: $p \equiv 3 \pmod 4$.**
In this case, $p$ is a prime in $\mathbb{Z}[i]$. Since $p^3 = (a^2 + ib^2)(a^2 - ib^2)$, $p$ must divide one of the factors. If $p | (a^2 + ib^2)$, then $a^2 + ib^2 = p(x + iy)$ for some $x, y \in \mathbb{Z}$. This implies $a^2 = px$ and $b^2 = py$, so $p | a$ and $p | b$, which contradicts $\gcd(a, b) = 1$. Thus, $p \equiv 3 \pmod 4$ is impossible.

**Case B: $p \equiv 1 \pmod 4$.**
Since $p \equiv 1 \pmod 4$, $p$ splits as $p = (u+iv)(u-iv)$ in $\mathbb{Z}[i]$. The factors $a^2 + ib^2$ and $a^2 - ib^2$ are coprime in $\mathbb{Z}[i]$ because any common divisor must divide their sum $2a^2$ and their difference $2ib^2$, and since $p$ is odd, the gcd must divide $a^2$ and $b^2$, which are coprime. Thus, $a^2 + ib^2 = \epsilon (u+iv)^3$ for some $u, v \in \mathbb{Z}$ and unit $\epsilon \in \{1, -1, i, -i\}$. By adjusting the signs of $u, v$ and swapping them if necessary, we can assume $\epsilon = 1$ and $a^2 + ib^2 = (u+iv)^3$. Expanding this, we get:
\[ a^2 = u(u^2 - 3v^2) \quad \text{and} \quad b^2 = v(3u^2 - v^2) \]
Since $u^2 + v^2 = p$ and $p$ is prime, $\gcd(u, v)=1$. We analyze the divisors of the factors: $\gcd(u, u^2 - 3v^2) = \gcd(u, 3)$ and $\gcd(v, 3u^2 - v^2) = \gcd(v, 3)$.

1. **$3 \nmid u$ and $3 \nmid v$:**
Then $\gcd(u, u^2 - 3v^2) = 1$ and $\gcd(v, 3u^2 - v^2) = 1$. For $a^2$ and $b^2$ to be squares, each factor must be a square: $u = s^2, u^2 - 3v^2 = t^2, v = r^2, 3u^2 - v^2 = w^2$. This yields $s^4 - 3r^4 = t^2$ and $3s^4 - r^4 = w^2$. Checking modulo 5, $s^4, r^4 \in \{0, 1\}$.
- If $r^4 \equiv 0 \pmod 5$, then $w^2 \equiv 3s^4 \pmod 5$. If $s^4 \equiv 1 \pmod 5$, then $w^2 \equiv 3 \pmod 5$ (impossible). If $s^4 \equiv 0 \pmod 5$, then $\gcd(u, v) \neq 1$.
- If $r^4 \equiv 1 \pmod 5$, then $s^4 - 3 \equiv t^2 \pmod 5$. If $s^4 \equiv 0 \pmod 5$, then $t^2 \equiv 2 \pmod 5$ (impossible). If $s^4 \equiv 1 \pmod 5$, then $t^2 \equiv -2 \equiv 3 \pmod 5$ (impossible).

2. **$3 | u$:**
Then $3 \nmid v$. Let $u = 3m$. Then $a^2 = 3m(9m^2 - 3v^2) = 9m(3m^2 - v^2)$. Since $\gcd(m, 3m^2 - v^2) = 1$, we must have $m = s^2$ and $3m^2 - v^2 = t^2$, so $3s^4 - v^2 = t^2$. Also, $\gcd(v, 3u^2 - v^2) = 1$ implies $v = r^2$ and $3u^2 - v^2 = w^2$. Substituting $u=3s^2, v=r^2$ into the $a^2$ equation, we get $3s^4 - r^4 = t^2$. Checking $3s^4 - r^4 = t^2$ modulo 8: $s^4, r^4 \in \{0, 1\}$. The only solution is $s^4=0, r^4=0$, which contradicts $\gcd(u, v)=1$.

3. **$3 | v$:**
Then $3 \nmid u$. Let $v = 3m$. Then $b^2 = 3m(3u^2 - 9m^2) = 9m(u^2 - 3m^2)$. Since $\gcd(m, u^2 - 3m^2) = 1$, we must have $m = r^2$ and $u^2 - 3m^2 = w^2$, so $u^2 - 3r^4 = w^2$. Also, $\gcd(u, u^2 - 3v^2) = 1$ implies $u = s^2$ and $u^2 - 3v^2 = t^2$. Substituting $u=s^2, v=3r^2$, we get $s^4 - 27r^4 = t^2$. The equation $u^2 - 3r^4 = w^2$ becomes $s^4 - 3r^4 = w^2$.
We prove that $s^4 - 3r^4 = w^2$ has no solutions in positive integers. Rewrite as $w^2 + 3(r^2)^2 = (s^2)^2$. If $r$ is odd, then $r^4 \equiv 1 \pmod{16}$. For $w^2 + 3r^4 = s^4$ to hold, $s$ must be even (since $w^2 + 3 \equiv s^4 \pmod 4$ implies $s^4 \equiv 0$ or $2 \pmod 4$, and $s^4 \equiv 0$ if $s$ is even). If $s$ is even, $s^4 \equiv 0 \pmod{16}$, so $w^2 \equiv -3 \equiv 13 \pmod{16}$, which is impossible. Thus $r$ must be even.
The primitive solutions to $X^2 + 3Y^2 = Z^2$ with $Y$ even are $Y = 2mn, Z = m^2 + 3n^2$ for coprime $m, n$. Thus $r^2 = 2mn$ and $s^2 = m^2 + 3n^2$.
- If $m=2u^2, n=v^2$, then $s^2 = 4u^4 + 3v^4$. Modulo 4, $s^2 \equiv 3v^4 \pmod 4$. If $v$ is odd, $s^2 \equiv 3 \pmod 4$ (impossible). If $v$ is even, $\gcd(m, n) \neq 1$.
- If $m=u^2, n=2v^2$, then $s^2 = u^4 + 12v^4$. Then $(s-u^2)(s+u^2) = 12v^4$. Since $u$ is odd (as $\gcd(u^2, 2v^2)=1$) and $s^2 = u^4 + 12v^4$, $s$ is also odd. Thus $\gcd(s-u^2, s+u^2) = 2$. We have $\frac{s-u^2}{2} \cdot \frac{s+u^2}{2} = 3v^4$.
    - If $\frac{s-u^2}{2} = 3m^4$ and $\frac{s+u^2}{2} = n^4$, then $n^4 - 3m^4 = u^2$. This is the original equation, but $n^4 = \frac{s+u^2}{2} < s^2$, providing an infinite descent.
    - If $\frac{s-u^2}{2} = m^4$ and $\frac{s+u^2}{2} = 3n^4$, then $3n^4 - m^4 = u^2$. Modulo 4, $3n^4 - m^4 \equiv u^2 \pmod 4$. If $n, m$ are odd, $2 \equiv u^2 \pmod 4$ (no). If $n$ is even, $m$ is odd, $3 \equiv u^2 \pmod 4$ (no). If $n$ is odd, $m$ is even, $3 \equiv u^2 \pmod 4$ (no).

Thus, $n=3$ has no solutions.

### 3. Verification of $n=5$
For $p=2$, $a^4 + b^4 = 2^5 = 32$. Setting $a=2$ and $b=2$ gives $16 + 16 = 32$. This is a valid solution.

### Conclusion
Since $n$ cannot be even and $n$ cannot be 3, and given $n \geq 2$, the smallest possible integer value for $n$ is 5. Thus, $n \geq 5$.
