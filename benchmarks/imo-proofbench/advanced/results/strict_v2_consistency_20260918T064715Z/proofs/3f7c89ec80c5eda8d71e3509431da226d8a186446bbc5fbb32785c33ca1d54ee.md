To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that the equation
\[ f(x-f(xy))=f(x)f(1-y) \]
holds for all $x, y \in \mathbb{Z}$, we proceed as follows:

### 1. Constant Solutions
Let $f(x) = c$ for some constant $c \in \mathbb{Z}$. Substituting this into the equation:
\[ c = c \cdot c \implies c^2 - c = 0 \implies c(c - 1) = 0 \]
This gives $c = 0$ or $c = 1$.
- If $f(x) = 0$, then $0 = 0 \cdot 0$, which is true.
- If $f(x) = 1$, then $1 = 1 \cdot 1$, which is true.
Thus, $f(x) = 0$ and $f(x) = 1$ are solutions.

### 2. Analysis of Non-Constant Solutions
Assume $f$ is not constant. Setting $x = 0$ in the original equation:
\[ f(-f(0)) = f(0)f(1 - y) \]
If $f(0) \neq 0$, then $f(1 - y) = \frac{f(-f(0))}{f(0)}$ for all $y \in \mathbb{Z}$, which implies $f$ is a constant. Since we assumed $f$ is not constant, we must have $f(0) = 0$.

Setting $y = 0$ in the original equation with $f(0) = 0$:
\[ f(x - f(0)) = f(x)f(1) \implies f(x) = f(x)f(1) \]
For this to hold for all $x$, either $f(x) = 0$ for all $x$ (already found) or $f(1) = 1$.

Setting $y = 1$ in the original equation with $f(0) = 0$:
\[ f(x - f(x)) = f(x)f(0) = 0 \]
Setting $x = 1$ in the original equation with $f(1) = 1$:
\[ f(1 - f(y)) = f(1)f(1 - y) = f(1 - y) \]

### 3. Testing the Identity Function
If $f(x) = x$, the original equation becomes:
\[ f(x - xy) = x(1 - y) \implies x - xy = x - xy \]
This is true for all $x, y \in \mathbb{Z}$. Thus, $f(x) = x$ is a solution.

### 4. Testing Modular Solutions
Consider the case where $f$ takes values in a finite set. If $f(x) = x \pmod 2$, then $f(x) \in \{0, 1\}$.
- If $x$ is even, $f(x) = 0$. The RHS is $0 \cdot f(1 - y) = 0$. Since $x$ is even, $xy$ is even, so $f(xy) = 0$. The LHS is $f(x - 0) = f(x) = 0$.
- If $x$ is odd, $f(x) = 1$. The RHS is $1 \cdot f(1 - y) = f(1 - y)$.
    - If $y$ is even, $xy$ is even, so $f(xy) = 0$. The LHS is $f(x - 0) = f(x) = 1$. The RHS is $f(1 - \text{even}) = f(\text{odd}) = 1$.
    - If $y$ is odd, $xy$ is odd, so $f(xy) = 1$. The LHS is $f(x - 1)$. Since $x$ is odd, $x - 1$ is even, so $f(x - 1) = 0$. The RHS is $f(1 - \text{odd}) = f(\text{even}) = 0$.
Thus, $f(x) = x \pmod 2$ is a solution.

### 5. Verification of Completeness
If $f(x) = x \pmod m$ for $m > 2$, the RHS $f(x)f(1 - y)$ could exceed $m-1$. For example, if $m=3$, $x=2, y=2$, then $f(2)f(-1) = 2 \cdot 2 = 4$, but the range of $f$ is $\{0, 1, 2\}$. Thus, no other modular solutions of this form exist. Any other function satisfying $f(1 - f(y)) = f(1 - y)$ and $f(x - f(x)) = 0$ would have to be the identity or a parity-based function given the restrictive nature of the product on the RHS.

The functions are $f(n) = 0$, $f(n) = 1$, $f(n) = n$, and $f(n) = n \pmod 2$.
