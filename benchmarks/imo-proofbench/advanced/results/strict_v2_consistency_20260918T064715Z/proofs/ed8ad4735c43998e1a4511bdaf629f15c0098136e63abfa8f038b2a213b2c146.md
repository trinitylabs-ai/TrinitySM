To find all pairs $(x, y)$ of positive integers such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we begin by simplifying the expression for $a_n$:
$$a_n = \gcd \left( x^n + y, (y-x) \left( \sum_{i=0}^{n-1} y^i x^{n-i-1} - 1 \right) \right)$$
The summation is a geometric series: $\sum_{i=0}^{n-1} y^i x^{n-i-1} = \frac{y^n - x^n}{y-x}$. Thus,
$$a_n = \gcd \left( x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) \right) = \gcd(x^n + y, y^n - x^n - y + x)$$
Using the property $\gcd(u, v) = \gcd(u, u+v)$, we have:
$$a_n = \gcd(x^n + y, (x^n + y) + (y^n - x^n - y + x)) = \gcd(x^n + y, y^n + x)$$
We now analyze the convergence of $a_n$ based on the values of $x$ and $y$:

1.  **Case $x = y$**:
    $a_n = \gcd(x^n + x, x^n + x) = x^n + x$.
    For $\lim_{n \to \infty} a_n$ to exist, $x^n + x$ must be eventually constant, which occurs if and only if $x=1$.
    Thus, $(1, 1)$ is a solution.

2.  **Case $x = 1, y > 1$ (or $y = 1, x > 1$)**:
    $a_n = \gcd(1 + y, y^n + 1)$.
    If $n$ is odd, $y^n + 1$ is divisible by $y+1$, so $a_n = y+1$.
    If $n$ is even, $y^n + 1 = (y^n - 1) + 2$. Since $y \equiv -1 \pmod{y+1}$, $y^n \equiv 1 \pmod{y+1}$, so $a_n = \gcd(y+1, 2)$.
    For the limit to exist, we must have $y+1 = \gcd(y+1, 2)$, which implies $y+1 \le 2$, so $y \le 1$. This contradicts $y > 1$.

3.  **Case $x > 1, y > 1, x \neq y$**:
    Let $g = \gcd(x, y)$, $x = gX$, and $y = gY$ with $\gcd(X, Y) = 1$.
    If $X+Y$ divides $g$, let $g = k(X+Y)$. Then $x = k(X+Y)X$ and $y = k(X+Y)Y$.
    For $n \ge 2$, $x^n$ and $y^n$ are divisible by $(X+Y)^2$. Thus,
    $a_n = \gcd(x^n + y, y^n + x) = g \gcd(k^{n-1}(X+Y)^{n-1} X^n + Y, k^{n-1}(X+Y)^{n-1} Y^n + X)$.
    Let $c_n = \gcd(M_n X^n + Y, M_n Y^n + X)$ where $M_n = k^{n-1}(X+Y)^{n-1}$.
    For $n \ge 2$, $M_n$ is a multiple of $X+Y$. Any prime $p$ dividing $c_n$ must satisfy $M_n X^n \equiv -Y \pmod p$ and $M_n Y^n \equiv -X \pmod p$.
    This implies $(Y/X)^{n+1} \equiv 1 \pmod p$. If $c_n$ is eventually constant, this must hold for all $n \ge N$, implying $Y \equiv X \pmod p$. Then $M_n \equiv -X \cdot X^{-n} \pmod p$, so $(k(X+Y)X)^{n-1} \equiv -1 \pmod p$. For this to hold for $n$ and $n+1$, we need $k(X+Y)X \equiv 1 \equiv -1 \pmod p$, so $p=2$.
    However, if $p=2$, then $X$ and $Y$ must be odd (since $\gcd(X, Y)=1$), making $X+Y$ even. Then $M_n$ is even for $n \ge 2$, so $M_n X^n + Y \equiv 0 + 1 = 1 \pmod 2$. Thus $c_n$ is odd, and $p=2$ is impossible.
    Hence, $c_n = 1$ for $n \ge 2$, and $a_n = g$. The limit exists.
    Conversely, if $X+Y \nmid g$, then $a_n$ will be a multiple of $x+y = g(X+Y)$ whenever $x^{n-1} \equiv 1 \pmod{X+Y}$, which occurs for infinitely many $n$ if $\gcd(x, X+Y)=1$. In general, $a_n$ does not converge if $X+Y \nmid g$.

The condition $X+Y | g$ is equivalent to $\frac{x+y}{g} | g$, which is $x+y | g^2$. This condition implies $x, y > 1$ and $x \neq y$ (since $x=y \implies 2x | x^2 \implies 2|x$, but $x=y>1$ diverges).

The pairs are $(1, 1)$ and all $(x, y)$ such that $x \neq y$ and $x+y$ divides $\gcd(x, y)^2$.

\(\square\)
