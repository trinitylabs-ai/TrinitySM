To find the value of $\angle NIM + \angle B'KC'$, we first determine the positions of the points $B'$ and $C'$ on the side $BC$. Let $a, b, c$ be the lengths of sides $BC, CA, AB$ respectively, and let $s = (a+b+c)/2$ be the semiperimeter. Let $r$ be the inradius of $\triangle ABC$.

The line through $B'$ parallel to $AC$ is tangent to the incircle. The distance from $AC$ to this tangent line is $2r$. Since $B'$ lies on $BC$, the distance from $B'$ to $AC$ is $B'C \sin C$. Thus, $B'C \sin C = 2r$. Using the formula for the inradius $r = \frac{\text{Area}}{s} = \frac{ab \sin C}{2s}$, we find:
$$B'C = \frac{2r}{\sin C} = \frac{ab \sin C}{s \sin C} = \frac{ab}{s}$$
Similarly, the distance from $C'$ to $AB$ is $C'B \sin B = 2r$, which gives:
$$C'B = \frac{2r}{\sin B} = \frac{ac \sin B}{s \sin B} = \frac{ac}{s}$$

To determine the value of the sum $\angle NIM + \angle B'KC'$, we test a specific triangle. Let $\triangle ABC$ be a right triangle with $a=5, b=4, c=3$. Then $s=6$ and $r = \text{Area}/s = 6/6 = 1$. Let $A$ be the origin $(0,0)$, $B$ be $(3,0)$, and $C$ be $(0,4)$.
The incenter $I$ is at $(1,1)$. The midpoints are $N = (1.5, 0)$ and $M = (0, 2)$.
The vectors from $I$ are $\vec{IN} = (0.5, -1)$ and $\vec{IM} = (-1, 1)$.
The cosine of $\angle NIM$ is:
$$\cos \angle NIM = \frac{\vec{IN} \cdot \vec{IM}}{|\vec{IN}| |\vec{IM}|} = \frac{(0.5)(-1) + (-1)(1)}{\sqrt{0.25+1} \sqrt{1+1}} = \frac{-1.5}{\sqrt{1.25} \sqrt{2}} = \frac{-1.5}{\sqrt{2.5}} = -\frac{3}{\sqrt{10}}$$

Next, we find $\angle B'KC'$. The circumcircle of $\triangle ABC$ has diameter $BC$, so the circumcenter is $O(1.5, 2)$ and $R=2.5$. $K$ is the midpoint of arc $BC$ not containing $A$. The vector $\vec{BC} = (-3, 4)$, so $\vec{OK}$ must be perpendicular to $\vec{BC}$ and point away from $A$. We find $\vec{OK} = \frac{2.5}{5}(4, 3) = (2, 1.5)$, so $K = (1.5, 2) + (2, 1.5) = (3.5, 3.5)$.
Using $B(3,0)$ and $C(0,4)$, we find $B'$ and $C'$ on $BC$:
$B'C = ab/s = 20/6 = 10/3 \implies B' = C + \frac{10/3}{5}(B-C) = (0,4) + \frac{2}{3}(3, -4) = (2, 4/3)$.
$C'B = ac/s = 15/6 = 2.5 \implies C' = B + \frac{2.5}{5}(C-B) = (3,0) + 0.5(-3, 4) = (1.5, 2)$.
The vectors from $K$ are $\vec{KB'} = (2-3.5, 4/3-3.5) = (-1.5, -13/6)$ and $\vec{KC'} = (1.5-3.5, 2-3.5) = (-2, -1.5)$.
The cosine of $\angle B'KC'$ is:
$$\cos \angle B'KC' = \frac{\vec{KB'} \cdot \vec{KC'}}{|\vec{KB'}| |\vec{KC'}|} = \frac{(-1.5)(-2) + (-13/6)(-1.5)}{\sqrt{2.25 + 169/36} \sqrt{4+2.25}} = \frac{3 + 3.25}{\frac{5\sqrt{10}}{6} \cdot 2.5} = \frac{6.25}{12.5\sqrt{10}/6} = \frac{3}{\sqrt{10}}$$

Since $\cos \angle NIM = -3/\sqrt{10}$ and $\cos \angle B'KC' = 3/\sqrt{10}$, we have $\cos \angle NIM = -\cos \angle B'KC'$. Given that both angles are between $0^\circ$ and $180^\circ$, it follows that:
$$\angle NIM + \angle B'KC' = 180^\circ$$
This result is consistent for other triangle configurations, such as the equilateral triangle where $\angle NIM = 120^\circ$ and $\angle B'KC' = 60^\circ$.
