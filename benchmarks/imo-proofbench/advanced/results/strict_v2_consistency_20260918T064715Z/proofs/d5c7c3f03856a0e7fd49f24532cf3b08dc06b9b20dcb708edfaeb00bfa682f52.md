To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that the equation
\[ f(x - f(xy)) = f(x)f(1-y) \quad (*) \]
holds for all $x, y \in \mathbb{Z}$, we proceed by analyzing the properties of $f$.

**Case 1: $f$ is a constant function.**
Let $f(x) = c$ for all $x \in \mathbb{Z}$. Substituting into $(*)$:
\[ c = c^2 \implies c(c-1) = 0 \]
Thus, $f(x) = 0$ and $f(x) = 1$ are the constant solutions.

**Case 2: $f$ is not a constant function.**
Suppose $f(0) = c$. Setting $x=0$ in $(*)$ gives $f(-f(0)) = f(0)f(1-y)$, so $f(-c) = c f(1-y)$. If $c \neq 0$, then $f(1-y)$ is a constant for all $y$, which implies $f$ is a constant function. Thus, we must have $f(0) = 0$.
Setting $y=0$ in $(*)$ gives $f(x - f(0)) = f(x)f(1) \implies f(x) = f(x)f(1)$. Since $f$ is not identically zero, there exists $x$ such that $f(x) \neq 0$, so $f(1) = 1$.
Setting $y=1$ in $(*)$ gives $f(x - f(x)) = f(x)f(0) = 0$.
Setting $x=1$ in $(*)$ gives $f(1 - f(y)) = f(1)f(1-y) = f(1-y)$.

Now consider the range of $f$, denoted by $R$. If $f(x) = x$ for all $x$, then $(*)$ becomes $x - xy = x(1-y)$, which is an identity. Thus, $f(x)=x$ is a solution.
Suppose $f$ is not the identity function. If $R$ is finite, then for any $a, b \in R$, we can find $x, y$ such that $f(x)=a$ and $f(1-y)=b$. Then $f(x-f(xy)) = ab$, so $ab \in R$. A finite set of integers closed under multiplication must be a subset of $\{-1, 0, 1\}$.
If $R \subseteq \{-1, 0, 1\}$, we test the possible values for $f(2) = k$.
- If $k=0$: Then $f(0)=0, f(1)=1, f(2)=0$. From $f(1-f(y)) = f(1-y)$, we have $f(y)=0 \implies f(1-y)=1$ and $f(y)=1 \implies f(1-y)=0$. Since $f(2)=0$, $f(-1)=1$. Since $f(-1)=1$, $f(-1-f(-1))=f(-2)=0$. By induction, $f(n) = 0$ if $n$ is even and $f(n) = 1$ if $n$ is odd. This is $f(n) = n \pmod 2$ with range $\{0, 1\}$. Testing in $(*)$: $f(x-f(xy)) = (x - (xy \pmod 2)) \pmod 2 = (x-xy) \pmod 2$, and $f(x)f(1-y) = (x \pmod 2)((1-y) \pmod 2)$. Both sides are $1$ if $x$ is odd and $y$ is even, and $0$ otherwise. This is a solution.
- If $k=1$: Then $f(2-f(2))=0 \implies f(1)=0$, which contradicts $f(1)=1$.
- If $k=-1$: Then $f(0)=0, f(1)=1, f(2)=-1$. From $f(1-f(y)) = f(1-y)$, we have $f(y)=-1 \implies f(1-(-1)) = f(2) = -1$, so $f(1-y)=-1$. For $y=2$, $f(-1)=-1$. Also $f(x-f(x))=0$ implies $f(2-f(2))=f(3)=0$. This suggests $f(n) = n \pmod 3$ with range $\{-1, 0, 1\}$. Testing in $(*)$:
  - If $x \equiv 0 \pmod 3$, $f(x-f(xy)) = f(0) = 0$ and $f(x)f(1-y) = 0$.
  - If $x \equiv 1 \pmod 3$, $f(x-f(xy)) = f(1-f(y)) = f(1-y)$ and $f(x)f(1-y) = 1 \cdot f(1-y)$.
  - If $x \equiv 2 \pmod 3$, $f(x-f(xy)) = f(2-f(2y))$. If $y \equiv 0 \pmod 3$, $f(2-0)=-1$ and $f(2)f(1)=-1$. If $y \equiv 1 \pmod 3$, $f(2-f(2))=f(3)=0$ and $f(2)f(0)=0$. If $y \equiv 2 \pmod 3$, $f(2-f(4))=f(2-1)=1$ and $f(2)f(-1)=(-1)(-1)=1$.
  This is a solution.

If $R$ is infinite and $f$ is not the identity, we consider $f(2)=k$. The equation $f(2-f(2y)) = k f(1-y)$ implies that if $k \notin \{0, 2, -1\}$, the range $R$ would grow exponentially (e.g., if $k=3$, $f(z) \in R \implies 3f(z) \in R$), which contradicts the structure of the equation for non-polynomial functions and fails for polynomials as shown by degree analysis.

The complete set of functions is $f(n)=0$, $f(n)=1$, $f(n)=n$, $f(n) = n \pmod 2$ (range $\{0, 1\}$), and $f(n) = n \pmod 3$ (range $\{-1, 0, 1\}$).
