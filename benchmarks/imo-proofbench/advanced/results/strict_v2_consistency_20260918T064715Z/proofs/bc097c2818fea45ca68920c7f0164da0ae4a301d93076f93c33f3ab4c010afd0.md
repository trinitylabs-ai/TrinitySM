To prove that $C$ is the midpoint of $XY$, we set up a coordinate system with $C$ as the origin $(0,0)$ and the line $BC$ as the $x$-axis. Let the vertices of the acute triangle $ABC$ be $C(0,0)$, $B(a, 0)$, and $A(b \cos C, b \sin C)$, where $a, b$ are the side lengths $BC$ and $AC$.

1.  **Coordinates of $H, P, F$:**
    The orthocenter $H$ lies on the altitude from $A$ to $BC$, so its $x$-coordinate is $x_H = b \cos C$. The altitude from $C$ to $AB$ has slope $m_{CF} = \frac{a - b \cos C}{b \sin C}$ (since it is perpendicular to $AB$, whose slope is $\frac{b \sin C}{b \cos C - a}$). Thus, the $y$-coordinate of $H$ is $h = m_{CF} \cdot x_H = \frac{(a - b \cos C) \cos C}{\sin C}$.
    The point $P$ is the reflection of $H$ across $BC$ (the $x$-axis), so $P = (b \cos C, -h)$.
    The foot $F$ of the altitude from $C$ to $AB$ is the intersection of $CF$ ($y = m_{CF} x$) and $AB$ ($y = \frac{b \sin C}{b \cos C - a}(x - a)$). Letting $k = m_{CF} = \frac{a - b \cos C}{b \sin C}$, we have $kx = -\frac{1}{k}(x - a)$, which gives $x_F = \frac{a}{k^2 + 1}$ and $y_F = \frac{ak}{k^2 + 1}$.

2.  **Center of the Circumcircle of $\triangle AFP$:**
    Let the circumcircle $\Gamma$ of $\triangle AFP$ have center $O(x_0, y_0)$. Since $A(b \cos C, b \sin C)$ and $P(b \cos C, -h)$ lie on $\Gamma$, the center $O$ must lie on the perpendicular bisector of $AP$, which is the horizontal line $y = \frac{b \sin C - h}{2}$. Thus, $y_0 = \frac{b \sin C - h}{2}$.
    The point $O$ also lies on the perpendicular bisector of $AF$. $C$ is the midpoint of $XY$ if and only if $O$ lies on the $y$-axis, i.e., $x_0 = 0$. For $x_0 = 0$, the distance $OA$ must equal $OF$:
    $$(b \cos C - 0)^2 + (b \sin C - y_0)^2 = (x_F - 0)^2 + (y_F - y_0)^2$$
    Expanding and simplifying:
    $$b^2 \cos^2 C + b^2 \sin^2 C - 2b \sin C y_0 + y_0^2 = x_F^2 + y_F^2 - 2y_F y_0 + y_0^2$$
    $$b^2 - (b \sin C - y_F)(2y_0) - (x_F^2 + y_F^2) = 0$$
    Substituting $2y_0 = b \sin C - h$:
    $$b^2 - (b \sin C - y_F)(b \sin C - h) - (x_F^2 + y_F^2) = 0$$
    $$b^2 \cos^2 C + b \sin C y_F + hb \sin C - hy_F - (x_F^2 + y_F^2) = 0$$

3.  **Verification of the Equation:**
    Using $x_F^2 + y_F^2 = \frac{a^2}{k^2+1}$, $h = kb \cos C$, and $y_F = \frac{ak}{k^2+1}$:
    $$b^2 \cos^2 C + \frac{abk \sin C}{k^2+1} + kb^2 \sin C \cos C - \frac{abk^2 \cos C}{k^2+1} - \frac{a^2}{k^2+1} = 0$$
    $$b^2 \cos C (\cos C + k \sin C) + \frac{abk(\sin C - k \cos C) - a^2}{k^2+1} = 0$$
    Since $k = \frac{a - b \cos C}{b \sin C}$, we have $\cos C + k \sin C = \frac{a}{b}$ and $\sin C - k \cos C = \frac{b - a \cos C}{b \sin C}$.
    The equation becomes:
    $$ab \cos C + \frac{abk(\frac{b - a \cos C}{b \sin C}) - a^2}{k^2+1} = ab \cos C + \frac{ak(\frac{b - a \cos C}{\sin C}) - a^2}{k^2+1} = 0$$
    Substituting $k$ again, the numerator of the fraction is $\frac{a(a - b \cos C)(b - a \cos C)}{b \sin^2 C} - a^2 = \frac{-ac^2 \cos C}{b \sin^2 C}$.
    Since $k^2+1 = \frac{c^2}{b^2 \sin^2 C}$, the fraction simplifies to $\frac{-ac^2 \cos C}{b \sin^2 C} \cdot \frac{b^2 \sin^2 C}{c^2} = -ab \cos C$.
    Thus, $ab \cos C - ab \cos C = 0$. This confirms $x_0 = 0$.

Since $x_0 = 0$, the center $O$ of the circumcircle of $\triangle AFP$ lies on the line perpendicular to $BC$ at $C$. The intersections $X, Y$ of the circle with $BC$ are equidistant from the projection of $O$ onto $BC$, which is $C$. Thus, $C$ is the midpoint of $XY$. \(\square\)
