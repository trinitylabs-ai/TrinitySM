To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows.

**Step 1: Testing for a simple solution.**
Suppose $f(x) = \frac{a}{x}$ for some $a > 0$. Substituting this into the equation:
LHS: $y f(y \frac{a}{x} + 1) = y \frac{a}{y \frac{a}{x} + 1} = \frac{ya}{\frac{ya+x}{x}} = \frac{yax}{ya+x}$.
RHS: $f(\frac{1}{x} + \frac{a}{y}) = \frac{a}{\frac{1}{x} + \frac{a}{y}} = \frac{a}{\frac{y+ax}{xy}} = \frac{axy}{y+ax}$.
For LHS = RHS, we require $\frac{axy}{ay+x} = \frac{axy}{ax+y}$, which implies $ay+x = ax+y$, or $(a-1)y = (a-1)x$ for all $x, y \in \mathbb{R}^+$. This holds if and only if $a=1$. Thus, $f(x) = \frac{1}{x}$ is a solution.

**Step 2: Proving injectivity.**
Suppose $f(y_1) = f(y_2) = c$ for some $y_1, y_2 \in \mathbb{R}^+$. Then for all $x \in \mathbb{R}^+$,
$$f\left(\frac{1}{x} + f(y_1)\right) = f\left(\frac{1}{x} + f(y_2)\right) \implies y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1).$$
Let $f(x) = z$. As $x$ varies, $z$ ranges over the image $S = \text{Im}(f)$. Thus, $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$ for all $z \in S$.
If $y_1 \neq y_2$, assume without loss of generality $y_1 < y_2$. Let $k = y_1/y_2 < 1$. Then $f(y_2 z + 1) = k f(y_1 z + 1)$.
Let $w_0 = y_2 z + 1$. Then $y_1 z + 1 = \frac{y_1}{y_2}(y_2 z + 1) + 1 - \frac{y_1}{y_2} = k w_0 + 1 - k$.
Thus, $f(w_0) = k f(k w_0 + 1 - k)$. Iterating this $n$ times, we get $f(w_0) = k^n f(w_n)$ where $w_n = k^n(w_0 - 1) + 1$.
As $n \to \infty$, $w_n \to 1^+$. This implies $f(w_n) = f(w_0) / k^n \to \infty$.
Now, consider the original equation for a fixed $y$: $f(1/x + f(y)) = y f(y f(x) + 1)$.
If $f(x) \to 0$ as $x \to \infty$, then for any $y$, as $x \to \infty$, $y f(x) + 1 \to 1^+$.
Then $y f(y f(x) + 1) \to \infty$, so $f(1/x + f(y)) \to \infty$.
Since $1/x + f(y) \to f(y)$, this means $f(w) \to \infty$ as $w \to f(y)^+$ for all $y \in \mathbb{R}^+$.
This implies $f(w)$ blows up as $w$ approaches any value in the image of $f$ from the right, which is impossible for a function $f: \mathbb{R}^+ \to \mathbb{R}^+$.
Thus, $f$ must be injective.

**Step 3: Solving for $f$.**
Let $f(1) = a$. Setting $x=1$ in the original equation:
$y f(y a + 1) = f(1 + f(y))$.
Setting $y=1$ in the original equation:
$f(f(x) + 1) = f(1/x + a)$.
Since $f$ is injective, $f(x) + 1 = 1/x + a$, so $f(x) = 1/x + a - 1$.
Substitute this back into the original equation:
$y f(y(1/x + a - 1) + 1) = f(1/x + 1/y + a - 1)$.
$y \left( \frac{1}{y/x + y(a-1) + 1} + a - 1 \right) = \frac{1}{1/x + 1/y + a - 1} + a - 1$.
$\frac{yx}{y + xy(a-1) + x} + y(a-1) = \frac{xy}{y + x + xy(a-1)} + a - 1$.
The fractions on both sides are identical, so we must have $y(a-1) = a-1$ for all $y \in \mathbb{R}^+$.
This implies $a-1 = 0$, so $a=1$.
Thus, $f(x) = 1/x + 1 - 1 = 1/x$.

Verification: $y f(y/x + 1) = y \frac{1}{y/x + 1} = \frac{yx}{y+x}$ and $f(1/x + 1/y) = \frac{1}{1/x + 1/y} = \frac{xy}{x+y}$.
The solution is consistent.

The only function satisfying the equation is $f(x) = \frac{1}{x}$.

\(\square\)
