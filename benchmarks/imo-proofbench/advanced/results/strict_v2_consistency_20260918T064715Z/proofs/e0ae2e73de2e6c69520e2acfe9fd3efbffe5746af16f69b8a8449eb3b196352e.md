Let the sequence of numbers chosen by the people in the line be $\{x_m\}_{m=1}^\infty$. For $m > N$, the rule is $x_m = 1 + C_{m-2}(x_{m-1})$, where $C_k(v)$ denotes the number of times the value $v$ appears in the set $\{x_1, \dots, x_k\}$. Let $S = \{v \in \mathbb{Z}^+ \mid v \text{ appears infinitely often in } \{x_m\}\}$.

First, we show $S \neq \emptyset$. Suppose $S = \emptyset$. Then every positive integer appears only finitely often in the sequence. Since the sequence is infinite, the set of values $\{x_m\}_{m=1}^\infty$ must be infinite. Let $f(v) = C_\infty(v)$ be the total number of times $v$ appears in the sequence. For $m > N$, $x_m = v$ if and only if $C_{m-2}(x_{m-1}) = v-1$. For a fixed value $s$, the $k$-th occurrence of $s$ at index $m-1$ produces $x_m = 1 + (k-1) = k$ if $s$ has appeared $k-1$ times in the first $m-2$ terms. Thus, the number of times $v$ is produced as a successor is exactly the number of values $s$ that appear at least $v$ times. Let $\delta_v$ be the number of times $v$ appears in the first $N$ terms. Then $f(v) = \text{count}\{s \in \mathbb{Z}^+ \mid f(s) \ge v\} + \delta_v$. For $v=1$, $f(1) = \text{count}\{s \in \mathbb{Z}^+ \mid f(s) \ge 1\} + \delta_1$. Since $S = \emptyset$ and the sequence is infinite, the number of distinct values $s$ that appear at least once is infinite, so $f(1) = \infty$, contradicting $S = \emptyset$.

Next, we show that either $S$ is finite or $S = \mathbb{Z}^+$. Let $n_k = \text{count}\{s \mid f(s) \ge k\}$. Then $f(k) = n_k + \delta_k$. If $S$ is infinite, then $n_1 = \infty$, so $f(1) = \infty$. If $n_k$ were finite for some $k$, then for $m > k$, $n_m \le n_k$. Then $f(m) = n_m + \delta_m \le n_k + \max \delta_m$ for all $m > k$. This implies $f(m)$ is bounded for all $m > k$, so $n_m = \text{count}\{s \mid f(s) \ge m\}$ must eventually be zero, which contradicts the fact that the sequence is infinite. Thus, if $S$ is infinite, $n_k = \infty$ for all $k \in \mathbb{Z}^+$, which implies $f(k) = \infty$ for all $k$, so $S = \mathbb{Z}^+$.

Case 1: $S = \mathbb{Z}^+$.
Since $f(1) = \infty$, let $m_k$ be the index of the $k$-th occurrence of 1. Then $x_{m_k} = 1$. For $m_k > N$, $x_{m_k+1} = 1 + C_{m_k-1}(x_{m_k}) = 1 + C_{m_k-1}(1)$. Since $x_{m_k}$ is the $k$-th occurrence of 1, $C_{m_k-1}(1) = k-1 + \delta_1$. Thus $x_{m_k+1} = k + \delta_1$.
Now consider $x_{m_k+2} = 1 + C_{m_k}(x_{m_k+1}) = 1 + C_{m_k}(k + \delta_1)$. For $k$ sufficiently large, $k + \delta_1 > \max\{x_1, \dots, x_N\}$. Any occurrence of $k + \delta_1$ at index $j \le m_k$ requires $C_{j-2}(x_{j-1}) = k + \delta_1 - 1$. This implies $x_{j-1}$ appeared at least $k + \delta_1 - 1$ times. Since $C_{m_k-1}(s) \le C_{m_k-1}(1) = k-1 + \delta_1$, the only value that could satisfy this is $x_{j-1} = 1$, but $C_{j-2}(1) = k + \delta_1 - 1$ only for $j-2 \ge m_k-1$, so $j \ge m_k+1$. Thus $C_{m_k}(k + \delta_1) = 0$ for large $k$, and $x_{m_k+2} = 1 + 0 = 1$.
This shows that for large $k$, $x_{m_k} = 1$ and $x_{m_k+2} = 1$. By induction, $x_{m_k+2j} = 1$ for all $j \ge 0$. Since these indices share the same parity, either $\{b_n\}$ or $\{g_n\}$ is eventually constant.

Case 2: $S$ is finite.
Let $S = \{s_1, \dots, s_k\}$. Since $f(v) = n_v + \delta_v$, for $v > \max \{f(s) \mid s \notin S\}$, we have $n_v = |S| = k$. Thus $f(v) = k + \delta_v$ for all large $v$. This implies $S = \{1, \dots, k\}$.
For $m$ sufficiently large, if $x_m \in S$, then $C_{m-1}(x_m) \to \infty$, so $x_{m+1} = 1 + C_{m-1}(x_m)$ eventually exceeds $k$, meaning $x_{m+1} \notin S$.
If $x_m \notin S$, then $x_{m+1} = 1 + C_{m-1}(x_m)$. Since $x_m \notin S$, $C_{m-1}(x_m) \le f(x_m) = k + \delta_{x_m}$. For large $x_m$, $C_{m-1}(x_m) \le k$, so $x_{m+1} \le k+1$.
If $x_m \in S$, then $x_{m+2} = 1 + C_m(x_{m+1})$. For $m$ large, $x_{m+1}$ is produced by $x_m \in S$, so $C_m(x_{m+1}) = \delta_{x_{m+1}} + \text{count}\{s \in S \mid C_{m-1}(s) \ge C_{m-1}(x_m)\}$. For $m$ large, $\delta_{x_{m+1}} = 0$, so $x_{m+2} = 1 + \text{count}\{s \in S \mid C_{m-1}(s) \ge C_{m-1}(x_m)\}$. This value is in $\{1, \dots, k+1\}$.
If $x_{m+2} \in S$, the sequence returns to $S$. If $x_{m+2} = k+1$, then $x_{m+3} = 1 + C_{m+1}(k+1) \le 1 + f(k+1) = 1 + k + \delta_{k+1}$. Since any $v \notin S$ appears only finitely often, the sequence must return to $S$ infinitely often.
The state of the sequence at step $m$ (where $x_m \in S$) can be described by $(x_m, \text{relative order of } \{C_{m-1}(s)\}_{s \in S})$. Since there are only $k \cdot k!$ such states and the evolution is deterministic, the sequence $\{x_m\}$ is eventually periodic. Thus both $\{b_n\}$ and $\{g_n\}$ are eventually periodic.

In both cases, at least one of $\{b_n\}$ or $\{g_n\}$ is eventually periodic.
