To prove that there exists a positive integer $N$ such that for every odd integer $n > N$, the digits in the base-$2n$ representation of $n^k$ are all greater than $d$, we analyze the base-$2n$ expansion of $n^k$.

Let the base-$2n$ representation of $n^k$ be
\[ n^k = a_m (2n)^m + a_{m-1} (2n)^{m-1} + \dots + a_1 (2n) + a_0, \]
where $0 \le a_i < 2n$ for all $i = 0, 1, \dots, m$. The digits $a_i$ are given by the formula
\[ a_i = S_i \pmod{2n}, \quad \text{where } S_i = \left\lfloor \frac{n^k}{(2n)^i} \right\rfloor. \]
For $i=0$, $S_0 = n^k$, so $a_0 = n^k \pmod{2n}$. Since $n$ is odd, $n^k - n = n(n^{k-1}-1)$. Because $n^{k-1}$ is odd, $n^{k-1}-1$ is even, so $n(n^{k-1}-1)$ is a multiple of $2n$. Thus, $n^k \equiv n \pmod{2n}$, which means $a_0 = n$. For $n > d$, we have $a_0 > d$.

For $i \ge 1$, we have $S_i = \left\lfloor \frac{n^k}{2^i n^i} \right\rfloor = \left\lfloor \frac{n^{k-i}}{2^i} \right\rfloor$.
If $i \ge k$, then $S_i = 0$, so $m = k-1$ (for $k \ge 1$).
For $1 \le i < k$, let $r = k-i \ge 1$. Then $a_i = \left\lfloor \frac{n^r}{2^i} \right\rfloor \pmod{2n}$.

Case 1: $r=1$.
Then $a_i = \left\lfloor \frac{n}{2^i} \right\rfloor \pmod{2n}$. Since $0 \le \lfloor n/2^i \rfloor < n < 2n$, we have $a_i = \lfloor n/2^i \rfloor$. For $n > 2^i(d+1)$, $a_i > d$.

Case 2: $r \ge 2$.
We want to evaluate $a_i = \lfloor n^r / 2^i \rfloor \pmod{2n}$. Let $n^{r-1} = q \cdot 2^{i+1} + R$, where $1 \le R < 2^{i+1}$ (since $n$ is odd). Then
\[ \frac{n^r}{2^i} = \frac{n \cdot n^{r-1}}{2^i} = \frac{n(q \cdot 2^{i+1} + R)}{2^i} = 2nq + \frac{nR}{2^i}. \]
Taking the floor, we have
\[ \left\lfloor \frac{n^r}{2^i} \right\rfloor = 2nq + \left\lfloor \frac{nR}{2^i} \right\rfloor. \]
Thus, $a_i = \lfloor nR/2^i \rfloor \pmod{2n}$. Since $1 \le R < 2^{i+1}$, we have $0 < nR/2^i < 2n$, so $a_i = \lfloor nR/2^i \rfloor$.
Since $R \ge 1$, $a_i \ge \lfloor n/2^i \rfloor$. For $n > 2^i(d+1)$, $a_i > d$.

In all cases, for $0 \le i < k$, the digits $a_i$ satisfy $a_i \ge \lfloor n/2^{k-1} \rfloor$ (since $a_0 = n$ and for $i \ge 1$, $a_i \ge \lfloor n/2^i \rfloor \ge \lfloor n/2^{k-1} \rfloor$).
By choosing $N = 2^{k-1}(d+1)$, we ensure that for all odd $n > N$, every digit $a_i$ satisfies
\[ a_i \ge \left\lfloor \frac{n}{2^{k-1}} \right\rfloor > \left\lfloor \frac{2^{k-1}(d+1)}{2^{k-1}} \right\rfloor = d. \]
Thus, all digits $a_i$ are greater than $d$.

\(\square\)
