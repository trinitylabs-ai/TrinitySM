To prove that there exist two real-coefficient polynomials $P(x)$ and $Q(x)$ satisfying the condition $P(Q(x)-x-1)=Q(P(x))$ with $\deg(P) \ge 2024$ and $\deg(Q) \ge 2$, we consider a construction where $P$ and $Q$ are based on shifts of power functions.

Let $P(x)$ be of the form $P(x) = (x-h)^n + k$ for some constants $h, k \in \mathbb{R}$ and an integer $n \ge 2024$.
Let $Q(x)$ be a quadratic polynomial of the form $Q(x) = x^2 + bx + c$ for some constants $b, c \in \mathbb{R}$.

Substituting these into the condition $P(Q(x)-x-1) = Q(P(x))$, we have:
\[ (Q(x)-x-1-h)^n + k = (P(x))^2 + b P(x) + c \]
Substituting $P(x) = (x-h)^n + k$:
\[ (Q(x)-x-1-h)^n + k = ((x-h)^n + k)^2 + b((x-h)^n + k) + c \]
Expanding the right-hand side:
\[ (Q(x)-x-1-h)^n + k = (x-h)^{2n} + 2k(x-h)^n + k^2 + b(x-h)^n + bk + c \]
\[ (Q(x)-x-1-h)^n + k = (x-h)^{2n} + (2k+b)(x-h)^n + (k^2 + bk + c) \]

To make the left-hand side match the right-hand side, we first set the inner polynomial of the left-hand side to be $(x-h)^2$:
\[ Q(x)-x-1-h = (x-h)^2 \]
\[ Q(x) = (x-h)^2 + x + 1 + h = x^2 - 2hx + h^2 + x + 1 + h = x^2 + (1-2h)x + (h^2 + h + 1) \]
Comparing this with $Q(x) = x^2 + bx + c$, we identify:
\[ b = 1-2h \quad \text{and} \quad c = h^2 + h + 1 \]
With this choice of $Q(x)$, the condition simplifies to:
\[ (x-h)^{2n} + k = (x-h)^{2n} + (2k+b)(x-h)^n + (k^2 + bk + c) \]
Equating the coefficients of $(x-h)^n$ and the constant terms:
1.  $2k + b = 0 \implies b = -2k$
2.  $k = k^2 + bk + c$

Using $b = 1-2h$ in the first equation:
\[ 1-2h = -2k \implies k = h - \frac{1}{2} \]
Substituting $k = h - \frac{1}{2}$ and $c = h^2 + h + 1$ into the second equation:
\[ h - \frac{1}{2} = \left(h - \frac{1}{2}\right)^2 + (1-2h)\left(h - \frac{1}{2}\right) + (h^2 + h + 1) \]
\[ h - \frac{1}{2} = (h^2 - h + \frac{1}{4}) + (-2h^2 + 2h - \frac{1}{2}) + h^2 + h + 1 \]
\[ h - \frac{1}{2} = 2h + \frac{3}{4} \]
\[ -h = \frac{5}{4} \implies h = -\frac{5}{4} \]
Now we calculate the values of $k, b,$ and $c$:
\[ k = -\frac{5}{4} - \frac{1}{2} = -\frac{7}{4} \]
\[ b = 1 - 2\left(-\frac{5}{4}\right) = 1 + \frac{5}{2} = \frac{7}{2} \]
\[ c = \left(-\frac{5}{4}\right)^2 + \left(-\frac{5}{4}\right) + 1 = \frac{25}{16} - \frac{20}{16} + \frac{16}{16} = \frac{21}{16} \]
Thus, we define the polynomials:
\[ P(x) = \left(x + \frac{5}{4}\right)^{2024} - \frac{7}{4}, \quad Q(x) = x^2 + \frac{7}{2}x + \frac{21}{16} \]
We verify the conditions:
1.  $\deg(P) = 2024 \ge 2024$ and $\deg(Q) = 2 \ge 2$.
2.  $Q(x) - x - 1 = x^2 + \frac{5}{2}x + \frac{5}{16}$.
3.  $P(Q(x)-x-1) = (x^2 + \frac{5}{2}x + \frac{5}{16} + \frac{5}{4})^{2024} - \frac{7}{4} = (x^2 + \frac{5}{2}x + \frac{25}{16})^{2024} - \frac{7}{4} = ((x + \frac{5}{4})^2)^{2024} - \frac{7}{4} = (x + \frac{5}{4})^{4048} - \frac{7}{4}$.
4.  $Q(P(x)) = P(x)^2 + \frac{7}{2}P(x) + \frac{21}{16} = ((x + \frac{5}{4})^{2024} - \frac{7}{4})^2 + \frac{7}{2}((x + \frac{5}{4})^{2024} - \frac{7}{4}) + \frac{21}{16}$
    $= (x + \frac{5}{4})^{4048} - \frac{7}{2}(x + \frac{5}{4})^{2024} + \frac{49}{16} + \frac{7}{2}(x + \frac{5}{4})^{2024} - \frac{49}{8} + \frac{21}{16}$
    $= (x + \frac{5}{4})^{4048} + \frac{49 - 98 + 21}{16} = (x + \frac{5}{4})^{4048} - \frac{28}{16} = (x + \frac{5}{4})^{4048} - \frac{7}{4}$.

The condition $P(Q(x)-x-1) = Q(P(x))$ is satisfied for all $x$.

\(\square\)
