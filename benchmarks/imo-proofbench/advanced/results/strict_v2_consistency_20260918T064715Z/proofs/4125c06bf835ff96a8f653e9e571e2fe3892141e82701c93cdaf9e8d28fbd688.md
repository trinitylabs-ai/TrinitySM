To find all positive real numbers $r$ such that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$, where $A(r) = \{2r\}$ and $B(n,r) = \sum_{k=1}^n A(kr)$, we begin by simplifying the expression for $B(n,r)$.

The fractional part of a real number $x$ is defined as $\{x\} = x - \lfloor x \rfloor$. Thus,
\[
B(n,r) = \sum_{k=1}^n \{2kr\} = \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor) = 2r \sum_{k=1}^n k - \sum_{k=1}^n \lfloor 2kr \rfloor = n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor.
\]
Substituting this into the given expression $f(n,r) = n(n+1)r - B(n,r)$, we get:
\[
f(n,r) = n(n+1)r - \left( n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor \right) = \sum_{k=1}^n \lfloor 2kr \rfloor.
\]
The condition that $f(n,r)$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$ means that $S_n = \sum_{k=1}^n \lfloor 2kr \rfloor$ must be divisible by $n$ for all $n \ge 1$. Let $x = 2r$. The condition is that $S_n = \sum_{k=1}^n \lfloor kx \rfloor \equiv 0 \pmod n$ for all $n \ge 1$.

Let $x = a + \delta$, where $a = \lfloor x \rfloor$ is an integer and $0 \le \delta < 1$. We rewrite $S_n$ as:
\[
S_n = \sum_{k=1}^n \lfloor k(a + \delta) \rfloor = \sum_{k=1}^n (ka + \lfloor k\delta \rfloor) = a \frac{n(n+1)}{2} + T_n,
\]
where $T_n = \sum_{k=1}^n \lfloor k\delta \rfloor$. The condition $S_n \equiv 0 \pmod n$ is equivalent to $\frac{S_n}{n} = \frac{a(n+1)}{2} + \frac{T_n}{n} \in \mathbb{Z}$.

Case 1: $a$ is even.
In this case, $\frac{a(n+1)}{2}$ is always an integer. Thus, we require $\frac{T_n}{n} \in \mathbb{Z}$ for all $n \ge 1$.
For $n=1$, $T_1 = \lfloor \delta \rfloor = 0$, which is divisible by 1.
For $n=2$, $T_2 = \lfloor \delta \rfloor + \lfloor 2\delta \rfloor = \lfloor 2\delta \rfloor$. For $T_2$ to be a multiple of 2, and since $0 \le \lfloor 2\delta \rfloor \le 1$, we must have $\lfloor 2\delta \rfloor = 0$.
For $n=3$, $T_3 = 0 + 0 + \lfloor 3\delta \rfloor$. For $T_3$ to be a multiple of 3, and since $0 \le \lfloor 3\delta \rfloor < 3$, we must have $\lfloor 3\delta \rfloor = 0$.
In general, assume $\lfloor k\delta \rfloor = 0$ for all $1 \le k < n$. Then $T_n = \sum_{k=1}^{n-1} 0 + \lfloor n\delta \rfloor = \lfloor n\delta \rfloor$. For $T_n$ to be a multiple of $n$, and since $0 \le \lfloor n\delta \rfloor < n$ (because $\delta < 1$), we must have $\lfloor n\delta \rfloor = 0$. By induction, $\lfloor n\delta \rfloor = 0$ for all $n \ge 1$, which implies $\delta = 0$.
Thus $x = a$ is an even integer. Since $x = 2r$, $r = a/2$ is a positive integer.

Case 2: $a$ is odd.
For $n=2$, $\frac{S_2}{2} = \frac{3a + \lfloor 2\delta \rfloor}{2}$. Since $3a$ is odd, $\lfloor 2\delta \rfloor$ must be odd, so $\lfloor 2\delta \rfloor = 1$. This implies $1/2 \le \delta < 1$.
For $n=3$, $\frac{S_3}{3} = \frac{4a}{2} + \frac{0 + 1 + \lfloor 3\delta \rfloor}{3} = 2a + \frac{1 + \lfloor 3\delta \rfloor}{3}$. We require $1 + \lfloor 3\delta \rfloor \equiv 0 \pmod 3$. Since $1/2 \le \delta < 1$, $3/2 \le 3\delta < 3$, so $\lfloor 3\delta \rfloor \in \{1, 2\}$. Thus $\lfloor 3\delta \rfloor = 2$.
For $n=4$, $\frac{S_4}{4} = \frac{5a}{2} + \frac{0 + 1 + 2 + \lfloor 4\delta \rfloor}{4} = \frac{10a + 3 + \lfloor 4\delta \rfloor}{4}$. Since $a$ is odd, $10a \equiv 2 \pmod 4$. Thus $\frac{S_4}{4} \equiv \frac{2 + 3 + \lfloor 4\delta \rfloor}{4} = \frac{5 + \lfloor 4\delta \rfloor}{4} \in \mathbb{Z}$.
Since $2/3 \le \delta < 1$, $\lfloor 4\delta \rfloor \in \{2, 3\}$. This forces $\lfloor 4\delta \rfloor = 3$.
In general, assume $\lfloor k\delta \rfloor = k-1$ for $k=1, \dots, n-1$. Then $T_n = \sum_{k=1}^{n-1} (k-1) + \lfloor n\delta \rfloor = \frac{(n-1)(n-2)}{2} + \lfloor n\delta \rfloor$. The condition $S_n \equiv 0 \pmod n$ becomes $\frac{an(n+1)}{2} + \frac{(n-1)(n-2)}{2} + \lfloor n\delta \rfloor \equiv 0 \pmod n$. Multiplying by 2, we get $(a+1)n^2 + (a-3)n + 2 + 2\lfloor n\delta \rfloor \equiv 0 \pmod n$, which simplifies to $2 + 2\lfloor n\delta \rfloor \equiv 0 \pmod n$. Since $\lfloor (n-1)\delta \rfloor = n-2$, we have $\delta \ge \frac{n-2}{n-1}$, so $\lfloor n\delta \rfloor \ge \lfloor \frac{n(n-2)}{n-1} \rfloor = \lfloor \frac{n^2-2n}{n-1} \rfloor = \lfloor \frac{(n-1)^2-1}{n-1} \rfloor = n-2$. Also $\delta < 1$ implies $\lfloor n\delta \rfloor \le n-1$. Thus $2n-2 \le 2 + 2\lfloor n\delta \rfloor \le 2n$. For this to be a multiple of $n$, we must have $2 + 2\lfloor n\delta \rfloor = 2n$ for $n \ge 3$, so $\lfloor n\delta \rfloor = n-1$. Repeating this, we find $\lfloor n\delta \rfloor = n-1$ for all $n \ge 1$. This requires $n-1 \le n\delta < n$, or $1 - \frac{1}{n} \le \delta < 1$ for all $n$. As $n \to \infty$, this implies $\delta \ge 1$, which contradicts $\delta < 1$.

Thus, the only solutions are $x = 2r \in \{2, 4, 6, \dots\}$, which means $r$ must be a positive integer. Checking this, if $r \in \mathbb{Z}^+$, then $S_n = \sum_{k=1}^n \lfloor 2kr \rfloor = 2r \frac{n(n+1)}{2} = rn(n+1)$, which is always a multiple of $n$.

The positive real numbers $r$ are the positive integers.
