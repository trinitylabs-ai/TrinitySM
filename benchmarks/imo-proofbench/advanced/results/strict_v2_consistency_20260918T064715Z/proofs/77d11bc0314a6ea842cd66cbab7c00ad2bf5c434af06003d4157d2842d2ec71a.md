To find all positive real numbers $r$ such that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$, we begin by analyzing the expression $B(n,r)$.
By definition, $A(r)$ is the fractional part of $2r$, so $A(r) = \{2r\} = 2r - \lfloor 2r \rfloor$. Then
\[ B(n,r) = \sum_{k=1}^n A(kr) = \sum_{k=1}^n \{2kr\} = \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor). \]
Substituting this into the expression $S_n = n(n+1)r - B(n,r)$, we have:
\[ S_n = n(n+1)r - \sum_{k=1}^n 2kr + \sum_{k=1}^n \lfloor 2kr \rfloor = n(n+1)r - 2r \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor 2kr \rfloor = \sum_{k=1}^n \lfloor 2kr \rfloor. \]
The condition is that $S_n = \sum_{k=1}^n \lfloor 2kr \rfloor$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$. Let $x = 2r$. We seek all $x > 0$ such that $C_n = \sum_{k=1}^n \lfloor kx \rfloor \equiv 0 \pmod{n}$ for all $n \ge 1$.

Let $x = q + \delta$, where $q = \lfloor x \rfloor$ is a non-negative integer and $0 \le \delta < 1$.
For $n=1$, $C_1 = \lfloor x \rfloor = q$, which is always a multiple of 1.
For $n=2$, $C_2 = \lfloor x \rfloor + \lfloor 2x \rfloor = q + (2q + \lfloor 2\delta \rfloor) = 3q + \lfloor 2\delta \rfloor \equiv q + \lfloor 2\delta \rfloor \equiv 0 \pmod{2}$.
- If $q$ is even, then $\lfloor 2\delta \rfloor = 0$, so $0 \le \delta < 1/2$.
- If $q$ is odd, then $\lfloor 2\delta \rfloor = 1$, so $1/2 \le \delta < 1$.

For $n=3$, $C_3 = C_2 + \lfloor 3x \rfloor \equiv 0 \pmod{3}$.
- If $q$ is even and $0 \le \delta < 1/2$, then $C_2 = 3q$, so $C_3 = 3q + (3q + \lfloor 3\delta \rfloor) \equiv \lfloor 3\delta \rfloor \equiv 0 \pmod{3}$. Since $0 \le 3\delta < 3/2$, we must have $\lfloor 3\delta \rfloor = 0$, so $0 \le \delta < 1/3$.
- If $q$ is odd and $1/2 \le \delta < 1$, then $C_3 = q + (2q+1) + (3q + \lfloor 3\delta \rfloor) = 6q + 1 + \lfloor 3\delta \rfloor \equiv 1 + \lfloor 3\delta \rfloor \equiv 0 \pmod{3}$. Since $3/2 \le 3\delta < 3$, we must have $\lfloor 3\delta \rfloor = 2$, so $2/3 \le \delta < 1$.

We hypothesize that for all $n \ge 1$:
Case A: $q$ is even and $0 \le \delta < 1/n$.
Case B: $q$ is odd and $1 - 1/n \le \delta < 1$.

We prove this by induction. Assume the hypothesis holds for $n$.
In Case A, since $0 \le \delta < 1/n$, for all $1 \le k \le n$ we have $0 \le k\delta < n(1/n) = 1$, so $\lfloor k\delta \rfloor = 0$. Thus $C_n = \sum_{k=1}^n \lfloor k(q+\delta) \rfloor = \sum_{k=1}^n (kq + \lfloor k\delta \rfloor) = \sum_{k=1}^n kq = q \frac{n(n+1)}{2}$. Since $q$ is even, $C_n \equiv 0 \pmod{n}$.
Then $C_{n+1} = q \frac{n(n+1)}{2} + (n+1)q + \lfloor (n+1)\delta \rfloor = q \frac{(n+1)(n+2)}{2} + \lfloor (n+1)\delta \rfloor$.
For $C_{n+1} \equiv 0 \pmod{n+1}$, we need $\lfloor (n+1)\delta \rfloor \equiv 0 \pmod{n+1}$. Given $0 \le \delta < 1/n$, we have $0 \le (n+1)\delta < 1 + 1/n$. Thus $\lfloor (n+1)\delta \rfloor \in \{0, 1\}$, so we must have $\lfloor (n+1)\delta \rfloor = 0$, which implies $0 \le \delta < 1/(n+1)$.

In Case B, since $1 - 1/n \le \delta < 1$, for all $1 \le k \le n$ we have $k(1 - 1/n) \le k\delta < k$. Since $k-1 \le k - k/n \le k(1-1/n)$, it follows that $k-1 \le k\delta < k$, so $\lfloor k\delta \rfloor = k-1$. Thus $C_n = \sum_{k=1}^n \lfloor k(q+\delta) \rfloor = \sum_{k=1}^n (kq + \lfloor k\delta \rfloor) = \sum_{k=1}^n (kq + k - 1) = (q+1) \frac{n(n+1)}{2} - n$. Since $q$ is odd, $q+1$ is even, so $C_n \equiv 0 \pmod{n}$.
Then $C_{n+1} = C_n + \lfloor (n+1)x \rfloor = (q+1) \frac{n(n+1)}{2} - n + (n+1)q + \lfloor (n+1)\delta \rfloor$.
$C_{n+1} = (n+1) \left[ \frac{n(q+1)}{2} + q \right] - n + \lfloor (n+1)\delta \rfloor \equiv 1 + \lfloor (n+1)\delta \rfloor \equiv 0 \pmod{n+1}$.
Thus $\lfloor (n+1)\delta \rfloor \equiv n \pmod{n+1}$. Given $1 - 1/n \le \delta < 1$, we have $n - 1/n \le (n+1)\delta < n+1$, so $\lfloor (n+1)\delta \rfloor \in \{n-1, n\}$. Thus we must have $\lfloor (n+1)\delta \rfloor = n$, which implies $n/(n+1) \le \delta < 1$.

As $n \to \infty$, Case A implies $\delta = 0$ and $q$ is even. Case B implies $\delta \ge 1$, which is impossible since $\delta < 1$. Thus $x = q$ must be an even integer.
Since $x = 2r$, we have $2r = 2m$ for some $m \in \mathbb{Z}^+$, so $r = m$.
Checking $r \in \mathbb{Z}^+$, we have $C_n = \sum_{k=1}^n \lfloor 2km \rfloor = 2m \frac{n(n+1)}{2} = mn(n+1)$, which is always a multiple of $n$.

The positive real numbers $r$ are all positive integers. \(\square\)
