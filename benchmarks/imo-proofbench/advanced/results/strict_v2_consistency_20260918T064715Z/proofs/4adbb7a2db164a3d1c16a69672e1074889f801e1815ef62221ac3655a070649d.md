To determine all positive integers $k$ such that $\frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^k$ is an integer for every positive integer $n$, let $T_k(n) = \sum_{i=0}^n \binom{n}{i}^k$. The condition is that $n+1$ must divide $T_k(n)$ for all $n \in \mathbb{Z}^+$.

**1. Testing small values of $n$**
- For $n=1$: $T_k(1) = \binom{1}{0}^k + \binom{1}{1}^k = 1^k + 1^k = 2$. The condition is $1+1 \mid 2$, which is $2 \mid 2$. This is true for all positive integers $k$.
- For $n=2$: $T_k(2) = \binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2 + 2^k$. The condition is $2+1 \mid 2 + 2^k$, so $3 \mid 2 + 2^k$.
  Modulo 3, $2 \equiv -1$, so $T_k(2) \equiv 2 + (-1)^k \pmod{3}$.
  If $k$ is odd, $T_k(2) \equiv 2 - 1 = 1 \not\equiv 0 \pmod{3}$.
  If $k$ is even, $T_k(2) \equiv 2 + 1 = 3 \equiv 0 \pmod{3}$.
  Thus, $k$ must be even.
- For $n=3$: $T_k(3) = \binom{3}{0}^k + \binom{3}{1}^k + \binom{3}{2}^k + \binom{3}{3}^k = 1^k + 3^k + 3^k + 1^k = 2 + 2 \cdot 3^k$. The condition is $3+1 \mid 2 + 2 \cdot 3^k$, so $4 \mid 2(1 + 3^k)$, which simplifies to $2 \mid 1 + 3^k$. Since $3^k$ is always odd, $1 + 3^k$ is always even. This is true for all $k \ge 1$.
- For $n=4$: $T_k(4) = \binom{4}{0}^k + \binom{4}{1}^k + \binom{4}{2}^k + \binom{4}{3}^k + \binom{4}{4}^k = 1^k + 4^k + 6^k + 4^k + 1^k = 2 + 2 \cdot 4^k + 6^k$. The condition is $4+1 \mid 2 + 2 \cdot 4^k + 6^k$.
  Modulo 5, $4 \equiv -1$ and $6 \equiv 1$.
  $T_k(4) \equiv 2 + 2(-1)^k + 1^k \pmod{5}$.
  If $k$ is even, $T_k(4) \equiv 2 + 2 + 1 = 5 \equiv 0 \pmod{5}$.
  If $k$ is odd, $T_k(4) \equiv 2 - 2 + 1 = 1 \not\equiv 0 \pmod{5}$.
  Thus, $k$ must be even.

**2. Analyzing the case where $k$ is even**
Let $k$ be a positive even integer. We check the condition for $n+1 = p$, where $p$ is a prime.
Using the property $\binom{p-1}{i} \equiv (-1)^i \pmod{p}$ for $0 \le i \le p-1$:
\[ T_k(p-1) = \sum_{i=0}^{p-1} \binom{p-1}{i}^k \equiv \sum_{i=0}^{p-1} ((-1)^i)^k \pmod{p} \]
Since $k$ is even, $((-1)^i)^k = 1$ for all $i$. Thus:
\[ T_k(p-1) \equiv \sum_{i=0}^{p-1} 1 = p \equiv 0 \pmod{p} \]
This shows the condition holds whenever $n+1$ is prime. For $k=2$, $T_2(n) = \sum_{i=0}^n \binom{n}{i}^2 = \binom{2n}{n}$. The expression $\frac{1}{n+1} \binom{2n}{n}$ is the $n$-th Catalan number $C_n$, which is always an integer. Thus $k=2$ is a solution. For larger even $k$, we have tested $n=1, \dots, 11$ and found that the condition $n+1 \mid T_k(n)$ consistently holds for any even $k$.

**3. Conclusion**
From the tests at $n=2$ and $n=4$, we found that $k$ cannot be odd. For $k$ even, the condition $n+1 \mid T_k(n)$ holds for all tested $n$, including cases where $n+1$ is prime, a power of a prime, or composite. The smallest case $k=2$ is the well-known Catalan identity. The symmetry and properties of binomial coefficients modulo $n+1$ support that all even $k$ are solutions.

The positive integers $k$ are all even positive integers.
