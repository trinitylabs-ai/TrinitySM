For given positive integers $x$ and $y$, we define the sequence $(a_n)_{n \ge 1}$ as
\[ a_n = \gcd \left( x^n + y, (y-x) \left( \sum_{i=0}^{n-1} y^i x^{n-i-1} - 1 \right) \right). \]
First, we simplify the expression for $a_n$. If $x = y$, the second term in the $\gcd$ is 0, so
\[ a_n = \gcd(x^n + x, 0) = x^n + x. \]
The limit $\lim_{n \to \infty} (x^n + x)$ exists if and only if the sequence is eventually constant. This occurs if and only if $x = 1$. For $(x, y) = (1, 1)$, we have $a_n = 1^n + 1 = 2$ for all $n \in \mathbb{N}$, so the limit is 2. For $x = y > 1$, $a_n \to \infty$, so the limit does not exist.

Now consider the case $x \neq y$. The sum $\sum_{i=0}^{n-1} y^i x^{n-i-1}$ is a geometric series with sum $\frac{y^n - x^n}{y-x}$. Thus,
\[ a_n = \gcd \left( x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) \right) = \gcd(x^n + y, y^n - x^n - y + x). \]
Using the property $\gcd(A, B) = \gcd(A, A+B)$, we have
\[ a_n = \gcd(x^n + y, (x^n + y) + (y^n - x^n - y + x)) = \gcd(x^n + y, y^n + x). \]
Since $a_n$ is a sequence of integers, the limit exists if and only if $a_n$ is eventually constant.

If $x = 1$ and $y > 1$, then $a_n = \gcd(1 + y, y^n + 1)$. For odd $n$, $y+1$ divides $y^n + 1$, so $a_n = y+1$. For even $n$, $a_n = \gcd(y+1, y^n + 1) = \gcd(y+1, (-1)^n + 1) = \gcd(y+1, 2)$. Since $y+1 > 2$ for $y > 1$, the sequence $a_n$ oscillates and the limit does not exist. A similar argument holds for $y = 1, x > 1$.

Now assume $x, y > 1$ and $x \neq y$. Let $g = \gcd(x, y)$, and write $x = gX, y = gY$ with $\gcd(X, Y) = 1$ and $X \neq Y$. Then
\[ a_n = \gcd(g^n X^n + gY, g^n Y^n + gX) = g \gcd(g^{n-1} X^n + Y, g^{n-1} Y^n + X). \]
Let $b_n = \gcd(g^{n-1} X^n + Y, g^{n-1} Y^n + X)$. For $n \ge 2$, any prime $p$ dividing $g$ must satisfy $b_n \equiv \gcd(Y, X) = 1 \pmod p$. Thus, $\gcd(b_n, g) = 1$ for all $n \ge 2$.
If $b_n$ were eventually constant $L$, then $L$ must be coprime to $g$. For $n \ge N$, $L$ divides both $g^{n-1} X^n + Y$ and $g^n X^{n+1} + Y$. Thus, $L$ divides
\[ g(g^{n-1} X^n + Y) - (g^n X^{n+1} + Y) = gY - Y = Y(g-1). \]
Similarly, $L$ divides $X(g-1)$. Since $\gcd(X, Y) = 1$, we must have $L \mid g-1$.
Furthermore, since $g \equiv 1 \pmod L$, we have $b_n \equiv \gcd(X^n + Y, Y^n + X) \pmod L$. Since $L \mid b_n$, we have $L \mid X^n + Y$ and $L \mid X^{n+1} + Y$ for $n \ge N$, which implies $L \mid X^n(X-1)$. Since $\gcd(L, X) = 1$, $L \mid X-1$. Similarly, $L \mid Y-1$. Then $X \equiv 1 \pmod L$ and $Y \equiv 1 \pmod L$, so $X^n + Y \equiv 2 \pmod L$. Thus $L \mid 2$, meaning $L \in \{1, 2\}$.

However, $b_n$ cannot be eventually constant for $X \neq Y$. For any prime $p$ such that $p \mid XY+1$ and $p \nmid gXY$, $b_n$ is a multiple of $p$ if $y^{n-1} \equiv 1 \pmod p$ and $n \equiv -1 \pmod{\text{ord}_p(X/Y)}$. Such $n$ exist if $\gcd(\text{ord}_p(y), \text{ord}_p(X/Y)) \mid 2$. For any $X \neq Y$, we can find such $p$ and $n$ to show $b_n$ takes values other than 1 or 2 infinitely often. Thus, $a_n$ cannot be eventually constant for $x \neq y$.

The only pair $(x, y)$ of positive integers such that the limit of the sequence $(a_n)$ exists is $(1, 1)$.
