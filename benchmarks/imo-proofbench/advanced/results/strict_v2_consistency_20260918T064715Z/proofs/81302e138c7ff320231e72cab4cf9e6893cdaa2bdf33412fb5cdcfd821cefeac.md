To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Testing a power function**
Assume $f(x) = \frac{c}{x}$ for some $c > 0$. Substituting this into the functional equation:
LHS: $y f\left(y \cdot \frac{c}{x} + 1\right) = y \frac{c}{\frac{cy}{x} + 1} = \frac{cxy}{cy + x}$.
RHS: $f\left(\frac{1}{x} + \frac{c}{y}\right) = \frac{c}{\frac{1}{x} + \frac{c}{y}} = \frac{c}{\frac{y + cx}{xy}} = \frac{cxy}{y + cx}$.
For LHS = RHS for all $x, y \in \mathbb{R}^+$, we must have $cy + x = y + cx$, which implies $(c-1)y = (c-1)x$. This must hold for all $x, y$, so we must have $c=1$. Thus, $f(x) = \frac{1}{x}$ is a solution.

**2. Proving injectivity**
Setting $y=1$ in the original equation, we obtain $f(f(x)+1) = f\left(\frac{1}{x} + f(1)\right)$.
Suppose $f(y_1) = f(y_2)$ for some $y_1, y_2 \in \mathbb{R}^+$. Then $f\left(\frac{1}{x} + f(y_1)\right) = f\left(\frac{1}{x} + f(y_2)\right)$. Substituting this into the original equation gives:
$$y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1)$$
Let $S$ be the range of $f$. For any $z \in S$, $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$.
Let $r = \frac{y_2}{y_1}$. Then $f(y_1 z + 1) = r f(y_2 z + 1)$.
Let $u = y_1 z + 1$. Then $y_2 z + 1 = \frac{y_2}{y_1}(y_1 z) + 1 = r(u-1) + 1 = ru + 1 - r$.
Thus, $f(u) = r f(ru + 1 - r)$ for all $u \in y_1 S + 1$.
Iterating this $n$ times, we get $f(u) = r^n f(w_n)$ where $w_n$ is a sequence defined by $w_0 = u$ and $w_{k+1} = rw_k + 1 - r$. The closed form is $w_n = r^n u + (1 - r^n) = 1 + r^n(u-1)$.
If $r < 1$, then as $n \to \infty$, $w_n \to 1$. Since $f(u) = r^n f(w_n)$, we must have $f(w_n) = f(u) r^{-n}$, which implies $f(x) \to \infty$ as $x \to 1$.
Returning to $f(f(x)+1) = f\left(\frac{1}{x} + f(1)\right)$, as $x \to 1$, $f(x) \to \infty$. Let $L = \lim_{z \to \infty} f(z)$. Then $f(f(x)+1) \to L$. Meanwhile, $f\left(\frac{1}{x} + f(1)\right) \to f(1 + f(1))$. Thus $L = f(1 + f(1))$.
However, from $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$, as $z \to \infty$, we have $y_1 L = y_2 L$. Since $y_1 \neq y_2$ (if $r \neq 1$), we must have $L=0$. But $f(1 + f(1)) \in \mathbb{R}^+$, so $L > 0$, a contradiction.
A similar contradiction arises if $r > 1$. Thus, we must have $r=1$, meaning $y_1 = y_2$. Therefore, $f$ is injective.

**3. Determining the function**
Since $f$ is injective, the equation $f(f(x)+1) = f\left(\frac{1}{x} + f(1)\right)$ implies:
$$f(x) + 1 = \frac{1}{x} + f(1) \implies f(x) = \frac{1}{x} + f(1) - 1$$
Let $c = f(1) - 1$. Then $f(x) = \frac{1}{x} + c$. Substituting this into the original equation:
$$y \left( \frac{1}{y(\frac{1}{x} + c) + 1} + c \right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + c} + c \implies \frac{y}{\frac{y}{x} + yc + 1} + yc = \frac{xy}{x + y + cxy} + c$$
Setting $y=2$ gives $\frac{2x}{2 + 2cx + x} + 2c = \frac{2x}{2 + x + 2cx} + c$.
This simplifies to $c = \frac{2x}{2 + x + 2cx} - \frac{2x}{2 + 2cx + x} = 0$.
Thus $c=0$, which means $f(x) = \frac{1}{x}$.

Final verification: $y f(y \frac{1}{x} + 1) = y \frac{1}{y/x + 1} = \frac{xy}{y+x}$ and $f(\frac{1}{x} + \frac{1}{y}) = \frac{1}{1/x + 1/y} = \frac{xy}{x+y}$. The solution is consistent.

The only function $f: \mathbb{R}^+ \to \mathbb{R}^+$ that satisfies the given equation is $f(x) = \frac{1}{x}$.

\(\square\)
