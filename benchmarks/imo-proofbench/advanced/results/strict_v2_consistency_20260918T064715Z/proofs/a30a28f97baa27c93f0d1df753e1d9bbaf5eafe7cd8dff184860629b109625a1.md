To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right),$$
we begin by testing simple functional forms.

**1. Testing a power function**
Assume $f(x) = c x^k$. Substituting this into the equation:
$$y c (y c x^k + 1)^k = c \left(\frac{1}{x} + c y^k\right)^k.$$
Dividing by $c$:
$$y (y c x^k + 1)^k = \left(\frac{1}{x} + c y^k\right)^k.$$
If $k = -1$:
$$y \frac{1}{y c x^{-1} + 1} = \frac{1}{\frac{1}{x} + c y^{-1}} \implies \frac{y}{\frac{yc}{x} + 1} = \frac{1}{\frac{y+cx}{xy}} \implies \frac{yx}{yc + x} = \frac{xy}{y + cx}.$$
For this to be an identity for all $x, y \in \mathbb{R}^+$, we must have $yc + x = y + cx$, which implies $(y-x)(c-1) = 0$. This holds for all $x, y$ if and only if $c = 1$. Thus, $f(x) = \frac{1}{x}$ is a solution.

**2. Exploring injectivity**
Suppose $f(y_1) = f(y_2)$ for some $y_1, y_2 \in \mathbb{R}^+$. Then for all $x \in \mathbb{R}^+$:
$$f\left(\frac{1}{x} + f(y_1)\right) = f\left(\frac{1}{x} + f(y_2)\right).$$
Using the original equation, this implies:
$$y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1).$$
If $f(x) = 1/x$, we have $\frac{y_1}{y_1/x + 1} = \frac{y_2}{y_2/x + 1}$, which simplifies to $\frac{y_1 x}{y_1 + x} = \frac{y_2 x}{y_2 + x}$. Cross-multiplying gives $y_1 x(y_2 + x) = y_2 x(y_1 + x) \implies y_1 y_2 x + y_1 x^2 = y_2 y_1 x + y_2 x^2 \implies y_1 = y_2$.
In the general case, if $f$ were not injective, there would exist $y_1 \neq y_2$ such that $f(u+a) = f(v+a)$ for all $a$ in the range of $f$, where $u=1/y_1, v=1/y_2$. This suggests a periodicity that contradicts the asymptotic behavior of the equation. Specifically, if $f$ is periodic for $z > \inf \text{Range}(f)$, the growth of $y f(yf(x)+1)$ as $y \to \infty$ would contradict the boundedness or periodicity of the RHS $f(1/x + f(y))$. Thus, $f$ must be injective.

**3. Solving for $f$**
Let $f(1) = c$. Setting $y=1$ in the original equation:
$$f(f(x)+1) = f\left(\frac{1}{x} + c\right).$$
Since $f$ is injective:
$$f(x) + 1 = \frac{1}{x} + c \implies f(x) = \frac{1}{x} + (c-1).$$
Let $k = c-1$. We substitute $f(x) = \frac{1}{x} + k$ back into the original equation:
$$y \left( \frac{1}{y(\frac{1}{x} + k) + 1} + k \right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + k} + k.$$
Simplifying the LHS:
$$y \left( \frac{1}{\frac{y}{x} + yk + 1} + k \right) = \frac{y}{\frac{y+xyk+x}{x}} + yk = \frac{xy}{y + xyk + x} + yk.$$
Simplifying the RHS:
$$\frac{1}{\frac{y+x+xyk}{xy}} + k = \frac{xy}{y + x + xyk} + k.$$
Equating the two:
$$\frac{xy}{y + x + xyk} + yk = \frac{xy}{y + x + xyk} + k \implies yk = k \implies k(y-1) = 0.$$
Since this must hold for all $y \in \mathbb{R}^+$, we must have $k = 0$.
Thus, $c-1 = 0 \implies c=1$ and $f(x) = \frac{1}{x}$.

**Final Verification**
Substitute $f(x) = 1/x$ into $yf(yf(x)+1) = f(1/x + f(y))$:
LHS: $y f(y/x + 1) = y \frac{1}{y/x + 1} = \frac{y}{(y+x)/x} = \frac{xy}{x+y}$.
RHS: $f(1/x + 1/y) = \frac{1}{1/x + 1/y} = \frac{1}{(x+y)/xy} = \frac{xy}{x+y}$.
The equality holds for all $x, y \in \mathbb{R}^+$.

The only function satisfying the condition is $f(x) = \frac{1}{x}$.

\(\square\)
