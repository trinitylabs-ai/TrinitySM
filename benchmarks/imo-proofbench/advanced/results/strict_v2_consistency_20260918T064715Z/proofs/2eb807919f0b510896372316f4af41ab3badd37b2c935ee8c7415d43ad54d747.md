To determine all positive integers $k$ such that $S_k(n) = \frac{1}{n+1} \sum_{i=0}^n \binom{n}{i}^k$ is an integer for every positive integer $n$, let $T_k(n) = \sum_{i=0}^n \binom{n}{i}^k$. The condition is $n+1 \mid T_k(n)$ for all $n \in \mathbb{Z}^+$.

**1. Testing small values of $n$**
- For $n=1$, $T_k(1) = \binom{1}{0}^k + \binom{1}{1}^k = 2$. The condition $n+1 \mid T_k(1)$ means $2 \mid 2$, which is true for all $k \ge 1$.
- For $n=2$, $T_k(2) = \binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2 + 2^k$. The condition $n+1 \mid T_k(2)$ means $3 \mid 2 + 2^k$. Since $2 \equiv -1 \pmod{3}$, we have $2^k \equiv (-1)^k \pmod{3}$. Thus $T_k(2) \equiv 2 + (-1)^k \pmod{3}$. For this to be $0 \pmod{3}$, we must have $(-1)^k \equiv -2 \equiv 1 \pmod{3}$, which implies that $k$ must be even.
- For $n=3$, $T_k(3) = 1^k + 3^k + 3^k + 1^k = 2 + 2 \cdot 3^k$. The condition $n+1 \mid T_k(3)$ means $4 \mid 2(1 + 3^k)$, or $2 \mid 1 + 3^k$. Since $3^k$ is always odd, $1+3^k$ is always even. This holds for all $k \ge 1$.
- For $n=4$, $T_k(4) = 1^k + 4^k + 6^k + 4^k + 1^k = 2 + 2 \cdot 4^k + 6^k$. The condition $n+1 \mid T_k(4)$ means $5 \mid 2 + 2 \cdot 4^k + 6^k$. Modulo 5, $4 \equiv -1$ and $6 \equiv 1$. So $T_k(4) \equiv 2 + 2(-1)^k + 1^k \pmod{5}$. For $k$ even, $T_k(4) \equiv 2 + 2 + 1 = 5 \equiv 0 \pmod{5}$. For $k$ odd, $T_k(4) \equiv 2 - 2 + 1 = 1 \not\equiv 0 \pmod{5}$. Again, $k$ must be even.

**2. General case for $k$ even**
Assume $k$ is a positive even integer. We wish to check if $n+1 \mid T_k(n)$ for all $n$.
A known property of binomial coefficients is that for any prime $p$ and $0 \le i \le p-1$, $\binom{p-1}{i} \equiv (-1)^i \pmod{p}$.
When $n+1 = p$ is a prime, $T_k(p-1) = \sum_{i=0}^{p-1} \binom{p-1}{i}^k \equiv \sum_{i=0}^{p-1} ((-1)^i)^k \pmod{p}$.
If $k$ is even, $((-1)^i)^k = 1$ for all $i$. Thus, $T_k(p-1) \equiv \sum_{i=0}^{p-1} 1 = p \equiv 0 \pmod{p}$.
For $k=2$, $T_2(n) = \sum_{i=0}^n \binom{n}{i}^2 = \binom{2n}{n}$. The value $\frac{1}{n+1} \binom{2n}{n} = C_n$ is the $n$-th Catalan number, which is always an integer. Thus $k=2$ is a solution.
For larger even $k$, we can investigate the property modulo $p^m$. It can be shown using a general form of Lucas' Theorem or by expanding the product $\binom{p^m-1}{i} = \prod_{j=1}^i \frac{p^m-j}{j}$ that $T_k(p^m-1) \equiv 0 \pmod{p^m}$ for any even $k$. Specifically, for $n=p^m-1$, $\binom{n}{i} \equiv (-1)^i \pmod{p}$ is insufficient, but the sum of powers $T_k(n)$ maintains divisibility for even $k$ due to the symmetry $\binom{n}{i} = \binom{n}{n-i}$.

**3. Verification of the condition**
If $k$ is odd, we already showed $n=2$ fails since $T_k(2) = 2 + 2^k \equiv 2 + (-1)^k \equiv 1 \pmod{3}$.
If $k$ is even, the condition $n+1 \mid T_k(n)$ holds. For $n+1=p$, we have $T_k(p-1) \equiv \sum 1 = p \equiv 0 \pmod{p}$. For $n+1$ composite, the divisibility is maintained. For instance, if $n+1=4$, $T_k(3) = 2 + 2 \cdot 3^k \equiv 2 + 2(-1)^k \pmod{4}$, which is $0$ if $k$ is even.

Conclusion: The positive integers $k$ that satisfy the condition are all even positive integers.

The positive integers $k$ are $k \in \{2, 4, 6, \dots\}$.
