To find all pairs of distinct positive integers $(a, b)$ such that we can make the two numbers equal after a finite number of steps using the operations $x \mapsto x+2$ and $x \mapsto 3x$, we analyze the invariants and reachable sets of these operations.

### 1. Parity and Modulo 4 Invariance
Let $a_n$ and $b_n$ be the numbers on the blackboard after $n$ steps. Both operations preserve the parity of the number:
- $x \mapsto x+2 \implies x+2 \equiv x \pmod 2$.
- $x \mapsto 3x \implies 3x \equiv x \pmod 2$.
Thus, $a_n \equiv a \pmod 2$ and $b_n \equiv b \pmod 2$ for all $n$. For $a_n = b_n$ to be possible, we must have $a \equiv b \pmod 2$.

Next, consider the case where $a$ and $b$ are odd. We examine the numbers modulo 4:
- If $x \equiv 1 \pmod 4$, then $x+2 \equiv 3 \pmod 4$ and $3x \equiv 3 \pmod 4$.
- If $x \equiv 3 \pmod 4$, then $x+2 \equiv 1 \pmod 4$ and $3x \equiv 9 \equiv 1 \pmod 4$.
In both cases, if $x$ is odd, the operation always flips the value modulo 4. Therefore, $x_n \equiv x_0 + 2n \pmod 4$. For $a_n = b_n$, we must have $a_n \equiv b_n \pmod 4$, which implies $a + 2n \equiv b + 2n \pmod 4$, simplifying to $a \equiv b \pmod 4$.

### 2. Analysis of Even Integers
Suppose $a$ and $b$ are even. Let $a = 2X$ and $b = 2Y$ for positive integers $X, Y$. The operations on $a$ and $b$ correspond to operations on $X$ and $Y$:
- $2X \mapsto 2X+2 \iff X \mapsto X+1$.
- $2X \mapsto 3(2X) \iff X \mapsto 3X$.
Let $S_n(X, k)$ be the set of values reachable from $X$ in $n$ steps where $k$ operations are multiplications by 3. A value $M$ is in $S_n(X, k)$ if $M = 3^k X + \sum_{i=1}^{n-k} 3^{d_i}$ where $0 \le d_i \le k$.
The sum $V = \sum_{i=1}^{n-k} 3^{d_i}$ satisfies $n-k \le V \le 3^k(n-k)$ and $V \equiv n-k \pmod 2$.
For $k=1$, $V = m(3) + (n-1-m)(1) = 2m + n-1$ for $0 \le m \le n-1$, so $S_n(X, 1) = \{ 3X + V \mid n-1 \le V \le 3n-3, V \equiv n-1 \pmod 2 \}$.
For $k=0$, $S_n(X, 0) = \{ X + n \}$.
For $k=2$, $V = 8m_2 + 2m_1 + n-2$ where $m_2+m_1 \le n-2$. Note that $V=n-2$ is always reachable (by $m_2=m_1=0$).

We show that any $X, Y$ can be made equal:
- Case $X \equiv Y \pmod 2$: Pick $k_X=1, k_Y=1$. We seek $3X + V_X = 3Y + V_Y$, or $V_Y - V_X = 3X - 3Y$. Since $X \equiv Y \pmod 2$, $3X-3Y$ is even. For sufficiently large $n$, the range of $V_Y - V_X$, which is $[(n-1)-(3n-3), (3n-3)-(n-1)] = [-2n+2, 2n-2]$, contains $3X-3Y$. Since $V_X, V_Y$ have the same parity $n-1$, their difference is always even, and all even values in the range are reachable.
- Case $X \not\equiv Y \pmod 2$: Pick $k_X=2, k_Y=1$. We seek $9X + V_X = 3Y + V_Y$, or $V_Y - V_X = 9X - 3Y$.
The parity of $V_Y - V_X$ is $(n-1) - (n-2) = 1 \pmod 2$. Since $X \not\equiv Y \pmod 2$, $9X - 3Y$ is odd.
If $9X - 3Y \ge 1$, pick $V_X = n-2$. Then $V_Y = 9X - 3Y + n-2$. For large $n$, $V_Y \in [n-1, 3n-3]$ and $V_Y \equiv n-1 \pmod 2$, so $V_Y \in S_n(Y, 1)$.
If $9X - 3Y < 1$, pick $V_Y = n-1$. Then $V_X = n-1 - (9X - 3Y) = n-1 + 3Y - 9X$. For large $n$, $V_X \in [n-2, 9(n-2)]$ and $V_X \equiv n \pmod 2$. Since $V_X - (n-2) = 3Y - 9X + 1$ is a fixed even integer, we can pick $m_2=0$ and $m_1 = (3Y-9X+1)/2$, which satisfies $m_2+m_1 \le n-2$ for large $n$.
Thus, all even pairs work.

### 3. Analysis of Odd Integers
Suppose $a$ and $b$ are odd. Let $a = 2X+1$ and $b = 2Y+1$. The operations are:
- $2X+1 \mapsto 2X+3 \iff X \mapsto X+1$.
- $2X+1 \mapsto 3(2X+1) = 2(3X+1)+1 \iff X \mapsto 3X+1$.
The value after $n$ steps with $k$ multiplications is $X_n = 3^k X + \frac{3^k-1}{2} + \sum_{i=1}^{n-k} 3^{d_i}$.
For $k=1$, $X_n = 3X + 1 + V$ where $V \in [n-1, 3n-3]$ and $V \equiv n-1 \pmod 2$.
If $a \equiv b \pmod 4$, then $2X+1 \equiv 2Y+1 \pmod 4 \implies X \equiv Y \pmod 2$.
Using $k_X=1, k_Y=1$, we seek $3X + 1 + V_X = 3Y + 1 + V_Y \implies V_Y - V_X = 3X - 3Y$.
As in the even case, since $X \equiv Y \pmod 2$, this is possible for large $n$.
If $a \not\equiv b \pmod 4$, the modulo 4 analysis in Section 1 shows they can never be equal.

The pairs $(a, b)$ are those such that $a, b$ are both even, or $a, b$ are both odd and $a \equiv b \pmod 4$.
