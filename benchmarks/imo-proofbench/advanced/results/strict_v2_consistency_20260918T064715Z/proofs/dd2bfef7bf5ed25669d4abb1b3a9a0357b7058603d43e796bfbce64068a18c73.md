To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows.

**1. Testing a candidate solution**
We test the function $f(x) = \frac{1}{x}$.
The left-hand side (LHS) of the equation becomes:
$$yf\left(y \cdot \frac{1}{x} + 1\right) = y \cdot \frac{1}{\frac{y}{x} + 1} = y \cdot \frac{x}{y+x} = \frac{xy}{x+y}.$$
The right-hand side (RHS) becomes:
$$f\left(\frac{1}{x} + \frac{1}{y}\right) = \frac{1}{\frac{1}{x} + \frac{1}{y}} = \frac{1}{\frac{x+y}{xy}} = \frac{xy}{x+y}.$$
Since LHS = RHS, $f(x) = \frac{1}{x}$ is a solution.

**2. Deriving functional properties**
Let $f(1) = a$ for some $a \in \mathbb{R}^+$.
Setting $x=1$ in the original equation:
$$yf(yf(1)+1) = f(1+f(y)) \implies yf(ay+1) = f(f(y)+1). \quad (1)$$
Setting $y=1$ in the original equation:
$$1 \cdot f(1 \cdot f(x)+1) = f\left(\frac{1}{x} + f(1)\right) \implies f(f(x)+1) = f\left(\frac{1}{x} + a\right). \quad (2)$$
Combining (1) and (2), we replace $y$ with $x$ in (1) to get $f(f(x)+1) = xf(ax+1)$. Thus:
$$xf(ax+1) = f\left(\frac{1}{x} + a\right). \quad (3)$$

**3. Proving injectivity**
Suppose $f(y_1) = f(y_2)$ for some $y_1, y_2 \in \mathbb{R}^+$. Then $f(\frac{1}{x} + f(y_1)) = f(\frac{1}{x} + f(y_2))$.
Substituting this into the original equation:
$$y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1).$$
Let $f(x) = z$. Then $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$ for all $z$ in the range of $f$.
As $x \to \infty$, if $f(x)$ approaches a limit $L$, the original equation $f(\frac{1}{x} + f(y)) = y f(y f(x) + 1)$ implies that $f(f(y)) = y f(yL+1)$ (assuming continuity). If $L > 0$, then as $y \to \infty$, $f(f(y)) \to \infty$, which implies $f(y) \to \infty$ as $y \to \infty$, contradicting $f(x) \to L$. Thus $L=0$.
If $L=0$, then $f(f(y)) = y f(1) = ay$. Since $a > 0$, $f(f(y))$ is a linear function, which implies $f$ is a bijection and therefore injective.

**4. Solving for $f(x)$**
Using the injectivity of $f$ in equation (2):
$$f(f(x)+1) = f\left(\frac{1}{x} + a\right) \implies f(x) + 1 = \frac{1}{x} + a \implies f(x) = \frac{1}{x} + a - 1.$$
We substitute this form back into the original equation:
$$y f\left(y\left(\frac{1}{x} + a - 1\right) + 1\right) = f\left(\frac{1}{x} + \frac{1}{y} + a - 1\right)$$
$$y \left( \frac{1}{\frac{y}{x} + y(a-1) + 1} + a - 1 \right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + a - 1} + a - 1$$
$$\frac{y}{\frac{y + x y(a-1) + x}{x}} + y(a-1) = \frac{1}{\frac{y + x + xy(a-1)}{xy}} + a - 1$$
$$\frac{xy}{x + y + xy(a-1)} + y(a-1) = \frac{xy}{x + y + xy(a-1)} + a - 1.$$
This simplifies to $y(a-1) = a-1$ for all $y \in \mathbb{R}^+$, which requires $a-1 = 0$, so $a=1$.
Substituting $a=1$ into $f(x) = \frac{1}{x} + a - 1$, we obtain $f(x) = \frac{1}{x}$.

The only function $f: \mathbb{R}^+ \to \mathbb{R}^+$ satisfying the equation is $f(x) = \frac{1}{x}$.

\(\square\)
