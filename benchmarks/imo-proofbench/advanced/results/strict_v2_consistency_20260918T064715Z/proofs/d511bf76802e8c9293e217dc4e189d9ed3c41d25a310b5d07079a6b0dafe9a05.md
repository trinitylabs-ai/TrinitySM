To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Monotonicity and Injectivity**
Suppose $f$ is not injective. Then there exist $y_1, y_2 \in \mathbb{R}^+$ such that $f(y_1) = f(y_2)$ with $y_1 < y_2$. For any $x \in \mathbb{R}^+$, the right-hand side of the original equation is the same for $y_1$ and $y_2$, implying:
$$y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1)$$
Let $z = f(x)$. For all $z$ in the range of $f$, we have $f(y_1 z + 1) = \frac{y_2}{y_1} f(y_2 z + 1)$. Since $\frac{y_2}{y_1} > 1$ and $f(y) > 0$, it follows that $f(y_1 z + 1) > f(y_2 z + 1)$. Since $y_1 z + 1 < y_2 z + 1$ for all $z \in \text{Ran}(f)$, and the set $\{yz+1 : y \in \mathbb{R}^+, z \in \text{Ran}(f)\}$ covers the interval $(1, \infty)$, $f$ must be strictly decreasing on $(1, \infty)$.

Since $f$ is strictly decreasing on $(1, \infty)$, the limit $L = \lim_{x \to \infty} f(x)$ exists and $L \ge 0$. For any monotonic function, the right-hand limit $f(t^+) = \lim_{h \to 0^+} f(t+h)$ exists for all $t$. Taking the limit as $x \to \infty$ in the original equation:
$$\lim_{x \to \infty} y f(yf(x)+1) = \lim_{x \to \infty} f\left(\frac{1}{x} + f(y)\right) \implies y f((yL+1)^+) = f(f(y)^+)$$
Suppose $L > 0$. As $y \to \infty$, the left-hand side $y f((yL+1)^+) \ge y L \to \infty$. However, since $f$ is strictly decreasing on $(1, \infty)$ and $f(y) \to L$, the right-hand side $f(f(y)^+) \to f(L^+)$, which is a constant. This is a contradiction, so we must have $L = 0$.

Taking the limit as $x \to \infty$ again with $L = 0$:
$$y f(1^+) = f(f(y)^+)$$
Let $f(1^+) = a$. Then $f(f(y)^+) = ay$. Since the function $g(y) = ay$ is continuous and strictly increasing, and $f$ is monotonic on $(1, \infty)$, $f$ cannot have any jump discontinuities; otherwise, $f(f(y)^+)$ would be constant on some intervals or exhibit jumps. Thus, $f$ is continuous on $\mathbb{R}^+$, and we have $f(f(y)) = ay$. This implies $f$ is a bijection from $\mathbb{R}^+$ to $\mathbb{R}^+$, and thus $f$ is injective, contradicting our initial assumption. Therefore, $f$ must be injective on $\mathbb{R}^+$.

**2. Functional Form**
Since $f$ is injective and $f(f(y)) = ay$ for $a = f(1)$, we substitute $y=1$ into the original equation:
$$1 \cdot f(1 \cdot f(x) + 1) = f\left(\frac{1}{x} + f(1)\right) \implies f(f(x)+1) = f\left(\frac{1}{x} + a\right)$$
Since $f$ is injective, we have:
$$f(x) + 1 = \frac{1}{x} + a \implies f(x) = \frac{1}{x} + a - 1$$
Let $k = a - 1$. Then $f(x) = \frac{1}{x} + k$. Substituting this back into the original equation:
$$y \left( \frac{1}{y(\frac{1}{x} + k) + 1} + k \right) = \frac{1}{\frac{1}{x} + (\frac{1}{y} + k)} + k$$
$$\frac{yx}{y + ykx + x} + yk = \frac{xy}{y + x + kxy} + k$$
For this to hold for all $y \in \mathbb{R}^+$, the fractions $\frac{xy}{x + y + ykx}$ and $\frac{xy}{x + y + kxy}$ must be equal, and we require:
$$yk = k \implies k(y-1) = 0$$
Since this must hold for all $y$, we must have $k = 0$. Then $a - 1 = 0 \implies a = 1$, and $f(x) = \frac{1}{x}$.

**3. Verification**
Substitute $f(x) = \frac{1}{x}$ into the original equation:
LHS: $y f(y \frac{1}{x} + 1) = y \frac{1}{\frac{y}{x} + 1} = y \frac{x}{y + x} = \frac{xy}{x + y}$
RHS: $f(\frac{1}{x} + \frac{1}{y}) = \frac{1}{\frac{1}{x} + \frac{1}{y}} = \frac{1}{\frac{x+y}{xy}} = \frac{xy}{x + y}$
The LHS equals the RHS for all $x, y \in \mathbb{R}^+$.

The only function satisfying the given condition is $f(x) = \frac{1}{x}$.

\(\square\)
