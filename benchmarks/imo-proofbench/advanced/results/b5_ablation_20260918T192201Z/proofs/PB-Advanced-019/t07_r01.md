To find all positive real numbers $r$ such that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$, we begin by simplifying the given expression.

The function $A(r)$ is defined as the fractional part of $2r$, which is $A(r) = \{2r\} = 2r - \lfloor 2r \rfloor$. The sum $B(n,r)$ is given by
$$ B(n,r) = \sum_{k=1}^n A(kr) = \sum_{k=1}^n \{2kr\} = \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor). $$
Substituting this into the expression $C(n,r) = n(n+1)r - B(n,r)$, we have
$$ C(n,r) = n(n+1)r - \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor) = n(n+1)r - 2r \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor 2kr \rfloor = \sum_{k=1}^n \lfloor 2kr \rfloor. $$
The condition is that $C(n,r)$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$. Let $x = 2r$. The condition becomes:
$$ S_n = \sum_{k=1}^n \lfloor kx \rfloor \equiv 0 \pmod n \quad \text{for all } n \in \mathbb{Z}^+. $$
For $n=1$, $S_1 = \lfloor x \rfloor \equiv 0 \pmod 1$, which is always true.
For $n=2$, $S_2 = \lfloor x \rfloor + \lfloor 2x \rfloor \equiv 0 \pmod 2$.
Let $x = m + \epsilon$, where $m = \lfloor x \rfloor$ and $0 \le \epsilon < 1$.
Then $\lfloor 2x \rfloor = 2m + \lfloor 2\epsilon \rfloor$.
$S_2 = m + 2m + \lfloor 2\epsilon \rfloor = 3m + \lfloor 2\epsilon \rfloor \equiv m + \lfloor 2\epsilon \rfloor \equiv 0 \pmod 2$.
Thus, $m \equiv \lfloor 2\epsilon \rfloor \pmod 2$.
For $n=3$, $S_3 = \lfloor x \rfloor + \lfloor 2x \rfloor + \lfloor 3x \rfloor = m + (2m + \lfloor 2\epsilon \rfloor) + (3m + \lfloor 3\epsilon \rfloor) = 6m + \lfloor 2\epsilon \rfloor + \lfloor 3\epsilon \rfloor \equiv 0 \pmod 3$.
This implies $\lfloor 2\epsilon \rfloor + \lfloor 3\epsilon \rfloor \equiv 0 \pmod 3$.
Since $0 \le \epsilon < 1$, $0 \le \lfloor 2\epsilon \rfloor \le 1$ and $0 \le \lfloor 3\epsilon \rfloor \le 2$.
The sum $\lfloor 2\epsilon \rfloor + \lfloor 3\epsilon \rfloor$ can be $0, 1, 2, 3$.
Case 1: $\lfloor 2\epsilon \rfloor + \lfloor 3\epsilon \rfloor = 0 \implies \lfloor 2\epsilon \rfloor = 0$ and $\lfloor 3\epsilon \rfloor = 0$, so $0 \le \epsilon < 1/3$.
Since $m \equiv \lfloor 2\epsilon \rfloor \pmod 2$, $m$ must be even.
Case 2: $\lfloor 2\epsilon \rfloor + \lfloor 3\epsilon \rfloor = 3 \implies \lfloor 2\epsilon \rfloor = 1$ and $\lfloor 3\epsilon \rfloor = 2$, so $2/3 \le \epsilon < 1$.
Since $m \equiv \lfloor 2\epsilon \rfloor \pmod 2$, $m$ must be odd.

Now consider $n=4$. $S_4 = S_3 + \lfloor 4x \rfloor = S_3 + 4m + \lfloor 4\epsilon \rfloor \equiv 0 \pmod 4$.
In Case 1 ($m$ even, $0 \le \epsilon < 1/3$): $S_3 = 6m + 0 + 0 = 6m$.
$6m + 4m + \lfloor 4\epsilon \rfloor = 10m + \lfloor 4\epsilon \rfloor \equiv 2m + \lfloor 4\epsilon \rfloor \equiv 0 \pmod 4$.
Since $m$ is even, $2m \equiv 0 \pmod 4$ only if $m$ is a multiple of 2 (already known).
Thus $\lfloor 4\epsilon \rfloor \equiv 0 \pmod 4$. Since $0 \le 4\epsilon < 4/3$, $\lfloor 4\epsilon \rfloor = 0$, so $0 \le \epsilon < 1/4$.
In Case 2 ($m$ odd, $2/3 \le \epsilon < 1$): $S_3 = 6m + 1 + 2 = 6m + 3$.
$6m + 3 + 4m + \lfloor 4\epsilon \rfloor = 10m + 3 + \lfloor 4\epsilon \rfloor \equiv 2m + 3 + \lfloor 4\epsilon \rfloor \equiv 2 + 3 + \lfloor 4\epsilon \rfloor \equiv 1 + \lfloor 4\epsilon \rfloor \equiv 0 \pmod 4$.
Thus $\lfloor 4\epsilon \rfloor \equiv 3 \pmod 4$. Since $8/3 \le 4\epsilon < 4$, $\lfloor 4\epsilon \rfloor = 3$, so $3/4 \le \epsilon < 1$.

Repeating this process for $n=5, 6, \dots$, we find that in Case 1, $\lfloor n\epsilon \rfloor = 0$ for all $n$, which implies $\epsilon = 0$. In Case 2, $\lfloor n\epsilon \rfloor = n-1$ for all $n$, which implies $\epsilon = 1$, but $\epsilon < 1$.
Thus, $x$ must be an integer. If $x$ is an integer, $S_n = x \frac{n(n+1)}{2}$.
For $S_n/n = \frac{x(n+1)}{2}$ to be an integer for all $n$, $x$ must be an even integer.
$x = 2r \implies 2r = 2k$ for some positive integer $k$, so $r = k$.

The positive real numbers $r$ are the positive integers.
