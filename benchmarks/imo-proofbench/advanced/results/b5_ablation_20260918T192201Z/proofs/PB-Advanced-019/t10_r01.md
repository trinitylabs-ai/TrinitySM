To find all positive real numbers $r$ such that $n(n+1)r - B(n, r)$ is a multiple of $n$ for all positive integers $n$, we begin by simplifying the expression $n(n+1)r - B(n, r)$.

Recall that $A(r)$ is the fractional part of $2r$, denoted by $\{2r\}$, and $B(n, r) = \sum_{k=1}^n A(kr) = \sum_{k=1}^n \{2kr\}$. We use the identity $\{x\} = x - \lfloor x \rfloor$:
$$
n(n+1)r - B(n, r) = n(n+1)r - \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor) = n(n+1)r - 2r \sum_{k=1}^n k + \sum_{k=1}^n \lfloor 2kr \rfloor
$$
Using the formula $\sum_{k=1}^n k = \frac{n(n+1)}{2}$, we have:
$$
n(n+1)r - B(n, r) = n(n+1)r - 2r \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor 2kr \rfloor = \sum_{k=1}^n \lfloor 2kr \rfloor
$$
The condition given is that $S_n = \sum_{k=1}^n \lfloor kx \rfloor$ is a multiple of $n$ for all $n \ge 1$, where $x = 2r$. Let $a_n = S_n/n$. The condition is that $a_n \in \mathbb{Z}$ for all $n \in \mathbb{Z}^+$.

If $x$ is an integer, say $x = m$, then $S_n = \sum_{k=1}^n km = m \frac{n(n+1)}{2}$. Thus $a_n = \frac{m(n+1)}{2}$. For $a_n$ to be an integer for all $n$, $m(n+1)$ must be even for all $n$. For $n=2$, $3m$ must be even, implying $m$ is even. If $m = 2k$ for some integer $k$, then $a_n = k(n+1)$, which is always an integer. Since $x = 2r = 2k$, we have $r = k$ for any positive integer $k$.

Now we consider the case where $x$ is not an integer. We examine the difference $d_n = a_{n+1} - a_n$:
$$
d_n = \frac{S_{n+1}}{n+1} - \frac{S_n}{n} = \frac{n(S_n + \lfloor (n+1)x \rfloor) - (n+1)S_n}{n(n+1)} = \frac{n\lfloor (n+1)x \rfloor - S_n}{n(n+1)}
$$
Rearranging gives $S_n = n\lfloor (n+1)x \rfloor - n(n+1)d_n$. Also $S_{n+1} = S_n + \lfloor (n+1)x \rfloor$. Substituting the expression for $S_n$:
$$
(n+1)a_{n+1} = n\lfloor (n+1)x \rfloor - n(n+1)d_n + \lfloor (n+1)x \rfloor = (n+1)\lfloor (n+1)x \rfloor - n(n+1)d_n
$$
Dividing by $n+1$, we obtain $a_{n+1} = \lfloor (n+1)x \rfloor - nd_n$. Then:
$$
d_{n+1} = a_{n+2} - a_{n+1} = \frac{n+1}{n+2} a_{n+1} + \frac{\lfloor (n+2)x \rfloor}{n+2} - a_{n+1} = \frac{\lfloor (n+2)x \rfloor - a_{n+1}}{n+2}
$$
For $d_{n+1}$ to be an integer, $n+2$ must divide $\lfloor (n+2)x \rfloor - a_{n+1}$. As $n \to \infty$, if $x$ is not an integer, the sequence $v_n = \lfloor (n+1)x \rfloor - \lfloor nx \rfloor$ alternates between $\lfloor x \rfloor$ and $\lfloor x \rfloor + 1$. Specifically, $d_n - d_{n-1} = \frac{v_n - 2d_{n-1}}{n+1}$. For this to be an integer for all $n$, we must have $v_n = 2d_{n-1}$ for sufficiently large $n$. However, $v_n$ is not constant unless $x$ is an integer, creating a contradiction.

Thus, $x$ must be an even integer, meaning $2r = 2k$, so $r$ must be a positive integer. Checking $r=k$ for any $k \in \mathbb{Z}^+$, $S_n = \sum_{k=1}^n 2jk = jn(n+1)$, which is always a multiple of $n$.

The positive real numbers $r$ are the positive integers.
