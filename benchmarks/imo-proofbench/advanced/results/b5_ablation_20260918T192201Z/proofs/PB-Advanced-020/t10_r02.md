To find all pairs $(x, y)$ of positive integers such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we begin by simplifying the general term $a_n$.

The sequence is defined as
$$a_n = \gcd \left( x^n + y, (y-x)\left(\sum_{i=0}^{n-1} y^i x^{n-i-1} - 1\right) \right)$$
If $x = y$, then $y-x = 0$, so $a_n = \gcd(x^n + x, 0) = x^n + x$. For the limit of $a_n$ to exist, $x^n + x$ must be constant for all $n \ge 1$. This happens if and only if $x = 1$. Thus, $(x, y) = (1, 1)$ is a solution.

If $x \neq y$, the sum is a geometric series: $\sum_{i=0}^{n-1} y^i x^{n-i-1} = \frac{y^n - x^n}{y-x}$. Substituting this into the formula for $a_n$:
$$a_n = \gcd \left( x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) \right) = \gcd(x^n + y, y^n - x^n - y + x)$$
Note that $y^n - x^n - y + x = (y^n + x) - (x^n + y)$. Therefore,
$$a_n = \gcd(x^n + y, (y^n + x) - (x^n + y)) = \gcd(x^n + y, y^n + x)$$
If $x = 1$ and $y > 1$, then $a_n = \gcd(1+y, y^n+1)$. For $n=1$, $a_1 = y+1$. For $n=2$, $a_2 = \gcd(y+1, y^2+1) = \gcd(y+1, (y+1)(y-1) + 2) = \gcd(y+1, 2)$. The limit exists only if $y+1 = \gcd(y+1, 2)$, implying $y+1$ divides 2, so $y=1$, which contradicts $y > 1$. Similarly, if $y = 1$ and $x > 1$, there are no solutions.

Now consider $x, y > 1$ and $x \neq y$. If the limit $\lim_{n \to \infty} a_n = L$ exists, then $a_n = L$ for all $n \ge N$. This implies $L$ must divide $x^n + y$ and $x^{n+1} + y$ for $n \ge N$, so $L | (x^{n+1} + y) - (x^n + y) = x^n(x-1)$. Similarly, $L | y^n(y-1)$. Let $p$ be a prime factor of $L$. If $p | x$, then $p | (x^n + y) \implies p | y$. If $p \nmid x$, then $p | x-1$. Likewise, $p$ must either divide $y$ (and thus $x$) or $y-1$. 
If $p | \gcd(x, y)$, the power of $p$ dividing $a_n$ becomes constant for $n \ge \max(v_p(x), v_p(y))$, specifically $v_p(a_n) = v_p(\gcd(x, y))$.
If $p \nmid \gcd(x, y)$, then $p$ must divide $\gcd(x-1, y-1)$. Then $x \equiv 1 \pmod p$ and $y \equiv 1 \pmod p$, so $x^n + y \equiv 1^n + 1 = 2 \pmod p$. For $p$ to divide $a_n$, we must have $p = 2$. This implies $x$ and $y$ are both odd.
For $v_2(a_n) = \min(v_2(x^n + y), v_2(y^n + x))$ to be constant, we need $x \equiv 1 \pmod 4$ and $y \equiv 1 \pmod 4$. If either is $3 \pmod 4$, $v_2(a_n)$ alternates. 
However, even if $x, y \equiv 1 \pmod 4$, any prime $p \nmid 2\gcd(x, y)$ that divides $a_{n_0}$ for some $n_0$ will also divide $a_n$ for all $n \equiv n_0 \pmod{\text{ord}_p(xy)}$. For $a_n$ to be eventually constant, no such $p$ can exist. But for $x \neq y$, such $p$ typically exist (e.g., $x=5, y=9 \implies a_1=14, a_7= \dots$). In fact, the only way to avoid this is if $x=y=1$.

Thus, the only pair of positive integers $(x, y)$ such that the limit exists is $(1, 1)$.

\(\square\)
