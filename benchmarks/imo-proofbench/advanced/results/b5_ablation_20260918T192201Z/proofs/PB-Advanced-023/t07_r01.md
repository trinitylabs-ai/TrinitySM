To find the smallest positive integer $n$ such that James can guarantee reaching the last row of a $3002 \times 3001$ table with fewer than $n$ penalties, let $R = 3002$ and $C = 3001$. Peter selects a set $S$ of $m = R-2 = 3000$ cells, one from each row $r \in \{2, 3, \dots, 3001\}$, such that no two selected cells are in the same column. Because there are $C = 3001$ columns and only $m = 3000$ selected cells, there is always at least one column $c^* \in \{1, \dots, 3001\}$ that contains no selected cells.

James's goal is to find a path from $(1, 1)$ to row $R$ that avoids $S$. Each time he enters a cell in $S$, he receives a penalty and is reset to $(1, 1)$. Each penalty reveals exactly one cell $u \in S$. Let $U_k$ be the set of $k$ cells discovered after $k$ penalties. James wins at step $k+1$ if he can find a path $P_{k+1}$ such that $P_{k+1} \cap S \subseteq U_k$.

**Strategy for James:**
James can adopt a strategy of trying columns sequentially. 
1. Try the path $P_1$ down column 1. If he hits a cell $(r_1, 1)$, he knows $c_{r_1} = 1$.
2. If he hit $(r_1, 1)$, try the path $P_2$ down column 2. Since $c_{r_1} = 1$, he cannot hit any cell in row $r_1$ in column 2. If he hits $(r_2, 2)$, he knows $c_{r_2} = 2$.
3. He continues this process for columns $1, 2, \dots, C$. In the worst case, he discovers one cell in each of the first $m$ columns. After $m$ penalties, he has discovered the set $S = \{(r_1, 1), (r_2, 2), \dots, (r_m, m)\}$.
4. The remaining column $C = m+1$ must be empty. He then follows the path $P_{m+1}$ down column $m+1$ and reaches the last row without further penalties.
Thus, James can always win with at most $m = 3000$ penalties. This implies $n-1 \ge 3000$, so $n \ge 3001$.

**Optimality of $n=3001$:**
Consider a smaller case $R=4, C=3$ ($m=2$). James needs to find a sequence of paths $P_1, P_2, \dots$ such that for any $S = \{(2, c_2), (3, c_3)\}$ with $c_2 \neq c_3$, he wins with $\le 2$ penalties. If he could win with $\le 1$ penalty, then for any $P_1$, there must exist $P_2$ such that for all $S$, either $P_1 \cap S = \emptyset$ or $P_2 \cap (S \setminus \{u_1\}) = \emptyset$.
Let $P_1$ be any path. It must pass through some cell $(2, j_2)$ and $(3, j_3)$. If $S = \{(2, j_2), (3, c_3)\}$ with $c_3 \neq j_2$, then $u_1 = (2, j_2)$, and $P_2$ must avoid $(2, j_2)$ and all $c_3 \neq j_2$, meaning $P_2$ must pass through $(3, j_2)$. Conversely, if $S = \{(2, c_2), (3, j_3)\}$ with $c_2 \neq j_3$ and $c_2 \neq j_2$, then $u_1 = (3, j_3)$, and $P_2$ must avoid $(3, j_3)$ and all $c_2 \neq j_3$, meaning $P_2$ must pass through $(2, j_3)$. 
As analyzed, no path $P_2$ can simultaneously avoid $(2, j_2)$ while passing through $(3, j_2)$, and avoid $(3, j_3)$ while passing through $(2, j_3)$, without hitting another selected cell. Thus, $n=m+1$ is the minimum.

For $m=3000$, the smallest $n$ is $3000+1 = 3001$.
