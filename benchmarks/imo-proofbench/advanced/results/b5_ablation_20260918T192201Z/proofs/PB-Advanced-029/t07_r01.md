To determine all positive integers $k$ such that $S_k(n) = \frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^k$ is an integer for every positive integer $n$, we analyze the condition $A_k(n) = \sum_{i=0}^{n} \binom{n}{i}^k \equiv 0 \pmod{n+1}$.

**1. Testing small values of $n$**
For $n=1$, $A_k(1) = \binom{1}{0}^k + \binom{1}{1}^k = 1^k + 1^k = 2$.
The condition $A_k(1) \equiv 0 \pmod 2$ is $2 \equiv 0 \pmod 2$, which is true for all $k \ge 1$.
For $n=2$, $A_k(2) = \binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2 + 2^k$.
The condition $A_k(2) \equiv 0 \pmod 3$ requires $2 + 2^k \equiv 0 \pmod 3$, which means $2^k \equiv -2 \equiv 1 \pmod 3$.
This occurs if and only if $k$ is even.

**2. Verifying $k=2$**
For $k=2$, $A_2(n) = \sum_{i=0}^n \binom{n}{i}^2 = \binom{2n}{n}$.
The expression $S_2(n) = \frac{1}{n+1} \binom{2n}{n}$ is the $n$-th Catalan number $C_n$, which is known to be an integer for all $n \ge 0$. Thus, $k=2$ is a solution.

**3. Analyzing even $k$**
Let $k$ be any even positive integer. We want to check if $A_k(n) = \sum_{i=0}^n \binom{n}{i}^k \equiv 0 \pmod{n+1}$.
Consider $n+1 = p$ where $p$ is a prime.
By the property $\binom{p-1}{i} \equiv (-1)^i \pmod p$, we have:
\[ A_k(p-1) = \sum_{i=0}^{p-1} \binom{p-1}{i}^k \equiv \sum_{i=0}^{p-1} ((-1)^i)^k \pmod p \]
Since $k$ is even, $((-1)^i)^k = 1$ for all $i$. Thus,
\[ A_k(p-1) \equiv \sum_{i=0}^{p-1} 1 = p \equiv 0 \pmod p \]
This shows the condition holds for all prime $n+1$.
For composite $n+1 = m$, we examine the sum $A_k(m-1) = \sum_{i=0}^{m-1} \binom{m-1}{i}^k \pmod m$.
Using the identity $\binom{m-1}{i} = \prod_{j=1}^i \frac{m-j}{j}$, we observe that in the ring of $p$-adic integers $\mathbb{Z}_p$ for any prime $p|m$, $\binom{m-1}{i} = (-1)^i \prod_{j=1}^i (1 - \frac{m}{j})$.
Since $k$ is even, $\binom{m-1}{i}^k = \prod_{j=1}^i (1 - \frac{m}{j})^k \equiv 1 - k \sum_{j=1}^i \frac{m}{j} \pmod{m^2}$.
Summing over $i$:
\[ A_k(m-1) \equiv \sum_{i=0}^{m-1} \left( 1 - km \sum_{j=1}^i \frac{1}{j} \right) = m - km \sum_{j=1}^{m-1} \frac{m-j}{j} = m - km \left( m \sum_{j=1}^{m-1} \frac{1}{j} - (m-1) \right) \]
\[ A_k(m-1) \equiv m - km^2 \sum \frac{1}{j} + km(m-1) \equiv m - km \equiv m(1-k) \pmod{m^2} \]
Since $m(1-k)$ is always a multiple of $m$, we have $A_k(m-1) \equiv 0 \pmod m$.

**4. Conclusion**
The condition $S_k(n) \in \mathbb{Z}$ for all $n \ge 1$ requires $k$ to be even. Our tests and the derived modular property suggest that all even positive integers $k$ satisfy the condition.

The positive integers $k$ are all even positive integers.

All even positive integers $k$. \(\square\)
