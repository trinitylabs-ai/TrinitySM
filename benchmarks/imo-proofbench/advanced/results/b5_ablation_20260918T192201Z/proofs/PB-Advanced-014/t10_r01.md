To determine all pairs of distinct positive integers $(a, b)$ such that we can make them equal through the given operations, we analyze the conditions under which the two numbers can be made equal.

### 1. Necessary Condition: Parity
Let $a_n$ and $b_n$ be the numbers on the blackboard after $n$ steps. The available operations for any number $x$ are $f_1(x) = x + 2$ and $f_2(x) = 3x$. We observe the effect of these operations on the parity of the numbers:
- $x + 2 \equiv x \pmod 2$
- $3x \equiv x \pmod 2$
In both cases, the parity of the number remains invariant. Therefore, $a_n \equiv a_0 \pmod 2$ and $b_n \equiv b_0 \pmod 2$ for all $n$. For $a_n = b_n$ to be possible, we must have $a_n \equiv b_n \pmod 2$, which implies $a \equiv b \pmod 2$. Thus, $a$ and $b$ must have the same parity.

### 2. Sufficiency of the Parity Condition
Assume $a \equiv b \pmod 2$. We wish to show that we can always make the numbers equal.
Let $a = 2A + r$ and $b = 2B + r$ where $r \in \{0, 1\}$. We define a transformed state $(A_n, B_n)$ such that $a_n = 2A_n + r$ and $b_n = 2B_n + r$.
- If we apply $x \to x + 2$, then $2A_n + r \to 2A_n + r + 2 = 2(A_n + 1) + r$, so $A_n \to A_n + 1$.
- If we apply $x \to 3x$, then $2A_n + r \to 3(2A_n + r) = 6A_n + 3r = 2(3A_n + r) + r$ (since $3r = 2r + r$), so $A_n \to 3A_n + r$.

Now we consider the two cases for $r$:
**Case 1: $r = 0$.** The operations on $A$ and $B$ are $x \to x+1$ and $x \to 3x$.
Let $D_n = B_n - A_n$. The goal is to reach $D_n = 0$. The possible transitions for $D$ are:
- $(A+1, B+1) \implies D \to D$
- $(3A, 3B) \implies D \to 3D$
- $(3A, B+1) \implies D \to B + 1 - 3A = (A+D) + 1 - 3A = D + 1 - 2A$
- $(A+1, 3B) \implies D \to 3B - (A+1) = 3(A+D) - A - 1 = 3D + 2A - 1$

By alternating these operations, we can manipulate $D$. Since $A$ can be increased arbitrarily via $A \to A+1$, we can reach a state where $D = 2A-1$, and the operation $(3A, B+1)$ then yields $D_{new} = (2A-1) + 1 - 2A = 0$. For example, if $A=1, B=2$, then $D=1$. Applying $x \to 3x$ to $A$ and $x \to x+1$ to $B$ gives $(3, 3)$, so $D=0$.

**Case 2: $r = 1$.** The operations on $A$ and $B$ are $x \to x+1$ and $x \to 3x+1$.
The transitions for $D = B - A$ are:
- $(A+1, B+1) \implies D \to D$
- $(3A+1, 3B+1) \implies D \to 3B+1 - (3A+1) = 3D$
- $(3A+1, B+1) \implies D \to B+1 - (3A+1) = B - 3A = D - 2A$
- $(A+1, 3B+1) \implies D \to 3B+1 - (A+1) = 3B - A = 2B + D$

Similarly, these operations allow us to adjust $D$. To reach $D=0$, we can use $(3A+1, B+1)$ when $D = 2A$. For instance, if $A=1, B=3$, then $D=2$. Applying $(3A+1, B+1)$ gives $A=4, B=4$, so $D=0$.

Since we can always manipulate the difference $D$ to zero by increasing $A$ and $B$ and using the multiplicative operations to shift $D$, the condition $a \equiv b \pmod 2$ is sufficient.

The pairs $(a, b)$ such that the numbers can be made equal are those where $a$ and $b$ have the same parity.

All pairs $(a, b)$ such that $a \equiv b \pmod 2$. \(\square\)
