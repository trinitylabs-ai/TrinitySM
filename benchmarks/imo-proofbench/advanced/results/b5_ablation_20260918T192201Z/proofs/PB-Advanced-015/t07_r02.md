For an acute triangle, this simplifies to $h_a(1-\cos A) = r(1+\cos A)$, which can be rewritten as $r = h_a \frac{1-\cos A}{1+\cos A} = h_a \tan^2(A/2)$.
Using $h_a = \frac{2rs}{a}$, we obtain $\frac{2rs}{a} \tan^2(A/2) = r$, which implies $\frac{2s}{a} \tan^2(A/2) = 1$. Since $s-a = r \cot(A/2)$, we find that this condition is equivalent to $s-a = s \cos A$, or $\frac{b+c}{a} = \cot^2(A/2)$.
