To prove that for any positive integers $k$ and $d$, there exists a positive integer $N$ such that for every odd integer $n > N$, the digits of $n^k$ in base $B = 2n$ are all greater than $d$, we proceed as follows.

### 1. Determination of the Digits in Base $2n$
Let $n^k$ be represented in base $B = 2n$ as:
$$n^k = a_{m} B^m + a_{m-1} B^{m-1} + \dots + a_1 B + a_0$$
where $0 \le a_i < B$. Since $n^k = \frac{(2n)^k}{2^k} = \frac{B^k}{2^k}$, and $2^k > 1$ for $k \ge 1$, we have $n^k < B^k$. Thus, $m \le k-1$. We are interested in the digits $a_0, a_1, \dots, a_{k-1}$ (where any $a_i$ for $i > m$ are zero).

The digits of $n^k$ in base $B$ are given by the formula $a_i = \lfloor \frac{n^k}{B^i} \rfloor \pmod{B}$. Substituting $B = 2n$:
$$a_i = \left\lfloor \frac{n^k}{(2n)^i} \right\rfloor \pmod{2n} = \left\lfloor \frac{n^{k-i}}{2^i} \right\rfloor \pmod{2n}$$
For $i=0$, we have $a_0 = n^k \pmod{2n}$. Since $n$ is odd, $n^{k-1}$ is odd, so $n^{k-1} = 2m+1$ for some integer $m$. Then $n^k = n(2m+1) = m(2n) + n$, which implies $a_0 = n$.

For $i \in \{1, 2, \dots, k-1\}$, let $j = k-i$. We can rewrite the digit expression as:
$$a_{k-j} = \left\lfloor \frac{n^j}{2^{k-j}} \right\rfloor \pmod{2n}$$
Let $m_j = n^{j-1} \pmod{2^{k-j+1}}$. Since $n$ is odd, $n^{j-1}$ is odd, and thus $m_j$ is an odd integer such that $1 \le m_j < 2^{k-j+1}$. We can express $n^{j-1}$ as $n^{j-1} = q \cdot 2^{k-j+1} + m_j$. Then:
$$\frac{n^j}{2^{k-j}} = \frac{n(q \cdot 2^{k-j+1} + m_j)}{2^{k-j}} = 2nq + \frac{nm_j}{2^{k-j}}$$
Taking the floor and then the modulo $2n$:
$$a_{k-j} = \lfloor 2nq + \frac{nm_j}{2^{k-j}} \rfloor \pmod{2n} = \lfloor \frac{nm_j}{2^{k-j}} \rfloor \pmod{2n}$$
Since $m_j < 2^{k-j+1}$, we have $\frac{nm_j}{2^{k-j}} < \frac{n \cdot 2^{k-j+1}}{2^{k-j}} = 2n$. Thus, $\lfloor \frac{nm_j}{2^{k-j}} \rfloor < 2n$, and the modulo operation is trivial:
$$a_{k-j} = \left\lfloor \frac{nm_j}{2^{k-j}} \right\rfloor$$

### 2. Establishing the Lower Bound for the Digits
We need $a_i > d$ for all $i \in \{0, \dots, k-1\}$.
- For $i=0$, $a_0 = n$. For any $n > d$, $a_0 > d$.
- For $i = k-j$ where $j \in \{1, \dots, k-1\}$, we have $a_{k-j} = \lfloor \frac{nm_j}{2^{k-j}} \rfloor$.
Since $m_j \ge 1$, we have:
$$a_{k-j} \ge \left\lfloor \frac{n}{2^{k-j}} \right\rfloor$$
The smallest value of $\lfloor \frac{n}{2^{k-j}} \rfloor$ occurs when $k-j$ is maximized. For $j \in \{1, \dots, k-1\}$, the maximum value of $k-j$ is $k-1$ (at $j=1$). Thus:
$$a_i \ge a_{k-1} = \left\lfloor \frac{n}{2^{k-1}} \right\rfloor \text{ for all } i \in \{1, \dots, k-1\}$$

### 3. Selection of $N$
We require $\lfloor \frac{n}{2^{k-1}} \rfloor > d$, which is equivalent to $\lfloor \frac{n}{2^{k-1}} \rfloor \ge d+1$. This holds if:
$$\frac{n}{2^{k-1}} \ge d+1 \implies n \ge (d+1) 2^{k-1}$$
Let $N = (d+1) 2^{k-1}$. For any odd integer $n > N$, we have $n \ge N+1 \ge (d+1) 2^{k-1}$, ensuring that $a_{k-1} \ge d+1 > d$. Consequently, $a_i \ge a_{k-1} > d$ for all $i \in \{1, \dots, k-1\}$, and $a_0 = n > N > d$. Thus, all digits are greater than $d$. $\square$
