To find all functions $P: \mathbb{Q} \to \mathbb{Q}$ satisfying the equation
\[ (P(b-P(a))+a-P(b))(P(a+P(b-P(a)))-b)=0 \]
for all $a, b \in \mathbb{Q}$, let $f(a, b) = P(b-P(a)) + a - P(b)$ and $g(a, b) = P(a+P(b-P(a))) - b$. The given condition is $f(a, b) g(a, b) = 0$ for all $a, b \in \mathbb{Q}$.

First, consider the case where $f(a, b) = 0$ for all $a, b$. This implies $P(b-P(a)) = P(b) - a$. Let $P(a) = y$. Then $P(b-y) = P(b) - a$. Since this holds for all $b$, the difference $P(b-y) - P(b)$ is independent of $b$, which is a property of linear functions. Let $P(x) = cx + d$. Substituting this into $f(a, b) = 0$ gives:
\[ c(b-(ca+d)) + d + a - (cb+d) = cb - c^2 a - cd + d + a - cb - d = (1-c^2)a - cd = 0 \]
For this to hold for all $a$, we must have $c^2 = 1$ (so $c = \pm 1$) and $cd = 0$ (so $d = 0$). Thus, $P(x) = x$ or $P(x) = -x$.

Next, consider the case where $g(a, b) = 0$ for all $a, b$. This implies $P(a+P(b-P(a))) = b$. Let $b-P(a) = z$. Then $P(a+P(z)) = z + P(a)$. Setting $a=0$ gives $P(P(z)) = z + P(0)$. Let $P(z) = w$, then $P(w) = P^{-1}(w) + P(0)$, so $P^{-1}(w) = P(w) - P(0)$. Substituting this back, $P(a+w) = P(w) - P(0) + P(a)$, which is Cauchy's functional equation for $Q(x) = P(x) - P(0)$. Thus $P(x) = cx + d$. Substituting this into $g(a, b) = 0$:
\[ c(a+c(b-ca-d)+d) - b = ca + c^2 b - c^3 a - c^2 d + cd - b = (c-c^3)a + (c^2-1)b + (c-c^2)d = 0 \]
For this to hold for all $a, b$, we need $c^2=1$ and $(c-c^2)d=0$. If $c=1$, $d$ can be anything, but we must check if $P(x)=x+d$ satisfies the original equation. We found $f(a,b)=-d$ and $g(a,b)=d$, so $f \cdot g = -d^2=0$ implies $d=0$. If $c=-1$, $(c-c^2)d = (-1-1)d = -2d = 0$, so $d=0$. Thus, $P(x) = x$ or $P(x) = -x$.

If $f(a, b) g(a, b) = 0$ but neither $f$ nor $g$ is identically zero, let's test if $P$ can be a hybrid. Suppose $P(x) = \epsilon_x x$. Substituting into $f(a, b) = \epsilon_{b-\epsilon_a a}(b-\epsilon_a a) + a - \epsilon_b b$. If $\epsilon_x$ is not constant, say $\epsilon_a = 1, \epsilon_b = -1$, then $f = \epsilon_{b-a}(b-a) + a + b$. If $\epsilon_{b-a} = 1$, $f=2b$; if $\epsilon_{b-a} = -1$, $f=2a$. For $f \cdot g = 0$, we would need $g = \epsilon_{a + \epsilon_{b-a}(b-a)}(a + \epsilon_{b-a}(b-a)) - b = 0$. If $\epsilon_{b-a} = 1$, $g = \epsilon_b b - b = -2b$. If $\epsilon_{b-a} = -1$, $g = \epsilon_{2a-b}(2a-b) - b$. In the first case, $f \cdot g = (2b)(-2b) = -4b^2$, which is not zero for $b \neq 0$.

Thus, the only solutions are $P(x) = x$ and $P(x) = -x$. In both cases:
\[ P(a) + P(-a) = a + (-a) = 0 \quad \text{or} \quad P(a) + P(-a) = -a + a = 0 \]
The set $\{P(a) + P(-a) : a \in \mathbb{Q}\}$ is $\{0\}$, which is a finite set containing exactly one element. The maximum possible number of elements is 1.

The set $\{P(a)+P(-a):a\in\mathbb{Q}\}$ is a finite set, and the maximum possible number of elements in this set is 1. \(\square\)
