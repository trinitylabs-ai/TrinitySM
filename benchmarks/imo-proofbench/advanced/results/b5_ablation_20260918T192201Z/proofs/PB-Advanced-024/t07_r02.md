To solve the given functional equation
\[ (P(b-P(a))+a-P(b))(P(a+P(b-P(a)))-b)=0 \]
for all $a, b \in \mathbb{Q}$, we consider the two factors $X = P(b-P(a)) + a - P(b)$ and $Y = P(a+P(b-P(a))) - b$. The equation states that for every pair $(a, b)$, either $X=0$ or $Y=0$.

**1. Testing Linear Solutions:**
Let $P(x) = mx + c$.
Then $P(b-P(a)) = m(b - (ma+c)) + c = mb - m^2a - mc + c$.
The factor $X$ becomes:
\[ X = (mb - m^2a - mc + c) + a - (mb + c) = (1-m^2)a - mc. \]
The factor $Y$ becomes:
\[ Y = P(a + mb - m^2a - mc + c) - b = m(a + mb - m^2a - mc + c) + c - b \]
\[ Y = (m-m^3)a + (m^2-1)b - m^2c + mc + c. \]
If $m=1$, then $X = -c$ and $Y = c$. The equation $X \cdot Y = -c^2 = 0$ implies $c=0$. Thus $P(x) = x$ is a solution.
If $m=-1$, then $X = c$ and $Y = -c$. The equation $X \cdot Y = -c^2 = 0$ implies $c=0$. Thus $P(x) = -x$ is a solution.
If $m \neq \pm 1$, then $X=0$ requires $a = \frac{mc}{1-m^2}$. Since this must hold for all $a$ whenever $Y \neq 0$, and $Y$ is a linear function of $a$ and $b$, this cannot hold for all $a, b \in \mathbb{Q}$ unless $P$ is constant.
If $P(x) = c$, then $X = a$ and $Y = c-b$. The equation $a(c-b) = 0$ must hold for all $a, b$, which is impossible.

**2. Analysis of $X=0$ and $Y=0$:**
If $X=0$ for all $a, b$, then $P(b-P(a)) - P(b) = -a$. Setting $a=0$, we get $P(b-P(0)) = P(b)$. If $P(0)=c \neq 0$, $P$ is periodic. However, the condition $P(b-P(a)) - P(b) = -a$ implies that for a fixed $a$, the difference $P(b-k) - P(b)$ is constant. For a periodic function, this constant must be 0, implying $a=0$ for all $a$, a contradiction. Thus $P(0)=0$. Then $P(b-P(a)) - P(b) = -a$. For $b=0$, $P(-P(a)) - P(0) = -a \implies P(-P(a)) = -a$.
Substituting $P(x) = mx$, we found $m^2=1$, so $P(x) = x$ or $P(x) = -x$.

Similarly, if $Y=0$ for all $a, b$, then $P(a+P(b-P(a))) = b$. If $P$ is linear $P(x)=mx+c$, we again find $m^2=1$ and $c=0$.

**3. The Set $\{P(a) + P(-a) : a \in \mathbb{Q}\}$:**
For $P(x) = x$, $P(a) + P(-a) = a + (-a) = 0$. The set is $\{0\}$.
For $P(x) = -x$, $P(a) + P(-a) = -a + a = 0$. The set is $\{0\}$.
In both cases, the set contains only one element. No other rational functions were found to satisfy the equation. Based on the structure of the equation, which is satisfied by $P(x) = \pm x$, the set $\{P(a) + P(-a) : a \in \mathbb{Q}\}$ is $\{0\}$.

The maximum possible number of elements in the set $\{P(a) + P(-a) : a \in \mathbb{Q}\}$ is 1.
