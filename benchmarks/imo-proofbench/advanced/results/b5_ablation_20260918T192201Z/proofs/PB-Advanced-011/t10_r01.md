To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that $yf(yf(x)+1) = f(\frac{1}{x} + f(y))$ for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Exploration and Candidates**
Let's test the candidate $f(x) = \frac{c}{x}$.
LHS: $yf(y \frac{c}{x} + 1) = y \frac{c}{\frac{cy}{x} + 1} = \frac{cxy}{cy + x}$.
RHS: $f(\frac{1}{x} + \frac{c}{y}) = \frac{c}{\frac{1}{x} + \frac{c}{y}} = \frac{cxy}{y + cx}$.
For these to be equal for all $x, y$, we must have $cy + x = y + cx$, which implies $(c-1)y = (c-1)x$. This must hold for all $x, y$, so $c=1$.
Thus, $f(x) = \frac{1}{x}$ is a solution.

**2. Deriving Functional Relations**
Let $f(1) = c$.
Setting $y=1$ in the original equation:
$f(f(x)+1) = f(\frac{1}{x} + c)$  (Eq. 1)
Setting $x=1$ in the original equation:
$yf(yf(1)+1) = f(1 + f(y)) \implies yf(cy+1) = f(f(y)+1)$ (Eq. 2)
Combining (Eq. 1) and (Eq. 2) by substituting $y$ for $x$ in (Eq. 1) and relating them:
$yf(cy+1) = f(f(y)+1) = f(\frac{1}{y} + c)$ (Eq. 3)

**3. Analyzing Injectivity**
Suppose $f(y_1) = f(y_2)$ for some $y_1, y_2 \in \mathbb{R}^+$.
From the original equation, $f(\frac{1}{x} + f(y_1)) = f(\frac{1}{x} + f(y_2))$, so:
$y_1 f(y_1 f(x)+1) = y_2 f(y_2 f(x)+1)$.
Let $f(x) = z$. As $x$ varies, $z$ varies over the range of $f$. Thus, $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$ for all $z \in \text{Im}(f)$.
Specifically, let $z = c = f(1)$. Then $y_1 f(y_1 c + 1) = y_2 f(y_2 c + 1)$.
Using (Eq. 3) with $y=y_1$ and $y=y_2$, we have:
$y_1 f(cy_1+1) = f(\frac{1}{y_1} + c)$ and $y_2 f(cy_2+1) = f(\frac{1}{y_2} + c)$.
Therefore, $f(\frac{1}{y_1} + c) = f(\frac{1}{y_2} + c)$.
If we can show that $f$ is injective, we then have $\frac{1}{y_1} + c = \frac{1}{y_2} + c$, implying $y_1 = y_2$.
From (Eq. 1), $f(f(y)+1) = f(\frac{1}{y} + c)$. If $f$ is injective, then $f(y) + 1 = \frac{1}{y} + c$, which means $f(y) = \frac{1}{y} + c - 1$.

**4. Finalizing the Solution**
Substituting $f(y) = \frac{1}{y} + a$ (where $a = c-1$) back into the original equation:
LHS: $y f(y(\frac{1}{x} + a) + 1) = y (\frac{1}{\frac{y}{x} + ay + 1} + a) = \frac{xy}{y + axy + x} + ay$.
RHS: $f(\frac{1}{x} + \frac{1}{y} + a) = \frac{1}{\frac{1}{x} + \frac{1}{y} + a} + a = \frac{xy}{y + x + axy} + a$.
Comparing the two, we have:
$\frac{xy}{x + y + axy} + ay = \frac{xy}{x + y + axy} + a \implies ay = a$.
Since this must hold for all $y \in \mathbb{R}^+$, we must have $a = 0$.
Thus, $f(y) = \frac{1}{y} + 0 = \frac{1}{y}$.
Since $f(x) = \frac{1}{x}$ is indeed a solution and the derivation shows that any function of the form $f(y) = \frac{1}{y} + a$ must have $a=0$, we conclude it is the unique solution.

The function is $f(x) = \frac{1}{x}$. \(\square\)
