To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
\[ y f(y f(x) + 1) = f\left(\frac{1}{x} + f(y)\right) \quad (*) \]
for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Testing Simple Functional Forms**
We test if $f(x) = \frac{c}{x}$ for some constant $c > 0$.
LHS: $y f\left(y \frac{c}{x} + 1\right) = y \frac{c}{\frac{cy}{x} + 1} = \frac{cxy}{cy + x}$.
RHS: $f\left(\frac{1}{x} + \frac{c}{y}\right) = \frac{c}{\frac{1}{x} + \frac{c}{y}} = \frac{cxy}{y + cx}$.
For LHS = RHS, we require $\frac{cxy}{cy + x} = \frac{cxy}{y + cx}$, which implies $cy + x = y + cx$ for all $x, y \in \mathbb{R}^+$. This holds if and only if $c = 1$. Thus, $f(x) = \frac{1}{x}$ is a solution.

**2. Proving Injectivity of $f$**
Suppose there exist $x_1, x_2 \in \mathbb{R}^+$ such that $f(x_1) = f(x_2)$. Substituting into $(*)$:
\[ f\left(\frac{1}{x_1} + f(y)\right) = y f(y f(x_1) + 1) = y f(y f(x_2) + 1) = f\left(\frac{1}{x_2} + f(y)\right) \]
for all $y \in \mathbb{R}^+$. Let $f(y) = z$. Then $f\left(\frac{1}{x_1} + z\right) = f\left(\frac{1}{x_2} + z\right)$ for all $z$ in the range of $f$, denoted by $R$. Let $d = \left| \frac{1}{x_1} - \frac{1}{x_2} \right|$. If $x_1 \neq x_2$, then $d > 0$ and $f(z + d) = f(z)$ for all $z \in R$.
Since $f(1/x + f(y)) = y f(y f(x) + 1)$, the value $y f(y f(x) + 1)$ must be in $R$ for all $x, y$. If $f$ is periodic on $R$ with period $d$, then $f(z)$ is bounded for all $z \in R$. Let $M = \sup_{z \in R} f(z)$. Then $y f(y f(x) + 1) \leq M$ for all $y \in \mathbb{R}^+$. This implies $f(y f(x) + 1) \leq \frac{M}{y}$, so $f(y f(x) + 1) \to 0$ as $y \to \infty$. However, a periodic function on its range that tends to 0 as its argument tends to infinity must be identically 0, which contradicts the codomain $\mathbb{R}^+$. Thus, $f$ must be injective.

**3. Deriving the Functional Form**
Since $f$ is injective, we use $(*)$ with $y=1$:
\[ f(f(x) + 1) = f\left(\frac{1}{x} + f(1)\right) \implies f(x) + 1 = \frac{1}{x} + f(1) \]
Let $f(1) = c$. Then $f(x) = \frac{1}{x} + c - 1$. Let $a = c - 1$. Then $f(x) = \frac{1}{x} + a$ for some constant $a \geq -1$ (since $f(x) > 0$).
Substitute $f(x) = \frac{1}{x} + a$ back into $(*)$:
\[ y \left( \frac{1}{y(\frac{1}{x} + a) + 1} + a \right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + a} + a \]
\[ \frac{y}{\frac{y}{x} + ay + 1} + ay = \frac{xy}{y + x + axy} + a \]
To find $a$, we test specific values $x=1, y=2$:
\[ \frac{2}{2 + 2a + 1} + 2a = \frac{2}{2 + 1 + 2a} + a \implies \frac{2}{2a + 3} + 2a = \frac{2}{2a + 3} + a \]
This simplifies to $2a = a$, which implies $a = 0$. Thus, $f(x) = \frac{1}{x}$.

**Conclusion**
We have shown that $f(x) = \frac{1}{x}$ is the only function satisfying the given equation.

The function is $f(x) = \frac{1}{x}$. \(\square\)
