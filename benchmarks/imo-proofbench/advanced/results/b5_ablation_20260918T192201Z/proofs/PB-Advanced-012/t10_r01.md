To prove that $n \geq 5$ for the equation $p^n = a^4 + b^4$ where $p$ is prime and $a, b, n$ are positive integers with $n \geq 2$, we examine the cases $n=2, 3, 4$.

**Case 1: $n=2$**
The equation becomes $a^4 + b^4 = p^2$. This is a specific case of the Diophantine equation $x^4 + y^4 = z^2$. It is a well-known theorem, proved by Pierre de Fermat using the method of infinite descent, that the equation $x^4 + y^4 = z^2$ has no solutions in positive integers. Thus, $n=2$ is impossible.

**Case 2: $n=4$**
The equation becomes $a^4 + b^4 = p^4$. This is a case of Fermat's Last Theorem for $k=4$, which states that $x^4 + y^4 = z^4$ has no non-zero integer solutions. Since $a, b$ are positive integers, $n=4$ is impossible.

**Case 3: $n=3$**
The equation is $a^4 + b^4 = p^3$. Let $g = \gcd(a, b)$. Then $a=gx$ and $b=gy$ with $\gcd(x, y)=1$. We have $g^4(x^4 + y^4) = p^3$. Since $p$ is prime, $g$ must be a power of $p$. Let $g = p^k$. Then $p^{4k}(x^4 + y^4) = p^3$. If $k \geq 1$, then $4k \geq 4 > 3$, which is impossible as $x^4 + y^4 \geq 2$. Thus, $k=0$, implying $\gcd(a, b)=1$.
If $p=2$, then $a^4 + b^4 = 8$. The only positive integers are $a=b=1$, but $1^4 + 1^4 = 2 \neq 8$.
If $p > 2$, then $p$ is odd. Since $\gcd(a, b)=1$, one of $a, b$ must be even and the other odd (if both were odd, $a^4 + b^4 \equiv 2 \pmod{16}$, so $p^3 \equiv 2 \pmod{16}$, which is impossible for odd $p$).
Working in the Gaussian integers $\mathbb{Z}[i]$, we have $(a^2 + ib^2)(a^2 - ib^2) = p^3$. Since $\gcd(a, b)=1$ and $a^2+b^2$ is odd, $\gcd(a^2+ib^2, a^2-ib^2) = 1$. Thus $a^2 + ib^2$ must be a cube (up to a unit). Since all units in $\mathbb{Z}[i]$ are cubes, we have $a^2 + ib^2 = (x+iy)^3$ for some $x, y \in \mathbb{Z}$. Equating real and imaginary parts:
\[ a^2 = x(x^2 - 3y^2) \quad \text{and} \quad b^2 = y(3x^2 - y^2) \]
Since $\gcd(a, b)=1$, we have $\gcd(x, y)=1$. If $3 \nmid x$, then $x = u^2$ and $x^2 - 3y^2 = v^2$. If $3 \nmid y$, then $y=s^2$ and $3x^2 - y^2 = t^2$. This leads to the system $u^4 - 3s^4 = v^2$ and $3u^4 - s^4 = t^2$. Multiplying these gives $(3u^4 - s^4)(u^4 - 3s^4) = (vt)^2$, which simplifies to $3u^8 - 10u^4s^4 + 3s^8 = (vt)^2$. Dividing by $s^8$ and setting $z = (u/s)^4$ leads to $3z^2 - 10z + 3 = w^2$. For $z=q^2$ (where $q = (u/s)^2$), we have $3q^4 - 10q^2 + 3 = w^2$. This elliptic curve has no rational solutions other than those where $q^2=3$ or $1/3$, which are impossible. If $3|y$, let $y=3s^2$; then $x^2-3y^2=v^2$ becomes $x^2-27s^4=v^2$. Simultaneously, $b^2=y(3x^2-y^2)$ implies $x^2-3s^4=t^2$. The equation $u^4 - 3s^4 = t^2$ only has trivial solutions $(s=0)$. Thus, $n=3$ is impossible.

**Case 4: $p=2$**
If $p=2$, $2^n = a^4 + b^4$. If $a, b$ are odd, $a^4 \equiv 1 \pmod{16}$ and $b^4 \equiv 1 \pmod{16}$, so $a^4 + b^4 \equiv 2 \pmod{16}$, implying $2^n \equiv 2 \pmod{16}$, so $n=1$. Since $n \geq 2$, $a$ and $b$ must be even. Let $a=2a_1, b=2b_1$. Then $2^n = 16(a_1^4 + b_1^4)$, so $2^{n-4} = a_1^4 + b_1^4$. Repeating this $k$ times, we reach $2^{n-4k} = a_k^4 + b_k^4$ where $a_k, b_k$ are odd. Thus $n-4k=1$, so $n = 4k+1$. Since $n \geq 2$, $k \geq 1$, so $n \geq 5$.

Conclusion: Since $n=2, 3, 4$ are impossible for all primes $p$, we must have $n \geq 5$.

\(\square\)
