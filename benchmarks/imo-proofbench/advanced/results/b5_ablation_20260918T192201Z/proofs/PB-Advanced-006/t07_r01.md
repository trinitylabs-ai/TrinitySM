To find all functions $f: \mathbb{Z} \to \mathbb{Z}$ such that the equation
\[ f(x - f(xy)) = f(x)f(1 - y) \]
holds for all $x, y \in \mathbb{Z}$, we proceed as follows:

**1. Constant Functions:**
Suppose $f(x) = c$ for all $x \in \mathbb{Z}$. Substituting this into the equation gives:
$f(x - c) = c \cdot c \implies c = c^2$.
The solutions to $c = c^2$ are $c = 0$ and $c = 1$.
Thus, $f(x) = 0$ and $f(x) = 1$ are potential solutions.
- For $f(x) = 0$: $0 = 0 \cdot 0$ (Valid).
- For $f(x) = 1$: $1 = 1 \cdot 1$ (Valid).

**2. Linear Functions:**
Suppose $f(x) = ax + b$. Substituting into the equation:
$a(x - (axy + b)) + b = (ax + b)(a(1 - y) + b)$.
$ax - a^2xy - ab + b = (ax + b)(a - ay + b) = a^2x - a^2xy + abx + ab - aby + b^2$.
Comparing coefficients:
- $xy$ term: $-a^2 = -a^2$ (Always true).
- $x$ term: $a = a^2 + ab$.
- $y$ term: $0 = -ab$.
- Constant term: $-ab + b = ab + b^2$.
From $ab = 0$, either $a = 0$ (constant case) or $b = 0$.
If $b = 0$, then $a = a^2$, so $a = 0$ or $a = 1$.
If $a = 1, b = 0$, then $f(x) = x$.
- For $f(x) = x$: $f(x - xy) = x - xy$ and $f(x)f(1 - y) = x(1 - y) = x - xy$ (Valid).

**3. Further Analysis:**
Let $f(0) = c$. For $x = 0$, we have $f(-f(0)) = f(0)f(1 - y) \implies f(-c) = c f(1 - y)$.
If $c \neq 0$, then $f(1 - y) = f(-c)/c$ is a constant. If $f$ is constant, we already found $f(x) = 0, 1$.
If $c = 0$, then $f(0) = 0$. The equation becomes $f(x - f(xy)) = f(x)f(1 - y)$.
For $y = 0$, $f(x - f(0)) = f(x)f(1) \implies f(x) = f(x)f(1)$.
Thus, for each $x$, either $f(x) = 0$ or $f(1) = 1$. If $f(x) = 0$ for all $x$, we have $f(x) = 0$. Otherwise, $f(1) = 1$.
For $y = 1$, $f(x - f(x)) = f(x)f(0) = 0$.
If $f(x) = 0 \iff x = 0$, then $x - f(x) = 0 \implies f(x) = x$.
If $f(x) = 0$ for some $x \neq 0$, let $S = \{x \in \mathbb{Z} : f(x) = 0\}$. We have $0 \in S$.
If $x \in S$, then $f(x - f(xy)) = 0 \implies x - f(xy) \in S$ for all $y$.
If $x \notin S$, then $f(x - f(xy)) = f(x)f(1 - y)$.
For $y = 1$, $f(x - f(x)) = 0 \implies x - f(x) \in S$.
If $f(x) = 1$ for all $x \notin S$, then $x \notin S \implies x - 1 \in S$.
Also, $x \in S \implies x - f(xy) \in S$. If $xy \notin S$, then $f(xy) = 1$, so $x - 1 \in S$.
The conditions $x \notin S \implies x - 1 \in S$ and $x \in S \implies x - 1 \in S$ (given $xy \notin S$) imply $S$ and its complement are interlaced. Since $0 \in S$, $S$ must be the set of even integers $2\mathbb{Z}$.
Testing $f(x) = 0$ if $x$ is even and $f(x) = 1$ if $x$ is odd:
- If $x$ is even, $f(x - f(xy)) = f(\text{even} - f(\text{even})) = f(\text{even} - 0) = 0$ and $f(x)f(1 - y) = 0$.
- If $x$ is odd and $y$ is even, $f(\text{odd} - f(\text{even})) = f(\text{odd} - 0) = 1$ and $f(\text{odd})f(\text{odd}) = 1 \cdot 1 = 1$.
- If $x$ is odd and $y$ is odd, $f(\text{odd} - f(\text{odd})) = f(\text{odd} - 1) = 0$ and $f(\text{odd})f(\text{even}) = 1 \cdot 0 = 0$.
All cases match.

The functions $f: \mathbb{Z} \to \mathbb{Z}$ that satisfy the equation are:
1. $f(x) = 0$
2. $f(x) = 1$
3. $f(x) = x$
4. $f(x) = \begin{cases} 0 & \text{if } x \text{ is even} \\ 1 & \text{if } x \text{ is odd} \end{cases}$
