Let $k = n/d$. The expression is $(d+k)^2 = d^2 + k^2 + 2n$. The remainder of $(d+k)^2$ when divided by $n$ is the same as the remainder of $d^2 + k^2$ when divided by $n$. We are given that this remainder is $n-c$, where $0 \le n-c < n$. This implies $0 < c \le n$ and
\[ d^2 + k^2 \equiv n-c \equiv -c \pmod{n}. \]
Thus, $d^2 + k^2 + c = mn$ for some positive integer $m$. Let $g = \gcd(d, k)$, so $d = ga$ and $k = gb$ with $\gcd(a, b) = 1$. Then $n = dk = g^2 ab$. Substituting these into the equation gives
\[ g^2 a^2 + g^2 b^2 + c = m g^2 ab \implies c = g^2(mab - a^2 - b^2). \]
Let $c' = mab - a^2 - b^2$. Then $c = g^2 c'$. Since $c > 0$, we must have $mab > a^2 + b^2$. We wish to find the smallest $c$ such that $n = g^2 ab \equiv 6 \pmod{7}$.

For a fixed $m$ and $c'$, the equation $a^2 + b^2 + c' = mab$ can be analyzed using Vieta jumping. Let $(a, b)$ be a solution in positive integers with $a \le b$ such that $a+b$ is minimal. The equation $x^2 - (mb)x + (b^2 + c') = 0$ has roots $a$ and $a' = mb - a = (b^2 + c')/a$. By the minimality of $a+b$, we must have $a' \ge a$, so $(b^2 + c')/a \ge a$, which implies $b^2 + c' \ge a^2$. If $a=b$, then $2a^2 + c' = ma^2$, so $a^2$ divides $c'$, implying $a^2 \le c'$. If $a < b$, then $a' = (b^2 + c')/a$. If $a' < b$, then $(a', b)$ is a solution with $a' \le b$ and $a' + b < a + b$, contradicting minimality. Thus $a' \ge b$, so $(b^2 + c')/a \ge b$, which implies $b^2 + c' \ge ab$. It is a known property of the equation $a^2+b^2+c'=mab$ that the minimal solution $(a, b)$ with $a \le b$ must satisfy $a^2 \le c'$. We check $c' = 1, 2, 3$.

Case $c' = 1$: $a^2 + b^2 + 1 = mab$.
The minimal solution must satisfy $a^2 \le 1$, so $a=1$. Then $1 + b^2 + 1 = mb \implies b^2 - mb + 2 = 0$. Thus $b$ must divide 2, so $b=1$ or $b=2$.
- If $b=1$, $m=3$. The solutions to $a^2 + b^2 + 1 = 3ab$ are pairs of odd-indexed Fibonacci numbers $(F_{2k-1}, F_{2k+1})$. The products $ab \pmod{7}$ follow the sequence $1, 2, 3, 2, 1, \dots$.
- If $b=2$, $m=3$, which is the same case.
We need $n = g^2 ab \equiv 6 \pmod{7}$.
- $ab \equiv 1 \implies g^2 \equiv 6 \pmod{7}$ (no solution).
- $ab \equiv 2 \implies 2g^2 \equiv 6 \implies g^2 \equiv 3 \pmod{7}$ (no solution).
- $ab \equiv 3 \implies 3g^2 \equiv 6 \implies g^2 \equiv 2 \pmod{7} \implies g \equiv 3, 4 \pmod{7}$.
The smallest $c$ here is $g^2 c' = 3^2 \cdot 1 = 9$.

Case $c' = 2$: $a^2 + b^2 + 2 = mab$.
The minimal solution must satisfy $a^2 \le 2$, so $a=1$. Then $1 + b^2 + 2 = mb \implies b^2 - mb + 3 = 0$. Thus $b$ must divide 3, so $b=1$ or $b=3$.
- If $b=1$, $m=4$. The solutions to $a^2 + b^2 + 2 = 4ab$ are $(1, 1), (1, 3), (3, 11), (11, 41), \dots$. The products $ab \pmod{7}$ follow the sequence $1, 3, 5, 3, 1, \dots$.
- If $b=3$, $m=4$, which is the same case.
We need $n = g^2 ab \equiv 6 \pmod{7}$.
- $ab \equiv 1 \implies g^2 \equiv 6 \pmod{7}$ (no solution).
- $ab \equiv 3 \implies 3g^2 \equiv 6 \implies g^2 \equiv 2 \pmod{7} \implies g \equiv 3, 4 \pmod{7}$, so $c = 9 \cdot 2 = 18$.
- $ab \equiv 5 \implies 5g^2 \equiv 6 \implies g^2 \equiv 4 \pmod{7} \implies g \equiv 2, 5 \pmod{7}$, so $c = 4 \cdot 2 = 8$.

Case $c' = 3$: $a^2 + b^2 + 3 = mab$.
The minimal solution must satisfy $a^2 \le 3$, so $a=1$. Then $1 + b^2 + 3 = mb \implies b^2 - mb + 4 = 0$. Thus $b$ must divide 4, so $b \in \{1, 2, 4\}$.
- If $b=1$, $m=5$. The solutions to $a^2 + b^2 + 3 = 5ab$ are $(1, 1), (1, 4), (4, 19), \dots$. The products $ab \pmod{7}$ are $1, 4, 76 \equiv 6, \dots$.
- If $b=2$, $m=4$. The solutions to $a^2 + b^2 + 3 = 4ab$ are $(1, 2), (2, 7), (7, 26), \dots$. The products $ab \pmod{7}$ are $2, 0, 0, \dots$.
- If $b=4$, $m=5$, which is the same as $b=1$.
For $ab \equiv 6$, we have $n = g^2 \cdot 6 \equiv 6 \pmod{7} \implies g^2 \equiv 1 \pmod{7} \implies g=1$.
Then $c = g^2 c' = 1^2 \cdot 3 = 3$.

Verification for $n=76, d=4$: $n/d=19$, $(4+19)^2 = 529 = 6 \cdot 76 + 73$. The remainder is $73 = 76-3$, so $c=3$.
Since $c=1$ and $c=2$ would require $g=1$ and $c' \in \{1, 2\}$, but we showed $ab \equiv 6 \pmod{7}$ is impossible for $c'=1, 2$, the smallest possible value is 3.
