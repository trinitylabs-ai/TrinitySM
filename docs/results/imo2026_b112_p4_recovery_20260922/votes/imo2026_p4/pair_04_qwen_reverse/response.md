# Proof comparison

## Proof A
Established theorem: Shan-Yu can avoid victory if $\theta/180^\circ \notin \mathbb{Q}$ or $\theta \ge 120^\circ$. The proof correctly demonstrates that for irrational multiples of $180^\circ$, Shan-Yu can maintain angles outside the additive group generated by $\theta$ and $180^\circ$, and for $\theta \ge 120^\circ$, the equilateral triangle $(60^\circ,60^\circ,60^\circ)$ strictly bounds all future angles below $120^\circ$.
Claim gap: The sufficiency claim for rational $\theta < 120^\circ$ is false and unjustified. The argument asserts that because the scaled state space of angle triples is finite, Mulan can "avoid cycles" and force a win. This confuses graph reachability with the existence of a winning strategy in an adversarial game. Finite state space alone does not prevent draws or losses; it requires a monotonic invariant or explicit strategy to guarantee termination at a winning state.
Qualifications and supplied repairs: NONE. The finite-state reachability claim cannot be repaired without introducing a new invariant or strategy, which the submission lacks.
Decisive checks: 
- Lines 12-16 claim Mulan wins for all rational $\theta < 120^\circ$ based on finite state space and cycle avoidance. This is a demonstrated defect: adversarial games on finite graphs can be draws or losses for the moving player. 
- Falsification check: Let $\theta = 100^\circ$ (rational, $<120^\circ$). Shan-Yu starts with $(60^\circ,60^\circ,60^\circ)$. Any cut of $60^\circ$ into $\alpha, 60^\circ-\alpha$ yields triangles $(\alpha, 60^\circ, 120^\circ-\alpha)$ and $(60^\circ-\alpha, 60^\circ, 60^\circ+\alpha)$. For both to contain $100^\circ$, we need $120^\circ-\alpha=100^\circ \Rightarrow \alpha=20^\circ$, but then $60^\circ+\alpha=80^\circ \neq 100^\circ$. Thus only one triangle contains $\theta$, and Shan-Yu discards it. Mulan cannot force a win, contradicting the claim.

## Proof B
Established theorem: Mulan can guarantee victory if and only if $\theta = 180^\circ/k$ for some integer $k \ge 2$. The proof establishes a descent argument within the set $W = \{n\theta \mid n\theta < 180^\circ\}$, proves entry into $W$ is forceable when $\theta=180^\circ/k$, and proves avoidance of $W$ is possible otherwise.
Claim gap: NONE supported by checks. The argument covers all cases rigorously.
Qualifications and supplied repairs: NONE. The case analysis for entering $W$ and the exhaustive check of the four combinations for both triangles to contain an angle in $W$ are complete and correctly executed.
Decisive checks:
- Lines 1-3: Descent argument. If a triangle has angle $n\theta$, cutting it into $\theta$ and $(n-1)\theta$ guarantees the kept triangle has an angle in $W$ with a strictly smaller coefficient. Verified correct.
- Lines 5-11: Entry into $W$ when $\theta=180^\circ/k$. Shows that if any angle $A > \theta$, the interval $(B, B+A)$ contains a multiple $n\theta$, making both resulting triangles contain angles in $W$. Handles the edge case $A,B,C \le \theta$ by summing to $180^\circ=k\theta$, forcing $k \le 3$ and checking $k=2,3$ explicitly. Verified correct.
- Lines 13-21: Avoidance when $\theta \neq 180^\circ/k$. Lists all 4 logical combinations for both $T_1$ and $T_2$ to have an angle in $W$. Each combination algebraically implies either an initial angle is in $W$ or $180^\circ$ is a multiple of $\theta$. Since Shan-Yu starts with no angles in $W$ and $\theta \neq 180^\circ/k$, none can occur. Thus at least one triangle avoids $W$, and Shan-Yu keeps it. Verified correct and exhaustive.

## Decision
Winner: B
Reason: Proof B provides a complete, rigorous characterization with airtight case analysis for both the winning strategy and the avoidance strategy. Proof A's necessity argument is partially correct, but its sufficiency claim for rational $\theta < 120^\circ$ is mathematically false and relies on a fundamental fallacy (equating finite state reachability with adversarial forceability). The counterexample $\theta = 100^\circ$ decisively invalidates A's main claim, while B's set $W$ framework correctly identifies that $180^\circ$ must be an integer multiple of $\theta$ to guarantee victory. B's argument requires no external repairs and stands as a complete solution.
