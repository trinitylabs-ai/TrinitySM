# Proof comparison

## Proof A
Established theorem: Claims Mulan wins iff $\theta$ is a rational multiple of $180^\circ$ and $\theta < 120^\circ$. The irrational case suggests Shan-Yu can avoid $\theta$ by maintaining angles outside the additive subgroup $S = \{n\theta + m180^\circ\}$, but does not rigorously connect subgroup density to the discrete cut choices. The rational case sufficiency is asserted via a finite state argument.
Claim gap: The sufficiency claim is mathematically false. The finite state argument (Line 16) asserts reachability of the winning state without providing a strategy, invariant, or termination condition. It fails to account for Shan-Yu's optimal discarding strategy, which can trap the game in a loop or avoid the target angle entirely.
Qualifications and supplied repairs: NONE. The gap is fundamental; no routine repair can salvage the claim that all rational $\theta < 120^\circ$ are winning.
Decisive checks: Line 16 claims "Mulan can always choose a cut... to avoid cycles" and force the state to $(m, n_2, n_3)$. This is unsupported. Counterexample: $\theta = 100^\circ$ (rational, $<120^\circ$). Starting from $(60^\circ, 60^\circ, 60^\circ)$, any cut of a $60^\circ$ angle yields triangles $(\alpha_1, 60^\circ, 120^\circ-\alpha_1)$ and $(\alpha_2, 60^\circ, 120^\circ-\alpha_2)$. To force a $100^\circ$ angle in both, we would need $120^\circ-\alpha_1=100^\circ$ and $120^\circ-\alpha_2=100^\circ$, implying $\alpha_1=\alpha_2=20^\circ$, but $\alpha_1+\alpha_2=60^\circ \neq 40^\circ$. Thus, at least one child triangle lacks $100^\circ$. Shan-Yu discards the other, maintaining avoidance. This falsifies the main theorem. The irrational necessity (Lines 3-7) relies on subgroup properties but does not verify that Shan-Yu's avoidance strategy survives all possible cuts; it remains an unresolved heuristic.

## Proof B
Established theorem: Mulan can guarantee victory iff $\theta = 180^\circ/n$ for some integer $n \ge 2$.
Claim gap: NONE supported by checks. Both sufficiency and necessity are fully justified.
Qualifications and supplied repairs: NONE. All algebraic steps, interval length calculations, and case analyses are verified as correct and complete. The $n=2$ edge case is explicitly handled.
Decisive checks: Lines 6-14 construct an explicit winning cut for sufficiency. Setting $180^\circ-\alpha_1-b = k_1\theta$ and $180^\circ-\alpha_2-c = k_2\theta$ yields $k_1+k_2=n$. The validity conditions $\alpha_1,\alpha_2>0$ reduce to finding an integer $k_1 \in (c/\theta, n-b/\theta)$. The interval length is exactly $a/\theta$. Since $a+b+c=n\theta$, at least one angle exceeds $\theta$ (or $n=2$ is handled separately), guaranteeing length $>1$ and thus an integer $k_1$. This rigorously proves Mulan can force both children to contain an angle in $S=\{k\theta\}$ in one move, after which a simple reduction strategy wins. Lines 17-24 exhaustively analyze the four logical combinations for both children to contain angles in $S$. Each combination algebraically implies either a parent angle was already in $S$ or $(n_1+n_2)\theta=180^\circ$. Since $\theta \neq 180^\circ/m$ in the necessity case, the latter is impossible. Thus, for any cut, at least one child triangle has no angle in $S$, giving Shan-Yu a valid invariant strategy. The initial triangle $(60^\circ,60^\circ,60^\circ)$ correctly avoids $S$ when $\theta \neq 180^\circ/n$. All steps are verified.

## Decision
Winner: B
Reason: Proof B provides a complete, rigorous proof with explicit constructions for both directions. Its sufficiency argument uses a precise interval length calculation to guarantee a valid cut, and its necessity argument exhaustively verifies an invariant strategy for Shan-Yu. Proof A's main claim is demonstrably false (e.g., $\theta=100^\circ$), and its sufficiency proof relies on an unjustified finite-state reachability assertion that ignores Shan-Yu's optimal discarding choices. B's mathematical obligations are fully met, while A contains a fatal gap in its central claim.
