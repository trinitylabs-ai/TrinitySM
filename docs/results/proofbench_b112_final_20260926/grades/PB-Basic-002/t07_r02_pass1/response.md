- The AM-GM application gives
  \[
  Q=x^2+y^2+z^2+t^2\ge 4\sqrt{xyzt}=4\sqrt P.
  \]
- Cauchy–Schwarz gives
  \[
  Q\ge \frac{(x+y+z+t)^2}{4}=\frac{S^2}{4}.
  \]
  Since \(2S\ge P\), it follows that
  \[
  Q\ge \frac{S^2}{4}\ge \frac{P^2}{16}.
  \]
- If \(P\le16\), then \(4\sqrt P\ge P\), so \(Q\ge P\).
- If \(P>16\), then \(P^2/16>P\), so again \(Q>P\).

The cases cover all positive \(P\), and the equality analysis \(x=y=z=t=2\) is also correct.
