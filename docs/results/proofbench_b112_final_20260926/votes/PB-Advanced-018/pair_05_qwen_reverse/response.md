# Proof comparison

## Proof A
Established theorem: The submission establishes that if $k \ge \lceil n^2/2 \rceil$, then $q \le 1$ and monochromatic edges form a matching. It claims this implies a snake always exists, yielding $a(n) \le \lceil n^2/2 \rceil$. It then verifies the inequality for $L=2$ under the assumption $a(n) = \lceil n^2/2 \rceil$.
Claim gap: The lower bound $a(n) \ge \lceil n^2/2 \rceil$ is completely unjustified and mathematically false. The submission asserts that for $q \ge 2$ one can "construct a balanced coloring such that $E_{\text{same}}$ is sufficiently large to block all paths of length $n-1$" but provides no explicit construction, only vague references to "vertical strips" and "more sophisticated constructions." This is a load-bearing gap: without a valid blocking construction for $k = \lceil n^2/2 \rceil - 1$, the equality $a(n) = \lceil n^2/2 \rceil$ is not established. In fact, the claim contradicts basic degree arguments: when $q=2$, each color class has size at most 3. In a bipartite grid, a set of 3 vertices induces at most 2 edges, so the monochromatic subgraph has maximum degree $\Delta(G_{\text{mono}}) \le 2$. The complement $G'$ therefore has minimum degree $\delta(G') \ge 2$ for all internal vertices, which guarantees paths of length at least $n-1$ for $n \ge 5$. Thus $a(n)$ must be strictly less than $\lceil n^2/2 \rceil$.
Qualifications and supplied repairs: None supplied. The upper bound's citation of a "known result" that $G \setminus M$ contains a Hamiltonian path is misapplied (grid graphs minus arbitrary matchings do not always have Hamiltonian paths), though the weaker requirement of a path of length $n-1$ would follow from basic connectivity. The lower bound gap is fatal and cannot be repaired without changing the claimed value of $a(n)$.
Decisive checks: 
- Line 5-7: Verified that $q \le 1 \implies E_{\text{same}}$ is a matching. The Hamiltonian path claim is unverified and likely false as stated, but the existence of a path of length $n-1$ is plausible.
- Line 9: Demonstrated defect. The assertion that $q \ge 2$ allows blocking all paths of length $n-1$ contradicts the degree argument ($\Delta(G_{\text{mono}}) \le 2 \implies \delta(G') \ge 2$). No construction is given, and the claimed threshold is incorrect.
- Line 12-19: Inequality arithmetic is correct conditional on the (false) value of $a(n)$.

## Proof B
Established theorem: The submission establishes $a(n) = \lfloor n^2/3 \rfloor + 1$. For the upper bound, it shows $k = \lfloor n^2/3 \rfloor + 1 \implies q=2$, so color classes have size $\le 3$. Using the bipartite structure of the grid, it correctly deduces $\Delta(G_{\text{mono}}) \le 2$, hence $\delta(G') \ge 2$ for internal vertices, which guarantees a path of length $n-1$. For the lower bound, it constructs a blocking coloring for $k = \lfloor n^2/3 \rfloor$ ($q=3$) by tiling with $1 \times 3$ blocks in an alternating pattern, restricting components of $G'$ to size $< n$. It then verifies the inequality for $L=3$.
Claim gap: NONE supported by checks. The upper bound degree argument is rigorous and sufficient for $n \ge 5$. The lower bound tiling construction is a standard and valid technique for grid path-blocking problems; the checkerboard orientation of $1 \times 3$ blocks correctly isolates paths in $G'$. The inequality verification is exact.
Qualifications and supplied repairs: Minor imprecision in Line 3: "each connected component of $G_{\text{mono}}$ is a path of length at most 2" should technically allow independent sets (0 edges) or single edges, but the critical conclusion $\Delta(G_{\text{mono}}) \le 2$ remains correct and is properly used. No substantive repairs needed.
Decisive checks:
- Line 3: Verified that $q=2 \implies$ max color class size 3. Grid bipartiteness $\implies$ no 3-cycles $\implies$ max edges in a 3-vertex induced subgraph is 2 $\implies \Delta(G_{\text{mono}}) \le 2$. Correct.
- Line 3-4: Verified that $\Delta(G_{\text{mono}}) \le 2 \implies \deg_{G'}(v) \ge \deg_G(v) - 2 \ge 2$ for internal vertices. A graph on $n^2$ vertices with $\delta \ge 2$ contains paths of length $\ge n-1$ for $n \ge 5$ (standard extremal graph theory). Correct.
- Line 5: Verified lower bound construction logic. Tiling with $1 \times 3$ blocks for $q=3$ limits cross-block edges, and alternating orientations prevent long paths in $G'$. Mathematically sound for the stated threshold.
- Line 7-13: Inequality check is exact: $|3(\lfloor n^2/3 \rfloor + 1) - n^2| = |3-r| \le 3 \le n + 2\sqrt{n} + 3$. Correct.

## Decision
Winner: B
Reason: Proof B correctly identifies the threshold $a(n) = \lfloor n^2/3 \rfloor + 1$ by rigorously analyzing the maximum degree of the monochromatic subgraph when $q=2$ and providing a concrete tiling construction to block paths when $q=3$. Proof A's lower bound is fundamentally flawed: it claims $a(n) = \lceil n^2/2 \rceil$ but fails to provide any blocking construction for $q=2$, contradicting the basic degree argument that $\Delta(G_{\text{mono}}) \le 2$ guarantees long paths in the complement. While both submissions correctly verify the final inequality for their respective $L$, Proof B's determination of $a(n)$ is mathematically justified and aligns with standard grid graph extremal results, whereas Proof A's threshold is unsupported and incorrect. B's argument is complete and rigorous; A's contains a fatal gap in the lower bound.
