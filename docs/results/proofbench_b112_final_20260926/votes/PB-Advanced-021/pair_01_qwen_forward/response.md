# Proof comparison

## Proof A
Established theorem: The set $S$ of values appearing infinitely often is non-empty and contains 1. The recurrence $x_m = 1 + c_{m-2}(x_{m-1})$ is correctly stated, and the proof correctly shows that values in $S$ generate arbitrarily large terms, which subsequently map back to bounded values.
Claim gap: The argument that one parity subsequence is eventually periodic relies on reducing the dynamics to a finite state machine based on the "rankings" of counts (Lines 30-31). This is a load-bearing defect: the transition $x_{m+1} = 1 + \#\{v \in S \mid c_{m-1}(v) \ge x_m\}$ depends on the exact numerical values of the counts relative to $x_m$, not merely their relative order. Since the counts $c_{m-1}(v)$ grow unboundedly with $m$, the state space is infinite, and boundedness of the values alone does not imply eventual periodicity. Additionally, Line 7 contains an off-by-one error ($n_k = \#\{v \mid c_\infty(v) \ge k-1\}$, not $\ge k$), which undermines the bounding estimates.
Qualifications and supplied repairs: NONE. The finite-state periodicity claim requires a substantive new lemma showing that the exact counts eventually stabilize or become periodic modulo the recurrence threshold, which is absent and non-trivial.
Decisive checks: Line 7: DEMONSTRATED defect (off-by-one in occurrence count formula). Lines 30-31: DEMONSTRATED defect (rankings do not determine the next term; exact counts are required, so the claimed finite state space is invalid and the periodicity conclusion is unsupported). Lines 14-18: UNRESOLVED (boundedness argument is heuristic and does not bridge the infinite-state gap).

## Proof B
Established theorem: The sequence $\{a_m\}$ is unbounded, and 1 appears infinitely often. Let $k_j$ be the index of the $j$-th occurrence of 1. The proof correctly derives $a_{k_j+1} = j$ (Line 5) and establishes that for sufficiently large $j$, $a_{k_j+2} = 1$ (Lines 9-11). This yields the exact asymptotic pattern $1, j, 1, j+1, 1, j+2, \dots$, proving that one parity subsequence is eventually constant (hence periodic).
Claim gap: Line 9 asserts $T(v, i) \ge T(1, i) = k_i$ for all $v, i$ to justify $c_{k_j}(j)=0$. This inequality is false for arbitrary initial conditions (early terms can place other values ahead of 1). However, the conclusion $c_{k_j}(j)=0$ for sufficiently large $j$ is correct: asymptotically, 1 is the unique value accumulating counts fast enough to trigger the generation of $j$, so $j$ appears for the first time at $k_j+1$. This is a minor justification gap that does not break the main derivation.
Qualifications and supplied repairs: Supplied routine justification for $c_{k_j}(j)=0$: for large $j$, only the value 1 reaches count $j-1$ by index $k_j$, because all other values are generated sequentially and appear exactly once until much later. This repairs the flawed inequality while preserving the proof's core claim. No other repairs were needed.
Decisive checks: Line 5: VERIFIED ($a_{k_j+1} = 1 + c_{k_j-1}(1) = 1 + (j-1) = j$). Line 9: DEMONSTRATED defect in stated inequality, but VERIFIED conclusion ($c_{k_j}(j)=0$ for large $j$) via count dominance of 1. Lines 11-13: VERIFIED (pattern $1, j, 1, j+1, \dots$ follows directly, yielding a constant subsequence on one parity).

## Decision
Winner: B
Reason: Proof B derives the exact asymptotic pattern $1, j, 1, j+1, 1, j+2, \dots$, which directly proves one parity subsequence is eventually constant (and thus periodic). Its core arithmetic derivation is concrete and verified. Proof A's argument relies on an unjustified finite-state reduction (claiming rankings suffice when exact counts are required) and ignores that the recurrence depends on unbounded counts, leaving the periodicity conclusion mathematically unsupported. While Proof B's justification for $c_{k_j}(j)=0$ cites a false inequality, the conclusion itself is correct for large $j$ and easily repaired by noting 1's asymptotic count dominance; this minor gap does not affect the validity of the main pattern. Proof B provides a complete, verifiable path to the result, whereas Proof A's central mechanism is fundamentally incomplete.
