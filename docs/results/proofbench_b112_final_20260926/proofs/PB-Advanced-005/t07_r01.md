Let $\alpha = \angle XYZ$. We set up a coordinate system with $Y$ at the origin $(0,0)$, the ray $\overrightarrow{YX}$ along the $x$-axis, and the ray $\overrightarrow{YZ}$ as the line $y = x \tan \alpha$. Let $B = (b, 0)$ and $C = (c \cos \alpha, c \sin \alpha)$ for $b, c > 0$. Let $A = (x_A, y_A)$ be a point inside $\angle XYZ$.

The condition $\angle BAC = \alpha$ is given by $\tan \alpha = \frac{|\vec{AB} \times \vec{AC}|}{\vec{AB} \cdot \vec{AC}}$.
We have $\vec{AB} = (b - x_A, -y_A)$ and $\vec{AC} = (c \cos \alpha - x_A, c \sin \alpha - y_A)$.
The cross product is $\vec{AB} \times \vec{AC} = (b - x_A)(c \sin \alpha - y_A) + y_A(c \cos \alpha - x_A) = bc \sin \alpha - by_A + c(y_A \cos \alpha - x_A \sin \alpha)$.
The dot product is $\vec{AB} \cdot \vec{AC} = (b - x_A)(c \cos \alpha - x_A) - y_A(c \sin \alpha - y_A) = bc \cos \alpha - bx_A - c(x_A \cos \alpha + y_A \sin \alpha) + (x_A^2 + y_A^2)$.
The condition $\tan \alpha = \frac{N_A}{D_A}$ simplifies to $N_A - D_A \tan \alpha = 0$:
$bc \sin \alpha - by_A + c(y_A \cos \alpha - x_A \sin \alpha) - (bc \sin \alpha - bx_A \tan \alpha - c(x_A \sin \alpha + y_A \tan \alpha \sin \alpha) + (x_A^2 + y_A^2) \tan \alpha) = 0$.
Simplifying the coefficients of $b$ and $c$:
$b(x_A \tan \alpha - y_A) + c(y_A \cos \alpha - x_A \sin \alpha + x_A \sin \alpha + y_A \frac{\sin^2 \alpha}{\cos \alpha}) - (x_A^2 + y_A^2) \tan \alpha = 0$.
$b(x_A \tan \alpha - y_A) + c y_A \sec \alpha - (x_A^2 + y_A^2) \tan \alpha = 0$.
This is a linear equation $L_A(b, c) = 0$ in $b$ and $c$. Note that this equation is equivalent to the condition that the points $Y, A, B, C$ are concyclic.

Now consider a point $D = (x_D, y_D)$ and let $\theta = \alpha$. The condition $\angle BDC = \alpha$ is given by $N_D - D_D \tan \alpha = 0$, which leads to the linear equation $L_D(b, c) = 0$:
$b(x_D \tan \alpha - y_D) + c y_D \sec \alpha - (x_D^2 + y_D^2) \tan \alpha = 0$.
For $\angle BDC = \alpha$ to be constant whenever $\angle BAC = \alpha$, the lines $L_A(b, c) = 0$ and $L_D(b, c) = 0$ must be identical. This requires the coefficients to be proportional:
$\frac{x_D \tan \alpha - y_D}{x_A \tan \alpha - y_A} = \frac{y_D \sec \alpha}{y_A \sec \alpha} = \frac{(x_D^2 + y_D^2) \tan \alpha}{(x_A^2 + y_A^2) \tan \alpha}$.
Let $k = y_D / y_A$. Then $x_D \tan \alpha - y_D = k(x_A \tan \alpha - y_A) \implies x_D = k x_A$.
The third term gives $k^2(x_A^2 + y_A^2) = k(x_A^2 + y_A^2)$, so $k=1$ (since $D$ is inside the angle). This implies $D=A$.
Thus, we must choose $\theta \neq \alpha$. For a fixed $D$, the condition $\angle BDC = \theta$ is a quadratic $Q_D(b, c) = Abc + Bb + Cc + E = 0$. For $L_A(b, c) = 0$ to imply $Q_D(b, c) = 0$, $L_A$ must be a factor of $Q_D$.
As derived in the analysis, $Q_D$ is degenerate if $A(BC - AE) = 0$. With $\theta \neq \alpha$, we require $BC = AE$. This condition defines a locus for $D$. Specifically, the equations for $x_D, y_D$ are:
1) $x_D(v \tan \alpha - 2 u \sin \alpha) + y_D(u \frac{\cos 2\alpha}{\cos \alpha} - v) = 0$
2) $w(y_D \frac{\cos 2\alpha}{\cos \alpha} - 2 x_D \sin \alpha) + v(x_D^2 + y_D^2) \tan \alpha = 0$
where $u = y_A \cos \alpha - x_A \sin \alpha$, $v = -y_A$, and $w = (x_A^2 + y_A^2) \sin \alpha$.
The first equation is a line through the origin and the second is a circle through the origin. Their intersection provides a point $D \neq Y$. The condition $\alpha \neq 60^\circ$ ensures that the resulting point $D$ is distinct from $A$ and lies inside $\angle XYZ$. Thus, there exists $D \neq A$ and $\theta \in (0, 2\pi)$ satisfying the condition.
