Let the two distinct positive integers be $a$ and $b$. The available operations are $f(x) = x+2$ and $g(x) = 3x$. In each step, we apply one of these operations to each number independently.

**1. Necessary Conditions**
First, observe that for any integer $x$, $f(x) = x+2 \equiv x \pmod 2$ and $g(x) = 3x \equiv x \pmod 2$. Thus, the parity of each number is invariant under both operations. For the two numbers to become equal, they must have the same parity. Thus, $a \equiv b \pmod 2$ is a necessary condition.

Next, consider the case where $a$ and $b$ are odd. We examine the operations modulo 4. For any odd integer $x$:
- If $x \equiv 1 \pmod 4$, then $f(x) = x+2 \equiv 3 \pmod 4$ and $g(x) = 3x \equiv 3 \pmod 4$.
- If $x \equiv 3 \pmod 4$, then $f(x) = x+2 \equiv 1 \pmod 4$ and $g(x) = 3x \equiv 1 \pmod 4$.
In both cases, any operation applied to an odd integer flips its residue modulo 4. After $n$ steps, the numbers $x_n$ and $y_n$ will satisfy $x_n \equiv a + 2n \pmod 4$ and $y_n \equiv b + 2n \pmod 4$. For $x_n = y_n$, we must have $x_n \equiv y_n \pmod 4$, which implies $a + 2n \equiv b + 2n \pmod 4$, simplifying to $a \equiv b \pmod 4$. Thus, $a \equiv b \pmod 4$ is a necessary condition for odd $a, b$.

**2. Sufficiency for Odd Integers**
Assume $a$ and $b$ are odd and $a \equiv b \pmod 4$. Let $a < b$ and let $d_n = y_n - x_n$ be the difference after $n$ steps. Since $a \equiv b \pmod 4$, $d_0 = b-a$ is a multiple of 4.
We aim to reach $d_n = 0$. Note that if $d_n$ is a multiple of 4 and $x_n$ is odd, then $d_{n+1}$ remains a multiple of 4 under any operation pair:
- $(f, f): d_{n+1} = (y_n+2) - (x_n+2) = d_n$.
- $(f, g): d_{n+1} = 3y_n - (x_n+2) = 3(x_n+d_n) - x_n - 2 = 2x_n + 3d_n - 2$. Since $x_n$ is odd, $2x_n - 2$ is a multiple of 4, so $d_{n+1} \equiv 0 \pmod 4$.
- $(g, f): d_{n+1} = (y_n+2) - 3x_n = (x_n+d_n+2) - 3x_n = d_n - 2x_n + 2$. Since $x_n$ is odd, $-2x_n + 2$ is a multiple of 4, so $d_{n+1} \equiv 0 \pmod 4$.
- $(g, g): d_{n+1} = 3y_n - 3x_n = 3d_n$.

We use the following strategy:
- If $d_n > 0$ and $x_n \le \frac{d_n}{2} + 1$, we apply the operation pair $(f, f)$ repeatedly until $x_m = \frac{d_n}{2} + 1$. Since $d_n$ is a multiple of 4, $\frac{d_n}{2} + 1$ is odd, so this is possible. Then, applying the operation pair $(g, f)$ gives $d_{m+1} = (y_m + 2) - 3x_m = (x_m + d_n + 2) - 3x_m = d_n - 2(x_m - 1) = d_n - 2(\frac{d_n}{2}) = 0$.
- If $d_n > 0$ and $x_n > \frac{d_n}{2} + 1$, we apply the operation pair $(f, g)$. The new difference is $d_{n+1} = 2x_n + 3d_n - 2$ and the new value of $x$ is $x_{n+1} = x_n + 2$. We check if $x_{n+1} \le \frac{d_{n+1}}{2} + 1$:
  $\frac{d_{n+1}}{2} + 1 = \frac{2x_n + 3d_n - 2}{2} + 1 = x_n + 1.5d_n$.
  Since $d_n \ge 4$, we have $x_n + 1.5d_n \ge x_n + 6 > x_n + 2 = x_{n+1}$.
Thus, we can always reach a state where $x_n \le \frac{d_n}{2} + 1$ and then reach $d=0$.

**3. Sufficiency for Even Integers**
Assume $a$ and $b$ are even. Let $a = 2a'$ and $b = 2b'$. The operations $x \to x+2$ and $x \to 3x$ on the blackboard correspond to $x' \to x'+1$ and $x' \to 3x'$ for the halved values. Let $a' < b'$ and $d'_n = b'_n - a'_n$.
We aim to reach $d'_n = 0$ using $f'(x) = x+1$ and $g'(x) = 3x$.
Note that applying the operation pair $(g', f')$ results in $d'_{n+1} = (b'_n + 1) - 3a'_n = d'_n - 2a'_n + 1$. If we can reach a state where $d'_n = 2a'_n - 1$, then $(g', f')$ makes $d'_{n+1} = 0$.
Let $h_n = d'_n - 2a'_n$. We want to reach $h_n = -1$.
- Operation $(f', f')$: $a' \to a'+1, d' \to d' \implies h_{n+1} = d'_n - 2(a'_n + 1) = h_n - 2$.
- Operation $(f', g')$: $a' \to a'+1, d' \to 3b'_n - (a'_n + 1) = 3(a'_n + d'_n) - a'_n - 1 = 3d'_n + 2a'_n - 1$.
  Then $h_{n+1} = (3d'_n + 2a'_n - 1) - 2(a'_n + 1) = 3d'_n - 3$.

If $h_n < 0$, applying $(f', g')$ gives $h_{n+1} = 3d'_n - 3$. Since $d'_n \ge 1$, $h_{n+1} \ge 0$.
Once $h_n \ge 0$:
- If $h_n$ is odd, we apply $(f', f')$ repeatedly to decrease $h$ by 2 until $h = -1$.
- If $h_n$ is even, we apply $(f', f')$ repeatedly until $h = 0$. Then we apply $(f', g')$ to get $h_{new} = 3d'_n - 3$. Since $h=0 \implies d'_n = 2a'_n$, we have $h_{new} = 6a'_n - 3$, which is odd. We then apply $(f', f')$ to reach $h = -1$.
Once $h = -1$, we apply $(g', f')$ to reach $d' = 0$.

**Conclusion**
The numbers can be made equal if and only if $a$ and $b$ are both even, or they are both odd and $a \equiv b \pmod 4$.
