To prove that at least one of the sequences $\{b_n\}$ or $\{g_n\}$ is eventually periodic, we analyze the behavior of the sequence $a_m$ defined by $a_m = 1 + C(a_{m-1}, m-2)$ for $m > N$, where $C(x, m)$ is the number of times $x$ appears in $\{a_1, \dots, a_m\}$.

**1. Existence of the value 1**
First, we show that the value 1 must appear in the sequence for $m > N$. Suppose $a_m \neq 1$ for all $m > N$. Then $a_m = 1 + C(a_{m-1}, m-2) \ge 2$ for all $m > N$. This implies that $C(a_{m-1}, m-2) \ge 1$, so $a_{m-1}$ must have appeared at least once in the first $m-2$ terms. By induction, this means every $a_m$ for $m > N$ must be a value already present in the set $\{a_1, \dots, a_N\}$. Let this finite set be $V$. Since the sequence is infinite and only takes values from $V$, at least one value $v \in V$ must appear infinitely often. Then $C(v, m) \to \infty$ as $m \to \infty$. However, whenever $a_{m-1} = v$, we have $a_m = 1 + C(v, m-2)$, which also tends to infinity. This contradicts the assumption that $a_m$ only takes values from the finite set $V$. Thus, $a_m = 1$ for some $m > N$.

**2. The "1 $\to$ Large $\to$ 1" Cycle**
Suppose $a_m = 1$ for some sufficiently large $m$. Then $a_{m+1} = 1 + C(1, m-1)$. Let $K = 1 + C(1, m-1)$. We examine $a_{m+2} = 1 + C(K, m)$.
$C(K, m)$ is the number of times $K$ appeared in $\{a_1, \dots, a_m\}$. For $a_i = K$ to occur for $i \le m$, we must have $C(a_{i-1}, i-2) = K-1 = C(1, m-1)$.

We observe that $a_j = 1$ whenever $a_{j-1}$ is a "new" value (one that has not appeared in the first $j-2$ terms). Conversely, whenever $a_{j-1} = 1$, the next term $a_j = 1 + C(1, j-2)$ is a value that grows as $j$ increases. For sufficiently large $j$, $a_j$ will be larger than any value previously appearing in the sequence. This creates a feedback loop where 1s and new large values appear in alternating fashion. Consequently, $C(1, m)$ grows linearly with $m$, while any value $x > \max(a_1, \dots, a_N)$ appears at most once because the values $1 + C(1, j-2)$ are strictly increasing for $j$ where $a_{j-1}=1$.

Now consider $i \le m$. The count $C(a_{i-1}, i-2)$ is bounded by the maximum frequency of any element in the first $i-2$ terms. For sufficiently large $m$, $C(1, m-1)$ will exceed the frequency of any element $x \neq 1$ in the first $m-2$ terms. Specifically, if $a_{i-1} \neq 1$, then $C(a_{i-1}, i-2)$ is small (bounded by a constant or growing much slower than $C(1, m)$). If $a_{i-1} = 1$, then $C(1, i-2) \le C(1, m-2)$. If $a_{m-1} = 1$, then $C(1, m-2) < C(1, m-1)$. If $a_{m-1} \neq 1$, then $C(1, m-2) = C(1, m-1)$, but we can choose $m$ large enough such that $C(1, m-1)$ is strictly greater than any $C(a_{i-1}, i-2)$ for $i \le m$ where $a_{i-1} \neq 1$.

Therefore, $C(a_{i-1}, i-2) < C(1, m-1)$ for all $i \le m$, which implies $C(K, m) = 0$. Thus, $a_{m+2} = 1 + 0 = 1$.

**3. Periodicity of Boys or Girls**
We have shown that if $a_m = 1$ for a sufficiently large $m$, then $a_{m+2} = 1$. By induction, $a_m = a_{m+2} = a_{m+4} = \dots = 1$.
The sequence $a_n$ consists of alternating boys and girls. If $m$ is odd, then $a_m, a_{m+2}, a_{m+4}, \dots$ are the numbers chosen by the boys $b_k, b_{k+1}, b_{k+2}, \dots$ for some $k$. If $m$ is even, they are the numbers chosen by the girls $g_k, g_{k+1}, g_{k+2}, \dots$.
In either case, one of the sequences $\{b_n\}_{n \ge M}$ or $\{g_n\}_{n \ge M}$ is eventually constant 1. A constant sequence is periodic with period 1.

Thus, at least one of the sequences $\{b_n\}_{n \ge M}$ or $\{g_n\}_{n \ge M}$ is periodic.

\(\square\)
