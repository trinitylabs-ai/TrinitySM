Let $\{x_m\}_{m \ge 1}$ be the sequence of numbers chosen by the people. For $m > N$, the recurrence is $x_m = 1 + c_{m-2}(x_{m-1})$, where $c_k(v)$ denotes the number of times $v$ appears in the sequence $x_1, \dots, x_k$.

1. The Set of Infinitely Occurring Values
Let $S$ be the set of positive integers that appear infinitely often in the sequence $\{x_m\}$.
First, $S$ is non-empty. If $S = \emptyset$, then for every $v \in \mathbb{Z}^+$, $c_m(v)$ is eventually constant. If the sequence $\{x_m\}$ is bounded, it must take some value infinitely often, so $S \neq \emptyset$. If $\{x_m\}$ is unbounded, then $x_m$ must take infinitely many distinct values. Whenever $x_{m-1}$ takes a value $v$ for the first time, $c_{m-2}(v) = 0$, so $x_m = 1 + 0 = 1$. Since $x_{m-1}$ takes infinitely many distinct values, the value 1 appears infinitely often, so $1 \in S$.

Second, we analyze the size of $S$. Let $n_k$ be the number of times the integer $k$ appears in the sequence. A value $k$ is produced at index $m$ if and only if $x_{m-1}$ is the $k$-th occurrence of some value $v$. Thus, $n_k = \#\{v \in \mathbb{Z}^+ \mid c_\infty(v) \ge k\}$.
If $S$ is infinite, then for all $v \in S$, $c_\infty(v) = \infty$. Thus $n_k \ge |S| = \infty$ for all $k$, which implies $S = \mathbb{Z}^+$.
If $S$ is finite, let $s = |S|$. Then for any $k \notin S$, $n_k$ must be finite. From the formula $n_k = s + \#\{v \notin S \mid c_\infty(v) \ge k\}$, this implies that for any $k \notin S$, only finitely many $v \notin S$ appear at least $k$ times.

2. Parity and Periodicity
Case 1: $S = \mathbb{Z}^+$.
Consider the indices $m$ where $x_m = 1$. These occur whenever $x_{m-1}$ is the first occurrence of some value $v$. Since $S = \mathbb{Z}^+$, there are infinitely many such $v$. Let $m_1 < m_2 < \dots$ be these indices. Then $x_{m_j} = 1$.
The next term is $x_{m_j+1} = 1 + c_{m_j-1}(1)$. As $j \to \infty$, $c_{m_j-1}(1) \to \infty$, so $x_{m_j+1} \to \infty$.
The indices $m_j$ and $m_j+1$ have opposite parity. One subsequence (say $\{g_n\}$) contains the values $x_{m_j} = 1$ infinitely often, while the other ($\{b_n\}$) contains the values $x_{m_j+1} \to \infty$.
If $x_m$ is eventually periodic, we are done. If not, we examine the structure. For large $j$, $x_{m_j} = 1$ and $x_{m_j+1} = j + C$. Then $x_{m_j+2} = 1 + c_{m_j}(j+C)$. Since $j+C$ is large, it has appeared very few times. In fact, $c_{m_j}(j+C)$ is the number of $v \in S$ that have already produced the value $j+C$. Since $S = \mathbb{Z}^+$, every $v$ produces $j+C$ exactly once. Thus $c_{m_j}(j+C)$ is the number of $v$ such that $c_{i-2}(v) = j+C-1$ for some $i \le m_j$.
As $j \to \infty$, the number of such $v$ is the number of $v$ that have appeared at least $j+C$ times. But for any fixed $m_j$, only finitely many $v$ have appeared that many times. Thus $x_{m_j+2}$ is bounded.
Since the sequence returns to bounded values on one parity, and the transitions are deterministic, the subsequence on that parity is eventually periodic.

Case 2: $S$ is finite.
Let $S = \{v_1, \dots, v_s\}$. For large $m$, if $x_{m-1} \in S$, then $c_{m-2}(x_{m-1}) \to \infty$, so $x_m = 1 + c_{m-2}(x_{m-1}) \to \infty$. Thus $x_m \notin S$.
Then $x_{m+1} = 1 + c_{m-1}(x_m)$. As $x_m$ is large, $c_{m-1}(x_m)$ is the number of $v \in S$ such that $c_{i-2}(v) = x_m - 1$ for some $i \le m$.
This count is exactly the number of $v \in S$ such that $c_{m-1}(v) \ge x_m$.
Since $x_m$ is produced by $x_{m-1} \in S$, and each $v \in S$ produces any large value $L$ exactly once, $c_{m-1}(x_m) \le s$.
Thus $x_{m+1} \le s+1$. Since $S$ is the set of values appearing infinitely often, the sequence must return to $S$.
For large $m$, if $x_{m-1} \in S$, then $x_m \notin S$ and $x_{m+1} \in S \cup \{1, \dots, s+1\}$.
This implies that all elements of $S$ eventually appear on indices of the same parity.
Let this parity be $p$. The subsequence $\{x_m\}_{m \equiv p \pmod 2}$ takes values in the finite set $S \cup \{1, \dots, s+1\}$.
The transition $x_{m-1} \to x_{m+1}$ is $x_{m+1} = 1 + \#\{v \in S \mid c_{m-1}(v) \ge 1 + c_{m-2}(x_{m-1})\}$.
As $m \to \infty$, the counts $c_{m-1}(v)$ for $v \in S$ all grow. The value $x_{m+1}$ depends only on the relative ranks of the counts of the elements of $S$.
Since there are only $s!$ possible rankings of the counts of $S$, the state $(x_{m-1}, \text{rankings})$ is finite.
Thus, the subsequence on parity $p$ is eventually periodic.

In all cases, at least one of $\{b_n\}$ or $\{g_n\}$ is eventually periodic.
