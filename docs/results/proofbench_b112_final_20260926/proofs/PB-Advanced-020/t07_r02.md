To find all pairs of positive integers $(x, y)$ such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we first simplify the expression for $a_n$:
$$a_n = \gcd \left( x^n + y, (y-x) \left( \sum_{i=0}^{n-1} y^i x^{n-i-1} - 1 \right) \right).$$
The sum $\sum_{i=0}^{n-1} y^i x^{n-i-1}$ is a geometric series. If $x = y$, the sum is $nx^{n-1}$. If $x \neq y$, the sum is $\frac{y^n - x^n}{y-x}$.

Case 1: $x = y$
If $x = y$, the second term in the $\gcd$ is $(x-x)(\dots) = 0$. Thus,
$$a_n = \gcd(x^n + x, 0) = x^n + x.$$
For the limit $\lim_{n \to \infty} a_n$ to exist, the sequence $x^n + x$ must be eventually constant. This occurs if and only if $x = 1$. If $x=1$, then $y=1$, and $a_n = 1^n + 1 = 2$ for all $n \ge 1$, which converges to 2. Thus, $(1, 1)$ is a solution.

Case 2: $x \neq y$
Substituting the sum formula into the expression for $a_n$:
$$a_n = \gcd \left( x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) \right) = \gcd(x^n + y, y^n - x^n - y + x).$$
Using the property $\gcd(A, B) = \gcd(A, A+B)$, we have:
$$a_n = \gcd(x^n + y, (x^n + y) + (y^n - x^n - y + x)) = \gcd(x^n + y, y^n + x).$$
Suppose the limit $\lim_{n \to \infty} a_n = L$ exists. Since $a_n$ is a sequence of integers, it must be eventually constant, so $a_n = L$ for all $n \ge N$.
Then $L$ must divide $x^n + y$ and $y^n + x$ for all $n \ge N$.
Consequently, $L$ must divide the difference:
$$L \mid (x^{n+1} + y) - x(x^n + y) = y - xy = y(1-x).$$
Similarly, $L \mid x(1-y)$.
Also, $L \mid (x^{n+1} + y) - (x^n + y) = x^n(x-1)$.
Let $g = \gcd(x, y)$. Let $x = gu$ and $y = gv$ with $\gcd(u, v) = 1$.
The sequence becomes $a_n = g \gcd(g^{n-1}u^n + v, g^{n-1}v^n + u)$.
Let $b_n = \gcd(g^{n-1}u^n + v, g^{n-1}v^n + u)$. For $a_n$ to converge, $b_n$ must converge to some $L' = L/g$.
If $p$ is a prime dividing $L'$, then $p$ cannot divide $g$ (because if $p \mid g$, then $p \mid g^{n-1}u^n + v \implies p \mid v$, and $p \mid g^{n-1}v^n + u \implies p \mid u$, contradicting $\gcd(u, v) = 1$).
Thus $\gcd(L', g) = 1$.
Since $L' \mid g^{n-1}u^n + v$ and $L' \mid g^n u^{n+1} + gv$ for $n \ge N$, we have:
$$L' \mid (g^n u^{n+1} + gv) - gu(g^{n-1} u^n + v) = gv(1-u).$$
Since $\gcd(L', g) = 1$ and $\gcd(L', v) = 1$ (as $p \mid L', p \mid v \implies p \mid g^{n-1}u^n \implies p \mid u$, contradiction), we have $L' \mid 1-u$. Similarly, $L' \mid 1-v$.
Then $g^{n-1}u^n + v \equiv g^{n-1}(1)^n + 1 \equiv g^{n-1} + 1 \pmod{L'}$.
Thus $L' \mid g^{n-1} + 1$ for all $n \ge N$. This implies $g^{n-1} \equiv -1 \pmod{L'}$ and $g^n \equiv -1 \pmod{L'}$, so $g = g^n/g^{n-1} \equiv 1 \pmod{L'}$.
Then $1 \equiv -1 \pmod{L'}$, so $L' \mid 2$. Thus $L' \in \{1, 2\}$.

We now show that $b_n$ cannot be eventually constant for $u \neq v$.
Note $b_1 = \gcd(u+v, v+u) = u+v$. Since $u \neq v$ and $u, v \ge 1$, $u+v > 2$.
Let $M$ be the largest divisor of $u+v$ such that $\gcd(M, g) = 1$.
If $M > 2$, then for $n-1$ being a multiple of $\phi(M)$, we have $g^{n-1} \equiv 1 \pmod M$ and $u^{n-1} \equiv 1 \pmod M$.
Then $g^{n-1}u^n + v \equiv u+v \equiv 0 \pmod M$ and $g^{n-1}v^n + u \equiv v+u \equiv 0 \pmod M$.
Thus $b_n$ is a multiple of $M$, so $b_n \ge M > 2$, which contradicts $b_n \in \{1, 2\}$ for $n \ge N$.
If $M = 1$, then all prime factors of $u+v$ divide $g$. Then for $n \ge 2$, $\gcd(b_n, u+v) = 1$ because $\gcd(b_n, g) = 1$. Since $u+v > 2$, $b_n$ cannot be constant as $b_1 = u+v$.
If $M = 2$, then $u+v = 2K$ where all prime factors of $K$ divide $g$.
If $L' = 1$, then $b_n$ is eventually 1, but for $n-1$ a multiple of $\phi(2)=1$, $b_n$ is a multiple of $M=2$, contradiction.
If $L' = 2$, then $b_n$ is eventually 2. This requires $g, u, v$ to be odd. But if $g, u, v$ are all odd, then $u+v$ is even and $\gcd(u+v, g)$ is odd. Thus $M$ would be the power of 2 dividing $u+v$. Since $u, v$ are odd and $u \neq v$, $u+v \ge 1+3=4$, so $M \ge 4$, contradiction.

Thus, no pairs $(x, y)$ with $x \neq y$ satisfy the condition. The only solution is $(1, 1)$.
