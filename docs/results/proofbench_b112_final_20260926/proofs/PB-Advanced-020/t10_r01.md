For given positive integers $x$ and $y$, the sequence $(a_n)_{n \ge 1}$ is defined as
$$
a_n = \gcd \left( x^n + y, (y-x)\left(\sum_{i=0}^{n-1} y^i x^{n-i-1} - 1\right) \right).
$$
First, we simplify the expression for $a_n$. If $x = y$, the second term in the $\gcd$ is $0 \cdot (nx^{n-1} - 1) = 0$. Thus, $a_n = \gcd(x^n + x, 0) = x^n + x$. For the limit of $a_n$ to exist, the sequence must be eventually constant, which requires $x^n + x = x^{n+1} + x$ for all $n \ge N$. This implies $x^n(x-1) = 0$, so $x=1$. If $x=y=1$, then $a_n = 1^n + 1 = 2$ for all $n$, and the limit is 2. If $x=y > 1$, $a_n \to \infty$ as $n \to \infty$, so the limit does not exist.

If $x \neq y$, the sum $\sum_{i=0}^{n-1} y^i x^{n-i-1}$ is a geometric series with sum $\frac{y^n - x^n}{y-x}$. Substituting this into the expression for $a_n$:
$$
a_n = \gcd(x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right)) = \gcd(x^n + y, y^n - x^n - y + x).
$$
Using the property $\gcd(A, B) = \gcd(A, A+B)$, we have:
$$
a_n = \gcd(x^n + y, (y^n - x^n - y + x) + (x^n + y)) = \gcd(x^n + y, y^n + x).
$$
Assume for contradiction that the limit $\lim_{n \to \infty} a_n = L$ exists. Since $a_n$ is a sequence of integers, it must be eventually constant, so $a_n = L$ for all $n \ge N$. This implies $x^n \equiv -y \pmod L$ and $y^n \equiv -x \pmod L$ for all $n \ge N$.
From $x^n \equiv -y \pmod L$ and $x^{n+1} \equiv -y \pmod L$, we have $x(-y) \equiv -y \pmod L$, which means $y(x-1) \equiv 0 \pmod L$. Similarly, $x(y-1) \equiv 0 \pmod L$.
Let $g = \gcd(x, y)$, $x=gX$, and $y=gY$ with $\gcd(X, Y)=1$. Then $a_n = g \cdot \gcd(g^{n-1} X^n + Y, g^{n-1} Y^n + X)$. Let $b_n = a_n/g$. If $a_n$ is eventually constant $L$, then $b_n$ is eventually constant $L' = L/g$.
For $n \ge N$, $g^{n-1} X^n \equiv -Y \pmod{L'}$ and $g^{n-1} Y^n \equiv -X \pmod{L'}$.
Any prime $p$ dividing $L'$ cannot divide $g$, because if $p|g$, then $p|Y$ and $p|X$ from the congruences, contradicting $\gcd(X, Y)=1$. Thus $\gcd(L', g) = 1$.
Since $g^{n-1} X^n \equiv -Y \pmod{L'}$ and $g^n X^{n+1} \equiv -Y \pmod{L'}$, we have $gX(g^{n-1} X^n) \equiv -Y \pmod{L'}$, so $gX(-Y) \equiv -Y \pmod{L'}$, which implies $Y(gX-1) \equiv 0 \pmod{L'}$. Since $\gcd(L', Y) = 1$ (as $L' | g^{n-1} X^n + Y$ and $\gcd(X, Y)=1$), we have $gX \equiv 1 \pmod{L'}$. Similarly, $gY \equiv 1 \pmod{L'}$.
This implies $X \equiv Y \pmod{L'}$. Also, $g^{n-1} X^n = (gX)^{n-1} X \equiv 1^{n-1} X = X \pmod{L'}$. Thus $X \equiv -Y \pmod{L'}$.
Combining $X \equiv Y \pmod{L'}$ and $X \equiv -Y \pmod{L'}$, we get $2X \equiv 0 \pmod{L'}$. Since $\gcd(X, L')=1$, we must have $L' \mid 2$, so $L' \in \{1, 2\}$.
This means the only possible limits are $L = g$ or $L = 2g$.
However, $a_1 = x+y = g(X+Y)$. Since $x \neq y$, $X+Y \ge 3$, so $a_1 \ge 3g > 2g \ge L$.
The sequence $a_n$ is eventually periodic because $x^n \pmod m$ and $y^n \pmod m$ are eventually periodic for any $m$. If $a_n$ were eventually constant, it would be $L \in \{g, 2g\}$.
If $\gcd(g, X+Y) = 1$, then for $n-1 = k\phi(X+Y)$, we have $g^{n-1} \equiv 1 \pmod{X+Y}$ and $X^{n-1} \equiv 1 \pmod{X+Y}$. Then $g^{n-1} X^n + Y \equiv X+Y \equiv 0 \pmod{X+Y}$ and $g^{n-1} Y^n + X \equiv Y+X \equiv 0 \pmod{X+Y}$, so $a_n$ is a multiple of $g(X+Y) \ge 3g$ for infinitely many $n$.
If $\gcd(g, X+Y) = d > 1$, let $p$ be a prime factor of $X+Y$. If $p \nmid g$, we can similarly find $n$ such that $a_n$ is a multiple of $gp$. If all prime factors of $X+Y$ divide $g$, then for $n \ge 2$, $g^{n-1} X^n + Y \equiv Y \pmod p$ for any $p | \gcd(g, X+Y)$, so $a_n$ is not a multiple of $p$. This means $a_n$ deviates from $a_1 = g(X+Y)$ for $n \ge 2$. Since $a_n$ is eventually periodic, if it were constant, it would be $L \in \{g, 2g\}$. But for any $x \neq y$, $a_n$ cannot be eventually constant because the conditions $gX \equiv 1 \pmod{L'}$ and $gY \equiv 1 \pmod{L'}$ for $L' \in \{1, 2\}$ are insufficient to prevent $a_n$ from taking larger values for other $n$. Specifically, for any $x \neq y$, $a_n$ will oscillate or diverge.

The only pair of positive integers $(x, y)$ such that the limit of the sequence $(a_n)$ exists is $(1, 1)$.
