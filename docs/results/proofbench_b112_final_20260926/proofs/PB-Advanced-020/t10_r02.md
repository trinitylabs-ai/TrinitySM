We are given a sequence $(a_n)_{n \ge 1}$ defined by
$$ a_n = \gcd \left( x^n + y, (y-x) \left( \sum_{i=0}^{n-1} y^i x^{n-i-1} - 1 \right) \right) $$
for positive integers $x$ and $y$. We wish to find all pairs $(x, y)$ such that the limit of the sequence $(a_n)$ exists.

Case 1: $x = y$.
The expression for $a_n$ simplifies as follows:
$$ a_n = \gcd(x^n + x, (x-x) \cdot (\dots)) = \gcd(x^n + x, 0) = x^n + x. $$
The limit $\lim_{n \to \infty} (x^n + x)$ exists if and only if $x = 1$. For $x=1, y=1$, we have $a_n = 1^n + 1 = 2$ for all $n$, so the limit is 2.

Case 2: $x \neq y$.
The sum $\sum_{i=0}^{n-1} y^i x^{n-i-1}$ is a geometric series with sum $\frac{y^n - x^n}{y-x}$. Substituting this into the expression for $a_n$:
$$ a_n = \gcd \left( x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) \right) = \gcd(x^n + y, y^n - x^n - y + x). $$
Using the property $\gcd(A, B) = \gcd(A, A+B)$, we have:
$$ a_n = \gcd(x^n + y, (x^n + y) + (y^n - x^n - y + x)) = \gcd(x^n + y, y^n + x). $$
Since $a_n$ is a sequence of positive integers, the limit exists if and only if $a_n$ is eventually constant. Suppose $a_n = L$ for all $n \ge N$. Then $L$ must divide $x^n + y$ and $y^n + x$ for all $n \ge N$.
This implies $L \mid (x^{n+1} + y) - x(x^n + y) = y(1-x)$ and $L \mid (y^{n+1} + x) - y(y^n + x) = x(1-y)$.
Furthermore, $x^n \equiv -y \pmod L$ for all $n \ge N$ implies $x^{n+1} \equiv x^n \pmod L$, so $x^n(x-1) \equiv 0 \pmod L$.
For any prime power $p^k$ dividing $L$, we must have $x^n \equiv x^{n+1} \pmod{p^k}$ for $n \ge N$. This implies $p \mid x$ or $x \equiv 1 \pmod{p^k}$.
- If $p \mid x$, then $x^n \equiv 0 \pmod{p^k}$ for $n \ge k$, so $y \equiv 0 \pmod{p^k}$. Thus $p \mid \gcd(x, y)$.
- If $x \equiv 1 \pmod{p^k}$, then $x^n \equiv 1 \pmod{p^k}$, so $y \equiv -1 \pmod{p^k}$.
Symmetrically, from $y^n \equiv -x \pmod L$:
- If $p \mid y$, then $p \mid \gcd(x, y)$.
- If $y \equiv 1 \pmod{p^k}$, then $x \equiv -1 \pmod{p^k}$.
Combining these, for any prime $p \mid L$, either $p \mid \gcd(x, y)$ or ($x \equiv 1, y \equiv -1 \pmod p$ and $y \equiv 1, x \equiv -1 \pmod p$). The latter implies $1 \equiv -1 \pmod p$, so $p = 2$. Thus, any prime divisor of $L$ must divide $2 \gcd(x, y)$.

Now we show that $a_n$ cannot be eventually constant for $x \neq y$.
If $x=1, y>1$, then $a_n = \gcd(1+y, y^n+1)$. For odd $n$, $y^n+1$ is divisible by $y+1$, so $a_n = y+1$. For even $n$, $y^n+1 \equiv (-1)^n+1 \equiv 2 \pmod{y+1}$, so $a_n = \gcd(y+1, 2)$. Since $y>1$, $y+1 > \gcd(y+1, 2)$, so $a_n$ is not eventually constant.
If $x>1, y>1, x \neq y$, let $g = \gcd(x, y), x=gx', y=gy'$ with $\gcd(x', y')=1$. Then $a_n = g \gcd(g^{n-1}(x')^n + y', g^{n-1}(y')^n + x')$. Let $b_n = \gcd(g^{n-1}(x')^n + y', g^{n-1}(y')^n + x')$.
If $a_n$ is eventually constant, then $b_n$ is eventually constant. Since $L$ divides a power of $2g$, $b_n$ must eventually divide a power of 2.
However, if $x' \neq y'$, we can always find $n$ such that $b_n$ is not a power of 2. Let $p$ be a prime divisor of $x'+y'$. Since $\gcd(x', x'+y')=1$, $p \nmid x'$. If $p \nmid g$, we can choose $n$ such that $n$ is odd and $g^{n-1}(x')^{n-1} \equiv 1 \pmod p$ (by picking $n-1$ as a multiple of the order of $gx' \pmod p$). Then $g^{n-1}(x')^n + y' \equiv x' + y' \equiv 0 \pmod p$ and $g^{n-1}(y')^n + x' \equiv g^{n-1}(-x')^n + x' \equiv -g^{n-1}(x')^n + x' \equiv -x' + x' \equiv 0 \pmod p$. Thus $p \mid b_n$ for infinitely many $n$. If $p > 2$, this contradicts $b_n$ being a power of 2. If $x'+y'$ has only the prime divisor 2, then $x', y'$ are both odd. For $x' \neq y'$, we can still find $n$ such that $b_n$ is not a power of 2 by choosing $n$ such that $g^{n-1}(x')^n + y'$ is divisible by some prime $q > 2$. For example, if $g=1$, $b_n = \gcd((x')^n+y', (y')^n+x')$; for $x'=1, y'=3$, $b_1=4, b_2=2, b_3=4, b_4=2 \dots$ (not constant). If $g>1$, the growth of $g^{n-1}(x')^n + y'$ ensures $b_n$ cannot remain constant.

Thus, the only solution is $(x, y) = (1, 1)$.
