Let $a_1, a_2, \dots, a_{18}$ be 18 real numbers with average $m$. Let $x_i = a_i - m$ for $i = 1, \dots, 18$. Then $\sum_{i=1}^{18} x_i = 0$, and the condition $a_i + a_j + a_k \ge 3m$ is equivalent to $x_i + x_j + x_k \ge 0$. Let $A$ be the number of such triples $1 \le i < j < k \le 18$.

First, we show that $A = 136$ is achievable. Let $x_1 = x_2 = \dots = x_{17} = -1$ and $x_{18} = 17$. The sum of any triple not containing $x_{18}$ is $-3 < 0$. The sum of any triple containing $x_{18}$ is $x_i + x_j + 17 = -1 - 1 + 17 = 15 \ge 0$ for $1 \le i < j \le 17$. There are $\binom{17}{2} = \frac{17 \times 16}{2} = 136$ such triples. Thus, $A = 136$ is possible.

To prove that $A \ge 136$ for any set of $x_i$ summing to 0, we consider the number of "bad" triples $B$, which are those with $x_i + x_j + x_k < 0$. Since there are $\binom{18}{3} = 816$ total triples, $A = 816 - B$. We aim to show that $B \le 680$.

Let $x_1 \le x_2 \le \dots \le x_{18}$. Let $k$ be the number of negative $x_i$. If $k=0$, then all $x_i = 0$ and $B=0$. If $k > 0$, let $y_i = -x_i > 0$ for $i=1, \dots, k$ and $z_j = x_j \ge 0$ for $j=k+1, \dots, 18$. The condition $\sum x_i = 0$ implies $\sum_{i=1}^k y_i = \sum_{j=k+1}^{18} z_j = S$.

A triple is bad if its sum is negative. The possible bad triples are:
1. Three negative numbers: $\binom{k}{3}$ triples.
2. Two negative numbers $y_i, y_j$ and one non-negative number $z_l$ such that $y_i + y_j > z_l$.
3. One negative number $y_i$ and two non-negative numbers $z_j, z_l$ such that $y_i > z_j + z_l$.

To maximize $B$, we should make the non-negative values $z_l$ as small as possible. For a fixed $k$, $B$ is maximized when $z_{k+1} = z_{k+2} = \dots = z_{17} = 0$ and $z_{18} = S$. In this configuration:
- The $\binom{k}{3}$ triples of negative numbers are all bad.
- For $l \in \{k+1, \dots, 17\}$, $z_l = 0$, so all $\binom{k}{2} \times (17-k)$ triples $(i, j, l)$ are bad.
- For $l = 18$, $z_{18} = S$, so $y_i + y_j > S$ is impossible since $y_i + y_j \le S$.
- For $i \in \{1, \dots, k\}$ and $j, l \in \{k+1, \dots, 17\}$, $z_j + z_l = 0$, so all $k \times \binom{17-k}{2}$ triples $(i, j, l)$ are bad.
- For $i \in \{1, \dots, k\}$ and $j \in \{k+1, \dots, 17\}, l=18$, $z_j + z_{18} = S$, so $y_i > S$ is impossible.

Thus, for a fixed $k$, the maximum $B$ is:
$B(k) = \binom{k}{3} + \binom{k}{2}(17-k) + k\binom{17-k}{2}$
$B(k) = \frac{k(k-1)(k-2)}{6} + \frac{k(k-1)(17-k)}{2} + \frac{k(17-k)(16-k)}{2}$
$B(k) = \frac{k}{6} [ (k^2-3k+2) + 3(18k-k^2-17) + 3(k^2-33k+272) ]$
$B(k) = \frac{k}{6} [ k^2-3k+2 + 54k-3k^2-51 + 3k^2-99k+816 ]$
$B(k) = \frac{k}{6} [ k^2 - 48k + 767 ]$

Evaluating $B(k)$ for $k \in \{1, \dots, 17\}$:
- For $k=17$, $B(17) = \frac{17}{6}(289 - 816 + 767) = \frac{17}{6}(240) = 680$.
- For $k=16$, $B(16) = \frac{16}{6}(256 - 768 + 767) = \frac{16}{6}(255) = 680$.
- For $k=15$, $B(15) = \frac{15}{6}(225 - 720 + 767) = \frac{15}{6}(272) = 680$.
- For $k=14$, $B(14) = \frac{14}{6}(196 - 672 + 767) = \frac{14}{6}(291) = 679$.
As $k$ decreases further, $B(k)$ continues to decrease. The maximum value of $B$ is 680. Therefore, $A = 816 - B \ge 816 - 680 = 136$.

The minimum possible value of $A$ is 136.
