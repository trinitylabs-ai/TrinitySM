Let $a_1, a_2, \dots, a_{18}$ be 18 real numbers with average $m$. We wish to minimize the number of triples $1 \le i < j < k \le 18$ such that $a_i + a_j + a_k \ge 3m$. Let $x_i = a_i - m$. Then $\sum_{i=1}^{18} x_i = 0$, and the condition $a_i + a_j + a_k \ge 3m$ is equivalent to $x_i + x_j + x_k \ge 0$. Let $A$ denote the number of such triples.

First, we show that $A=136$ is achievable. Let $x_1 = 17$ and $x_2 = x_3 = \dots = x_{18} = -1$. The sum is $\sum x_i = 17 + 17(-1) = 0$. A triple $(i, j, k)$ has a non-negative sum if and only if it contains $x_1$, because any triple not containing $x_1$ has sum $-1-1-1 = -3 < 0$, and any triple containing $x_1$ has sum $17-1-1 = 15 \ge 0$. The number of such triples is $\binom{17}{2} = \frac{17 \times 16}{2} = 136$.

To prove that $A \ge 136$ for any configuration, let $p$ be the number of strictly positive elements among $x_1, \dots, x_{18}$. If $p=0$, then all $x_i \le 0$. Since $\sum x_i = 0$, we must have $x_i = 0$ for all $i$, in which case $A = \binom{18}{3} = 816$. Thus, we assume $1 \le p \le 17$. Let the positive elements be $x_1, \dots, x_p$ and the non-positive elements be $x_{p+1}, \dots, x_{18}$. Let $y_k = -x_k \ge 0$ for $k=p+1, \dots, 18$. Let $S = \sum_{i=1}^p x_i = \sum_{k=p+1}^{18} y_k$. Let $q = 18-p$.

The number of non-negative triples $A$ is at least the sum of:
1. Triples with 3 positive elements: $\binom{p}{3}$ triples.
2. Triples with 2 positive elements $x_i, x_j$ and 1 non-positive $-y_k$: $S_2 = \sum_{1 \le i < j \le p} \sum_{k=p+1}^{18} \mathbb{I}(x_i + x_j \ge y_k)$.
3. Triples with 1 positive element $x_i$ and 2 non-positive $-y_j, -y_k$: $S_1 = \sum_{i=1}^p \sum_{p+1 \le j < k \le 18} \mathbb{I}(x_i \ge y_j + y_k)$.

We analyze $A$ for different values of $p$:

Case $p=1$: Let $x_1 = S$. Then $S_2 = 0$. $S_1 = \sum_{p+1 \le j < k \le 18} \mathbb{I}(S \ge y_j + y_k)$. Since $y_j + y_k \le \sum y_m = S$, all $\binom{17}{2} = 136$ pairs $(j, k)$ satisfy the condition. Thus $A \ge 136$.

Case $p=2$: Let $x_1, x_2$ be the positive elements. Then $x_1 + x_2 = S$.
$S_2 = \sum_{k=3}^{18} \mathbb{I}(x_1 + x_2 \ge y_k) = \sum_{k=3}^{18} \mathbb{I}(S \ge y_k) = q = 16$.
$S_1 = \sum_{3 \le j < k \le 18} (\mathbb{I}(x_1 \ge y_j + y_k) + \mathbb{I}(x_2 \ge y_j + y_k))$.
For any fixed pair $j < k$, let $z_{jk} = y_j + y_k$. Since $z_{jk} \le S$, at least one of $x_1, x_2$ must be $\ge z_{jk}$ if $z_{jk} \le S/2$. If $z_{jk} > S/2$, it is possible that both $x_1, x_2 < z_{jk}$. However, if we concentrate the positive values such that $x_1 \to 0$ and $x_2 \to S$, then $\mathbb{I}(x_1 \ge z_{jk}) + \mathbb{I}(x_2 \ge z_{jk}) = 0 + 1 = 1$ for all $z_{jk} < S$. In this limit, $S_1 = \binom{16}{2} = 120$.
Thus $A \ge 0 + 16 + 120 = 136$. (Any other distribution of $x_1, x_2$ such as $x_1=x_2=S/2$ would make $S_1 = 2 \times |\{z_{jk} \le S/2\}|$, which for $q=16$ is $\ge 2 \binom{14}{2} = 182 > 120$).

Case $p=3$: Let $x_1, x_2, x_3$ be the positive elements.
$S_1 = \sum_{j < k} n(z_{jk})$, where $n(z)$ is the number of $x_i \ge z$.
$S_2 = \sum_k (\mathbb{I}(x_1+x_2 \ge y_k) + \mathbb{I}(x_1+x_3 \ge y_k) + \mathbb{I}(x_2+x_3 \ge y_k))$.
In the limit $x_1, x_2 \to 0$ and $x_3 \to S$, we have $n(z_{jk}) = 1$ for all $j, k$, so $S_1 = \binom{15}{2} = 105$.
For $S_2$, we have $\mathbb{I}(x_1+x_2 \ge y_k) \to 0$ and $\mathbb{I}(x_1+x_3 \ge y_k) \to 1$ and $\mathbb{I}(x_2+x_3 \ge y_k) \to 1$ (since $S \ge y_k$).
Thus $S_2 = 0 + q + q = 2(15) = 30$.
$A \ge \binom{3}{3} + 30 + 105 = 1 + 30 + 105 = 136$.

For $p \ge 4$, we consider the boundary configuration $x_1, \dots, x_{p-1} \to 0$ and $x_p \to S$.
Then $S_1 = \binom{q}{2}$ and $S_2 = (p-1)q$.
$A(p) = \binom{p}{3} + (p-1)q + \binom{q}{2}$.
Substituting $q = 18-p$:
$A(p) = \frac{p(p-1)(p-2)}{6} + (p-1)(18-p) + \frac{(18-p)(17-p)}{2} = 136 + \frac{(p-1)(p-2)(p-3)}{6}$.
For $p \ge 4$, $A(p) \ge 136 + \frac{3 \cdot 2 \cdot 1}{6} = 137$.

Since $A \ge 136$ for all $1 \le p \le 17$ and $A=816$ for $p=0$, the minimum possible value of $A$ is 136.
