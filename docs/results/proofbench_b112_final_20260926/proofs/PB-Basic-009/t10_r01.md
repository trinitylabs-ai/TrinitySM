Let $a_1, a_2, \dots, a_{18}$ be 18 real numbers with average $m$. Let $x_i = a_i - m$ for $i=1, \dots, 18$. The condition that the average of $a_i$ is $m$ implies that $\sum_{i=1}^{18} x_i = 0$. The condition $a_i + a_j + a_k \ge 3m$ is equivalent to $x_i + x_j + x_k \ge 0$. We wish to minimize the number of such triples $A$.

First, we show that $A=136$ is possible. Let $x_1 = x_2 = \dots = x_{17} = -1$ and $x_{18} = 17$. The sum is $\sum x_i = 17(-1) + 17 = 0$. A triple $(i, j, k)$ has $x_i + x_j + x_k \ge 0$ if and only if it contains $x_{18}$, because if it does not, the sum is $-1-1-1 = -3 < 0$. If it contains $x_{18}$, the sum is $17-1-1 = 15 \ge 0$. The number of such triples is $\binom{17}{2} = \frac{17 \cdot 16}{2} = 136$. Thus, the minimum possible value of $A$ is at most 136.

Next, we prove that $A \ge 136$ for any set of $x_i$ with $\sum x_i = 0$. Let $k$ be the number of positive elements among $x_1, \dots, x_{18}$.
If $k=0$, then all $x_i \le 0$. Since $\sum x_i = 0$, we must have $x_i = 0$ for all $i$. Then every triple has sum $0 \ge 0$, so $A = \binom{18}{3} = 816 \ge 136$.
If $k=1$, let $x_{18} = S > 0$ be the only positive element, and $x_1, \dots, x_{17} \le 0$. Then $S = \sum_{i=1}^{17} |x_i|$. For any $1 \le i < j \le 17$, the triple $\{x_i, x_j, x_{18}\}$ has sum $S - |x_i| - |x_j| = \sum_{m \in \{1, \dots, 17\} \setminus \{i,j\}} |x_m| \ge 0$. There are $\binom{17}{2} = 136$ such triples, so $A \ge 136$.

If $k \ge 2$, let the positive elements be $p_1, \dots, p_k$ and the non-positive elements be $n_1, \dots, n_{18-k}$. Let $S = \sum p_i = \sum |n_j|$.
To find a lower bound for $A$ for a fixed $k$, we consider the configuration where $k-1$ of the positive elements are very small ($\epsilon \to 0^+$) and the non-positive elements are equal. Let $p_1 = S - (k-1)\epsilon$ and $p_2 = \dots = p_k = \epsilon$, and $n_1 = \dots = n_{18-k} = -S/(18-k)$.
In this limiting configuration, the triples with sum $\ge 0$ are:
1. Triples with three positive elements: $\binom{k}{3}$ triples.
2. Triples with two positive elements: A triple $\{p_i, p_j, n_l\}$ has sum $\ge 0$ if it contains $p_1$, since $p_1 + p_j + n_l \approx S + 0 - S/(18-k) > 0$. If it does not contain $p_1$, the sum is $\approx 0 + 0 - S/(18-k) < 0$. There are $(k-1)(18-k)$ such triples.
3. Triples with one positive element: A triple $\{p_i, n_j, n_l\}$ has sum $\ge 0$ if it contains $p_1$ and $S - 2S/(18-k) \ge 0$, which is true if $18-k \ge 2$. If it contains $p_i$ for $i \ge 2$, the sum is $\approx 0 - 2S/(18-k) < 0$. There are $\binom{18-k}{2}$ such triples.
4. Triples with zero positive elements: These have sum $\approx -3S/(18-k) < 0$.

For $k \le 16$, the number of non-negative triples in this configuration is $A(k) = \binom{k}{3} + (k-1)(18-k) + \binom{18-k}{2}$.
Evaluating $A(k)$ for small $k$:
- $A(2) = 0 + 1(16) + \binom{16}{2} = 16 + 120 = 136$.
- $A(3) = 1 + 2(15) + \binom{15}{2} = 1 + 30 + 105 = 136$.
- $A(4) = 4 + 3(14) + \binom{14}{2} = 4 + 42 + 91 = 137$.
The function $f(k) = \frac{1}{6}k^3 - k^2 + \frac{11}{6}k + 135$ represents $A(k)$, and its derivative $f'(k) = \frac{1}{2}k^2 - 2k + \frac{11}{6}$ is positive for $k \ge 3$. Thus $A(k)$ is non-decreasing for $k \ge 3$. For $k > 16$, $A(k) \ge \binom{k}{3} \ge \binom{17}{3} = 680$.
In all cases, $A \ge 136$.

The minimum possible value of $A$ is 136.
