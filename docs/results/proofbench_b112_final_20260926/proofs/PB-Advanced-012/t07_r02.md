To prove that $n \geq 5$ for the equation $p^n = a^4 + b^4$, where $p$ is a prime and $a, b$ are positive integers, we analyze the constraints on $n \geq 2$.

**1. Parity of $n$**
If $n$ is even, let $n = 2k$ for some integer $k \geq 1$. The equation becomes $a^4 + b^4 = (p^k)^2$. According to Fermat's Theorem on the equation $x^4 + y^4 = z^2$, there are no solutions in positive integers. Thus, $n$ must be odd. Since $n \geq 2$, we have $n \in \{3, 5, 7, \dots\}$.

**2. The Case $n=3$**
Suppose $n=3$, so $p^3 = a^4 + b^4$. Let $d = \gcd(a, b)$. Then $a = dA$ and $b = dB$ with $\gcd(A, B) = 1$. The equation is:
\[ p^3 = d^4(A^4 + B^4) \]
Since $p$ is prime, $d$ must be a power of $p$. If $d = p^k$ for $k \geq 1$, then $d^4 \geq p^4$, implying $p^3 \geq p^4(A^4 + B^4)$, which is impossible since $A^4 + B^4 \geq 2$. Thus, $d = 1$, and we must have $p^3 = A^4 + B^4$ with $\gcd(A, B) = 1$.

If $p=2$, then $A^4 + B^4 = 8$, which implies $A=B=1$ (since $2^4 > 8$). However, $1^4 + 1^4 = 2 \neq 8$. Thus, $p$ must be an odd prime.
Since $p$ is odd, $A$ and $B$ must have opposite parity. Assume $A$ is odd and $B$ is even. We factor the equation in the Gaussian integers $\mathbb{Z}[i]$:
\[ (A^2 + iB^2)(A^2 - iB^2) = p^3 \]
The greatest common divisor $\delta = \gcd(A^2 + iB^2, A^2 - iB^2)$ divides $2A^2$ and $2iB^2$. Since $A^2 + iB^2$ is odd, $\delta$ must be a unit. Thus, $A^2 + iB^2$ is a cube (up to a unit) in $\mathbb{Z}[i]$. Since all units in $\mathbb{Z}[i]$ are cubes, we have:
\[ A^2 + iB^2 = (x + iy)^3 = (x^3 - 3xy^2) + i(3x^2y - y^3) \]
Equating real and imaginary parts:
1) $A^2 = x(x^2 - 3y^2)$
2) $B^2 = y(3x^2 - y^2)$
Given $\gcd(A, B) = 1$, we have $\gcd(x, y) = 1$. From (1), $\gcd(x, x^2 - 3y^2) = \gcd(x, 3)$.

**Case 1: $\gcd(x, 3) = 1$.**
Then $x = u^2$ and $x^2 - 3y^2 = v^2$. From (2), $B^2 = y(3u^4 - y^2)$. Since $\gcd(x, y) = 1$, $\gcd(y, 3u^4 - y^2) = \gcd(y, 3)$.
- If $\gcd(y, 3) = 1$, then $y$ and $3u^4 - y^2$ are both squares. Let $y = s^2$. Then $3u^4 - s^4 = t^2$. Modulo 3, this gives $t^2 \equiv -s^4 \equiv 2 \pmod 3$, which is impossible.
- If $\gcd(y, 3) = 3$, let $y = 3s^2$. Then $B^2 = 3s^2(3u^4 - 9s^4) = 9s^2(u^4 - 3s^4)$, so $u^4 - 3s^4 = t^2$.
We analyze $u^4 - 3s^4 = t^2$ with $\gcd(u, s) = 1$.
If $u$ is odd and $s$ is even, then $t$ is odd. $(u^2 - t)(u^2 + t) = 3s^4$. Let $\gcd(u, t) = g$. Then $g$ divides $3s^4$, and since $\gcd(u, s) = 1$, $g$ must be 1 or 3. If $g=3$, then $3|u$ and $3|t$, so $81U^4 - 9T^2 = 3s^4 \implies 27U^4 - 3T^2 = s^4$, implying $3|s$, contradicting $\gcd(u, s)=1$. If $g=1$, then $\gcd(u^2 - t, u^2 + t) = 2$. Thus $\{u^2 - t, u^2 + t\} = \{2m^4, 6n^4\}$ or $\{6m^4, 2n^4\}$. In either case, $s^4 = \frac{(u^2 - t)(u^2 + t)}{3} = 4m^4n^4$, so $s^2 = 2m^2n^2$, which is impossible for $m, n \neq 0$.
If $u$ is even and $s$ is odd, then $t$ is odd. $(u^2 - t)(u^2 + t) = 3s^4$. Since $u^2 - t$ is odd, $\gcd(u^2 - t, u^2 + t) = \gcd(u^2 - t, u^2)$. Any prime dividing this gcd must divide $u$ and $t$, and thus divide $3s^4$, so it must be 3. If $3 \nmid u$, then $\gcd(u^2 - t, u^2 + t) = 1$, so $\{u^2 - t, u^2 + t\} = \{m^4, 3n^4\}$ or $\{3m^4, n^4\}$. Then $2u^2 = m^4 + 3n^4$. Since $s$ is odd, $m$ and $n$ are odd, so $m^4 + 3n^4 \equiv 1 + 3 \equiv 4 \pmod 8$. However, $u$ even implies $2u^2 \equiv 0 \pmod 8$, a contradiction. If $3 | u$, then $3 | t$, and as before, this implies $3 | s$, contradicting $\gcd(u, s) = 1$.

**Case 2: $\gcd(x, 3) = 3$.**
Let $x = 3X$. Then $A^2 = 3X(9X^2 - 3y^2) = 9X(3X^2 - y^2)$. Thus $X = u^2$ and $3X^2 - y^2 = v^2$, so $3u^4 - y^2 = v^2$.
From (2), $B^2 = y(3(3u^2)^2 - y^2) = y(27u^4 - y^2)$. Since $\gcd(x, y) = 1$, $\gcd(y, 3) = 1$. Thus $y = s^2$ and $27u^4 - s^4 = t^2$.
From $3u^4 - y^2 = v^2$ and $y=s^2$, we have $v^2 + s^4 = 3u^4$.
Modulo 3, this implies $v^2 + s^4 \equiv 0 \pmod 3$, which requires $v \equiv 0 \pmod 3$ and $s \equiv 0 \pmod 3$.
Let $v = 3V$ and $s = 3S$. Substituting these into the equation:
$9V^2 + 81S^4 = 3u^4 \implies 3V^2 + 27S^4 = u^4$.
This implies $u^4 \equiv 0 \pmod 3$, so $u = 3U$.
$3V^2 + 27S^4 = 81U^4 \implies V^2 + 9S^4 = 27U^4$.
This implies $V^2 \equiv 0 \pmod 3$, so $V = 3V_1$.
$9V_1^2 + 9S^4 = 27U^4 \implies V_1^2 + S^4 = 3U^4$.
This is the same form as the equation $v^2 + s^4 = 3u^4$. By the method of infinite descent, the only solution is $u=s=v=0$, which contradicts $a, b$ being positive integers.

Since all cases for $n=3$ result in contradictions, $n \neq 3$. Given $n$ is odd and $n \geq 2$, we must have $n \geq 5$.

\(\square\)
