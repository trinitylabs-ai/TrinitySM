To prove that $n \geq 5$ given the equation $p^n = a^4 + b^4$ for a prime $p$ and positive integers $a, b$ with $n \geq 2$, we analyze the problem by considering the parity of the prime $p$.

### Case 1: $p = 2$
Substituting $p=2$ into the equation, we have $2^n = a^4 + b^4$.
Since $2^n$ is even, $a$ and $b$ must have the same parity.
If $a$ and $b$ are both odd, then $a^4 \equiv 1 \pmod{16}$ and $b^4 \equiv 1 \pmod{16}$, which implies $a^4 + b^4 \equiv 2 \pmod{16}$.
The equation $2^n \equiv 2 \pmod{16}$ holds if and only if $n=1$. However, we are given $n \geq 2$.

Therefore, $a$ and $b$ must both be even. Let $a = 2^k a_0$ and $b = 2^k b_0$ where $k \geq 1$ and at least one of $a_0, b_0$ is odd. Substituting these into the equation:
\[ 2^n = (2^k a_0)^4 + (2^k b_0)^4 = 2^{4k}(a_0^4 + b_0^4) \implies a_0^4 + b_0^4 = 2^{n-4k} \]
Since $a_0^4 + b_0^4$ is a power of 2 and at least one of $a_0, b_0$ is odd, both must be odd. As established, if $a_0$ and $b_0$ are odd, then $a_0^4 + b_0^4 \equiv 2 \pmod{16}$. This implies $2^{n-4k} = 2$, so $n-4k = 1$, which gives $n = 4k + 1$.
For $k \geq 1$, the smallest possible value for $n$ is $4(1) + 1 = 5$. Thus, if $p=2$, then $n \geq 5$.

### Case 2: $p > 2$
Let $d = \gcd(a, b)$. Then $d^4$ must divide $p^n$, so $d = p^k$ for some $k \geq 0$.
We can write $a = p^k a_1$ and $b = p^k b_1$ where $\gcd(a_1, b_1) = 1$. Substituting these into the equation:
\[ p^n = p^{4k}(a_1^4 + b_1^4) \implies a_1^4 + b_1^4 = p^{n-4k} \]
Let $m = n - 4k$. We examine the possible values for $m$:
1.  **If $m = 1$**: Then $n = 4k + 1$. Since $n \geq 2$, we must have $k \geq 1$, which implies $n \geq 5$.
2.  **If $m = 2$**: We have $a_1^4 + b_1^4 = p^2$. This is a case of the equation $x^4 + y^4 = z^2$, which Fermat proved has no solutions in positive integers. Thus, $m=2$ is impossible.
3.  **If $m = 3$**: We have $a_1^4 + b_1^4 = p^3$ with $\gcd(a_1, b_1) = 1$.
    If $p \equiv 3 \pmod 4$, then $a_1^4 + b_1^4 \equiv 0 \pmod p$ implies $a_1^2 \equiv 0 \pmod p$ and $b_1^2 \equiv 0 \pmod p$ (since $-1$ is not a quadratic residue modulo $p$), contradicting $\gcd(a_1, b_1) = 1$.
    If $p \equiv 1 \pmod 4$, we work in the Gaussian integers $\mathbb{Z}[i]$. Then $p = \pi \bar{\pi}$ for some prime $\pi \in \mathbb{Z}[i]$.
    $a_1^4 + b_1^4 = (a_1^2 + ib_1^2)(a_1^2 - ib_1^2) = p^3 = \pi^3 \bar{\pi}^3$.
    Since $\gcd(a_1^2 + ib_1^2, a_1^2 - ib_1^2)$ divides $2a_1^2$ and $2ib_1^2$, and $p$ is odd, the factors are coprime. Thus $a_1^2 + ib_1^2 = u \pi^3$ for some unit $u \in \{1, -1, i, -i\}$.
    Let $\pi = x + iy$. Then $a_1^2 + ib_1^2 = u(x + iy)^3$. This implies that $\{a_1^2, b_1^2\} = \{|x(x^2 - 3y^2)|, |y(3x^2 - y^2)|\}$ for some $x, y$ with $\gcd(x, y) = 1$ and $p = x^2 + y^2$.
    If $3 \nmid x$ and $3 \nmid y$, then $x, x^2 - 3y^2, y, 3x^2 - y^2$ must be squares up to a sign. Let $x = \pm u^2, y = \pm v^2$. Then $u^4 - 3v^4 = \pm w^2$ and $3u^4 - v^4 = \pm z^2$. Modulo 3, $3u^4 - v^4 = z^2 \implies z^2 \equiv -v^4 \pmod 3$, which is impossible since $3 \nmid v$. Thus $3u^4 - v^4 = -z^2$, so $v^4 - 3u^4 = z^2$. Similarly, $u^4 - 3v^4 = w^2$ or $u^4 - 3v^4 = -w^2$. If $u^4 - 3v^4 = -w^2$, then $3v^4 - u^4 = w^2$, which implies $w^2 \equiv -u^4 \pmod 3$, impossible since $3 \nmid u$. Thus $u^4 - 3v^4 = w^2$. But $u^4 > 3v^4$ and $v^4 > 3u^4$ cannot both be true for positive $u, v$.
    If $3|x$, let $x = 3X$. Then $a_1^2 = 9|X(3X^2 - y^2)|$ and $b_1^2 = |y(27X^2 - y^2)|$. Since $\gcd(X, y) = 1$, this implies $|X|, |3X^2 - y^2|, |y|, |27X^2 - y^2|$ are all squares. Let $X = \pm u^2$ and $y = \pm s^2$. Then $|3u^4 - s^4| = v^2$ and $|27u^4 - s^4| = t^2$.
    Since $3 \nmid s$, $3u^4 - s^4 = v^2 \implies v^2 \equiv -s^4 \equiv 2 \pmod 3$, which is impossible. Thus $s^4 - 3u^4 = v^2$. This is a known Diophantine equation $x^4 - 3y^4 = z^2$, which has no solutions in positive integers. Thus $m=3$ is impossible.
4.  **If $m = 4$**: We have $a_1^4 + b_1^4 = p^4$, which has no positive integer solutions by Fermat's Last Theorem.
5.  **If $m \geq 5$**: Then $n = m + 4k \geq 5$.

In all possible cases for $p > 2$, we find that $n \geq 5$.

Combining the results from Case 1 and Case 2, we conclude that $n \geq 5$ for any prime $p$ and positive integers $a, b$ such that $p^n = a^4 + b^4$ and $n \geq 2$.
