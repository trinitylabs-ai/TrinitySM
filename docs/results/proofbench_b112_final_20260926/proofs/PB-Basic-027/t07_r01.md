To prove that $XO$ is perpendicular to $DE$, we use a coordinate geometry approach.

Let $C$ be the origin $(0, 0)$ and let the side $CA$ lie along the $x$-axis. Let $A = (a, 0)$. Since $\triangle ABC$ is acute, the foot of the altitude $D$ from $B$ to $AC$ lies between $A$ and $C$. Let $D = (d, 0)$ and $B = (d, b)$.

The side $AB$ passes through $(a, 0)$ and $(d, b)$. Its slope is $m_{AB} = \frac{b}{d-a}$. The altitude $CE$ is perpendicular to $AB$, so its slope is $m_{CE} = \frac{a-d}{b}$. The equation of line $CE$ is $y = \frac{a-d}{b}x$.
The point $E$ is the intersection of $AB$ and $CE$. The equation of $AB$ is $y = \frac{b}{d-a}(x-a)$. Setting the expressions for $y$ equal:
\[ \frac{a-d}{b}x = \frac{b}{d-a}(x-a) \implies -(a-d)^2 x = b^2(x-a) \implies x(b^2 + (a-d)^2) = b^2 a. \]
Let $AB^2 = b^2 + (a-d)^2$. Then $x_E = \frac{b^2 a}{AB^2}$ and $y_E = \frac{(a-d)ba}{AB^2}$.

$E_1$ is the reflection of $E$ across $AC$ (the $x$-axis), so $E_1 = (x_E, -y_E)$.
$E_2$ is the reflection of $E$ across $BC$. The line $BC$ passes through $(0,0)$ and $(d,b)$, so its slope is $m = b/d$. The reflection $P'(x',y')$ of $P(x,y)$ across $y=mx$ is given by $x' = \frac{1-m^2}{1+m^2}x + \frac{2m}{1+m^2}y$ and $y' = \frac{2m}{1+m^2}x - \frac{1-m^2}{1+m^2}y$.
With $m=b/d$, we have $\frac{1-m^2}{1+m^2} = \frac{d^2-b^2}{d^2+b^2}$ and $\frac{2m}{1+m^2} = \frac{2bd}{d^2+b^2}$. Thus,
\[ x_{E_2} = \frac{d^2-b^2}{d^2+b^2}x_E + \frac{2bd}{d^2+b^2}y_E, \quad y_{E_2} = \frac{2bd}{d^2+b^2}x_E - \frac{d^2-b^2}{d^2+b^2}y_E. \]

The center $O(x_O, y_O)$ of the circumcircle $\omega$ of $\triangle CE_1E_2$ satisfies $OC=OE_1=OE_2$. Since $C$ is the origin, $x_O^2 + y_O^2 = (x_O-x_E)^2 + (y_O+y_E)^2 = (x_O-x_{E_2})^2 + (y_O-y_{E_2})^2$.
This simplifies to:
1) $2x_O x_E - 2y_O y_E = x_E^2 + y_E^2 = CE^2$
2) $2x_O x_{E_2} + 2y_O y_{E_2} = x_{E_2}^2 + y_{E_2}^2 = CE^2$
Subtracting these gives $x_O(x_E - x_{E_2}) = y_O(y_E + y_{E_2})$.
Using $s = d^2+b^2$, we calculate:
\[ x_E - x_{E_2} = x_E - \frac{d^2-b^2}{s}x_E - \frac{2bd}{s}y_E = \frac{2b^2 x_E - 2bdy_E}{s}, \quad y_E + y_{E_2} = y_E + \frac{2bd}{s}x_E - \frac{d^2-b^2}{s}y_E = \frac{2b^2 y_E + 2bdx_E}{s}. \]
Thus, $\frac{x_O}{y_O} = \frac{2b^2 y_E + 2bdx_E}{2b^2 x_E - 2bdy_E} = \frac{by_E + dx_E}{bx_E - dy_E}$.
Substituting $x_E, y_E$:
\[ by_E + dx_E = \frac{b(a-d)ba + db^2 a}{AB^2} = \frac{b^2 a^2}{AB^2}, \quad bx_E - dy_E = \frac{b(b^2 a) - d(a-d)ba}{AB^2} = \frac{ba(b^2 - ad + d^2)}{AB^2}. \]
So, $\frac{x_O}{y_O} = \frac{ba}{b^2 + d^2 - ad}$.

The intersection $X$ of $\omega$ and $AC$ (the $x$-axis) is $(2x_O, 0)$.
The vector $\vec{XO} = (x_O - 2x_O, y_O - 0) = (-x_O, y_O)$.
The vector $\vec{DE} = (x_E - d, y_E)$.
$XO \perp DE \iff \vec{XO} \cdot \vec{DE} = -x_O(x_E - d) + y_O y_E = 0 \iff \frac{x_O}{y_O} = \frac{y_E}{x_E - d}$.
We have $\frac{y_E}{x_E - d} = \frac{(a-d)ba/AB^2}{b^2 a/AB^2 - d} = \frac{(a-d)ba}{b^2 a - d(b^2 + (a-d)^2)}$.
The denominator is $b^2 a - db^2 - da^2 + 2ad^2 - d^3$.
Checking the equality $\frac{x_O}{y_O} = \frac{y_E}{x_E - d}$ is equivalent to:
\[ (a-d)(b^2 + d^2 - ad) = b^2 a - db^2 - da^2 + 2ad^2 - d^3. \]
Expanding the left side:
\[ (a-d)(b^2 + d^2 - ad) = ab^2 + ad^2 - a^2 d - db^2 - d^3 + ad^2 = ab^2 - db^2 - a^2 d + 2ad^2 - d^3. \]
The expressions match. Thus, $XO \perp DE$. \(\square\)
