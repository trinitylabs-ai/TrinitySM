Let $k = 2024$. We seek all polynomials $P(x) \in \mathbb{Z}[x]$ such that for every $n \in \mathbb{Z}_{\ge 0}$, the equation $P(x) = n^k$ has an integer solution $x_n$.

**1. Establishing that $x_n$ is eventually a polynomial**
Let $d$ be the degree of $P(x)$. If $P$ is constant, $P(x) = C$, then $C = n^k$ for all $n \in \mathbb{Z}_{\ge 0}$, which is impossible. Thus $d \ge 1$. Let $P(x) = a_d x^d + a_{d-1} x^{d-1} + \dots + a_0$ with $a_d \neq 0$.
The equation $P(x) - n^k = 0$ defines $x$ as an algebraic function of $n$. According to the theory of Puiseux series, for sufficiently large $n$, the solutions $x(n)$ can be represented as series of the form:
$$x(n) = \sum_{j=0}^\infty c_j n^{r_j}$$
where $r_0 > r_1 > r_2 > \dots$ are decreasing rational numbers. Comparing the leading terms of $P(x) = n^k$, we have $a_d x^d \sim n^k$, so $x \sim (a_d^{-1})^{1/d} n^{k/d}$. Thus, the leading exponent is $r_0 = k/d$.

For large $n$, the solutions $x_{n,j}$ to $P(x) = n^k$ are distributed among $d$ branches. For a solution $x_n$ to be an integer, it must belong to a real branch. If $d$ is even, there are at most two real branches; if $d$ is odd, there is at most one. Let these real branches be $R_1(n), \dots, R_s(n)$ (where $s \le 2$). 
If $x_n$ eventually stays on one branch $R_i(n)$, then $x_n$ is represented by a Puiseux series. The forward difference operator $\Delta f(n) = f(n+1) - f(n)$ acts on $n^r$ such that $\Delta^m (n^r) \sim C n^{r-m}$. Thus, $\Delta^m x_n$ is also a Puiseux series whose leading term is proportional to $n^{r_0-m}$. By choosing an integer $m > r_0 = k/d$, we have $\lim_{n \to \infty} \Delta^m x_n = 0$.
If $x_n$ switches between different real branches $R_i(n)$ and $R_j(n)$ infinitely often, then $\Delta x_n$ would be approximately $R_i(n) - R_j(n) \sim n^{k/d}$, which does not converge to 0, nor do higher differences.
Since $x_n$ is an integer for all $n$, $\Delta^m x_n$ is also an integer. An integer sequence that converges to 0 must be eventually zero. Thus, there exists $N$ such that $\Delta^m x_n = 0$ for all $n \ge N$, which implies $x_n$ is eventually a polynomial $Q(n) \in \mathbb{Q}[n]$.
Consequently, the identity $P(Q(n)) = n^k$ holds for all $n \ge N$, and since both are polynomials, $P(Q(x)) = x^k$ for all $x$.

**2. Solving the Functional Equation $P(Q(x)) = x^k$**
Let $d = \deg P$ and $q = \deg Q$, so $dq = k$. Differentiating $P(Q(x)) = x^k$ gives:
$$P'(Q(x)) Q'(x) = k x^{k-1}$$
The only root of the right-hand side is $x = 0$. Thus, any root of $Q'(x)$ must be $0$. Since $\deg Q' = q-1$, we have $Q'(x) = c x^{q-1}$ for some constant $c$. Integrating gives:
$$Q(x) = \frac{c}{q} x^q + b$$
Substituting this into the derivative equation:
$$P'(Q(x)) \cdot c x^{q-1} = k x^{k-1} \implies P'(Q(x)) = \frac{k}{c} x^{k-q}$$
Let $z = Q(x) = \frac{c}{q} x^q + b$. Then $x^q = \frac{q}{c}(z-b)$. Substituting this into the expression for $P'(z)$:
$$P'(z) = \frac{k}{c} \left( \frac{q}{c}(z-b) \right)^{\frac{k-q}{q}} = \frac{k}{c} \left( \frac{q}{c} \right)^{d-1} (z-b)^{d-1}$$
Integrating $P'(z) = A(z-b)^{d-1}$ gives $P(z) = a_d(z-b)^d + C$.
Substituting $P$ and $Q$ back into $P(Q(x)) = x^k$:
$$a_d \left( \frac{c}{q} x^q + b - b \right)^d + C = a_d \left( \frac{c}{q} \right)^d x^{dq} + C = x^k$$
This implies $C = 0$ and $a_d (c/q)^d = 1$. Thus, $P(x) = a_d (x-b)^d$.

**3. Determining Integer Coefficients and Solutions**
Since $P(x) \in \mathbb{Z}[x]$, the leading coefficient $a_d$ must be an integer.
For $n=0$, $P(x_0) = a_d (x_0-b)^d = 0$, which implies $x_0 = b$. Since $x_0 \in \mathbb{Z}$, $b$ must be an integer.
For $n=1$, $P(x_1) = a_d (x_1-b)^d = 1$. Since $a_d, x_1, b \in \mathbb{Z}$, we must have $a_d = \pm 1$.

- **Case 1: $a_d = 1$.** $P(x) = (x-b)^d$. The equation $(x-b)^d = n^k$ must have an integer solution $x$ for all $n$. This requires $n^{k/d}$ to be an integer for all $n$, so $d$ must divide $k$. Let $m=d$. Then $m|2024$.
- **Case 2: $a_d = -1$.** $P(x) = -(x-b)^d$. The equation $-(x-b)^d = n^k$ must have an integer solution $x$ for all $n$. If $d$ is even, $-(x-b)^d \le 0$, so no solution exists for $n \ge 1$. If $d$ is odd, $(x-b)^d = -n^k$ implies $x-b = -n^{k/d}$. This requires $d$ to divide $k$. Let $m=d$. Then $m|2024$ and $m$ is odd.

Replacing $-b$ with $b$ (as $b$ is an arbitrary integer), the polynomials are:
$P(x) = (x+b)^m$ where $m|2024, b \in \mathbb{Z}$, and $P(x) = -(x+b)^m$ where $m|2024, m$ is odd, $b \in \mathbb{Z}$.

The set of all such polynomials is $\{P(x) = (x+b)^m : m|2024, b \in \mathbb{Z}\} \cup \{P(x) = -(x+b)^m : m|2024, m \text{ is odd}, b \in \mathbb{Z}\}$.
