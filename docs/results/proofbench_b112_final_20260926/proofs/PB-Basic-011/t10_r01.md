To find the minimum possible value of the smallest element $m_A$ for a set $A \subset \{1, 2, \dots, 2000\}$ with $|A| = 1000$ such that no element in $A$ divides another, we proceed as follows:

### 1. Decomposition by Odd Parts
Every integer $n \in \{1, 2, \dots, 2000\}$ can be uniquely written in the form $n = 2^k \cdot o$, where $o$ is an odd integer. The set of all possible odd parts for integers in $\{1, 2, \dots, 2000\}$ is $O = \{1, 3, 5, \dots, 1999\}$. There are exactly 1000 such odd integers.

If $A$ is an antichain under divisibility with $|A| = 1000$, then $A$ must contain exactly one element for each odd part $o \in O$. Indeed, if $A$ contained two elements with the same odd part, say $a = 2^{k_1} o$ and $b = 2^{k_2} o$ with $k_1 < k_2$, then $a$ would divide $b$, which is forbidden. Thus, we can represent $A$ as:
$$A = \{2^{k_o} \cdot o : o \in O\}$$
where $k_o \ge 0$ for each $o \in O$.

### 2. The Antichain Condition
The condition that no element in $A$ divides another implies that for any two distinct odd integers $o_1, o_2 \in O$, if $o_1$ divides $o_2$, then $2^{k_{o_1}} o_1$ cannot divide $2^{k_{o_2}} o_2$. 
Divisibility $2^{k_{o_1}} o_1 \mid 2^{k_{o_2}} o_2$ occurs if and only if $o_1 \mid o_2$ and $k_{o_1} \le k_{o_2}$. To prevent this, whenever $o_1 \mid o_2$ and $o_1 \neq o_2$, we must have $k_{o_1} > k_{o_2}$.

### 3. Determining the Minimum Possible $m_A$
Let $L(o)$ be the length of the longest chain of odd integers in $O$ starting at $o$. To maximize the length of a chain $o = o_1 \mid o_2 \mid \dots \mid o_L$ where each $o_i \le 1999$, we want the ratios $o_{i+1}/o_i$ to be as small as possible. The smallest odd integer greater than 1 is 3. Thus, the longest chain is formed by successive multiplication by 3: $o, 3o, 3^2o, \dots, 3^{L-1}o \le 1999$. This implies $L(o) - 1 = \lfloor \log_3(1999/o) \rfloor$.

Based on the condition $k_{o_1} > k_{o_2} > \dots > k_{o_L} \ge 0$ for any chain $o_1 \mid o_2 \mid \dots \mid o_L$, it follows that $k_{o_1} \ge L(o)-1$.
Thus, for any element $a_o = 2^{k_o} \cdot o$ in $A$, we have $a_o \ge 2^{L(o)-1} \cdot o$.
The smallest element of the set is $m_A = \min_{o \in O} a_o$. To minimize $m_A$, we seek to minimize the bound $f(o) = 2^{L(o)-1} \cdot o$ over all $o \in O$.

Let $k = L(o)-1 = \lfloor \log_3(1999/o) \rfloor$. Then $k$ is an integer such that $3^k \le 1999/o < 3^{k+1}$, which implies $o > 1999/3^{k+1}$. For a fixed $k$, $f(o) = 2^k \cdot o$ is minimized when $o$ is the smallest odd integer greater than $1999/3^{k+1}$.
- If $k=6$, then $o > 1999/2187 \approx 0.91$, so $o \ge 1$. $f(o) \ge 2^6 \cdot 1 = 64$.
- If $k=5$, then $o > 1999/729 \approx 2.74$, so $o \ge 3$. $f(o) \ge 2^5 \cdot 3 = 96$.
- If $k=4$, then $o > 1999/243 \approx 8.22$, so $o \ge 9$. $f(o) \ge 2^4 \cdot 9 = 144$.
- If $k=3$, then $o > 1999/81 \approx 24.67$, so $o \ge 25$. $f(o) \ge 2^3 \cdot 25 = 200$.
- If $k=2$, then $o > 1999/27 \approx 74.03$, so $o \ge 75$. $f(o) \ge 2^2 \cdot 75 = 300$.
- If $k=1$, then $o > 1999/9 \approx 222.11$, so $o \ge 223$. $f(o) \ge 2^1 \cdot 223 = 446$.
- If $k=0$, then $o > 1999/3 \approx 666.33$, so $o \ge 667$. $f(o) \ge 2^0 \cdot 667 = 667$.

In all cases, $a_o \ge f(o) \ge 64$. Thus, $m_A \ge 64$ for any valid set $A$.

### 4. Construction for $m_A = 64$
We can achieve $m_A = 64$ by setting $k_o = L(o) - 1$ for all $o \in O$. If $o_1 \mid o_2$ and $o_1 \neq o_2$, then $o_2 \ge 3o_1$, so $L(o_2) = \lfloor \log_3(1999/o_2) \rfloor + 1 \le \lfloor \log_3(1999/3o_1) \rfloor + 1 = L(o_1) - 1$. Thus $k_{o_2} \le k_{o_1} - 1$, ensuring $k_{o_1} > k_{o_2}$, which makes $A$ an antichain.

To ensure $A \subset \{1, \dots, 2000\}$, we verify that $a_o = 2^{L(o)-1} \cdot o \le 2000$. Let $k = L(o)-1$. By definition, $3^k \le 1999/o$. Then:
$$a_o = 2^k \cdot o \le 2^k \cdot \frac{1999}{3^k} = 1999 \cdot \left(\frac{2}{3}\right)^k \le 1999 \le 2000$$
The minimum element is $a_1 = 2^{L(1)-1} \cdot 1 = 2^6 \cdot 1 = 64$.

The minimum possible value of $m_A$ is 64.
