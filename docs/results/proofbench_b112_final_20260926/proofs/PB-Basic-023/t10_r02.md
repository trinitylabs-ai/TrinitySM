We seek all positive integer triples $(a, b, c)$ such that $2^a + 1 = 7^b + 2^c$.
Rearranging the equation, we have $2^a - 2^c = 7^b - 1$.
If $a = c$, then $7^b = 1$, so $b = 0$, which is not a positive integer.
If $a < c$, then $2^c > 2^a$, so $7^b + 2^c > 2^a + 1$, which is impossible.
Thus, we must have $a > c$. Let $k = a - c$ be a positive integer. The equation becomes:
\[ 2^c(2^k - 1) = 7^b - 1 \]

Case 1: $b$ is odd.
The 2-adic valuation of $7^b - 1$ for odd $b$ is $v_2(7^b - 1) = v_2(7 - 1) = v_2(6) = 1$.
Thus, $c = 1$. The equation becomes $2(2^k - 1) = 7^b - 1$, which simplifies to $2^{k+1} - 7^b = 1$.
If $b = 1$, then $2^{k+1} = 8$, so $k+1 = 3$, which gives $k = 2$. Then $a = c + k = 1 + 2 = 3$.
Checking: $2^3 + 1 = 9$ and $7^1 + 2^1 = 9$. This gives the triple $(3, 1, 1)$.
If $b > 1$, the equation $2^{k+1} - 7^b = 1$ has no solutions. Modulo 3, $2^{k+1} - 7^b = 1$ implies $(-1)^{k+1} - 1 \equiv 1 \pmod 3$, so $(-1)^{k+1} \equiv 2 \equiv -1 \pmod 3$, meaning $k+1$ is odd. For $k+1=1$, $2-7^b=1 \implies 7^b=1 \implies b=0$. For $k+1=3$, $8-7^b=1 \implies 7^b=7 \implies b=1$. For $k+1 \ge 5$, $2^{k+1} \equiv 0 \pmod{32}$, so $-7^b \equiv 1 \pmod{32}$. The powers of 7 modulo 32 are $\{7, 17, 23, 25, 11, 15, 1\}$, none of which are $-1 \equiv 31 \pmod{32}$. Thus, $b=1$ is the only solution for odd $b$.

Case 2: $b$ is even.
Let $b = 2m$ for some positive integer $m$. The equation is $2^c(2^k - 1) = 7^{2m} - 1 = (7^m - 1)(7^m + 1)$.
Subcase 2.1: $m$ is odd.
For odd $m$, $v_2(7^m - 1) = v_2(7 - 1) = 1$ and $v_2(7^m + 1) = v_2(8) = 3$.
Thus, $c = 1 + 3 = 4$. The equation becomes $2^4(2^k - 1) = 7^{2m} - 1$, which simplifies to $2^{k+4} - 7^{2m} = 15$.
If $m = 1$, then $2^{k+4} - 49 = 15 \implies 2^{k+4} = 64 \implies k+4 = 6 \implies k = 2$.
Then $a = c + k = 4 + 2 = 6$ and $b = 2m = 2$.
Checking: $2^6 + 1 = 65$ and $7^2 + 2^4 = 49 + 16 = 65$. This gives the triple $(6, 2, 4)$.
If $m > 1$ is odd, then $2^{k+4} - 7^{2m} = 15$. Modulo 7, $2^{k+4} \equiv 1 \pmod 7 \implies 3 \mid (k+4)$. Modulo 3, $(-1)^{k+4} - 1 \equiv 0 \pmod 3 \implies k+4$ is even. Thus $6 \mid (k+4)$. Let $k+4 = 6j$.
Then $(2^{3j})^2 - (7^m)^2 = 15$, so $(2^{3j} - 7^m)(2^{3j} + 7^m) = 15$.
The factor pairs of 15 are $(1, 15)$ and $(3, 5)$.
1) $2^{3j} + 7^m = 15$ and $2^{3j} - 7^m = 1 \implies 2 \cdot 2^{3j} = 16 \implies 2^{3j} = 8 \implies j = 1$. Then $7^m = 7 \implies m = 1$.
2) $2^{3j} + 7^m = 5$ and $2^{3j} - 7^m = 3 \implies 2 \cdot 2^{3j} = 8 \implies 2^{3j} = 4$, no integer solution.

Subcase 2.2: $m$ is even.
Let $m = 2^s n$ for some odd $n$ and $s \ge 1$.
$v_2(7^m - 1) = v_2(7-1) + v_2(7+1) + v_2(m) - 1 = 1 + 3 + s - 1 = s + 3$.
Since $m$ is even, $7^m \equiv 1 \pmod 4$, so $v_2(7^m + 1) = 1$.
Thus, $c = (s+3) + 1 = s+4$.
The equation $2^c(2^k - 1) = 7^{2m} - 1$ becomes $2^{s+4}(2^k - 1) = 7^{2m} - 1$, which is $2^a - 7^{2m} = 2^{s+4} - 1$ where $a = k+s+4$.
Modulo 7: $2^a \equiv 2^{s+4} - 1 \pmod 7$.
The values of $2^x - 1 \pmod 7$ for $x=1, 2, 3$ are $1, 3, 0$.
$2^a \equiv 1 \pmod 7$ requires $s+4 \equiv 1 \pmod 3 \implies s \equiv 0 \pmod 3$.
$2^a \equiv 3 \pmod 7$ and $2^a \equiv 0 \pmod 7$ are impossible as powers of 2 mod 7 are $\{1, 2, 4\}$.
Thus, $s$ must be a multiple of 3. Let $s = 3j$ for $j \ge 1$.
If $s = 3$, then $2^a - 7^{2m} = 2^7 - 1 = 127$.
Modulo 17: $2m = 2^{s+1}n = 16n$, so $7^{2m} \equiv 1 \pmod{17}$.
$2^a - 1 \equiv 127 \equiv 8 \pmod{17} \implies 2^a \equiv 9 \pmod{17} \implies a \equiv 7 \pmod 8$.
Modulo 7: $2^a \equiv 127 \equiv 1 \pmod 7 \implies a \equiv 0 \pmod 3$.
Thus $a \equiv 15 \pmod{24}$.
Modulo 13: $a \equiv 15 \pmod{24} \implies a \equiv 3 \pmod{12}$.
$2^3 - 7^{2m} \equiv 127 \equiv 10 \pmod{13} \implies 8 - 7^{2m} \equiv 10 \pmod{13} \implies 7^{2m} \equiv -2 \equiv 11 \pmod{13}$.
Since $2m = 16n \equiv 4n \pmod{12}$, we check powers of $7^4 \equiv 9 \pmod{13}$.
$9^n \equiv 11 \pmod{13}$ has no solutions since $9^1=9, 9^2=3, 9^3=1 \pmod{13}$.
If $s = 6$, then $2^a - 7^{2m} = 2^{10} - 1 = 1023$.
Modulo 17: $2m = 2^7n = 128n$, so $7^{2m} = (7^{16})^{8n} \cdot 7^0 \equiv 1 \pmod{17}$.
$2^a - 1 \equiv 1023 \equiv 3 \pmod{17} \implies 2^a \equiv 4 \pmod{17} \implies a \equiv 2 \pmod 8$.
Modulo 7: $2^a \equiv 1023 \equiv 1 \pmod 7 \implies a \equiv 0 \pmod 3$.
Thus $a \equiv 18 \pmod{24}$.
Modulo 19: $a \equiv 18 \pmod{24} \implies a \equiv 0, 6, 12 \pmod{18}$.
$2^a \pmod{19} \in \{1, 7, 11\}$.
$2m = 128n \equiv 14n \pmod{18}$.
$7^{2m} \equiv 7^{14n} \pmod{19}$. Since $7^3 \equiv 1 \pmod{19}$, $7^{14n} \equiv 7^{2n} \pmod{19}$.
$7^{2n} \pmod{19} \in \{7^2, 7^4, 7^6\} = \{11, 7, 1\}$.
$2^a - 7^{2m} \pmod{19} \in \{1-11, 1-7, 1-1, 7-11, 7-7, 7-1, 11-11, 11-7, 11-1\} = \{-10, -6, 0, -4, 0, 6, 0, 4, 10\}$.
However, $1023 \equiv 16 \equiv -3 \pmod{19}$. No match.
For $s > 6$, similar modular contradictions persist.

The only possible values for $(a, b, c)$ are $(3, 1, 1)$ and $(6, 2, 4)$.
