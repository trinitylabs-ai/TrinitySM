To find all functions $f: \mathbb{R} \rightarrow \mathbb{R}$ such that for all $a, b \in \mathbb{R}$,
\[ (b - a)f(f(a)) = a f(a + f(b)), \]
we examine several cases based on the properties of $f$.

**1. Constant Solutions**
Suppose $f(x) = k$ for some constant $k$. Substituting this into the original equation:
\[ (b - a)k = ak \implies bk - ak = ak \implies bk = 2ak. \]
For this to hold for all $a, b \in \mathbb{R}$, we must have $k = 0$.
Checking $f(x) = 0$: $(b - a) \cdot 0 = a \cdot 0 \implies 0 = 0$.
Thus, $f(x) = 0$ is a solution.

**2. Non-constant Solutions**
Let $f(0) = c$. Substituting $a = 0$ into the original equation:
\[ (b - 0)f(f(0)) = 0 \cdot f(0 + f(b)) \implies b f(c) = 0. \]
Since this must hold for all $b \in \mathbb{R}$, we have $f(c) = 0$.

**Case 2.1: $c = 0$**
If $f(0) = 0$, the original equation becomes $(b - a)f(f(a)) = a f(a + f(b))$.
Setting $b = 0$:
\[ -a f(f(a)) = a f(a + f(0)) = a f(a). \]
For $a \neq 0$, we have $f(f(a)) = -f(a)$. Since $f(f(0)) = f(0) = 0 = -f(0)$, the identity $f(f(a)) = -f(a)$ holds for all $a \in \mathbb{R}$. Substituting this back into the original equation:
\[ (b - a)(-f(a)) = a f(a + f(b)). \]
If $f(a) = 0$ for all $a$, we return to the solution $f(x) = 0$. If there exists some $a \neq 0$ such that $f(a) \neq 0$, then for a fixed $a$, the expression $\frac{(a - b)f(a)}{a}$ can take any real value as $b$ varies. Thus, $f(a + f(b))$ takes all real values, meaning $f$ is surjective.
Since $f$ is surjective, for any $y \in \mathbb{R}$, there exists $x$ such that $f(x) = y$. Then $f(y) = f(f(x)) = -f(x) = -y$.
Checking $f(x) = -x$:
LHS: $(b - a)f(f(a)) = (b - a)a = ab - a^2$.
RHS: $a f(a + f(b)) = a f(a - b) = a(-(a - b)) = ab - a^2$.
This is a solution.

**Case 2.2: $c \neq 0$**
Setting $a = c$ in the original equation:
\[ (b - c)f(f(c)) = c f(c + f(b)). \]
Since $f(c) = 0$, we have $f(f(c)) = f(0) = c$. Thus:
\[ (b - c)c = c f(c + f(b)) \implies f(c + f(b)) = b - c. \]
Setting $b = c$ in the original equation:
\[ (c - a)f(f(a)) = a f(a + f(c)) = a f(a + 0) = a f(a). \]
For $a \neq c$, $f(f(a)) = \frac{a f(a)}{c - a}$.
Setting $b = 0$ in the original equation:
\[ (0 - a)f(f(a)) = a f(a + f(0)) = a f(a + c). \]
For $a \neq 0$, $f(a + c) = -f(f(a)) = \frac{a f(a)}{a - c}$.
From $f(c + f(b)) = b - c$, we apply $f$ to both sides:
\[ f(f(c + f(b))) = f(b - c). \]
We note that if $f(b) = 0$, then $f(c + f(b)) = f(c) = 0$, so $b - c = 0$, which means $b = c$. Thus, for $b \neq c$, we have $f(b) \neq 0$. This ensures that $x = c + f(b) \neq c$, allowing us to use the identity $f(f(x)) = \frac{x f(x)}{c - x}$ with $x = c + f(b)$:
\[ f(b - c) = \frac{(c + f(b)) f(c + f(b))}{c - (c + f(b))} = \frac{(c + f(b))(b - c)}{-f(b)}. \]
Let $b - c = x$, so $b = x + c$:
\[ f(x) = \frac{(c + f(x + c))x}{-f(x + c)} \implies f(x) (-f(x + c)) = cx + x f(x + c) \implies f(x + c) = \frac{-cx}{x + f(x)}. \]
Equating the two expressions for $f(x + c)$:
\[ \frac{x f(x)}{x - c} = \frac{-cx}{x + f(x)}. \]
For $x \neq 0, c$, we have $\frac{f(x)}{x - c} = \frac{-c}{x + f(x)}$, which implies:
\[ f(x)^2 + x f(x) = -cx + c^2 \implies f(x)^2 + x f(x) + cx - c^2 = 0. \]
Solving the quadratic for $f(x)$:
\[ f(x) = \frac{-x \pm \sqrt{x^2 - 4(cx - c^2)}}{2} = \frac{-x \pm \sqrt{(x - 2c)^2}}{2} = \frac{-x \pm |x - 2c|}{2}. \]
This implies that for each $x$, $f(x)$ is either $-c$ or $c - x$.
If $f(b) = -c$ for some $b$, then from $f(c + f(b)) = b - c$, we get $f(0) = b - c \implies c = b - c \implies b = 2c$.
Thus, for $b \neq 2c$, we must have $f(b) = c - b$. For $b = 2c$, $f(2c) = c - 2c = -c$.
Therefore, $f(x) = c - x$ for all $x \in \mathbb{R}$.
Checking $f(x) = c - x$:
LHS: $(b - a)f(f(a)) = (b - a)f(c - a) = (b - a)(c - (c - a)) = (b - a)a$.
RHS: $a f(a + f(b)) = a f(a + c - b) = a(c - (a + c - b)) = a(b - a)$.
This is a solution for any $c \in \mathbb{R}$.

The functions satisfying the equation are $f(x) = 0$ and $f(x) = c - x$ for any constant $c \in \mathbb{R}$.
