To find all functions $f: \mathbb{R} \rightarrow \mathbb{R}$ such that for all $a, b \in \mathbb{R}$,
\[ (b - a) f(f(a)) = a f(a + f(b)), \tag{1} \]
we proceed as follows.

Setting $a = 0$ in (1), we have:
\[ (b - 0) f(f(0)) = 0 \cdot f(0 + f(b)) \implies b f(f(0)) = 0. \]
Since this must hold for all $b \in \mathbb{R}$, we must have $f(f(0)) = 0$. Let $f(0) = c$. Then $f(c) = 0$.

Setting $b = a$ in (1), we have:
\[ (a - a) f(f(a)) = a f(a + f(a)) \implies 0 = a f(a + f(a)). \]
For all $a \neq 0$, it follows that $f(a + f(a)) = 0$.

We now consider two cases based on the value of $c$.

Case 1: $c \neq 0$.
Substituting $a = c$ into (1), we have:
\[ (b - c) f(f(c)) = c f(c + f(b)). \]
Since $f(c) = 0$, we have $f(f(c)) = f(0) = c$. Thus,
\[ (b - c) c = c f(c + f(b)). \]
Since $c \neq 0$, we divide by $c$ to obtain:
\[ f(c + f(b)) = b - c. \tag{2} \]
We check for injectivity. Suppose $f(b_1) = f(b_2)$ for some $b_1, b_2 \in \mathbb{R}$. Then $f(c + f(b_1)) = f(c + f(b_2))$. Applying (2), we get $b_1 - c = b_2 - c$, which implies $b_1 = b_2$. Thus, $f$ is injective.
Since $f$ is injective and $f(c) = 0$, we have $f(x) = 0$ if and only if $x = c$.
From the previously derived property $f(a + f(a)) = 0$ for $a \neq 0$, we conclude that $a + f(a) = c$ for all $a \neq 0$. Thus, $f(a) = c - a$ for all $a \neq 0$.
For $a = 0$, we have $f(0) = c$, which is consistent with $c - 0 = c$.
Therefore, $f(x) = c - x$ for all $x \in \mathbb{R}$.

Case 2: $c = 0$.
If $c = 0$, then $f(0) = 0$. Equation (1) becomes:
\[ (b - a) f(f(a)) = a f(a + f(b)). \]
If $f$ is the constant function $f(x) = 0$, it clearly satisfies (1).
Suppose $f$ is not identically zero. We first show that $f$ must be a bijection.
If $f(f(a)) = 0$ for all $a \in \mathbb{R}$, then $a f(a + f(b)) = 0$ for all $a, b$. For $a \neq 0$, $f(a + f(b)) = 0$. Let $R_f$ be the range of $f$. Then for any $y \in R_f$ and any $a \neq 0$, $a + y$ is a root of $f$. This implies that $f$ vanishes on $\mathbb{R} \setminus \{y\}$. If $R_f$ contains more than one element, $f$ must be identically zero. If $R_f$ is a singleton $\{y\}$, then $f(x) = y$ for all $x$, which implies $f(f(x)) = y$; since $f(f(a)) = 0$, we have $y = 0$, so $f \equiv 0$.
Thus, there must exist some $a_0 \neq 0$ such that $f(f(a_0)) \neq 0$. For this $a_0$, we have:
\[ f(a_0 + f(b)) = \frac{f(f(a_0))}{a_0} (b - a_0). \]
As $b$ varies over $\mathbb{R}$, the right-hand side takes all real values, so $f$ is surjective. Furthermore, if $f(b_1) = f(b_2)$, then $f(a_0 + f(b_1)) = f(a_0 + f(b_2))$, which implies $b_1 - a_0 = b_2 - a_0$, so $b_1 = b_2$. Thus, $f$ is a bijection.
Since $f$ is a bijection and $f(0) = 0$, we have $f(x) = 0$ if and only if $x = 0$.
From $f(a + f(a)) = 0$ for $a \neq 0$, we conclude $a + f(a) = 0$, so $f(a) = -a$ for all $a \neq 0$.
Since $f(0) = 0$, we have $f(x) = -x$ for all $x \in \mathbb{R}$. This is a special case of $f(x) = c - x$ with $c = 0$.

Final Verification:
1. If $f(x) = 0$, then $(b - a) \cdot 0 = a \cdot 0$, which is $0 = 0$.
2. If $f(x) = c - x$, then $f(f(a)) = c - (c - a) = a$ and $f(a + f(b)) = c - (a + c - b) = b - a$.
   The equation $(b - a) f(f(a)) = a f(a + f(b))$ becomes $(b - a) a = a (b - a)$, which is true.

The functions satisfying the equation are $f(x) = 0$ and $f(x) = c - x$ for any $c \in \mathbb{R}$.
