To find all functions $f: \mathbb{R} \rightarrow \mathbb{R}$ such that for all $a, b \in \mathbb{R}$,
\[ (b - a)f(f(a)) = a f(a + f(b)), \]
we proceed as follows:

**1. Preliminary Observations**
Let the given equation be $P(a, b)$.
$P(0, b) \implies b f(f(0)) = 0$ for all $b \in \mathbb{R}$, which implies $f(f(0)) = 0$.
$P(a, a) \implies 0 = a f(a + f(a))$, which implies $f(a + f(a)) = 0$ for all $a \neq 0$.

**2. Case 1: $f(0) = 0$**
If $f(0) = 0$, then $f(f(0)) = 0$ is naturally satisfied. We have $f(a + f(a)) = 0$ for all $a \neq 0$.
If $f$ is identically zero, $f(x) = 0$ for all $x$, which satisfies the equation.
Suppose $f$ is not identically zero. Let $S = \{x \in \mathbb{R} : f(x) = 0\}$. Since $f(0) = 0$, $0 \in S$.
If $S = \{0\}$, then for $a \neq 0$, $f(a + f(a)) = 0$ implies $a + f(a) = 0$, so $f(a) = -a$.
Checking $f(x) = -x$:
LHS: $(b - a)f(f(a)) = (b - a)f(-a) = (b - a)a$.
RHS: $a f(a + f(b)) = a f(a - b) = a(b - a)$.
LHS = RHS, so $f(x) = -x$ is a solution.

If $S$ contains some $a_0 \neq 0$, then $P(a_0, b)$ gives:
$(b - a_0)f(f(a_0)) = a_0 f(a_0 + f(b)) \implies (b - a_0)f(0) = a_0 f(a_0 + f(b)) \implies 0 = a_0 f(a_0 + f(b))$.
Thus, $f(a_0 + f(b)) = 0$ for all $b \in \mathbb{R}$. This implies that for any $v$ in the range of $f$, $a_0 + v \in S$.
Now consider $P(a, b)$ for $a \notin S$. Let $f(f(a)) = k$.
If $k \neq 0$, then $f(a + f(b)) = \frac{k(b - a)}{a}$. As $b$ varies, the right-hand side takes all real values, meaning $f$ is surjective. However, we found that $a_0 + \text{Range}(f) \subseteq S$. If $f$ is surjective, $\text{Range}(f) = \mathbb{R}$, so $a_0 + \mathbb{R} \subseteq S$, which implies $S = \mathbb{R}$, so $f(x) = 0$ for all $x$, contradicting that $f$ is not identically zero.
If $k = 0$ for all $a$, then $f(f(a)) = 0$ for all $a$. Then $P(a, b)$ becomes $0 = a f(a + f(b))$, so $f(a + f(b)) = 0$ for all $a \neq 0$. For a fixed $b$, $f(x) = 0$ for all $x \neq f(b)$. This implies $f$ can be non-zero at most at one point $z$.
- If $z = 0$, then $f(0) = w$ and $f(x) = 0$ for $x \neq 0$. $P(a, b)$ for $a \neq 0$ gives $(b - a)f(f(a)) = a f(a + f(b))$. Since $f(f(a)) = f(0) = w$, we have $(b - a)w = a f(a + f(b))$. If $b \neq 0$, $f(b) = 0$, so $(b - a)w = a f(a) = 0$ for all $b \neq 0$, implying $w = 0$.
- If $z \neq 0$, then $f(z) = w$ and $f(x) = 0$ for $x \neq z$. $P(a, b)$ for $a \neq z$ gives $0 = a f(a + f(b))$. If $b = z$, $f(b) = w$, so $0 = a f(a + w)$ for all $a \neq z$. For any $a \notin \{0, z\}$, we must have $f(a + w) = 0$, which means $a + w \neq z$. Thus $w \neq z - a$ for all $a \notin \{0, z\}$, which implies $w \in \{z - 0, z - z\} = \{z, 0\}$.
If $w = z$, then $f(z) = z$ and $f(x) = 0$ for $x \neq z$. $P(z, b)$ gives $(b - z)f(f(z)) = z f(z + f(b))$. Since $f(f(z)) = f(z) = z$, we have $(b - z)z = z f(z + f(b))$. For $b \neq z$, $f(b) = 0$, so $(b - z)z = z f(z) = z^2$, which implies $b = 2z$. This cannot hold for all $b \neq z$.
If $w = 0$, then $f(x) = 0$ for all $x$.
Thus, if $f(0) = 0$, the only solutions are $f(x) = 0$ and $f(x) = -x$.

**3. Case 2: $f(0) = c \neq 0$**
We know $f(f(0)) = 0$, so $f(c) = 0$.
$P(c, b) \implies (b - c)f(f(c)) = c f(c + f(b))$.
Since $f(c) = 0$, $f(f(c)) = f(0) = c$. Thus, $(b - c)c = c f(c + f(b))$.
Since $c \neq 0$, we have $f(c + f(b)) = b - c$.
To show that $f$ is injective, suppose $f(x) = f(y)$. Then $c + f(x) = c + f(y)$, so $f(c + f(x)) = f(c + f(y))$. By the identity $f(c + f(b)) = b - c$, this implies $x - c = y - c$, so $x = y$.
To show that $f$ is surjective, for any $y \in \mathbb{R}$, we can choose $b = y + c$. Then $f(c + f(y + c)) = (y + c) - c = y$.
Since $f$ is injective and $f(c) = 0$, $c$ is the unique root of $f$.
From $P(a, a)$, we have $f(a + f(a)) = 0$ for $a \neq 0$. Since $c$ is the unique root, $a + f(a) = c$ for all $a \neq 0$.
Thus, $f(a) = -a + c$ for all $a \neq 0$.
Since $f(0) = c$, the formula $f(x) = -x + c$ also holds for $x = 0$.

**4. Verification**
For $f(x) = 0$: $(b - a)(0) = a(0) \implies 0 = 0$. Correct.
For $f(x) = -x + c$:
$f(f(a)) = -(-a + c) + c = a$.
$f(a + f(b)) = f(a - b + c) = -(a - b + c) + c = b - a$.
$(b - a)a = a(b - a)$. Correct.

The functions satisfying the equation are $f(x) = 0$ and $f(x) = -x + c$ for any constant $c \in \mathbb{R}$.
