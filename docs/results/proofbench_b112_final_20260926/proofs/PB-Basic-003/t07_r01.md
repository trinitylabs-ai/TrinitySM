To find all functions $f: \mathbb{R} \rightarrow \mathbb{R}$ such that for all $a, b \in \mathbb{R}$,
\[ (b - a)f(f(a)) = a f(a + f(b)), \]
we proceed as follows:

**1. Constant Solutions**
If $f(x) = c$ for some constant $c$, the equation becomes $(b - a)c = ac$, which simplifies to $bc - ac = ac$, or $bc = 2ac$. For this to hold for all $a, b \in \mathbb{R}$, we must have $c = 0$. Thus, $f(x) = 0$ is a solution.

**2. Initial Properties**
Setting $a = 0$ in the original equation gives $b f(f(0)) = 0 \cdot f(0 + f(b)) = 0$. Since this holds for all $b \in \mathbb{R}$, we must have $f(f(0)) = 0$. Let $f(0) = c$. Then $f(c) = 0$.

**3. Case 1: $c \neq 0$**
Substituting $a = c$ into the original equation:
\[ (b - c)f(f(c)) = c f(c + f(b)). \]
Since $f(c) = 0$, we have $f(f(c)) = f(0) = c$. Thus, $(b - c)c = c f(c + f(b))$. Since $c \neq 0$, we divide by $c$ to obtain:
\[ f(c + f(b)) = b - c. \quad (*) \]
This equation implies that $f$ is a bijection. Specifically, since the right-hand side $b - c$ takes all real values as $b$ varies, $f$ is surjective. If $f(x) = f(y)$, then $f(c + f(x)) = f(c + f(y))$, which implies $x - c = y - c$, so $x = y$, meaning $f$ is injective.

Next, substitute $b = c$ into the original equation:
\[ (c - a)f(f(a)) = a f(a + f(c)). \]
Since $f(c) = 0$, we have $(c - a)f(f(a)) = a f(a)$. For $a \neq c$, this gives:
\[ f(f(a)) = \frac{a f(a)}{c - a}. \quad (**) \]
Substituting $(**)$ back into the original equation:
\[ (b - a) \frac{a f(a)}{c - a} = a f(a + f(b)). \]
For $a \neq 0$ and $a \neq c$, we have $f(a + f(b)) = \frac{(b - a)f(a)}{c - a}$.
Let $f(b) = z$. Then $f(a + z) = \frac{f(a)}{c - a} (f^{-1}(z) - a)$.
Setting $b = 0$ in $(*)$ gives $f(c + f(0)) = 0 - c$, so $f(c + c) = -c$, which means $f(2c) = -c$.
Substituting $a = 2c$ into the relation $f(a + f(b)) = \frac{(b - a)f(a)}{c - a}$:
\[ f(2c + f(b)) = \frac{(b - 2c)f(2c)}{c - 2c} = \frac{(b - 2c)(-c)}{-c} = b - 2c. \]
Let $f(b) = z$. Then $f(2c + z) = f^{-1}(z) - 2c$.
We already have $f(c + z) = f^{-1}(z) - c$ from $(*)$. Subtracting these two yields:
\[ f(2c + z) - f(c + z) = (f^{-1}(z) - 2c) - (f^{-1}(z) - c) = -c. \]
Let $x = c + z$, then $f(x + c) - f(x) = -c$, or $f(x + c) = f(x) - c$.
Using this in $f(c + z) = f^{-1}(z) - c$, we get $f(z) - c = f^{-1}(z) - c$, so $f(z) = f^{-1}(z)$, which implies $f(f(z)) = z$ for all $z$.
Now substitute $f^{-1}(z) = f(z)$ into $f(a + z) = \frac{f(a)}{c - a} (f^{-1}(z) - a)$:
\[ f(a + z) = \frac{f(a)}{c - a} (f(z) - a). \]
Setting $z = c$ gives $f(a + c) = \frac{f(a)}{c - a} (f(c) - a) = \frac{f(a)}{c - a} (0 - a) = \frac{-a f(a)}{c - a}$.
From $(**)$, we have $f(f(a)) = \frac{a f(a)}{c - a}$, so $f(a + c) = -f(f(a))$.
Since $f(f(a)) = a$, we have $f(a + c) = -a$.
Also, we know $f(a + c) = f(a) - c$. Thus:
\[ f(a) - c = -a \implies f(a) = c - a. \]
Checking $f(x) = c - x$:
LHS: $(b - a)f(f(a)) = (b - a)a$.
RHS: $a f(a + f(b)) = a f(a + c - b) = a(c - (a + c - b)) = a(b - a)$.
LHS = RHS, so $f(x) = c - x$ is a solution for any $c \in \mathbb{R}$.

**4. Case 2: $c = 0$**
If $f(0) = 0$, then $f(f(0)) = 0$. Setting $b = 0$ in the original equation gives:
\[ -a f(f(a)) = a f(a + f(0)) = a f(a). \]
For $a \neq 0$, $f(f(a)) = -f(a)$. Since $f(f(0)) = 0 = -f(0)$, this holds for all $a \in \mathbb{R}$.
Substituting $f(f(a)) = -f(a)$ into the original equation:
\[ (b - a)(-f(a)) = a f(a + f(b)) \implies a f(a) - b f(a) = a f(a + f(b)). \]
For $a \neq 0$, $f(a + f(b)) = f(a)(1 - \frac{b}{a})$.
If $f$ is not identically zero, there exists $a \neq 0$ such that $f(a) \neq 0$. Then $f(a + f(b))$ is a non-constant linear function of $b$, which implies $f$ is a bijection.
Let $f(1) = k$. Since $f$ is a bijection and $f(0) = 0$, we must have $k \neq 0$.
Setting $a = 1$ in $f(a + f(b)) = f(a)(1 - \frac{b}{a})$ gives:
\[ f(1 + f(b)) = k(1 - b). \]
Applying $f$ to both sides:
\[ f(f(1 + f(b))) = f(k(1 - b)). \]
Using $f(f(x)) = -f(x)$, we have $-f(1 + f(b)) = f(k(1 - b))$.
Substituting $f(1 + f(b)) = k(1 - b)$ into this equation:
\[ -k(1 - b) = f(k(1 - b)) \implies f(k(1 - b)) = k(b - 1). \]
Let $z = k(1 - b)$. Then $b - 1 = -z/k$.
Substituting this into the equation gives $f(z) = k(-z/k) = -z$.
Testing $f(x) = -x$ (which is $c - x$ with $c = 0$):
LHS: $(b - a)f(f(a)) = (b - a)a$.
RHS: $a f(a + f(b)) = a f(a - b) = a(b - a)$.
LHS = RHS, so $f(x) = -x$ is a solution.

**Conclusion**
The solutions are $f(x) = 0$ and $f(x) = c - x$ for any $c \in \mathbb{R}$.
