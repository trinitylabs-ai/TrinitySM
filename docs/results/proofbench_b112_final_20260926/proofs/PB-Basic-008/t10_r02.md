To prove that $\sqrt{a}+\sqrt{b}+\sqrt{c} \geq 3\sqrt{3}(ab+bc+ca)$ for positive reals $a,b,c$ such that $a+b+c=1$, we proceed as follows:

First, we express the term $ab+bc+ca$ in terms of the given constraint $a+b+c=1$. We know that:
\[(a+b+c)^2 = a^2+b^2+c^2 + 2(ab+bc+ca) = 1\]
Thus, we have $ab+bc+ca = \frac{1 - (a^2+b^2+c^2)}{2}$. Substituting this into the target inequality, we seek to prove:
\[\sqrt{a}+\sqrt{b}+\sqrt{c} \geq 3\sqrt{3} \left( \frac{1 - (a^2+b^2+c^2)}{2} \right)\]
Rearranging the terms to group variables, this is equivalent to:
\[\sqrt{a}+\sqrt{b}+\sqrt{c} + \frac{3\sqrt{3}}{2}(a^2+b^2+c^2) \geq \frac{3\sqrt{3}}{2}\]
Since $a+b+c=1$, we can write the constant on the right side as $\frac{3\sqrt{3}}{2}(a+b+c)$. The inequality then becomes:
\[\sum_{cyc} \left( \sqrt{a} + \frac{3\sqrt{3}}{2} a^2 \right) \geq \sum_{cyc} \frac{3\sqrt{3}}{2} a\]
This is equivalent to showing that:
\[\sum_{cyc} \left( \sqrt{a} + \frac{3\sqrt{3}}{2} a^2 - \frac{3\sqrt{3}}{2} a \right) \geq 0\]
Let $h(x) = \sqrt{x} + \frac{3\sqrt{3}}{2}(x^2 - x)$ for $x \in (0, 1)$. We aim to show that $h(x) \geq 0$ for all $x \in (0, 1)$.
The derivative of $h(x)$ is:
\[h'(x) = \frac{1}{2\sqrt{x}} + 3\sqrt{3}x - \frac{3\sqrt{3}}{2} = \frac{1 + 6\sqrt{3}x\sqrt{x} - 3\sqrt{3}\sqrt{x}}{2\sqrt{x}}\]
To find the critical points, we set the numerator to zero. Let $u = \sqrt{x}$, where $u \in (0, 1)$. We solve:
\[N(u) = 6\sqrt{3}u^3 - 3\sqrt{3}u + 1 = 0\]
Testing $u = \frac{1}{\sqrt{3}}$, we find $N\left(\frac{1}{\sqrt{3}}\right) = 6\sqrt{3}\left(\frac{1}{3\sqrt{3}}\right) - 3\sqrt{3}\left(\frac{1}{\sqrt{3}}\right) + 1 = 2 - 3 + 1 = 0$.
Since $u = \frac{1}{\sqrt{3}}$ is a root, we factor $N(u)$ as:
\[N(u) = \left(u - \frac{1}{\sqrt{3}}\right)(6\sqrt{3}u^2 + 6u - \sqrt{3})\]
The roots of the quadratic factor $6\sqrt{3}u^2 + 6u - \sqrt{3} = 0$ are:
\[u = \frac{-6 \pm \sqrt{36 - 4(6\sqrt{3})(-\sqrt{3})}}{12\sqrt{3}} = \frac{-6 \pm \sqrt{36 + 72}}{12\sqrt{3}} = \frac{-6 \pm \sqrt{108}}{12\sqrt{3}} = \frac{-6 \pm 6\sqrt{3}}{12\sqrt{3}} = \frac{-1 \pm \sqrt{3}}{2\sqrt{3}}\]
The only positive root is $u_0 = \frac{\sqrt{3}-1}{2\sqrt{3}}$.
Analyzing the sign of $N(u)$ for $u \in (0, 1)$:
- For $u \in (0, u_0)$, $N(u) > 0$ (since $N(0) = 1$), so $h(x)$ is increasing.
- For $u \in (u_0, 1/\sqrt{3})$, $N(u) < 0$, so $h(x)$ is decreasing.
- For $u \in (1/\sqrt{3}, 1)$, $N(u) > 0$, so $h(x)$ is increasing.

We evaluate $h(x)$ at the boundaries and the local minimum:
$h(0) = 0$ and $h(1/3) = \sqrt{1/3} + \frac{3\sqrt{3}}{2}(\frac{1}{9} - \frac{1}{3}) = \frac{1}{\sqrt{3}} + \frac{3\sqrt{3}}{2}(-\frac{2}{9}) = \frac{1}{\sqrt{3}} - \frac{\sqrt{3}}{3} = 0$.
Since $h(x)$ increases from $0$ to $h(u_0^2)$, then decreases to $h(1/3) = 0$, and then increases again, we conclude that $h(x) \geq 0$ for all $x \in (0, 1)$.

Summing the inequalities $h(a) \geq 0, h(b) \geq 0, h(c) \geq 0$, we obtain:
\[\sum \sqrt{a} + \frac{3\sqrt{3}}{2} \sum a^2 - \frac{3\sqrt{3}}{2} \sum a \geq 0\]
Substituting $\sum a = 1$ and $\sum a^2 = 1 - 2(ab+bc+ca)$:
\[\sum \sqrt{a} + \frac{3\sqrt{3}}{2}(1 - 2(ab+bc+ca)) - \frac{3\sqrt{3}}{2} \geq 0\]
\[\sum \sqrt{a} + \frac{3\sqrt{3}}{2} - 3\sqrt{3}(ab+bc+ca) - \frac{3\sqrt{3}}{2} \geq 0\]
\[\sqrt{a}+\sqrt{b}+\sqrt{c} \geq 3\sqrt{3}(ab+bc+ca)\]
Equality holds if and only if $a=b=c=1/3$.
