To prove that for positive reals $a, b, c$ such that $a+b+c=1$, the inequality $\sqrt{a}+\sqrt{b}+\sqrt{c} \geq 3\sqrt{3}(ab+bc+ca)$ holds, we proceed as follows:

First, we use the algebraic identity for the sum of pairwise products:
\[ (a+b+c)^2 = a^2+b^2+c^2 + 2(ab+bc+ca). \]
Given that $a+b+c=1$, we can express the sum of pairwise products as:
\[ ab+bc+ca = \frac{1 - (a^2+b^2+c^2)}{2}. \]
Substituting this expression into the right-hand side of the inequality we wish to prove, we have:
\[ 3\sqrt{3}(ab+bc+ca) = 3\sqrt{3} \left( \frac{1 - (a^2+b^2+c^2)}{2} \right) = \frac{3\sqrt{3}}{2}(1 - \sum a^2). \]
The original inequality $\sqrt{a}+\sqrt{b}+\sqrt{c} \geq 3\sqrt{3}(ab+bc+ca)$ is therefore equivalent to:
\[ \sum \sqrt{a} \geq \frac{3\sqrt{3}}{2}(1 - \sum a^2). \]
Since $a+b+c=1$, we can write $1$ as $\sum a$. The inequality becomes:
\[ \sum \sqrt{a} \geq \frac{3\sqrt{3}}{2} \sum a - \frac{3\sqrt{3}}{2} \sum a^2, \]
which can be rearranged as:
\[ \sum \left( \sqrt{a} - \frac{3\sqrt{3}}{2} a + \frac{3\sqrt{3}}{2} a^2 \right) \geq 0. \]
Let $g(x) = \sqrt{x} - \frac{3\sqrt{3}}{2} x + \frac{3\sqrt{3}}{2} x^2$ for $x \in (0, 1)$. To prove the inequality, it suffices to show that $g(x) \geq 0$ for all $x \in (0, 1)$. We factor out $\sqrt{x}$ from the expression:
\[ g(x) = \sqrt{x} \left( 1 - \frac{3\sqrt{3}}{2} \sqrt{x} + \frac{3\sqrt{3}}{2} x^{3/2} \right). \]
Let $t = \sqrt{x}$. Since $x \in (0, 1)$, we have $t \in (0, 1)$. The term in the parentheses is:
\[ f(t) = 1 - \frac{3\sqrt{3}}{2} (t - t^3). \]
To find the maximum value of the function $h(t) = t - t^3$ on the interval $(0, 1)$, we compute its derivative:
\[ h'(t) = 1 - 3t^2. \]
Setting $h'(t) = 0$ yields $t = \frac{1}{\sqrt{3}}$. The maximum value of $h(t)$ on this interval is:
\[ h\left(\frac{1}{\sqrt{3}}\right) = \frac{1}{\sqrt{3}} - \left(\frac{1}{\sqrt{3}}\right)^3 = \frac{1}{\sqrt{3}} - \frac{1}{3\sqrt{3}} = \frac{2}{3\sqrt{3}}. \]
Using this maximum value, we find the minimum value of $f(t)$:
\[ f(t) = 1 - \frac{3\sqrt{3}}{2} h(t) \geq 1 - \frac{3\sqrt{3}}{2} \left( \frac{2}{3\sqrt{3}} \right) = 1 - 1 = 0. \]
Since $t = \sqrt{x} > 0$ and $f(\sqrt{x}) \geq 0$, it follows that $g(x) = \sqrt{x} f(\sqrt{x}) \geq 0$ for all $x \in (0, 1)$. Summing these values for $a, b, c$, we obtain:
\[ \sum g(a) = \sum \sqrt{a} - \frac{3\sqrt{3}}{2} \sum a + \frac{3\sqrt{3}}{2} \sum a^2 = \sum \sqrt{a} - \frac{3\sqrt{3}}{2}(1 - \sum a^2) \geq 0. \]
Thus, $\sum \sqrt{a} \geq 3\sqrt{3} \sum ab$. Equality holds if and only if $f(\sqrt{a}) = f(\sqrt{b}) = f(\sqrt{c}) = 0$, which implies $\sqrt{a} = \sqrt{b} = \sqrt{c} = \frac{1}{\sqrt{3}}$, or $a=b=c=1/3$.

\(\square\)
