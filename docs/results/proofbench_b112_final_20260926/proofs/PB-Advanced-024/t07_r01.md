Let $P: \mathbb{Q} \to \mathbb{Q}$ be a function satisfying the equation
\[ (P(b-P(a))+a-P(b))(P(a+P(b-P(a)))-b)=0 \]
for all $a, b \in \mathbb{Q}$. Let $X(a, b) = P(b-P(a)) + a - P(b)$ and $Y(a, b) = P(a+P(b-P(a))) - b$. The given equation is $X(a, b) Y(a, b) = 0$.

First, we prove that $P$ is injective. Suppose there exist $x, y \in \mathbb{Q}$ such that $P(x) = P(y)$ with $x \neq y$. For any $a \in \mathbb{Q}$, let $w_a = P(x-P(a))$. Since $P(x) = P(y)$, we have $P(x-P(a)) = P(y-P(a))$, so $w_a$ is the same for both $x$ and $y$. Then:
$X(a, x) = w_a + a - P(x)$ and $X(a, y) = w_a + a - P(y)$.
Since $P(x) = P(y)$, we have $X(a, x) = X(a, y)$ for all $a$.
Also, $Y(a, x) = P(a+w_a) - x$ and $Y(a, y) = P(a+w_a) - y$.
Since $x \neq y$, $Y(a, x)$ and $Y(a, y)$ cannot both be zero.
Since $X(a, x) Y(a, x) = 0$ and $X(a, y) Y(a, y) = 0$, and $X(a, x) = X(a, y)$, it must be that $X(a, x) = 0$ for all $a \in \mathbb{Q}$.
Thus, $P(x-P(a)) = P(x) - a$ for all $a \in \mathbb{Q}$.
As $a$ varies over $\mathbb{Q}$, the expression $P(x) - a$ takes all values in $\mathbb{Q}$, which implies that $P$ is surjective.
Since $P$ is surjective, there exists $c \in \mathbb{Q}$ such that $P(c) = 0$.
Substituting $a=c$ into $P(x-P(a)) = P(x) - a$, we get $P(x-0) = P(x) - c$, which implies $c = 0$. Thus $P(0) = 0$.
Substituting $x=0$ into $P(x-P(a)) = P(x) - a$, we get $P(-P(a)) = P(0) - a = -a$.
If $P(a) = P(b)$, then $-a = P(-P(a)) = P(-P(b)) = -b$, so $a = b$.
This proves that $P$ is injective, contradicting our assumption $x \neq y$. Thus, $P$ must be injective.

Next, we show $P(0) = 0$. Since $P$ is injective, $X(0, b) = P(b-P(0)) - P(b)$.
$X(0, b) = 0$ if and only if $b-P(0) = b$, which means $P(0) = 0$.
If $P(0) = c \neq 0$, then $X(0, b) \neq 0$ for all $b$, so we must have $Y(0, b) = 0$ for all $b$:
$P(P(b-c)) = b$. Let $b-c = z$, then $P(P(z)) = z+c$.
Then $P(P(0)) = 0+c = c$. Since $P(0) = c$, we have $P(c) = c$.
Then $P(P(c)) = c+c = 2c$. But $P(P(c)) = P(c) = c$.
Thus $2c = c$, which implies $c = 0$, contradicting $c \neq 0$.
Therefore, $P(0) = 0$.

With $P(0) = 0$, we have $X(a, 0) = P(-P(a)) + a$ and $Y(a, 0) = P(a+P(-P(a)))$.
Since $X(a, 0) Y(a, 0) = 0$, for each $a$, either $P(-P(a)) = -a$ or $P(a+P(-P(a))) = 0$.
Since $P$ is injective and $P(0)=0$, $P(a+P(-P(a))) = 0$ implies $a+P(-P(a)) = 0$, so $P(-P(a)) = -a$.
Thus, $P(-P(a)) = -a$ for all $a \in \mathbb{Q}$.

We now show that $P(P(b)) = b$ for all $b \in \mathbb{Q}$.
Suppose there exists $b_0 \in \mathbb{Q}$ such that $P(P(b_0)) \neq b_0$.
If $X(a, b_0) = 0$, then $P(b_0-P(a)) = P(b_0) - a$.
Then $Y(a, b_0) = P(a+P(b_0-P(a))) - b_0 = P(a + P(b_0) - a) - b_0 = P(P(b_0)) - b_0$.
Since $P(P(b_0)) \neq b_0$, $Y(a, b_0) \neq 0$ whenever $X(a, b_0) = 0$.
Since $X(a, b_0) Y(a, b_0) = 0$ for all $a$, we must have $X(a, b_0) = 0$ for all $a \in \mathbb{Q}$.
Then $P(b_0-P(a)) = P(b_0) - a$. Let $P(a) = z$. Then $P(b_0-z) = P(b_0) - P^{-1}(z)$.
For $z=b_0$, we have $P(0) = P(b_0) - P^{-1}(b_0)$.
Since $P(0) = 0$, we have $P(b_0) = P^{-1}(b_0)$, so $P(P(b_0)) = b_0$, a contradiction.
Thus, $P(P(b)) = b$ for all $b \in \mathbb{Q}$.

Now, if $X(a, b) = 0$, then $P(b-P(a)) = P(b) - a$.
Then $Y(a, b) = P(a+P(b)-a) - b = P(P(b)) - b = b - b = 0$.
Thus $X(a, b) = 0$ implies $Y(a, b) = 0$.
The original equation $X(a, b) Y(a, b) = 0$ then implies $Y(a, b) = 0$ for all $a, b \in \mathbb{Q}$.
$P(a+P(b-P(a))) = b$.
Let $P(b-P(a)) = z$. Then $b-P(a) = P(z)$, so $b = P(z) + P(a)$.
The equation becomes $P(a+z) = P(a) + P(z)$ for all $a, z \in \mathbb{Q}$.
This is Cauchy's functional equation, and since the domain is $\mathbb{Q}$, $P(x) = mx$ for some $m \in \mathbb{Q}$.
Substituting $P(x) = mx$ into $P(P(x)) = x$, we get $m^2x = x$, so $m^2 = 1$, which means $m = 1$ or $m = -1$.
Thus, the only solutions are $P(x) = x$ and $P(x) = -x$.

For both $P(x) = x$ and $P(x) = -x$, we have $P(a) + P(-a) = a + (-a) = 0$ or $P(a) + P(-a) = -a + a = 0$.
The set $\{P(a) + P(-a) : a \in \mathbb{Q}\}$ is $\{0\}$, which contains exactly 1 element.
The maximum possible number of elements in this set is 1.
