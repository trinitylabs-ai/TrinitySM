To prove that there exists a positive integer $N$ such that for every odd integer $n > N$, the digits in the base-$2n$ representation of $n^k$ are all greater than $d$, we analyze the process of finding the digits of $n^k$ in base $2n$.

Let the base-$2n$ representation of $n^k$ be $n^k = a_m(2n)^m + a_{m-1}(2n)^{m-1} + \dots + a_1(2n) + a_0$, where $0 \le a_i < 2n$. These digits are determined by the sequence $X_0, X_1, \dots, X_m$ defined by $X_0 = n^k$, $a_i = X_i \pmod{2n}$, and $X_{i+1} = \frac{X_i - a_i}{2n}$.

First, we determine $a_0$. Since $n$ is odd, $n^{k-1}$ is also odd, so $n^{k-1} = 2q + 1$ for some integer $q$. Then $n^k = n(2q + 1) = 2qn + n$. Since $0 \le n < 2n$, we have $a_0 = n$. For $n > d$, it is clear that $a_0 > d$.

Next, we find $X_1$:
$X_1 = \frac{n^k - n}{2n} = \frac{n^{k-1} - 1}{2}$.
The digit $a_1$ is $X_1 \pmod{2n}$, which implies $2a_1 = 2X_1 \pmod{4n} = (n^{k-1} - 1) \pmod{4n}$.
Thus, $2a_1 = m_1 n - 1$ for some integer $m_1$. Since $0 \le a_1 < 2n$, we have $0 \le 2a_1 < 4n$, implying $1 \le m_1 n < 4n + 1$, so $m_1 \in \{1, 2, 3, 4\}$. Because $m_1 n = 2a_1 + 1$ is odd and $n$ is odd, $m_1$ must be odd, so $m_1 \in \{1, 3\}$.
Then $X_2 = \frac{X_1 - a_1}{2n} = \frac{\frac{n^{k-1}-1}{2} - \frac{m_1 n - 1}{2}}{2n} = \frac{n^{k-1} - m_1 n}{4n} = \frac{n^{k-2} - m_1}{4}$.

We proceed by induction. Assume $X_i = \frac{n^{k-i} - m_{i-1}}{2^i}$ for some odd integer $m_{i-1}$. Then:
$2^i a_i = 2^i X_i \pmod{2^{i+1} n} = (n^{k-i} - m_{i-1}) \pmod{2^{i+1} n}$.
Thus, $2^i a_i = m_i n - m_{i-1}$ for some integer $m_i$. Since $0 \le a_i < 2n$, we have $0 \le 2^i a_i < 2^{i+1} n$, which means $m_{i-1} \le m_i n < 2^{i+1} n + m_{i-1}$. Since $m_i n = 2^i a_i + m_{i-1}$ and $m_{i-1}$ is odd, $m_i n$ must be odd, so $m_i$ is odd.
Then $X_{i+1} = \frac{X_i - a_i}{2n} = \frac{\frac{n^{k-i} - m_{i-1}}{2^i} - \frac{m_i n - m_{i-1}}{2^i}}{2n} = \frac{n^{k-i} - m_i n}{2^{i+1} n} = \frac{n^{k-i-1} - m_i}{2^{i+1}}$.
This inductive step holds for $i = 1, 2, \dots, k-1$.

For $i = k-1$, we have $X_{k-1} = \frac{n - m_{k-2}}{2^{k-1}}$. For $n$ sufficiently large, $0 < X_{k-1} < 2n$, so $a_{k-1} = X_{k-1}$ and $X_k = 0$. The digits are $a_0, a_1, \dots, a_{k-1}$.
From $m_i n < 2^{i+1} n + m_{i-1}$, we have $m_i < 2^{i+1} + \frac{m_{i-1}}{n}$. For $n > 2^k$, we can show by induction that $m_i \le 2^{i+1} - 1$ for all $i$.
Now we bound the digits $a_i$:
1. $a_0 = n$.
2. For $1 \le i \le k-2$, $a_i = \frac{m_i n - m_{i-1}}{2^i} \ge \frac{n - (2^i - 1)}{2^i} = \frac{n+1}{2^i} - 1$.
3. For $i = k-1$, $a_{k-1} = \frac{n - m_{k-2}}{2^{k-1}} \ge \frac{n - (2^{k-1} - 1)}{2^{k-1}} = \frac{n+1}{2^{k-1}} - 1$.

All digits $a_i$ are greater than $d$ if $\frac{n+1}{2^{k-1}} - 1 > d$, which simplifies to $n > 2^{k-1}(d+1) - 1$.
Choosing $N = \max(2^k, 2^{k-1}(d+1))$, for every odd integer $n > N$, all digits in the base-$2n$ representation of $n^k$ are greater than $d$. \(\square\)
