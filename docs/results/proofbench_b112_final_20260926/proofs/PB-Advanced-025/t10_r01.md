Let $k$ and $d$ be positive integers. We wish to show that there exists a positive integer $N$ such that for every odd integer $n > N$, the digits of $n^k$ in base $B = 2n$ are all greater than $d$.

Case 1: $k = 1$.
In this case, $n^k = n$. Since $n < 2n$, the base-$2n$ representation of $n$ consists of a single digit $a_0 = n$. For any $n > d$, we have $a_0 > d$. Thus, for $k=1$, we may take $N = d$.

Case 2: $k \ge 2$.
Let $B = 2n$. The base-$B$ representation of $n^k$ is $n^k = a_m B^m + a_{m-1} B^{m-1} + \dots + a_0$, where $0 \le a_i < B$.
For $n > 2^{k-1}$, we have $B^{k-1} = (2n)^{k-1} = 2^{k-1} n^{k-1} < n \cdot n^{k-1} = n^k$. Also, $n^k < (2n)^k = B^k$. Thus, the number of digits is exactly $k$, and the highest power is $m = k-1$.

The digits $a_i$ are determined by the recursive process:
$R_k = n^k$
$a_{k-1} = \lfloor R_k / B^{k-1} \rfloor = \lfloor n^k / (2n)^{k-1} \rfloor = \lfloor n / 2^{k-1} \rfloor$
$R_{k-1} = R_k \pmod{B^{k-1}} = n^k - \lfloor n/2^{k-1} \rfloor 2^{k-1} n^{k-1} = (n \pmod{2^{k-1}}) n^{k-1}$

Let $r_{k-1} = n \pmod{2^{k-1}}$. Since $k \ge 2$, $2^{k-1}$ is even. Since $n$ is odd, $r_{k-1}$ must be odd.
We now show by induction that for $j = k-1, k-2, \dots, 1$, the remainder is $R_j = r_j n^j$ with $r_j$ being an odd integer.
The base case $j = k-1$ is established: $R_{k-1} = r_{k-1} n^{k-1}$ and $r_{k-1}$ is odd.
Suppose $R_j = r_j n^j$ for some $j \in \{k-1, \dots, 1\}$ with $r_j$ odd. Then:
$a_{j-1} = \lfloor R_j / B^{j-1} \rfloor = \lfloor r_j n^j / (2n)^{j-1} \rfloor = \lfloor r_j n / 2^{j-1} \rfloor$
$R_{j-1} = R_j \pmod{B^{j-1}} = r_j n^j \pmod{2^{j-1} n^{j-1}} = (r_j n \pmod{2^{j-1}}) n^{j-1}$
Let $r_{j-1} = r_j n \pmod{2^{j-1}}$. Since $r_j$ and $n$ are both odd, their product $r_j n$ is odd. For $j-1 \ge 1$, any odd number modulo $2^{j-1}$ is odd. Thus, $r_{j-1}$ is odd.
This completes the induction, showing $r_j \ge 1$ for all $j \in \{1, \dots, k-1\}$.

Now we evaluate the digits $a_i$:
1. For $i = k-1$, $a_{k-1} = \lfloor n / 2^{k-1} \rfloor$.
2. For $i \in \{0, \dots, k-2\}$, let $j = i+1$. Then $a_i = \lfloor r_j n / 2^{j-1} \rfloor$. Since $r_j \ge 1$, we have $a_i \ge \lfloor n / 2^{j-1} \rfloor$.
3. For $i = 0$, $a_0 = \lfloor r_1 n / 2^0 \rfloor = r_1 n$. Since $r_1$ is odd and $0 \le r_1 < 2^1$, we must have $r_1 = 1$, so $a_0 = n$.

Comparing the lower bounds, since $2^{j-1} \le 2^{k-2}$ for $j \le k-1$, we have $\lfloor n / 2^{j-1} \rfloor \ge \lfloor n / 2^{k-2} \rfloor$. Thus, the smallest digit is $a_{k-1} = \lfloor n / 2^{k-1} \rfloor$.
To ensure all digits are greater than $d$, we require $a_{k-1} \ge d+1$:
$\lfloor n / 2^{k-1} \rfloor \ge d+1 \iff n / 2^{k-1} \ge d+1 \iff n \ge (d+1) 2^{k-1}$.

Let $N = (d+1) 2^{k-1}$. For any odd integer $n > N$, we have $n \ge (d+1) 2^{k-1} + 1$ (since $(d+1) 2^{k-1}$ is even for $k \ge 2$). Then:
$a_{k-1} = \lfloor n / 2^{k-1} \rfloor \ge \lfloor ((d+1) 2^{k-1} + 1) / 2^{k-1} \rfloor = d+1 > d$.
Since $a_{k-1}$ is the minimum digit, all digits are greater than $d$.
Finally, we verify that $n > N$ ensures the number of digits is $k$:
$N = (d+1) 2^{k-1} \ge 2 \cdot 2^{k-1} = 2^k > 2^{k-1}$.
Thus $n > N \implies n > 2^{k-1}$, which guarantees $n^k$ has exactly $k$ digits in base $2n$.

Combining both cases, $N = (d+1) 2^{k-1}$ suffices for all $k \ge 1$.
