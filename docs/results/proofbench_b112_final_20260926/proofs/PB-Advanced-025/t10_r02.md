Let $k$ and $d$ be positive integers. We wish to find a positive integer $N$ such that for every odd integer $n > N$, the digits of $n^k$ in base $B = 2n$ are all greater than $d$.

Let the base-$2n$ representation of $n^k$ be
\[ n^k = a_m (2n)^m + a_{m-1} (2n)^{m-1} + \dots + a_1 (2n) + a_0 \]
where $0 \le a_j < 2n$ for all $j$ and $a_m \neq 0$. The digits $a_j$ are determined by the sequence of quotients $X_j$, where $X_0 = n^k$ and $X_{j+1} = \lfloor X_j / 2n \rfloor$, such that $a_j = X_j \pmod{2n} = X_j - 2n X_{j+1}$.

First, we determine $a_0$. Since $n$ is odd, $n^{k-1}$ is also odd, so $n^{k-1} = 2q + 1$ for some integer $q$. Then
\[ n^k = n \cdot n^{k-1} = n(2q + 1) = q(2n) + n. \]
Since $0 \le n < 2n$, the remainder of $n^k$ modulo $2n$ is $a_0 = n$. For any $n > d$, we have $a_0 > d$.

Next, we determine the subsequent digits. The first quotient is $X_1 = \lfloor n^k / 2n \rfloor = q = \frac{n^{k-1}-1}{2}$.
For $j=1, 2, \dots, k$, let $s_j$ be the remainder of $n^{k-j}$ modulo $2^j$. Since $n$ is odd, $n^{k-j}$ is odd for all $j$, which implies $s_j \in \{1, 3, \dots, 2^j-1\}$. In particular, $1 \le s_j \le 2^j-1$.

We claim that for sufficiently large $n$, $X_j = \frac{n^{k-j}-s_j}{2^j}$ for $j=1, 2, \dots, k-1$.
For $j=1$, $X_1 = \frac{n^{k-1}-1}{2}$. Since $s_1 = n^{k-1} \pmod 2 = 1$, the claim holds.
Assume the claim holds for some $j < k-1$. Then
\[ X_{j+1} = \left\lfloor \frac{X_j}{2n} \right\rfloor = \left\lfloor \frac{n^{k-j}-s_j}{2^j \cdot 2n} \right\rfloor = \left\lfloor \frac{n^{k-j-1}}{2^{j+1}} - \frac{s_j}{2^{j+1}n} \right\rfloor. \]
Using the definition of $s_{j+1}$, let $n^{k-j-1} = 2^{j+1} q + s_{j+1}$. Then
\[ X_{j+1} = q + \left\lfloor \frac{s_{j+1}}{2^{j+1}} - \frac{s_j}{2^{j+1}n} \right\rfloor = q + \left\lfloor \frac{s_{j+1}n - s_j}{2^{j+1}n} \right\rfloor. \]
Since $s_{j+1} \ge 1$ and $s_j \le 2^j-1$, we have $s_{j+1}n - s_j \ge n - (2^j-1)$. For $n \ge 2^j$, this is at least 1. Furthermore, since $s_{j+1} \le 2^{j+1}-1$, we have $s_{j+1}n - s_j \le (2^{j+1}-1)n - 1 < 2^{j+1}n$. Thus, for $n \ge 2^j$, the term inside the floor satisfies $0 < \frac{s_{j+1}n - s_j}{2^{j+1}n} < 1$, so the floor is 0.
Thus, $X_{j+1} = q = \frac{n^{k-j-1}-s_{j+1}}{2^{j+1}}$. This completes the induction for $j=1, \dots, k-1$.

Now we calculate the digits $a_j$ for $j=1, \dots, k-1$:
For $j=1, \dots, k-2$:
\[ a_j = X_j - 2n X_{j+1} = \frac{n^{k-j}-s_j}{2^j} - 2n \left( \frac{n^{k-j-1}-s_{j+1}}{2^{j+1}} \right) = \frac{n^{k-j}-s_j - (n^{k-j}-s_{j+1}n)}{2^j} = \frac{s_{j+1}n - s_j}{2^j}. \]
Since $s_{j+1} \ge 1$ and $s_j \le 2^j-1$, we have $a_j \ge \frac{n - (2^j-1)}{2^j}$.
For $j=k-1$:
$X_k = \lfloor X_{k-1}/2n \rfloor = \lfloor \frac{n-s_{k-1}}{2^{k-1} \cdot 2n} \rfloor = \lfloor \frac{n-s_{k-1}}{2^k n} \rfloor$.
Since $0 \le n-s_{k-1} < n$, we have $0 \le \frac{n-s_{k-1}}{2^k n} < \frac{1}{2^k} < 1$. Thus, $X_k = 0$.
This implies that the highest power of $2n$ in the representation of $n^k$ is $(2n)^{k-1}$, and the digits are $a_0, a_1, \dots, a_{k-1}$.
The last digit is $a_{k-1} = X_{k-1} = \frac{n-s_{k-1}}{2^{k-1}} \ge \frac{n - (2^{k-1}-1)}{2^{k-1}}$.

Finally, we ensure all $a_j > d$. For each $j \in \{1, \dots, k-1\}$, the condition $a_j > d$ is satisfied if
\[ \frac{n - (2^j-1)}{2^j} > d \implies n > d 2^j + 2^j - 1. \]
By choosing $N = \max \{ d, \max_{1 \le j \le k-1} (d 2^j + 2^j - 1), 2^{k-2} \}$, we guarantee that for all odd $n > N$, the induction condition $n \ge 2^j$ is satisfied and all digits $a_0, a_1, \dots, a_{k-1}$ are greater than $d$.
