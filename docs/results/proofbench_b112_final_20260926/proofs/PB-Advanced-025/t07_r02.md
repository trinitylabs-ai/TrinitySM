Let $k$ and $d$ be positive integers. We wish to show that there exists a positive integer $N$ such that for every odd integer $n > N$, the digits in the base-$2n$ representation of $n^k$ are all greater than $d$. Let the base be $B = 2n$. The base-$B$ representation of $n^k$ is given by
\[ n^k = a_m B^m + a_{m-1} B^{m-1} + \dots + a_1 B + a_0, \]
where $0 \le a_i < B$ for all $i$ and $a_m \neq 0$. We must show that $a_i > d$ for all $i \in \{0, 1, \dots, m\}$.

First, consider the digit $a_0$. By definition, $a_0 \equiv n^k \pmod{2n}$. Since $n$ is odd, $n^{k-1}$ is also odd, so $n^{k-1}-1$ is even. Thus, $n^k - n = n(n^{k-1}-1)$ is a multiple of $2n$. This implies $n^k \equiv n \pmod{2n}$. Since $0 \le n < 2n$, we must have $a_0 = n$. For any $n > d$, the condition $a_0 > d$ is satisfied.

Next, we determine the digits $a_1, \dots, a_m$. From the base representation, we have
\[ n^k - n = \sum_{i=1}^m a_i (2n)^i. \]
Dividing both sides by $2n$, we obtain
\[ X = \frac{n^{k-1}-1}{2} = \sum_{i=1}^m a_i (2n)^{i-1}. \]
This expression is the base-$2n$ representation of the integer $X$. The digits $a_1, \dots, a_m$ are the coefficients of the powers of $2n$ in the expansion of $X$. Specifically, for $i \ge 1$, the $i$-th digit $a_i$ is given by
\[ a_i = \left\lfloor \frac{X}{(2n)^{i-1}} \right\rfloor \pmod{2n} = \left\lfloor \frac{n^{k-1}-1}{2(2n)^{i-1}} \right\rfloor \pmod{2n} = \left\lfloor \frac{n^{k-i}}{2^i} - \frac{1}{2^i n^{i-1}} \right\rfloor \pmod{2n}. \]
For $i \in \{1, \dots, k-1\}$, let $x = \frac{n^{k-i}}{2^i}$ and $\epsilon = \frac{1}{2^i n^{i-1}}$. Since $n$ is odd, $n^{k-i}$ is odd, so the fractional part of $x$ is $\{x\} = \frac{n^{k-i} \pmod{2^i}}{2^i}$. Because $n^{k-i}$ is odd, $n^{k-i} \pmod{2^i}$ is an odd integer $\ge 1$, so $\{x\} \ge \frac{1}{2^i}$. Since $n \ge 1$ and $i \ge 1$, we have $\epsilon = \frac{1}{2^i n^{i-1}} \le \frac{1}{2^i}$. Thus $\{x\} \ge \epsilon$, which implies $\lfloor x - \epsilon \rfloor = \lfloor x \rfloor$.
It follows that $a_i = \lfloor \frac{n^{k-i}}{2^i} \rfloor \pmod{2n}$ for $i=1, \dots, k-1$. For $i \ge k$, we have $X = \frac{n^{k-1}-1}{2} < \frac{n^{k-1}}{2} < (2n)^{k-1}$ for all $n \ge 1, k \ge 1$. Since $X < (2n)^{k-1}$, the base-$2n$ representation of $X$ has at most $k-1$ digits. Thus, $a_i = 0$ for all $i \ge k$. This means the maximum index is $m \le k-1$.

To analyze $a_i = \lfloor \frac{n^{k-i}}{2^i} \rfloor \pmod{2n}$ for $i \in \{1, \dots, k-1\}$, let $M = k-i$ and $C = 2^i$. We examine $a_i = \lfloor \frac{n^M}{C} \rfloor \pmod{2n}$ for $M \in \{1, \dots, k-1\}$.
Let $n^{M-1} = q(2C) + s$, where $0 \le s < 2C$. Since $n$ is odd, $n^{M-1}$ is odd, and since $2C$ is even, $s$ must be odd, implying $s \ge 1$. Then
\[ n^M = n(q(2C) + s) = 2nCq + ns. \]
We can write $\lfloor \frac{n^M}{C} \rfloor = \lfloor \frac{2nCq + ns}{C} \rfloor = 2nq + \lfloor \frac{ns}{C} \rfloor$.
Taking this modulo $2n$, we find
\[ a_i = \lfloor \frac{ns}{C} \rfloor \pmod{2n}. \]
Since $s < 2C$, we have $ns < 2nC$, so $\lfloor \frac{ns}{C} \rfloor < 2n$. Thus, $a_i = \lfloor \frac{ns}{C} \rfloor$.
Since $s \ge 1$, we have $a_i \ge \lfloor \frac{n}{C} \rfloor$. For $a_i > d$, it suffices that $\lfloor \frac{n}{C} \rfloor \ge d+1$, which is true if $n \ge C(d+1)$.
Since $C = 2^i \le 2^{k-1}$, this condition is satisfied for all $i \in \{1, \dots, k-1\}$ if $n \ge 2^{k-1}(d+1)$.

Choosing $N = 2^{k-1}(d+1)$, we have shown that for every odd integer $n > N$, the digits $a_0 = n$ and $a_i = \lfloor \frac{ns}{2^i} \rfloor$ for $1 \le i \le k-1$ are all greater than $d$. Since $a_i = 0$ for $i \ge k$, the only digits in the base-$2n$ representation of $n^k$ are $a_0, \dots, a_m$ with $m \le k-1$, all of which are greater than $d$.
