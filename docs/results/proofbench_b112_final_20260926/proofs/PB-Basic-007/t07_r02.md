We seek all positive integers $n$ and integer sequences $a_0, a_1, \dots, a_n$ such that $a_n = 3$ and $f(a_{i-1}) = a_i$ for $i = 1, 2, \dots, n$, where $f(x) = a_n x^n + a_{n-1} x^{n-1} + \dots + a_0$.

**Case 1: $n=1$**
The polynomial is $f(x) = 3x + a_0$. The condition $f(a_0) = a_1$ gives $3a_0 + a_0 = 3$, so $4a_0 = 3$, which has no integer solution. Thus, $n=1$ is impossible.

**Case 2: $n=2$**
The polynomial is $f(x) = 3x^2 + a_1 x + a_0$. The conditions are:
1. $f(a_1) = a_2 = 3 \implies 3a_1^2 + a_1^2 + a_0 = 3 \implies 4a_1^2 + a_0 = 3$.
2. $f(a_0) = a_1 \implies 3a_0^2 + a_1 a_0 + a_0 = a_1$.

From the first equation, $a_0 = 3 - 4a_1^2$. Substituting into the second:
$3(3 - 4a_1^2)^2 + a_1(3 - 4a_1^2) + (3 - 4a_1^2) = a_1$
$3(9 - 24a_1^2 + 16a_1^4) + 3a_1 - 4a_1^3 + 3 - 4a_1^2 - a_1 = 0$
$48a_1^4 - 4a_1^3 - 76a_1^2 + 2a_1 + 30 = 0 \implies 24a_1^4 - 2a_1^3 - 38a_1^2 + a_1 + 15 = 0$.
Testing integer divisors of 15, we find $a_1 = 1$ is a root: $24 - 2 - 38 + 1 + 15 = 0$.
For $a_1 = 1$, $a_0 = 3 - 4(1)^2 = -1$.
Check: $f(x) = 3x^2 + x - 1$. $f(-1) = 3 - 1 - 1 = 1 = a_1$ and $f(1) = 3 + 1 - 1 = 3 = a_2$.
Testing other integer divisors of 15 ($\pm 3, \pm 5, \pm 15$) shows no other integer roots. Thus, $(n, a_0, a_1, a_2) = (2, -1, 1, 3)$ is the only solution for $n=2$.

**Case 3: $n \ge 3$**
For any polynomial $f(x)$ with integer coefficients, $(x - y) \mid (f(x) - f(y))$.
Thus, $(a_1 - a_0) \mid (f(a_1) - f(a_0)) = (a_2 - a_1)$, and generally $(a_k - a_{k-1}) \mid (a_{k+1} - a_k)$ for $k=1, \dots, n-1$.
Let $d_k = a_k - a_{k-1}$. Then $d_1 \mid d_2 \mid \dots \mid d_n$.

Subcase 3.1: $d_k = 0$ for some $k$.
If $d_k = 0$, then $a_k = a_{k-1}$. Since $d_k \mid d_{k+1}$, we must have $d_{k+1} = 0$, and by induction $a_{k-1} = a_k = \dots = a_n = 3$.
If $k=1$, then $a_0 = a_1 = \dots = a_n = 3$. Then $f(3) = 3 \sum_{j=0}^n 3^j = 3 \frac{3^{n+1}-1}{2} = 3 \implies 3^{n+1} = 3 \implies n=0$, a contradiction.
If $k > 1$, let $m = k-1$. Then $a_m = a_{m+1} = \dots = a_n = 3$ and $a_{m-1} \neq 3$.
Then $f(a_{m-1}) = a_m = 3$ and $f(3) = a_{m+1} = 3$.
Thus $f(x) - 3 = (x-3)(x-a_{m-1}) Q(x)$ for some $Q(x) \in \mathbb{Z}[x]$.
Since $a_n = 3$, the leading coefficient of $Q(x)$ must be 3.
For $n=3$, if $a_2 = a_3 = 3$, then $f(x) = 3x^3 + 3x^2 + a_1 x + a_0$.
$f(3) = 3 \implies 81 + 27 + 3a_1 + a_0 = 3 \implies 3a_1 + a_0 = -105$.
$f(a_1) = 3 \implies 3a_1^3 + 3a_1^2 + a_1^2 + a_0 = 3 \implies 3a_1^3 + 4a_1^2 + a_0 = 3$.
Substituting $a_0 = -105 - 3a_1$ gives $3a_1^3 + 4a_1^2 - 3a_1 - 108 = 0$.
The only integer root is $a_1 = 3$, which implies $a_1 = a_2 = a_3 = 3$, reducing to the $k=1$ case.
For $n > 3$, if $a_{n-1} = a_n = 3$, then $f(x) - 3 = (x-3)(x-a_{n-2}) Q(x)$ with leading coefficient of $Q$ being 3.
Then $f(a_{n-3}) = a_{n-2} \implies 3(a_{n-3}-3)(a_{n-3}-a_{n-2}) Q(a_{n-3}) + 3 = a_{n-2}$.
This implies $(a_{n-3}-3)(a_{n-3}-a_{n-2}) \mid (a_{n-2}-3)$.
Let $X = a_{n-3}-3$ and $d = a_{n-2}-a_{n-3}$. Then $X(-d) \mid (X+d)$.
If $X=0$, then $a_{n-3}=3$, leading back to $a_i=3$. If $d=0$, then $a_{n-2}=a_{n-3}$, leading back to $a_i=3$.
If $X, d \neq 0$, then $|Xd| \le |X+d|$. For $X, d \ge 1$, $(X-1)(d-1) \le 1$.
If $X=1, d=1$, then $a_{n-3}=4, a_{n-2}=5$. Then $Q(4) = \frac{5-3}{3(4-3)(4-5)} = -2/3$, not an integer.
If $X=1, d=2$, then $a_{n-3}=4, a_{n-2}=6$. Then $Q(4) = \frac{6-3}{3(4-3)(4-6)} = -1/2$, not an integer.
Similar checks for negative $X, d$ show no solutions.

Subcase 3.2: $d_k \neq 0$ for all $k$.
Then $|d_1| \le |d_2| \le \dots \le |d_n|$.
$f(a_{n-1}) = 3 \implies 3 a_{n-1}^n + a_{n-1} a_{n-1}^{n-1} + a_{n-2} a_{n-1}^{n-2} + \dots + a_0 = 3$.
$4 a_{n-1}^n - 3 = - \sum_{k=0}^{n-2} a_k a_{n-1}^k$.
Let $A = |a_{n-1}|$. If $A \ge 3$, the LHS $|4 a_{n-1}^n - 3|$ grows as $4 A^n$, while the RHS $\sum_{k=0}^{n-2} |a_k| A^k$ grows as $O(A^{n-1})$.
Specifically, $|a_k| \le A + (n-k)|d_n|$. With $|d_n| = |3-a_{n-1}|$, for $A \ge 3$, $4 A^n - 3 \le \sum_{k=0}^{n-2} (A + (n-k)|d_n|) A^k$.
For $a_{n-1} = 3$, $d_n=0$ (handled). For $a_{n-1} \ge 4$, $d_n \le A+3$, and $4 A^n - 3 \le A \frac{A^{n-1}-1}{A-1} + (A+3) \sum (n-k) A^k$.
For $A=4$, $4 \cdot 4^n - 3 \le \frac{4^n-4}{3} + 7(2^n + 2^{n-1} - n - 2)$, which is false for $n \ge 3$.
For $a_{n-1} = -3$, $d_n = 6$. $|4(-3)^n - 3| \le 3 \frac{3^{n-1}-1}{2} + 6(3^n + 3^{n-1} - n - 2)$, which is false for $n \ge 3$.
Thus we only check $a_{n-1} \in \{-2, -1, 0, 1, 2\}$.
If $a_{n-1} = 2$, $d_n = 1$. $f(2) = 3$ and $f(a_{n-2}) = 2$.
Then $(2 - a_{n-2}) \mid (f(2) - f(a_{n-2})) = 1 \implies a_{n-2} \in \{1, 3\}$.
If $a_{n-2} = 3$, $f(3) = 2$. But $f(3) - f(2) = \sum_{j=1}^n a_j (3^j - 2^j) + (a_0 - a_0) = 3(3^n - 2^n) + 2(3^{n-1} - 2^{n-1}) + \dots$
For $n=3$, $f(3)-f(2) = 3(19) + 2(5) + 3(1) = 70 \neq -1$. For $n > 3$, this is even larger.
If $a_{n-2} = 1$, $f(1) = 2$. $f(2) - f(1) = 3(2^n - 1) + 2(2^{n-1} - 1) + 1(2^{n-2} - 1) + \dots$
For $n=3$, $f(2)-f(1) = 3(7) + 2(3) + 1(1) = 28 \neq 1$.
If $a_{n-1} = 1$, $d_n = 2$. $f(1) = 3$ and $f(a_{n-2}) = 1$.
Then $(1 - a_{n-2}) \mid 2 \implies a_{n-2} \in \{0, 2, -1, 3\}$.
If $a_{n-2} = 0$, $f(0) = 1 \implies a_0 = 1$. $f(1) = 3 \implies 3 + 1 + 0 + \dots + 1 = 3 \implies \sum_{k=1}^{n-3} a_k = -2$.
For $n=3$, $a_1 = -2$. $f(-2) = 3(-8) + 1(4) + 0 + 1 = -19 \neq 0$.
If $a_{n-1} = 0$, $d_n = 3$. $f(0) = 3 \implies a_0 = 3$. $f(a_{n-2}) = 0 \implies 3 a_{n-2}^n + 0 + a_{n-2} a_{n-2}^{n-2} + \dots + 3 = 0$.
For $n=3$, $3 a_1^3 + a_1^2 + 3 = 0$, no integer roots.
If $a_{n-1} = -1$, $d_n = 4$. $f(-1) = 3$ and $f(a_{n-2}) = -1$.
Then $(-1 - a_{n-2}) \mid 4 \implies a_{n-2} \in \{0, -2, 1, -3, -5, 3\}$.
For $n=3$, $f(-1) = -3 + 1 + a_1(-1) + a_0 = 3 \implies a_0 - a_1 = 5$.
$f(a_1) = -1 \implies 3 a_1^3 - a_1^2 + a_1^2 + a_0 = -1 \implies 3 a_1^3 + a_0 = -1$.
Substituting $a_0 = 5 + a_1$ gives $3 a_1^3 + a_1 + 6 = 0$.
Integer roots must divide 6. $a_1 = -1 \implies -3-1+6 = 2$; $a_1 = -2 \implies -24-2+6 = -20$. No roots.
If $a_{n-1} = -2$, $d_n = 5$. $f(-2) = 3$ and $f(a_{n-2}) = -2$.
Then $(-2 - a_{n-2}) \mid 5 \implies a_{n-2} \in \{-1, -3, -7, 3\}$.
For $n=3$, $f(-2) = -24 + 8 - 2 a_1 + a_0 = 3 \implies a_0 - 2 a_1 = 19$.
$f(a_1) = -2 \implies 3 a_1^3 - 2 a_1^2 + a_1^2 + a_0 = -2 \implies 3 a_1^3 - a_1^2 + a_0 = -2$.
Substituting $a_0 = 19 + 2 a_1$ gives $3 a_1^3 - a_1^2 + 2 a_1 + 21 = 0$.
Integer roots must divide 21. $a_1 = -1 \implies -3-1-2+21 = 15$; $a_1 = -2 \implies -24-4-4+21 = -11$. No roots.

The only solution is $n=2$ with $a_0 = -1, a_1 = 1, a_2 = 3$.
