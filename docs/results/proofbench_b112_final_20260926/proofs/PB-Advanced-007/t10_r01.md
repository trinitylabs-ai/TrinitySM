To prove that there exist real-coefficient polynomials $P(x)$ and $Q(x)$ satisfying the condition $P(Q(x)-x-1) = Q(P(x))$ with $\deg(P) \ge 2024$ and $\deg(Q) \ge 2$, we seek a specific form for $P$ and $Q$.

Let $Q(x) = x^2 + x + 1$. Then the expression $Q(x) - x - 1$ simplifies to $x^2$. The condition $P(Q(x)-x-1) = Q(P(x))$ then becomes:
\[ P(x^2) = P(x)^2 + P(x) + 1 \]
We search for a polynomial $P(x)$ of the form $P(x) = x^n + a_{n-1}x^{n-1} + \dots + a_0$ for $n \ge 2024$.
Equating the leading coefficients of $P(x^2)$ and $P(x)^2 + P(x) + 1$, we have $a_n = a_n^2$, which implies $a_n = 1$ since $P$ is not the zero polynomial.
Matching the coefficient of $x^{2n-1}$ in the equation $P(x^2) = P(x)^2 + P(x) + 1$:
The LHS $P(x^2)$ has no $x^{2n-1}$ term. The RHS $P(x)^2 + P(x) + 1$ contains the term $2a_n a_{n-1} x^{2n-1} = 2a_{n-1} x^{2n-1}$. Thus, $2a_{n-1} = 0$, implying $a_{n-1} = 0$.
Continuing this for all odd powers $x^{2n-k}$, we find $a_{n-k} = 0$ for all odd $k$.
If we test the form $P(x) = x^n + c$, the equation becomes:
\[ x^{2n} + c = (x^n + c)^2 + (x^n + c) + 1 = x^{2n} + (2c+1)x^n + c^2 + c + 1 \]
For this to hold for all $x$, we must have:
1. $2c + 1 = 0 \implies c = -1/2$.
2. $c = c^2 + c + 1 \implies c^2 + 1 = 0$.
This system has no real solutions.

However, if we consider the case where $P$ and $Q$ are constants, we find solutions like $P(x) = 1, Q(x) = x^2 - x + 1$, where $P(Q(x)-x-1) = 1$ and $Q(P(x)) = Q(1) = 1^2 - 1 + 1 = 1$. To satisfy $\deg(P) \ge 2024$, we look for a non-constant $P$ such that $Q(P(x)) = P(Q(x)-x-1)$.

We search for polynomials of the form $Q(x) = qx^2 + x + c$ and $P(x) = bx^n + a$ for some $n \ge 2024$.
First, we simplify the expression $Q(x) - x - 1$:
\[ Q(x) - x - 1 = (qx^2 + x + c) - x - 1 = qx^2 + c - 1 \]
The condition $P(Q(x)-x-1) = Q(P(x))$ then becomes:
\[ b(qx^2 + c - 1)^n + a = q(bx^n + a)^2 + (bx^n + a) + c \]
Expanding the right-hand side:
\[ b(qx^2 + c - 1)^n + a = qb^2x^{2n} + (2qab + b)x^n + qa^2 + a + c \]

For $n=2$, the left-hand side is $b(q^2x^4 + 2q(c-1)x^2 + (c-1)^2) + a$. Matching the coefficients of $x^4, x^2,$ and the constant term:
1. $bq^2 = qb^2 \implies q = b$ (assuming $q, b \neq 0$).
2. $2bq(c-1) = 2qab + b \implies 2q^2(c-1) = 2q^2a + q \implies 2q(c-1) = 2qa + 1$.
3. $b(c-1)^2 + a = qa^2 + a + c \implies q(c-1)^2 = qa^2 + c$.

From (2), we have $a = c - 1 - \frac{1}{2q}$. Substituting this into (3):
\[ q(c-1)^2 = q\left(c - 1 - \frac{1}{2q}\right)^2 + c \]
\[ q(c-1)^2 = q\left((c-1)^2 - \frac{c-1}{q} + \frac{1}{4q^2}\right) + c \]
\[ q(c-1)^2 = q(c-1)^2 - (c-1) + \frac{1}{4q} + c \]
\[ 0 = -c + 1 + \frac{1}{4q} + c \implies 1 + \frac{1}{4q} = 0 \implies q = -\frac{1}{4} \]
Thus, for $n=2$, any $c \in \mathbb{R}$ works with $q = b = -1/4$ and $a = c + 1$.

For $n \ge 2024$, we repeat the matching process. The leading coefficients require $bq^n = qb^2 \implies b = q^{n-1}$. The right-hand side contains only terms $x^{2n}, x^n,$ and $x^0$. The left-hand side $b(qx^2 + c - 1)^n + a$ is a polynomial in $x^2$ and contains terms $x^{2n}, x^{2n-2}, \dots, x^0$. For the polynomials to be equal, the coefficients of all terms $x^{2k}$ where $2k \neq 2n$ and $2k \neq n$ must be zero.
Specifically, the coefficient of $x^{2n-2}$ is $b \binom{n}{n-1} q^{n-1} (c-1)$. For this to be zero (given $b, q \neq 0$), we must have $c = 1$.
When $c=1$, the left-hand side simplifies to $bq^n x^{2n} + a$. Now we match the remaining coefficients:
1. $x^{2n}$: $bq^n = qb^2 \implies b = q^{n-1}$.
2. $x^n$: The LHS has no $x^n$ term (since $n \ge 2024 > 0$), so the RHS coefficient must be zero: $2qab + b = 0 \implies b(2qa + 1) = 0 \implies a = -1/(2q)$.
3. Constant term: $a = qa^2 + a + c \implies qa^2 + 1 = 0$ (since $c=1$).

Substituting $a = -1/(2q)$ into $qa^2 + 1 = 0$:
\[ q\left(-\frac{1}{2q}\right)^2 + 1 = 0 \implies \frac{q}{4q^2} + 1 = 0 \implies \frac{1}{4q} + 1 = 0 \implies q = -\frac{1}{4} \]
Then $a = -1/(2 \cdot -1/4) = 2$ and $b = (-1/4)^{n-1}$.
For any $n \ge 2024$, the polynomials $Q(x) = -\frac{1}{4}x^2 + x + 1$ and $P(x) = (-\frac{1}{4})^{n-1}x^n + 2$ satisfy the condition.

\(\square\)
