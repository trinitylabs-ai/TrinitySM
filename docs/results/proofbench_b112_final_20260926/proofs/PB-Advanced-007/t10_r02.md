To prove that there exist real-coefficient polynomials $P(x)$ and $Q(x)$ such that $\deg P \ge 2024$, $\deg Q \ge 2$, and $P(Q(x)-x-1) = Q(P(x))$ for all real $x$, we consider polynomials of the following forms:
\[ P(x) = (x-h)^n + k, \quad Q(x) = x^2 + ax + b \]
where $n \ge 2024$. Substituting these into the given condition $P(Q(x)-x-1) = Q(P(x))$, we have:
\[ P(x^2 + ax + b - x - 1) = Q((x-h)^n + k) \]
\[ (x^2 + (a-1)x + b-1-h)^n + k = ((x-h)^n + k)^2 + a((x-h)^n + k) + b \]
Expanding the right-hand side:
\[ (x^2 + (a-1)x + b-1-h)^n + k = (x-h)^{2n} + 2k(x-h)^n + k^2 + a(x-h)^n + ak + b \]
\[ (x^2 + (a-1)x + b-1-h)^n + k = (x-h)^{2n} + (2k+a)(x-h)^n + k^2 + ak + b \]
To satisfy this equation for all $x$, we can set the base of the power on the left-hand side equal to the base of the power on the right-hand side:
\[ x^2 + (a-1)x + b-1-h = (x-h)^2 = x^2 - 2hx + h^2 \]
Comparing the coefficients of $x$ and the constant terms, we obtain:
1) $a-1 = -2h \implies a = 1-2h$
2) $b-1-h = h^2 \implies b = h^2+h+1$

With this substitution, the functional equation simplifies to:
\[ (x-h)^{2n} + k = (x-h)^{2n} + (2k+a)(x-h)^n + k^2 + ak + b \]
For this to hold for all $x$, the coefficients of $(x-h)^n$ and the constant terms must match:
3) $2k+a = 0 \implies k = -a/2$
4) $k = k^2 + ak + b$

Substituting $a = 1-2h$ into (3), we find $k = -(1-2h)/2 = h - 1/2$. Now we substitute $a=1-2h$, $b=h^2+h+1$, and $k=h-1/2$ into (4):
\[ h - \frac{1}{2} = \left(h - \frac{1}{2}\right)^2 + (1-2h)\left(h - \frac{1}{2}\right) + h^2+h+1 \]
Expanding the right-hand side:
\[ h - \frac{1}{2} = \left(h^2 - h + \frac{1}{4}\right) + \left(h - \frac{1}{2} - 2h^2 + h\right) + h^2+h+1 \]
\[ h - \frac{1}{2} = (h^2 - 2h^2 + h^2) + (-h + 2h + h) + \left(\frac{1}{4} - \frac{1}{2} + 1\right) \]
\[ h - \frac{1}{2} = 2h + \frac{3}{4} \]
Solving for $h$:
\[ h = -\frac{1}{2} - \frac{3}{4} = -\frac{5}{4} \]
Using $h = -5/4$, we determine the other parameters:
\[ a = 1 - 2\left(-\frac{5}{4}\right) = 1 + \frac{5}{2} = \frac{7}{2} \]
\[ b = \left(-\frac{5}{4}\right)^2 + \left(-\frac{5}{4}\right) + 1 = \frac{25}{16} - \frac{20}{16} + \frac{16}{16} = \frac{21}{16} \]
\[ k = -\frac{5}{4} - \frac{1}{2} = -\frac{7}{4} \]
We verify condition (4) with these values:
\[ k^2 + ak + b = \left(-\frac{7}{4}\right)^2 + \left(\frac{7}{2}\right)\left(-\frac{7}{4}\right) + \frac{21}{16} = \frac{49}{16} - \frac{49}{8} + \frac{21}{16} = \frac{49 - 98 + 21}{16} = -\frac{28}{16} = -\frac{7}{4} \]
Since $k = -7/4$, the condition is satisfied. Thus, for any $n \ge 2024$, the polynomials
\[ P(x) = \left(x + \frac{5}{4}\right)^n - \frac{7}{4} \quad \text{and} \quad Q(x) = x^2 + \frac{7}{2}x + \frac{21}{16} \]
satisfy the given condition. The degree of $P(x)$ is $n \ge 2024$ and the degree of $Q(x)$ is 2, fulfilling all requirements.
