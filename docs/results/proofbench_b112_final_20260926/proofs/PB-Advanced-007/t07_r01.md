To prove that there exist two real-coefficient polynomials $P(x)$ and $Q(x)$ satisfying the condition $P(Q(x)-x-1) = Q(P(x))$ with $\deg(P) \ge 2024$ and $\deg(Q) \ge 2$, we search for polynomials of a specific form.

Let $f(x) = Q(x) - x - 1$. The given condition is $P(f(x)) = Q(P(x))$.
We consider the case where $Q(x)$ is a quadratic polynomial, $Q(x) = x^2 + bx + c$. Then $f(x) = x^2 + (b-1)x + c - 1$.
We seek a solution where $P(x)$ is a polynomial of degree $n \ge 2024$. Let $P(x) = (x + \frac{b-1}{2})^n + a$ for some constant $a$.

To evaluate $P(f(x))$, we first compute $f(x) + \frac{b-1}{2}$:
\[ f(x) + \frac{b-1}{2} = x^2 + (b-1)x + c - 1 + \frac{b-1}{2} \]
Completing the square for the $x$ terms:
\[ f(x) + \frac{b-1}{2} = \left(x + \frac{b-1}{2}\right)^2 - \left(\frac{b-1}{2}\right)^2 + c - 1 + \frac{b-1}{2} \]
Let $K = c - 1 + \frac{b-1}{2} - \frac{(b-1)^2}{4}$. Then $f(x) + \frac{b-1}{2} = (x + \frac{b-1}{2})^2 + K$.
The expression for $P(f(x))$ becomes:
\[ P(f(x)) = \left(f(x) + \frac{b-1}{2}\right)^n + a = \left(\left(x + \frac{b-1}{2}\right)^2 + K\right)^n + a \]

Now we evaluate $Q(P(x))$:
\[ Q(P(x)) = P(x)^2 + bP(x) + c \]
Substituting $P(x) = (x + \frac{b-1}{2})^n + a$:
\[ Q(P(x)) = \left((x + \frac{b-1}{2})^n + a\right)^2 + b\left((x + \frac{b-1}{2})^n + a\right) + c \]
\[ Q(P(x)) = (x + \frac{b-1}{2})^{2n} + 2a(x + \frac{b-1}{2})^n + a^2 + b(x + \frac{b-1}{2})^n + ba + c \]
\[ Q(P(x)) = (x + \frac{b-1}{2})^{2n} + (2a + b)(x + \frac{b-1}{2})^n + a^2 + ba + c \]

For $P(f(x)) = Q(P(x))$ to hold for all $x$, we compare the two expressions. Let $u = x + \frac{b-1}{2}$:
\[ (u^2 + K)^n + a = u^{2n} + (2a + b)u^n + a^2 + ba + c \]
Expanding $(u^2 + K)^n$ using the binomial theorem:
\[ u^{2n} + nKu^{2n-2} + \binom{n}{2}K^2u^{2n-4} + \dots + K^n + a = u^{2n} + (2a + b)u^n + a^2 + ba + c \]
For $n \ge 2024$, the term $u^{2n-2}$ exists and its exponent $2n-2$ is strictly greater than $n$. Thus, to match the right side, we must have $K = 0$.
Substituting $K = 0$, the equation simplifies to:
\[ u^{2n} + a = u^{2n} + (2a + b)u^n + a^2 + ba + c \]
Matching the coefficients of $u^n$ and the constant terms:
1. $2a + b = 0 \implies a = -b/2$
2. $a = a^2 + ba + c$

We now use the condition $K = 0$:
\[ c - 1 + \frac{b-1}{2} - \frac{(b-1)^2}{4} = 0 \implies c = 1 - \frac{b-1}{2} + \frac{(b-1)^2}{4} \]
From the second coefficient match $a = a^2 + ba + c$, and substituting $a = -b/2$:
\[ -b/2 = (-b/2)^2 + b(-b/2) + c \implies -b/2 = \frac{b^2}{4} - \frac{b^2}{2} + c \implies c = \frac{b^2}{4} - \frac{b}{2} \]
Equating the two expressions for $c$:
\[ \frac{b^2}{4} - \frac{b}{2} = 1 - \frac{b-1}{2} + \frac{b^2 - 2b + 1}{4} \]
\[ \frac{b^2}{4} - \frac{b}{2} = 1 - \frac{b}{2} + \frac{1}{2} + \frac{b^2}{4} - \frac{b}{2} + \frac{1}{4} \]
\[ 0 = 1.75 - \frac{b}{2} \implies b = 3.5 \]
Using $b = 3.5$, we find:
\[ a = -3.5/2 = -1.75 \]
\[ c = \frac{(3.5)^2}{4} - \frac{3.5}{2} = \frac{12.25}{4} - 1.75 = 3.0625 - 1.75 = 1.3125 \]
The value of $\frac{b-1}{2}$ is $\frac{2.5}{2} = 1.25$.
Thus, for any $n \ge 2024$, the polynomials $P(x) = (x + 1.25)^n - 1.75$ and $Q(x) = x^2 + 3.5x + 1.3125$ satisfy the condition.

\(\square\)
