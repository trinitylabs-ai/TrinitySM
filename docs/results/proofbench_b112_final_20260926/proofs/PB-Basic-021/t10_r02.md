To prove that $x_{n-1}$ divides $x_n$ for all integers $n \ge 2$, we observe that $x_n = 2^{x_{n-1}} + 2$. Thus, the condition $x_{n-1} \mid x_n$ is equivalent to proving that $x_n \mid 2^{x_n} + 2$ for all $n \ge 1$.

Let $P(n)$ be the statement $x_n \mid 2^{x_n} + 2$ and $R(n)$ be the statement $x_n - 1 \mid 2^{x_n} + 1$. We will prove that both $P(n)$ and $R(n)$ are true for all $n \ge 1$ by induction.

**Base Case:**
For $n=1$, $x_1 = 6$.
$P(1): 6 \mid 2^6 + 2 = 66$. Since $66 = 6 \times 11$, $P(1)$ is true.
$R(1): x_1 - 1 = 5$ and $2^{x_1} + 1 = 2^6 + 1 = 65$. Since $65 = 5 \times 13$, $R(1)$ is true.

**Inductive Step:**
Assume $P(n)$ and $R(n)$ are true for some $n \ge 1$. We show that $P(n+1)$ and $R(n+1)$ are also true.

First, we prove $R(n) \implies P(n+1)$.
By definition, $x_{n+1} = 2^{x_n} + 2$. The statement $P(n+1)$ is $x_{n+1} \mid 2^{x_{n+1}} + 2$.
We can rewrite the terms as:
$x_{n+1} = 2(2^{x_n-1} + 1)$
$2^{x_{n+1}} + 2 = 2(2^{x_{n+1}-1} + 1) = 2(2^{2^{x_n} + 1} + 1)$
Thus, $P(n+1)$ is equivalent to $2^{x_n-1} + 1 \mid 2^{2^{x_n} + 1} + 1$.
We use the lemma that for any positive integers $k, m$, $2^k + 1 \mid 2^m + 1$ if and only if $m/k$ is an odd integer.
Here $k = x_n - 1$ and $m = 2^{x_n} + 1$. The condition for $P(n+1)$ to be true is that $\frac{2^{x_n} + 1}{x_n - 1}$ is an odd integer.
By the inductive hypothesis $R(n)$, we have $x_n - 1 \mid 2^{x_n} + 1$. Since $x_n$ is even for all $n \ge 1$ (as $x_1=6$ and $x_n=2^{x_{n-1}}+2$), both $x_n - 1$ and $2^{x_n} + 1$ are odd. Therefore, their quotient must also be odd. This proves $P(n+1)$.

Next, we prove $P(n) \implies R(n+1)$.
The statement $R(n+1)$ is $x_{n+1} - 1 \mid 2^{x_{n+1}} + 1$.
Substituting the definition of $x_{n+1}$, we have $x_{n+1} - 1 = 2^{x_n} + 1$.
Thus, $R(n+1)$ is $2^{x_n} + 1 \mid 2^{x_{n+1}} + 1$.
Using the same lemma, this holds if $x_{n+1}/x_n$ is an odd integer.
We have $x_{n+1}/x_n = (2^{x_n} + 2)/x_n$.
By the inductive hypothesis $P(n)$, we know $x_n \mid 2^{x_n} + 2$, so this quotient is an integer.
To check its parity, we look at the 2-adic valuation $v_2(x)$.
For $x_1=6$, $v_2(x_1) = 1$. For $n \ge 2$, $x_n = 2^{x_{n-1}} + 2 = 2(2^{x_{n-1}-1} + 1)$. Since $x_{n-1}-1 \ge 1$, the term $2^{x_{n-1}-1} + 1$ is odd, meaning $v_2(x_n) = 1$ for all $n \ge 1$.
Then $v_2(x_{n+1}/x_n) = v_2(x_{n+1}) - v_2(x_n) = 1 - 1 = 0$.
This implies that $x_{n+1}/x_n$ is an odd integer. This proves $R(n+1)$.

Since $P(1)$ and $R(1)$ are true, and $P(n) \implies R(n+1)$ and $R(n) \implies P(n+1)$, it follows by induction that $P(n)$ and $R(n)$ are true for all $n \ge 1$.
Specifically, $P(n-1)$ is true for all $n \ge 2$, meaning $x_{n-1} \mid 2^{x_{n-1}} + 2$.
Since $x_n = 2^{x_{n-1}} + 2$, we conclude that $x_{n-1} \mid x_n$ for all $n \ge 2$.

\(\square\)
