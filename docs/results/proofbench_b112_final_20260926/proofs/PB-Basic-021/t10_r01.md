To prove that $x_{n-1}$ divides $x_n$ for all integers $n \ge 2$, where $x_1 = 6$ and $x_n = 2^{x_{n-1}} + 2$, it is sufficient to prove that $x_n$ divides $2^{x_n} + 2$ for all integers $n \ge 1$.

We define two statements $P(n)$ and $S(n)$ for $n \ge 1$:
$P(n)$: The quotient $q_n = \frac{2^{x_n} + 2}{x_n}$ is an odd integer.
$S(n)$: The quotient $r_n = \frac{2^{x_n} + 1}{x_n - 1}$ is an odd integer.

**Base Cases:**
For $n=1$, we have $x_1 = 6$.
$2^{x_1} + 2 = 2^6 + 2 = 66$. Then $q_1 = \frac{66}{6} = 11$, which is an odd integer. Thus, $P(1)$ is true.
For $n=1$, $x_1 - 1 = 5$ and $2^{x_1} + 1 = 2^6 + 1 = 65$. Then $r_1 = \frac{65}{5} = 13$, which is an odd integer. Thus, $S(1)$ is true.

**Inductive Step:**
We prove that $P(n) \implies S(n+1)$ and $S(n) \implies P(n+1)$.

1.  **Proof that $P(n) \implies S(n+1)$:**
    Assume $P(n)$ is true. We want to show that $S(n+1)$ is true, i.e., $x_{n+1} - 1$ divides $2^{x_{n+1}} + 1$ and the quotient is odd.
    From the definition, $x_{n+1} - 1 = (2^{x_n} + 2) - 1 = 2^{x_n} + 1$.
    We need to show $2^{x_n} + 1 \mid 2^{x_{n+1}} + 1$. Let $M = 2^{x_n} + 1$. Then $2^{x_n} \equiv -1 \pmod{M}$.
    The expression $2^{x_{n+1}} + 1$ can be written as $2^{2^{x_n} + 2} + 1$.
    Since $P(n)$ is true, $2^{x_n} + 2 = q_n x_n$ where $q_n$ is an odd integer.
    Then $2^{x_{n+1}} = 2^{q_n x_n} = (2^{x_n})^{q_n}$.
    Substituting the congruence $2^{x_n} \equiv -1 \pmod{M}$:
    $2^{x_{n+1}} \equiv (-1)^{q_n} \pmod{M}$.
    Since $q_n$ is odd, $2^{x_{n+1}} \equiv -1 \pmod{M}$, so $M \mid 2^{x_{n+1}} + 1$.
    Because both $2^{x_{n+1}} + 1$ and $x_{n+1} - 1$ are odd, their quotient $r_{n+1}$ must be odd. Thus, $S(n+1)$ is true.

2.  **Proof that $S(n) \implies P(n+1)$:**
    Assume $S(n)$ is true. We want to show that $P(n+1)$ is true, i.e., $x_{n+1}$ divides $2^{x_{n+1}} + 2$ and the quotient is odd.
    $x_{n+1} = 2^{x_n} + 2$. Let $N = x_{n+1}$. We want to show $N \mid 2^N + 2$.
    $q_{n+1} = \frac{2^N + 2}{N} = \frac{2(2^{N-1} + 1)}{2(2^{x_n-1} + 1)} = \frac{2^{N-1} + 1}{2^{x_n-1} + 1}$.
    Let $L = 2^{x_n-1} + 1$. We need to show $L \mid 2^{N-1} + 1$.
    Note that $2^{x_n-1} \equiv -1 \pmod{L}$, which implies $2^{2(x_n-1)} \equiv 1 \pmod{L}$.
    The exponent is $N-1 = 2^{x_n} + 1$.
    Since $S(n)$ is true, $x_n - 1 \mid 2^{x_n} + 1$ and the quotient $r_n$ is odd.
    Thus, $N-1 = r_n(x_n - 1)$.
    $2^{N-1} = (2^{x_n-1})^{r_n} \equiv (-1)^{r_n} \pmod{L}$.
    Since $r_n$ is odd, $2^{N-1} \equiv -1 \pmod{L}$, so $L \mid 2^{N-1} + 1$.
    Because both $2^{N-1} + 1$ and $L$ are odd, the quotient $q_{n+1}$ must be odd. Thus, $P(n+1)$ is true.

**Conclusion:**
By induction, $P(n)$ and $S(n)$ are true for all $n \ge 1$. Since $P(n)$ is true, $x_n \mid 2^{x_n} + 2$ for all $n \ge 1$.
For any $n \ge 2$, we have $x_n = 2^{x_{n-1}} + 2$.
Since $P(n-1)$ is true, $x_{n-1} \mid 2^{x_{n-1}} + 2$.
Therefore, $x_{n-1} \mid x_n$ for all integers $n \ge 2$.

\(\square\)
