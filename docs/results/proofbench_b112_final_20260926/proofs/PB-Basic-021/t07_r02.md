To prove that $x_{n-1}$ divides $x_n$ for all integers $n \ge 2$, we examine the sequence defined by $x_1 = 6$ and $x_n = 2^{x_{n-1}} + 2$ for $n \ge 2$. The statement $x_{n-1} \mid x_n$ for $n \ge 2$ is equivalent to the statement $x_n \mid 2^{x_n} + 2$ for all $n \ge 1$.

We prove this by induction using two mutually reinforcing statements. Let $P(n)$ and $Q(n)$ be the following:
- $P(n)$: $x_n$ divides $2^{x_n} + 2$, and the quotient $q_n = \frac{2^{x_n} + 2}{x_n}$ is an odd integer.
- $Q(n)$: $x_n - 1$ divides $2^{x_n} + 1$, and the quotient $r_n = \frac{2^{x_n} + 1}{x_n - 1}$ is an odd integer.

**Base Cases:**
For $n=1$, $x_1 = 6$.
$P(1): \frac{2^6 + 2}{6} = \frac{66}{6} = 11$. Since 11 is an odd integer, $P(1)$ is true.
$Q(1): \frac{2^6 + 1}{6 - 1} = \frac{65}{5} = 13$. Since 13 is an odd integer, $Q(1)$ is true.

**Inductive Step:**
We utilize the following lemma: For positive integers $a$ and $b$, $2^a + 1$ divides $2^b + 1$ if and only if $b$ is an odd multiple of $a$.
*Proof of Lemma:* If $b = (2k+1)a$, then $2^b + 1 = (2^a)^{2k+1} + 1$. Since $m+1$ divides $m^n+1$ for odd $n$, $(2^a + 1)$ divides $(2^a)^{2k+1} + 1$. Conversely, if $2^a + 1 \mid 2^b + 1$, then $2^b \equiv -1 \pmod{2^a + 1}$. Since $2^a \equiv -1 \pmod{2^a + 1}$, let $b = qa + r$ where $0 \le r < a$. Then $2^b = (2^a)^q 2^r \equiv (-1)^q 2^r \equiv -1 \pmod{2^a + 1}$. If $q$ is even, $2^r \equiv -1 \pmod{2^a + 1}$, which is impossible as $2^r + 1 < 2^a + 1$. If $q$ is odd, $-2^r \equiv -1 \pmod{2^a + 1} \implies 2^r \equiv 1 \pmod{2^a + 1}$, which implies $r=0$. Thus $b = qa$ with $q$ odd.

1.  **Assume $P(n)$ is true.**
    We show $Q(n+1)$ is true. By definition, $x_{n+1} - 1 = (2^{x_n} + 2) - 1 = 2^{x_n} + 1$.
    We must check if $x_{n+1} - 1$ divides $2^{x_{n+1}} + 1 = 2^{2^{x_n} + 2} + 1$.
    Applying the lemma with $a = x_n$ and $b = 2^{x_n} + 2$, we see that $2^{x_n} + 1 \mid 2^{2^{x_n} + 2} + 1$ if and only if $2^{x_n} + 2$ is an odd multiple of $x_n$.
    From $P(n)$, $2^{x_n} + 2 = q_n x_n$ where $q_n$ is odd. Thus, $Q(n+1)$ is true. The quotient is odd because both $2^{x_{n+1}} + 1$ and $x_{n+1} - 1$ are odd.

2.  **Assume $Q(n)$ is true.**
    We show $P(n+1)$ is true. We need to prove $x_{n+1} \mid 2^{x_{n+1}} + 2$.
    $x_{n+1} \mid 2^{x_{n+1}} + 2 \iff \frac{x_{n+1}}{2} \mid \frac{2^{x_{n+1}} + 2}{2} \iff 2^{x_n-1} + 1 \mid 2^{2^{x_n} + 1} + 1$.
    Applying the lemma with $a = x_n - 1$ and $b = 2^{x_n} + 1$, this holds if and only if $2^{x_n} + 1$ is an odd multiple of $x_n - 1$.
    From $Q(n)$, $2^{x_n} + 1 = r_n(x_n - 1)$ where $r_n$ is odd. Thus, $P(n+1)$ is true.
    The quotient $q_{n+1} = \frac{2^{x_{n+1}} + 2}{x_{n+1}} = \frac{2(2^{2^{x_n} + 1} + 1)}{2(2^{x_n-1} + 1)} = \frac{2^{2^{x_n} + 1} + 1}{2^{x_n-1} + 1}$ is the quotient of two odd integers, hence it is odd.

Since $P(1)$ and $Q(1)$ are true, by induction, $P(n)$ is true for all $n \ge 1$. This implies $x_n \mid 2^{x_n} + 2$ for all $n \ge 1$. Since $x_{n+1} = 2^{x_n} + 2$, it follows that $x_n \mid x_{n+1}$ for all $n \ge 1$. Shifting the index, we have $x_{n-1} \mid x_n$ for all $n \ge 2$.

\(\square\)
