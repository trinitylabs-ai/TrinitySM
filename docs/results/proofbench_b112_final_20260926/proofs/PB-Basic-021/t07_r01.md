To prove that $x_{n-1}$ divides $x_n$ for all integers $n \ge 2$, where the sequence is defined by $x_1 = 6$ and $x_n = 2^{x_{n-1}} + 2$, we proceed by induction.

### 1. Preliminary Lemma
**Lemma:** For integers $a > 1$ and $n, m \ge 1$, $a^n + 1$ divides $a^m + 1$ if and only if $m$ is an odd multiple of $n$.

*Proof:* 
If $m = (2k+1)n$ for some integer $k \ge 0$, then $a^m + 1 = (a^n)^{2k+1} + 1$. Using the factorization $y^{2k+1} + 1 = (y+1)(y^{2k} - y^{2k-1} + \dots + 1)$ with $y = a^n$, we see that $a^n + 1$ divides $a^m + 1$.
Conversely, suppose $a^n + 1 \mid a^m + 1$. Let $m = qn + r$ where $0 \le r < n$. Then
$a^m + 1 = a^r(a^n)^q + 1 \equiv a^r(-1)^q + 1 \pmod{a^n + 1}$.
For this to be $0 \pmod{a^n + 1}$, we must have $(-1)^q a^r + 1 \equiv 0 \pmod{a^n + 1}$.
If $q$ is even, $a^r + 1 \equiv 0 \pmod{a^n + 1}$. Since $0 \le r < n$, we have $1 < a^r + 1 < a^n + 1$, so this is impossible.
If $q$ is odd, $-a^r + 1 \equiv 0 \pmod{a^n + 1}$. This requires $a^r = 1$, which implies $r = 0$.
Thus, $m = qn$ with $q$ odd. $\square$

### 2. Inductive Framework
We define two properties for $n \ge 1$:
- $P(n): x_n \mid 2^{x_n} + 2$
- $Q(n): x_n - 1 \mid 2^{x_n} + 1$

Note that $x_n = 2^{x_{n-1}} + 2$, so the goal $x_{n-1} \mid x_n$ for $n \ge 2$ is exactly the statement $P(n-1)$ for $n \ge 2$.

**Base Cases:**
- For $n=1$, $x_1 = 6$. $2^6 + 2 = 66$. Since $6 \mid 66$, $P(1)$ is true.
- For $n=1$, $x_1 - 1 = 5$. $2^6 + 1 = 65$. Since $5 \mid 65$, $Q(1)$ is true.

### 3. Inductive Steps
**Part A: $Q(n) \implies P(n+1)$**
Assume $Q(n)$ is true: $x_n - 1 \mid 2^{x_n} + 1$.
We want to show $P(n+1): x_{n+1} \mid 2^{x_{n+1}} + 2$.
Substituting $x_{n+1} = 2^{x_n} + 2$:
$P(n+1) \iff 2^{x_n} + 2 \mid 2^{2^{x_n} + 2} + 2 \iff 2(2^{x_n-1} + 1) \mid 2(2^{2^{x_n} + 1} + 1) \iff 2^{x_n-1} + 1 \mid 2^{2^{x_n} + 1} + 1$.
By the Lemma, this holds if and only if $2^{x_n} + 1$ is an odd multiple of $x_n - 1$.
Since both $2^{x_n} + 1$ and $x_n - 1$ are odd, any integer quotient between them must be odd. Thus, $2^{x_n} + 1$ is an odd multiple of $x_n - 1$ if and only if $x_n - 1 \mid 2^{x_n} + 1$, which is $Q(n)$.

**Part B: $P(n) \implies Q(n+1)$**
Assume $P(n)$ is true: $x_n \mid 2^{x_n} + 2$.
We want to show $Q(n+1): x_{n+1} - 1 \mid 2^{x_{n+1}} + 1$.
Substituting $x_{n+1} - 1 = 2^{x_n} + 1$:
$Q(n+1) \iff 2^{x_n} + 1 \mid 2^{2^{x_n} + 2} + 1$.
By the Lemma, this holds if and only if $2^{x_n} + 2$ is an odd multiple of $x_n$.
Let $2^{x_n} + 2 = q x_n$. Then $q = \frac{2(2^{x_n-1} + 1)}{x_n}$.
For $n=1$, $x_1/2 = 3$ (odd). For $n \ge 2$, $x_n/2 = 2^{x_{n-1}-1} + 1$, which is odd because $x_{n-1} \ge 6$.
Thus, $q = \frac{2^{x_n-1} + 1}{x_n/2}$ is a ratio of two odd numbers. Therefore, $q$ is odd whenever it is an integer.
The condition that $q$ is an integer is exactly $x_n \mid 2^{x_n} + 2$, which is $P(n)$.

### 4. Final Synthesis
We have $P(1)$ and $Q(1)$ as true. The implications $P(n) \implies Q(n+1)$ and $Q(n) \implies P(n+1)$ establish by induction that $P(n)$ is true for all $n \ge 1$.
Since $P(n-1)$ is the statement $x_{n-1} \mid 2^{x_{n-1}} + 2$ and $x_n = 2^{x_{n-1}} + 2$, it follows that $x_{n-1} \mid x_n$ for all $n \ge 2$.
