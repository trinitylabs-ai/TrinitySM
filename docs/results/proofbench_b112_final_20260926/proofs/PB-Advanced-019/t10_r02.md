To find all positive real numbers $r$ such that $n(n+1)r - B(n, r)$ is a multiple of $n$ for all positive integers $n$, where $A(r)$ is the fractional part of $2r$ and $B(n, r) = \sum_{k=1}^n A(kr)$, we begin by simplifying the given expression.

Let $S_n = n(n+1)r - B(n, r)$. By definition, $A(kr) = \{2kr\}$, where $\{x\} = x - \lfloor x \rfloor$ denotes the fractional part of $x$. Thus:
\[ S_n = n(n+1)r - \sum_{k=1}^n \{2kr\} = n(n+1)r - \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor) \]
\[ S_n = n(n+1)r - 2r \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor 2kr \rfloor = \sum_{k=1}^n \lfloor 2kr \rfloor \]
The condition is that $S_n = \sum_{k=1}^n \lfloor 2kr \rfloor$ must be a multiple of $n$ for all $n \in \mathbb{Z}^+$. Let $m_n = S_n/n$. We require $m_n \in \mathbb{Z}$ for all $n \ge 1$.

Let $2r = I + f$, where $I = \lfloor 2r \rfloor$ is an integer and $0 \le f < 1$. Then:
\[ S_n = \sum_{k=1}^n \lfloor k(I+f) \rfloor = \sum_{k=1}^n (kI + \lfloor kf \rfloor) = I \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor kf \rfloor \]
The condition $m_n \in \mathbb{Z}$ becomes:
\[ m_n = \frac{I(n+1)}{2} + \frac{1}{n} \sum_{k=1}^n \lfloor kf \rfloor \in \mathbb{Z} \quad \text{for all } n \ge 1. \]

Case 1: $I$ is even. Let $I = 2m$ for some integer $m$.
Then $m_n = m(n+1) + \frac{1}{n} \sum_{k=1}^n \lfloor kf \rfloor$. This requires $T_n = \sum_{k=1}^n \lfloor kf \rfloor$ to be a multiple of $n$ for all $n \ge 1$.
For $n=1$, $T_1 = \lfloor f \rfloor = 0$.
For $n=2$, $T_2 = \lfloor f \rfloor + \lfloor 2f \rfloor = \lfloor 2f \rfloor$. For $T_2$ to be a multiple of 2, since $0 \le 2f < 2$, we must have $\lfloor 2f \rfloor = 0$.
By induction, if $\lfloor kf \rfloor = 0$ for all $k < n$, then $T_n = \lfloor nf \rfloor$. For $T_n$ to be a multiple of $n$, we must have $\lfloor nf \rfloor = 0$ for all $n \ge 1$. This implies $nf < 1$ for all $n$, which is only possible if $f = 0$.
Thus, $2r = I = 2m$, so $r = m \in \mathbb{Z}^+$.

Case 2: $I$ is odd. Let $I = 2m + 1$ for some integer $m$.
Then $m_n = \frac{(2m+1)(n+1)}{2} + \frac{T_n}{n} = m(n+1) + \frac{n+1}{2} + \frac{T_n}{n}$.
This requires $C_n = \frac{n+1}{2} + \frac{T_n}{n} \in \mathbb{Z}$ for all $n \ge 1$.
From this, we have $T_n = n C_n - \frac{n(n+1)}{2}$.
Since $T_n - T_{n-1} = \lfloor nf \rfloor$, we have:
\[ \lfloor nf \rfloor = n C_n - \frac{n(n+1)}{2} - \left( (n-1) C_{n-1} - \frac{(n-1)n}{2} \right) = n C_n - (n-1) C_{n-1} - n \]
Since $0 \le f < 1$, we must have $0 \le \lfloor nf \rfloor \le n-1$. Thus:
\[ n \le n C_n - (n-1) C_{n-1} \le 2n-1 \]
For $n=1$, $C_1 = \frac{1+1}{2} + \frac{0}{1} = 1$.
For $n=2$, $2 \le 2 C_2 - 1 \le 3 \implies 3 \le 2 C_2 \le 4 \implies C_2 = 2$.
We proceed by induction to show $C_n = n$ for all $n \ge 1$. Assume $C_{n-1} = n-1$. Then:
\[ n \le n C_n - (n-1)^2 \le 2n-1 \]
\[ n + n^2 - 2n + 1 \le n C_n \le 2n-1 + n^2 - 2n + 1 \]
\[ n^2 - n + 1 \le n C_n \le n^2 \]
Dividing by $n$, we get $n - 1 + \frac{1}{n} \le C_n \le n$. Since $C_n$ is an integer, we must have $C_n = n$.
Substituting $C_n = n$ back into the expression for $\lfloor nf \rfloor$:
\[ \lfloor nf \rfloor = n(n) - (n-1)(n-1) - n = n^2 - (n^2 - 2n + 1) - n = n - 1 \]
This implies $n-1 \le nf < n$, which means $1 - \frac{1}{n} \le f < 1$ for all $n \ge 1$.
Taking the limit as $n \to \infty$, we find $f \ge 1$, which contradicts the assumption $f < 1$.
Thus, Case 2 yields no solutions.

The only solutions are positive integers $r$.

The positive real numbers $r$ are $r \in \{1, 2, 3, \dots\}$.

\(\square\)
