Let $\{y\} = y - \lfloor y \rfloor$ denote the fractional part of a real number $y$. The problem defines $A(r) = \{2r\}$. For a positive integer $n$, we have
$$B(n,r) = \sum_{k=1}^n A(kr) = \sum_{k=1}^n \{2kr\} = \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor).$$
We are given that $C(n,r) = n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$. Substituting the expression for $B(n,r)$:
$$C(n,r) = n(n+1)r - \left( 2r \sum_{k=1}^n k - \sum_{k=1}^n \lfloor 2kr \rfloor \right) = n(n+1)r - 2r \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor 2kr \rfloor = \sum_{k=1}^n \lfloor 2kr \rfloor.$$
The condition is that $S_n = \sum_{k=1}^n \lfloor 2kr \rfloor$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$. Let $x = 2r$. The condition is $S_n = \sum_{k=1}^n \lfloor kx \rfloor \equiv 0 \pmod n$.
Let $x = m + \alpha$, where $m = \lfloor x \rfloor$ is a non-negative integer and $0 \le \alpha < 1$. Then
$$S_n = \sum_{k=1}^n \lfloor k(m+\alpha) \rfloor = \sum_{k=1}^n (km + \lfloor k\alpha \rfloor) = m \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor k\alpha \rfloor.$$
For any odd integer $n$, $n+1$ is even, so $m \frac{n(n+1)}{2} = n \cdot \frac{m(n+1)}{2}$ is a multiple of $n$. Thus, for odd $n$, the condition $S_n \equiv 0 \pmod n$ reduces to
$$\sum_{k=1}^n \lfloor k\alpha \rfloor \equiv 0 \pmod n.$$
Let $a_n = \frac{1}{n} \sum_{k=1}^n \lfloor k\alpha \rfloor$. For all odd $n$, $a_n$ must be an integer. We examine the difference $a_{n+2} - a_n$ for odd $n$:
$$a_n = \frac{1}{n} \sum_{k=1}^n (k\alpha - \{k\alpha\}) = \alpha \frac{n+1}{2} - \frac{1}{n} \sum_{k=1}^n \{k\alpha\}.$$
Let $E_n = \frac{1}{n} \sum_{k=1}^n \{k\alpha\}$. Then $a_n = \alpha \frac{n+1}{2} - E_n$. The difference is
$$a_{n+2} - a_n = \left( \alpha \frac{n+3}{2} - E_{n+2} \right) - \left( \alpha \frac{n+1}{2} - E_n \right) = \alpha - (E_{n+2} - E_n).$$
We analyze $E_{n+2} - E_n$:
$$E_{n+2} - E_n = \frac{\sum_{k=1}^{n+2} \{k\alpha\}}{n+2} - \frac{\sum_{k=1}^n \{k\alpha\}}{n} = \frac{n \sum_{k=1}^{n+2} \{k\alpha\} - (n+2) \sum_{k=1}^n \{k\alpha\}}{n(n+2)} = \frac{n(\{ (n+1)\alpha \} + \{ (n+2)\alpha \}) - 2 \sum_{k=1}^n \{k\alpha\}}{n(n+2)}.$$
Since $0 \le \{y\} < 1$, the numerator is bounded:
$$|n(\{ (n+1)\alpha \} + \{ (n+2)\alpha \}) - 2 \sum_{k=1}^n \{k\alpha\}| < 2n + 2n = 4n.$$
Thus, $|E_{n+2} - E_n| < \frac{4n}{n(n+2)} = \frac{4}{n+2}$. As $n \to \infty$, $E_{n+2} - E_n \to 0$.
Since $a_n$ is an integer for all odd $n$, $a_{n+2} - a_n$ is an integer for all odd $n$. A sequence of integers that converges must be eventually constant. Therefore, $\lim_{n \to \infty} (a_{n+2} - a_n) = \alpha$ must be an integer. Given $0 \le \alpha < 1$, we must have $\alpha = 0$.

Consequently, $x = 2r = m$ is an integer. The original condition $S_n \equiv 0 \pmod n$ becomes
$$m \frac{n(n+1)}{2} \equiv 0 \pmod n \implies \frac{m(n+1)}{2} \in \mathbb{Z} \text{ for all } n \in \mathbb{Z}^+.$$
For $n=2$, we have $\frac{3m}{2} \in \mathbb{Z}$, which implies $m$ must be even. Let $m = 2k$ for some positive integer $k$ (since $r > 0$). Then $\frac{2k(n+1)}{2} = k(n+1)$, which is always an integer for any $n$.
Since $2r = m = 2k$, we have $r = k$. Thus, $r$ must be a positive integer.
Testing $r=k \in \mathbb{Z}^+$, we find $C(n,k) = \sum_{j=1}^n \lfloor 2jk \rfloor = 2k \frac{n(n+1)}{2} = kn(n+1)$, which is a multiple of $n$ for all $n$.

The positive real numbers $r$ are all positive integers.
