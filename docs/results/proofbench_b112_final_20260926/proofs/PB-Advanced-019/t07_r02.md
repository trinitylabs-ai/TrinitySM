To find all positive real numbers $r$ such that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$, we first analyze the definition of $B(n,r)$.

The fractional part of a real number $x$ is denoted by $\{x\} = x - \lfloor x \rfloor$. The problem defines $A(r) = \{2r\}$. Thus, for a positive integer $n$, we have:
$$B(n,r) = \sum_{k=1}^n A(kr) = \sum_{k=1}^n \{2kr\} = \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor)$$
Using the identity $\sum_{k=1}^n k = \frac{n(n+1)}{2}$, we can simplify $B(n,r)$:
$$B(n,r) = 2r \frac{n(n+1)}{2} - \sum_{k=1}^n \lfloor 2kr \rfloor = n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor$$
The condition given in the problem is that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$. Substituting the expression for $B(n,r)$, we get:
$$n(n+1)r - \left( n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor \right) = \sum_{k=1}^n \lfloor 2kr \rfloor$$
Let $S_n = \sum_{k=1}^n \lfloor 2kr \rfloor$. The condition is that $S_n \equiv 0 \pmod n$ for all $n \ge 1$.
Let $x = 2r$. We seek all $x > 0$ such that $\sum_{k=1}^n \lfloor kx \rfloor$ is a multiple of $n$ for all $n \ge 1$.

Case 1: $x$ is an integer.
If $x \in \mathbb{Z}^+$, then $\sum_{k=1}^n \lfloor kx \rfloor = \sum_{k=1}^n kx = x \frac{n(n+1)}{2}$.
For this to be a multiple of $n$, the value $\frac{x(n+1)}{2}$ must be an integer for all $n \ge 1$.
For $n=1$, $\frac{2x}{2} = x$ is an integer (which we assumed).
For $n=2$, $\frac{3x}{2}$ must be an integer, which implies $x$ must be even.
If $x = 2m$ for some $m \in \mathbb{Z}^+$, then $\frac{2m(n+1)}{2} = m(n+1)$, which is always an integer for all $n$.
Thus, $x$ must be an even integer, meaning $2r = 2m \implies r = m$ for some $m \in \mathbb{Z}^+$.

Case 2: $x$ is not an integer.
Let $x = I + f$, where $I = \lfloor x \rfloor$ and $0 < f < 1$. Then:
$$S_n = \sum_{k=1}^n \lfloor k(I+f) \rfloor = I \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor kf \rfloor$$
For any odd integer $n$, $I \frac{n(n+1)}{2} = n \cdot I \frac{n+1}{2}$, which is a multiple of $n$. Thus, we must have $T_n = \sum_{k=1}^n \lfloor kf \rfloor \equiv 0 \pmod n$ for all odd $n \ge 1$.
For $n=1$, $T_1 = \lfloor f \rfloor = 0$, which is always true for $0 < f < 1$.
For $n=3$, $T_3 = \lfloor 2f \rfloor + \lfloor 3f \rfloor \equiv 0 \pmod 3$. Since $0 \le \lfloor 2f \rfloor \le 1$ and $0 \le \lfloor 3f \rfloor \le 2$, the only possibilities are:
(i) $\lfloor 2f \rfloor = 0$ and $\lfloor 3f \rfloor = 0$, implying $f < 1/3$.
(ii) $\lfloor 2f \rfloor = 1$ and $\lfloor 3f \rfloor = 2$, implying $f \ge 2/3$.

Since $f < 1/3$, we have $0 \le \lfloor 4f \rfloor \le 1$ and $0 \le \lfloor 5f \rfloor \le 1$. Their sum is at most 2, so we must have $\lfloor 4f \rfloor = 0$ and $\lfloor 5f \rfloor = 0$, implying $f < 1/5$. By induction, $\lfloor nf \rfloor = 0$ for all odd $n$, which implies $f=0$, a contradiction.

In subcase (ii), if $f \ge 2/3$, then for $n=5$, $T_5 = 1 + 2 + \lfloor 4f \rfloor + \lfloor 5f \rfloor = 3 + \lfloor 4f \rfloor + \lfloor 5f \rfloor \equiv 0 \pmod 5$. Given $f \in [2/3, 1)$, $\lfloor 4f \rfloor \in \{2, 3\}$ and $\lfloor 5f \rfloor \in \{3, 4\}$. Thus, the only solutions are the positive integers $r$.

The positive real numbers $r$ are all positive integers $r \in \{1, 2, 3, \dots\}$.
