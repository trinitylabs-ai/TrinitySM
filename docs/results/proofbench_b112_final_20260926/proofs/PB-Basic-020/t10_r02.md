To find all pairs of primes $(a, b)$ such that $a^2 - ab - b^3 = 1$, we rearrange the equation as:
\[ a(a - b) = b^3 + 1 = (b + 1)(b^2 - b + 1) \]
Since $a$ is a prime number, $a$ must divide the product $(b + 1)(b^2 - b + 1)$. By Euclid's Lemma, $a$ must divide either $b + 1$ or $b^2 - b + 1$.

**Case 1: $a$ divides $b + 1$**
Let $b + 1 = na$ for some positive integer $n$. Substituting this into the factored equation:
\[ a(a - b) = na(b^2 - b + 1) \implies a - b = n(b^2 - b + 1) \implies a = n(b^2 - b + 1) + b \]
Substituting $a = \frac{b + 1}{n}$ into this expression:
\[ \frac{b + 1}{n} = n(b^2 - b + 1) + b \implies b + 1 = n^2b^2 - n^2b + n^2 + nb \]
Rearranging this into a quadratic in $b$:
\[ n^2b^2 + (n - n^2 - 1)b + (n^2 - 1) = 0 \]
For $b$ to be an integer, the discriminant $D_n$ must be a perfect square:
\[ D_n = (n - n^2 - 1)^2 - 4n^2(n^2 - 1) = (n^2 - n + 1)^2 - 4n^4 + 4n^2 \]
\[ D_n = (n^4 + n^2 + 1 - 2n^3 + 2n^2 - 2n) - 4n^4 + 4n^2 = -3n^4 - 2n^3 + 7n^2 - 2n + 1 \]
If $n = 1$, $D_1 = -3 - 2 + 7 - 2 + 1 = 1$. The values for $b$ are $b = \frac{-(1 - 1 - 1) \pm 1}{2(1)^2} = \frac{1 \pm 1}{2}$, so $b = 1$ or $b = 0$, neither of which is prime.
If $n = 2$, $D_2 = -3(16) - 2(8) + 7(4) - 2(2) + 1 = -48 - 16 + 28 - 4 + 1 = -39 < 0$.
For $n \ge 2$, let $f(n) = -3n^4 - 2n^3 + 7n^2 - 2n + 1$. Its derivative $f'(n) = -12n^3 - 6n^2 + 14n - 2 = -2(6n^3 + 3n^2 - 7n + 1)$. For $n \ge 1$, the term $g(n) = 6n^3 + 3n^2 - 7n + 1$ is positive since $g(1) = 3$ and $g'(n) = 18n^2 + 6n - 7 > 0$. Thus $f'(n) < 0$ for $n \ge 1$, and since $f(2) < 0$, we have $D_n < 0$ for all $n \ge 2$.
Thus, Case 1 yields no solutions.

**Case 2: $a$ divides $b^2 - b + 1$**
Let $b^2 - b + 1 = ma$ for some positive integer $m$. Substituting this into the factored equation:
\[ a(a - b) = (b + 1)ma \implies a - b = m(b + 1) \implies a = (m + 1)b + m \]
Now substitute this expression for $a$ back into $b^2 - b + 1 = ma$:
\[ b^2 - b + 1 = m((m + 1)b + m) = (m^2 + m)b + m^2 \]
\[ b^2 - (m^2 + m + 1)b + (1 - m^2) = 0 \]
For $b$ to be an integer, the discriminant $D_m$ must be a perfect square:
\[ D_m = (m^2 + m + 1)^2 - 4(1 - m^2) = m^4 + 2m^3 + 3m^2 + 2m + 1 - 4 + 4m^2 = m^4 + 2m^3 + 7m^2 + 2m - 3 \]
We bound $D_m$ between two consecutive squares for $m \ge 3$:
1. $(m^2 + m + 2)^2 = m^4 + 2m^3 + 5m^2 + 4m + 4$.
   $D_m - (m^2 + m + 2)^2 = 2m^2 - 2m - 7$. For $m \ge 3$, $2m^2 - 2m - 7 \ge 2(9) - 6 - 7 = 5 > 0$.
2. $(m^2 + m + 3)^2 = m^4 + 2m^3 + 7m^2 + 6m + 9$.
   $(m^2 + m + 3)^2 - D_m = 4m + 12$, which is clearly positive for $m \ge 1$.

Since $(m^2 + m + 2)^2 < D_m < (m^2 + m + 3)^2$ for $m \ge 3$, $D_m$ cannot be a perfect square for $m \ge 3$. We only need to check $m = 1$ and $m = 2$:
- If $m = 1$, $D_1 = 1 + 2 + 7 + 2 - 3 = 9 = 3^2$.
  Then $b = \frac{(1+1+1) \pm 3}{2} = \frac{3 \pm 3}{2}$, so $b = 3$ or $b = 0$.
  Since $b$ must be prime, $b = 3$. Then $a = (1+1)3 + 1 = 7$, which is prime.
- If $m = 2$, $D_2 = 16 + 16 + 28 + 4 - 3 = 61$, which is not a perfect square.

Checking the solution $(7, 3)$: $7^2 - 7(3) - 3^3 = 49 - 21 - 27 = 1$.

The only pair of primes $(a, b)$ that satisfies the equation is $(7, 3)$.
