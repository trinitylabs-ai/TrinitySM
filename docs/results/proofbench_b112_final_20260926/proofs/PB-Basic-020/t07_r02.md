To find all pairs of primes $(a, b)$ such that $a^2 - ab - b^3 = 1$, we rewrite the equation as:
\[a(a - b) = b^3 + 1 = (b + 1)(b^2 - b + 1)\]
Since $a$ is prime, $a$ must divide the product $(b + 1)(b^2 - b + 1)$. By Euclid's Lemma, $a$ must divide $b + 1$ or $a$ must divide $b^2 - b + 1$.

**Case 1: $a$ divides $b^2 - b + 1$**
Let $b^2 - b + 1 = ma$ for some integer $m$. Since $b$ is a prime, $b \ge 2$, so $b^2 - b + 1 > 0$. Since $a$ is a prime, $a > 0$, so $m$ must be a positive integer. Substituting $ma$ for $b^2 - b + 1$ in the original factored equation:
\[a(a - b) = (b + 1)ma\]
Dividing by $a$ (since $a \neq 0$):
\[a - b = m(b + 1) \implies a = (m + 1)b + m\]
Substitute this expression for $a$ back into $b^2 - b + 1 = ma$:
\[b^2 - b + 1 = m((m + 1)b + m) = (m^2 + m)b + m^2\]
Rearranging gives a quadratic equation in $b$:
\[b^2 - (m^2 + m + 1)b + (1 - m^2) = 0\]
The discriminant of this quadratic is:
\[D_m = (m^2 + m + 1)^2 - 4(1 - m^2) = m^4 + 2m^3 + 3m^2 + 2m + 1 - 4 + 4m^2 = m^4 + 2m^3 + 7m^2 + 2m - 3\]
We determine when $D_m$ is a perfect square for $m \in \mathbb{Z}^+$:
1. If $m = 1$, $D_1 = 1 + 2 + 7 + 2 - 3 = 9 = 3^2$. The solutions for $b$ are $b = \frac{3 \pm 3}{2}$, so $b = 3$ or $b = 0$. Since $b$ must be prime, $b = 3$. Then $a = (1 + 1)3 + 1 = 7$, which is prime. This gives the pair $(7, 3)$.
2. If $m = 2$, $D_2 = 16 + 16 + 28 + 4 - 3 = 61$, which is not a square.
3. If $m \ge 3$, we compare $D_m$ to $(m^2 + m + 2)^2$ and $(m^2 + m + 3)^2$:
   - $D_m - (m^2 + m + 2)^2 = (m^4 + 2m^3 + 7m^2 + 2m - 3) - (m^4 + 2m^3 + 5m^2 + 4m + 4) = 2m^2 - 2m - 7$. For $m \ge 3$, $2m^2 - 2m - 7 \ge 18 - 6 - 7 = 5 > 0$.
   - $(m^2 + m + 3)^2 - D_m = (m^4 + 2m^3 + 7m^2 + 6m + 9) - (m^4 + 2m^3 + 7m^2 + 2m - 3) = 4m + 12 > 0$.
   Thus, for $m \ge 3$, $D_m$ lies strictly between two consecutive squares and cannot be a square.

**Case 2: $a$ divides $b + 1$**
Let $b + 1 = na$ for some integer $n$. Since $a, b$ are primes, $n$ must be a positive integer. Substituting $na$ for $b + 1$ in the original factored equation:
\[a(a - b) = na(b^2 - b + 1)\]
Dividing by $a$:
\[a - b = n(b^2 - b + 1) \implies a = nb^2 - nb + n + b\]
Substitute $a = \frac{b + 1}{n}$ into this expression:
\[\frac{b + 1}{n} = nb^2 - nb + n + b \implies b + 1 = n^2b^2 - n^2b + n^2 + nb\]
Rearranging gives a quadratic equation in $b$:
\[n^2b^2 - (n^2 - n + 1)b + (n^2 - 1) = 0\]
The discriminant of this quadratic is:
\[D_n = (n^2 - n + 1)^2 - 4n^2(n^2 - 1) = (n^4 + n^2 + 1 - 2n^3 + 2n^2 - 2n) - 4n^4 + 4n^2 = -3n^4 - 2n^3 + 7n^2 - 2n + 1\]
For $b$ to be a real number, we require $D_n \ge 0$.
- If $n = 1$, $D_1 = -3 - 2 + 7 - 2 + 1 = 1 = 1^2$. The solutions for $b$ are $b = \frac{(1-1+1) \pm 1}{2(1)^2} = \frac{1 \pm 1}{2}$, so $b = 1$ or $b = 0$, neither of which is prime.
- If $n \ge 2$, we have $D_n = n^2(-3n^2 - 2n + 7) - 2n + 1$. For $n = 2$, $-3n^2 - 2n + 7 = -12 - 4 + 7 = -9$. For $n > 2$, this expression is even more negative. Thus $D_n < 0$ for all $n \ge 2$.

Therefore, Case 2 yields no solutions.

The only pair of primes is $(7, 3)$.
Verification: $7^2 - 7(3) - 3^3 = 49 - 21 - 27 = 1$.
