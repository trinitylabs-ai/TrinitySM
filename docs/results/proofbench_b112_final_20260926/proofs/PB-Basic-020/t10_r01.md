To find all pairs of primes $(a, b)$ such that $a^2 - ab - b^3 = 1$, we treat the equation as a quadratic in $a$:
\[ a^2 - ba - (b^3 + 1) = 0 \]
Applying the quadratic formula, we solve for $a$:
\[ a = \frac{b \pm \sqrt{b^2 + 4(b^3 + 1)}}{2} = \frac{b \pm \sqrt{4b^3 + b^2 + 4}}{2} \]
For $a$ to be an integer, the discriminant $D = 4b^3 + b^2 + 4$ must be a perfect square. Let $D = k^2$ for some integer $k \ge 0$.
Considering the equation $k^2 = 4b^3 + b^2 + 4$ modulo $b$, we have:
\[ k^2 \equiv 4 \pmod{b} \]
This implies $k \equiv 2 \pmod{b}$ or $k \equiv -2 \pmod{b}$. Thus, we can write $k = nb \pm 2$ for some integer $n$. Substituting this back into the equation for $k^2$:
\[ (nb \pm 2)^2 = 4b^3 + b^2 + 4 \]
\[ n^2b^2 \pm 4nb + 4 = 4b^3 + b^2 + 4 \]
\[ n^2b^2 \pm 4nb = 4b^3 + b^2 \]
Since $b$ is a prime, $b \neq 0$, so we divide by $b$:
\[ n^2b \pm 4n = 4b^2 + b \]
Rearranging the terms to isolate the multiple of $b$:
\[ b(n^2 - 4b - 1) = \mp 4n \]
This equation implies that $b$ must divide $4n$. Since $b$ is prime, this means either $b=2$ or $b$ divides $n$.

**Case 1: $b = 2$**
Substituting $b=2$ into the discriminant $D$:
\[ D = 4(2^3) + 2^2 + 4 = 32 + 4 + 4 = 40 \]
Since 40 is not a perfect square, there are no solutions for $b=2$.

**Case 2: $b$ divides $n$**
Let $n = mb$ for some integer $m$. Substituting this into $n^2b \pm 4n = 4b^2 + b$:
\[ (mb)^2b \pm 4(mb) = 4b^2 + b \]
\[ m^2b^3 \pm 4mb = 4b^2 + b \]
Dividing by $b$:
\[ m^2b^2 \pm 4m = 4b + 1 \]
We analyze the two possible signs:

Subcase 2.1: $m^2b^2 + 4m = 4b + 1$
Rearranging as a quadratic in $b$: $m^2b^2 - 4b + (4m - 1) = 0$.
Solving for $b$:
\[ b = \frac{4 \pm \sqrt{16 - 4m^2(4m - 1)}}{2m^2} = \frac{2 \pm \sqrt{4 - 4m^3 + m^2}}{m^2} \]
For $b$ to be a real number, we require $4 - 4m^3 + m^2 \ge 0$.
If $m=1$, $b = \frac{2 \pm \sqrt{1}}{1} \in \{3, 1\}$. Since $b$ is prime, $b=3$ is a candidate.
If $m \ge 2$, then $4m^3 - m^2 - 4 \ge 32 - 4 - 4 = 24 > 0$, so the discriminant is negative.
If $m=0$, the equation $m^2b^2 + 4m = 4b + 1$ becomes $0 = 4b + 1$, which has no prime solutions.
If $m < 0$, let $m = -p$ for $p > 0$. The equation $m^2b^2 + 4m = 4b + 1$ becomes $p^2b^2 - 4p = 4b + 1$, which is the case analyzed in Subcase 2.2.

Subcase 2.2: $m^2b^2 - 4m = 4b + 1$
Rearranging as a quadratic in $b$: $m^2b^2 - 4b - (4m + 1) = 0$.
Solving for $b$:
\[ b = \frac{4 \pm \sqrt{16 + 4m^2(4m + 1)}}{2m^2} = \frac{2 \pm \sqrt{4 + 4m^3 + m^2}}{m^2} \]
If $m=1$, $b = \frac{2 \pm \sqrt{9}}{1} \in \{5, -1\}$. Since $b$ is prime, $b=5$ is a candidate.
If $m=2$, $b = \frac{2 \pm \sqrt{40}}{4}$, which is not an integer.
If $m \ge 3$, we check if $b \ge 2$. For $b = \frac{2 + \sqrt{4m^3 + m^2 + 4}}{m^2} \ge 2$, we need:
\[ \sqrt{4m^3 + m^2 + 4} \ge 2m^2 - 2 \implies 4m^3 + m^2 + 4 \ge 4m^4 - 8m^2 + 4 \implies 4m^4 - 4m^3 - 9m^2 \le 0 \]
Dividing by $m^2$, we get $4m^2 - 4m - 9 \le 0$. The roots of $4m^2 - 4m - 9 = 0$ are $m = \frac{4 \pm \sqrt{160}}{8} = \frac{1 \pm \sqrt{10}}{2}$. Since $\sqrt{10} \approx 3.16$, the inequality holds for $m \le \frac{1 + 3.16}{2} \approx 2.08$. Thus, for $m \ge 3$, $b < 2$, so no prime solutions exist.
If $m=0$, the equation $m^2b^2 - 4m = 4b + 1$ becomes $0 = 4b + 1$, which has no prime solutions.
If $m < 0$, let $m = -p$ for $p > 0$. The equation $m^2b^2 - 4m = 4b + 1$ becomes $p^2b^2 + 4p = 4b + 1$, which is the case analyzed in Subcase 2.1.

**Testing the candidates $b=3$ and $b=5$:**
- For $b=3$:
  $a^2 - 3a - 3^3 = 1 \implies a^2 - 3a - 28 = 0 \implies (a-7)(a+4) = 0$.
  Since $a$ must be prime, $a=7$. The pair $(7, 3)$ is a solution.
- For $b=5$:
  $a^2 - 5a - 5^3 = 1 \implies a^2 - 5a - 126 = 0 \implies (a-14)(a+9) = 0$.
  Neither $14$ nor $-9$ is prime.

Thus, the only pair of primes $(a, b)$ that satisfies the equation is $(7, 3)$.
