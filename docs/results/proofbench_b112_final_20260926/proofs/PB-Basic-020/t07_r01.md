To find all pairs of primes $(a, b)$ such that $a^2 - ab - b^3 = 1$, we begin by rearranging the equation to isolate the terms involving $a$:
\[ a^2 - ab = b^3 + 1 \]
Factoring the right side as a sum of cubes, we have:
\[ a(a - b) = (b+1)(b^2 - b + 1) \]
Alternatively, we can rearrange the original equation as:
\[ a^2 - 1 = b^3 + ab \]
Factoring the left side and the right side:
\[ (a-1)(a+1) = b(b^2 + a) \]
Since $b$ is a prime number, by Euclid's Lemma, $b$ must divide at least one of the factors on the left side. This implies that $b \mid (a-1)$ or $b \mid (a+1)$. We analyze these two cases separately.

**Case 1: $b \mid (a-1)$**
Let $a-1 = nb$ for some integer $n \ge 1$. Then $a = nb + 1$. Substituting this into the original equation:
\[ (nb+1)^2 - (nb+1)b - b^3 = 1 \]
\[ n^2b^2 + 2nb + 1 - nb^2 - b - b^3 = 1 \]
\[ -b^3 + (n^2-n)b^2 + (2n-1)b = 0 \]
Since $b$ is a prime, $b \neq 0$, so we divide by $b$:
\[ -b^2 + (n^2-n)b + (2n-1) = 0 \implies b^2 + (n-n^2)b + (1-2n) = 0 \]
Using the quadratic formula to solve for $b$:
\[ b = \frac{(n^2-n) \pm \sqrt{(n-n^2)^2 - 4(1-2n)}}{2} = \frac{n^2-n \pm \sqrt{n^4 - 2n^3 + n^2 + 8n - 4}}{2} \]
For $b$ to be an integer, the discriminant $m^2 = n^4 - 2n^3 + n^2 + 8n - 4$ must be a perfect square.
- If $n=1$, $m^2 = 1-2+1+8-4 = 4 = 2^2$. Then $b = \frac{0 \pm 2}{2} = \pm 1$, which is not prime.
- If $n=2$, $m^2 = 16-16+4+16-4 = 16 = 4^2$. Then $b = \frac{2 \pm 4}{2}$, giving $b=3$ or $b=-1$. For $b=3$, we have $a = 2(3)+1 = 7$. Since both $a=7$ and $b=3$ are prime, $(7, 3)$ is a solution.
- If $n=3$, $m^2 = 81-54+9+24-4 = 56$, not a square.
- If $n=4$, $m^2 = 256-128+16+32-4 = 172$, not a square.
- If $n \ge 5$, we observe that $(n^2-n)^2 = n^4 - 2n^3 + n^2 < m^2$. Also, $(n^2-n+1)^2 = n^4 - 2n^3 + 3n^2 - 2n + 1$. The difference $(n^2-n+1)^2 - m^2 = 2n^2 - 10n + 5$ is positive for $n \ge 5$. Thus, $(n^2-n)^2 < m^2 < (n^2-n+1)^2$, meaning $m^2$ cannot be a perfect square.

**Case 2: $b \mid (a+1)$**
Let $a+1 = nb$ for some integer $n \ge 1$. Then $a = nb - 1$. Substituting this into the original equation:
\[ (nb-1)^2 - (nb-1)b - b^3 = 1 \]
\[ n^2b^2 - 2nb + 1 - nb^2 + b - b^3 = 1 \]
\[ -b^3 + (n^2-n)b^2 + (1-2n)b = 0 \]
Dividing by $b$:
\[ -b^2 + (n^2-n)b + (1-2n) = 0 \implies b^2 + (n-n^2)b + (2n-1) = 0 \]
Solving for $b$:
\[ b = \frac{(n^2-n) \pm \sqrt{(n-n^2)^2 - 4(2n-1)}}{2} = \frac{n^2-n \pm \sqrt{n^4 - 2n^3 + n^2 - 8n + 4}}{2} \]
Let $m^2 = n^4 - 2n^3 + n^2 - 8n + 4$.
- If $n=1$, $m^2 = 1-2+1-8+4 = -4$.
- If $n=2$, $m^2 = 16-16+4-16+4 = -8$.
- If $n=3$, $m^2 = 81-54+9-24+4 = 16 = 4^2$. Then $b = \frac{6 \pm 4}{2}$, giving $b=5$ or $b=1$. For $b=5$, we have $a = 3(5)-1 = 14$, which is not prime.
- If $n=4$, $m^2 = 256-128+16-32+4 = 116$, not a square.
- If $n \ge 5$, we observe that $m^2 < (n^2-n)^2$ because $m^2 - (n^2-n)^2 = -8n+4 < 0$. Also, $(n^2-n-1)^2 = n^4 - 2n^3 - n^2 + 2n + 1$. The difference $m^2 - (n^2-n-1)^2 = 2n^2 - 10n + 3$ is positive for $n \ge 5$. Thus, $(n^2-n-1)^2 < m^2 < (n^2-n)^2$, meaning $m^2$ cannot be a perfect square.

Checking the solution $(7, 3)$: $7^2 - 7(3) - 3^3 = 49 - 21 - 27 = 1$. This is correct.

The only pair of primes $(a, b)$ that satisfies the equation is $(7, 3)$.

\(\square\)
