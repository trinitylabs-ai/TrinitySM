To determine all positive integers $k$ such that $S_n(k) = \frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^{k}$ is an integer for every positive integer $n$, we analyze the condition that $m = n+1$ must divide the sum $S(m) = \sum_{i=0}^{m-1} \binom{m-1}{i}^{k}$ for all $m \ge 2$.

**1. Necessary Condition for $k$**
Consider the case $n=2$, so $m=3$. The sum is:
\[ S(3) = \sum_{i=0}^{2} \binom{2}{i}^k = \binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2^k + 2 \]
For $S_2(k)$ to be an integer, we require $3 \mid (2^k + 2)$, which means $2^k \equiv -2 \equiv 1 \pmod{3}$.
The powers of $2$ modulo $3$ are $2^1 \equiv 2 \pmod{3}$ and $2^2 \equiv 1 \pmod{3}$, alternating with parity. Thus, $2^k \equiv 1 \pmod{3}$ if and only if $k$ is even. Therefore, $k$ must be an even positive integer.

**2. Sufficient Condition for Even $k$**
Let $k$ be any even positive integer. We wish to show that $m \mid S(m)$ for all $m \ge 2$. By the Chinese Remainder Theorem, it suffices to prove that for any prime power $p^e$ dividing $m$, we have $S(m) \equiv 0 \pmod{p^e}$.
Let $m = N p^e$ for some positive integer $N$. We examine $S(m) \pmod{p^e}$.

**Lemma:** For any $0 \le i < m$, $\binom{m-1}{i} \equiv (-1)^{i - \lfloor i/p \rfloor} \binom{N p^{e-1} - 1}{\lfloor i/p \rfloor} \pmod{p^e}$.
*Proof:* The binomial coefficient is given by $\binom{m-1}{i} = \prod_{j=1}^i \frac{m-j}{j}$. We partition the product into indices $j$ where $p \nmid j$ and indices $j$ where $p \mid j$.
For $p \nmid j$, the term $\frac{m-j}{j} = \frac{m}{j} - 1$. Since $m = N p^e$, we have $\frac{m}{j} \equiv 0 \pmod{p^e}$ because $j$ is invertible modulo $p^e$. Thus, $\frac{m-j}{j} \equiv -1 \pmod{p^e}$. There are exactly $i - \lfloor i/p \rfloor$ such terms in the product.
For $j = pv$, the product over these indices is:
\[ \prod_{v=1}^{\lfloor i/p \rfloor} \frac{m-pv}{pv} = \prod_{v=1}^{\lfloor i/p \rfloor} \frac{N p^e - pv}{pv} = \prod_{v=1}^{\lfloor i/p \rfloor} \frac{N p^{e-1} - v}{v} = \binom{N p^{e-1} - 1}{\lfloor i/p \rfloor} \]
Combining these, we obtain $\binom{m-1}{i} \equiv (-1)^{i - \lfloor i/p \rfloor} \binom{N p^{e-1} - 1}{\lfloor i/p \rfloor} \pmod{p^e}$. $\square$

Using this lemma, we substitute into the sum $S(m)$:
\[ S(m) = \sum_{i=0}^{m-1} \binom{m-1}{i}^k \equiv \sum_{i=0}^{m-1} \left( (-1)^{i - \lfloor i/p \rfloor} \binom{N p^{e-1} - 1}{\lfloor i/p \rfloor} \right)^k \pmod{p^e} \]
Since $k$ is even, $(-1)^{k(i - \lfloor i/p \rfloor)} = 1$. Thus:
\[ S(m) \equiv \sum_{i=0}^{m-1} \binom{N p^{e-1} - 1}{\lfloor i/p \rfloor}^k \pmod{p^e} \]
As $i$ ranges from $0$ to $m-1 = N p^e - 1$, the value $j = \lfloor i/p \rfloor$ takes each integer from $0$ to $N p^{e-1} - 1$ exactly $p$ times. Therefore:
\[ S(m) \equiv p \sum_{j=0}^{N p^{e-1} - 1} \binom{N p^{e-1} - 1}{j}^k = p S(N p^{e-1}) \pmod{p^e} \]

We now prove $p^e \mid S(N p^e)$ by induction on $e$ for a fixed $N$:
- Base case $e=1$: $S(N p) \equiv p S(N) \equiv 0 \pmod{p}$, which is true since $S(N)$ is an integer.
- Inductive step: Assume $p^{e-1} \mid S(N p^{e-1})$. Then $S(N p^{e-1}) = A p^{e-1}$ for some integer $A$. From our recurrence, $S(N p^e) \equiv p (A p^{e-1}) = A p^e \equiv 0 \pmod{p^e}$.

Thus, $S(m)$ is divisible by $p^e$ for every prime power dividing $m$, implying $m \mid S(m)$ for all $m \ge 2$ when $k$ is even.

The positive integers $k$ such that $\frac{1}{n+1}\sum_{i=0}^{n}\binom{n}{i}^{k}$ is an integer for every positive integer $n$ are all even positive integers.
