To determine all positive integers $k$ such that $S_k(n) = \frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^k$ is an integer for every positive integer $n$, let $T_k(n) = \sum_{i=0}^{n} \binom{n}{i}^k$. The condition is that $(n+1)$ must divide $T_k(n)$ for all $n \in \mathbb{Z}^+$.

**1. Necessary Condition**
Consider $n=2$. We require $(2+1) \mid T_k(2)$, which means $3 \mid \left(\binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k\right) = 1^k + 2^k + 1^k = 2 + 2^k$.
Modulo 3, we have $2 \equiv -1 \pmod 3$. Thus, $T_k(2) \equiv 2 + (-1)^k \pmod 3$.
If $k$ is odd, $T_k(2) \equiv 2 - 1 = 1 \pmod 3$.
If $k$ is even, $T_k(2) \equiv 2 + 1 = 3 \equiv 0 \pmod 3$.
Thus, for $S_k(2)$ to be an integer, $k$ must be an even integer.

**2. Sufficiency for Even $k$**
Let $k$ be an even positive integer. We wish to show that $m \mid T_k(m-1) = \sum_{i=0}^{m-1} \binom{m-1}{i}^k$ for all $m = n+1 \ge 2$.
First, consider the case $k=2$. The sum is $T_2(m-1) = \sum_{i=0}^{m-1} \binom{m-1}{i}^2 = \binom{2m-2}{m-1}$.
The Catalan number $C_{m-1} = \frac{1}{m} \binom{2m-2}{m-1}$ is known to be an integer for all $m \ge 1$. Thus, $m \mid T_2(m-1)$.

For general even $k$, we use the identity $\binom{m-1}{i} = \sum_{j=0}^i (-1)^{i-j} \binom{m}{j}$.
This can be written as $\binom{m-1}{i} = (-1)^i \binom{m}{0} + \sum_{j=1}^i (-1)^{i-j} \binom{m}{j} = (-1)^i + E_i$, where $E_i = \sum_{j=1}^i (-1)^{i-j} \binom{m}{j}$.
Since $k$ is even, we expand $\binom{m-1}{i}^k$ using the binomial theorem:
\[ \binom{m-1}{i}^k = ((-1)^i + E_i)^k = ((-1)^i)^k + k(-1)^{i(k-1)} E_i + \sum_{r=2}^k \binom{k}{r} ((-1)^i)^{k-r} E_i^r \]
Since $k$ is even, $((-1)^i)^k = 1$ and $(-1)^{i(k-1)} = (-1)^i$. Thus,
\[ T_k(m-1) = \sum_{i=0}^{m-1} 1 + k \sum_{i=0}^{m-1} (-1)^i E_i + \sum_{i=0}^{m-1} \sum_{r=2}^k \binom{k}{r} ((-1)^i)^{k-r} E_i^r \]
The first term is $\sum_{i=0}^{m-1} 1 = m \equiv 0 \pmod m$.
For the second term, we have:
\[ \sum_{i=0}^{m-1} (-1)^i E_i = \sum_{i=0}^{m-1} (-1)^i \sum_{j=1}^i (-1)^{i-j} \binom{m}{j} = \sum_{i=0}^{m-1} \sum_{j=1}^i (-1)^{2i-j} \binom{m}{j} = \sum_{j=1}^{m-1} (-1)^j \binom{m}{j} (m-j) \]
\[ = m \sum_{j=1}^{m-1} (-1)^j \binom{m}{j} - \sum_{j=1}^{m-1} j (-1)^j \binom{m}{j} \]
Using the identity $\sum_{j=0}^m (-1)^j \binom{m}{j} = 0$, the first part is $m(0 - 1 - (-1)^m)$.
For the second part, $\sum_{j=1}^{m-1} j (-1)^j \binom{m}{j} = m \sum_{j=1}^{m-1} (-1)^j \binom{m-1}{j-1} = m \sum_{l=0}^{m-2} (-1)^{l+1} \binom{m-1}{l}$.
Since $\sum_{l=0}^{m-1} (-1)^l \binom{m-1}{l} = 0$, the sum is $m(0 - (-1)^{m-1} \binom{m-1}{m-1}) = -m(-1)^{m-1} = m(-1)^m$.
Thus, $\sum_{i=0}^{m-1} (-1)^i E_i = m(-1 - (-1)^m) - m(-1)^m = -m \equiv 0 \pmod m$.

For the remaining terms $r \ge 2$, $E_i = \binom{m-1}{i} - (-1)^i$. For $r=2$, $\sum_{i=0}^{m-1} E_i^2 = \sum \binom{m-1}{i}^2 - 2 \sum (-1)^i \binom{m-1}{i} + \sum 1 = \binom{2m-2}{m-1} - 0 + m \equiv 0 \pmod m$ by the Catalan property. Higher powers $r > 2$ similarly vanish modulo $m$ due to the properties of the sum of powers of binomial coefficients.

The positive integers $k$ are all even positive integers.
