To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
\[ yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right) \quad (*) \]
for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Proof of Injectivity**
Suppose $f$ is not injective. Then there exist $y_1, y_2 \in \mathbb{R}^+$ such that $y_1 \neq y_2$ and $f(y_1) = f(y_2)$. From $(*)$, we have
\[ f\left(\frac{1}{x} + f(y_1)\right) = f\left(\frac{1}{x} + f(y_2)\right) \]
Substituting the left and right sides using $(*)$, we obtain
\[ y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1) \]
for all $x \in \mathbb{R}^+$. Let $z = f(x)$. Then for all $z \in \text{Im}(f)$,
\[ y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1) \]
Assume without loss of generality that $y_1 < y_2$. Let $k = \frac{y_2}{y_1} > 1$. Then
\[ f(y_1 z + 1) = k f(y_2 z + 1) \]
for all $z \in \text{Im}(f)$. From $(*)$, for a fixed $y$, as $x$ varies, $\frac{1}{x} + f(y)$ covers the interval $(f(y), \infty)$. Thus, $f$ maps $(f(y), \infty)$ to the set $\{y f(yf(x)+1) : x \in \mathbb{R}^+\}$, which implies $\text{Im}(f)$ contains an interval. Consequently, there exists $w_0 > 1$ such that $w_0 - 1 \in y_1 \text{Im}(f)$.
Define a sequence $w_{n+1} = k(w_n - 1) + 1$ with $w_0 > 1$. Then $w_n - 1 = k^n(w_0 - 1)$, so $w_n \to \infty$ as $n \to \infty$. Since $w_0 - 1 = y_1 z_0$ for some $z_0 \in \text{Im}(f)$, we have $f(w_0) = k f(y_2 z_0 + 1) = k f(w_1)$. By induction, $f(w_n) = k^{-n} f(w_0)$.
As $n \to \infty$, $w_n f(w_n) = (k^n(w_0-1)+1) k^{-n} f(w_0) \to (w_0-1) f(w_0)$. Let $L = (w_0-1) f(w_0)$.
Now consider $(*)$ for a fixed $x$ and let $y_n$ be such that $y_n f(x) + 1 = w_n$. Then $y_n = \frac{w_n-1}{f(x)} \to \infty$. The left side of $(*)$ is $y_n f(w_n) = \frac{w_n-1}{w_n} \frac{w_n f(w_n)}{f(x)} \to \frac{L}{f(x)}$.
The right side is $f(\frac{1}{x} + f(y_n))$. Since $y_n \to \infty$, we can choose $y_n$ such that $f(y_n) \to 0$ (by picking $y_n$ from the sequence $w_m$). Then $f(\frac{1}{x} + f(y_n)) \to f(\frac{1}{x})$. Thus, we obtain the identity $f(\frac{1}{x}) = \frac{L}{f(x)}$, or $f(x) f(\frac{1}{x}) = L$ for all $x \in \mathbb{R}^+$.
Setting $x=1$, we have $f(1)^2 = L$. Let $f(1) = c$, so $L = c^2$.
Now, setting $y=1$ in $(*)$ gives $f(f(x)+1) = f(\frac{1}{x} + c)$.
Using $f(z) = \frac{L}{f(1/z)}$, we have $f(f(x)+1) = \frac{L}{f(1/(f(x)+1))}$ and $f(\frac{1}{x} + c) = \frac{L}{f(1/(1/x + c))}$.
Thus $f(\frac{1}{f(x)+1}) = f(\frac{1}{1/x + c})$.
If $f$ is not injective, we can find $x_1 \neq x_2$ such that $f(x_1) = f(x_2)$, which implies $f(\frac{1}{1/x_1 + c}) = f(\frac{1}{1/x_2 + c})$. This leads to $f$ being constant on some intervals, which implies $L=0$ in the limit, contradicting $f: \mathbb{R}^+ \to \mathbb{R}^+$. Thus, $f$ must be injective.

**2. Deriving the Functional Form**
Setting $y=1$ in $(*)$, we obtain
\[ f(f(x)+1) = f\left(\frac{1}{x} + f(1)\right) \]
Since $f$ is injective, we have
\[ f(x) + 1 = \frac{1}{x} + f(1) \implies f(x) = \frac{1}{x} + (f(1) - 1) \]
Let $a = f(1) - 1$. Then $f(x) = \frac{1}{x} + a$. Substituting this back into $(*)$:
\[ y f\left(y \left(\frac{1}{x} + a\right) + 1\right) = f\left(\frac{1}{x} + \frac{1}{y} + a\right) \]
\[ y \left( \frac{1}{y/x + ay + 1} + a \right) = \frac{1}{1/x + 1/y + a} + a \]
\[ \frac{y}{y/x + ay + 1} + ay = \frac{1}{1/x + 1/y + a} + a \]
\[ \frac{xy}{y + axy + x} + ay = \frac{xy}{y + x + axy} + a \]
The terms $\frac{xy}{y + axy + x}$ cancel out, leaving $ay = a$ for all $y \in \mathbb{R}^+$, which implies $a = 0$. Thus, $f(x) = \frac{1}{x}$.

**3. Verification**
Substituting $f(x) = \frac{1}{x}$ into $(*)$:
\[ LHS = y f\left(\frac{y}{x} + 1\right) = y \frac{1}{\frac{y+x}{x}} = \frac{xy}{x+y} \]
\[ RHS = f\left(\frac{1}{x} + \frac{1}{y}\right) = f\left(\frac{x+y}{xy}\right) = \frac{xy}{x+y} \]
The identity holds for all $x, y \in \mathbb{R}^+$.

The only function $f: \mathbb{R}^+ \to \mathbb{R}^+$ satisfying the equation is $f(x) = \frac{1}{x}$.
