To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Verification of $f(x) = \frac{1}{x}$**
Substituting $f(x) = \frac{1}{x}$ into the original equation:
$$\text{LHS} = y f\left(\frac{y}{x} + 1\right) = y \left(\frac{1}{\frac{y}{x} + 1}\right) = y \left(\frac{x}{y+x}\right) = \frac{xy}{x+y}$$
$$\text{RHS} = f\left(\frac{1}{x} + \frac{1}{y}\right) = \frac{1}{\frac{1}{x} + \frac{1}{y}} = \frac{1}{\frac{x+y}{xy}} = \frac{xy}{x+y}$$
The equation holds for all $x, y \in \mathbb{R}^+$. Thus, $f(x) = \frac{1}{x}$ is a solution.

**2. Proof of Injectivity**
Suppose $f$ is not injective. Then there exist $x_1, x_2 \in \mathbb{R}^+$ such that $x_1 \neq x_2$ and $f(x_1) = f(x_2)$.
From the original equation, we have:
$$f\left(\frac{1}{x_1} + f(y)\right) = y f(y f(x_1) + 1)$$
$$f\left(\frac{1}{x_2} + f(y)\right) = y f(y f(x_2) + 1)$$
Since $f(x_1) = f(x_2)$, the right-hand sides are identical for all $y \in \mathbb{R}^+$, yielding:
$$f\left(\frac{1}{x_1} + f(y)\right) = f\left(\frac{1}{x_2} + f(y)\right)$$
Let $a = \frac{1}{x_1}$ and $b = \frac{1}{x_2}$. Since $x_1 \neq x_2$, we have $a \neq b$. Let $w = f(y)$. Then for all $w \in \text{Im}(f)$, we have:
$$f(a + w) = f(b + w)$$
Assume without loss of generality that $a < b$. Let $p = b - a > 0$. Then $f(a + w) = f(a + w + p)$ for all $w \in \text{Im}(f)$.
Now consider the original equation again: $f(\frac{1}{x} + f(y)) = y f(y f(x) + 1)$.
For a fixed $x$, the right-hand side is $y f(y f(x) + 1)$. The left-hand side is $f(\frac{1}{x} + f(y))$.
Since $f(y) \in \text{Im}(f)$, the property $f(a+w) = f(a+w+p)$ implies that for any $w \in \text{Im}(f)$, $f(a+w) = f(a+w+p) = f(a+w+2p) = \dots$ as long as the values remain in the domain.
Crucially, if $f(a+w) = f(b+w)$ for all $w \in \text{Im}(f)$, then for any $y \in \mathbb{R}^+$, $f(\frac{1}{x} + f(y))$ would be periodic in $f(y)$ with period $p$.
However, $f(\frac{1}{x} + f(y)) = y f(y f(x) + 1)$. If $f$ were periodic on its image, then for a fixed $x$, the expression $y f(y f(x) + 1)$ would have to exhibit periodic behavior in $y$ (since $f(y)$ is periodic). But the term $y f(y f(x) + 1)$ involves a linear multiplier $y$, which prevents the expression from being periodic unless $f(y f(x) + 1) = 0$, which is impossible as the codomain is $\mathbb{R}^+$.
Thus, the assumption that $f$ is not injective leads to a contradiction. Therefore, $f$ must be injective.

**3. Deriving the Unique Solution**
Since $f$ is injective, we use the original equation with $y=1$:
$$f(f(x)+1) = f\left(\frac{1}{x} + f(1)\right)$$
Injectivity implies:
$$f(x) + 1 = \frac{1}{x} + f(1)$$
Let $k = f(1) - 1$. Then $f(x) = \frac{1}{x} + k$. Substituting this back into the original equation:
$$\text{LHS} = y f\left(y\left(\frac{1}{x} + k\right) + 1\right) = y \left(\frac{1}{\frac{y}{x} + yk + 1} + k\right) = \frac{xy}{x + y + xyk} + yk$$
$$\text{RHS} = f\left(\frac{1}{x} + \frac{1}{y} + k\right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + k} + k = \frac{xy}{x + y + xyk} + k$$
Comparing the two sides, we obtain $yk = k$ for all $y \in \mathbb{R}^+$, which implies $k=0$.
Therefore, $f(x) = \frac{1}{x}$ is the only solution.

The only function $f: \mathbb{R}^+ \to \mathbb{R}^+$ satisfying the equation is $f(x) = \frac{1}{x}$.
