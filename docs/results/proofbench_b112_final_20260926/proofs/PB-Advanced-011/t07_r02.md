To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
\[ y f(y f(x) + 1) = f\left(\frac{1}{x} + f(y)\right) \quad \text{for all } x, y \in \mathbb{R}^+, \]
we proceed as follows:

**1. Testing for a simple solution**
We test if $f(x) = \frac{1}{x}$ is a solution. Substituting this into the functional equation:
LHS: $y f\left(y \frac{1}{x} + 1\right) = y \frac{1}{\frac{y}{x} + 1} = \frac{yx}{y + x}$.
RHS: $f\left(\frac{1}{x} + \frac{1}{y}\right) = \frac{1}{\frac{1}{x} + \frac{1}{y}} = \frac{xy}{x + y}$.
Since LHS = RHS for all $x, y \in \mathbb{R}^+$, $f(x) = \frac{1}{x}$ is a solution.

**2. Proving Injectivity**
Suppose there exist $y_1, y_2 \in \mathbb{R}^+$ such that $y_1 \neq y_2$ and $f(y_1) = f(y_2)$. Without loss of generality, assume $y_1 > y_2$. Let $k = \frac{y_1}{y_2} > 1$.
From the original equation, $f(y_1) = f(y_2)$ implies $f(\frac{1}{x} + f(y_1)) = f(\frac{1}{x} + f(y_2))$. Substituting the original equation into both sides:
\[ y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1). \]
Let $z = f(x)$. Then $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$ for all $z \in \text{Ran}(f)$. Since $y_1 = k y_2$, we have:
\[ k y_2 f(k y_2 z + 1) = y_2 f(y_2 z + 1) \implies f(y_2 z + 1) = k f(k y_2 z + 1) \quad \text{for all } z \in \text{Ran}(f). \]
Now, substitute $y = k^n y_2$ into the original functional equation for $n \in \mathbb{N}$:
\[ k^n y_2 f(k^n y_2 f(x) + 1) = f\left(\frac{1}{x} + f(k^n y_2)\right). \]
Using the relation $f(y_2 z + 1) = k f(k y_2 z + 1)$ repeatedly (or by induction on $n$), we have $f(y_2 z + 1) = k^n f(k^n y_2 z + 1)$. Thus, the LHS becomes:
\[ k^n y_2 \left[ k^{-n} f(y_2 f(x) + 1) \right] = y_2 f(y_2 f(x) + 1). \]
From the original equation with $y = y_2$, we know $y_2 f(y_2 f(x) + 1) = f(\frac{1}{x} + f(y_2))$. Thus,
\[ f\left(\frac{1}{x} + f(k^n y_2)\right) = f\left(\frac{1}{x} + f(y_2)\right) \quad \text{for all } x \in \mathbb{R}^+, n \in \mathbb{N}. \]
Let $a_n = f(k^n y_2)$. Then $f(s + a_n) = f(s + a_0)$ for all $s > 0$, where $a_0 = f(y_2)$.
If $a_n$ is not constant for $n \in \mathbb{N}$, then $f$ is periodic on the interval $(\min(a_0, a_n), \infty)$. If $f$ is periodic, let $M = \sup f$. Then $f(1/x + f(y)) \le M$ for all $x, y$. However, $y f(y f(x) + 1) \ge y \inf f$. If $\inf f > 0$, then for large $y$, $y \inf f > M$, a contradiction. If $\inf f = 0$, we note that $f(k^n y_2 z + 1) = k^{-n} f(y_2 z + 1) \to 0$ as $n \to \infty$. A periodic function $f: \mathbb{R}^+ \to \mathbb{R}^+$ that tends to 0 at infinity must be identically 0, which contradicts the codomain $\mathbb{R}^+$.
Thus, $a_n$ must be constant, so $f(k^n y_2) = a_0$ for all $n \in \mathbb{N}$.
However, we established that $f(k^n y_2 z + 1) = k^{-n} f(y_2 z + 1)$, which implies $f(w) \to 0$ as $w \to \infty$ for $w$ in the set $\{k^n y_2 z + 1 : z \in \text{Ran}(f), n \in \mathbb{N}\}$. Since $\text{Ran}(f)$ contains an interval $(f(y), \infty)$, this set covers all values from some $T$ onwards. Thus $f(w) \to 0$ as $w \to \infty$. Since $k^n y_2 \to \infty$ as $n \to \infty$, we must have $f(k^n y_2) \to 0$, which contradicts $f(k^n y_2) = a_0 > 0$.
Therefore, $y_1$ must equal $y_2$, and $f$ is injective.

**3. Determining the Function**
Using the injectivity of $f$ and setting $y=1$ in the original equation:
\[ f(f(x) + 1) = f\left(\frac{1}{x} + f(1)\right). \]
Since $f$ is injective, the arguments must be equal:
\[ f(x) + 1 = \frac{1}{x} + f(1). \]
Let $f(1) = a$. Then $f(x) = \frac{1}{x} + a - 1$.
Substitute this back into the original equation:
LHS: $y f\left(y\left(\frac{1}{x} + a - 1\right) + 1\right) = y \left( \frac{1}{\frac{y}{x} + y(a-1) + 1} + a - 1 \right) = \frac{yx}{y + xy(a-1) + x} + y(a-1)$.
RHS: $f\left(\frac{1}{x} + \frac{1}{y} + a - 1\right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + a - 1} + a - 1 = \frac{xy}{x + y + xy(a-1)} + a - 1$.
Equating the two sides:
\[ \frac{xy}{x + y + xy(a-1)} + y(a-1) = \frac{xy}{x + y + xy(a-1)} + a - 1. \]
This implies $y(a-1) = a-1$ for all $y \in \mathbb{R}^+$, which means $a-1 = 0$, so $a=1$.
Substituting $a=1$ into $f(x) = \frac{1}{x} + a - 1$ gives $f(x) = \frac{1}{x}$.

The only function $f: \mathbb{R}^+ \to \mathbb{R}^+$ that satisfies the given equation is $f(x) = \frac{1}{x}$.
