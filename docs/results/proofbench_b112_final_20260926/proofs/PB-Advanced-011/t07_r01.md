To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Testing simple functional forms**
If $f(x) = \frac{1}{x}$, then:
LHS: $y f\left(\frac{y}{x} + 1\right) = y \frac{1}{\frac{y+x}{x}} = \frac{xy}{x+y}$.
RHS: $f\left(\frac{1}{x} + \frac{1}{y}\right) = f\left(\frac{x+y}{xy}\right) = \frac{xy}{x+y}$.
Since LHS = RHS, $f(x) = \frac{1}{x}$ is a solution.

**2. Proving injectivity**
Suppose $f$ is not injective. Then there exist $x_1, x_2 \in \mathbb{R}^+$ with $x_1 \neq x_2$ such that $f(x_1) = f(x_2)$. Substituting these into the original equation:
$$f\left(\frac{1}{x_1} + f(y)\right) = y f(y f(x_1) + 1) \quad \text{and} \quad f\left(\frac{1}{x_2} + f(y)\right) = y f(y f(x_2) + 1).$$
Since $f(x_1) = f(x_2)$, the right-hand sides are identical, implying $f(\frac{1}{x_1} + f(y)) = f(\frac{1}{x_2} + f(y))$ for all $y \in \mathbb{R}^+$. Let $T = |\frac{1}{x_1} - \frac{1}{x_2}| > 0$ and $a = \min(\frac{1}{x_1}, \frac{1}{x_2})$. For any $z$ in the set $S + a$ (where $S$ is the range of $f$), we have $f(z + T) = f(z)$. Since the original equation implies that for a fixed $y$, as $x \to 0^+$, the term $\frac{1}{x} + f(y)$ covers the interval $(f(y), \infty)$, the function $f$ is periodic with period $T$ on some interval $(a', \infty)$.

Now, fix $x \in \mathbb{R}^+$ and define $h(y) = f(yf(x)+1)$. The original equation is $f(\frac{1}{x} + f(y)) = yh(y)$.
For $y$ large enough such that $y > a'$, we have $f(y+T) = f(y)$. Thus:
$$f\left(\frac{1}{x} + f(y+T)\right) = f\left(\frac{1}{x} + f(y)\right) \implies (y+T)h(y+T) = yh(y) \implies h(y+T) = \frac{y}{y+T}h(y).$$
Additionally, $h$ is periodic with period $T_h = T/f(x)$ for large $y$, because:
$$h\left(y + \frac{T}{f(x)}\right) = f\left(\left(y + \frac{T}{f(x)}\right)f(x) + 1\right) = f(yf(x) + 1 + T).$$
For $yf(x)+1 > a'$, we have $f(yf(x)+1+T) = f(yf(x)+1) = h(y)$.
Now, for any $y$ large enough, we have $h(y+T) = \frac{y}{y+T}h(y)$. Since $h$ is $T_h$-periodic, we have $h(y+mT_h) = h(y)$ for all $m \in \mathbb{N}$. Then:
$$h(y+mT_h+T) = \frac{y+mT_h}{y+mT_h+T}h(y+mT_h) = \frac{y+mT_h}{y+mT_h+T}h(y).$$
As $m \to \infty$, the right-hand side $\frac{y+mT_h}{y+mT_h+T}h(y) \to h(y)$.
However, the left-hand side $h(y+mT_h+T) = h(y+T)$ is constant for all $m$ due to the $T_h$-periodicity of $h$.
Thus, we must have $h(y+T) = h(y)$.
Combining this with $h(y+T) = \frac{y}{y+T}h(y)$, we get $h(y) = \frac{y}{y+T}h(y)$, which implies $h(y) = 0$ for all $y$.
This contradicts the codomain $\mathbb{R}^+$. Thus, $f$ must be injective.

**3. Deriving the general form**
Given that $f$ is injective, we substitute $y=1$ into the original equation:
$$f(f(x)+1) = f\left(\frac{1}{x} + f(1)\right).$$
Since $f$ is injective, we have:
$$f(x) + 1 = \frac{1}{x} + f(1) \implies f(x) = \frac{1}{x} + f(1) - 1.$$
Let $C = f(1) - 1$. Then $f(x) = \frac{1}{x} + C$. Substitute this back into the original equation:
$$y \left( \frac{1}{y(\frac{1}{x} + C) + 1} + C \right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + C} + C.$$
Simplifying the left-hand side:
$$\frac{y}{\frac{y}{x} + yC + 1} + yC = \frac{xy}{y + xyC + x} + yC.$$
Simplifying the right-hand side:
$$\frac{1}{\frac{x+y}{xy} + C} + C = \frac{xy}{x+y + xyC} + C.$$
Equating the two:
$$\frac{xy}{x+y + xyC} + yC = \frac{xy}{x+y + xyC} + C \implies yC = C \quad \text{for all } y \in \mathbb{R}^+.$$
This implies $C = 0$. Thus $f(1) = 1$, and the function must be $f(x) = \frac{1}{x}$.
We have already verified that $f(x) = \frac{1}{x}$ is a solution.

The only solution is $f(x) = \frac{1}{x}$.
