To prove that $2x+2y+1$ is a perfect square given that $x$ and $y$ are positive integers satisfying $2x^2 + x = 3y^2 + y$, we transform the given equation into a Pell-like equation.

**1. Transformation to a Pell Equation**
Multiply the given equation $2x^2 + x = 3y^2 + y$ by 8:
\[ 16x^2 + 8x = 24y^2 + 8y \]
Adding 1 to both sides completes the square on the left:
\[ (4x+1)^2 = 24y^2 + 8y + 1 \]
To further simplify, multiply the entire equation by 3:
\[ 3(4x+1)^2 = 72y^2 + 24y + 3 = 2(36y^2 + 12y + 1) + 1 = 2(6y+1)^2 + 1 \]
Let $k = 4x+1$ and $u = 6y+1$. The equation becomes:
\[ 3k^2 - 2u^2 = 1 \]

**2. Solving the Pell Equation**
To find all positive integer solutions to $3k^2 - 2u^2 = 1$, we multiply by 3 to obtain $9k^2 - 6u^2 = 3$. Let $X = 3k$ and $Y = u$, so we have the equation $X^2 - 6Y^2 = 3$. The fundamental solution to the associated Pell equation $z^2 - 6w^2 = 1$ is $(z_1, w_1) = (5, 2)$. According to the theory of Pell-like equations, any fundamental solution $(X_0, Y_0)$ to $X^2 - 6Y^2 = N$ must satisfy $0 \le Y_0 \le \frac{w_1 \sqrt{|N|}}{\sqrt{2(z_1+1)}}$. For $N=3$, this gives:
\[ 0 \le Y_0 \le \frac{2\sqrt{3}}{\sqrt{2(5+1)}} = \frac{2\sqrt{3}}{\sqrt{12}} = 1 \]
Testing $Y_0 = 0$ gives $X_0^2 = 3$ (no integer solution), and $Y_0 = 1$ gives $X_0^2 = 9$, so $X_0 = 3$. Thus, the only fundamental solution is $(X_0, Y_0) = (3, 1)$, which corresponds to $(k_0, u_0) = (1, 1)$. All solutions $(k_n, u_n)$ are generated by:
\[ k_n\sqrt{3} + u_n\sqrt{2} = (\sqrt{3} + \sqrt{2})(5 + 2\sqrt{6})^n \]
From this, we obtain the recurrence relations:
\[ k_{n+1} = 5k_n + 4u_n, \quad u_{n+1} = 6k_n + 5u_n \]
with $k_0 = 1$ and $u_0 = 1$. For $x$ and $y$ to be integers, we must satisfy $k_n \equiv 1 \pmod 4$ and $u_n \equiv 1 \pmod 6$.
- Modulo 4: $k_{n+1} \equiv 5k_n + 4u_n \equiv k_n \pmod 4$. Since $k_0 = 1$, $k_n \equiv 1 \pmod 4$ for all $n \ge 0$.
- Modulo 6: $u_{n+1} \equiv 6k_n + 5u_n \equiv -u_n \pmod 6$. Since $u_0 = 1$, $u_n \equiv (-1)^n \pmod 6$.
Thus, $u_n \equiv 1 \pmod 6$ if and only if $n$ is even. Let $n = 2m$ for some integer $m \ge 0$.

**3. Proving $2x+2y+1$ is a Square**
Express $2x+2y+1$ in terms of $k$ and $u$:
\[ 2x + 2y + 1 = 2\left(\frac{k-1}{4}\right) + 2\left(\frac{u-1}{6}\right) + 1 = \frac{k-1}{2} + \frac{u-1}{3} + 1 = \frac{3k + 2u + 1}{6} \]
Using the closed forms for $k_n$ and $u_n$ with $\beta = 5+2\sqrt{6}$ and $\bar{\beta} = 5-2\sqrt{6}$:
\[ k_n = \frac{3+\sqrt{6}}{6}\beta^n + \frac{3-\sqrt{6}}{6}\bar{\beta}^n, \quad u_n = \frac{2+\sqrt{6}}{4}\beta^n + \frac{2-\sqrt{6}}{4}\bar{\beta}^n \]
For $n = 2m$, we calculate $3k_{2m} + 2u_{2m}$:
\[ 3k_{2m} + 2u_{2m} = \left( \frac{3+\sqrt{6}}{2} + \frac{2+\sqrt{6}}{2} \right)\beta^{2m} + \left( \frac{3-\sqrt{6}}{2} + \frac{2-\sqrt{6}}{2} \right)\bar{\beta}^{2m} = \frac{5+2\sqrt{6}}{2}\beta^{2m} + \frac{5-2\sqrt{6}}{2}\bar{\beta}^{2m} \]
Now, evaluate $k_m^2$:
\[ k_m^2 = \left( \frac{3+\sqrt{6}}{6}\beta^m + \frac{3-\sqrt{6}}{6}\bar{\beta}^m \right)^2 = \frac{(3+\sqrt{6})^2}{36}\beta^{2m} + \frac{(3-\sqrt{6})^2}{36}\bar{\beta}^{2m} + \frac{2(3+\sqrt{6})(3-\sqrt{6})}{36}(\beta\bar{\beta})^m \]
Since $(3 \pm \sqrt{6})^2 = 15 \pm 6\sqrt{6} = 3(5 \pm 2\sqrt{6})$ and $\beta\bar{\beta} = 1$:
\[ k_m^2 = \frac{3(5+2\sqrt{6})}{36}\beta^{2m} + \frac{3(5-2\sqrt{6})}{36}\bar{\beta}^{2m} + \frac{2(3)}{36} = \frac{5+2\sqrt{6}}{12}\beta^{2m} + \frac{5-2\sqrt{6}}{12}\bar{\beta}^{2m} + \frac{1}{6} \]
Multiplying by 6 gives:
\[ 6k_m^2 = \frac{5+2\sqrt{6}}{2}\beta^{2m} + \frac{5-2\sqrt{6}}{2}\bar{\beta}^{2m} + 1 = 3k_{2m} + 2u_{2m} + 1 \]
Thus:
\[ 2x + 2y + 1 = \frac{3k_{2m} + 2u_{2m} + 1}{6} = \frac{6k_m^2}{6} = k_m^2 \]
Since $k_m$ is an integer, $2x+2y+1$ is a perfect square. \(\square\)
