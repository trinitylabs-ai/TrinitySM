To find all strictly increasing functions $g: \mathbb{R} \to \mathbb{R}$ that are surjective and satisfy the functional equation $g(g(x)) = g(x) + 20x$, we proceed as follows:

**1. Properties of $g$**
Since $g$ is strictly increasing and surjective, $g$ must be continuous. If $g$ had a jump discontinuity at any point $c$, then the left-hand limit $L_1 = \lim_{x \to c^-} g(x)$ and the right-hand limit $L_2 = \lim_{x \to c^+} g(x)$ would exist and satisfy $L_1 < L_2$. The range of $g$ would then omit the interval $(L_1, L_2)$, except possibly for the single value $g(c)$, which contradicts the surjectivity of $g$. Thus, $g$ is a continuous bijection from $\mathbb{R}$ to $\mathbb{R}$.

**2. Recurrence Relation of Iterates**
For any $x_0 \in \mathbb{R}$, we define a sequence $(x_n)_{n \in \mathbb{Z}}$ such that $x_{n+1} = g(x_n)$ for all $n$. Since $g$ is a bijection, this sequence is well-defined for all integers $n$. The given functional equation $g(g(x)) = g(x) + 20x$ implies that for all $n$:
\[ x_{n+2} = x_{n+1} + 20x_n \]
This is a linear homogeneous recurrence relation with constant coefficients. The characteristic equation is:
\[ r^2 - r - 20 = 0 \implies (r-5)(r+4) = 0 \]
The roots are $r_1 = 5$ and $r_2 = -4$. The general solution for the sequence is:
\[ x_n = A(x_0) 5^n + B(x_0) (-4)^n \]
where $A(x_0)$ and $B(x_0)$ are constants determined by the initial value $x_0$ and $x_1 = g(x_0)$. Specifically:
\[ x_0 = A(x_0) + B(x_0) \]
\[ g(x_0) = 5A(x_0) - 4B(x_0) \]

**3. Monotonicity and Asymptotic Behavior**
Because $g$ is strictly increasing, the sequence $(x_n)_{n \in \mathbb{Z}}$ must be monotonic for any $x_0$. 
- If $g(x_0) > x_0$, then $x_1 > x_0$. Since $g$ is strictly increasing, $g(x_1) > g(x_0) \implies x_2 > x_1$. By induction, $x_{n+1} > x_n$ for all $n \ge 0$. For $n < 0$, if $x_0 \le x_{-1}$, then $g(x_0) \le g(x_{-1}) \implies x_1 \le x_0$, which contradicts $x_1 > x_0$. Thus, $x_{n+1} > x_n$ for all $n \in \mathbb{Z}$.
- Similarly, if $g(x_0) < x_0$, then $x_{n+1} < x_n$ for all $n \in \mathbb{Z}$.
- If $g(x_0) = x_0$, then $x_n$ is constant for all $n$.

Consider the difference between consecutive terms:
\[ \Delta_n = x_{n+1} - x_n = A(x_0)(5^{n+1} - 5^n) + B(x_0)((-4)^{n+1} - (-4)^n) \]
\[ \Delta_n = 4 A(x_0) 5^n - 5 B(x_0) (-4)^n \]
For the sequence to be monotonic, $\Delta_n$ must have a constant sign (or be identically zero) for all $n \in \mathbb{Z}$. Let us examine the behavior as $n \to -\infty$. Let $n = -m$ where $m \to \infty$:
\[ \Delta_{-m} = \frac{4 A(x_0)}{5^m} - \frac{5 B(x_0)}{(-4)^m} = \frac{1}{4^m} \left[ 4 A(x_0) \left(\frac{4}{5}\right)^m - 5 B(x_0) (-1)^{-m} \right] \]
As $m \to \infty$, the term $4 A(x_0) (4/5)^m$ decays to zero. Thus, for sufficiently large $m$, the sign of $\Delta_{-m}$ is determined by the sign of $-5 B(x_0) (-1)^{-m}$. Since $(-1)^{-m}$ alternates in sign for each successive integer $m$, the sign of $\Delta_{-m}$ will alternate as $m \to \infty$ unless $B(x_0) = 0$.

**4. Conclusion and Verification**
For $\Delta_n$ to maintain a constant sign for all $n \in \mathbb{Z}$, we must have $B(x_0) = 0$ for all $x_0 \in \mathbb{R}$. Substituting $B(x_0) = 0$ into the expressions for $x_0$ and $g(x_0)$:
\[ x_0 = A(x_0) \]
\[ g(x_0) = 5 A(x_0) = 5x_0 \]
Thus, the only possible function is $g(x) = 5x$. We verify this solution:
- $g$ is strictly increasing: $5x > 5y$ for $x > y$.
- $g$ is surjective: For any $y \in \mathbb{R}$, $x = y/5$ satisfies $g(x) = y$.
- Functional equation: $g(g(x)) = 5(5x) = 25x$ and $g(x) + 20x = 5x + 20x = 25x$.
The conditions are all satisfied.

The only such function is $g(x) = 5x$.
