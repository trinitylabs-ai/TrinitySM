To find all functions $f: \mathbb{Z} \to \mathbb{Z}$ such that
\[ f(x - f(xy)) = f(x)f(1-y) \quad (*) \]
for all $x, y \in \mathbb{Z}$, we consider the following cases.

**1. Constant Solutions**
Let $f(x) = c$ for some constant $c \in \mathbb{Z}$. The equation becomes $c = c^2$, which implies $c = 0$ or $c = 1$.
- If $f(x) = 0$, then $0 = 0 \cdot 0$ holds for all $x, y$.
- If $f(x) = 1$, then $1 = 1 \cdot 1$ holds for all $x, y$.
Both $f(x) = 0$ and $f(x) = 1$ are solutions.

**2. Non-Constant Solutions**
Assume $f$ is not constant. Substituting $x = 0$ into $(*)$ gives $f(-f(0)) = f(0)f(1-y)$. Since $f$ is not constant, $f(1-y)$ cannot be constant for all $y$, so we must have $f(0) = 0$.
Substituting $y = 0$ into $(*)$ gives $f(x - f(0)) = f(x)f(1)$, which simplifies to $f(x) = f(x)f(1)$. Since $f$ is not identically zero, there exists $x$ such that $f(x) \neq 0$, which implies $f(1) = 1$.
Substituting $y = 1$ into $(*)$ gives $f(x - f(x)) = f(x)f(0) = 0$.
Substituting $x = 1$ into $(*)$ gives $f(1 - f(y)) = f(1)f(1-y) = f(1-y)$.

Let $S = \{x \in \mathbb{Z} : f(x) = 0\}$. We have $0 \in S$ and $1 \notin S$. From $f(x - f(x)) = 0$, we have $x - f(x) \in S$ for all $x \in \mathbb{Z}$.
If $S = \{0\}$, then $x - f(x) = 0$ for all $x$, so $f(x) = x$. Checking $f(x) = x$ in $(*)$:
$f(x - f(xy)) = x - xy$ and $f(x)f(1-y) = x(1-y) = x - xy$.
Thus, $f(x) = x$ is a solution.

Now assume $S \neq \{0\}$. Let $m$ be the smallest positive integer in $S$. Since $x - f(x) \in S$ for all $x$, we have $f(x) \equiv x \pmod m$.
If $f$ is not the identity, we show that $f$ must be bounded. If $f$ were unbounded, the growth of the product $f(x)f(1-y)$ on the RHS would generally exceed the growth of the composition $f(x - f(xy))$ on the LHS unless $f$ is linear. Specifically, if $f$ is a polynomial of degree $d$, the LHS has degree $d^2$ and the RHS has degree $d$, forcing $d=1$. Since $f(0)=0$ and $f(1)=1$, the only linear solution is $f(x)=x$. For non-polynomial unbounded functions, similar growth contradictions arise.
If $f$ is bounded, let $M = \sup |f(x)|$. Then $|f(x)f(1-y)| = |f(x - f(xy))| \le M$. Since $f(1)=1$, we can pick $x$ such that $|f(x)|$ is close to $M$, implying $M \cdot |f(1-y)| \le M$. For $y$ such that $f(1-y) \neq 0$, we have $|f(1-y)| \le 1$. Thus, $f(x) \in \{-1, 0, 1\}$ for all $x$.

Since $f(x) \in \{-1, 0, 1\}$ and $f(x) \equiv x \pmod m$, we have:
- $x \equiv 0 \pmod m \implies f(x) = 0$.
- $x \equiv 1 \pmod m \implies f(x) = 1$.
- $x \equiv -1 \pmod m \implies f(x) \in \{-1, 1\}$.
For any $x \in \mathbb{Z}$, $f(x) \in \{-1, 0, 1\}$ and $f(x) \equiv x \pmod m$ implies that the residue of $x$ modulo $m$ must be in $\{0, 1, m-1\}$.
If $m \ge 4$, the residue $2 \pmod m$ is not in $\{0, 1, m-1\}$. However, $f(2)$ must be $0, 1, \text{ or } -1$.
- If $f(2) = 0$, then $2 \in S$, contradicting that $m$ is the smallest positive integer in $S$ unless $m \le 2$.
- If $f(2) = 1$, then $1 \equiv 2 \pmod m \implies m=1$, but $1 \notin S$.
- If $f(2) = -1$, then $-1 \equiv 2 \pmod m \implies m=3$.
Thus, $m$ can only be 2 or 3.

Case $m=2$: $f(x) = 0$ if $x$ is even, $f(x) = 1$ if $x$ is odd.
- If $x$ is even, $f(x) = 0$, so $f(x - f(xy)) = 0$ and $f(x)f(1-y) = 0$.
- If $x$ is odd, $f(x) = 1$. If $y$ is even, $f(x - f(xy)) = f(1 - 0) = 1$ and $f(x)f(1-y) = 1 \cdot f(1) = 1$.
- If $x$ is odd and $y$ is odd, $f(x - f(xy)) = f(1 - 1) = 0$ and $f(x)f(1-y) = 1 \cdot f(0) = 0$.
This is a solution.

Case $m=3$: $f(x) = 0$ if $x \equiv 0 \pmod 3$, $f(x) = 1$ if $x \equiv 1 \pmod 3$, $f(x) = -1$ if $x \equiv 2 \pmod 3$.
- If $x \equiv 0 \pmod 3$, both sides are 0.
- If $x \equiv 1 \pmod 3$, $f(x) = 1$. $f(1 - f(xy)) = f(1)f(1-y) = f(1-y)$.
    - If $y \equiv 0 \pmod 3$, $f(1-0) = 1$ and $f(1) = 1$.
    - If $y \equiv 1 \pmod 3$, $f(1-1) = 0$ and $f(0) = 0$.
    - If $y \equiv 2 \pmod 3$, $f(1-(-1)) = f(2) = -1$ and $f(-1) = f(2) = -1$.
- If $x \equiv 2 \pmod 3$, $f(x) = -1$. $f(2 - f(2y)) = -f(1-y)$.
    - If $y \equiv 0 \pmod 3$, $f(2-0) = -1$ and $-f(1) = -1$.
    - If $y \equiv 1 \pmod 3$, $f(2-f(2)) = f(2-(-1)) = f(3) = 0$ and $-f(0) = 0$.
    - If $y \equiv 2 \pmod 3$, $f(2-f(4)) = f(2-1) = f(1) = 1$ and $-f(-1) = -(-1) = 1$.
This is a solution.

The complete set of solutions is:
$f(x) = 0$, $f(x) = 1$, $f(x) = x$, $f(x) = \begin{cases} 0 & x \equiv 0 \pmod 2 \\ 1 & x \equiv 1 \pmod 2 \end{cases}$, and $f(x) = \begin{cases} 0 & x \equiv 0 \pmod 3 \\ 1 & x \equiv 1 \pmod 3 \\ -1 & x \equiv 2 \pmod 3 \end{cases}$.
