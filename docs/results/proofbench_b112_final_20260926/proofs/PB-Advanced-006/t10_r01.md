We seek all functions $f: \mathbb{Z} \to \mathbb{Z}$ such that
\[ f(x - f(xy)) = f(x)f(1 - y) \quad (*) \]
holds for all $x, y \in \mathbb{Z}$.

**1. Constant Solutions**
Let $f(x) = c$ for all $x \in \mathbb{Z}$. Substituting into $(*)$ gives $c = c \cdot c$, so $c^2 - c = 0$, which implies $c = 0$ or $c = 1$.
- If $f(x) = 0$, then $f(x - f(xy)) = 0$ and $f(x)f(1 - y) = 0 \cdot 0 = 0$. This is a solution.
- If $f(x) = 1$, then $f(x - f(xy)) = 1$ and $f(x)f(1 - y) = 1 \cdot 1 = 1$. This is a solution.

**2. Non-Constant Solutions**
Suppose $f$ is not constant.
Substituting $y = 1$ into $(*)$ gives $f(x - f(x)) = f(x)f(0)$.
Substituting $x = 0$ into $(*)$ gives $f(-f(0)) = f(0)f(1 - y)$.
If $f(0) = c \neq 0$, then $f(1 - y) = \frac{f(-c)}{c}$ for all $y \in \mathbb{Z}$, which implies $f$ is a constant function. Since we assumed $f$ is not constant, we must have $f(0) = 0$.
Returning to the $y = 1$ equation, $f(0) = 0$ implies $f(x - f(x)) = 0$ for all $x \in \mathbb{Z}$.
Substituting $x = 1$ into $(*)$ gives $f(1 - f(y)) = f(1)f(1 - y)$.
Let $f(1) = a$. Then $f(1 - f(y)) = a f(1 - y)$.
Substituting $y = 0$ into this equation, and using $f(0) = 0$, we get $f(1 - f(0)) = a f(1)$, so $f(1) = a^2$. Thus $a = a^2$, meaning $a \in \{0, 1\}$.
If $a = 0$, then $f(1) = 0$. Substituting $y = 0$ into $(*)$ gives $f(x - f(0)) = f(x)f(1)$, so $f(x) = 0$ for all $x$, which is a constant solution.
Thus, $f(1) = 1$. The equation $f(1 - f(y)) = a f(1 - y)$ becomes $f(1 - f(y)) = f(1 - y)$.

**3. Analysis of $f(2)$**
Let $f(2) = k$. From $f(x - f(x)) = 0$ with $x = 2$, we have $f(2 - k) = 0$.
From $f(1 - f(y)) = f(1 - y)$ with $y = 2$, we have $f(1 - k) = f(-1)$.
Substituting $y = 2$ into $(*)$ gives $f(x - f(2x)) = f(x)f(-1)$.
Let $f(-1) = a$. Then $f(x - f(2x)) = a f(x)$.
For $x = 1$, $f(1 - f(2)) = a f(1) \implies f(1 - k) = a$.
For $y = -1$ in $f(1 - f(y)) = f(1 - y)$, we have $f(1 - a) = f(2) = k$.

**Case A: $k = 0$**
Then $f(2) = 0$. From $f(1 - k) = a$, we have $f(1) = a$, so $a = 1$.
Then $f(-1) = 1$. The equation $f(x - f(2x)) = a f(x)$ becomes $f(x - f(2x)) = f(x)$.
Testing $f(x) = x \pmod 2$ (with range $\{0, 1\}$):
- If $x$ is even, $f(x) = 0$. LHS: $f(x - f(xy)) = f(\text{even} - f(xy))$. If $xy$ is even, $f(xy)=0 \implies f(\text{even})=0$. If $xy$ is odd, $f(xy)=1 \implies f(\text{odd})=1$. However, $f(x)f(1-y) = 0 \cdot f(1-y) = 0$. For this to hold, $xy$ must be even whenever $x$ is even, which is true.
- If $x$ is odd, $f(x) = 1$. LHS: $f(x - f(xy))$. If $y$ is even, $xy$ is even, $f(xy)=0 \implies f(\text{odd})=1$. RHS: $1 \cdot f(1-\text{even}) = f(\text{odd}) = 1$. If $y$ is odd, $xy$ is odd, $f(xy)=1 \implies f(\text{odd}-1)=f(\text{even})=0$. RHS: $1 \cdot f(1-\text{odd}) = f(\text{even}) = 0$.
Thus, $f(x) = x \pmod 2$ is a solution.

**Case B: $k = 2$**
Then $f(2) = 2$. From $f(1 - k) = a$, we have $f(-1) = a$.
From $f(1 - a) = k$, we have $f(1 - a) = 2$.
If $a = -1$, then $f(2) = 2$, which is consistent.
Testing $f(x) = x$:
LHS: $f(x - f(xy)) = x - xy$.
RHS: $f(x)f(1 - y) = x(1 - y) = x - xy$.
Thus, $f(x) = x$ is a solution.

**Case C: $k = -1$**
Then $f(2) = -1$. From $f(1 - k) = a$, we have $f(2) = a$, so $a = -1$.
Then $f(1 - a) = k \implies f(2) = -1$, which is consistent.
Testing $f(x) = x \pmod 3$ with range $\{0, 1, -1\}$:
- If $x \equiv 0 \pmod 3$, $f(x) = 0$, so both sides are 0.
- If $x \equiv 1 \pmod 3$, $f(x) = 1$, LHS $f(1 - f(y))$, RHS $f(1 - y)$. This holds as $f(1 - f(y)) = f(1 - y)$ for $f(x) = x \pmod 3$.
- If $x \equiv 2 \pmod 3$, $f(x) = -1$, LHS $f(2 - f(2y))$, RHS $-f(1 - y)$.
  - $y \equiv 0 \pmod 3 \implies f(2 - 0) = -1, -f(1) = -1$.
  - $y \equiv 1 \pmod 3 \implies f(2 - f(2)) = f(2 - (-1)) = f(3) = 0, -f(0) = 0$.
  - $y \equiv 2 \pmod 3 \implies f(2 - f(4)) = f(2 - 1) = f(1) = 1, -f(-1) = -(-1) = 1$.
Thus, $f(x) = x \pmod 3$ (with range $\{0, 1, -1\}$) is a solution.

**4. Exhaustiveness**
For any non-constant solution, we have $f(0)=0, f(1)=1$. If $f(x) = x \pmod n$ (balanced range), then the maximum absolute value is $M = \lfloor n/2 \rfloor$. The equation $f(x - f(xy)) = f(x)f(1 - y)$ implies $M^2 \le M$ if the range is fully utilized, so $M \le 1$, which means $n \le 3$. For $n=2$, we get $f(x) = x \pmod 2$. For $n=3$, we get $f(x) = x \pmod 3$. For $f(x) = x$, the range is unbounded.

The solutions are $f(x) = 0$, $f(x) = 1$, $f(x) = x$, $f(x) = \begin{cases} 0 & x \text{ is even} \\ 1 & x \text{ is odd} \end{cases}$, and $f(x) = \begin{cases} 0 & x \equiv 0 \pmod 3 \\ 1 & x \equiv 1 \pmod 3 \\ -1 & x \equiv 2 \pmod 3 \end{cases}$.
