To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that the equation
\[ f(x - f(xy)) = f(x)f(1 - y) \quad (*) \]
holds for all $x, y \in \mathbb{Z}$, we proceed as follows.

### 1. Constant Solutions
Let $f(n) = c$ for all $n \in \mathbb{Z}$. Substituting into $(*)$:
\[ c = c^2 \implies c(c - 1) = 0 \implies c = 0 \text{ or } c = 1. \]
Both $f(n) = 0$ and $f(n) = 1$ are solutions.

### 2. Non-constant Solutions
Assume $f$ is not constant. Setting $x = 0$ in $(*)$:
\[ f(-f(0)) = f(0)f(1 - y). \]
If $f(0) \neq 0$, then $f(1 - y) = \frac{f(-f(0))}{f(0)}$ for all $y \in \mathbb{Z}$, which implies $f$ is constant. Thus, we must have $f(0) = 0$.
Setting $y = 0$ in $(*)$:
\[ f(x - f(0)) = f(x)f(1) \implies f(x) = f(x)f(1). \]
Since $f$ is not identically zero, there exists $x$ such that $f(x) \neq 0$, forcing $f(1) = 1$.
Setting $y = 1$ in $(*)$:
\[ f(x - f(x)) = f(x)f(0) = 0. \]
Setting $x = 1$ in $(*)$:
\[ f(1 - f(y)) = f(1)f(1 - y) = f(1 - y). \]

Let $K = \{ n \in \mathbb{Z} \mid f(n) = 0 \}$. We know $0 \in K$.
From $f(x - f(x)) = 0$, we have $x - f(x) \in K$ for all $x \in \mathbb{Z}$.
If $y \in K$, then $f(1 - y) = f(1 - f(y)) = f(1 - 0) = f(1) = 1$.
Then $(1 - y) - f(1 - y) = 1 - y - 1 = -y \in K$. Thus, $y \in K \iff -y \in K$.

**Case A: $K = \{0\}$.**
From $x - f(x) \in K$, we have $x - f(x) = 0$ for all $x \in \mathbb{Z}$, so $f(x) = x$.
Checking this in $(*)$: $LHS = f(x - xy) = x - xy$ and $RHS = f(x)f(1 - y) = x(1 - y) = x - xy$.
So $f(n) = n$ is a solution.

**Case B: $K \neq \{0\}$.**
Let $x_0$ be the smallest positive integer in $K$. Since $f(1) = 1$, $x_0 \geq 2$.
If $x \in K$, then $f(x - f(xy)) = f(x)f(1 - y) = 0$, so $x - f(xy) \in K$ for all $y \in \mathbb{Z}$.
For $x = x_0$, we have $x_0 - f(x_0 y) \in K$ for all $y \in \mathbb{Z}$.
If $0 < f(x_0 y) < x_0$, then $0 < x_0 - f(x_0 y) < x_0$, contradicting the minimality of $x_0$.
Thus, for all $y$, $f(x_0 y) \notin \{1, 2, \dots, x_0 - 1\}$.
Since $x - f(x) \in K$ for all $x$, we have $2 - f(2) \in K$.
If $f(2) = 1$, then $1 \in K$, but $x_0 \geq 2$.
If $f(2) = 0$, then $x_0 = 2$.
If $f(2) = -1$, then $3 \in K$, so $x_0 \leq 3$.
If $f(2) \notin \{-1, 0, 1\}$, then $2 - f(2) \in K$. If $2 - f(2) > 0$, then $2 - f(2) \geq x_0$. If $2 - f(2) < 0$, then $f(2) - 2 \geq x_0$.

Subcase B1: $x_0 = 2$.
Then $f(2) = 0$. Testing $f(n) = n \pmod 2$ (range $\{0, 1\}$):
If $x$ is even, $f(x) = 0$, so $LHS = f(\text{even} - f(xy)) = f(\text{even} - 0) = 0$ and $RHS = 0$.
If $x$ is odd, $f(x) = 1$. If $y$ is even, $f(xy) = 0$, $LHS = f(\text{odd} - 0) = 1$, $RHS = 1 \cdot f(\text{odd}) = 1$.
If $y$ is odd, $f(xy) = 1$, $LHS = f(\text{odd} - 1) = f(\text{even}) = 0$, $RHS = 1 \cdot f(\text{even}) = 0$.
So $f(n) = n \pmod 2$ is a solution.

Subcase B2: $x_0 = 3$.
Then $f(1) = 1, f(2) \neq 0, f(3) = 0$.
From $2 - f(2) \in K$, since $x_0 = 3$, we must have $2 - f(2) \leq 0$ or $2 - f(2) \geq 3$.
If $f(2) = -1$, then $2 - (-1) = 3 \in K$, which is consistent.
Testing $f(n) = n \pmod 3$ with range $\{-1, 0, 1\}$:
This function is completely multiplicative: $f(xy) = f(x)f(y)$.
Also, $f(n) \equiv n \pmod 3$ for all $n$, so $x - f(xy) \equiv x - xy \pmod 3$, which implies $f(x - f(xy)) = f(x - xy)$.
Since $f$ is completely multiplicative, $f(x - xy) = f(x(1 - y)) = f(x)f(1 - y)$.
Thus, $f(n) = n \pmod 3$ (range $\{-1, 0, 1\}$) is a solution.

If $x_0 > 3$, we already showed that $f(2)$ must be $-1$ to satisfy $2 - f(2) \in K$ (since $f(2)=0 \implies x_0=2$ and $f(2)=1 \implies x_0=1$), but $f(2) = -1 \implies 3 \in K$, contradicting $x_0 > 3$. Thus, no other solutions exist in Case B.

The functions are $f(n) = 0$, $f(n) = 1$, $f(n) = n$, $f(n) = n \pmod 2$ (range $\{0, 1\}$), and $f(n) = n \pmod 3$ (range $\{-1, 0, 1\}$).
