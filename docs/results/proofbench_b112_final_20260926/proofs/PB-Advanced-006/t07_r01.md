We seek all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that
\[ f(x - f(xy)) = f(x)f(1 - y) \quad (*) \]
for all $x, y \in \mathbb{Z}$.

**1. Constant Solutions**
If $f(x) = c$ for some constant $c \in \mathbb{Z}$, then $(*)$ becomes $c = c^2$, so $c \in \{0, 1\}$.
Testing $f(x) = 0$: $0 = 0 \cdot 0$ (Valid).
Testing $f(x) = 1$: $1 = 1 \cdot 1$ (Valid).

**2. Non-constant Solutions**
Assume $f$ is not constant.
Setting $x = 0$ in $(*)$ gives $f(-f(0)) = f(0)f(1 - y)$. If $f(0) \neq 0$, then $f(1 - y)$ must be the constant $\frac{f(-f(0))}{f(0)}$ for all $y \in \mathbb{Z}$, which implies $f$ is constant, contradicting our assumption. Thus, $f(0) = 0$.
Setting $y = 0$ in $(*)$ gives $f(x - f(0)) = f(x)f(1) \implies f(x) = f(x)f(1)$. Since $f$ is not identically zero, there exists $x$ such that $f(x) \neq 0$, forcing $f(1) = 1$.
Setting $y = 1$ in $(*)$ gives $f(x - f(x)) = f(x)f(0) = 0$.
Setting $x = 1$ in $(*)$ gives $f(1 - f(y)) = f(1)f(1 - y) = f(1 - y)$.

**3. Case: $f(x) \in \{0, 1\}$ for all $x \in \mathbb{Z}$**
We have $f(0) = 0$ and $f(1) = 1$.
From $f(1 - f(y)) = f(1 - y)$, if $f(y) = 0$, then $f(1) = f(1 - y) \implies f(1 - y) = 1$. If $f(y) = 1$, then $f(0) = f(1 - y) \implies f(1 - y) = 0$. Thus, $f(y) = 0 \iff f(1 - y) = 1$.
From $f(x - f(x)) = 0$, if $f(x) = 1$, then $f(x - 1) = 0$.
If $f(x) = 0$, then $f(1 - x) = 1$, which implies $f((1 - x) - 1) = f(-x) = 0$.
Suppose $f(x) = 0$ and $f(x - 1) = 0$. Then $f(1 - (x - 1)) = f(2 - x) = 1$, which implies $f((2 - x) - 1) = f(1 - x) = 0$. But $f(x) = 0 \implies f(1 - x) = 1$, a contradiction.
Thus, $f(x) = 0 \iff f(x - 1) = 1$.
Since $f(0) = 0$, we have $f(1) = 1, f(2) = 0, f(3) = 1, \dots$ and $f(-1) = 1, f(-2) = 0, \dots$.
This is the function $f(x) = x \pmod 2$. Testing this in $(*)$:
- If $x$ is even, $f(x) = 0$, so RHS $= 0$. LHS $= f(\text{even} - f(xy)) = f(\text{even} - 0) = 0$.
- If $x$ is odd, $f(x) = 1$, so RHS $= f(1 - y)$.
  - If $y$ is even, $f(xy) = 0$, LHS $= f(\text{odd} - 0) = 1$. RHS $= f(1 - \text{even}) = f(\text{odd}) = 1$.
  - If $y$ is odd, $f(xy) = 1$, LHS $= f(\text{odd} - 1) = f(\text{even}) = 0$. RHS $= f(1 - \text{odd}) = f(\text{even}) = 0$.
Thus, $f(x) = x \pmod 2$ is a solution.

**4. Case: $f(x)$ takes values other than $\{0, 1\}$**
Let $S = \{z \in \mathbb{Z} \mid f(z) = 0\}$. We know $0 \in S$.
If $s \in S$, then for all $y$, $f(s - f(sy)) = f(s)f(1 - y) = 0 \cdot f(1 - y) = 0$, so $s - f(sy) \in S$.
Suppose $S \neq \{0\}$. Let $s \in S, s \neq 0$. Then $f(1 - s) = f(1 - f(s)) = f(1) = 1$.
From $s - f(sy) \in S$ for all $y$, let $y = 1$. Then $s - f(s) = s - 0 = s \in S$.
If $f(x) = x$ for all $x \notin S$, then for any $s \in S, s \neq 0$, we have $s - f(sy) \in S$.
If $sy \notin S$, then $s - sy \in S$. For $y=2$, $s - 2s = -s \in S$.
If $S$ is a subgroup of $\mathbb{Z}$, then $S = n\mathbb{Z}$ for some $n > 1$.
If $f(x) = x$ for $x \notin n\mathbb{Z}$ and $f(x) = 0$ for $x \in n\mathbb{Z}$, we test $(*)$ with $x \notin n\mathbb{Z}$ and $xy \in n\mathbb{Z}$ (e.g., $x=1, y=n$):
LHS: $f(1 - f(n)) = f(1 - 0) = f(1) = 1$.
RHS: $f(1)f(1 - n) = 1 \cdot (1 - n) = 1 - n$.
For $1 = 1 - n$, we need $n = 0$, but $n > 1$.
Thus, $f(x)$ cannot be $x$ for all $x \notin S$ if $S \neq \{0\}$.
If $f$ takes values other than $\{0, 1\}$, the only remaining possibility is $S = \{0\}$.
If $S = \{0\}$, then $f(x - f(x)) = 0 \implies x - f(x) = 0 \implies f(x) = x$.
Testing $f(x) = x$ in $(*)$: $f(x - xy) = x - xy$ and $f(x)f(1 - y) = x(1 - y) = x - xy$.
Thus, $f(x) = x$ is a solution.

The functions that satisfy the equation are $f(x) = 0$, $f(x) = 1$, $f(x) = x$, and $f(x) = x \pmod 2$.
