\[ d^2 + k^2 + c = mdk \]

- If $d=k$, then $2d^2 + 1 = md^2$, so $(m-2)d^2 = 1$, which implies $d=1$ and $m=3$.

\[ 4^2 + 19^2 + 3 = 16 + 361 + 3 = 380 \]
