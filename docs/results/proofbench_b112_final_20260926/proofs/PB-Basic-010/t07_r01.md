To prove that $\sum_{(a, b) \in S_{AB}} (b - a) \neq \sum_{(a, b) \in S_{BA}} (a - b)$, we define the given sets and sums and analyze their relationship.

Let $n = 1011$. The set $X = \{1, 2, 3, \ldots, 2n\}$ is partitioned into two sets $A$ and $B$ such that $|A| = |B| = n$. We are given:
- $S_{AB} = \{ (a, b) \in A \times B \mid a < b \}$
- $S_{BA} = \{ (a, b) \in A \times B \mid b < a \}$

Let $L$ be the sum over $S_{AB}$ and $R$ be the sum over $S_{BA}$:
\[ L = \sum_{(a, b) \in S_{AB}} (b - a), \quad R = \sum_{(a, b) \in S_{BA}} (a - b) \]

Since $A$ and $B$ are a partition of $X$, they are disjoint ($A \cap B = \emptyset$). Thus, for any pair $(a, b) \in A \times B$, it is impossible for $a$ to equal $b$. Consequently, every pair $(a, b) \in A \times B$ must satisfy either $a < b$ or $b < a$. This implies that $S_{AB} \cup S_{BA} = A \times B$ and $S_{AB} \cap S_{BA} = \emptyset$.

We examine the difference $L - R$:
\[ L - R = \sum_{(a, b) \in S_{AB}} (b - a) - \sum_{(a, b) \in S_{BA}} (a - b) \]
Using the fact that $-(a - b) = b - a$, we can rewrite the second sum:
\[ L - R = \sum_{(a, b) \in S_{AB}} (b - a) + \sum_{(a, b) \in S_{BA}} (b - a) \]
Since $S_{AB}$ and $S_{BA}$ partition the set $A \times B$, the two sums combine into a single sum over all pairs in $A \times B$:
\[ L - R = \sum_{(a, b) \in A \times B} (b - a) \]
Expanding this sum, we have:
\[ L - R = \sum_{a \in A} \sum_{b \in B} b - \sum_{b \in B} \sum_{a \in A} a \]
Let $\Sigma_A = \sum_{a \in A} a$ and $\Sigma_B = \sum_{b \in B} b$. The double sums simplify as follows:
\[ L - R = |A| \Sigma_B - |B| \Sigma_A \]
Since $|A| = |B| = n = 1011$, we obtain:
\[ L - R = n(\Sigma_B - \Sigma_A) \]

The condition $L = R$ holds if and only if $n(\Sigma_B - \Sigma_A) = 0$, which, since $n \neq 0$, requires $\Sigma_A = \Sigma_B$. We check if this equality is possible by calculating the total sum $S$ of the set $X$:
\[ S = \Sigma_A + \Sigma_B = \sum_{k=1}^{2022} k = \frac{2022 \times 2023}{2} = 1011 \times 2023 \]
Since $1011$ and $2023$ are both odd, their product $S$ is odd. If $\Sigma_A = \Sigma_B$, then $S = 2\Sigma_A$, which would imply that $S$ is even. This is a contradiction. Therefore, $\Sigma_A \neq \Sigma_B$.

Since $n \neq 0$ and $\Sigma_B - \Sigma_A \neq 0$, it follows that $L - R \neq 0$. Thus, we have proven that:
\[ \sum_{(a, b) \in S_{AB}} (b - a) \neq \sum_{(a, b) \in S_{BA}} (a - b) \]

\(\square\)
