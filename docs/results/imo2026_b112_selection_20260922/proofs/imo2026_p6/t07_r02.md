Let $(a_n)_{n \ge 1}$ be the sequence of positive integers greater than 1 such that $a_{n+1}$ is the smallest integer greater than $a_n$ satisfying $\gcd(a_{n+1}, a_i) > 1$ for all $i = 1, \dots, n$. Let $P(x)$ denote the set of prime factors of $x$. A set of primes $H$ is a hitting set for the collection $S_n = \{P(a_1), \dots, P(a_n)\}$ if $H \cap P(a_i) \neq \emptyset$ for all $i = 1, \dots, n$.

First, we show that the gaps $g_n = a_{n+1} - a_n$ are bounded. By definition, $a_2$ must satisfy $\gcd(a_2, a_1) > 1$, so $P(a_2) \cap P(a_1) \neq \emptyset$. For any $n \ge 2$, $a_n$ must satisfy $\gcd(a_n, a_1) > 1$, so $P(a_n) \cap P(a_1) \neq \emptyset$. This implies that $P(a_1)$ is a hitting set for $S_n$ for all $n \ge 1$. Let $M = \prod_{p \in P(a_1)} p$. Since $a_n + M$ is a multiple of every prime in $P(a_1)$, it satisfies $\gcd(a_n + M, a_i) \ge \gcd(M, a_i) > 1$ for all $i = 1, \dots, n$. Thus, $a_{n+1} \le a_n + M$, and the gaps $g_n$ are bounded by $M$.

Let $\mathcal{P}_M = \{p \text{ prime} : p \le M\}$. Since $a_{n+1} \le a_n + M$, any prime factor $p > M$ of $a_{n+1}$ cannot be the sole reason $a_{n+1}$ is the smallest integer hitting $S_n$, as a multiple of a hitting set $H \subseteq \mathcal{P}_M$ would provide a smaller or equal candidate. Specifically, since $P(a_1) \subseteq \mathcal{P}_M$ is a hitting set for $S_n$, $a_{n+1}$ is the smallest multiple of some hitting set $H \subseteq \mathcal{P}_M$ greater than $a_n$. Thus, $a_{n+1}$ always shares at least one prime factor with $M$.

Let $S'_n = \{ P(a_i) \cap \mathcal{P}_M : i = 1, \dots, n \}$. Since $S'_n$ is a collection of subsets of the finite set $\mathcal{P}_M$, the sequence $S'_1 \subseteq S'_2 \subseteq \dots$ must stabilize. There exists $N$ such that $S'_n = S'_N$ for all $n \ge N$. For $n \ge N$, $a_{n+1}$ is the smallest integer $> a_n$ such that $P(a_{n+1})$ hits all sets in $S'_N$. This condition depends only on $a_n \pmod{L_0}$ where $L_0 = \prod_{p \in \mathcal{P}_M} p$. Since the state $(a_n \pmod{L_0}, S'_n)$ takes values in a finite set, the sequence of gaps $g_n$ is eventually periodic. Thus, there exist $T, L$ such that $a_{n+T} = a_n + L$ for all $n \ge N$.

Finally, we prove that the periodicity holds for all $n \ge 1$. For any $n \ge 1$, $a_{n+1}$ hits $S_n$ by definition. Furthermore, for any $k > n$, $a_{k+1}$ must hit $a_{n+1}$ by the definition of the sequence, so $\gcd(a_{k+1}, a_{n+1}) > 1$. This implies that $a_{n+1}$ is hit by all subsequent terms $a_{n+2}, a_{n+3}, \dots, a_N$. Thus, $\gcd(a_{n+1}, a_i) > 1$ for all $i = 1, \dots, N$, meaning $a_{n+1}$ hits $S'_N$ for all $n \ge 1$.

For $n < N$, $g_n$ is the smallest $x$ such that $a_n + x$ hits $S_n$. Since $S_n \subseteq S'_N$, $g_{n+T}$ (the smallest $x$ such that $a_{n+T} + x$ hits $S_{n+T} = S'_N$) satisfies $g_{n+T} \ge g_n$. However, we know $a_n + g_n = a_{n+1}$ already hits $S'_N$. Since $a_{n+T} \equiv a_n \pmod{L_0}$, $a_{n+T} + g_n$ also hits $S'_N$. Thus, $g_{n+T} \le g_n$. It follows that $g_{n+T} = g_n$ for all $n \ge 1$. This implies $a_{n+T} = a_n + L$ for all $n \ge 1$.
