Let $Q_n$ be the set of prime factors of $a_n$. The condition $\gcd(a_{n+1}, a_i) > 1$ for all $i = 1, \dots, n$ implies that $Q_{n+1}$ must be a hitting set for the family $\mathcal{F}_n = \{Q_1, \dots, Q_n\}$. Let $M_n$ be the set of products of primes in minimal hitting sets of $\mathcal{F}_n$. The value of $a_{n+1}$ is the smallest integer greater than $a_n$ that is a multiple of some $m \in M_n$:
\[ a_{n+1} = \min_{m \in M_n} \left\{ m \left\lceil \frac{a_n+1}{m} \right\rceil \right\} \]
Since $Q_1$ is a hitting set for $\mathcal{F}_n$ for every $n \ge 1$, $M_n$ always contains a minimal hitting set $S \subseteq Q_1$. Thus, $\min M_n \le \prod_{p \in Q_1} p = m_{max}$ for all $n$. This implies $a_{n+1} \le a_n + m_{max}$.

We first show that the set of primes that can belong to a minimal hitting set of $\mathcal{F}_n$ is finite for $n \ge N$. Let $h_n$ be the size of the minimum hitting set of $\mathcal{F}_n$. Since $h_n$ is non-decreasing and bounded by $|Q_1|$, it stabilizes to $h$ for $n \ge N$. Let $S$ be a minimal hitting set for $\mathcal{F}_n$ ($n \ge N$). For every $p \in S$, there exists a witness index $i \le n$ such that $S \cap Q_i = \{p\}$. If $i \le N$, $p$ is a prime factor of $a_i$. If $i > N$, then $S \setminus \{p\}$ is a hitting set for $\mathcal{F}_n \setminus \{Q_i\}$, and thus for $\mathcal{F}_N$. Let $\mathcal{H}_N$ be the set of all hitting sets for $\mathcal{F}_N$ of size $\le |Q_1|$. $\mathcal{H}_N$ is finite. For any $S' \in \mathcal{H}_N$, let $I_{S'} = \{ j \in \mathbb{Z}^+ : S' \cap Q_j = \emptyset \}$. If $S' \cup \{p\}$ is a minimal hitting set for $\mathcal{F}_n$, then $p$ must divide $a_j$ for all $j \in I_{S'} \cap \{1, \dots, n\}$. Thus $p$ divides $g_{S', n} = \gcd_{j \in I_{S'} \cap \{1, \dots, n\}} (a_j)$. Since $(g_{S', n})$ is a non-increasing sequence of positive integers, it stabilizes to $g_{S'}$ for $n \ge N_{S'}$. Thus, for $n \ge \max_{S' \in \mathcal{H}_N} N_{S'}$, any prime $p$ in a minimal hitting set $S$ of $\mathcal{F}_n$ must divide some $a_i$ ($i \le N$) or some $g_{S'}$. This set of primes $\mathcal{P}_{global}$ is finite.

Since $M_n$ consists of products of primes from $\mathcal{P}_{global}$, $M_n$ is a subset of a finite set $M_{global}$ for $n \ge N_{final}$. Let $L_0 = \text{lcm}(m \in M_{global})$. The state of the sequence at step $n$ can be described by $(a_n \pmod{L_0}, \mathcal{F}_n)$. Since $\mathcal{F}_n$ is a collection of subsets of $\mathcal{P}_{global}$, there are only finitely many possible families $\mathcal{F}_n$ (determined by which subsets of $\mathcal{P}_{global}$ have appeared). Thus, the sequence of states is eventually periodic. There exist $T'$ and $L'$ such that $a_{n+T'} = a_n + L'$ for all $n \ge N$.

To extend this to $n=1$, choose $m$ such that $L = m L'$ is a multiple of $\text{rad}(a_1 a_2 \dots a_{N+mT'})$. Let $T = mT'$. Then $a_{n+T} = a_n + L$ for $n \ge N$. We use downward induction to show $a_{n+T} = a_n + L$ for $n < N$. Suppose $a_{m+T} = a_m + L$ for $m \ge n+1$. We show $a_{n+T} = a_n + L$.
$a_n$ is the smallest integer $> a_{n-1}$ such that $\gcd(a_n, a_i) > 1$ for $i < n$.
$a_{n+T}$ is the smallest integer $> a_{n-1+T}$ such that $\gcd(a_{n+T}, a_i) > 1$ for $i < n+T$.
By induction, $a_{n-1+T} = a_{n-1} + L$. Consider $x = a_n + L$.
1. For $i < N$, $\gcd(a_n + L, a_i) = \gcd(a_n, a_i) > 1$ because $L$ is a multiple of $\text{rad}(a_i)$.
2. For $N \le i < n+T$, let $j = i-T$. If $j \ge N$, $\gcd(a_n + L, a_{j+T}) = \gcd(a_n + L, a_j + L) = \gcd(a_n, a_j) > 1$ since $j < n$. If $j < N$, $\gcd(a_n + L, a_i) = \gcd(a_n, a_i) > 1$ because $L$ is a multiple of $\text{rad}(a_i)$ and $\gcd(a_n, a_i) > 1$ (since $i > n$).
Thus $a_n + L$ satisfies the GCD conditions. If there were a smaller $y \in (a_{n-1} + L, a_n + L)$ satisfying them, then $y-L \in (a_{n-1}, a_n)$ would satisfy $\gcd(y-L, a_i) = \gcd(y, a_i) > 1$ for $i < N$ and $\gcd(y-L, a_j) = \gcd(y, a_{j+T}) > 1$ for $j \ge N$ (since $j+T < n+T$), contradicting the minimality of $a_n$. Thus $a_{n+T} = a_n + L$ for all $n \ge 1$.
