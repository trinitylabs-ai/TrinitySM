Let $\mathcal{P}(m)$ denote the set of prime factors of $m$. The condition $\gcd(x, a_i) > 1$ for all $i=1, \dots, n$ is equivalent to $\mathcal{P}(x) \cap \mathcal{P}(a_i) \neq \emptyset$ for all $i=1, \dots, n$. Let $\mathcal{F}_n = \{\mathcal{P}(a_1), \dots, \mathcal{P}(a_n)\}$ be the family of sets of prime factors of the first $n$ terms. Let $\mathcal{G}_n$ be the collection of minimal elements of $\mathcal{F}_n$ under inclusion. An integer $x$ satisfies $\gcd(x, a_i) > 1$ for all $i=1, \dots, n$ if and only if $\mathcal{P}(x)$ is a hitting set for $\mathcal{G}_n$ (i.e., $\mathcal{P}(x) \cap S \neq \emptyset$ for all $S \in \mathcal{G}_n$).

By definition, $a_{n+1}$ is the smallest integer $x > a_n$ such that $\mathcal{P}(x)$ hits $\mathcal{G}_n$. The family $\mathcal{G}_{n+1}$ consists of the minimal elements of $\mathcal{G}_n \cup \{\mathcal{P}(a_{n+1})\}$.

First, we prove by induction that $\mathcal{G}_n$ is an intersecting family. For $n=1$, $\mathcal{G}_1 = \{\mathcal{P}(a_1)\}$ is vacuously intersecting. Assume $\mathcal{G}_n$ is intersecting. Since $\mathcal{P}(a_{n+1})$ hits every $S \in \mathcal{G}_n$, $\mathcal{P}(a_{n+1}) \cap S \neq \emptyset$ for all $S \in \mathcal{G}_n$. Any two elements $S, S' \in \mathcal{G}_{n+1}$ either both belong to $\mathcal{G}_n$ (intersecting by induction), or one is a subset of $\mathcal{P}(a_{n+1})$ and the other is in $\mathcal{G}_n$. If $S' \subseteq \mathcal{P}(a_{n+1})$ and $S' \in \mathcal{G}_{n+1}$, then $S'$ must either be in $\mathcal{G}_n$ or be $\mathcal{P}(a_{n+1})$ itself. In either case, since $\mathcal{P}(a_{n+1})$ hits every $S \in \mathcal{G}_n$, the intersection is non-empty. Thus $\mathcal{G}_{n+1}$ is intersecting.

Next, we show $\mathcal{P}(a_1)$ is always a hitting set for $\mathcal{G}_n$. For $n=1$, this is trivial. Assume $\mathcal{P}(a_1)$ hits $\mathcal{G}_n$. Then there exists $S \in \mathcal{G}_n$ such that $S \subseteq \mathcal{P}(a_1)$. Since $\mathcal{P}(a_{n+1})$ hits $S$, $\mathcal{P}(a_{n+1}) \cap \mathcal{P}(a_1) \neq \emptyset$. Thus $\mathcal{P}(a_1)$ hits $\mathcal{P}(a_{n+1})$ and all $S \in \mathcal{G}_n$, making it a hitting set for $\mathcal{G}_{n+1}$.

Let $\mathcal{H}(\mathcal{G}_n)$ be the set of minimal hitting sets of $\mathcal{G}_n$. For $H \in \mathcal{H}(\mathcal{G}_n)$, let $M_H = \prod_{p \in H} p$. Any multiple of $M_H$ hits $\mathcal{G}_n$. Let $m_n = \min \{ M_H \mid H \in \mathcal{H}(\mathcal{G}_n) \}$. Since any hitting set of $\mathcal{G}_{n+1}$ must also hit $\mathcal{G}_n$, $m_{n+1} \ge m_n$. Since $\mathcal{P}(a_1)$ is a hitting set, $m_n \le M_{\mathcal{P}(a_1)}$. Thus, $m_n$ stabilizes to a value $m$ for $n \ge N_1$. For $n \ge N_1$, $a_{n+1} \le a_n + m$ because the smallest multiple of the minimal hitting set $H^*$ with $M_{H^*} = m$ greater than $a_n$ is at most $a_n + m$.

Let $P_n = \bigcup_{S \in \mathcal{G}_n} S$. If $\mathcal{P}(a_{n+1})$ is a minimal element of $\mathcal{G}_{n+1}$, then for every $q \in \mathcal{P}(a_{n+1})$, there exists $S_q \in \mathcal{G}_n$ such that $\mathcal{P}(a_{n+1}) \cap S_q = \{q\}$. This implies $q \in S_q \subseteq P_n$, so $\mathcal{P}(a_{n+1}) \subseteq P_n$. If $\mathcal{P}(a_{n+1})$ is not a minimal element, then $\mathcal{G}_{n+1} = \mathcal{G}_n$ unless $\mathcal{P}(a_{n+1})$ is a subset of some $S \in \mathcal{G}_n$, in which case $P_{n+1} \subseteq P_n$. Thus, for $n \ge N_1$, $P_n$ is a non-increasing sequence of finite sets, which must stabilize to a set $P$ for $n \ge N_2$.

Since $\mathcal{G}_n$ is a family of subsets of the finite set $P$ for $n \ge N_2$, we consider the stabilization of $\mathcal{G}_n$. A set $\mathcal{P}(a_{n+1})$ can only be a minimal element of $\mathcal{G}_{n+1}$ if it is a minimal hitting set for $\mathcal{G}_n$. Any minimal hitting set for $\mathcal{G}_n$ must be a subset of $P$ because every $S \in \mathcal{G}_n$ is a subset of $P$. Thus, for $\mathcal{P}(a_{n+1})$ to be a minimal element, $a_{n+1}$ must be $P$-smooth (all prime factors in $P$). However, the gap between $P$-smooth numbers grows as $a_n \to \infty$. Since $a_{n+1} \le a_n + m$, for sufficiently large $n \ge N_3$, $a_{n+1}$ cannot be $P$-smooth unless $\mathcal{P}(a_{n+1})$ is already a subset of some $S \in \mathcal{G}_n$. In either case, $\mathcal{G}_n$ must eventually stabilize to a constant family $\mathcal{G}$ for $n \ge N$.

Once $\mathcal{G}_n = \mathcal{G}$, the sequence $(a_n)_{n \ge N}$ consists of the integers in increasing order that belong to the set $C = \{ x \in \mathbb{Z}^+ \mid \mathcal{P}(x) \text{ is a hitting set for } \mathcal{G} \}$. This property depends only on the residue of $x$ modulo $M = \prod_{p \in P} p$. Thus $C$ is a union of congruence classes modulo $M$. The sequence of gaps $a_{n+1} - a_n$ depends only on $a_n \pmod M$. Since there are only $M$ possible residues, the sequence $a_n \pmod M$ is eventually periodic. This implies there exist $T$ and $L$ such that $a_{n+T} = a_n + L$ for all $n \ge N$.
