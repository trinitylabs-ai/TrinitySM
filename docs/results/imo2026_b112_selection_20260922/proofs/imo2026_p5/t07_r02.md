To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for all $x, y > 0$,
$$\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)},$$
we proceed as follows.

**1. Deriving a functional equation**
Setting $x = f(y)$ in the given chain of inequalities, we obtain:
$$\sqrt{\frac{f(y)^2 + f(y)^2}{2}} \ge \frac{f(f(y)) + y}{2} \ge \sqrt{f(y) f(y)} \implies f(y) \ge \frac{f(f(y)) + y}{2} \ge f(y).$$
This forces equality throughout, so $f(f(y)) = 2f(y) - y$ for all $y > 0$.
Let $c(x) = f(x) - x$. Then $f(x) = x + c(x)$. The equation $f(f(x)) = 2f(x) - x$ becomes:
$$f(x) + c(f(x)) = 2(x + c(x)) - x = x + 2c(x) \implies x + c(x) + c(f(x)) = x + 2c(x) \implies c(f(x)) = c(x).$$
Iterating this, we have $f^{(n)}(x) = x + n c(x)$. Since the codomain of $f$ is $\mathbb{R}_{>0}$, we must have $x + n c(x) > 0$ for all $n \in \mathbb{N}$ and $x > 0$, which implies $c(x) \ge 0$ for all $x > 0$.

**2. Establishing bounds on $c(x)$**
Let $z = f(y)$. Then $y = z - c(y) = z - c(z)$ because $c(y) = c(f(y)) = c(z)$.
Substituting these into the first inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$:
$$\sqrt{\frac{x^2 + z^2}{2}} \ge \frac{x + c(x) + z - c(z)}{2} \implies c(x) - c(z) \le \sqrt{2x^2 + 2z^2} - (x + z).$$
Let $h(x, z) = \sqrt{2x^2 + 2z^2} - (x + z)$.
Substituting into the second inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$:
$$\frac{x + c(x) + z - c(z)}{2} \ge \sqrt{xz} \implies c(z) - c(x) \le x + z - 2\sqrt{xz} = (\sqrt{x} - \sqrt{z})^2.$$
Let $g(x, z) = (\sqrt{x} - \sqrt{z})^2$.
Thus, for any $x > 0$ and $z \in \text{Im}(f)$, we have $-g(x, z) \le c(x) - c(z) \le h(x, z)$.

**3. Proving $c(x)$ is constant**
Fix $z_0 \in \text{Im}(f)$. As $x \to z_0$, both $g(x, z_0) \to 0$ and $h(x, z_0) \to 0$. By the Squeeze Theorem, $\lim_{x \to z_0} c(x) = c(z_0)$. Thus $c$ is continuous at every point of $\text{Im}(f)$. Since $f(x) = x + c(x)$, $f$ is also continuous at every point of $\text{Im}(f)$.

Now, let $z_1, z_2 \in \text{Im}(f)$. Then $z_1 + n c(z_1)$ and $z_2 + m c(z_2)$ are also in $\text{Im}(f)$ for all $n, m \in \mathbb{N}$. Since $c(z + n c(z)) = c(z)$, we have:
$$|c(z_1) - c(z_2)| = |c(z_1 + n c(z_1)) - c(z_2 + m c(z_2))| \le \max(g(z_1 + n c(z_1), z_2 + m c(z_2)), h(z_1 + n c(z_1), z_2 + m c(z_2))).$$
If $c(z_1) = c > 0$ and $c(z_2) = c' > 0$, we can choose $n, m \in \mathbb{N}$ such that $z_1 + nc$ and $z_2 + mc'$ are arbitrarily close (this is possible because the set $\{nc - mc' : n, m \in \mathbb{N}\}$ is dense in $\mathbb{R}$ if $c/c'$ is irrational, and can be made exactly $z_2 - z_1$ or close to it if $c/c'$ is rational). As $z_1 + nc \to z_2 + mc'$, both $g$ and $h$ tend to 0. This implies $|c - c'| = 0$, so $c(z)$ is constant on the set $S = \{z \in \text{Im}(f) : c(z) > 0\}$. Let this constant be $c > 0$.

If there exists $z_2 \in \text{Im}(f)$ such that $c(z_2) = 0$, then for any $z_1 \in S$, we have $c(z_1) - c(z_2) = c \le h(z_1, z_2)$. Since $c(z_2) = 0$, $f$ is continuous at $z_2$, so $\text{Im}(f)$ contains points $z_1$ arbitrarily close to $z_2$. As $z_1 \to z_2$, $h(z_1, z_2) \to 0$, which contradicts $c \le h(z_1, z_2)$ for $c > 0$.
Thus, either $c(z) = 0$ for all $z \in \text{Im}(f)$ or $c(z) = c > 0$ for all $z \in \text{Im}(f)$. In either case, $c$ is constant on $\text{Im}(f)$.
Since $c(x) = c(f(x))$ and $f(x) \in \text{Im}(f)$, it follows that $c(x)$ is constant for all $x > 0$. Let $c(x) = c$ for $c \ge 0$.

**4. Verification**
Substituting $f(x) = x + c$ with $c \ge 0$ into the original inequalities:
- $\sqrt{\frac{x^2 + (y+c)^2}{2}} \ge \frac{x+c+y}{2} \iff 2x^2 + 2(y+c)^2 \ge (x+y+c)^2 \iff (x - (y+c))^2 \ge 0$.
- $\frac{x+c+y}{2} \ge \sqrt{x(y+c)} \iff (x+y+c)^2 \ge 4x(y+c) \iff (x - (y+c))^2 \ge 0$.
Both are true for all $x, y > 0$ and $c \ge 0$.

The solutions are $f(x) = x + c$ for any constant $c \ge 0$.
