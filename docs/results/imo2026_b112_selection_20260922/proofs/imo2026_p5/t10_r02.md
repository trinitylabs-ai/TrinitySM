To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we analyze the given inequalities. Let $A(x, y) = \sqrt{\frac{x^2 + f(y)^2}{2}}$, $B(x, y) = \frac{f(x) + y}{2}$, and $C(x, y) = \sqrt{x f(y)}$. The condition is $A \ge B \ge C$. Since all terms are positive, we square them:
(i) $A^2 \ge B^2 \implies 2x^2 + 2f(y)^2 \ge (f(x) + y)^2$
(ii) $B^2 \ge C^2 \implies (f(x) + y)^2 \ge 4x f(y)$

Note that $A^2 - C^2 = \frac{x^2 + f(y)^2}{2} - x f(y) = \frac{(x - f(y))^2}{2}$.
If $x = f(y)$, then $A^2 - C^2 = 0$. Since $A \ge B \ge C$, we must have $A = B = C$. In particular, $B = C$ implies:
\[ \frac{f(f(y)) + y}{2} = \sqrt{f(y) f(y)} = f(y) \implies f(f(y)) = 2f(y) - y. \]
Let $c(y) = f(y) - y$. Then $f(f(y)) = f(y) + c(f(y))$, so $2f(y) - y = f(y) + c(f(y))$, which implies $c(f(y)) = f(y) - y = c(y)$. By induction, $c(f^{(n)}(y)) = c(y)$ for all $n \in \mathbb{N}$, where $f^{(n)}$ denotes the $n$-th iterate of $f$. Also, $f^{(n)}(y) = y + nc(y)$. Since the codomain of $f$ is $\mathbb{R}_{>0}$, we must have $y + nc(y) > 0$ for all $n \in \mathbb{N}$, which implies $c(y) \ge 0$ for all $y > 0$.

If $c(y) = 0$ for all $y > 0$, then $f(x) = x$ for all $x > 0$. If there exists $y_0 > 0$ such that $c(y_0) > 0$, let $c = c(y_0)$. Then $f^{(n)}(y_0) = y_0 + nc$. Let $y_n = f^{(n)}(y_0)$.
From (ii), $f(x) \ge 2\sqrt{x f(y)} - y$. Substituting $y = y_n$:
\[ f(x) \ge 2\sqrt{x(y_n + c)} - y_n. \]
Let $z_n = y_n + c = y_0 + (n+1)c$. Then $y_n = z_n - c$, so $f(x) \ge 2\sqrt{x z_n} - z_n + c$.
For a fixed $x$, we can choose $n$ such that $z_n \le x < z_{n+1}$. Then $z_n \in (x-c, x]$. The function $g(z) = 2\sqrt{xz} - z$ is increasing on $(0, x)$, so $g(z_n) \ge g(x-c)$. Thus:
\[ f(x) \ge 2\sqrt{x(x-c)} - (x-c) + c = 2\sqrt{x^2 - xc} - x + 2c. \]
As $x \to \infty$, $2\sqrt{x^2 - xc} - x = 2x(1 - \frac{c}{2x} - \frac{c^2}{8x^2} + O(x^{-3})) - x = x - c - \frac{c^2}{4x} + O(x^{-2})$.
Thus, $f(x) \ge x + c - \frac{c^2}{4x} + O(x^{-2})$, implying $\liminf_{x \to \infty} (f(x) - x) \ge c$.

From (i), $f(x) \le \sqrt{2x^2 + 2f(y)^2} - y$. Substituting $y = y_n$:
\[ f(x) \le \sqrt{2x^2 + 2(y_n + c)^2} - y_n = \sqrt{2x^2 + 2z_n^2} - z_n + c. \]
The function $h(z) = \sqrt{2x^2 + 2z^2} - z$ has a minimum at $z = x$ with $h(x) = x$. Since $z_n \in (x-c, x+c]$, $h(z_n) \le \max(h(x-c), h(x+c))$.
As $x \to \infty$, $h(x \pm c) = \sqrt{2x^2 + 2(x \pm c)^2} - (x \pm c) = \sqrt{4x^2 \pm 4xc + 2c^2} - x \mp c = 2x\sqrt{1 \pm \frac{c}{x} + \frac{c^2}{2x^2}} - x \mp c = x + \frac{c^2}{4x} + O(x^{-2})$.
Thus, $f(x) \le x + c + \frac{c^2}{4x} + O(x^{-2})$, implying $\limsup_{x \to \infty} (f(x) - x) \le c$.

Therefore, for any $y_0$ such that $c(y_0) > 0$, the limit $\lim_{x \to \infty} (f(x) - x)$ exists and equals $c(y_0)$. This means $c(y)$ must be the same constant $c$ for all $y$ such that $c(y) > 0$.
If $c(y) = 0$ for some $y$, then $f(y) = y$. Substituting this into (i) and (ii) for all $x > 0$:
$2\sqrt{xy} - y \le f(x) \le \sqrt{2x^2 + 2y^2} - y$.
For a fixed $x$, the value of $2\sqrt{xy} - y$ is maximized at $y=x$ with value $x$, and $\sqrt{2x^2 + 2y^2} - y$ is minimized at $y=x$ with value $x$. Thus $f(x) = x$ for all $x$, which is the case $c = 0$.
If $c(y) > 0$ for all $y$, then $c(y) = c$ for all $y$. In both cases, $f(x) = x + c$ for some $c \ge 0$.

Checking $f(x) = x + c$ in the original inequalities:
$A^2 - B^2 = \frac{x^2 + (y+c)^2}{2} - \frac{(x+y+c)^2}{4} = \frac{2x^2 + 2y^2 + 4yc + 2c^2 - (x^2 + y^2 + c^2 + 2xy + 2xc + 2yc)}{4} = \frac{(x-y-c)^2}{4} \ge 0$.
$B^2 - C^2 = \frac{(x+y+c)^2}{4} - x(y+c) = \frac{x^2 + y^2 + c^2 + 2xy + 2xc + 2yc - 4xy - 4xc}{4} = \frac{(x-y-c)^2}{4} \ge 0$.
Both are non-negative for all $x, y > 0$ and $c \ge 0$.

The functions satisfying the condition are $f(x) = x + c$ for any $c \ge 0$.
