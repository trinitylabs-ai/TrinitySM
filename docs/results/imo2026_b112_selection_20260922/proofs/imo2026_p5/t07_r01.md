To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we analyze the two given inequalities.

**1. Derivation of a Functional Identity**
The right inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ implies $f(x) \ge 2\sqrt{x f(y)} - y$.
The left inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$ implies $f(x) \le \sqrt{2(x^2 + f(y)^2)} - y$.
Substituting $x = f(y)$ into these two inequalities:
From the right: $f(f(y)) \ge 2\sqrt{f(y) f(y)} - y = 2f(y) - y$.
From the left: $f(f(y)) \le \sqrt{2(f(y)^2 + f(y)^2)} - y = \sqrt{4f(y)^2} - y = 2f(y) - y$.
Thus, for all $y > 0$, we have the identity:
\[ f(f(y)) = 2f(y) - y. \]

**2. Properties of $g(x) = f(x) - x$**
Let $g(x) = f(x) - x$. The identity $f(f(y)) = 2f(y) - y$ can be rewritten as:
\[ f(f(y)) - f(y) = f(y) - y \implies g(f(y)) = g(y). \]
By induction, the $n$-th iterate of $f$ is $f^{(n)}(y) = y + n g(y)$ for all $n \in \mathbb{N}$. Since the codomain of $f$ is $\mathbb{R}_{>0}$, we must have $y + n g(y) > 0$ for all $n \in \mathbb{N}$ and all $y > 0$. This implies $g(y) \ge 0$ for all $y > 0$. Thus $f(x) \ge x$ for all $x > 0$.

**3. Constraining the Range of $g$**
Let $S = f(\mathbb{R}_{>0})$ be the range of $f$. For any $x > 0$ and $z \in S$, let $z = f(y)$. Then $y = z - g(y) = z - g(z)$ because $g(f(y)) = g(y)$. Substituting $z$ and $y$ into the original inequalities:
\[ 2\sqrt{xz} - (z - g(z)) \le x + g(x) \le \sqrt{2(x^2 + z^2)} - (z - g(z)). \]
Rearranging, we obtain:
\[ g(z) - (\sqrt{z} - \sqrt{x})^2 \le g(x) \le g(z) + \sqrt{2(x^2 + z^2)} - (x + z). \]
Let $h(x, z) = \sqrt{2(x^2 + z^2)} - (x + z)$. Note that $h(x, z) \ge 0$ and $h(x, z) \to 0$ as $z \to x$.
For any $z_1, z_2 \in S$, let $c_1 = g(z_1)$ and $c_2 = g(z_2)$. If $c_1, c_2 > 0$, then $u_n = z_1 + n c_1 \in S$ and $v_m = z_2 + m c_2 \in S$ for all $n, m \in \mathbb{N}$, with $g(u_n) = c_1$ and $g(v_m) = c_2$. For any $n$, we can choose $m$ such that $|u_n - v_m| \le c_2$. Then
\[ |c_1 - c_2| \le \max(h(u_n, v_m), (\sqrt{u_n} - \sqrt{v_m})^2). \]
As $n \to \infty$, $u_n \to \infty$ and $v_m \to \infty$. Since $|u_n - v_m|$ is bounded, $h(u_n, v_m) \to 0$ and $(\sqrt{u_n} - \sqrt{v_m})^2 \to 0$. Thus $c_1 = c_2$.
This implies that $g(S)$ contains at most one positive value $c > 0$. Since $g(\mathbb{R}_{>0}) = g(S)$ (because $g(x) = g(f(x))$), we have $g(y) \in \{0, c\}$ for all $y > 0$.

**4. Proving $g$ is Constant**
Suppose $g$ takes both values $0$ and $c > 0$. Let $Z = \{z \in \mathbb{R}_{>0} : g(z) = 0\}$.
If $z_1 \in Z$, then $f(z_1) = z_1$. Substituting $x = z_1$ into the right inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ gives:
\[ \frac{z_1 + y}{2} \ge \sqrt{z_1(y + g(y))} \implies g(y) \le \frac{(z_1 - y)^2}{4 z_1}. \]
If $g(y) = c$, then $c \le \frac{(z_1 - y)^2}{4 z_1}$, so $|z_1 - y| \ge 2\sqrt{z_1 c}$. This means the interval $J_{z_1} = (z_1 - 2\sqrt{z_1 c}, z_1 + 2\sqrt{z_1 c}) \cap \mathbb{R}_{>0}$ is contained in $Z$.
Since $Z$ contains an interval, we can iteratively apply this property. If $(a, b) \subset Z$, then for any $z \in (a, b)$, $z + 2\sqrt{zc} \in Z$. The sequence $b_{n+1} = b_n + 2\sqrt{b_n c}$ diverges to $\infty$, so $Z$ must contain an interval $(L, \infty)$ for some $L > 0$.
However, if $g(y) = c$, then for all $z \in Z$, we must have $c \le \frac{(z - y)^2}{4 z}$, which simplifies to $z^2 - 2z(y + 2c) + y^2 \ge 0$. The roots of this quadratic in $z$ are $z = y + 2c \pm 2\sqrt{yc + c^2} = (\sqrt{y+c} \pm \sqrt{c})^2$. Thus, $Z \cap ((\sqrt{y+c} - \sqrt{c})^2, (\sqrt{y+c} + \sqrt{c})^2) = \emptyset$.
For sufficiently large $y$, the interval $((\sqrt{y+c} - \sqrt{c})^2, (\sqrt{y+c} + \sqrt{c})^2)$ is contained in $(L, \infty)$. This contradicts the fact that $Z$ contains $(L, \infty)$.
Thus, $g$ must be constant.

**5. Final Verification**
If $g(x) = c$, then $f(x) = x + c$ for some $c \ge 0$. Substituting this into the original inequalities:
\[ \sqrt{\frac{x^2 + (y+c)^2}{2}} \ge \frac{x+c+y}{2} \ge \sqrt{x(y+c)}. \]
The left inequality is the Root-Mean-Square vs Arithmetic-Mean inequality, and the right inequality is the Arithmetic-Mean vs Geometric-Mean inequality. Both are always true for $x, y > 0$ and $c \ge 0$.

The solutions are $f(x) = x + c$ for any $c \ge 0$.
