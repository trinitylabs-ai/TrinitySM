To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
$$\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)},$$
we analyze the constraints imposed by these inequalities.

**1. Verification of Candidate Solutions**
Let $f(x) = x + c$ for some constant $c \ge 0$. For $f$ to map $\mathbb{R}_{>0}$ to $\mathbb{R}_{>0}$, we must have $c \ge 0$.
Substituting $f(x) = x + c$ into the right-hand inequality:
$$\frac{x + c + y}{2} \ge \sqrt{x(y + c)}.$$
This is the Arithmetic Mean-Geometric Mean (AM-GM) inequality for $x$ and $y + c$, which holds for all $x, y > 0$ and $c \ge 0$.
Substituting $f(x) = x + c$ into the left-hand inequality:
$$\sqrt{\frac{x^2 + (y + c)^2}{2}} \ge \frac{x + c + y}{2}.$$
This is the Root Mean Square-Arithmetic Mean (RMS-AM) inequality for $x$ and $y + c$, which holds for all $x, y > 0$ and $c \ge 0$.
Thus, $f(x) = x + c$ for any $c \ge 0$ is a solution.

**2. Derivation of Functional Properties**
For any $y > 0$, let $x = f(y)$. The given inequalities become:
$$\sqrt{\frac{f(y)^2 + f(y)^2}{2}} \ge \frac{f(f(y)) + y}{2} \ge \sqrt{f(y) f(y)} \implies f(y) \ge \frac{f(f(y)) + y}{2} \ge f(y).$$
This forces $f(f(y)) + y = 2f(y)$. Let $c(y) = f(y) - y$. The equation $f(f(y)) - f(y) = f(y) - y$ implies $c(f(y)) = c(y)$.
By induction, $f^{(n)}(y) = y + n c(y)$ for all $n \in \mathbb{N}$. Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we must have $y + n c(y) > 0$ for all $n \in \mathbb{N}$ and $y > 0$, which implies $c(y) \ge 0$ for all $y > 0$.

Next, consider the right-hand inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$. Rearranging for $f(x)$:
$$f(x) \ge 2\sqrt{x f(y)} - y.$$
Substituting $f(x) = x + c(x)$ and $y = f(y) - c(y)$:
$$x + c(x) \ge 2\sqrt{x f(y)} - (f(y) - c(y)) \implies c(x) \ge c(y) - (f(y) - 2\sqrt{x f(y)} + x) = c(y) - (\sqrt{f(y)} - \sqrt{x})^2.$$
Let $z = f(y)$. Since $c(z) = c(f(y)) = c(y)$, we have $c(x) \ge c(z) - (\sqrt{z} - \sqrt{x})^2$ for all $x > 0$ and $z \in \text{Range}(f)$.
If $x$ is also in the range of $f$, we have $c(z) \ge c(x) - (\sqrt{x} - \sqrt{z})^2$. Thus, for all $x, z \in \text{Range}(f)$:
$$|c(x) - c(z)| \le (\sqrt{x} - \sqrt{z})^2.$$

**3. Constancy of $c(x)$ on $S$**
Let $S = \{x \in \mathbb{R}_{>0} : c(x) > 0\}$ and $Z = \{x \in \mathbb{R}_{>0} : c(x) = 0\}$.
Suppose $S$ is non-empty. For any $y_1, y_2 \in S$, the sequences $z_{1,n} = f^{(n)}(y_1) = y_1 + n c(y_1)$ and $z_{2,m} = f^{(m)}(y_2) = y_2 + m c(y_2)$ are in $\text{Range}(f)$ for $n, m \ge 1$.
Using the range inequality:
$$|c(y_1) - c(y_2)| = |c(z_{1,n}) - c(z_{2,m})| \le (\sqrt{z_{1,n}} - \sqrt{z_{2,m}})^2 = \frac{(z_{1,n} - z_{2,m})^2}{(\sqrt{z_{1,n}} + \sqrt{z_{2,m}})^2}.$$
For a fixed $n$, we can choose $m$ such that $z_{2,m} \le z_{1,n} < z_{2,m+1}$, which implies $0 \le z_{1,n} - z_{2,m} < c(y_2)$. Thus, $|z_{1,n} - z_{2,m}| \le \max(c(y_1), c(y_2))$. As $n \to \infty$, $z_{1,n} \to \infty$ and $z_{2,m} \to \infty$, so the right-hand side tends to 0. Thus, $c(y_1) = c(y_2)$ for all $y_1, y_2 \in S$. Let this constant value be $c > 0$.

**4. Analysis of the Fixed-Point Set $Z$**
Suppose $Z$ is non-empty. For any $z \in Z$ and $x \in S$, we have $f(z) = z \in \text{Range}(f)$ and $f(x) = x + c \in \text{Range}(f)$. Applying the range inequality:
$$|c(f(x)) - c(f(z))| \le (\sqrt{f(x)} - \sqrt{f(z)})^2 \implies |c - 0| \le (\sqrt{x + c} - \sqrt{z})^2.$$
This implies $\sqrt{c} \le |\sqrt{x + c} - \sqrt{z}|$.
Case A: $\sqrt{x + c} \ge \sqrt{z} + \sqrt{c} \implies x + c \ge z + c + 2\sqrt{zc} \implies x \ge z + 2\sqrt{zc}$.
Case B: $\sqrt{x + c} \le \sqrt{z} - \sqrt{c} \implies x + c \le z + c - 2\sqrt{zc} \implies x \le z - 2\sqrt{zc}$.
Thus, for any $z \in Z$, the interval $(z - 2\sqrt{zc}, z + 2\sqrt{zc}) \cap \mathbb{R}_{>0}$ contains no elements of $S$. Since $S \cup Z = \mathbb{R}_{>0}$, this interval must be a subset of $Z$.
This implies that $Z$ is an open set in $\mathbb{R}_{>0}$. If $Z$ is non-empty, let $z_0 \in Z$. Then $Z$ contains $I_0 = (z_0 - 2\sqrt{z_0 c}, z_0 + 2\sqrt{z_0 c}) \cap \mathbb{R}_{>0}$. We can pick $z_1 \in Z$ arbitrarily close to the right endpoint $z_0 + 2\sqrt{z_0 c}$, and the interval around $z_1$ will extend the set $Z$ further to the right. By induction, $Z$ is not bounded above. Similarly, $Z$ can be extended to the left until it covers $(0, \infty)$. Thus, $Z = \mathbb{R}_{>0}$.
Consequently, either $S = \emptyset$ (so $c(x) = 0$ for all $x$) or $Z = \emptyset$ (so $c(x) = c$ for all $x$).

In both cases, $f(x) = x + c$ for some constant $c \ge 0$.
The functions are $f(x) = x + c$ for any $c \ge 0$.
