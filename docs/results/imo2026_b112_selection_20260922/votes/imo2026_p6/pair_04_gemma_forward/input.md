# Problem

IMO 2026 Problem 6. Let (a_n) be an infinite sequence of positive integers greater than 1. Suppose that for every positive integer n, a_{n+1} is the smallest positive integer greater than a_n such that gcd(a_{n+1},a_i) > 1 for every i = 1,...,n. Prove that there exist positive integers T and L such that a_{n+T} = a_n + L for every positive integer n. Here gcd(x,y) denotes the greatest common divisor of positive integers x,y.

# Proof A

1: Let $\mathcal{P}(m)$ denote the set of prime factors of $m$. The condition $\gcd(x, a_i) > 1$ for all $i=1, \dots, n$ is equivalent to $\mathcal{P}(x) \cap \mathcal{P}(a_i) \neq \emptyset$ for all $i=1, \dots, n$. Let $\mathcal{F}_n = \{\mathcal{P}(a_1), \dots, \mathcal{P}(a_n)\}$ be the family of sets of prime factors of the first $n$ terms. Let $\mathcal{G}_n$ be the collection of minimal elements of $\mathcal{F}_n$ under inclusion. An integer $x$ satisfies $\gcd(x, a_i) > 1$ for all $i=1, \dots, n$ if and only if $\mathcal{P}(x)$ is a hitting set for $\mathcal{G}_n$ (i.e., $\mathcal{P}(x) \cap S \neq \emptyset$ for all $S \in \mathcal{G}_n$).
2: 
3: By definition, $a_{n+1}$ is the smallest integer $x > a_n$ such that $\mathcal{P}(x)$ hits $\mathcal{G}_n$. The family $\mathcal{G}_{n+1}$ consists of the minimal elements of $\mathcal{G}_n \cup \{\mathcal{P}(a_{n+1})\}$.
4: 
5: First, we prove by induction that $\mathcal{G}_n$ is an intersecting family. For $n=1$, $\mathcal{G}_1 = \{\mathcal{P}(a_1)\}$ is vacuously intersecting. Assume $\mathcal{G}_n$ is intersecting. Since $\mathcal{P}(a_{n+1})$ hits every $S \in \mathcal{G}_n$, $\mathcal{P}(a_{n+1}) \cap S \neq \emptyset$ for all $S \in \mathcal{G}_n$. Any two elements $S, S' \in \mathcal{G}_{n+1}$ either both belong to $\mathcal{G}_n$ (intersecting by induction), or one is a subset of $\mathcal{P}(a_{n+1})$ and the other is in $\mathcal{G}_n$. If $S' \subseteq \mathcal{P}(a_{n+1})$ and $S' \in \mathcal{G}_{n+1}$, then $S'$ must either be in $\mathcal{G}_n$ or be $\mathcal{P}(a_{n+1})$ itself. In either case, since $\mathcal{P}(a_{n+1})$ hits every $S \in \mathcal{G}_n$, the intersection is non-empty. Thus $\mathcal{G}_{n+1}$ is intersecting.
6: 
7: Next, we show $\mathcal{P}(a_1)$ is always a hitting set for $\mathcal{G}_n$. For $n=1$, this is trivial. Assume $\mathcal{P}(a_1)$ hits $\mathcal{G}_n$. Then there exists $S \in \mathcal{G}_n$ such that $S \subseteq \mathcal{P}(a_1)$. Since $\mathcal{P}(a_{n+1})$ hits $S$, $\mathcal{P}(a_{n+1}) \cap \mathcal{P}(a_1) \neq \emptyset$. Thus $\mathcal{P}(a_1)$ hits $\mathcal{P}(a_{n+1})$ and all $S \in \mathcal{G}_n$, making it a hitting set for $\mathcal{G}_{n+1}$.
8: 
9: Let $\mathcal{H}(\mathcal{G}_n)$ be the set of minimal hitting sets of $\mathcal{G}_n$. For $H \in \mathcal{H}(\mathcal{G}_n)$, let $M_H = \prod_{p \in H} p$. Any multiple of $M_H$ hits $\mathcal{G}_n$. Let $m_n = \min \{ M_H \mid H \in \mathcal{H}(\mathcal{G}_n) \}$. Since any hitting set of $\mathcal{G}_{n+1}$ must also hit $\mathcal{G}_n$, $m_{n+1} \ge m_n$. Since $\mathcal{P}(a_1)$ is a hitting set, $m_n \le M_{\mathcal{P}(a_1)}$. Thus, $m_n$ stabilizes to a value $m$ for $n \ge N_1$. For $n \ge N_1$, $a_{n+1} \le a_n + m$ because the smallest multiple of the minimal hitting set $H^*$ with $M_{H^*} = m$ greater than $a_n$ is at most $a_n + m$.
10: 
11: Let $P_n = \bigcup_{S \in \mathcal{G}_n} S$. If $\mathcal{P}(a_{n+1})$ is a minimal element of $\mathcal{G}_{n+1}$, then for every $q \in \mathcal{P}(a_{n+1})$, there exists $S_q \in \mathcal{G}_n$ such that $\mathcal{P}(a_{n+1}) \cap S_q = \{q\}$. This implies $q \in S_q \subseteq P_n$, so $\mathcal{P}(a_{n+1}) \subseteq P_n$. If $\mathcal{P}(a_{n+1})$ is not a minimal element, then $\mathcal{G}_{n+1} = \mathcal{G}_n$ unless $\mathcal{P}(a_{n+1})$ is a subset of some $S \in \mathcal{G}_n$, in which case $P_{n+1} \subseteq P_n$. Thus, for $n \ge N_1$, $P_n$ is a non-increasing sequence of finite sets, which must stabilize to a set $P$ for $n \ge N_2$.
12: 
13: Since $\mathcal{G}_n$ is a family of subsets of the finite set $P$ for $n \ge N_2$, we consider the stabilization of $\mathcal{G}_n$. A set $\mathcal{P}(a_{n+1})$ can only be a minimal element of $\mathcal{G}_{n+1}$ if it is a minimal hitting set for $\mathcal{G}_n$. Any minimal hitting set for $\mathcal{G}_n$ must be a subset of $P$ because every $S \in \mathcal{G}_n$ is a subset of $P$. Thus, for $\mathcal{P}(a_{n+1})$ to be a minimal element, $a_{n+1}$ must be $P$-smooth (all prime factors in $P$). However, the gap between $P$-smooth numbers grows as $a_n \to \infty$. Since $a_{n+1} \le a_n + m$, for sufficiently large $n \ge N_3$, $a_{n+1}$ cannot be $P$-smooth unless $\mathcal{P}(a_{n+1})$ is already a subset of some $S \in \mathcal{G}_n$. In either case, $\mathcal{G}_n$ must eventually stabilize to a constant family $\mathcal{G}$ for $n \ge N$.
14: 
15: Once $\mathcal{G}_n = \mathcal{G}$, the sequence $(a_n)_{n \ge N}$ consists of the integers in increasing order that belong to the set $C = \{ x \in \mathbb{Z}^+ \mid \mathcal{P}(x) \text{ is a hitting set for } \mathcal{G} \}$. This property depends only on the residue of $x$ modulo $M = \prod_{p \in P} p$. Thus $C$ is a union of congruence classes modulo $M$. The sequence of gaps $a_{n+1} - a_n$ depends only on $a_n \pmod M$. Since there are only $M$ possible residues, the sequence $a_n \pmod M$ is eventually periodic. This implies there exist $T$ and $L$ such that $a_{n+T} = a_n + L$ for all $n \ge N$.

# Proof B

1: Let $S = \{a_1, a_2, \dots\}$ be the set of terms of the sequence. By the definition of the sequence, $a_{n+1}$ is the smallest integer greater than $a_n$ such that $\gcd(a_{n+1}, a_i) > 1$ for all $i = 1, \dots, n$. This implies that for any $n > 1$, $\gcd(a_n, a_i) > 1$ for all $i < n$. Furthermore, for any $j > n$, $a_j$ is chosen such that $\gcd(a_j, a_i) > 1$ for all $i < j$, so $\gcd(a_j, a_n) > 1$. Thus, any two elements of $S$ share a common factor.
2: 
3: Conversely, if $x$ is a positive integer such that $\gcd(x, a_n) > 1$ for all $n \ge 1$, then $x$ satisfies the condition $C_n(x) : \gcd(x, a_i) > 1$ for all $i = 1, \dots, n$ for every $n$. If $x \notin S$, there would exist $n$ such that $a_n < x < a_{n+1}$. But $x$ satisfies $C_n(x)$, and $a_{n+1}$ is the smallest integer greater than $a_n$ satisfying $C_n(x)$, so $a_{n+1} \le x$, a contradiction. Thus, $S = \{x \in \mathbb{Z}^+ : \forall s \in S, \gcd(x, s) > 1\}$.
4: 
5: Let $P(x)$ denote the set of prime factors of $x$. The condition $x \in S$ is equivalent to $P(x) \cap P(s) \neq \emptyset$ for all $s \in S$. Thus, $P(x)$ is a hitting set for the family of sets $\mathcal{F} = \{P(s) : s \in S\}$. Let $\mathcal{M}$ be the collection of minimal hitting sets of $\mathcal{F}$. Then $x \in S$ if and only if $P(x)$ contains some $M \in \mathcal{M}$. This is equivalent to saying that $x$ is a multiple of $m_M = \prod_{p \in M} p$ for some $M \in \mathcal{M}$. Thus, $S = \bigcup_{M \in \mathcal{M}} m_M \mathbb{Z}$.
6: 
7: Since $a_1 \in S$, $P(a_1)$ is a hitting set for $\mathcal{F}$. Any minimal hitting set $M \in \mathcal{M}$ must satisfy $|M| \le |P(a_1)| = k$. Since $m_M, m_{M'} \in S$ for any $M, M' \in \mathcal{M}$, we have $\gcd(m_M, m_{M'}) > 1$, so $M \cap M' \neq \emptyset$. Thus, $\mathcal{M}$ is an intersecting family of sets of size at most $k$.
8: 
9: We prove by induction on $k$ that $\mathcal{M}$ must be finite.
10: Base case: $k=1$. Every $M \in \mathcal{M}$ is a singleton $\{p\}$. Since any two such sets must intersect, all $M \in \mathcal{M}$ must be the same singleton. Thus $\mathcal{M}$ is finite.
11: Inductive step: Assume that for any intersecting family $\mathcal{G}$, the collection of its minimal hitting sets is finite provided the hitting sets have size at most $k-1$. Let $\mathcal{F}$ be an intersecting family (as is the case for the prime factor sets of $S$), and let $\mathcal{M}$ be the collection of its minimal hitting sets, with $|M| \le k$ for all $M \in \mathcal{M}$.
12: If $\mathcal{M}$ is empty, it is finite. Otherwise, pick $M_1 \in \mathcal{M}$. Since $\mathcal{M}$ is an intersecting family, every $M \in \mathcal{M}$ must intersect $M_1$. Thus, $\mathcal{M} = \bigcup_{p \in M_1} \mathcal{M}_p$, where $\mathcal{M}_p = \{M \in \mathcal{M} : p \in M\}$.
13: For each $p \in M_1$, let $\mathcal{M}'_p = \{M \setminus \{p\} : M \in \mathcal{M}_p\}$. We claim that $\mathcal{M}'_p$ is the collection of minimal hitting sets for the family $\mathcal{F}_p = \{P(s) \in \mathcal{F} : p \notin P(s)\}$.
14: First, for any $M \in \mathcal{M}_p$ and any $P(s) \in \mathcal{F}_p$, we have $M \cap P(s) \neq \emptyset$. Since $p \notin P(s)$, it must be that $(M \setminus \{p\}) \cap P(s) \neq \emptyset$. Thus $M \setminus \{p\}$ is a hitting set for $\mathcal{F}_p$.
15: Second, $M \setminus \{p\}$ is minimal. If there were a proper subset $H \subset M \setminus \{p\}$ hitting $\mathcal{F}_p$, then $H \cup \{p\}$ would hit all $P(s) \in \mathcal{F}$ (hitting those in $\mathcal{F}_p$ via $H$ and those containing $p$ via $\{p\}$). This would contradict the minimality of $M$ in $\mathcal{M}$.
16: Since $\mathcal{F}_p \subseteq \mathcal{F}$, $\mathcal{F}_p$ is an intersecting family. The sets in $\mathcal{M}'_p$ have size at most $k-1$. By the inductive hypothesis, $\mathcal{M}'_p$ is finite, which implies $\mathcal{M}_p$ is finite. Since $M_1$ is finite, $\mathcal{M}$ is a finite union of finite sets, hence finite.
17: 
18: Since $\mathcal{M}$ is finite, $S$ is a finite union of arithmetic progressions $m_M \mathbb{Z}$. Such a set is periodic. Let $L' = \text{lcm}_{M \in \mathcal{M}} (m_M)$. Then $x \in S \iff x + L' \in S$. Let $T$ be the number of elements of $S$ in the interval $[a_1, a_1 + L' - 1]$. Since $S$ is periodic with period $L'$, the increasing enumeration $a_n$ satisfies $a_{n+T} = a_n + L'$ for all $n \ge 1$. Thus, there exist positive integers $T$ and $L$ such that $a_{n+T} = a_n + L$ for every positive integer $n$.
