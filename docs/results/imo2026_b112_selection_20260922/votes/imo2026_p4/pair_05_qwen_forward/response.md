# Proof comparison

## Proof A
Established theorem: Shan-Yu can avoid $\theta$ indefinitely if $\theta/180^\circ \notin \mathbb{Q}$ or if $\theta \ge 120^\circ$. The proof claims Mulan wins for all rational $\theta < 120^\circ$, but this claim is not justified.
Claim gap: The rational $\theta < 120^\circ$ case contains a decisive defect. The argument reduces the game to a finite state space of integer triples and asserts Mulan can "always choose a cut... to avoid cycles" and force the winning state. This ignores the algebraic structure of the winning set $W = \{k\theta \mid k \in \mathbb{Z}^+\}$. For $\theta = 72^\circ$ (rational, $<120^\circ$, but $\neq 180^\circ/n$), $W=\{72^\circ, 144^\circ\}$ lacks the symmetry $180^\circ-\phi \in W \iff \phi \in W$. Shan-Yu can start with $(60^\circ,60^\circ,60^\circ)$ and always discard any triangle containing an angle in $W$, maintaining a state outside $W$ forever. The finite state argument provides no mechanism to overcome this asymmetry, making the sufficiency claim false.
Qualifications and supplied repairs: NONE. The defect is intrinsic to the submitted argument; no routine repair bridges the gap between the vague state-space claim and the actual game dynamics. The proof does not verify that Mulan can force entry into $W$ or navigate the state space against an optimal Shan-Yu.
Decisive checks: Lines 3-7 (irrational case) correctly identify that Shan-Yu can avoid a dense subgroup, though the notation is slightly loose. Lines 10-11 ($\theta \ge 120^\circ$) correctly show the equilateral triangle caps angles below $120^\circ$. Lines 12-16 (rational $<120^\circ$) fail verification: the claim that "Mulan can always force the maximum angle to change until it equals $m\delta$" is unsupported and contradicted by the $\theta=72^\circ$ counterexample where Shan-Yu's discard strategy strictly avoids $W$. The proof does not establish the stated iff condition.

## Proof B
Established theorem: Mulan can guarantee victory if and only if $\theta = 180^\circ/n$ for some integer $n \ge 2$.
Claim gap: NONE supported by checks. The argument covers both sufficiency and necessity with complete case analysis.
Qualifications and supplied repairs: Minor notational swap in line 15: cutting from the vertex with angle $\alpha$ yields the cut-angle interval $(\gamma, \beta+\gamma)$, not $(\beta, \gamma+\beta)$. Since $\alpha$ is the smallest angle, $\beta,\gamma \ge 60^\circ$, so the interval length is $\max(\beta,\gamma) \ge 60^\circ$ regardless. This does not affect the length argument or the conclusion. No substantive repairs were needed.
Decisive checks: Lines 3-6 correctly derive the valid range for the cut angle $\psi$ as an open interval of length equal to the opposite angle, correctly respecting the domain constraint that $P$ is not a vertex. Lines 13-18 (Case 1) correctly use the interval length $\ge 60^\circ \ge \theta$ to guarantee a multiple of $\theta$ lies strictly inside, and exploit the symmetry $\phi \in W \iff 180^\circ-\phi \in W$ (valid exactly when $\theta=180^\circ/n$) to force both child triangles into $W$. The induction on the multiplier $k$ correctly handles the "finitely many steps" requirement. Lines 20-29 (Case 2) exhaustively verify the four logical combinations for both children entering $W$; each combination algebraically implies an original angle is in $W$, contradicting the hypothesis. This rigorously proves Shan-Yu can avoid $W$ when $\theta \neq 180^\circ/n$. All steps are verified and logically airtight.

## Decision
Winner: B
Reason: Proof B provides a complete, rigorous, and correct solution. It correctly identifies $\theta = 180^\circ/n$ as the necessary and sufficient condition, using a precise interval-length argument for sufficiency and an exhaustive 4-case algebraic analysis for necessity. Proof A's claim that all rational $\theta < 120^\circ$ are winnable is mathematically false (e.g., $\theta = 72^\circ$), and its justification relies on an unjustified finite-state assertion that fails to account for the asymmetry of the winning angle set. B's case analysis directly addresses the core game mechanic (forcing both split triangles into the winning set), while A's argument collapses on the rational case. B is decisively superior.
