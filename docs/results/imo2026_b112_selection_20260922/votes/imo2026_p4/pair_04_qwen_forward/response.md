# Proof comparison

## Proof A
Established theorem: $\theta \ge 120^\circ \implies$ Shan-Yu can guarantee a draw (Mulan cannot win). $\theta \in \mathbb{Q} \cdot 180^\circ \cap (0, 120^\circ) \implies$ Mulan can guarantee victory.
Claim gap: The proof incorrectly asserts that irrational multiples of $180^\circ$ are losing positions for Mulan. The rationality condition is unnecessary; the true winning condition is simply $\theta < 120^\circ$. The argument for irrational $\theta$ fails to account for direct geometric construction of $\theta$ in a single cut.
Qualifications and supplied repairs: NONE credited to the submission. I independently verified that for any $\theta < 120^\circ$, Mulan wins in exactly one move from any initial triangle (if $\theta < 60^\circ$, cut any angle $\alpha \ge 60^\circ > \theta$ into $\theta$ and $\alpha-\theta$; if $60^\circ \le \theta < 120^\circ$, the minimum angle $\gamma \le 60^\circ \le \theta$, so $\gamma < \theta$ or the game has already ended; cut the opposite vertex $\alpha$ into $\alpha_1 = 180^\circ - \beta - \theta$ and $\alpha_2 = \theta - \gamma$, both strictly positive, making one new triangle contain $\theta$). This 1-move strategy is absent from the submission and was supplied solely to identify the gap.
Decisive checks: 
- Lines 10-11: VERIFIED. The equilateral triangle $(60^\circ,60^\circ,60^\circ)$ keeps all angles strictly below $120^\circ$ under any cut, correctly establishing $\theta \ge 120^\circ$ as a loss for Mulan. The inequality direction and boundary case are handled correctly.
- Lines 3-7: DEMONSTRATED DEFECT. The argument that Shan-Yu can avoid $\theta$ for irrational $\theta$ relies on the set $S = \{n\theta + m180^\circ\}$ and claims angles can be kept out of $S$. This fails because it ignores the immediate 1-move winning strategy. The density/linear independence reasoning is irrelevant to the geometric cut that directly produces $\theta$, and the quantifier order (Shan-Yu chooses $T_0$ first, then Mulan cuts) allows Mulan to force $\theta$ regardless of $S$.
- Lines 12-17: UNRESOLVED. The finite-state graph argument is schematic and lacks rigorous justification for reachability, but it correctly targets the $\theta < 120^\circ$ threshold. The conclusion matches the true boundary despite the flawed irrational case.

## Proof B
Established theorem: $\theta = \frac{180^\circ}{n}$ for integer $n \ge 2 \implies$ Mulan can guarantee victory.
Claim gap: The converse claim that these are the *only* winning values is false. The proof misses the entire continuous interval $(0, 120^\circ)$ and incorrectly restricts the solution to a discrete set. The converse argument fundamentally misreads the win condition and cut mechanics.
Qualifications and supplied repairs: NONE. The converse argument contains a structural defect that cannot be repaired without rewriting the core strategy.
Decisive checks:
- Lines 5-14: VERIFIED for the stated subset. The interval length argument correctly shows Mulan wins in one move when $\theta = 180^\circ/n$. The quantifier handling for $k_1$ and the positivity constraints are correct.
- Lines 16-24: DEMONSTRATED DEFECT. The proof assumes Shan-Yu can avoid the set $S = \{k\theta\}$ indefinitely if $\theta \neq 180^\circ/n$. This fails because Mulan wins if *either* resulting triangle contains $\theta$, not both. For $\theta = 100^\circ$ (not of the form $180^\circ/n$), Shan-Yu's equilateral triangle $(60^\circ,60^\circ,60^\circ)$ has no angles in $S$, but Mulan cuts a $60^\circ$ angle into $20^\circ$ and $40^\circ$. The new triangle $T_1 = (20^\circ, 60^\circ, 100^\circ)$ contains $\theta$, so Mulan wins immediately. Lines 19-23 analyze cases where both triangles must land in $S$ or derive conditions like $(n_1+n_2)\theta=180^\circ$, which is a stricter condition than the problem requires. The domain of valid cuts is misapplied, invalidating the converse.

## Decision
Winner: A
Reason: Proof A correctly identifies the critical phase transition at $\theta = 120^\circ$ and provides a valid, rigorous defense for $\theta \ge 120^\circ$ using the equilateral triangle invariant. Its error is an unnecessary rationality restriction that incorrectly excludes irrational $\theta < 120^\circ$, but the core threshold and winning region boundary are correct. Proof B's characterization $\theta = 180^\circ/n$ is fundamentally too restrictive, missing the continuous winning interval $(0, 120^\circ)$. Its converse argument fails because it misinterprets the win condition (requiring both split triangles to enter a set $S$ rather than just one containing $\theta$) and overlooks the immediate 1-move winning strategy available for almost all $\theta < 120^\circ$. A's substantive progress on the $120^\circ$ boundary outweighs B's discrete subset analysis.
