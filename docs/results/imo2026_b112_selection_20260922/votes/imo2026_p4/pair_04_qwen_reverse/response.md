# Proof comparison

## Proof A
Established theorem: Mulan can guarantee victory in finitely many steps if and only if $\theta = \frac{180^\circ}{n}$ for some integer $n \ge 2$. The proof rigorously establishes both directions: a constructive reduction strategy for sufficiency and an invariant-based avoidance strategy for necessity.
Claim gap: NONE. The argument correctly handles all quantifier orders, boundary cases ($n=2,3$), and Shan-Yu's optimal responses.
Qualifications and supplied repairs: NONE. The derivation is self-contained; no external lemmas or silent repairs were required.
Decisive checks: 
- Line 1 (Reduction strategy): Verified. Splitting $k\theta$ into $\theta$ and $(k-1)\theta$ yields two triangles. Shan-Yu must keep one. If he keeps the $\theta$ triangle, the game stops and Mulan wins. If he keeps the $(k-1)\theta$ triangle, the multiple strictly decreases. After at most $k-1$ steps, the angle becomes $\theta$, guaranteeing a win. The quantifier order (Mulan chooses cut $\to$ Shan-Yu chooses child $\to$ state updates) is correctly modeled.
- Lines 6-14 (Sufficiency construction): Verified. The condition for both children to contain an angle in $S$ reduces to finding an integer $k_1 \in (c/\theta, n - b/\theta)$. The interval length is $a/\theta$. If $a > \theta$, length $>1$ guarantees an integer. For $n=2$ ($\theta=90^\circ$), if all angles $<90^\circ$, the interval is $(c/90, 2-b/90)$. Since $c,b < 90$, $c/90 < 1 < 2-b/90$, so $k_1=1$ always exists. The cut is valid ($\alpha_1, \alpha_2 > 0$) and forces both children into $S$. Correct.
- Lines 16-24 (Necessity invariant): Verified. The four cases for both children to land in $S$ are exhaustively checked. Cases 1-3 imply an existing angle was already in $S$, contradicting the invariant. Case 4 implies $(n_1+n_2)\theta = 180^\circ$, i.e., $\theta = 180^\circ/m$ for integer $m$, contradicting the hypothesis. Thus, $\forall$ cuts by Mulan, $\exists$ a child with no angle in $S$. Shan-Yu picks it. Starting with $(60^\circ,60^\circ,60^\circ)$ avoids $S$ unless $\theta=180^\circ/(3k)$. The invariant holds indefinitely. Correct.

## Proof B
Established theorem: Claims Mulan wins iff $\theta$ is a rational multiple of $180^\circ$ and $\theta < 120^\circ$. This conclusion is mathematically incorrect.
Claim gap: The sufficiency argument for rational $\theta < 120^\circ$ contains a verified defect. It incorrectly assumes that a finite state space and multiple cut options allow Mulan to "force" a win against an optimal opponent. In combinatorial game theory, finite state spaces permit cycles or forced losses for the moving player; Shan-Yu's optimal discard strategy is not addressed. The quantifier order is inverted: the proof assumes $\exists$ a sequence of cuts leading to a win, rather than proving $\forall$ Shan-Yu responses, $\exists$ a winning cut. Additionally, the claimed condition is false: $\theta = 100^\circ$ (rational, $<120^\circ$) is a counterexample where Shan-Yu can maintain the invariant "no angle equals $100^\circ$" indefinitely.
Qualifications and supplied repairs: NONE. The proof contains a substantive false claim and an unverified game-theoretic leap that cannot be repaired without replacing the core strategy.
Decisive checks:
- Line 10: Correctly identifies that $\theta \ge 120^\circ$ is a loss for Mulan using the equilateral triangle. However, this contradicts the final conclusion in Line 18 and fails to generalize to other rational values.
- Lines 12-16: Sufficiency claim fails. The argument states "Because the state space is finite and Mulan can choose from multiple values of $k$ to avoid cycles, she can force the state to $(m, n_2, n_3)$." This is a logical fallacy. Finite state space does not imply a forced win; it implies the game must eventually repeat or terminate. Shan-Yu chooses which branch to keep, and can consistently select branches that avoid the winning configuration or cycle. No analysis of Shan-Yu's optimal responses is provided.
- Counterexample verification: For $\theta = 100^\circ$, Shan-Yu starts with $(60^\circ,60^\circ,60^\circ)$. Any cut of $60^\circ$ into $\alpha_1, \alpha_2$ produces triangles with third angles $120^\circ-\alpha_1$ and $120^\circ-\alpha_2$. To make both equal $100^\circ$, we need $\alpha_1=\alpha_2=20^\circ$, but $\alpha_1+\alpha_2=60^\circ$, impossible. Thus at least one child has no $100^\circ$ angle. Shan-Yu keeps it. The invariant holds, Mulan cannot win. This directly falsifies Proof B's claimed condition.

## Decision
Winner: A
Reason: Proof A provides a complete, rigorous, and correct solution. It establishes a precise necessary and sufficient condition ($\theta = 180^\circ/n$), proves sufficiency via a constructive reduction strategy, and proves necessity via a robust invariant that correctly accounts for Shan-Yu's optimal play. Proof B's claimed condition is mathematically false (e.g., $\theta=100^\circ$ is a loss for Mulan), and its sufficiency argument relies on an invalid game-theoretic assumption that finite state spaces guarantee forced wins against an optimal opponent. Proof A's invariant and interval analysis are fully verified, while Proof B's core claim is demonstrably incorrect.
