Let $\{x_m\}_{m \ge 1}$ be the sequence of numbers chosen by the people in line. For $m > N$, the rule is $x_m = c_{m-2}(x_{m-1}) + 1$, where $c_k(v)$ denotes the number of times the value $v$ appears in the first $k$ terms of the sequence.

First, we prove that $\{x_m\}$ is unbounded. Suppose $\{x_m\}$ is bounded by some $K$. Then by the Pigeonhole Principle, at least one value $v \in \{1, \dots, K\}$ must appear infinitely often. Let $m_1 < m_2 < \dots$ be the indices such that $x_{m_j} = v$. For $j > 1$, the rule gives $x_{m_j+1} = c_{m_j-1}(x_{m_j}) + 1 = c_{m_j-1}(v) + 1$. Since $v$ appears infinitely often, $c_{m_j-1}(v) \to \infty$ as $j \to \infty$, which implies $x_{m_j+1} \to \infty$, contradicting the assumption that the sequence is bounded. Thus, $\{x_m\}$ is unbounded.

Let $M_k = \max\{x_1, \dots, x_k\}$ and $D_k$ be the number of distinct values in $\{x_1, \dots, x_k\}$. Note that $D_k \le M_k$. For any $m > N$, if $x_m$ is a new maximum (i.e., $x_m > M_{m-1}$), then $x_m$ has not appeared in the first $m-1$ terms, so $c_{m-1}(x_m) = 0$. The next term is $x_{m+1} = c_{m-1}(x_m) + 1 = 0 + 1 = 1$. Since $\{x_m\}$ is unbounded, new maxima occur infinitely often, and thus the value 1 appears infinitely often.

We now prove that there exists an index $m$ such that $x_{m-1} = 1$ and $x_m = c_{m-2}(1) + 1$ is a new maximum. Let $C_k = c_k(1)$. Let $m_1 < m_2 < \dots$ be the indices of the new maxima. Then $x_{m_k} = M_{m_k}$ and $x_{m_k+1} = 1$.
For $u > 1$, $x_j = u$ only if $c_{j-2}(x_{j-1}) = u-1$. For a fixed $w$, the sequence $c_{j-2}(w)$ is strictly increasing at indices $j$ where $x_{j-1}=w$. Thus, for a fixed $u$, the number of $j$ such that $x_j = u$ is at most the number of distinct values $w$ that have appeared in the sequence. Hence, $c_m(u) \le D_{m-1} \le M_{m-1}$ for all $u > 1$.
If $x_{m_{k+1}}$ is a new maximum and $x_{m_{k+1}-1} = u > 1$, then $x_{m_{k+1}} = c_{m_{k+1}-2}(u) + 1 \le M_{m_{k+1}-2} + 1$. Since $x_{m_{k+1}} > M_{m_{k+1}-1} \ge M_{m_{k+1}-2}$, we must have $x_{m_{k+1}} = M_{m_{k+1}-2} + 1$. This implies $M_{m_{k+1}} \le M_{m_k} + 1$.
Conversely, since $x_{m_k+1} = 1$ for every new maximum $x_{m_k}$, we have $C_{m_k} \ge k + \text{constant}$. Thus $M_{m_k} - C_{m_k}$ is a non-increasing sequence of integers.
If $M_{m_k} - C_{m_k} \le 0$ for some $k$, then $x_{m_k+2} = C_{m_k} + 1 > M_{m_k}$, so $x_{m_k+2}$ is a new maximum and $x_{m_k+1}=1$.
If $M_{m_k} - C_{m_k} = \Delta > 0$ for all $k \ge k_0$, then $M_{m_{k+1}} - M_{m_k} = C_{m_{k+1}} - C_{m_k}$. Since $M_{m_{k+1}} - M_{m_k} \le 1$ and $C_{m_{k+1}} - C_{m_k} \ge 1$, both must be exactly 1. This implies that between $m_k$ and $m_{k+1}$, only one 1 is produced (at $x_{m_k+1}$). Thus, $x_{m_k+2}, \dots, x_{m_{k+1}-1}$ are all not 1. However, $x_{m_k+2} = C_{m_k} + 1$. Since $C_{m_k} \to \infty$, for large $k$, $x_{m_k+2}$ must be a new value. If $x_{m_k+2}$ is a new value, then $x_{m_k+3} = c_{m_k+1}(x_{m_k+2}) + 1 = 0 + 1 = 1$, which is a second 1, contradicting $C_{m_{k+1}} = C_{m_k} + 1$. Thus, we must eventually have $x_{m-1}=1$ and $x_m$ as a new maximum.

Once we have such an index $m$, we prove by induction that $x_{m+2k}$ is a new maximum and $x_{m+2k+1} = 1$ for all $k \ge 0$.
Base case: For $k=0$, $x_m$ is a new maximum and $x_{m+1} = c_{m-1}(x_m) + 1 = 0 + 1 = 1$.
Inductive step: Suppose $x_{m+2k}$ is a new maximum and $x_{m+2k+1} = 1$.
Then $x_{m+2k+2} = c_{m+2k}(1) + 1$.
Since $x_{m+2k}$ was a new maximum and $x_{m+2k-1} = 1$, we have $x_{m+2k} = c_{m+2k-2}(1) + 1$.
The count of 1s at index $m+2k$ is $c_{m+2k}(1) = c_{m+2k-2}(1) + 1$ (since $x_{m+2k-1}=1$ and $x_{m+2k}$ is a new maximum, so $x_{m+2k} \neq 1$).
Thus, $x_{m+2k+2} = (c_{m+2k-2}(1) + 1) + 1 = x_{m+2k} + 1$.
Since $x_{m+2k}$ was the maximum of the sequence up to that point, $x_{m+2k+2} = x_{m+2k} + 1$ is also a new maximum.
Consequently, $x_{m+2k+3} = c_{m+2k+1}(x_{m+2k+2}) + 1 = 0 + 1 = 1$.

The sequence $\{x_j\}$ eventually alternates between 1 and a strictly increasing sequence of integers. Specifically, $x_j = 1$ for all $j \ge m+1$ of a certain parity. If $m+1$ is even, then $x_{2n} = 1$ for all $n \ge (m+1)/2$, meaning the sequence of numbers chosen by the girls $\{g_n\}$ is eventually constant. If $m+1$ is odd, then $x_{2n-1} = 1$ for all $n \ge (m+2)/2$, meaning the sequence of numbers chosen by the boys $\{b_n\}$ is eventually constant. In either case, at least one of the sequences is eventually periodic.
