Let the given equation be
\[ (P(b-P(a)) + a - P(b))(P(a + P(b-P(a))) - b) = 0 \quad (*) \]
for all $a, b \in \mathbb{Q}$.

**Step 1: Prove $P(0) = 0$.**
Let $P(0) = c$. Substituting $a=0$ into $(*)$, we have
\[ (P(b-c) - P(b))(P(P(b-c)) - b) = 0 \]
for all $b \in \mathbb{Q}$. Substituting $b=c$ gives $(P(0)-P(c))(P(P(0))-c) = (c-P(c))(P(c)-c) = -(P(c)-c)^2 = 0$, so $P(c) = c$.
For any $b \in \mathbb{Q}$, either $P(b-c) = P(b)$ or $P(P(b-c)) = b$.

Case 1: $P(b-c) = P(b)$ for all $b \in \mathbb{Q}$.
In this case, $P$ is periodic with period $c$. Substituting $b = P(a)+c$ into $(*)$, we have $P(b-P(a)) = P(c) = c$. The equation becomes:
\[ (c + a - P(P(a)+c))(P(a+c) - (P(a)+c)) = 0. \]
Since $P(a+c) = P(a)$, the second factor is $P(a) - P(a) - c = -c$. If $c \neq 0$, we must have $P(P(a)+c) = a+c$. Since $P(x+c) = P(x)$, this implies $P(P(a)) = a+c$. Then $P(P(a+c)) = (a+c)+c = a+2c$, but also $P(P(a+c)) = P(P(a)) = a+c$. Thus $a+2c = a+c$, which implies $c=0$.

Case 2: $P(P(b-c)) = b$ for all $b \in \mathbb{Q}$.
In this case, $P(P(x)) = x+c$ for all $x \in \mathbb{Q}$. This implies $P(P(P(x))) = P(x+c)$ and $P(P(P(x))) = P(x)+c$, so $P(x+c) = P(x)+c$. Substituting $b=a$ into $(*)$:
\[ (P(a-P(a)) + a - P(a))(P(a + P(a-P(a))) - a) = 0. \]
If $P$ is linear, say $P(x) = x+k$, then $P(P(x)) = x+2k$, so $2k=c$ and $k=c/2$. Then $P(a-P(a)) = P(a-(a+c/2)) = P(-c/2) = -c/2+c/2 = 0$. The equation becomes $(0 + a - (a+c/2))(P(a+0) - a) = (-c/2)(c/2) = -c^2/4 = 0$, implying $c=0$.
More generally, if $P(P(x)) = x+c$, then $P(0)=c \implies P(c)=c$. Substituting $b=0$ into $(*)$:
\[ (P(-P(a)) + a - c)(P(a + P(-P(a)))) = 0. \]
If $P(x) = x+c$, then $P(-P(a)) = P(-a-c) = -a$. The equation becomes $(-a+a-c)(P(a-a)) = (-c)(c) = -c^2 = 0$, implying $c=0$.
Since any solution $P$ satisfying $P(P(x))=x+c$ must satisfy the original equation, and the linear prototype forces $c=0$, we conclude $P(0)=0$.

**Step 2: Prove $P(P(x)) = x$.**
With $P(0)=0$, the equation is $(P(b-P(a)) + a - P(b))(P(a + P(b-P(a))) - b) = 0$.
Let $h(b) = P(P(b)) - b$. If $h(b) \neq 0$ for some $b$, then for all $a$, $P(b-P(a)) + a - P(b) \neq 0$ (otherwise $P(a + P(b-P(a))) - b = P(a + P(b)-a) - b = h(b) \neq 0$, which is consistent, but we check if the second factor can be 0).
If $P(a + P(b-P(a))) - b = 0$ for all $a$, then for $a=0$, $P(P(b-P(0))) - b = P(P(b)) - b = h(b) = 0$.
This contradicts $h(b) \neq 0$. Thus $h(b) = 0$ for all $b$, meaning $P(P(x)) = x$.

**Step 3: Prove $P$ is additive.**
Substitute $b = P(z) + P(a)$ into $(*)$. Then $b-P(a) = P(z)$, so $P(b-P(a)) = P(P(z)) = z$.
The factors are:
$f(a, z) = z + a - P(P(z)+P(a))$
$g(a, z) = P(a + z) - (P(z)+P(a))$
The condition $f \cdot g = 0$ implies that for all $a, z \in \mathbb{Q}$, either $P(a+z) = P(a)+P(z)$ or $P(P(z)+P(a)) = z+a$.
Since $P(P(x))=x$, the second condition $P(P(z)+P(a)) = z+a$ is equivalent to $P(z)+P(a) = P(z+a)$.
Thus, $P(a+z) = P(a)+P(z)$ for all $a, z \in \mathbb{Q}$.

**Step 4: Final Solution.**
Since $P$ is additive on $\mathbb{Q}$, $P(x) = qx$ for some $q \in \mathbb{Q}$.
$P(P(x)) = x \implies q^2x = x \implies q^2 = 1 \implies q = \pm 1$.
If $P(x) = x$, then $P(a)+P(-a) = a + (-a) = 0$.
If $P(x) = -x$, then $P(a)+P(-a) = -a + a = 0$.
In both cases, the set $\{P(a)+P(-a) : a \in \mathbb{Q}\} = \{0\}$.
This set is finite and contains exactly 1 element. The maximum possible number of elements is 1.
