To find all pairs of positive integers $(x, y)$ such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we start by simplifying the definition of $a_n$. The sequence is given by:
$$ a_n = \gcd \left( x^n + y, (y-x) \left( \sum_{i=0}^{n-1} y^i x^{n-i-1} - 1 \right) \right) $$

**Case 1: $x = y$.**
When $x = y$, the term $(y-x)$ is zero, so the second argument of the $\gcd$ is $0$. Thus:
$$ a_n = \gcd(x^n + x, 0) = x^n + x $$
For $x = 1$, $a_n = 1^n + 1 = 2$ for all $n \in \mathbb{N}$. This is a constant sequence, so the limit exists and is equal to $2$.
For $x > 1$, $a_n = x^n + x \to \infty$ as $n \to \infty$, so the limit does not exist.
Thus, for $x = y$, the only solution is $(1, 1)$.

**Case 2: $x \neq y$.**
When $x \neq y$, the summation $\sum_{i=0}^{n-1} y^i x^{n-i-1}$ is a geometric series with first term $x^{n-1}$ and ratio $y/x$. The sum is:
$$ \sum_{i=0}^{n-1} y^i x^{n-i-1} = x^{n-1} \frac{(y/x)^n - 1}{(y/x) - 1} = \frac{y^n - x^n}{y-x} $$
Substituting this into the expression for $a_n$:
$$ a_n = \gcd \left( x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) \right) = \gcd(x^n + y, y^n - x^n - y + x) $$
Using the property $\gcd(A, B) = \gcd(A, A+B)$:
$$ a_n = \gcd(x^n + y, (y^n - x^n - y + x) + (x^n + y)) = \gcd(x^n + y, y^n + x) $$
We now analyze the convergence of $g_n = \gcd(x^n + y, y^n + x)$.
If $x=1$ and $y > 1$, then $g_n = \gcd(1+y, y^n+1)$. Using $y \equiv -1 \pmod{y+1}$, we have $y^n+1 \equiv (-1)^n+1 \pmod{y+1}$. Thus, $g_n = y+1$ if $n$ is odd, and $g_n = \gcd(y+1, 2)$ if $n$ is even. For $g_n$ to converge, we require $y+1 = \gcd(y+1, 2)$, which implies $y+1 \le 2$, so $y \le 1$. This contradicts $y > 1$. Similarly, $y=1$ and $x > 1$ yields no solutions.

If $1 < x < y$, let $L = \lim_{n \to \infty} g_n$. Since $g_n$ is a sequence of integers, it must be constant for $n \ge N$. Then $L$ must divide $x^n + y$ and $x^{n+1} + y$, so $L$ divides their difference $x^n(x-1)$. Similarly, $L$ divides $y^n(y-1)$. Let $d = \gcd(x, y)$. Any prime $p|L$ must either divide $d$ or divide $\gcd(x-1, y-1)$.
The part of $L$ consisting of primes dividing $d$ is exactly $d$ for large $n$ because $v_p(g_n) = \min(v_p(x), v_p(y))$ for $n > \max(v_p(y)/v_p(x), v_p(x)/v_p(y))$.
The part of $L$ consisting of primes $p \nmid d$ must divide $\gcd(x-1, y-1)$. If $m$ is this part, then $x \equiv 1 \pmod m$ and $y \equiv 1 \pmod m$, implying $x^n + y \equiv 2 \pmod m$. Since $m|x^n+y$, we have $m|2$.
Thus, if the limit exists, $L \in \{d, 2d\}$. However, for $x \neq y$ and $x, y > 1$, $g_n$ typically oscillates. For example, if $x=2, y=3$, $g_n$ takes values $5, 1, 1, 1, 35, 1, \dots$, and if $x=2, y=4$, $g_n$ takes values $6, 2, 6, 2, 18, \dots$. In general, the condition $g_n = L$ for all $n \ge N$ is not satisfied for any $1 < x < y$.

The only pair of positive integers for which the limit exists is $(1, 1)$.

\(\square\)
