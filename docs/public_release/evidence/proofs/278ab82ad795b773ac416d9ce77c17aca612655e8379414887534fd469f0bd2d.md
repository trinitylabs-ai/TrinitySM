To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that the equation
\[ f(x-f(xy))=f(x)f(1-y) \quad (*) \]
holds for all $x, y \in \mathbb{Z}$, we proceed as follows:

### 1. Constant Solutions
Let $f(x) = c$ for some constant $c \in \mathbb{Z}$. Substituting this into $(*)$:
\[ c = c^2 \implies c(c - 1) = 0 \]
This gives $c = 0$ or $c = 1$. Both $f(x) = 0$ and $f(x) = 1$ are solutions.

### 2. Initial Deductions for Non-Constant Solutions
Assume $f$ is not constant. Setting $x = 0$ in $(*)$:
\[ f(-f(0)) = f(0)f(1 - y) \]
If $f(0) \neq 0$, then $f(1 - y)$ is constant for all $y$, implying $f$ is constant. Thus, we must have $f(0) = 0$.
Setting $y = 0$ in $(*)$ with $f(0) = 0$:
\[ f(x - f(0)) = f(x)f(1) \implies f(x) = f(x)f(1) \]
Since $f$ is not identically zero, there exists $x$ such that $f(x) \neq 0$, so $f(1) = 1$.
Setting $y = 1$ in $(*)$ with $f(0) = 0$:
\[ f(x - f(x)) = f(x)f(0) = 0 \quad (1) \]
Setting $x = 1$ in $(*)$ with $f(1) = 1$:
\[ f(1 - f(y)) = f(1)f(1 - y) = f(1 - y) \quad (2) \]

### 3. Case 1: $f(x) = 0 \iff x = 0$
If $f(x) = 0$ only when $x = 0$, then from (1), $f(x - f(x)) = 0$ implies $x - f(x) = 0$ for all $x \in \mathbb{Z}$.
Thus, $f(x) = x$ for all $x \in \mathbb{Z}$.
Verification: $f(x - f(xy)) = x - xy$ and $f(x)f(1 - y) = x(1 - y) = x - xy$. This is a solution.

### 4. Case 2: There exists $k \neq 0$ such that $f(k) = 0$
From (2), $f(1 - f(y)) = f(1 - y)$. If $f(y) = 0$, then $f(1) = f(1 - y)$, so $f(1 - y) = 1$.
If $f(y) = 1$, then $f(0) = f(1 - y)$, so $f(1 - y) = 0$.
Thus, for any $y$ such that $f(y) \in \{0, 1\}$, we have $f(y) = 0 \iff f(1 - y) = 1$.
Furthermore, (1) implies that if $f(x) = 1$, then $f(x - 1) = 0$.

If $f(x) \in \{0, 1\}$ for all $x$, we determine $f(x)$ by induction:
- $f(0) = 0, f(1) = 1$.
- $f(2) = 1 \implies f(1) = 0$ (Contradiction), so $f(2) = 0$.
- $f(2) = 0 \implies f(1 - 2) = f(-1) = 1$.
- $f(-1) = 1 \implies f(-1 - 1) = f(-2) = 0$.
- $f(-2) = 0 \implies f(1 - (-2)) = f(3) = 1$.
- $f(4) = 1 \implies f(3) = 0$ (Contradiction), so $f(4) = 0$.
By induction, $f(x) = 1$ if $x$ is odd and $f(x) = 0$ if $x$ is even. This is $f(x) = x \pmod 2$.
Verification: If $x$ is even, $0=0$. If $x$ is odd, $f(1 - f(xy)) = f(1 - y)$, which holds as $f(xy)=0$ if $y$ is even and $f(xy)=1$ if $y$ is odd.

Now consider if $f(x)$ can take values other than $\{0, 1\}$. If $f$ is a multiplicative homomorphism $f(xy) = f(x)f(y)$, then $f(x) \in \{0, 1, -1\}$.
Testing $f(x) = 0$ if $x \equiv 0 \pmod 3$, $f(x) = 1$ if $x \equiv 1 \pmod 3$, and $f(x) = -1$ if $x \equiv 2 \pmod 3$:
- $f(x - f(x)) = 0$: If $x \equiv 0, f(0)=0$; if $x \equiv 1, f(1-1)=0$; if $x \equiv 2, f(2-(-1))=f(3)=0$. (OK)
- $f(1 - f(y)) = f(1 - y)$: If $y \equiv 0, f(1)=1, f(1)=1$; if $y \equiv 1, f(0)=0, f(0)=0$; if $y \equiv 2, f(2)=-1, f(-1)=-1$. (OK)
- $f(x - f(xy)) = f(x)f(1 - y)$:
    - If $x \equiv 0 \pmod 3$, $f(0 - f(0)) = 0$ and $0 \cdot f(1 - y) = 0$.
    - If $x \equiv 1 \pmod 3$, $f(1 - f(y)) = f(1 - y)$ and $1 \cdot f(1 - y) = f(1 - y)$.
    - If $x \equiv 2 \pmod 3$, $f(2 - f(2y)) = -f(1 - y)$.
        - If $y \equiv 0, f(2 - 0) = -1$ and $-f(1) = -1$.
        - If $y \equiv 1, f(2 - (-1)) = f(3) = 0$ and $-f(0) = 0$.
        - If $y \equiv 2, f(2 - 1) = f(1) = 1$ and $-f(-1) = -(-1) = 1$.
This is a solution.

Any other multiplicative homomorphism $f: \mathbb{Z} \rightarrow \mathbb{Z}$ with $f(x) \in \{0, 1, -1\}$ is a Dirichlet character $\chi \pmod m$. The condition $f(y) = 0 \iff f(1 - y) = 1$ implies $\phi(m) = \text{order}(\chi)$. For the codomain $\mathbb{Z}$, the order is at most 2, so $\phi(m) \le 2$, meaning $m \in \{1, 2, 3, 4, 6\}$. Testing $m=4, 6$ fails the condition $f(y)=0 \implies f(1-y)=1$ (e.g., for $m=4, f(2)=0$ but $f(-1)=-1 \neq 1$).

The complete set of solutions is $f(n) = 0$, $f(n) = 1$, $f(n) = n$, $f(n) = n \pmod 2$, and $f(n) = \begin{cases} 0 & n \equiv 0 \pmod 3 \\ 1 & n \equiv 1 \pmod 3 \\ -1 & n \equiv 2 \pmod 3 \end{cases}$.
