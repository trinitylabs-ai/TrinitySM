To prove that $n \geq 5$ for the equation $p^n = a^4 + b^4$, where $p$ is a prime and $a, b$ are positive integers with $n \geq 2$, we analyze the possible values of $n$.

### 1. Analysis of Even $n$
Suppose $n$ is even, say $n = 2k$ for some integer $k \geq 1$. The equation becomes:
\[ a^4 + b^4 = (p^k)^2 \]
This is a specific case of the equation $x^4 + y^4 = z^2$. According to Fermat's Last Theorem for $n=4$ (proven by Fermat using the method of infinite descent), the equation $x^4 + y^4 = z^2$ has no solutions in positive integers. Thus, $n$ cannot be even.

### 2. Analysis of $n=3$
Suppose $n=3$, so $a^4 + b^4 = p^3$. If $\gcd(a, b) = d$, then $d^4$ must divide $p^3$, which implies $d=1$ since $p$ is prime. Thus, $a$ and $b$ are coprime. 
For $a^4 + b^4$ to be a power of $p$, $p$ must be $2$ or $p \equiv 1 \pmod 8$.
- If $p=2$, $a^4 + b^4 = 8$, which implies $a=b=1$ but $1+1=2 \neq 8$.
- If $p > 2$, we consider the equation modulo 16. Since $\gcd(a, b)=1$, $a^4$ and $b^4$ are in $\{0, 1\} \pmod{16}$, so $a^4 + b^4 \in \{1, 2\} \pmod{16}$. For $p^3 \equiv 1$ or $2 \pmod{16}$, we must have $p \equiv 1 \pmod{16}$.

Working in the Gaussian integers $\mathbb{Z}[i]$, the equation $a^4 + b^4 = p^3$ implies $a^2 + ib^2 = (u+iv)^3$ for some $u, v$ such that $u^2 + v^2 = p$. Expanding this, we get:
\[ a^2 = u(u^2 - 3v^2) \quad \text{and} \quad b^2 = v(3u^2 - v^2) \]
Since $\gcd(u, v)=1$, the factors must be squares (or 3 times squares).
- If $u=s^2$ and $u^2 - 3v^2 = t^2$, then $s^4 - 3v^2 = t^2$. If $v=r^2$, we have $s^4 - 3r^4 = t^2$. Similarly, $b^2 = r^2(3s^4 - r^4)$ implies $3s^4 - r^4 = w^2$.
- Checking $s^4 - 3r^4 = t^2$ and $3s^4 - r^4 = w^2$ modulo 5:
  - If $r^4 \equiv 0 \pmod 5$, then $w^2 \equiv 3s^4 \pmod 5$, which is impossible as $3$ is not a quadratic residue mod 5.
  - If $r^4 \equiv 1 \pmod 5$, then $s^4 - 3 \equiv t^2 \pmod 5$ and $3s^4 - 1 \equiv w^2 \pmod 5$. 
    - If $s^4 \equiv 0 \pmod 5$, then $t^2 \equiv -3 \equiv 2 \pmod 5$ (impossible).
    - If $s^4 \equiv 1 \pmod 5$, then $t^2 \equiv -2 \equiv 3 \pmod 5$ (impossible).
Thus, $n=3$ has no solutions.

### 3. Verification of $n=5$
We check if $n=5$ is possible. For $p=2$:
\[ a^4 + b^4 = 2^5 = 32 \]
Setting $a=2$ and $b=2$ gives $2^4 + 2^4 = 16 + 16 = 32$. This is a valid solution.

### Conclusion
Since $n$ cannot be even and $n$ cannot be 3, and given $n \geq 2$, the smallest possible integer value for $n$ is 5. Thus, $n \geq 5$.

\(\square\)
