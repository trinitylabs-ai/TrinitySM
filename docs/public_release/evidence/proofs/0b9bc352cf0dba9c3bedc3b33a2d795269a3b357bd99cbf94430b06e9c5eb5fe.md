To find all positive real numbers $r$ such that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$, where $B(n,r) = \sum_{k=1}^n A(kr)$ and $A(r)$ is the fractional part of $2r$, we proceed as follows.

First, we express $A(r)$ using the fractional part notation $\{x\} = x - \lfloor x \rfloor$. Thus, $A(r) = \{2r\}$. The sum $B(n,r)$ becomes:
$$B(n,r) = \sum_{k=1}^n \{2kr\} = \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor) = 2r \frac{n(n+1)}{2} - \sum_{k=1}^n \lfloor 2kr \rfloor = n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor$$
The condition given is that $C(n,r) = n(n+1)r - B(n,r)$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$. Substituting the expression for $B(n,r)$:
$$C(n,r) = n(n+1)r - \left( n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor \right) = \sum_{k=1}^n \lfloor 2kr \rfloor$$
The requirement is that $S_n = \sum_{k=1}^n \lfloor 2kr \rfloor \equiv 0 \pmod n$ for all $n \ge 1$. Let $x = 2r$. We seek $x > 0$ such that $S_n = \sum_{k=1}^n \lfloor kx \rfloor \equiv 0 \pmod n$ for all $n \ge 1$.
Let $x = m + \alpha$, where $m = \lfloor x \rfloor$ and $0 \le \alpha < 1$. Then:
$$S_n = \sum_{k=1}^n \lfloor k(m+\alpha) \rfloor = \sum_{k=1}^n (km + \lfloor k\alpha \rfloor) = m \frac{n(n+1)}{2} + T_n, \quad \text{where } T_n = \sum_{k=1}^n \lfloor k\alpha \rfloor$$
For any odd integer $n$, $n+1$ is even, so $\frac{n+1}{2}$ is an integer. This implies $m \frac{n(n+1)}{2}$ is a multiple of $n$. Thus, for odd $n$, the condition $S_n \equiv 0 \pmod n$ implies $T_n \equiv 0 \pmod n$.
We examine $T_n$ for small odd $n$:
1. For $n=1$, $T_1 = \lfloor \alpha \rfloor = 0$, which is always true since $0 \le \alpha < 1$.
2. For $n=3$, $T_3 = \lfloor 2\alpha \rfloor + \lfloor 3\alpha \rfloor$. Since $0 \le \alpha < 1$, $T_3 \in \{0, 1, 2, 3\}$. For $T_3 \equiv 0 \pmod 3$, we must have $T_3 = 0$ (which means $\alpha \in [0, 1/3)$) or $T_3 = 3$ (which means $\alpha \in [2/3, 1)$).
3. For $n=5$, if $\alpha \in [0, 1/3)$, then $T_5 = \lfloor 4\alpha \rfloor + \lfloor 5\alpha \rfloor \in \{0, 1, 2\}$. For $T_5 \equiv 0 \pmod 5$, we must have $T_5 = 0$, implying $\alpha \in [0, 1/5)$.
If $\alpha \in [2/3, 1)$, then $T_5 = 1 + 2 + \lfloor 4\alpha \rfloor + \lfloor 5\alpha \rfloor \in \{8, 9, 10\}$. For $T_5 \equiv 0 \pmod 5$, we must have $T_5 = 10$, implying $\alpha \in [4/5, 1)$.

By induction, for all odd $n$, $T_n \equiv 0 \pmod n$ implies $\alpha \in [0, 1/n) \cup [(n-1)/n, 1)$. The intersection of these sets for all odd $n$ is $\{0\}$. Thus, $\alpha$ must be $0$.
If $\alpha = 0$, then $x = m$ is an integer. The condition $S_n \equiv 0 \pmod n$ becomes:
$$m \frac{n(n+1)}{2} \equiv 0 \pmod n \quad \text{for all } n \ge 1$$
For $n=2$, $S_2 = m \frac{2(3)}{2} = 3m$. For $3m$ to be a multiple of 2, $m$ must be even. Let $m = 2k$ for some positive integer $k$. Then $S_n = \frac{2kn(n+1)}{2} = kn(n+1)$, which is always a multiple of $n$.
Thus, $x = 2r = 2k$, which means $r = k$ for any positive integer $k$.

The positive real numbers $r$ that satisfy the condition are all positive integers.

\(\square\)
