To find all pairs of positive integers $(x, y)$ such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we first simplify the expression for $a_n$:
$$ a_n = \gcd \left( x^n + y, (y-x) \left( \sum_{i=0}^{n-1} y^i x^{n-i-1} - 1 \right) \right) $$
If $x = y$, the second term in the $\gcd$ is $0$, so $a_n = \gcd(x^n + x, 0) = x^n + x$. For $x=1$, $a_n = 2$ for all $n$, so the limit exists. For $x > 1$, $a_n \to \infty$, so the limit does not exist. Thus, $(1, 1)$ is a solution.

If $x \neq y$, the sum is a geometric series $\sum_{i=0}^{n-1} y^i x^{n-i-1} = \frac{y^n - x^n}{y-x}$. Substituting this into the formula:
$$ a_n = \gcd(x^n + y, (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right)) = \gcd(x^n + y, y^n - x^n - (y-x)) $$
Using the property $\gcd(A, B) = \gcd(A, A+B)$, we have:
$$ a_n = \gcd(x^n + y, (x^n + y) + (y^n - x^n - y + x)) = \gcd(x^n + y, y^n + x) $$
If $x=1$ and $y>1$, then $a_n = \gcd(1+y, y^n+1)$. For odd $n$, $y+1$ divides $y^n+1$, so $a_n = y+1$. For even $n$, $y^n+1 = (y^n-1)+2 = (y+1)(y^{n-1}-y^{n-2}+\dots-1)+2$, so $a_n = \gcd(y+1, 2)$. Since $y>1$, $y+1 > 2$, so $a_n$ oscillates between $y+1$ and $\gcd(y+1, 2)$. Thus, the limit does not exist. Symmetrically, the limit does not exist for $y=1, x>1$.

Now consider $x, y > 1$ with $x \neq y$. Let $g = \gcd(x, y)$, $x = gx'$, and $y = gy'$ with $\gcd(x', y') = 1$. Then
$$ a_n = \gcd(g^n x'^n + gy', g^n y'^n + gx') = g \gcd(g^{n-1} x'^n + y', g^{n-1} y'^n + x') $$
Let $b_n = a_n/g = \gcd(g^{n-1} x'^n + y', g^{n-1} y'^n + x')$. Let $S = x' + y'$.
Suppose there exists a prime $p$ such that $p \mid S$ but $p \nmid g$. Then $x' \equiv -y' \pmod p$. For odd $n$, we have:
$$ g^{n-1} x'^n + y' \equiv g^{n-1} (-y')^n + y' \equiv y'(1 - (gy')^{n-1}) \pmod p $$
$$ g^{n-1} y'^n + x' \equiv g^{n-1} y'^n - y' \equiv -y'(1 - (gy')^{n-1}) \pmod p $$
Since $p \nmid g$ and $p \nmid y'$ (as $\gcd(x', y')=1$ and $p \mid x'+y'$), $gy'$ is invertible modulo $p$. By Euler's Theorem, $(gy')^{\phi(p)} \equiv 1 \pmod p$. Choosing $n-1$ as a multiple of $\phi(p)$ such that $n$ is odd, we find $b_n \equiv 0 \pmod p$ infinitely often.
If $p > 2$, then for even $n$, $b_n \equiv \gcd(y'(g^{n-1}y'^{n-1}+1), y'(g^{n-1}y'^{n-1}-1)) \pmod p$. For $b_n$ to be a multiple of $p$, we would need $g^{n-1}y'^{n-1} \equiv \pm 1 \pmod p$ simultaneously, implying $2 \equiv 0 \pmod p$, a contradiction. If $p=2$ is the only prime factor of $S$ and $2 \nmid g$, then $x', y'$ are odd. For $x=1, y=3$, $b_n = \gcd(4, 3^n+1)$ oscillates between 4 and 2. In general, if $p \mid S$ and $p \nmid g$, $b_n$ does not converge.

Conversely, suppose every prime factor of $S = x' + y'$ divides $g$. Then $\text{rad}(S) \mid g$. For $n \ge 2$, $g^{n-1}$ is a multiple of $\text{rad}(S)$.
We observe that $b_n \mid g(g^{n-1}x'^n + y') - (g^n x'^n + y') = (g-1)y'$ and $b_n \mid (g-1)x'$. Since $\gcd(x', y') = 1$, $b_n \mid g-1$.
This implies $\gcd(b_n, g) = 1$. Since $\text{rad}(S) \mid g$, we have $\gcd(b_n, S) = 1$.
Because $b_n \mid g-1$, we have $g \equiv 1 \pmod{b_n}$, so $b_n \equiv \gcd(x'^n + y', y'^n + x') \pmod{b_n}$.
Then $x'^n \equiv -y' \pmod{b_n}$ and $y'^n \equiv -x' \pmod{b_n}$.
This implies $x'^{n+1} \equiv x'(-y') \equiv -y' \pmod{b_n}$, so $y'(x'-1) \equiv 0 \pmod{b_n}$.
Since $\gcd(b_n, y') = 1$ (as $\gcd(b_n, g)=1$ and $b_n \mid g^{n-1}x'^n + y'$), we have $x' \equiv 1 \pmod{b_n}$. Similarly $y' \equiv 1 \pmod{b_n}$.
Then $x'^n \equiv 1 \pmod{b_n}$ and $x'^n \equiv -y' \equiv -1 \pmod{b_n}$, so $b_n \mid 2$.
Thus $b_n \in \{1, 2\}$. The value of $b_n \pmod 2$ depends only on the parity of $g, x', y'$ for $n \ge 2$, so $b_n$ is eventually constant.
The condition $\text{rad}(x' + y') \mid g$ is equivalent to $\text{rad}(\frac{x+y}{\gcd(x, y)}) \mid \gcd(x, y)$, which is equivalent to $\text{rad}(x+y) \mid \gcd(x, y)$.

The pairs $(x, y)$ for which the limit exists are $(1, 1)$ and all pairs $(x, y)$ with $x \neq y$ such that $\text{rad}(x+y) \mid \gcd(x, y)$.
