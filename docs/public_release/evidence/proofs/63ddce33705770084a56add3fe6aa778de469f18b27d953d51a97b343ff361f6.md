To determine all positive integers $k$ such that $S_k(n) = \frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^k$ is an integer for every positive integer $n$, we examine the condition
\[ \sum_{i=0}^{n} \binom{n}{i}^k \equiv 0 \pmod{n+1} \]
for all $n \in \mathbb{Z}^+$.

**1. Necessary Conditions**
We test small values of $n$:
- For $n=1$, $n+1=2$. The sum is $\binom{1}{0}^k + \binom{1}{1}^k = 2 \equiv 0 \pmod{2}$, which is true for all $k \ge 1$.
- For $n=2$, $n+1=3$. The sum is $\binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2 + 2^k$. For this to be $0 \pmod{3}$, we need $2^k \equiv -2 \equiv 1 \pmod{3}$, which occurs if and only if $k$ is even.
- For $n=p-1$ where $p$ is an odd prime, $n+1=p$. Using the property $\binom{p-1}{i} \equiv (-1)^i \pmod{p}$, the sum becomes
\[ \sum_{i=0}^{p-1} \binom{p-1}{i}^k \equiv \sum_{i=0}^{p-1} ((-1)^i)^k \pmod{p}. \]
If $k$ is even, $((-1)^i)^k = 1$, so the sum is $\sum_{i=0}^{p-1} 1 = p \equiv 0 \pmod{p}$.
If $k$ is odd, $((-1)^i)^k = (-1)^i$, so the sum is $\sum_{i=0}^{p-1} (-1)^i = 1 \pmod{p}$ (since $p-1$ is even).
Thus, $k$ must be even.

**2. Sufficient Conditions**
We prove that all even $k \ge 2$ satisfy the condition. Let $m = n+1$. We wish to show that $\sum_{i=0}^{m-1} \binom{m-1}{i}^k \equiv 0 \pmod{m}$ for all even $k$. By the Chinese Remainder Theorem, it suffices to show this for $m = p^a$ where $p$ is a prime and $a \ge 1$.
Consider the binomial coefficient $\binom{m-1}{i}$ for $0 \le i < m$. We have the identity in $\mathbb{Q}$:
\[ \binom{m-1}{i} = \prod_{j=1}^i \frac{m-j}{j} = (-1)^i \prod_{j=1}^i \left( 1 - \frac{m}{j} \right). \]
For even $k$, $\binom{m-1}{i}^k = \prod_{j=1}^i (1 - \frac{m}{j})^k$. Expanding this as a power series in $m$ (or working in the ring of $p$-adic integers $\mathbb{Z}_p$):
\[ \binom{m-1}{i}^k = 1 - km \sum_{j=1}^i \frac{1}{j} + \sum_{r=2}^k m^r \sigma_{r,i}, \]
where $H_i = \sum_{j=1}^i \frac{1}{j}$ and $\sigma_{r,i}$ are symmetric sums of reciprocals of the form $\sum \frac{1}{j_1 \dots j_r}$.
Summing over $i$ from $0$ to $m-1$:
\[ \sum_{i=0}^{m-1} \binom{m-1}{i}^k = m - km \sum_{i=1}^{m-1} H_i + \sum_{r=2}^k m^r \sum_{i=1}^{m-1} \sigma_{r,i}. \]
The first term $m \equiv 0 \pmod{m}$. For the second term, we have $\sum_{i=1}^{m-1} H_i = \sum_{j=1}^{m-1} \frac{m-j}{j} = m H_{m-1} - (m-1)$. Thus,
\[ km \sum_{i=1}^{m-1} H_i = km^2 H_{m-1} - km(m-1). \]
Since $v_p(H_{m-1}) \ge -(a-1)$, we have $v_p(km^2 H_{m-1}) \ge 2a - (a-1) = a+1$, so $km^2 H_{m-1} \equiv 0 \pmod{p^a}$. Also $km(m-1) \equiv 0 \pmod{p^a}$.
For the higher order terms, let $S_r(m) = \sum_{i=1}^{m-1} \sigma_{r,i} = \sum_{i=1}^{m-1} \sum_{1 \le j_1 < \dots < j_r \le i} \frac{1}{j_1 \dots j_r}$.
We can rewrite this as:
\[ S_r(m) = \sum_{1 \le j_1 < \dots < j_r \le m-1} \frac{m-j_r}{j_1 \dots j_r} = m \sum_{1 \le j_1 < \dots < j_r \le m-1} \frac{1}{j_1 \dots j_r} - S_{r-1}(m). \]
Multiplying by $m^r$:
\[ m^r S_r(m) = m^{r+1} \sum_{1 \le j_1 < \dots < j_r \le m-1} \frac{1}{j_1 \dots j_r} - m^r S_{r-1}(m). \]
The $p$-adic valuation of the first term is $v_p(m^{r+1} \sum \frac{1}{j_1 \dots j_r}) \ge (r+1)a - r(a-1) = a+r$.
Thus, $m^r S_r(m) \equiv -m^r S_{r-1}(m) \pmod{p^{a+r}}$.
By induction, $m^r S_r(m) \equiv (-1)^{r-1} m^r S_1(m) \pmod{p^a}$.
Since $m S_1(m) = m^2 H_{m-1} - m(m-1) \equiv 0 \pmod{p^a}$, it follows that $m^r S_r(m) \equiv 0 \pmod{p^a}$ for all $r \ge 1$.
Therefore, $\sum_{i=0}^{m-1} \binom{m-1}{i}^k \equiv 0 \pmod{m}$ for all even $k$.

The positive integers $k$ are all even positive integers.
