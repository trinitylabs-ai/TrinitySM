For given positive integers $x$ and $y$, we define the sequence $(a_n)_{n \ge 1}$ as
$$ a_n = \gcd \left( x^n +y , \, (y-x)\left(\sum_{i=0}^{n-1} y^i x^{n-i-1} - 1\right) \right) $$
First, we simplify the expression for $a_n$. If $x = y$, the second argument of the $\gcd$ is 0, so $a_n = \gcd(x^n + x, 0) = x^n + x$. For the limit $\lim_{n \to \infty} (x^n + x)$ to exist, the sequence must be eventually constant. This occurs if and only if $x = 1$. If $x = 1$, then $y = 1$ and $a_n = 2$ for all $n$, so the limit is 2. If $x > 1$, $a_n \to \infty$ as $n \to \infty$, so the limit does not exist.

Now consider the case $x \neq y$. The summation is a geometric series: $\sum_{i=0}^{n-1} y^i x^{n-i-1} = \frac{y^n - x^n}{y-x}$. Substituting this into the expression for $a_n$:
$$ (y-x) \left( \frac{y^n - x^n}{y-x} - 1 \right) = y^n - x^n - (y-x) = y^n - x^n - y + x $$
Thus, $a_n = \gcd(x^n + y, y^n - x^n - y + x)$. Since $(y^n + x) - (x^n + y) = y^n - x^n - y + x$, we have:
$$ a_n = \gcd(x^n + y, y^n + x) $$
Suppose the limit $\lim_{n \to \infty} a_n = L$ exists. Then there exists $N$ such that $a_n = L$ for all $n \ge N$. This implies $L \mid x^n + y$ and $L \mid x^{n+1} + y$ for all $n \ge N$. Subtracting these gives $L \mid x^{n+1} - x^n = x^n(x-1)$. Similarly, $L \mid y^n(y-1)$.

Let $p$ be a prime divisor of $L$.
If $p \mid x$, then $L \mid x^n + y$ implies $p \mid y$. Let $v_p(x) = v_x$ and $v_p(y) = v_y$. For sufficiently large $n$, $nv_x > v_y$ and $nv_y > v_x$. Then $v_p(x^n + y) = \min(nv_x, v_y) = v_y$ and $v_p(y^n + x) = \min(nv_y, v_x) = v_x$. Thus $v_p(a_n) = \min(v_x, v_y)$ for $n \ge N$, which means $v_p(L) = \min(v_p(x), v_p(y))$.
If $p \nmid x$, then $L \mid x^n(x-1)$ implies $p \mid x-1$, so $x \equiv 1 \pmod p$. Then $L \mid x^n + y$ implies $1^n + y \equiv 0 \pmod p$, so $y \equiv -1 \pmod p$. Similarly, $L \mid y^n(y-1)$ implies $p \mid y-1$ since $p \nmid y$. Thus $y \equiv 1 \pmod p$. Combining $y \equiv 1 \pmod p$ and $y \equiv -1 \pmod p$ gives $2 \equiv 0 \pmod p$, so $p = 2$.
If $p=2$ and $2 \nmid x$, then $x \equiv 1 \pmod{2^{v_2(L)}}$ and $y \equiv -1 \pmod{2^{v_2(L)}}$. Then $y^n + x \equiv (-1)^n + 1 \pmod{2^{v_2(L)}}$. For this to be $0 \pmod{2^{v_2(L)}}$ for all $n \ge N$, we must have $2^{v_2(L)} \mid 2$, so $v_2(L) \le 1$.

Combining these, $L$ must divide $2 \gcd(x, y)$. Let $g = \gcd(x, y)$, $x = gX$, and $y = gY$ with $\gcd(X, Y) = 1$. Then $a_n = g \gcd(g^{n-1} X^n + Y, g^{n-1} Y^n + X)$. Let $b_n = \gcd(g^{n-1} X^n + Y, g^{n-1} Y^n + X)$. If $a_n \to L$, then $b_n$ must be eventually constant, say $b_n = L'$ where $L' = L/g \in \{1, 2\}$.
If $b_n = L'$ for $n \ge N$, then for any prime $p$, the property $p \mid b_n$ must be eventually constant. However, $p \mid b_n$ if and only if $g^{n-1} X^n \equiv -Y \pmod p$ and $g^{n-1} Y^n \equiv -X \pmod p$. These conditions are periodic in $n$. Thus, the property $p \mid b_n$ is periodic. A periodic sequence that is eventually constant must be constant for all $n \ge 1$.
This implies that for any prime $p$, $p \mid b_n$ for all $n \ge 1$ if $p \mid L'$, and $p \nmid b_n$ for all $n \ge 1$ if $p \nmid L'$. In particular, $b_1 = \gcd(X+Y, Y+X) = X+Y$ must have the same prime divisors as $L'$. Since $L' \in \{1, 2\}$, $X+Y$ must be a power of 2.
If $X+Y=1$, this is impossible for positive integers. If $X+Y=2$, then $X=Y=1$, which implies $x=y$, contradicting our case. If $X+Y=2^k$ for $k \ge 2$, we consider $b_n$ modulo $2^{k+1}$. For $X=1, Y=2^k-1, g=1$, we have $b_n = \gcd(1 + (2^k-1), (2^k-1)^n + 1) = \gcd(2^k, (2^k-1)^n + 1)$.
For $n=1$, $b_1 = \gcd(2^k, 2^k) = 2^k$.
For $n=2$, $b_2 = \gcd(2^k, (2^k-1)^2 + 1) = \gcd(2^k, 2^{2k} - 2^{k+1} + 2) = 2$.
Since $k \ge 2$, $b_1 \neq b_2$, so $b_n$ is not constant. Thus, $b_n$ cannot be eventually constant for $x \neq y$.

The only pair $(x, y)$ such that the limit exists is $(1, 1)$.
