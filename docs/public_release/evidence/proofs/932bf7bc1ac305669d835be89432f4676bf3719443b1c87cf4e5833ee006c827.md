Let $M = 3000$ be the number of rows from which Peter selects cells, and let $K = 3001$ be the number of columns. Peter selects a set $S = \{(i, c_i) : i = 2, \dots, M+1\}$, where $c_i \in \{1, \dots, K\}$ are distinct. James starts at $(1, 1)$ and aims to reach row $M+2$. If James enters a cell in $S$, he receives a penalty and returns to $(1, 1)$. We seek the smallest positive integer $n$ such that James can guarantee reaching the last row before receiving $n$ penalties.

First, we show that James can reach row $M+2$ with at most $M$ penalties. Since there are $M$ obstacles and $K = M+1$ columns, there is exactly one column $j_{free} \in \{1, \dots, K\}$ that contains no obstacle. James can employ a strategy of trying paths $P_1, P_2, \dots, P_K$ sequentially, where $P_j$ is the path that stays in column $j$ for all rows $i \in \{2, \dots, M+1\}$. If James tries $P_j$ and it is not the free column, he will eventually hit an obstacle $(i, j) \in S$. Upon hitting this cell, he receives a penalty and learns that $c_i = j$. Since each column contains at most one obstacle, once he has hit an obstacle in column $j$, he knows that all other cells in that column are safe. After at most $M$ such penalties, James will have identified $M$ obstacles. Since there are only $M$ obstacles in total, he will then know the identity of all obstacles and can identify the free column $j_{free}$. He can then traverse $P_{j_{free}}$ to reach row $M+2$ without any further penalties. Thus, James can guarantee success with at most $M$ penalties, so $n \le M+1$.

Next, we show that Peter can force James to receive at least $M$ penalties. We describe a dynamic strategy for Peter. Peter does not fix the set $S$ initially. Instead, he maintains a set of unassigned rows $U_{rows} \subseteq \{2, \dots, M+1\}$ and unassigned columns $U_{cols} \subseteq \{1, \dots, K\}$. Initially, $U_{rows} = \{2, \dots, M+1\}$ and $U_{cols} = \{1, \dots, K\}$. Let $S_{cols} = U_{cols}^c$ be the set of columns already assigned as obstacles.

Whenever James chooses a path $P$, Peter checks if there exists a cell $(i, j) \in P$ such that $i \in U_{rows}$ and $j \in U_{cols}$. If such a cell exists, Peter picks one, sets $c_i = j$, and updates $U_{rows} \to U_{rows} \setminus \{i\}$ and $U_{cols} \to U_{cols} \setminus \{j\}$. James receives a penalty and returns to $(1, 1)$. Peter can repeat this process as long as James's paths $P$ intersect $U_{rows} \times U_{cols}$.

Suppose James has received $m < M$ penalties. Peter's strategy is to always pick the smallest available row $i \in U_{rows}$ to assign an obstacle if possible. Thus, $U_{rows} = \{m+2, \dots, M+1\}$. To avoid the $(m+1)$-th penalty, James must choose a path $P$ such that $P \cap (U_{rows} \times U_{cols}) = \emptyset$. This means that for all $i \in \{m+2, \dots, M+1\}$, the set of columns $J_i$ visited by $P$ in row $i$ must satisfy $J_i \subseteq S_{cols}$, where $|S_{cols}| = m$.

Since $J_i$ is a contiguous interval and $J_i \cap J_{i+1} \neq \emptyset$, the path must stay within the same contiguous block of $S_{cols}$ for all $i \in \{m+2, \dots, M+1\}$. Let $B$ be the contiguous block of $S_{cols}$ such that $J_i \subseteq B$ for all $i \in \{m+2, \dots, M+1\}$.
Now consider the path from row 1 to row $m+2$. It must pass through row $m+1$. Since $m+1 \notin U_{rows}$, an obstacle $(m+1, c_{m+1})$ has already been placed, where $c_{m+1} \in S_{cols}$. To avoid a penalty, James must ensure $c_{m+1} \notin J_{m+1}$.
However, $J_{m+2} \subseteq B \subseteq S_{cols}$. Let $j \in J_{m+2}$. Since $J_{m+1} \cap J_{m+2} \neq \emptyset$, $J_{m+1}$ must contain some element of $B$. If Peter maintains $S_{cols}$ such that it contains no two adjacent integers, then every contiguous block $B$ is a singleton $\{j\}$. In this case, $J_i = \{j\}$ for all $i \in \{m+2, \dots, M+1\}$. Then $j \in S_{cols}$, so $j = c_r$ for some $r \in \{2, \dots, m+1\}$. To avoid the obstacle $(r, c_r)$, James must have $c_r \notin J_r$. But the path must go from $J_1$ (which contains 1) to $J_{m+2} = \{c_r\}$. Since $J_r$ avoids $c_r$, the path must cross the column $c_r$ in some row $k \neq r$. If $k \in \{2, \dots, m+1\}$, James avoids the penalty as long as $c_k \neq c_r$. However, if Peter maintains $S_{cols}$ such that no two elements are adjacent, then to move from a column $j_1 \in S_{cols}$ to $j_2 \in S_{cols}$ in row $k$, the path $J_k$ must contain all columns between $j_1$ and $j_2$. If $S_{cols}$ is sparse, any path that avoids all $(i, c_i)$ and stays within $S_{cols}$ for $i \in U_{rows}$ is impossible.

Specifically, if $S_{cols}$ contains no adjacent integers, then $J_i = \{j\}$ for all $i \in U_{rows}$. To reach $J_{m+2}=\{j\}$ from $J_1=\{1, \dots, k_1\}$ while avoiding $(i, c_i)$ for $i \in \{2, \dots, m+1\}$, James must use some column $j' \notin S_{cols}$ in row $r$ where $c_r=j$. But then $J_r \cap J_{r+1} \neq \emptyset$ implies $J_{r+1}$ contains $j'$. If $r+1 \in U_{rows}$, then $J_{r+1} \subseteq S_{cols}$, which contradicts $j' \notin S_{cols}$. Thus, Peter can force $M$ penalties.

The smallest positive integer $n$ such that James can guarantee success before receiving $n$ penalties is $n = M+1 = 3001$.
