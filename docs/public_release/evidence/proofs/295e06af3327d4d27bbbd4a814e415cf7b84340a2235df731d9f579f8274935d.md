To prove that for any positive integers $k$ and $d$, there exists a positive integer $N$ such that for every odd integer $n > N$, the digits of $n^k$ in base $B = 2n$ are all greater than $d$, we analyze the base-$B$ representation of $n^k$.

Let $n^k$ be written in base $B = 2n$ as:
$$n^k = a_m B^m + a_{m-1} B^{m-1} + \dots + a_1 B + a_0$$
where $0 \le a_i < B$ and $a_m \neq 0$. We first determine the range of $m$. Since $n^k = \frac{(2n)^k}{2^k} = \frac{B^k}{2^k}$, and $2^k > 1$ for $k \ge 1$, we have $n^k < B^k$, so $m \le k-1$. Furthermore, if $n \ge 2^{k-1}$, then $n^k \ge 2^{k-1} n^{k-1} = (2n)^{k-1} \frac{n}{2}$, which for $n \ge 2^{k-1}$ is at least $B^{k-1} \cdot \frac{2^{k-1}}{2}$. For $k \ge 2$ and $n \ge 2^{k-1}$, we have $n^k \ge B^{k-1}$, so $m = k-1$. (If $k=1$, $n^1 = a_0 = n$, so $m=0$ and $a_0 > d$ for $n > d$).

The digits $a_i$ are given by $a_i = \lfloor \frac{n^k}{B^i} \rfloor \pmod{B}$ for $i = 0, 1, \dots, k-1$.
For $i=0$, we have $a_0 = n^k \pmod{2n}$. Since $n$ is odd, $n^{k-1}$ is odd, say $n^{k-1} = 2m+1$ for some integer $m$. Then $n^k = n(2m+1) = 2mn + n = m(2n) + n$. Thus, $a_0 = n$.

For $i \in \{1, \dots, k-1\}$, let $j = k-i$. We have:
$$a_i = \left\lfloor \frac{n^k}{(2n)^i} \right\rfloor \pmod{2n} = \left\lfloor \frac{n^{k-i}}{2^i} \right\rfloor \pmod{2n} = \left\lfloor \frac{n^j}{2^{k-j}} \right\rfloor \pmod{2n}$$
Let $r_j$ be the remainder of $n^{j-1}$ when divided by $2^{k-j+1}$. Since $n$ is odd, $n^{j-1}$ is odd, so $r_j$ is an odd integer such that $1 \le r_j < 2^{k-j+1}$. We can write $n^{j-1} = q \cdot 2^{k-j+1} + r_j$. Then:
$$\frac{n^j}{2^{k-j}} = \frac{n(q \cdot 2^{k-j+1} + r_j)}{2^{k-j}} = 2nq + \frac{nr_j}{2^{k-j}}$$
Taking the floor and the modulo $2n$:
$$a_i = \left\lfloor 2nq + \frac{nr_j}{2^{k-j}} \right\rfloor \pmod{2n} = \left\lfloor \frac{nr_j}{2^{k-j}} \right\rfloor \pmod{2n}$$
Since $r_j < 2^{k-j+1}$, we have $\frac{nr_j}{2^{k-j}} < \frac{n \cdot 2^{k-j+1}}{2^{k-j}} = 2n$. Thus, $\lfloor \frac{nr_j}{2^{k-j}} \rfloor < 2n$, and the modulo is trivial:
$$a_i = \left\lfloor \frac{nr_j}{2^{k-j}} \right\rfloor$$
Since $r_j \ge 1$, we have $a_i \ge \lfloor \frac{n}{2^{k-j}} \rfloor$. The smallest such value occurs when $k-j$ is maximized. For $i \in \{1, \dots, k-1\}$, $k-j = i$. The minimum occurs at $i=k-1$ (where $j=1$), so:
$$a_i \ge a_{k-1} = \left\lfloor \frac{n}{2^{k-1}} \right\rfloor$$
To ensure all digits are greater than $d$, we require $a_0 > d$ and $a_{k-1} > d$.
1. $a_0 = n > d$.
2. $a_{k-1} = \lfloor \frac{n}{2^{k-1}} \rfloor \ge d+1 \iff n \ge (d+1) 2^{k-1}$.

Let $N = \max\{d, (d+1) 2^{k-1}, 2^{k-1}\}$. For any odd integer $n > N$, we have $n \ge (d+1) 2^{k-1}$, ensuring $a_{k-1} \ge d+1 > d$. Since $a_i \ge a_{k-1}$ for all $i \in \{1, \dots, k-1\}$ and $a_0 = n > d$, all digits in the base-$2n$ representation of $n^k$ are greater than $d$.

\(\square\)
