To determine all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[ \sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}, \]
we analyze the two given inequalities separately.

**1. Simplifying the inequalities**
The right inequality $\frac{f(x) + y}{2} \ge \sqrt{x f(y)}$ can be squared (since both sides are positive):
\[ (f(x) + y)^2 \ge 4x f(y) \implies f(x)^2 + 2y f(x) + y^2 \ge 4x f(y). \quad (1) \]
The left inequality $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2}$ can also be squared:
\[ \frac{x^2 + f(y)^2}{2} \ge \frac{(f(x) + y)^2}{4} \implies 2x^2 + 2f(y)^2 \ge f(x)^2 + 2y f(x) + y^2. \quad (2) \]
Combining these, we have the chain:
\[ 4x f(y) \le (f(x) + y)^2 \le 2x^2 + 2f(y)^2. \]

**2. Testing $f(x) = x$**
If $f(x) = x$, the inequalities become $\sqrt{\frac{x^2 + y^2}{2}} \ge \frac{x + y}{2} \ge \sqrt{xy}$. These are the Root Mean Square-Arithmetic Mean (RMS-AM) and Arithmetic Mean-Geometric Mean (AM-GM) inequalities, which hold for all $x, y > 0$. Thus, $f(x) = x$ is a solution.

**3. Proving uniqueness**
Let $f(x) = x + \epsilon(x)$ for some function $\epsilon: \mathbb{R}_{>0} \to \mathbb{R}$. Substituting this into (1) and (2):
From (1): $(x + \epsilon(x) + y)^2 \ge 4x(y + \epsilon(y)) \implies (x - y)^2 + 2(x + y)\epsilon(x) + \epsilon(x)^2 \ge 4x \epsilon(y)$.
From (2): $2x^2 + 2(y + \epsilon(y))^2 \ge (x + \epsilon(x) + y)^2 \implies (x - y)^2 + 4y \epsilon(y) + 2\epsilon(y)^2 \ge 2(x + y)\epsilon(x) + \epsilon(x)^2$.
Adding these two inequalities, the terms involving $\epsilon(x)$ cancel:
\[ (x - y)^2 + 4y \epsilon(y) + 2\epsilon(y)^2 \ge 4x \epsilon(y) \implies (x - y)^2 + 2\epsilon(y)^2 \ge 4(x - y)\epsilon(y). \]
Let $\delta = x - y$. For a fixed $y$, $\delta$ can be any value in $(-y, \infty)$. The quadratic $Q(\delta) = \delta^2 - 4\epsilon(y)\delta + 2\epsilon(y)^2$ must be non-negative for all $\delta \in (-y, \infty)$.
The vertex of $Q(\delta)$ is at $\delta_0 = 2\epsilon(y)$.
- If $\epsilon(y) > 0$, then $\delta_0 > 0$ is always in the interval. The minimum value $Q(\delta_0) = -2\epsilon(y)^2$ must be $\ge 0$, forcing $\epsilon(y) = 0$.
- If $\epsilon(y) < 0$, the vertex $\delta_0 < 0$. If $\delta_0 \in (-y, \infty)$, then $Q(\delta_0) = -2\epsilon(y)^2 \ge 0$ forces $\epsilon(y) = 0$. Thus, if $\epsilon(y) \neq 0$, we must have $\delta_0 \le -y$, which means $2\epsilon(y) \le -y \implies \epsilon(y) \le -y/2$.

Consequently, for every $y > 0$, either $\epsilon(y) = 0$ or $\epsilon(y) \le -y/2$.
If there exists $y$ such that $\epsilon(y) \neq 0$, then $f(y) \le y/2$. From the combined inequality $(f(x) + y)^2 \le 2x^2 + 2f(y)^2$, if $f(y) \le y/2$ for all $y$, then $f(x) \le \sqrt{2x^2 + y^2/2} - y$. As $y \to \infty$, the right side tends to $-\infty$, which contradicts $f(x) > 0$.
If $\epsilon(x) = 0$ for some $x$ and $\epsilon(y) \neq 0$ for some $y$, then from (2) we have $(x - y)^2 + 4y \epsilon(y) + 2\epsilon(y)^2 \ge 2(x + y)\epsilon(x) + \epsilon(x)^2 = 0$.
For a fixed $y$, the minimum of $(x - y)^2 + 4y \epsilon(y) + 2\epsilon(y)^2$ over $x$ is $4y \epsilon(y) + 2\epsilon(y)^2$. Thus $4y \epsilon(y) + 2\epsilon(y)^2 \ge 0$. Since $\epsilon(y) < 0$, dividing by $2\epsilon(y)$ yields $2y + \epsilon(y) \le 0$, so $\epsilon(y) \le -2y$. This implies $f(y) = y + \epsilon(y) \le -y$, which contradicts $f(y) > 0$.

Thus, $\epsilon(y) = 0$ for all $y > 0$, meaning $f(x) = x$.

The only function is $f(x) = x$. \(\square\)
