To find all positive real numbers $r$ such that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$, where $B(n,r) = \sum_{k=1}^n \{2kr\}$, we begin by simplifying the expression.

The fractional part of a real number $x$ is defined as $\{x\} = x - \lfloor x \rfloor$. Thus,
$$B(n,r) = \sum_{k=1}^n \{2kr\} = \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor) = 2r \sum_{k=1}^n k - \sum_{k=1}^n \lfloor 2kr \rfloor = n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor.$$
The given condition is that $n(n+1)r - B(n,r)$ is a multiple of $n$. Substituting the expression for $B(n,r)$, we have:
$$n(n+1)r - \left( n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor \right) = \sum_{k=1}^n \lfloor 2kr \rfloor.$$
Let $x = 2r$. The condition is that $S_n = \sum_{k=1}^n \lfloor kx \rfloor$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$. This means $S_n = n \cdot m_n$ for some integer $m_n$.

If $x$ is an integer, $S_n = \sum_{k=1}^n kx = x \frac{n(n+1)}{2}$. For $S_n$ to be a multiple of $n$, $x \frac{n+1}{2}$ must be an integer for all $n$. For $n=1$, $x$ must be an integer. For $n=2$, $3x/2$ must be an integer, which implies $x$ must be even. If $x$ is an even integer, say $x=2m$, then $S_n = 2m \frac{n(n+1)}{2} = mn(n+1)$, which is always a multiple of $n$. Thus, $x=2r$ being an even integer implies $r$ is a positive integer.

If $x$ is not an integer, let $x = I + f$ where $I = \lfloor x \rfloor$ and $0 < f < 1$.
Then $S_n = I \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor kf \rfloor$.
For $n=1$, $S_1 = I$, which is always a multiple of 1.
For $n=2$, $S_2 = 3I + \lfloor 2f \rfloor$. For $S_2$ to be a multiple of 2, $I + \lfloor 2f \rfloor$ must be even.
For $n=3$, $S_3 = 6I + \lfloor 2f \rfloor + \lfloor 3f \rfloor$. For $S_3$ to be a multiple of 3, $\lfloor 2f \rfloor + \lfloor 3f \rfloor$ must be a multiple of 3.
Since $0 < f < 1$, $0 \le \lfloor 2f \rfloor \le 1$ and $0 \le \lfloor 3f \rfloor \le 2$. The sum $\lfloor 2f \rfloor + \lfloor 3f \rfloor$ can only be 0 or 3.
- Case 1: $\lfloor 2f \rfloor + \lfloor 3f \rfloor = 0 \implies \lfloor 2f \rfloor = 0$ and $\lfloor 3f \rfloor = 0$. This requires $0 < f < 1/3$.
- Case 2: $\lfloor 2f \rfloor + \lfloor 3f \rfloor = 3 \implies \lfloor 2f \rfloor = 1$ and $\lfloor 3f \rfloor = 2$. This requires $2/3 \le f < 1$.

In Case 1, $I$ must be even (from $n=2$). For $n=4$, $S_4 = 10I + \sum_{k=1}^4 \lfloor kf \rfloor$. Since $I$ is even, $10I \equiv 2I \pmod 4$, so $2I + \sum_{k=1}^4 \lfloor kf \rfloor \equiv 0 \pmod 4$. For $f$ small enough, $\sum \lfloor kf \rfloor = 0$, but for any $f > 0$, there exists $k_0$ such that $\lfloor k_0 f \rfloor = 1$. At $n=k_0$, $S_{k_0} = I \frac{k_0(k_0+1)}{2} + 1$. Since $I$ is even, $I \frac{k_0(k_0+1)}{2}$ is a multiple of $k_0$, so $S_{k_0} \equiv 1 \pmod{k_0}$, which is only 0 if $k_0=1$, but $f < 1$ implies $k_0 > 1$.
In Case 2, $I$ must be odd (from $n=2$). For $n=4$, $S_4 = 10I + \lfloor 2f \rfloor + \lfloor 3f \rfloor + \lfloor 4f \rfloor \equiv 2 + 1 + 2 + \lfloor 4f \rfloor \equiv 1 + \lfloor 4f \rfloor \pmod 4$. For this to be 0, $\lfloor 4f \rfloor = 3$. For $n=5$, $S_5 = 15I + \sum_{k=1}^5 \lfloor kf \rfloor \equiv 0 + 1 + 2 + 3 + \lfloor 5f \rfloor \equiv 1 + \lfloor 5f \rfloor \pmod 5$. For this to be 0, $\lfloor 5f \rfloor = 4$.
Continuing this, we must have $\lfloor nf \rfloor = n-1$ for all $n$, which implies $1 - \frac{1}{n} \le f < 1$ for all $n$, forcing $f \ge 1$, a contradiction.

Thus, the only solutions are when $x=2r$ is an even integer, meaning $r$ is a positive integer.

The positive real numbers $r$ are $r \in \{1, 2, 3, \dots\}$.
