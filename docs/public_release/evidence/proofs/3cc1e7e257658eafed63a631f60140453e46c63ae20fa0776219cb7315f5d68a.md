To prove that there exists a positive integer $N$ such that for every odd integer $n > N$, the digits in the base-$2n$ representation of $n^k$ are all greater than $d$, we proceed as follows.

### 1. Base-2n Representation of $n^k$
Let $n$ be a positive odd integer. The base-$2n$ representation of $n^k$ is the unique sequence of integers $a_m, a_{m-1}, \dots, a_0$ such that:
\[ n^k = a_m(2n)^m + a_{m-1}(2n)^{m-1} + \dots + a_1(2n) + a_0 \]
where $0 \le a_i < 2n$ for all $i$, and $a_m \neq 0$.

First, we observe that $(2n)^{k-1} = 2^{k-1}n^{k-1}$. For $n \ge 2^{k-1}$, we have $n^k \ge 2^{k-1}n^{k-1} = (2n)^{k-1}$. Also, since $k \ge 1$, $n^k < (2n)^k$ is obviously true as $(2n)^k = 2^k n^k > n^k$. Thus, for $n \ge 2^{k-1}$, the base-$2n$ representation of $n^k$ has exactly $k$ digits, $a_{k-1}, a_{k-2}, \dots, a_0$.

### 2. Determining the Digits $a_i$
We use the division algorithm to find the digits.
Let $R_k = n^k$.
For $i = k-1, k-2, \dots, 0$, the digit $a_i$ is given by $a_i = \lfloor R_{i+1} / (2n)^i \rfloor$, and the remainder is $R_i = R_{i+1} \pmod{(2n)^i}$.

For $i = k-1$:
\[ a_{k-1} = \lfloor n^k / (2n)^{k-1} \rfloor = \lfloor n^k / (2^{k-1}n^{k-1}) \rfloor = \lfloor n/2^{k-1} \rfloor \]
The remainder is $R_{k-1} = n^k - \lfloor n/2^{k-1} \rfloor (2^{k-1}n^{k-1}) = n^{k-1}(n - 2^{k-1} \lfloor n/2^{k-1} \rfloor)$.
Let $r_{k-1} = n \pmod{2^{k-1}}$. Then $R_{k-1} = r_{k-1} n^{k-1}$.

For $i = k-2, k-3, \dots, 1$:
Assuming $R_{i+1} = r_{i+1} n^{i+1}$ for some $r_{i+1}$, we have:
\[ a_i = \lfloor r_{i+1} n^{i+1} / (2n)^i \rfloor = \lfloor r_{i+1} n^{i+1} / (2^i n^i) \rfloor = \lfloor r_{i+1} n / 2^i \rfloor \]
The remainder is $R_i = r_{i+1} n^{i+1} - a_i (2^i n^i) = n^i (r_{i+1} n - a_i 2^i) = n^i (r_{i+1} n \pmod{2^i})$.
Let $r_i = r_{i+1} n \pmod{2^i}$. Then $R_i = r_i n^i$.

Finally, for $i = 0$:
$R_1 = r_1 n$. The digit is $a_0 = R_1 \pmod{2n} = r_1 n \pmod{2n}$.

### 3. Analysis of the Remainders $r_i$
Since $n$ is an odd integer, $r_{k-1} = n \pmod{2^{k-1}}$ is odd (as the remainder of an odd number divided by an even number is odd).
By induction, if $r_{i+1}$ is odd, then $r_i = r_{i+1} n \pmod{2^i}$ is the remainder of the product of two odd integers divided by an even integer, which is always odd. Thus, $r_i$ is an odd positive integer for all $i = 1, \dots, k-1$.
Specifically, $r_1$ is an odd integer in the range $[0, 2^1-1]$, so $r_1 = 1$.
Thus, $a_0 = (1 \cdot n) \pmod{2n} = n$.

### 4. Lower Bounds for $a_i$
Since $r_{i+1} \ge 1$ for all $i \in \{1, \dots, k-1\}$, we have:
\[ a_i = \lfloor r_{i+1} n / 2^i \rfloor \ge \lfloor n / 2^i \rfloor \]
To ensure $a_i > d$ for all $i \in \{1, \dots, k-1\}$, it suffices to have $\lfloor n / 2^i \rfloor \ge d+1$, which is equivalent to $n \ge (d+1)2^i$. The strongest condition is for $i = k-1$:
\[ n \ge (d+1)2^{k-1} \]
Additionally, we require $a_0 > d$, which means $n > d$. Since $(d+1)2^{k-1} \ge d+1$, the condition $n \ge (d+1)2^{k-1}$ implies $n > d$.

### 5. Conclusion
Let $N = (d+1)2^{k-1}$. For any odd integer $n > N$, we have $n \ge (d+1)2^{k-1} + 1$ (since $n$ and $N$ may both be even or odd). In either case, $n \ge (d+1)2^{k-1}$.
Thus:
1. $a_0 = n > d$.
2. $a_i \ge \lfloor n/2^i \rfloor \ge \lfloor (d+1)2^{k-1}/2^i \rfloor \ge \lfloor d+1 \rfloor = d+1 > d$ for $1 \le i \le k-1$.

All digits $a_i$ are greater than $d$. $\square$
