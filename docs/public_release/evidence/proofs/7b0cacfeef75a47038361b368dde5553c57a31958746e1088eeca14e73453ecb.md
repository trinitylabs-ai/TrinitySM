To determine for which real values of $\theta \in (0^\circ, 180^\circ)$ Mulan can guarantee victory, we analyze the game's mechanics. Let the angles of the current triangle $T$ be $A, B, C$. Mulan's move consists of choosing a vertex (say $A$) and a point $P$ on the opposite side $BC$, dividing $\angle A$ into $\alpha$ and $\beta$ ($\alpha + \beta = A$). The resulting triangles are $T_1$ with angles $(\alpha, B, 180^\circ - \alpha - B)$ and $T_2$ with angles $(\beta, C, 180^\circ - \beta - C)$. Shan-Yu then chooses which triangle to keep.

**1. Sufficient Condition: $\theta = 180^\circ/k$ for $k \in \{2, 3, \dots\}$**
If $\theta = 180^\circ/k$, Mulan can force a win using the following strategy:
- **Case $k=2$ ($\theta=90^\circ$):** Mulan picks $P$ such that $AP \perp BC$. Then $\angle APC = \angle APB = 90^\circ$. Regardless of Shan-Yu's choice, the new triangle has an angle of $90^\circ$. Mulan wins in one step.
- **Case $k \ge 3$:** Mulan's goal is to force an angle of $2\theta$ and then split it into $\theta$ and $\theta$.
    - First, Mulan ensures the triangle has an angle strictly less than $\theta$. If all angles $A, B, C \ge \theta$, she can repeatedly cut $\alpha = \theta$ from any angle $A > \theta$. Shan-Yu must pick $T_2(A-\theta, C, B+\theta)$. This process continues until at least one angle is less than $\theta$.
    - Once $T$ has an angle $C < \theta$, Mulan picks vertex $A$ and $\alpha = 180^\circ - B - \theta$. Then $T_1$ has an angle $180^\circ - \alpha - B = \theta$. Shan-Yu must pick $T_2$. The angles of $T_2$ are $(A - \alpha, C, 180^\circ - A + \alpha - C) = (\theta - C, C, 180^\circ - \theta)$.
    - Since $180^\circ = k\theta$, the angle $180^\circ - \theta = (k-1)\theta$.
    - If $T$ has an angle $n\theta$ for $n \ge 2$, Mulan can split it into $\theta$ and $(n-1)\theta$. Shan-Yu must pick the triangle with $(n-1)\theta$. Repeating this, Mulan forces an angle of $2\theta$.
    - Finally, Mulan splits $2\theta$ into $\theta$ and $\theta$. Both resulting triangles have an angle $\theta$, guaranteeing victory.

**2. Necessary Condition: $\theta = 180^\circ/k$**
Suppose $180^\circ/\theta$ is not an integer. Let $180^\circ = q\theta + r$ where $0 < r < \theta$.
- For Mulan to win in one step, she must make both $T_1$ and $T_2$ contain $\theta$. As analyzed, if $\theta \neq 90^\circ$, this requires the current triangle to have an angle of $2\theta$ or $\theta$.
- If $180^\circ$ is not a multiple of $\theta$, Shan-Yu can prevent any angle from becoming a multiple of $\theta$. If Mulan picks $\alpha = \theta$ to make $T_1$ have $\theta$, Shan-Yu picks $T_2(A-\theta, C, B+\theta)$. If the original angles were not multiples of $\theta$, the new angles are not either.
- If Mulan picks $\alpha = 180^\circ - B - \theta$ to make $T_1$ have $\theta$, Shan-Yu picks $T_2(\theta - C, C, 180^\circ - \theta)$. Since $180^\circ$ is not a multiple of $\theta$, $180^\circ - \theta$ is not a multiple of $\theta$.
- Thus, if $180^\circ/\theta \notin \mathbb{Z}$, Shan-Yu can ensure that no angle ever becomes a multiple of $\theta$, and specifically, no angle ever becomes $\theta$.

Mulan can guarantee victory if and only if $\theta = 180^\circ/k$ for some integer $k \ge 2$.

The real values of $\theta$ are $\theta = \frac{180^\circ}{k}$ for $k \in \{2, 3, 4, \dots\}$.
