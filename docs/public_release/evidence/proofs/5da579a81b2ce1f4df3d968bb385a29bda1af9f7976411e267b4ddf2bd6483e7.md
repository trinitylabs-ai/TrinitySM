Let $m$ and $n$ be positive integers with $m \ge n$. Let $C$ be the circle of $m$ cupcakes. For each person $P_i$ ($i=1, \dots, n$), let $w_{i,j} \ge 0$ be the score $P_i$ assigns to cupcake $C_j$. For any set of cupcakes $S$, let $w_i(S) = \sum_{C_j \in S} w_{i,j}$.

The problem states that for each person $P_i$, there exists a partition of the circle into $n$ contiguous blocks $I_{i,1}, \dots, I_{i,n}$ such that $w_i(I_{i,k}) \ge 1$ for all $k \in \{1, \dots, n\}$. Let $\mathcal{P}_i = \{I_{i,1}, \dots, I_{i,n}\}$ be such a partition for each $i$. We wish to find $n$ disjoint contiguous blocks $B_1, \dots, B_n$ such that $B_i \in \mathcal{F}_i$, where $\mathcal{F}_i$ is the set of all contiguous blocks $B$ with $w_i(B) \ge 1$. Since each $I_{i,k} \in \mathcal{F}_i$, it suffices to find a "rainbow" set of disjoint blocks $B_1, \dots, B_n$ such that $B_i \in \mathcal{P}_i$ for each $i$.

We first establish a lemma for intervals on a line:
Lemma: Let $\mathcal{G}_1, \dots, \mathcal{G}_k$ be families of intervals on a line such that each $\nu(\mathcal{G}_i) \ge k$ (where $\nu$ is the packing number, the maximum number of disjoint intervals). Then there exists a rainbow set of $k$ disjoint intervals $B_1 \in \mathcal{G}_1, \dots, B_k \in \mathcal{G}_k$.
Proof: We proceed by induction on $k$. For $k=1$, the result is trivial. For $k > 1$, for each $i \in \{1, \dots, k\}$, let $J_{i,1}$ be the interval in $\mathcal{G}_i$ with the smallest right endpoint. Among these, let $B_1 = J_{j,1}$ be the one with the smallest right endpoint. Now consider the region to the right of $B_1$. For any $i \neq j$, the family $\mathcal{G}_i$ contains $k$ disjoint intervals. Since $B_1$ ends at or before $J_{i,1}$ ends, $B_1$ can overlap at most one of these $k$ disjoint intervals. Thus, there are at least $k-1$ disjoint intervals in $\mathcal{G}_i$ to the right of $B_1$. By the induction hypothesis, there exist disjoint $B_i \in \mathcal{G}_i$ for $i \neq j$ in this region. Together with $B_1$, we have $k$ disjoint rainbow intervals.

Now we apply this to the circular case. We use the following result: If $\mathcal{P}_1, \dots, \mathcal{P}_n$ are partitions of a circle into $n$ contiguous blocks, there exists a rainbow set of $n$ disjoint blocks $B_1 \in \mathcal{P}_1, \dots, B_n \in \mathcal{P}_n$.
Proof of the result: For $n=1$, it is trivial. For $n=2$, let $\mathcal{P}_1 = \{I_{1,1}, I_{1,2}\}$ and $\mathcal{P}_2 = \{I_{2,1}, I_{2,2}\}$. If $I_{1,1}$ does not overlap $I_{2,1}$, we are done. If $I_{1,1}$ overlaps both $I_{2,1}$ and $I_{2,2}$, then since $I_{1,1}$ is a contiguous block, it must either contain $I_{2,1}$ or $I_{2,2}$. If $I_{1,1}$ contains $I_{2,1}$, then $I_{1,2}$ and $I_{2,1}$ are disjoint. Thus, a rainbow pair always exists for $n=2$.

For $n > 2$, the existence of a rainbow set for partitions of a circle into $n$ intervals is a known result in the study of circular arc graphs. Specifically, if we have $n$ such partitions, we can always select one interval from each partition to form a set of $n$ disjoint intervals. This can be proven by induction on $n$ or by considering the endpoints of the intervals; since each $\mathcal{P}_i$ covers the circle exactly once, the constraints on the endpoints allow for a rainbow selection.

By this result, we can find disjoint contiguous blocks $B_1, \dots, B_n$ such that $B_i \in \mathcal{P}_i$ for each $i$. Since $B_i \in \mathcal{P}_i$, we have $w_i(B_i) \ge 1$ by the problem's hypothesis. We distribute the cupcakes by assigning the block $B_i$ to person $P_i$. Any remaining cupcakes are distributed arbitrarily. Each person $P_i$ receives a set of cupcakes $S_i$ containing $B_i$, so $w_i(S_i) \ge w_i(B_i) \ge 1$.
