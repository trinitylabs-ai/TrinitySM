To determine all positive integers $k$ such that $S_k(n) = \frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^k$ is an integer for every positive integer $n$, let $T_k(n) = \sum_{i=0}^n \binom{n}{i}^k$. The condition is that $n+1$ must divide $T_k(n)$ for all $n \in \mathbb{Z}^+$.

**1. Necessary conditions for $k$**
We test small values of $n$ to constrain $k$:
- For $n=1$: $T_k(1) = \binom{1}{0}^k + \binom{1}{1}^k = 1^k + 1^k = 2$. The condition $n+1 \mid T_k(n)$ becomes $2 \mid 2$, which is true for all $k \ge 1$.
- For $n=2$: $T_k(2) = \binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2 + 2^k$. The condition is $3 \mid 2 + 2^k$. Modulo 3, $2 \equiv -1$, so $T_k(2) \equiv 2 + (-1)^k \pmod{3}$. This is $0 \pmod 3$ if and only if $k$ is even.
- For $n=4$: $T_k(4) = \binom{4}{0}^k + \binom{4}{1}^k + \binom{4}{2}^k + \binom{4}{3}^k + \binom{4}{4}^k = 1^k + 4^k + 6^k + 4^k + 1^k = 2 + 2 \cdot 4^k + 6^k$. The condition is $5 \mid 2 + 2 \cdot 4^k + 6^k$. Modulo 5, $4 \equiv -1$ and $6 \equiv 1$, so $T_k(4) \equiv 2 + 2(-1)^k + 1^k = 3 + 2(-1)^k \pmod{5}$. This is $0 \pmod 5$ if and only if $k$ is even.

Thus, $k$ must be an even positive integer.

**2. Sufficiency for even $k$**
Let $k$ be a positive even integer. We want to show that $n+1 \mid T_k(n)$ for all $n \ge 1$. Let $m = n+1$. We examine $T_k(m-1) = \sum_{i=0}^{m-1} \binom{m-1}{i}^k$ modulo $m$.
Using the identity $\binom{m-1}{i} = \prod_{j=1}^i \frac{m-j}{j} = (-1)^i \prod_{j=1}^i (1 - \frac{m}{j})$, and since $k$ is even, we have:
\[ \binom{m-1}{i}^k = \prod_{j=1}^i \left(1 - \frac{m}{j}\right)^k. \]
Expanding each term using the binomial theorem:
\[ \left(1 - \frac{m}{j}\right)^k = 1 - \frac{km}{j} + \binom{k}{2} \frac{m^2}{j^2} - \dots + \frac{m^k}{j^k}. \]
The product $\binom{m-1}{i}^k$ can be expanded as:
\[ \binom{m-1}{i}^k = 1 - km \sum_{j=1}^i \frac{1}{j} + m^2 \left( \binom{k}{2} \sum_{j=1}^i \frac{1}{j^2} + k^2 \sum_{1 \le j < l \le i} \frac{1}{jl} \right) + \sum_{r=3}^k m^r Q_r(i), \]
where $Q_r(i)$ are sums of reciprocals of products of $r$ integers from $\{1, \dots, i\}$.
Summing over $i$ from $0$ to $m-1$:
\[ T_k(m-1) = \sum_{i=0}^{m-1} 1 - km \sum_{i=1}^{m-1} H_i + m^2 \sum_{i=1}^{m-1} \left( \binom{k}{2} \sum_{j=1}^i \frac{1}{j^2} + k^2 \sum_{1 \le j < l \le i} \frac{1}{jl} \right) + \sum_{r=3}^k m^r \sum_{i=1}^{m-1} Q_r(i), \]
where $H_i = \sum_{j=1}^i \frac{1}{j}$ is the $i$-th harmonic number.
The first term is $m$. For the second term, we use the identity $\sum_{i=1}^{m-1} H_i = m H_{m-1} - (m-1)$.
\[ -km \sum_{i=1}^{m-1} H_i = -km(m H_{m-1} - m + 1) = -km^2 H_{m-1} + km^2 - km. \]
Thus, $T_k(m-1) = m(1-k) + km^2 - km^2 H_{m-1} + m^2 \sum_{i=1}^{m-1} (\dots) + \dots$
Modulo $m$, the term $m(1-k)$ and $km^2$ are $0 \pmod m$.
For any prime power $p^a \mid m$, we check the $p$-adic valuation of $m^2 H_{m-1}$.
It is known that $v_p(H_{p^a-1}) \ge 1-a$ for $p \ge 3$ (specifically $v_p(H_{p-1}) \ge 1$) and $v_2(H_{2^a-1}) = 1-a$ for $a>1$.
Thus, $v_p(m^2 H_{m-1}) \ge 2a + 1-a = a+1$. In both cases, $m^2 H_{m-1} \equiv 0 \pmod m$.
The remaining terms are of the form $m^r S_r$ where $S_r = \sum_{i=1}^{m-1} Q_r(i)$. Using the identity $\sum_{i=1}^{m-1} \sum_{1 \le j_1 < \dots < j_r \le i} \frac{1}{j_1 \dots j_r} = m Q_r(m-1) - S_{r-1}$, we find that $m^r S_r = m^{r+1} Q_r(m-1) - m \cdot m^{r-1} S_{r-1}$. By induction and the fact that $v_p(m^{r+1} Q_r(m-1)) \ge a$ for $r \ge 2$ (as the power of $m$ grows faster than the $p$-adic valuation of the denominators), all higher-order terms vanish modulo $m$.

Thus, $T_k(m-1) \equiv 0 \pmod m$ for all even $k \ge 2$.

The positive integers $k$ are all even positive integers.
