To find all pairs of positive integers $(x, y)$ such that the limit of the sequence $(a_n)_{n \ge 1}$ exists, we start by simplifying the expression for $a_n$:
$$ a_n = \gcd \left( x^n + y, \, (y-x)\left(\sum_{i=0}^{n-1} y^i x^{n-i-1} - 1\right) \right) $$
If $x = y$, the second term in the $\gcd$ becomes $(x-x)(\dots) = 0$. Thus, $a_n = \gcd(x^n + x, 0) = x^n + x$. For the limit of $a_n$ to exist, the sequence $x^n + x$ must be constant for $n \ge 1$ or converge to a finite value. This occurs if and only if $x=1$, in which case $a_n = 1^n + 1 = 2$ for all $n$. If $x > 1$, $a_n \to \infty$, which is not considered a convergent limit. Thus, $(1, 1)$ is a solution.

If $x \neq y$, the sum is a geometric series $S_n = \sum_{i=0}^{n-1} y^i x^{n-i-1} = \frac{y^n - x^n}{y-x}$. Substituting this into the formula:
$$ a_n = \gcd(x^n + y, (y-x)(\frac{y^n - x^n}{y-x} - 1)) = \gcd(x^n + y, y^n - x^n - (y-x)) $$
Using the property $\gcd(A, B) = \gcd(A, A+B)$, we have:
$$ a_n = \gcd(x^n + y, (x^n + y) + (y^n - x^n - y + x)) = \gcd(x^n + y, y^n + x) $$
Suppose the limit $\lim_{n \to \infty} a_n = L$ exists. Since $x^n+y$ grows for $x>1$, $L$ must be a finite constant. For $n \ge N$, $a_n = L$. This implies $L \mid x^n + y$ and $L \mid x^{n+1} + y$. Then $L$ must divide the difference:
$$ L \mid (x^{n+1} + y) - x(x^n + y) = y - xy = y(1-x) $$
Similarly, $L \mid x(1-y)$. If $x=1$ and $y>1$, then $a_n = \gcd(y+1, y^n+1)$. For $n$ odd, $a_n = y+1$. For $n$ even, $y^n+1 \equiv (-1)^n+1 \equiv 2 \pmod{y+1}$, so $a_n = \gcd(y+1, 2)$. For the limit to exist, $y+1 = \gcd(y+1, 2)$, which implies $y=1$, contradicting $y>1$. Symmetric reasoning applies for $y=1, x>1$.

Now consider $x, y > 1$ with $x \neq y$. If $a_n = L$ for $n \ge N$, then $x^n \equiv -y \pmod L$ for all $n \ge N$. This implies $x^{n+1} \equiv x^n \pmod L$, so $x^n(x-1) \equiv 0 \pmod L$. Since $x^n \equiv -y \pmod L$, we have $-y(x-1) \equiv 0 \pmod L$. Let $p$ be a prime divisor of $L$. If $p \nmid x$, then $x \equiv 1 \pmod p$, which implies $1 \equiv -y \pmod p$, so $y \equiv -1 \pmod p$. Also $y^n \equiv -x \equiv -1 \pmod p$. However, since $y \equiv -1 \pmod p$, $y^n \equiv (-1)^n \pmod p$. For this to be $-1$ for all $n \ge N$, $n$ must be always odd, which is impossible. Thus, any prime divisor of $L$ must divide $x$. Symmetrically, any prime divisor of $L$ must divide $y$. Thus $L$ must divide some power of $g = \gcd(x, y)$.
Let $x=gx', y=gy'$. Then $a_n = g \gcd(g^{n-1}x'^n + y', g^{n-1}y'^n + x')$. Let $b_n = \gcd(g^{n-1}x'^n + y', g^{n-1}y'^n + x')$. If $b_n$ converges to $B$, then $B$ must divide $\gcd(y'(g-1), x'(g-1)) = g-1$. This implies $g \equiv 1 \pmod B$. Then $g^{n-1}x'^n + y' \equiv x'^n + y' \pmod B$. For $x'^n \equiv -y' \pmod B$ to hold for all $n \ge N$, $x' \equiv 1 \pmod{B'}$ (where $B'$ is the part of $B$ coprime to $x'$), leading to $y' \equiv -1 \pmod{B'}$. Then $y'^n \equiv (-1)^n \pmod{B'}$, which must equal $-x' \equiv -1 \pmod{B'}$ for all $n \ge N$, again requiring $n$ to be always odd. Thus $B=1$ and $L=g$. However, $a_n$ oscillates for $x \neq y$ (e.g., for $x=2, y=4$, $a_n$ is $6, 2, 6, 2, 18, 2, \dots$).

The only pair $(x, y)$ for which the limit exists is $(1, 1)$.

\(\square\)
