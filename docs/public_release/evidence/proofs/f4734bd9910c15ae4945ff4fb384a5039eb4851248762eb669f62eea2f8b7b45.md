To find all positive real numbers $r$ such that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$, we first simplify the expression $B(n,r)$.

The fractional part of $2r$ is denoted by $A(r) = \{2r\}$. The sum $B(n,r)$ is defined as:
$$B(n,r) = \sum_{k=1}^n A(kr) = \sum_{k=1}^n \{2kr\}.$$
The condition is that $S_n = n(n+1)r - B(n,r)$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$. Using the identity $\{x\} = x - \lfloor x \rfloor$, we rewrite $S_n$ as:
$$S_n = n(n+1)r - \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor) = n(n+1)r - 2r \sum_{k=1}^n k + \sum_{k=1}^n \lfloor 2kr \rfloor.$$
Since $\sum_{k=1}^n k = \frac{n(n+1)}{2}$, we have:
$$S_n = n(n+1)r - 2r \frac{n(n+1)}{2} + \sum_{k=1}^n \lfloor 2kr \rfloor = \sum_{k=1}^n \lfloor 2kr \rfloor.$$
Let $x = 2r$. The condition is that $f(n) = \sum_{k=1}^n \lfloor kx \rfloor$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$.

**Case 1: $x$ is an integer.**
If $x$ is an integer, then $f(n) = \sum_{k=1}^n kx = x \frac{n(n+1)}{2}$. For $f(n)$ to be a multiple of $n$ for all $n$, the value $\frac{f(n)}{n} = \frac{x(n+1)}{2}$ must be an integer for all $n \ge 1$.
For $n=1$, $\frac{2x}{2} = x$ is an integer.
For $n=2$, $\frac{3x}{2}$ must be an integer, which implies that $x$ must be an even integer.
If $x$ is an even integer, say $x = 2m$ for some $m \in \mathbb{Z}^+$, then $\frac{2m(n+1)}{2} = m(n+1)$ is always an integer.
Since $x = 2r$, we have $2r = 2m \implies r = m$, where $m$ is a positive integer.

**Case 2: $x$ is rational.**
Let $x = \frac{p}{q}$ in lowest terms with $q > 1$ and $\gcd(p,q)=1$. For $n=q$, we have:
$$f(q) = \sum_{k=1}^q \left\lfloor \frac{kp}{q} \right\rfloor = \frac{1}{q} \left( p \frac{q(q+1)}{2} - \sum_{k=1}^q (kp \pmod q) \right).$$
Since $\gcd(p,q)=1$, the set $\{kp \pmod q : k=1, \dots, q\}$ is $\{0, 1, \dots, q-1\}$, so the sum is $\frac{q(q-1)}{2}$. Thus:
$$f(q) = \frac{p(q+1) - (q-1)}{2} = \frac{pq + p - q + 1}{2}.$$
For $f(q)$ to be a multiple of $q$, $pq + p - q + 1 = 2mq$ for some integer $m$, which simplifies to $p+1 = q(2m - p + 1)$. This implies $q$ divides $p+1$. Let $p = kq-1$. Then $x = \frac{kq-1}{q} = k - \frac{1}{q}$.
Testing $n=q+1$:
$$f(q+1) = \sum_{j=1}^{q+1} \lfloor j(k - 1/q) \rfloor = k \frac{(q+1)(q+2)}{2} + \sum_{j=1}^{q+1} \lfloor -j/q \rfloor.$$
For $j=1, \dots, q$, $\lfloor -j/q \rfloor = -1$ (since $q > 1$). For $j=q+1$, $\lfloor -(q+1)/q \rfloor = -2$. The sum is $-q-2$.
$$f(q+1) = \frac{k(q+1)(q+2)}{2} - (q+2) = (q+2) \left[ \frac{k(q+1)}{2} - 1 \right].$$
For $f(q+1)$ to be a multiple of $q+1$, we need $(q+2) [ \frac{k(q+1)}{2} - 1 ] \equiv 0 \pmod{q+1}$.
Reducing modulo $q+1$, we get $1 \cdot (-1) \equiv 0 \pmod{q+1}$, so $q+1$ must divide 1, which is impossible for $q \ge 1$.

**Case 3: $x$ is irrational.**
Let $m_n = f(n)/n$. We require $m_n \in \mathbb{Z}$ for all $n$. Note that:
$$m_n = \frac{x(n+1)}{2} - \frac{1}{n} \sum_{k=1}^n \{kx\}.$$
Then $m_{n+1} - m_n = \frac{x}{2} + \frac{S_n - n\{(n+1)x\}}{n(n+1)}$, where $S_n = \sum_{k=1}^n \{kx\}$.
By the equidistribution theorem, $\frac{S_n}{n} \to \frac{1}{2}$ as $n \to \infty$. The term $\frac{S_n - n\{(n+1)x\}}{n(n+1)} = \frac{S_n/n - \{(n+1)x\}}{n+1}$ vanishes as $n \to \infty$.
Thus, $m_{n+1} - m_n \to \frac{x}{2}$. Since $m_n$ are integers, $m_{n+1} - m_n$ must eventually be a constant integer $C$, implying $x = 2C$, which contradicts the assumption that $x$ is irrational.

The only solutions are $x = 2, 4, 6, \dots$, which means $r = 1, 2, 3, \dots$.

The positive real numbers $r$ are the positive integers.

\(\square\)
