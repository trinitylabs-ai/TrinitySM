To prove that there exists a positive integer $N$ such that for every odd integer $n > N$, the digits in the base-$2n$ representation of $n^k$ are all greater than $d$, we analyze the process of finding the digits of $n^k$ in base $2n$.

Let $X_0 = n^k$. The digits $a_0, a_1, \dots, a_m$ of $X_0$ in base $2n$ are determined by the recursive sequence:
$a_i = X_i \pmod{2n}$ and $X_{i+1} = \frac{X_i - a_i}{2n}$, where $X_0$ is the starting value and the process terminates when $X_{m+1} = 0$.

First, we find $a_0$. Since $n$ is odd, $n^{k-1}$ is odd, so $n^{k-1}-1$ is even. We can write:
$n^k = n(n^{k-1}-1) + n = \frac{n^{k-1}-1}{2}(2n) + n$.
Since $0 \le n < 2n$ for $n \ge 1$, we have $a_0 = n$ and $X_1 = \frac{n^{k-1}-1}{2}$.
For any $n > d$, we have $a_0 > d$.

Next, we determine the subsequent digits $a_i$ and quotients $X_i$ for $i \ge 1$. We claim that for $i = 1, 2, \dots, k$, the quotients $X_i$ can be expressed in the form:
$X_i = \frac{n^{k-i} - r_{i-1}}{2^i}$
where $r_{i-1}$ is an odd integer such that $1 \le r_{i-1} < 2^i$.
For $i=1$, we have $X_1 = \frac{n^{k-1}-1}{2}$, so $r_0 = 1$, which is an odd integer in the range $[1, 2^1)$.

Suppose the claim holds for $i$. We find $a_i$ by taking $X_i \pmod{2n}$. Let $r_i$ be the unique odd integer such that $r_i \equiv n^{k-i-1} \pmod{2^{i+1}}$ and $1 \le r_i < 2^{i+1}$. Consider the value:
$a_i = \frac{r_i n - r_{i-1}}{2^i}$.
We verify that $a_i$ is the remainder of $X_i$ modulo $2n$:
1. **Integrality**: Since $r_i \equiv n^{k-i-1} \pmod{2^i}$, we have $r_i n \equiv n^{k-i} \pmod{2^i}$. Since $X_i = \frac{n^{k-i}-r_{i-1}}{2^i}$ is an integer, $n^{k-i} \equiv r_{i-1} \pmod{2^i}$. Thus $r_i n - r_{i-1} \equiv n^{k-i} - r_{i-1} \equiv 0 \pmod{2^i}$, so $a_i$ is an integer.
2. **Range**: Since $1 \le r_i < 2^{i+1}$ and $1 \le r_{i-1} < 2^i$, we have:
$a_i = \frac{r_i n - r_{i-1}}{2^i} < \frac{2^{i+1}n}{2^i} = 2n$.
Also, $a_i \ge \frac{1 \cdot n - (2^i-1)}{2^i} = \frac{n+1}{2^i} - 1$. For $n \ge 2^i-1$, $a_i \ge 0$.
3. **Next Quotient**: The next quotient is:
$X_{i+1} = \frac{X_i - a_i}{2n} = \frac{\frac{n^{k-i}-r_{i-1}}{2^i} - \frac{r_i n - r_{i-1}}{2^i}}{2n} = \frac{n^{k-i} - r_i n}{2^{i+1} n} = \frac{n^{k-i-1} - r_i}{2^{i+1}}$.
This matches the claimed form for $X_{i+1}$, and $X_{i+1}$ is an integer because $r_i \equiv n^{k-i-1} \pmod{2^{i+1}}$.

This induction holds for $i=1, \dots, k-1$. At $i=k-1$, we have $X_{k-1} = \frac{n - r_{k-2}}{2^{k-1}}$. For sufficiently large $n$, $0 \le X_{k-1} < 2n$, so the final digit is $a_{k-1} = X_{k-1}$ and $X_k = \frac{1 - r_{k-1}}{2^k}$. Since $r_{k-1} \equiv n^{k-k} \equiv 1 \pmod{2^k}$, we have $r_{k-1}=1$, so $X_k = 0$.

The digits of $n^k$ in base $2n$ are $a_0, a_1, \dots, a_{k-1}$. We have:
$a_0 = n$
$a_i = \frac{r_i n - r_{i-1}}{2^i}$ for $1 \le i \le k-2$
$a_{k-1} = \frac{n - r_{k-2}}{2^{k-1}}$
For $i \ge 1$, we have $a_i \ge \frac{n+1}{2^i} - 1 \ge \frac{n+1}{2^{k-1}} - 1$.
To ensure all $a_i > d$, we require $n > d$ and $\frac{n+1}{2^{k-1}} - 1 > d$, which simplifies to $n > 2^{k-1}(d+1) - 1$.
Thus, by choosing $N = \max(d, 2^{k-1}(d+1))$, for every odd integer $n > N$, all digits of $n^k$ in base $2n$ are greater than $d$.

\(\square\)
