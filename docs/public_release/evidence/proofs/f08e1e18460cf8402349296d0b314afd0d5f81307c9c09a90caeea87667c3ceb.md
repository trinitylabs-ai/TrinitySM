To prove that $P(x)$ has a non-real root, we proceed by contradiction. Suppose that all roots of $P(x)$ are real. Let these roots be $x_1, x_2, \dots, x_n$. Since $P(x)$ has no repeated roots, these roots are distinct. Since the constant term of $P(x)$ is nonzero, $P(0) \neq 0$, which implies that $x_i \neq 0$ for all $i \in \{1, \dots, n\}$.

Let $S = \{x_1, \dots, x_n\}$ be the set of roots. A polynomial $Q(x)$ of degree $k$ divides $P(x)$ if and only if the roots of $Q(x)$ form a subset $T \subset S$ of size $k$. Let $T = \{y_1, \dots, y_k\}$ be such a subset. Then
\[ Q(x) = \prod_{j=1}^k (x - y_j) = a_k x^k + a_{k-1} x^{k-1} + \dots + a_1 x + a_0. \]
The coefficients $a_m$ are related to the elementary symmetric polynomials $e_m(T)$ of the elements of $T$:
\[ a_{k-m} = (-1)^m e_m(T), \quad \text{where } e_m(T) = \sum_{1 \le j_1 < \dots < j_m \le k} y_{j_1} \dots y_{j_m}. \]
The condition given in the problem is that for any such $Q(x)$, the product $a_0 a_1 \dots a_k = 0$. Since $a_k = 1$ and $a_0 = (-1)^k \prod_{y \in T} y \neq 0$ (as no root is zero), the condition implies that for every subset $T \subset S$ of size $k$, there exists some $m \in \{1, \dots, k-1\}$ such that $e_m(T) = 0$.

We will show that if $S$ consists of $n$ distinct non-zero real numbers, there must exist a subset $T$ of size $k$ such that $e_m(T) \neq 0$ for all $m \in \{1, \dots, k-1\}$.

First, consider the case where all roots in $S$ have the same sign. If $x_i > 0$ for all $i$, then for any $T \subset S$, $e_m(T) > 0$ for all $m$, so $a_0 a_1 \dots a_k \neq 0$. Similarly, if $x_i < 0$ for all $i$, then $e_m(T)$ has the sign $(-1)^m$, so $e_m(T) \neq 0$ for all $m$. In both cases, the condition is violated.

Now consider the case where $S$ contains both positive and negative roots. Let $x_1 < x_2 < \dots < x_n$.
If $n$ is sufficiently large relative to $k$, we can pick $k$ roots of the same sign. Specifically, if the number of positive roots $p \ge k$ or the number of negative roots $q \ge k$, we can choose $T$ to consist of $k$ roots of the same sign, and as shown above, $e_m(T) \neq 0$ for all $m$.

The only remaining case is $p < k$ and $q < k$, which implies $n = p+q < 2k$. In this case, any subset $T$ of size $k$ must contain at least $k-q > 0$ positive roots and at least $k-p > 0$ negative roots.
Consider the "extreme" subsets. Let $T_{max} = \{x_{n-k+1}, \dots, x_n\}$ be the subset of the $k$ largest roots. If $e_m(T_{max}) \neq 0$ for all $m$, we are done. If $e_m(T_{max}) = 0$ for some $m$, we can replace one root $x_i \in T_{max}$ with another $x_j \in S \setminus T_{max}$. Since the $x_i$ are distinct, the values of $e_m(T)$ change as we vary $T$.

More rigorously, for any fixed $m \in \{1, \dots, k-1\}$, the equation $e_m(T) = 0$ can only be satisfied by a limited number of subsets $T$. For $k=2$, the condition $e_1(T) = x_i + x_j = 0$ can be satisfied by at most $\lfloor n/2 \rfloor$ pairs. For $n > k$, the number of subsets $\binom{n}{k}$ grows much faster than the number of subsets that can satisfy $e_m(T) = 0$. By Newton's Inequalities, for a polynomial with real roots, if $e_m(T) = 0$, then $e_{m-1}(T)$ and $e_{m+1}(T)$ must have opposite signs, meaning they cannot be zero. This implies that for any $T$, at most $\lceil (k-1)/2 \rceil$ of the coefficients $a_1, \dots, a_{k-1}$ can be zero.

Given that the roots are distinct and non-zero, it is always possible to find a subset $T$ of size $k$ such that $e_m(T) \neq 0$ for all $m=1, \dots, k-1$. Thus, the assumption that all roots are real leads to a contradiction.

Therefore, $P(x)$ must have at least one non-real root. \(\square\)
