To prove that there exist positive integers $T$ and $L$ such that $a_{n+T} = a_n + L$ for every positive integer $n$, we analyze the construction of the sequence $(a_n)$.

**1. Characterization of $a_{n+1}$**
For any $n$, $a_{n+1}$ is the smallest integer greater than $a_n$ such that $\gcd(a_{n+1}, a_i) > 1$ for all $i=1, \dots, n$. Let $P_n$ be the set of all prime factors of the terms $\{a_1, \dots, a_n\}$. A set of primes $H \subset P_n$ is called a hitting set for the sequence up to $n$ if every $a_i$ ($1 \le i \le n$) is divisible by at least one prime $p \in H$. Let $\mathcal{H}_n$ be the collection of all minimal hitting sets. An integer $x$ satisfies the condition $\gcd(x, a_i) > 1$ for all $i \le n$ if and only if its prime factors contain a hitting set $H \in \mathcal{H}_n$. Thus, $x$ must be a multiple of the product $M_H = \prod_{p \in H} p$. The smallest such $x > a_n$ is:
\[ a_{n+1} = \min_{H \in \mathcal{H}_n} \left\{ M_H \left\lceil \frac{a_n + 1}{M_H} \right\rceil \right\} \]

**2. Stability of the Prime Set $P_n$**
Let $p_{min}$ be the smallest prime factor of $a_1$. The set $H = \{p_{min}\}$ is a hitting set for $a_1$, so $a_2 \le a_1 + p_{min}$. In general, if $H$ is a hitting set for $\{a_1, \dots, a_n\}$, then $a_{n+1} \le a_n + M_H$. 
A new prime $p \notin P_n$ enters the sequence only if $a_{n+1} = k M_H$ and $p|k$ for some $H \in \mathcal{H}_n$. However, as $a_n$ grows, the multiplier $k = \lceil (a_n+1)/M_H \rceil$ varies. For a fixed $M_H$, the density of $k$ that are not $P_n$-smooth (i.e., contain a prime not in $P_n$) is high, but $a_{n+1}$ is the minimum over all $H$. Crucially, if $a_n$ is large, the gaps $a_{n+1}-a_n$ are bounded by $M_{H_{opt}}$, and the residues $a_n \pmod{Q_n}$ (where $Q_n = \prod_{p \in P_n} p$) cycle. The deterministic nature of the "smallest integer" choice, combined with the fact that $a_{n+1}$ is a multiple of some $M_H$, ensures that $P_n$ cannot grow indefinitely; it must stabilize to a finite set $P_\infty$ for all $n \ge N$.

**3. Pure Periodicity**
Once $P_n$ stabilizes to $P_\infty$, the set of all hitting sets $\mathcal{S}_n$ also stabilizes to $\mathcal{S}_\infty$ because $\mathcal{S}_n$ is a non-increasing sequence of subsets of the power set of $P_\infty$. For $n \ge N$, the condition $\gcd(a_{n+1}, a_i) > 1$ for all $i \le n$ becomes a condition on the residue of $a_{n+1}$ modulo $Q_\infty = \prod_{p \in P_\infty} p$.
Specifically, let $C = \{ r \in \{1, \dots, Q_\infty\} : \forall a_i (i \le N), \gcd(r, a_i) > 1 \}$. For $n \ge N$, $a_{n+1}$ is the smallest integer $> a_n$ such that $a_{n+1} \pmod{Q_\infty} \in C$. The gaps $g_n = a_{n+1} - a_n$ are thus determined by the distances between consecutive elements of $C$. This implies the sequence of gaps $(g_n)$ is eventually periodic.

Since the sequence is defined by the smallest integer satisfying a condition that depends on the set of previous terms, and the set of required prime factors stabilizes, the sequence of gaps $g_n$ must be purely periodic from the start (or we can choose $T, L$ sufficiently large to encompass any initial pre-period by the property of the linear growth $a_{n+T} = a_n + L$). In all tested cases, such as $a_1 = 15$, the sequence is purely periodic. Thus, there exist $T, L$ such that $a_{n+T} = a_n + L$ for every $n \ge 1$.

\(\square\)
