To prove that there exists a positive integer $N$ such that for every odd integer $n > N$, the digits in the base-$2n$ representation of $n^k$ are all greater than $d$, we examine the digits $a_i$ of $n^k$ in base $B = 2n$.

The representation of $n^k$ in base $2n$ is given by:
\[ n^k = a_m (2n)^m + a_{m-1} (2n)^{m-1} + \dots + a_1 (2n) + a_0 \]
where $0 \le a_i < 2n$. The digits $a_i$ are determined by the recurrence $S_0 = n^k$ and $S_{i+1} = \lfloor S_i / (2n) \rfloor$, where $a_i = S_i \pmod{2n}$.

First, consider the digit $a_0$:
\[ a_0 = n^k \pmod{2n} \]
Since $n$ is odd, $n^{k-1}$ is odd, which implies $n^{k-1}-1$ is even. We can write:
\[ n^k = n(n^{k-1}-1) + n = \frac{n^{k-1}-1}{2}(2n) + n \]
Since $0 \le n < 2n$, we have $a_0 = n$. For any $n > d$, $a_0 > d$.

Next, consider the digits $a_j$ for $j \ge 1$. The sequence $S_j$ is given by:
\[ S_j = \left\lfloor \frac{n^k}{(2n)^j} \right\rfloor = \left\lfloor \frac{n^{k-j}}{2^j} \right\rfloor \]
The largest digit index $m$ is such that $(2n)^m \le n^k < (2n)^{m+1}$. This implies $m \le \lfloor \log_{2n} n^k \rfloor < k$.
For $1 \le j \le m$, let $r = k-j$. Since $j < k$, we have $r \ge 1$.
The digit $a_j$ is given by:
\[ a_j = S_j \pmod{2n} = \left\lfloor \frac{n^r}{2^j} \right\rfloor \pmod{2n} \]

Case 1: $r=1$.
Then $a_j = \lfloor \frac{n}{2^j} \rfloor \pmod{2n}$. Since $0 \le \lfloor \frac{n}{2^j} \rfloor < n < 2n$, we have $a_j = \lfloor \frac{n}{2^j} \rfloor$.
This is greater than $d$ if $n \ge 2^j(d+1)$.

Case 2: $r \ge 2$.
We write $n^{r-1} = 2^{j+1} Q + \rho$, where $\rho$ is the remainder of $n^{r-1}$ modulo $2^{j+1}$. Since $n$ is odd, $n^{r-1}$ is odd, so $\rho \in \{1, 3, \dots, 2^{j+1}-1\}$.
Then:
\[ \frac{n^r}{2^j} = \frac{n(2^{j+1} Q + \rho)}{2^j} = 2n Q + \frac{n \rho}{2^j} \]
Thus:
\[ a_j = \left\lfloor 2n Q + \frac{n \rho}{2^j} \right\rfloor \pmod{2n} = \left\lfloor \frac{n \rho}{2^j} \right\rfloor \pmod{2n} \]
Since $1 \le \rho \le 2^{j+1}-1$, we have $0 < \frac{n \rho}{2^j} < \frac{n(2^{j+1})}{2^j} = 2n$.
Therefore, $a_j = \lfloor \frac{n \rho}{2^j} \rfloor$.
Since $\rho \ge 1$, we have $a_j \ge \lfloor \frac{n}{2^j} \rfloor$.
This is greater than $d$ if $n \ge 2^j(d+1)$.

In all cases for $0 \le j \le m$, the digits $a_j$ are at least $\lfloor \frac{n}{2^j} \rfloor$ (with $a_0 = n$).
To ensure $a_j > d$ for all $j \in \{0, \dots, m\}$, it suffices to have:
\[ \left\lfloor \frac{n}{2^j} \right\rfloor > d \quad \text{for all } 1 \le j < k \]
This is satisfied if $n \ge 2^{k-1}(d+1) + 1$.
Thus, choosing $N = 2^{k-1}(d+1)$ ensures that for every odd integer $n > N$, all digits $a_j$ are greater than $d$.
