Let $k$ and $d$ be positive integers. We wish to show that there exists a positive integer $N$ such that for every odd integer $n > N$, the digits of $n^k$ in base $2n$ are all greater than $d$.

Let the base-$2n$ representation of $n^k$ be
$$n^k = a_m(2n)^m + a_{m-1}(2n)^{m-1} + \dots + a_1(2n) + a_0$$
where $0 \le a_i < 2n$ for all $i \in \{0, 1, \dots, m\}$.

**1. Determining the first digit $a_0$**
The digit $a_0$ is given by $a_0 = n^k \pmod{2n}$. Since $n$ is a divisor of $n^k$, $a_0$ must be a multiple of $n$. In the range $0 \le a_0 < 2n$, the only multiples of $n$ are $0$ and $n$. Since $n$ is odd, $n^k$ is odd, while $2n$ is even. Thus, $n^k$ cannot be divisible by $2n$, so $a_0 \neq 0$. Therefore, $a_0 = n$. For any $n > d$, we have $a_0 > d$.

**2. Determining the subsequent digits $a_i$**
We define a sequence $Y_i$ such that $Y_1 = \frac{n^k - a_0}{2n} = \frac{n^k - n}{2n} = \frac{n^{k-1}-1}{2}$. The digits for $i \ge 1$ are given by $a_i = Y_i \pmod{2n}$, and the sequence continues as $Y_{i+1} = \lfloor \frac{Y_i}{2n} \rfloor$.
By iteration, $Y_i = \lfloor \frac{Y_1}{(2n)^{i-1}} \rfloor = \lfloor \frac{n^{k-1}-1}{2(2n)^{i-1}} \rfloor = \lfloor \frac{n^{k-i}}{2^i} - \frac{1}{2^i n^{i-1}} \rfloor$.
For $i \ge k$, $Y_i = \lfloor \frac{n^{k-i}}{2^i} - \frac{1}{2^i n^{i-1}} \rfloor$. Since $n \ge 1$, $0 \le \frac{n^{k-i}}{2^i} - \frac{1}{2^i n^{i-1}} < 1$ for $i \ge k$, so $Y_i = 0$. Thus, the leading digit index $m$ is at most $k-1$.

For $1 \le i < k$, let $n^{k-i} = 2^i q_i + r_i$ where $r_i \in \{1, 3, \dots, 2^i-1\}$. Then
$$Y_i = \lfloor q_i + \frac{r_i}{2^i} - \frac{1}{2^i n^{i-1}} \rfloor = q_i + \lfloor \frac{r_i n^{i-1} - 1}{2^i n^{i-1}} \rfloor$$
Since $r_i \ge 1$ and $n > 1$, $0 < \frac{r_i n^{i-1} - 1}{2^i n^{i-1}} < 1$, so $Y_i = q_i = \frac{n^{k-i} - r_i}{2^i}$.
Now we find $a_i = Y_i \pmod{2n} = Y_i - 2n \lfloor \frac{Y_i}{2n} \rfloor$.
$$\frac{Y_i}{2n} = \frac{n^{k-i} - r_i}{2^{i+1} n} = \frac{n^{k-i-1}}{2^{i+1}} - \frac{r_i}{2^{i+1} n}$$
Let $n^{k-i-1} = 2^{i+1} q_{i+1} + r_{i+1}$ where $r_{i+1} \in \{1, 3, \dots, 2^{i+1}-1\}$. Then
$$\frac{Y_i}{2n} = q_{i+1} + \frac{r_{i+1}}{2^{i+1}} - \frac{r_i}{2^{i+1} n} = q_{i+1} + \frac{n r_{i+1} - r_i}{2^{i+1} n}$$
For $n > 2^i$, we have $0 < n r_{i+1} - r_i < 2^{i+1} n$ because $r_{i+1} \ge 1$ and $r_i < 2^i$. Thus, $0 < \frac{n r_{i+1} - r_i}{2^{i+1} n} < 1$, which implies $\lfloor \frac{Y_i}{2n} \rfloor = q_{i+1} = \frac{n^{k-i-1} - r_{i+1}}{2^{i+1}}$.
Substituting these into the formula for $a_i$:
$$a_i = \frac{n^{k-i} - r_i}{2^i} - 2n \left( \frac{n^{k-i-1} - r_{i+1}}{2^{i+1}} \right) = \frac{n^{k-i} - r_i - (n^{k-i} - n r_{i+1})}{2^i} = \frac{n r_{i+1} - r_i}{2^i}$$
Since $r_{i+1} \ge 1$ and $r_i \le 2^i-1$, we have $a_i \ge \frac{n - (2^i-1)}{2^i} = \frac{n+1}{2^i} - 1$.

**3. Conclusion**
For any $1 \le i \le k-1$, $a_i \ge \frac{n+1}{2^{k-1}} - 1$. To ensure $a_i > d$ for all $i \in \{0, \dots, k-1\}$, we require:
1. $n > d$ (for $a_0$)
2. $n > 2^{k-1}(d+1) - 1$ (for $a_i, i \ge 1$)
3. $n > 2^{k-1}$ (to ensure the floor approximations are valid).

Let $N$ be the maximum of these bounds. For any odd $n > N$, $a_0 = n > d$ and $a_i \ge \frac{n+1}{2^{k-1}} - 1 > d$ for $1 \le i \le m \le k-1$. Thus, all digits in the base-$2n$ representation of $n^k$ are greater than $d$.
