To prove that $n \geq 5$ for the equation $p^n = a^4 + b^4$, where $p$ is a prime and $a, b, n$ are positive integers with $n \geq 2$, we analyze the equation based on the prime $p$.

### Case 1: $p = 2$
If $p = 2$, we have $2^n = a^4 + b^4$. Let $d = \gcd(a, b)$. Then $a = dx$ and $b = dy$ with $\gcd(x, y) = 1$. Substituting these into the equation gives $d^4(x^4 + y^4) = 2^n$. This implies $d$ must be a power of 2, say $d = 2^k$. Thus, $x^4 + y^4 = 2^{n-4k}$. Let $m = n-4k$.
Since $\gcd(x, y) = 1$ and $x^4 + y^4 = 2^m$, both $x$ and $y$ must be odd (if one were even, the other would be even, contradicting $\gcd(x, y)=1$, or $x^4+y^4$ would be odd). For any odd integer $z$, $z^4 \equiv 1 \pmod{16}$. Thus, $x^4 + y^4 \equiv 1 + 1 = 2 \pmod{16}$.
The only power of 2 that is congruent to $2 \pmod{16}$ is $2^1 = 2$. Therefore, $m = 1$, which means $n - 4k = 1$, or $n = 4k + 1$. Since $n \geq 2$, the smallest possible value for $k$ is $k=1$, which gives $n = 5$.

### Case 2: $p > 2$
Let $d = \gcd(a, b)$. Then $a = dx$ and $b = dy$ with $\gcd(x, y) = 1$. Substituting these into the equation gives $d^4(x^4 + y^4) = p^n$. This implies $d$ is a power of $p$, say $d = p^k$. Then $x^4 + y^4 = p^{n-4k}$. Let $m = n-4k$.
If $n \in \{2, 3, 4\}$, then since $k \geq 1$ would imply $m \leq 0$ (which is impossible for $x, y \geq 1$), we must have $k=0$, so $m=n \in \{2, 3, 4\}$. We prove $x^4 + y^4 = p^m$ has no solutions for $m \in \{2, 3, 4\}$ with $\gcd(x, y) = 1$.

**Subcase $m=2$ and $m=4$:**
The equation $x^4 + y^4 = p^2$ is a specific case of $x^4 + y^4 = z^2$. Fermat proved using the method of infinite descent that this equation has no non-trivial integer solutions. Similarly, $x^4 + y^4 = p^4$ is a case of Fermat's Last Theorem for $n=4$, which also has no non-trivial solutions.

**Subcase $m=3$:**
Consider $x^4 + y^4 = p^3$ with $\gcd(x, y) = 1$. In the Gaussian integers $\mathbb{Z}[i]$, this factors as $(x^2 + iy^2)(x^2 - iy^2) = p^3$. Since $p$ must be $\equiv 1 \pmod{4}$ to be a sum of two squares, $p = \pi \bar{\pi}$ for some Gaussian prime $\pi$. 
Let $\delta = \gcd(x^2 + iy^2, x^2 - iy^2)$. Then $\delta$ divides $2x^2$ and $2iy^2$, so $\delta$ divides $2$. In $\mathbb{Z}[i]$, $2 = -i(1+i)^2$. If $1+i \mid x^2 + iy^2$, then $x^2 + iy^2 \equiv 0 \pmod{1+i}$. Since $i \equiv -1 \pmod{1+i}$, this implies $x^2 - y^2 \equiv 0 \pmod{1+i}$, meaning $x^2 - y^2$ is even. However, since $x^4 + y^4 = p^3$ and $p$ is odd, $x$ and $y$ must have opposite parity, so $x^2 - y^2$ is odd. Thus $\delta$ is a unit, and the factors $x^2 + iy^2$ and $x^2 - iy^2$ are coprime.
Thus, $x^2 + iy^2 = u \pi^3$ for some unit $u \in \{1, -1, i, -i\}$.
Let $\pi = a + bi$. For $u=1$, we have $x^2 + iy^2 = (a+bi)^3 = a(a^2 - 3b^2) + ib(3a^2 - b^2)$. Equating real and imaginary parts:
\[ x^2 = a(a^2 - 3b^2) \quad \text{and} \quad y^2 = b(3a^2 - b^2) \]
Since $\gcd(x, y) = 1$, we have $\gcd(a, b) = 1$. Thus $\gcd(a, a^2 - 3b^2) = \gcd(a, 3)$.
If $\gcd(a, 3) = 1$, then $a$ and $a^2 - 3b^2$ are both squares. Let $a = u^2$. Then $y^2 = b(3u^4 - b^2)$. Since $\gcd(b, 3u^4 - b^2) = \gcd(b, 3)$, we have two possibilities:
1. $\gcd(b, 3) = 1$: Then $b$ and $3u^4 - b^2$ are squares. Let $b = w^2$. Then $3u^4 - w^4 = z^2$, or $z^2 + w^4 = 3u^4$. Modulo 3, $z^2 + w^4 \equiv 0 \pmod{3}$ implies $3 \mid z$ and $3 \mid w$. Let $z=3Z, w=3W$. Then $9Z^2 + 81W^4 = 3u^4 \implies 3Z^2 + 27W^4 = u^4$, so $3 \mid u$. Let $u=3U$. Then $3Z^2 + 27W^4 = 81U^4 \implies Z^2 + 9W^4 = 27U^4$, which implies $3 \mid Z$. Let $Z=3\zeta$, then $9\zeta^2 + 9W^4 = 27U^4 \implies \zeta^2 + W^4 = 3U^4$. This is the same equation with $U < u$, leading to an infinite descent.
2. $\gcd(b, 3) = 3$: Then $b = 3w^2$ and $y^2 = 3w^2(3u^4 - 9w^4) = 9w^2(u^4 - 3w^4)$, so $u^4 - 3w^4 = z^2$, or $z^2 + 3w^4 = u^4$. Then $(u^2 - z)(u^2 + z) = 3w^4$. Since $\gcd(u, w) = 1$, $\gcd(u^2 - z, u^2 + z)$ is 1 or 2. If the gcd is 1, then $2u^2 = s^4 + 3t^4$, which for $s, t$ odd gives $2u^2 \equiv 1 + 3 \equiv 4 \pmod{16} \implies u^2 \equiv 2 \pmod{8}$, impossible. If the gcd is 2, then $u^2 = s^4 + 3t^4$. For $u$ to be odd, $s$ must be odd and $t$ even. Then $u^2 - s^4 = 3t^4 \implies (u - s^2)(u + s^2) = 3t^4$. With $\gcd(u-s^2, u+s^2)=2$, we have $(u-s^2)/2 \cdot (u+s^2)/2 = 3(t/2)^4$. Thus $\{ (u-s^2)/2, (u+s^2)/2 \} = \{ s_1^4, 3t_1^4 \}$. This implies $s^2 = 3t_1^4 - s_1^4$ or $s^2 = s_1^4 - 3t_1^4$. The former is $s^2 + s_1^4 = 3t_1^4$ (already solved by descent) and the latter is $s^2 + 3t_1^4 = s_1^4$, which is the same form as $z^2 + 3w^4 = u^4$ but with $s_1 < u$, leading to infinite descent.
If $\gcd(a, 3) = 3$, let $a = 3u^2$. Then $x^2 = 3u^2(9u^4 - 3b^2) = 9u^2(3u^4 - b^2)$, so $3u^4 - b^2$ is a square. Also $y^2 = b(27u^4 - b^2)$. Since $\gcd(b, 27u^4 - b^2) = 1$, $b$ must be a square, say $b = w^2$. Then $3u^4 - w^4 = z^2$, which we already showed has no non-trivial solutions.
Other units $u$ lead to the same systems. If $u = -1$, we replace $\pi$ with $-\pi$. If $u = i$, then $x^2 + iy^2 = i(a+bi)^3 = -b(3a^2 - b^2) + ia(a^2 - 3b^2)$, giving $x^2 = b(b^2 - 3a^2)$ and $y^2 = a(a^2 - 3b^2)$, which is the same system with $a$ and $b$ swapped. If $u = -i$, we replace $\pi$ with $-\pi$ in the $u=i$ case.

Thus, $n \in \{2, 3, 4\}$ is impossible. Since $n \geq 2$ and $n \notin \{2, 3, 4\}$, we must have $n \geq 5$.

\(\square\)
