To find the minimum possible value of $A$, the number of triples $1 \le i < j < k \le 18$ such that $a_i + a_j + a_k \ge 3m$, we let $b_i = a_i - m$. The average of $b_i$ is 0, so $\sum_{i=1}^{18} b_i = 0$. The condition $a_i + a_j + a_k \ge 3m$ is equivalent to $b_i + b_j + b_k \ge 0$. We seek to minimize the number of such triples.

Consider the case where one number is positive and the others are negative. Let $b_1, \dots, b_{17} < 0$ and $b_{18} > 0$. Since $\sum_{i=1}^{18} b_i = 0$, we have $b_{18} = -\sum_{i=1}^{17} b_i$. For any $i, j < 18$, the sum of the triple $(b_i, b_j, b_{18})$ is:
\[ b_i + b_j + b_{18} = b_i + b_j - \sum_{k=1}^{17} b_k = -\sum_{k \neq i, j, 18} b_k. \]
Since all $b_k$ for $k < 18$ are negative, the sum $-\sum_{k \neq i, j, 18} b_k$ is positive. Thus, every triple containing $b_{18}$ is non-negative. There are $\binom{17}{2} = \frac{17 \times 16}{2} = 136$ such triples. Any triple not containing $b_{18}$ consists of three negative numbers and thus has a negative sum. Therefore, for this configuration, $A = 136$.

We check if $A$ can be smaller. If we have $p$ positive numbers $b_{n-p+1}, \dots, b_n$ and $n-p$ negative numbers $b_1, \dots, b_{n-p}$, we can set $b_1 = \dots = b_{n-p} = -1$ and $b_{n-p+1} = \dots = b_{n-1} = \epsilon$ for a very small $\epsilon > 0$. Then $b_n = (n-p) - (p-1)\epsilon$.
The triples that are non-negative are:
1. Triples containing $b_n$:
   - Two other positive numbers: $\binom{p-1}{2}$ triples.
   - One positive, one negative: $(p-1)(n-p)$ triples.
   - Two negative numbers: $\binom{n-p}{2}$ triples. Sum is $(n-p-2) - (p-1)\epsilon$. This is $\ge 0$ if $n-p \ge 2$ and $\epsilon$ is sufficiently small. If $n-p=2$, this specific triple is negative.
2. Triples not containing $b_n$:
   - Three positive numbers: $\binom{p-1}{3}$ triples. Sum $3\epsilon > 0$.
   - Other combinations will have negative sums for small $\epsilon$.

For $n=18$, if we choose $p=1$, $A = \binom{17}{2} = 136$. If we choose $p=2$, $A = \binom{17}{2} + \binom{1}{3} = 136$. If $p=3$, $A = 136 + \binom{2}{3} = 136$. For $p \ge 4$, $A$ increases. If $n-p < 2$, $A$ also increases. Specifically, if $n-p=2$ ($p=16$), $A = \binom{15}{2} + 15 \times 2 + \binom{15}{3} = 105 + 30 + 455 = 590$.

Finally, we note that the sum of all $\binom{18}{3}$ triples is $\binom{17}{2} \sum b_i = 0$. This implies at least one triple must be non-negative. However, the construction above shows that the minimum is 136.

The minimum possible value of $A$ is 136.
