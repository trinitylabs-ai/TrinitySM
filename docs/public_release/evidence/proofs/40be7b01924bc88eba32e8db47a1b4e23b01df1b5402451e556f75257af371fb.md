To determine the smallest positive integer $n$ such that James can reach the last row $R_{3002}$ before receiving $n$ penalties, we let $M = 3000$ be the number of rows Peter selects cells from and $K = 3001$ be the number of columns. Peter's selected cells are $S = \{(i, c_i) : i = 2, \dots, M+1\}$, where $c_i \in \{1, \dots, K\}$ are distinct. James starts at $(1, 1)$ and aims to reach $R_{M+2}$.

Let $f(M, K)$ be the maximum number of penalties James must receive to guarantee reaching the final row.
For $M=1, K=2$, $S = \{(2, c_2)\}$. James tries $P_1 = \{(1,1), (2,1), (3,1)\}$. If he hits $(2,1)$, then $c_2=1$, and $P_2 = \{(1,1), (1,2), (2,2), (3,2)\}$ is safe. Thus, $f(1, 2) = 1$.

For $M=2, K=3$, $S = \{(2, c_2), (3, c_3)\}, c_2 \neq c_3$. James tries $P_1 = \{(1,1), (2,1), (3,1), (4,1)\}$.
1. If $P_1$ hits $(2,1)$, then $c_2=1$. $S = \{(2,1), (3, c_3)\}$ with $c_3 \in \{2, 3\}$. The path $P_2 = \{(1,1), (1,2), (2,2), (3,1), (4,1)\}$ is safe because $(2,2)$ is safe ($c_2=1$) and $(3,1)$ is safe ($c_3 \neq 1$).
2. If $P_1$ hits $(3,1)$, then $c_3=1$. $S = \{(2, c_2), (3,1)\}$ with $c_2 \in \{2, 3\}$. Any path $P_2$ to $R_4$ must use some $(2, j)$. If $j=1$, James must move to $R_3$ via $(2,2)$ or $(3,1)$. Since $(3,1) \in S$, he must use $(2,2)$, but Peter could have $c_2=2$. If $j \in \{2, 3\}$, Peter could have $c_2=j$. Thus, no single $P_2$ is safe for all $c_2 \in \{2, 3\}$. James will need at most one more penalty to identify $c_2$ and then use a safe path.
Thus, $f(2, 3) = 1 + f(1, 2) = 2$.

By induction, if James hits a cell $(i, j)$ on his first path $P_1$ (where $P_1$ is a straight line down column 1), he identifies $c_i = j$. The problem then reduces to finding a path avoiding $M-1$ cells in $K-1$ columns. The structure of the constraints (one cell per row and column) ensures that the most efficient strategy is to resolve the remaining rows one by one. Each penalty identifies the column of one row, reducing the remaining problem size.

The recurrence relation is $f(M, K) = 1 + f(M-1, K-1)$.
Given $f(1, 2) = 1$, we have:
$f(2, 3) = 2$
$f(3, 4) = 3$
$\dots$
$f(M, M+1) = M$.
For $M = 3000$, the maximum number of penalties is $f(3000, 3001) = 3000$.
The problem asks for the smallest $n$ such that James achieves his goal *before* receiving $n$ penalties. This means he can receive at most $n-1$ penalties.
$n-1 = 3000 \implies n = 3001$.

\(\square\)
