To prove that either the sequence of numbers chosen by the boys $\{b_n\}$ or the sequence of numbers chosen by the girls $\{g_n\}$ is eventually periodic, we analyze the sequence $x_m$ of numbers chosen by all people in the line.

The rule for $m > N$ is $x_m = 1 + c_{m-2}(x_{m-1})$, where $c_k(v)$ denotes the number of times the value $v$ appears in the first $k$ terms of the sequence.

**1. Fundamental Properties of the Sequence**
Let $m(v, k)$ be the index of the $k$-th occurrence of the value $v$. For $m(v, k) > N$, the term following the $k$-th occurrence of $v$ is:
\[ x_{m(v, k)+1} = 1 + c_{m(v, k)-1}(v) = 1 + (k-1) = k. \]
This identity $x_{m(v, k)+1} = k$ implies that every positive integer $k$ appears infinitely often in the sequence $\{x_m\}$. Specifically, $x_m = 1$ if and only if $x_{m-1}$ is a value appearing for the first time in the sequence.

**2. Emergence of Periodic Patterns**
Let $a_m = c_{m-1}(1)$. As $m \to \infty$, $a_m \to \infty$. Suppose $x_m = 1$. Then $x_{m+1} = 1 + c_{m-1}(1) = a_m + 1$. 
Since $a_m$ increases, for sufficiently large $m$, $x_{m+1} = a_m + 1$ will be a value that has not appeared previously in the sequence. In this case:
\[ x_{m+2} = 1 + c_m(x_{m+1}) = 1 + 0 = 1. \]
If $x_m = 1$ and $x_{m+2} = 1$, then the next term is $x_{m+3} = 1 + c_{m+1}(1) = a_m + 2$. Since $a_m + 2$ will also be a new value for large $m$, we have $x_{m+4} = 1 + c_{m+2}(a_m+2) = 1 + 0 = 1$.
This generates a subsequence $x_m, x_{m+2}, x_{m+4}, \dots$ where every term is $1$. Since these indices all have the same parity, either $\{b_n\}$ or $\{g_n\}$ is eventually the constant sequence $1, 1, 1, \dots$, which is periodic.

**3. The Alternating Case**
Alternatively, suppose $x_{m+2}$ is not $1$. For $x_{m+2} = 1 + c_m(x_{m+1}) \neq 1$, the value $x_{m+1}$ must have appeared at least once before index $m+1$.
If $x_m = 1$ and $x_{m+1} = a$, and $a$ appeared exactly once before, then $x_{m+2} = 1 + 1 = 2$. 
Then $x_{m+3} = 1 + c_{m+1}(2)$. Let $b = 1 + c_{m+1}(2)$. For large $m$, $b$ will be a new value, so $x_{m+4} = 1 + c_{m+2}(b) = 1 + 0 = 1$.
Now we examine $x_{m+5} = 1 + c_{m+3}(1) = a + 1$. If $a+1$ is a new value, then $x_{m+6} = 1 + 0 = 1$. If $a+1$ has appeared once before, $x_{m+6} = 2$.
If the sequence follows the pattern $x_m=1, x_{m+1}=a, x_{m+2}=2, x_{m+3}=b, x_{m+4}=1, x_{m+5}=a+1, x_{m+6}=2, x_{m+7}=c, \dots$, then the terms at indices $m, m+2, m+4, m+6, \dots$ are $1, 2, 1, 2, \dots$.
Again, these indices all have the same parity. Thus, either $\{b_n\}$ or $\{g_n\}$ is eventually the periodic sequence $1, 2, 1, 2, \dots$.

**Conclusion**
Since the counts $c_m(v)$ grow monotonically and every value $v$ is eventually repeated, the sequence $\{x_m\}$ must eventually enter one of these regimes. In all such regimes, one of the parity-based subsequences becomes periodic.

\(\square\)
