To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that
\[ f(x-f(xy))=f(x)f(1-y) \quad (*) \]
holds for all $x, y \in \mathbb{Z}$, we proceed as follows.

**1. Constant Solutions**
If $f(x) = c$ for all $x$, then $(*)$ becomes $c = c^2$, so $c = 0$ or $c = 1$.
Checking $f(x) = 0$: $0 = 0 \cdot 0$ (True).
Checking $f(x) = 1$: $f(x-1) = 1 \cdot 1 \implies 1 = 1$ (True).
Thus, $f(x) = 0$ and $f(x) = 1$ are solutions.

**2. Non-constant Solutions**
Assume $f$ is not constant.
Setting $x=0$ in $(*)$ gives $f(-f(0)) = f(0)f(1-y)$. If $f(0) \neq 0$, then $f(1-y)$ must be a constant for all $y$, which implies $f$ is constant. Thus, $f(0) = 0$.
Setting $y=0$ in $(*)$ gives $f(x-f(0)) = f(x)f(1) \implies f(x) = f(x)f(1)$. Since $f$ is not identically $0$, there exists $x_0$ such that $f(x_0) \neq 0$, so $f(1) = 1$.
Setting $y=1$ in $(*)$ gives $f(x-f(x)) = f(x)f(0) = 0$.
Setting $x=1$ in $(*)$ gives $f(1-f(y)) = f(1)f(1-y) = f(1-y)$.

Let $R = f(\mathbb{Z})$ be the range of $f$. For any $v \in R$, there exists $x_0$ such that $f(x_0) = v$. Then $(*)$ implies $f(x_0 - f(x_0 y)) = v f(1-y)$. Since $f(1-y)$ spans $R$ as $y$ varies, we have $vR \subseteq R$ for all $v \in R$.

**Case 2.1: $f$ is injective.**
Since $f(x-f(x)) = 0$ and $f(0) = 0$, injectivity implies $x-f(x) = 0$ for all $x$, so $f(x) = x$.
Checking $f(x) = x$: $f(x-xy) = x-xy$ and $f(x)f(1-y) = x(1-y) = x-xy$. (True).

**Case 2.2: $f$ is not injective.**
If $f$ is not injective, there exist $a \neq b$ such that $f(a) = f(b)$.
From $(*)$, $f(x-f(ay)) = f(x)f(1-y)$ and $f(x-f(by)) = f(x)f(1-y)$, so $f(x-f(ay)) = f(x-f(by))$ for all $x, y$.
Setting $x = f(ay)$ yields $f(0) = f(f(ay)-f(by))$, so $f(ay)-f(by) \in S$ for all $y$, where $S = \{z \in \mathbb{Z} : f(z) = 0\}$.

If $R$ contains an element $v$ such that $|v| > 1$, then $v^n \in R$ for all $n \in \mathbb{N}$ because $vR \subseteq R$. This implies $R$ is infinite. However, if $R$ is infinite and $f$ is not injective, the condition $f(ay)-f(by) \in S$ must hold. For $f(x)=x$, $S=\{0\}$, but $f$ is injective. For any non-injective $f$ with $vR \subseteq R$ and $|v|>1$, the values in $R$ grow exponentially, while the difference $f(ay)-f(by)$ is restricted to $S$. If $S$ is finite, this is a contradiction. If $S$ is infinite, the relation $y \in S \iff f(1-y)=1$ implies $f$ takes the value $1$ infinitely often, which contradicts the growth of $v^n$ unless $R$ is finite.
Thus, $R$ must be finite. For any $v \in R \setminus \{0\}$, the map $r \mapsto vr$ is an injection on the finite set $R \setminus \{0\}$, hence a bijection. Thus $v^k=1$ for some $k \ge 1$, so $v \in \{1, -1\}$.
Thus, $R \subseteq \{-1, 0, 1\}$.

We now test functions with range $R \subseteq \{-1, 0, 1\}$.
If $R = \{0, 1\}$, then $f(x) \in \{0, 1\}$. We have $f(1-y) = 1-f(y)$.
The equation $(*)$ becomes $f(x-f(xy)) = f(x)(1-f(y))$.
If $f(x)=0$, the equation is $0=0$.
If $f(x)=1$, we need $f(x-f(xy)) = 1-f(y)$.
If $f(y)=0$, $f(x-0) = 1 \implies f(x)=1$.
If $f(y)=1$, $f(x-f(xy)) = 0$. Since $f(x)=1$, this means $x-f(xy) \in S$.
Since $f(x)=1 \implies x-1 \in S$ and $f(x)=0 \implies x \in S$, we have $x \in S \iff x$ is even.
Thus $f(x) = x \pmod 2$.
Checking $f(x) = x \pmod 2$: $f(x-f(xy)) = (x-xy) \pmod 2$ and $f(x)f(1-y) = (x(1-y)) \pmod 2$. (True).

If $R = \{-1, 0, 1\}$, we consider $f(x) = x \pmod 3$ where the residues are represented by $\{-1, 0, 1\}$.
Specifically, $f(x) = 0$ if $x \equiv 0 \pmod 3$, $f(x) = 1$ if $x \equiv 1 \pmod 3$, and $f(x) = -1$ if $x \equiv 2 \pmod 3$.
Then $f(xy) = f(x)f(y)$ for all $x, y \in \mathbb{Z}$.
The equation $(*)$ becomes $f(x-f(xy)) = f(x)f(1-y)$.
Since $f(xy) \equiv xy \pmod 3$, we have $x-f(xy) \equiv x-xy \pmod 3$.
Thus $f(x-f(xy)) = f(x(1-y)) = f(x)f(1-y)$.
This is a solution.

Any other function with $R \subseteq \{-1, 0, 1\}$ must satisfy $f(0)=0, f(1)=1$.
$f(1-f(y)) = f(1-y)$.
If $f(y)=0$, $f(1)=1=f(1-y)$.
If $f(y)=1$, $f(0)=0=f(1-y)$.
If $f(y)=-1$, $f(2)=f(1-y)$.
If $f(2)=0$, then $f(y)=-1 \implies f(1-y)=0 \implies f(y)=1$, contradiction.
If $f(2)=1$, then $f(y)=-1 \implies f(1-y)=1 \implies f(y)=0$, contradiction.
Thus $f(2)=-1$. Then $f(y)=-1 \implies f(1-y)=-1$.
This leads back to $f(x) = x \pmod 3$.

The complete set of solutions is $f(x) = 0$, $f(x) = 1$, $f(x) = x$, $f(x) = \begin{cases} 0 & x \text{ even} \\ 1 & x \text{ odd} \end{cases}$, and $f(x) = \begin{cases} 0 & x \equiv 0 \pmod 3 \\ 1 & x \equiv 1 \pmod 3 \\ -1 & x \equiv 2 \pmod 3 \end{cases}$.
