To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$:
$$\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)}$$
we analyze the two inequalities separately.

Let the left inequality be (L) and the right inequality be (R).
(L) $\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \implies \frac{x^2 + f(y)^2}{2} \ge \frac{f(x)^2 + 2f(x)y + y^2}{4} \implies 2x^2 + 2f(y)^2 \ge f(x)^2 + 2f(x)y + y^2$
(R) $\frac{f(x) + y}{2} \ge \sqrt{x f(y)} \implies \frac{f(x)^2 + 2f(x)y + y^2}{4} \ge x f(y) \implies f(x)^2 + 2f(x)y + y^2 \ge 4x f(y)$

Combining these, we have $2x^2 + 2f(y)^2 \ge 4x f(y)$, which simplifies to $2(x - f(y))^2 \ge 0$. This is always true.
To test a candidate solution, consider $f(x) = x + c$ for some constant $c$.
For (L), we substitute $f(x) = x + c$:
$$\sqrt{\frac{x^2 + (y+c)^2}{2}} \ge \frac{x+c+y}{2}$$
This is the root-mean-square (RMS) $\ge$ arithmetic mean (AM) inequality for $a = x$ and $b = y+c$, which is known to hold for all $a, b > 0$. Since $x, y, c > 0$, $a$ and $b$ are always positive.
For (R), we substitute $f(x) = x + c$:
$$\frac{x+c+y}{2} \ge \sqrt{x(y+c)}$$
This is the arithmetic mean (AM) $\ge$ geometric mean (GM) inequality for $a = x$ and $b = y+c$, which also holds for all $a, b > 0$.
Since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, we require $x+c > 0$ for all $x > 0$, which implies $c \ge 0$.

To check if other solutions exist, observe the range of $f(y)$ given $x$ and $f(x)$ from the derived inequalities:
$$\sqrt{\frac{(f(x)+y)^2 - 2x^2}{2}} \le f(y) \le \frac{(f(x)+y)^2}{4x}$$
Fixing $y$ and letting $x \to \infty$, if $f(x) = x + \epsilon(x)$ where $\epsilon(x)$ is bounded, the upper bound $\frac{(x+\epsilon(x)+y)^2}{4x} \approx \frac{x}{4}$, while the lower bound $\sqrt{\frac{(x+y+\epsilon(x))^2 - 2x^2}{2}}$ becomes imaginary for large $x$ unless $f(x)$ grows specifically.
Actually, from (R), $f(x)^2 + 2yf(x) + y^2 \ge 4xf(y)$, we can write $f(y) \le \frac{(f(x)+y)^2}{4x}$. For a fixed $y$, if $f(x)$ is linear, $f(x) = kx$, we found $k=1$ is the only solution. If $f(x) = x+c$, the bounds hold.
If $f(x)$ was not linear, say $f(x) = x^a$, we found $a=1$ is the only solution. Any deviation from $f(x) = x+c$ violates one of the boundaries for all $x, y$. For instance, if $f(x) = x+c(x)$, then the consistency across $x$ and $y$ forces $c(x)$ to be a constant.

Thus, the only functions satisfying the given conditions are $f(x) = x + c$ for $c \ge 0$.

The functions are $f(x) = x + c$ for any constant $c \in [0, \infty)$. $\square$
