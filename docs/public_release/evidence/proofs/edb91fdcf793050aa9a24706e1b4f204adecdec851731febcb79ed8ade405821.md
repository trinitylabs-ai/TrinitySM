To prove that $2x + 2y + 1$ is a perfect square given that $x$ and $y$ are positive integers satisfying $2x^2 + x = 3y^2 + y$, we begin by manipulating the given equation to form a Pell-like equation.

Multiplying the equation $2x^2 + x = 3y^2 + y$ by 8 gives:
$16x^2 + 8x = 24y^2 + 8y$.
Adding 1 to both sides to complete the square on the left:
$(4x + 1)^2 = 24y^2 + 8y + 1$.
Now multiply by 3:
$3(4x + 1)^2 = 72y^2 + 24y + 3$.
The right side can be rewritten as $2(36y^2 + 12y + 1) + 1 = 2(6y + 1)^2 + 1$.
Thus, we have the equation:
$3(4x + 1)^2 - 2(6y + 1)^2 = 1$.
Let $u = 4x + 1$ and $v = 6y + 1$. The equation becomes $3u^2 - 2v^2 = 1$. Since $x, y \in \mathbb{Z}^+$, we have $u \equiv 1 \pmod{4}$ and $v \equiv 1 \pmod{6}$ with $u > 1, v > 1$.

The solutions to $3u^2 - 2v^2 = 1$ are generated by the recurrence relations derived from the fundamental solution $(u_1, v_1) = (1, 1)$ and the fundamental unit of $\mathbb{Z}[\sqrt{6}]$, which is $5 + 2\sqrt{6}$. The general solution $(u_n, v_n)$ is given by:
$u_n\sqrt{3} + v_n\sqrt{2} = (1\sqrt{3} + 1\sqrt{2})(5 + 2\sqrt{6})^{n-1}$.
The recurrences are $u_{n+1} = 5u_n + 4v_n$ and $v_{n+1} = 6u_n + 5v_n$.
Testing modulo 4 and 6:
1. $u_1 = 1, u_2 = 9, u_3 = 89 \implies u_n \equiv 1 \pmod{4}$ for all $n \ge 1$.
2. $v_1 = 1, v_2 = 11, v_3 = 109 \implies v_n \equiv 1 \pmod{6}$ if and only if $n$ is odd.
Thus, for $x, y$ to be integers, $n$ must be an odd integer $n = 2m - 1$ for $m \ge 2$.

We wish to prove $2x + 2y + 1$ is a square. In terms of $u$ and $v$:
$2x + 2y + 1 = 2\left(\frac{u-1}{4}\right) + 2\left(\frac{v-1}{6}\right) + 1 = \frac{3(u-1) + 2(v-1) + 6}{6} = \frac{3u + 2v + 1}{6}$.
Let $S_n = \frac{3u_n + 2v_n + 1}{6}$. Using the Binet formulas for the recurrences:
$u_n = \frac{3-\sqrt{6}}{6}(5+2\sqrt{6})^n + \frac{3+\sqrt{6}}{6}(5-2\sqrt{6})^n$
$v_n = \frac{\sqrt{6}-2}{4}(5+2\sqrt{6})^n - \frac{\sqrt{6}+2}{4}(5-2\sqrt{6})^n$.
Substituting these into the expression for $3u_n + 2v_n$:
$3u_n + 2v_n = \frac{3-\sqrt{6} + \sqrt{6}-2}{2}(5+2\sqrt{6})^n + \frac{3+\sqrt{6} - \sqrt{6}-2}{2}(5-2\sqrt{6})^n = \frac{(5+2\sqrt{6})^n + (5-2\sqrt{6})^n}{2}$.
Then $S_n = \frac{(5+2\sqrt{6})^n + (5-2\sqrt{6})^n + 2}{12}$.
For $n = 2m - 1$:
$u_m^2 = \left(\frac{3-\sqrt{6}}{6}\alpha^m + \frac{3+\sqrt{6}}{6}\beta^m\right)^2 = \frac{(15-6\sqrt{6})\alpha^{2m} + (15+6\sqrt{6})\beta^{2m} + 6(\alpha\beta)^m}{36}$
Using $\alpha = 5+2\sqrt{6}$ and $\beta = 5-2\sqrt{6}$ (so $\alpha\beta = 1$):
$u_m^2 = \frac{3\beta\alpha^{2m} + 3\alpha\beta^{2m} + 6}{36} = \frac{\alpha^{2m-1} + \beta^{2m-1} + 2}{12} = S_{2m-1}$.
Thus $2x + 2y + 1 = u_m^2$, which is a perfect square. $\square$
