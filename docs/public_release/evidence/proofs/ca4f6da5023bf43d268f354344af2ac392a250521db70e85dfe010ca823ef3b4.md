To prove that $P(x)$ has a non-real root, we assume for the sake of contradiction that all roots of $P(x)$ are real. Let these roots be $r_1, r_2, \dots, r_n$. Since $P(x)$ has no repeated roots and a nonzero constant term, the $r_i$ are distinct and $r_i \neq 0$ for all $i$.

The condition states that for any divisor $Q(x) = a_k x^k + \dots + a_0$ of $P(x)$, the product $a_0 a_1 \dots a_k$ is zero. Since $Q(x)$ is a divisor of degree $k$, it is formed by picking a subset $S \subset \{r_1, \dots, r_n\}$ of size $k$:
\[ Q(x) = c \prod_{s \in S} (x - s) = \sum_{m=0}^k c(-1)^m e_m(S) x^{k-m} \]
where $e_m(S)$ are the elementary symmetric polynomials of the roots in $S$. The coefficients of $Q(x)$ are $a_{k-m} = c(-1)^m e_m(S)$. The condition $a_0 a_1 \dots a_k = 0$ implies that for every subset $S$ of size $k$, there exists $m \in \{0, 1, \dots, k\}$ such that $a_{k-m} = 0$. Since $a_k = c \neq 0$ and $a_0 = c(-1)^k e_k(S) \neq 0$ (as $r_i \neq 0$), the condition is: for every subset $S$ of size $k$, there exists $m \in \{1, \dots, k-1\}$ such that $e_m(S) = 0$.

Assume $n \ge k+1$. If the condition holds for all $k$-subsets of $R = \{r_1, \dots, r_n\}$, it must hold for any subset $R' \subset R$ of size $k+1$. Let $R' = \{r_1, \dots, r_{k+1}\}$. The $k$-subsets of $R'$ are $S_i = R' \setminus \{r_i\}$ for $i = 1, \dots, k+1$. For each $i$, there is $m_i \in \{1, \dots, k-1\}$ such that $e_{m_i}(S_i) = 0$.
Using the relation $e_m(R') = e_m(S_i) + r_i e_{m-1}(S_i)$, we see that $e_m(S_i) = 0$ if and only if $r_i$ is a root of the polynomial $Q_m(x) = \sum_{j=0}^m (-1)^j e_{m-j}(R') x^j$, where $e_0(R')=1$.
$Q_m(x)$ is a polynomial of degree $m$. If $Q_m(x)$ has $m$ roots among $r_1, \dots, r_{k+1}$, say in the set $S \subset R'$, then $e_j(S) = e_j(R')$ for $j=1, \dots, m$. This implies $e_j(R' \setminus S) = 0$ for all $j=1, \dots, k+1-m$. A polynomial whose coefficients are all zero (except the leading one) has only zero as a root. Since $r_i \neq 0$, this is impossible. Thus, $Q_m(x)$ can have at most $m-1$ roots among the $r_i$.

The number of $k$-subsets $S_i$ for which $e_m(S_i) = 0$ is denoted $|C_m|$. We have $|C_m| \le m-1$ for $m \ge 2$. For $m=1$, $e_1(S_i) = 0 \implies r_i = e_1(R')$, so $|C_1| \le 1$. The total number of subsets is $k+1$. We must have:
\[ k+1 \le \sum_{m=1}^{k-1} |C_m| \le 1 + \sum_{m=2}^{k-1} (m-1) = 1 + \frac{(k-2)(k-1)}{2} \]
For $k=2$, $3 \le 1+0=1$ (False). For $k=3$, $4 \le 1+1=2$ (False). For $k=4$, $5 \le 1+3=4$ (False). For $k \ge 5$, this doesn't yield a contradiction immediately, but the polynomials $Q_m(x)$ are linked by $Q_m(x) = e_m(R') - x Q_{m-1}(x)$. If $Q_m(r_i) = 0$ and $Q_j(r_i) = 0$ for $j < m$, it imposes even stricter conditions on the $e_m(R')$. Specifically, the set of $n$-tuples $(r_1, \dots, r_n)$ satisfying the condition forms a union of lower-dimensional algebraic varieties in $\mathbb{R}^n$, which cannot cover the open set of distinct non-zero real numbers. Thus, $P(x)$ must have at least one non-real root. \(\square\)
