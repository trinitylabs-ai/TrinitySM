To determine all positive integers $k$ such that $S_k(n) = \frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^k$ is an integer for every positive integer $n$, we examine the condition:
\[ A_k(n) = \sum_{i=0}^{n} \binom{n}{i}^k \equiv 0 \pmod{n+1} \]

**1. Necessary Condition**
Consider $n=2$, so $n+1=3$. The condition requires:
\[ A_k(2) = \binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2 + 2^k \equiv 0 \pmod 3 \]
This implies $2^k \equiv -2 \equiv 1 \pmod 3$. Since $2^1 \equiv 2 \pmod 3$ and $2^2 \equiv 1 \pmod 3$, the power $2^k \equiv 1 \pmod 3$ holds if and only if $k$ is even. Thus, $k$ must be even.

**2. Sufficient Condition**
Let $k$ be any even positive integer. We wish to prove that $A_k(n) \equiv 0 \pmod{n+1}$ for all $n \ge 1$. Let $m = n+1$. It suffices to show that for every prime power $p^r$ dividing $m$, $A_k(m-1) = \sum_{i=0}^{m-1} \binom{m-1}{i}^k \equiv 0 \pmod{p^r}$.
Using the identity $\binom{m-1}{i} = \prod_{j=1}^i \frac{m-j}{j}$, we have:
\[ \binom{m-1}{i}^k = \prod_{j=1}^i \left( \frac{m}{j} - 1 \right)^k \]
Since $k$ is even, $\left( \frac{m}{j} - 1 \right)^k = \left( 1 - \frac{m}{j} \right)^k$. Expanding this using the binomial theorem:
\[ \left( 1 - \frac{m}{j} \right)^k = \sum_{t=0}^k \binom{k}{t} (-1)^t \frac{m^t}{j^t} \]
Let $P_j(m) = \sum_{t=0}^k \binom{k}{t} (-1)^t \frac{m^t}{j^t}$. Then $\binom{m-1}{i}^k = \prod_{j=1}^i P_j(m)$. We can expand this product as a power series in $m$:
\[ \prod_{j=1}^i P_j(m) = \sum_{t=0}^{ik} m^t C_{i,t} \]
where $C_{i,t}$ is the sum of all possible products of $t$ terms chosen from the $i$ polynomials $P_j(m)$. Specifically,
\[ C_{i,t} = \sum_{1 \le j_1 < j_2 < \dots < j_s \le i} \sum_{\substack{t_1 + \dots + t_s = t \\ t_r \ge 1}} \frac{\prod_{r=1}^s \binom{k}{t_r} (-1)^{t_r}}{j_1^{t_1} \dots j_s^{t_s}} \]
Summing $A_k(m-1)$ over $i=0, \dots, m-1$:
\[ A_k(m-1) = \sum_{i=0}^{m-1} \sum_{t=0}^{ik} m^t C_{i,t} = \sum_{t=0}^{k(m-1)} m^t \sum_{i=0}^{m-1} C_{i,t} \]
For $t=0$, $C_{i,0} = 1$ for all $i$, so $\sum_{i=0}^{m-1} C_{i,0} = m \equiv 0 \pmod{p^r}$.
For $t \ge 1$, consider a general term $T = \frac{a}{j_1^{t_1} \dots j_s^{t_s}}$ in $C_{i,t}$ (where $a \in \mathbb{Z}$ and $j_s$ is the largest index). This term appears in $C_{i,t}$ if and only if $i \ge j_s$. Thus, in the sum $\sum_{i=0}^{m-1} C_{i,t}$, this term appears exactly $(m-1) - j_s + 1 = m - j_s$ times. The contribution of this term to $A_k(m-1)$ is:
\[ m^t \cdot \frac{a}{j_1^{t_1} \dots j_s^{t_s}} \cdot (m - j_s) = \frac{a m^{t+1}}{j_1^{t_1} \dots j_s^{t_s}} - \frac{a m^t j_s}{j_1^{t_1} \dots j_s^{t_s}} = \frac{a m^{t+1}}{j_1^{t_1} \dots j_s^{t_s}} - \frac{a m^t}{j_1^{t_1} \dots j_s^{t_s-1}} \]
We now analyze the $p$-adic valuation $v_p$ of these two terms for $m=p^r$. Since $1 \le j_n < p^r$, we have $v_p(j_n) \le r-1$.
For the first term:
\[ v_p\left( \frac{a m^{t+1}}{j_1^{t_1} \dots j_s^{t_s}} \right) \ge (t+1)r - \sum_{n=1}^s t_n v_p(j_n) \ge (t+1)r - t(r-1) = r + t \ge r \]
For the second term:
\[ v_p\left( \frac{a m^t}{j_1^{t_1} \dots j_s^{t_s-1}} \right) \ge tr - \left( \sum_{n=1}^{s-1} t_n v_p(j_n) + (t_s-1) v_p(j_s) \right) \ge tr - (t-1)(r-1) = r + t - 1 \ge r \]
Since every term in the expansion of $A_k(m-1)$ has a $p$-adic valuation $\ge r$, we have $A_k(m-1) \equiv 0 \pmod{p^r}$.
Because this holds for every prime power $p^r$ dividing $m$, it follows that $A_k(m-1) \equiv 0 \pmod m$.

The positive integers $k$ are all even positive integers.
