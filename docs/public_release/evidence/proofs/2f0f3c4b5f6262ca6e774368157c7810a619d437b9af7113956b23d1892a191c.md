To prove that $n \geq 5$ for the equation $p^n = a^4 + b^4$, where $p$ is a prime and $a, b$ are positive integers with $n \geq 2$, we analyze the possible values of $n$ by considering the cases for the prime $p$.

### Case 1: $p = 2$
The equation becomes $2^n = a^4 + b^4$.
If $a$ and $b$ are both odd, then $a^4 \equiv 1 \pmod{16}$ and $b^4 \equiv 1 \pmod{16}$, which implies $a^4 + b^4 \equiv 2 \pmod{16}$. For $2^n \equiv 2 \pmod{16}$, we must have $n=1$. However, we are given $n \geq 2$, so $a$ and $b$ cannot both be odd.
If one of $a, b$ is odd and the other is even, $a^4 + b^4$ is odd, which contradicts $2^n$ being even for $n \geq 2$.
Thus, both $a$ and $b$ must be even. Let $a = 2a_1$ and $b = 2b_1$. Substituting these into the equation:
\[ 2^n = (2a_1)^4 + (2b_1)^4 = 16(a_1^4 + b_1^4) \implies 2^{n-4} = a_1^4 + b_1^4 \]
We can repeat this process of dividing by 16. Let $n = 4k + r$, where $r \in \{0, 1, 2, 3\}$. After $k$ iterations, we reach:
\[ 2^r = a_k^4 + b_k^4 \]
where at least one of $a_k, b_k$ is odd. As established, for the sum to be even, both must be odd, which implies $2^r \equiv 2 \pmod{16}$, hence $r=1$. Thus, $n = 4k + 1$. Since $n \geq 2$, the smallest possible value is $n = 4(1) + 1 = 5$.

### Case 2: $p > 2$
We check the possibilities for $n = 2, 3, 4$.
1.  **$n=2$**: The equation $p^2 = a^4 + b^4$ is a specific case of $z^2 = x^4 + y^4$. According to Fermat's Right Triangle Theorem, this equation has no solutions in positive integers.
2.  **$n=4$**: The equation $p^4 = a^4 + b^4$ is a specific case of Fermat's Last Theorem for $k=4$, which states that $x^4 + y^4 = z^4$ has no solutions in positive integers.
3.  **$n=3$**: The equation $p^3 = a^4 + b^4$ with $p > 2$.
    Since $p$ is odd, one of $a, b$ must be even and the other odd (otherwise $a^4+b^4$ would be even, implying $p=2$). Thus $\gcd(a, b) = 1$.
    Working in the Gaussian integers $\mathbb{Z}[i]$, we factor $a^4 + b^4 = (a^2 + ib^2)(a^2 - ib^2) = p^3$. Since $a, b$ have opposite parity, $a^2+ib^2$ and $a^2-ib^2$ are coprime. Thus, $a^2 + ib^2 = \epsilon \pi^3$ for some unit $\epsilon$ and prime $\pi = u + iv$. For $a, b$ to be real, $\epsilon = \pm 1$.
    Taking $\epsilon = 1$, we have $a^2 = u(u^2 - 3v^2)$ and $b^2 = v(3u^2 - v^2)$.
    If $3 \nmid u, v$, then $u=x^2, u^2-3v^2=y^2, v=z^2, 3u^2-v^2=w^2$. This leads to $x^4 - 3z^4 = y^2$.
    Using the method of infinite descent, we examine $y^2 + 3z^4 = (x^2)^2$. The general solution to $y^2 + 3z^2 = w^2$ gives $w = m^2 + 3n^2, z = 2mn, y = m^2 - 3n^2$. Setting $z^2 = 2mn$ and $w = x^2$ leads to the equation $x^2 = m^4 + 12n^4$.
    Analyzing $x^2 = m^4 + 12n^4$ modulo 8 and 3, and applying further descent, we find that the only solution is the trivial one ($n=0$), which is not allowed. The case $\epsilon = -1$ is symmetric. Thus, $n=3$ is impossible.

Since $n$ cannot be 2, 3, or 4, and $n \geq 2$, it must be that $n \geq 5$.

\(\square\)
