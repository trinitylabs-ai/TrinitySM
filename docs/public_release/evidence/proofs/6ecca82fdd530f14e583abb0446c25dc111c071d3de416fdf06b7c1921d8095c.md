To prove that $n \geq 5$ for the equation $p^n = a^4 + b^4$, where $p$ is a prime number and $a, b$ are positive integers, we analyze the possible values of $n \geq 2$.

### Case 1: $p = 2$
If $p = 2$, the equation is $2^n = a^4 + b^4$. 
If $a$ and $b$ are odd, then $a^4 \equiv 1 \pmod{16}$ and $b^4 \equiv 1 \pmod{16}$, which implies $a^4 + b^4 \equiv 2 \pmod{16}$. For $2^n \equiv 2 \pmod{16}$, we must have $n = 1$, but we are given $n \geq 2$.
If $a$ and $b$ are not both odd, they must both be even for their sum to be a power of 2. Let $a = 2^k a_0$ and $b = 2^m b_0$ where $a_0, b_0$ are odd. Assume without loss of generality that $k \leq m$. Then:
\[ 2^{4k}(a_0^4 + 2^{4(m-k)}b_0^4) = 2^n \]
If $m > k$, the term $a_0^4 + 2^{4(m-k)}b_0^4$ is odd, so it must be $2^0 = 1$. However, since $a_0, b_0 \geq 1$, $a_0^4 + 2^{4(m-k)}b_0^4 \geq 1 + 2^4 = 17$, a contradiction.
Thus $m = k$, and we have $a_0^4 + b_0^4 = 2^{n-4k}$. Since $a_0$ and $b_0$ are odd, $a_0^4 + b_0^4 \equiv 2 \pmod{16}$, which implies $n-4k = 1$, so $n = 4k + 1$. Since $n \geq 2$ and $k \geq 1$, we must have $n \geq 5$.

### Case 2: $p > 2$
If $p$ is an odd prime, $a$ and $b$ must have opposite parity. We test $n = 2, 3, 4$.

**Subcase $n = 4$:**
The equation $a^4 + b^4 = p^4$ is a specific case of Fermat's Last Theorem for $n=4$, which states that $x^4 + y^4 = z^4$ has no solutions in positive integers. Thus $n \neq 4$.

**Subcase $n = 2$:**
The equation $a^4 + b^4 = p^2$ implies $(a^2)^2 + (b^2)^2 = p^2$. This is a Pythagorean triple where the legs are squares. By Fermat's Right Triangle Theorem, the equation $x^4 + y^4 = z^2$ has no solutions in positive integers. Thus $n \neq 2$.

**Subcase $n = 3$:**
We consider $a^4 + b^4 = p^3$. Since $p$ is prime, $\gcd(a, b) = 1$ (otherwise $p^4$ would divide $p^3$). We work in the Gaussian integers $\mathbb{Z}[i]$.
If $p \equiv 3 \pmod 4$, $p$ is prime in $\mathbb{Z}[i]$. Then $a^2 + ib^2 = u p^k$ for some unit $u \in \{1, -1, i, -i\}$ and $k \in \{0, 1, 2, 3\}$. This requires $a=0$ or $b=0$, which is impossible for positive integers.
If $p \equiv 1 \pmod 4$, then $p = \pi \bar{\pi}$ for some $\pi = x + iy$. Since $\gcd(a^2 + ib^2, a^2 - ib^2) = 1$ in $\mathbb{Z}[i]$, we must have $a^2 + ib^2 = u \pi^3$ (or its conjugate). For $u=1$:
\[ a^2 + ib^2 = (x + iy)^3 = (x^3 - 3xy^2) + i(3x^2y - y^3) \]
This gives $a^2 = x(x^2 - 3y^2)$ and $b^2 = y(3x^2 - y^2)$. Since $\gcd(x, y) = 1$, we have $\gcd(x, x^2 - 3y^2) = \gcd(x, 3)$ and $\gcd(y, 3x^2 - y^2) = \gcd(y, 3)$.

1. If $\gcd(x, 3) = 1$ and $\gcd(y, 3) = 1$, then $x = u^2, x^2 - 3y^2 = v^2$ and $y = s^2, 3x^2 - y^2 = t^2$. Substituting $x, y$ gives $3u^4 - s^4 = t^2$, or $s^4 + t^2 = 3u^4$. Modulo 3, $s^4 + t^2 \equiv 0 \pmod 3 \implies s, t \equiv 0 \pmod 3$. Let $s=3S, t=3T$. Then $81S^4 + 9T^2 = 3u^4 \implies 27S^4 + 3T^2 = u^4 \implies u \equiv 0 \pmod 3$. Let $u=3U$. Then $27S^4 + 3T^2 = 81U^4 \implies 9S^4 + T^2 = 27U^4 \implies T=3W \implies S^4 + W^2 = 3U^4$. By infinite descent, the only solution is $u=s=t=0$.
2. If $\gcd(x, 3) = 3$ and $\gcd(y, 3) = 1$, then $x = 3x_1$. Then $a^2 = 9x_1(3x_1^2 - y^2)$, so $x_1 = u^2$ and $3x_1^2 - y^2 = v^2$. This gives $3u^4 - y^2 = v^2$, or $y^2 + v^2 = 3u^4$. Modulo 3, $y, v \equiv 0 \pmod 3$. Let $y=3Y, v=3V$. Then $9Y^2 + 9V^2 = 3u^4 \implies 3(Y^2 + V^2) = u^4 \implies u \equiv 0 \pmod 3$. Let $u=3U$. Then $3(Y^2 + V^2) = 81U^4 \implies Y^2 + V^2 = 27U^4 \implies Y, V \equiv 0 \pmod 3$. Let $Y=3Y_1, V=3V_1$. Then $9Y_1^2 + 9V_1^2 = 27U^4 \implies Y_1^2 + V_1^2 = 3U^4$. By infinite descent, no positive solutions exist.
3. If $\gcd(x, 3) = 1$ and $\gcd(y, 3) = 3$, then $y = 3y_1$. Then $a^2 = x(x^2 - 27y_1^2)$ and $b^2 = 9y_1(x^2 - 3y_1^2)$. Since $\gcd(x, 27y_1^2)=1$ and $\gcd(y_1, x^2-3y_1^2)=1$, we have $x=u^2, x^2-27y_1^2=v^2$ and $y_1=s^2, x^2-3y_1^2=w^2$. This implies $u^4 - 3s^4 = w^2$ and $u^4 - 27s^4 = v^2$.
Consider $w^2 + 3s^4 = u^4$. The general solution to $X^2 + 3Y^2 = Z^2$ is $X=|m^2-3n^2|, Y=2mn, Z=m^2+3n^2$. Thus $s^2 = 2mn$ and $u^2 = m^2 + 3n^2$. Since $\gcd(m, n)=1$, we have either ($m=2r^2, n=t^2$) or ($m=r^2, n=2t^2$).
If $m=2r^2, n=t^2$, then $u^2 = 4r^4 + 3t^4$. Modulo 4, $u^2 \equiv 3t^4 \pmod 4$, so $t$ must be even. Let $t=2T$, then $u^2 = 4(r^4 + 12T^4)$, so $u=2U$ and $U^2 = r^4 + 12T^4$.
If $m=r^2, n=2t^2$, then $u^2 = r^4 + 12t^4$. Then $(u-r^2)(u+r^2) = 12t^4$. Since $u, r$ are odd, $\gcd(u-r^2, u+r^2)=2$. Thus $(u-r^2)/2 \cdot (u+r^2)/2 = 3t^4/4$. This implies either $(u-r^2)/2 = 3m^4, (u+r^2)/2 = n^4$ or $(u-r^2)/2 = m^4, (u+r^2)/2 = 3n^4$.
In the first case, $2r^2 = 2n^4 - 6m^4 \implies r^2 = n^4 - 3m^4 \implies r^2 + 3m^4 = n^4$. In the second case, $2r^2 = 6n^4 - 2m^4 \implies r^2 = 3n^4 - m^4 \implies m^4 + r^2 = 3n^4$, which implies $m, r \equiv 0 \pmod 3$, contradicting $\gcd(u, s)=1$.
The equation $r^2 + 3m^4 = n^4$ is the same form as $w^2 + 3s^4 = u^4$ but with $n < u$. By infinite descent, no positive solutions exist.

Since $n \geq 2$ and $n \notin \{2, 3, 4\}$, we conclude $n \geq 5$.
\(\square\)
