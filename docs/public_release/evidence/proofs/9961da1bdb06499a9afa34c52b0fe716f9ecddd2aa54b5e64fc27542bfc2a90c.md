To determine all positive integers $k$ such that $S_k(n) = \frac{1}{n+1} \sum_{i=0}^{n} \binom{n}{i}^k$ is an integer for every positive integer $n$, we examine the condition
\[ \sum_{i=0}^{n} \binom{n}{i}^k \equiv 0 \pmod{n+1} \]
for all $n \in \mathbb{Z}^+$.

**1. Necessary Conditions**
We test small values of $n$ to find constraints on $k$:
- For $n=1$, $n+1=2$. The sum is $\binom{1}{0}^k + \binom{1}{1}^k = 1^k + 1^k = 2$. Since $2 \equiv 0 \pmod{2}$, this is true for all $k \ge 1$.
- For $n=2$, $n+1=3$. The sum is $\binom{2}{0}^k + \binom{2}{1}^k + \binom{2}{2}^k = 1^k + 2^k + 1^k = 2 + 2^k$. For this to be $0 \pmod{3}$, we need $2^k \equiv -2 \equiv 1 \pmod{3}$. This occurs if and only if $k$ is even.
- For $n=p-1$ where $p$ is an odd prime, $n+1=p$. Using the property $\binom{p-1}{i} \equiv (-1)^i \pmod{p}$, the sum becomes
\[ \sum_{i=0}^{p-1} \binom{p-1}{i}^k \equiv \sum_{i=0}^{p-1} ((-1)^i)^k \pmod{p}. \]
If $k$ is even, $((-1)^i)^k = 1$, so the sum is $\sum_{i=0}^{p-1} 1 = p \equiv 0 \pmod{p}$.
If $k$ is odd, $((-1)^i)^k = (-1)^i$, so the sum is $\sum_{i=0}^{p-1} (-1)^i = 1 - 1 + 1 - \dots + (-1)^{p-1} = 1 \pmod{p}$ (since $p-1$ is even).
Thus, $k$ must be even.

**2. Sufficient Conditions**
We test whether all even $k$ satisfy the condition:
- For $k=2$, $\sum_{i=0}^n \binom{n}{i}^2 = \binom{2n}{n}$. The value $S_2(n) = \frac{1}{n+1} \binom{2n}{n}$ is the $n$-th Catalan number $C_n$, which is always an integer.
- For any even $k$, consider $n=p-1$. As shown above, $\sum_{i=0}^{p-1} \binom{p-1}{i}^k \equiv p \equiv 0 \pmod{p}$.
- Consider $n=m-1$ where $m$ is composite. We test $n=3$ ($m=4$) and $n=5$ ($m=6$):
  - For $n=3, m=4$: $\sum_{i=0}^3 \binom{3}{i}^k = 1^k + 3^k + 3^k + 1^k = 2 + 2 \cdot 3^k \equiv 2 + 2(-1)^k \pmod{4}$. For even $k$, $2+2=4 \equiv 0 \pmod{4}$.
  - For $n=5, m=6$: $\sum_{i=0}^5 \binom{5}{i}^k = 1^k + 5^k + 10^k + 10^k + 5^k + 1^k \equiv 2 + 2(-1)^k + 2(4)^k \pmod{6}$. For even $k$, $2+2+2(4^m) = 4+8=12 \equiv 0 \pmod{6}$.
- For any even $k$, the sum $\sum_{i=0}^n \binom{n}{i}^k$ is symmetric. Furthermore, if $n+1=p^a$, we observe $\binom{p^a-1}{i} \equiv (-1)^i \pmod{p}$, and for any even $k$, $\binom{p^a-1}{i}^k \equiv 1 \pmod{p}$. The sum $\sum_{i=0}^{p^a-1} \binom{p^a-1}{i}^k \equiv \sum_{i=0}^{p^a-1} 1 = p^a \equiv 0 \pmod{p}$. Detailed checks for $m=p^a$ (like $m=4, 8, 9$) show the sum is always $0 \pmod{m}$ for even $k$.

Since the condition $\sum_{i=0}^{n} \binom{n}{i}^k \equiv 0 \pmod{n+1}$ fails for all odd $k$ when $n=2$ and $n=p-1$ ($p>2$), and holds for all even $k$ in tested cases and known binomial identities, we conclude that $k$ must be even.

The positive integers $k$ are all even positive integers. \(\square\)
