To find all pairs of distinct positive integers $(a, b)$ such that we can make the two numbers equal after a finite number of steps using the operations $x \mapsto x+2$ and $x \mapsto 3x$, we analyze the properties of these operations.

### 1. Parity and Modulo 4 Invariance
Let $a_n$ and $b_n$ be the numbers on the blackboard after $n$ steps. Both operations preserve the parity of the number:
- $x \mapsto x+2 \implies x+2 \equiv x \pmod 2$.
- $x \mapsto 3x \implies 3x \equiv x \pmod 2$.
Thus, $a_n \equiv a \pmod 2$ and $b_n \equiv b \pmod 2$ for all $n$. For $a_n = b_n$ to be possible, we must have $a \equiv b \pmod 2$.

Next, consider the case where $a$ and $b$ are odd. We examine the numbers modulo 4:
- $x \mapsto x+2 \pmod 4$: $1 \to 3$ and $3 \to 1$.
- $x \mapsto 3x \pmod 4$: $1 \to 3$ and $3 \to 1$.
In both cases, if $x$ is odd, the operation always flips the value modulo 4. Therefore, $x_n \equiv x_0 + 2n \pmod 4$. For $a_n = b_n$, we must have $a_n \equiv b_n \pmod 4$, which implies $a + 2n \equiv b + 2n \pmod 4$, which simplifies to $a \equiv b \pmod 4$.

### 2. Analysis of Even Integers
Suppose $a$ and $b$ are even. Let $a = 2X$ and $b = 2Y$ for positive integers $X, Y$. The operations on $a$ and $b$ correspond to operations on $X$ and $Y$:
- $2X \mapsto 2X+2 \iff X \mapsto X+1$.
- $2X \mapsto 3(2X) \iff X \mapsto 3X$.
Let $S(X, n)$ be the set of values reachable from $X$ in $n$ steps. A value $M$ is in $S(X, n)$ if there exists $k \in \{0, \dots, n\}$ such that $M \ge 3^k X$ and the sum of digits of $M - 3^k X$ in base 3, denoted $S_3(M - 3^k X)$, satisfies $S_3(M - 3^k X) \le n-k$ and $S_3(M - 3^k X) \equiv n-k \pmod 2$.
For any $X, Y$, we can find $M, k_1, k_2$ such that $k_1 + S_3(M - 3^{k_1} X) \equiv k_2 + S_3(M - 3^{k_2} Y) \pmod 2$. Using $S_3(N) \equiv N \pmod 2$, this condition is $k_1 + M - 3^{k_1} X \equiv k_2 + M - 3^{k_2} Y \pmod 2$, which simplifies to $k_1 - X \equiv k_2 - Y \pmod 2$. Since $k_1, k_2$ can be chosen freely, this is always solvable. Picking $n$ sufficiently large, we can make $X$ and $Y$ equal. Thus, all pairs of even integers $(a, b)$ are solutions.

### 3. Analysis of Odd Integers
Suppose $a$ and $b$ are odd. From Section 1, $a \equiv b \pmod 4$ is necessary. Let $a = 2X+1$ and $b = 2Y+1$. Then $a \equiv b \pmod 4$ implies $X \equiv Y \pmod 2$. The operations are:
- $2X+1 \mapsto 2X+3 \iff X \mapsto X+1$.
- $2X+1 \mapsto 3(2X+1) = 6X+3 \iff X \mapsto 3X+1$.
The value after $n$ steps is $X_n = 3^k X + \frac{3^k-1}{2} + \sum_{i=0}^k s_i 3^i$ with $\sum s_i = n-k$.
The parity condition for $M$ to be reachable from both $X$ and $Y$ in $n$ steps is:
$k_1 + S_3(M - 3^{k_1} X - \frac{3^{k_1}-1}{2}) \equiv k_2 + S_3(M - 3^{k_2} Y - \frac{3^{k_2}-1}{2}) \pmod 2$.
Using $S_3(N) \equiv N \pmod 2$ and $\frac{3^k-1}{2} \equiv k \pmod 2$, this simplifies to:
$k_1 + M - 3^{k_1} X - k_1 \equiv k_2 + M - 3^{k_2} Y - k_2 \pmod 2 \implies X \equiv Y \pmod 2$.
This is exactly the condition $a \equiv b \pmod 4$. Thus, odd integers $a, b$ can be made equal if and only if $a \equiv b \pmod 4$.

The pairs $(a, b)$ are those such that $a, b$ are both even, or $a, b$ are both odd and $a \equiv b \pmod 4$. \(\square\)
