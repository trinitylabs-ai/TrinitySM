To prove that $P(x)$ must have a non-real root, we assume for the sake of contradiction that all roots $r_1, r_2, \dots, r_n$ of $P(x)$ are real. Since $P(x)$ is given to have no repeated roots and a nonzero constant term, these roots must be distinct and $r_i \neq 0$ for all $i \in \{1, \dots, n\}$.

Any divisor $Q(x)$ of $P(x)$ of degree $k$ is of the form $Q(x) = c \prod_{i \in S} (x - r_i)$ for some subset $S \subset \{1, \dots, n\}$ of size $k$. Let the coefficients of $Q(x)$ be $a_k, a_{k-1}, \dots, a_0$. The condition that the product $a_0 a_1 \dots a_k = 0$ for any such $Q(x)$ implies that for every $k$-subset $S$, there exists at least one $j \in \{0, 1, \dots, k\}$ such that $a_j = 0$. Since $P(0) \neq 0$, we have $a_0 = c (-1)^k \prod_{i \in S} r_i \neq 0$. Furthermore, $a_k$ is the leading coefficient, so $a_k \neq 0$. Thus, for every $S$, there must exist some $j \in \{1, \dots, k-1\}$ such that $a_j = 0$.

We utilize a fundamental property of polynomials with only real roots: Newton's Inequalities. For a polynomial $Q(x) = \sum_{j=0}^k a_j x^j$ with real roots, the elementary symmetric means $c_j = a_j / \binom{k}{j}$ satisfy $c_j^2 \ge c_{j-1} c_{j+1}$. If the roots are distinct, this inequality is strict: $c_j^2 > c_{j-1} c_{j+1}$. If $a_j = 0$ for some $0 < j < k$, then $c_j = 0$, which implies $0 > c_{j-1} c_{j+1}$, meaning $a_{j-1}$ and $a_{j+1}$ must have opposite signs. A critical consequence of this is that no two consecutive coefficients of $Q(x)$ can be zero.

Consider the case $n = k+1$. The divisors of degree $k$ are $Q_i(x) = P(x)/(x-r_i)$ for $i=1, \dots, n$. Let $P(x) = \sum_{m=0}^n a_m x^m$. The coefficients $b_j$ of $Q_i(x)$ can be determined via synthetic division: $b_{k-j} = \sum_{m=0}^j a_{n-m} r_i^{j-m}$ for $j=0, \dots, k$. The condition implies that for each $i$, there is some $j \in \{1, \dots, k-1\}$ such that $b_{k-j}(r_i) = 0$. Thus, each $r_i$ is a root of the polynomial $f(x) = \prod_{j=1}^{k-1} b_{k-j}(x)$. The degree of $f(x)$ is $\sum_{j=1}^{k-1} j = \frac{k(k-1)}{2}$. For $k=2, n=3$, $\deg(f)=1 < 3$; for $k=3, n=4$, $\deg(f)=3 < 4$. In these cases, $f(x)$ must be identically zero, which is impossible since $a_n \neq 0$.

For larger $k$, we observe that if $Q(x)$ has only real roots, the number of sign changes $V$ in its coefficients must equal the number of positive roots $p$, and $V'$ (for $Q(-x)$) must equal the number of negative roots $m$. Thus, $V+V' = p+m = k$. However, if $Q(x)$ has zero coefficients, $V+V'$ is strictly constrained. Specifically, if $m$ is the number of non-zero coefficients minus 1, $V+V' \le m + m_{even}$, where $m_{even}$ is the number of indices of non-zero coefficients with the same parity. If $Q(x)$ has too many zero coefficients, $V+V' < k$, contradicting the real-root assumption. If $Q(x)$ has few zero coefficients, the requirement $a_{j-1} a_{j+1} < 0$ forces a sign pattern that cannot be maintained for all $k$-subsets $S$ of a set of distinct real roots.

Since the assumption that all roots of $P(x)$ are real leads to a contradiction for any $n > k$, $P(x)$ must have at least one non-real root.

\(\square\)
