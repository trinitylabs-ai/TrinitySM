To prove that there exist positive integers $T$ and $L$ such that $a_{n+T} = a_n + L$ for every positive integer $n$, we analyze the condition that $a_{n+1}$ is the smallest integer greater than $a_n$ such that $\gcd(a_{n+1}, a_i) > 1$ for all $i=1, \dots, n$.

### 1. Prime Factors and Hitting Sets
For each $n$, let $S_n$ be the set of prime factors of $a_n$. The condition $\gcd(a_{n+1}, a_i) > 1$ for all $i \le n$ is equivalent to stating that $S_{n+1} \cap S_i \neq \emptyset$ for all $i=1, \dots, n$. In combinatorics, a set $H$ that has a non-empty intersection with every set in a collection $\mathcal{C}$ is called a **hitting set** of $\mathcal{C}$. Let $C_n = \{ S_1, S_2, \dots, S_n \}$. The integer $a_{n+1}$ is the smallest integer $> a_n$ such that $S_{n+1}$ is a hitting set of $C_n$.

### 2. Stabilization of Minimal Hitting Sets
Let $\mathcal{M}_n$ be the collection of all **minimal** hitting sets of $C_n$. A set $H$ is a hitting set of $C_n$ if and only if it contains some $M \in \mathcal{M}_n$. 
As $n$ increases, the condition to be a hitting set becomes more restrictive. Specifically, $H$ is a hitting set of $C_{n+1}$ if and only if $H$ is a hitting set of $C_n$ and $H \cap S_{n+1} \neq \emptyset$. 
Since $a_{n+1}$ is the smallest integer whose prime factors $S_{n+1}$ form a hitting set of $C_n$, it follows that $S_{n+1}$ must contain some $M \in \mathcal{M}_n$. If $S_{n+1}$ hits all other $M' \in \mathcal{M}_n$, then $\mathcal{M}_{n+1} = \mathcal{M}_n$. If not, some $M' \in \mathcal{M}_n$ must be expanded by adding a prime from $S_{n+1}$ to maintain the hitting property. Because the candidates for $a_{n+1}$ are multiples of the products of primes in $\mathcal{M}_n$, and the process of adding primes to disjoint minimal hitting sets terminates (as it effectively "fills" the available prime space from $S_{n+1}$), $\mathcal{M}_n$ must stabilize to a constant collection $\mathcal{M}_N$ for some $N$.

### 3. Periodicity of the Sequence
Once $\mathcal{M}_n = \mathcal{M}_N$ for all $n \ge N$, the condition for $x$ to be a candidate for $a_{n+1}$ is that $S_x$ contains some $M \in \mathcal{M}_N$. This is equivalent to:
$$x \text{ is a multiple of some } v \in V_N, \text{ where } V_N = \left\{ \prod_{p \in M} p : M \in \mathcal{M}_N \right\}$$
The sequence of integers that are multiples of at least one element of a finite set $V_N$ is periodic in its differences. Specifically, if $L = \text{lcm}(V_N)$ and $T$ is the number of such multiples in the range $[1, L]$, then the $k$-th multiple $x_k$ satisfies $x_{k+T} = x_k + L$.

### 4. Initial Terms
The claim that $a_{n+T} = a_n + L$ for every $n$ implies that $a_1, a_2, \dots$ must themselves be the sequence of all such multiples. Since $S_n$ is a hitting set of $C_{n-1}$ for all $n$, and $\mathcal{M}_N$ is the limit of the minimal hitting sets, any $S_n$ must eventually satisfy the hitting property for the stabilized $\mathcal{M}_N$. In the construction of the sequence, $a_1$ is the first multiple, $a_2$ the second, and so on. Since $a_1$ trivially satisfies the condition (as $C_0$ is empty) and each subsequent $a_n$ is the smallest integer satisfying the hitting set property for the growing collection $C_{n-1}$, the sequence $\{a_n\}$ coincides exactly with the sequence of all integers whose prime factors hit the limit collection $\mathcal{M}_N$. Thus, the periodicity holds for all $n \ge 1$.

There exist $T, L$ such that $a_{n+T} = a_n + L$ for every positive integer $n$. \(\square\)
