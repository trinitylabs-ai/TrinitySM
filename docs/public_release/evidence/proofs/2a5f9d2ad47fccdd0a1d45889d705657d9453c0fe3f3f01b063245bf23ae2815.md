To prove that the sequence $(a_n)$ is eventually quasi-periodic such that $a_{n+T} = a_n + L$ for all $n \ge 1$, we analyze the conditions under which $a_{n+1}$ is chosen.

Let $\mathcal{P}(m)$ denote the set of prime factors of a positive integer $m$. The condition $\gcd(a_{n+1}, a_i) > 1$ for all $i = 1, \dots, n$ is equivalent to the statement that $\mathcal{P}(a_{n+1}) \cap \mathcal{P}(a_i) \neq \emptyset$ for all $i \in \{1, \dots, n\}$. Let $\mathcal{F}_n = \{\mathcal{P}(a_1), \dots, \mathcal{P}(a_n)\}$ be the family of prime factor sets of the first $n$ terms. We define $\mathcal{G}_n$ as the collection of minimal elements of $\mathcal{F}_n$ under set inclusion. An integer $x$ satisfies $\gcd(x, a_i) > 1$ for all $i \le n$ if and only if $\mathcal{P}(x)$ is a hitting set for $\mathcal{G}_n$ (i.e., $\mathcal{P}(x) \cap S \neq \emptyset$ for all $S \in \mathcal{G}_n$).

By the problem definition, $a_{n+1}$ is the smallest integer $x > a_n$ such that $\mathcal{P}(x)$ is a hitting set for $\mathcal{G}_n$. Thus, $\mathcal{P}(a_{n+1})$ is itself a hitting set for $\mathcal{G}_n$. The family $\mathcal{G}_{n+1}$ is then the set of minimal elements of $\mathcal{G}_n \cup \{\mathcal{P}(a_{n+1})\}$. If $\mathcal{P}(a_{n+1})$ is a superset of some $S \in \mathcal{G}_n$, then $\mathcal{G}_{n+1} = \mathcal{G}_n$. Otherwise, $\mathcal{P}(a_{n+1})$ is added to the family, and any $S \in \mathcal{G}_n$ that is a superset of $\mathcal{P}(a_{n+1})$ is removed.

We claim that $\mathcal{G}_n$ eventually becomes constant. Let $\mathcal{H}(\mathcal{G})$ denote the set of minimal hitting sets of a family $\mathcal{G}$. Since $a_{n+1}$ is the smallest integer hitting $\mathcal{G}_n$, it must be a multiple of $M_H = \prod_{p \in H} p$ for some $H \in \mathcal{H}(\mathcal{G}_n)$. If $H \in \mathcal{G}_n$, then $\mathcal{P}(a_{n+1}) \supseteq H$, and $\mathcal{G}_{n+1} = \mathcal{G}_n$. If $H \notin \mathcal{G}_n$, we add $\mathcal{P}(a_{n+1})$ to the family. However, $H$ is a hitting set for $\mathcal{G}_n$ and $H \cap \mathcal{P}(a_{n+1}) \neq \emptyset$ (since $H \subseteq \mathcal{P}(a_{n+1})$), so $H$ is also a hitting set for $\mathcal{G}_{n+1}$. The smallest integer $a_{n+2} > a_{n+1}$ hitting $\mathcal{G}_{n+1}$ will then be bounded by the smallest multiple of $M_H$ greater than $a_{n+1}$. This process of adding minimal hitting sets to the family $\mathcal{G}_n$ must terminate because the number of possible minimal hitting sets over a finite set of primes is finite, and adding a hitting set to the family makes it "easier" for subsequent terms to be multiples of existing elements in $\mathcal{G}_n$.

Suppose $\mathcal{G}_n = \mathcal{G}$ for all $n \ge N$. Then for $n \ge N$, $a_{n+1}$ is the smallest integer $x > a_n$ such that $\mathcal{P}(x)$ hits every $S \in \mathcal{G}$. Let $C = \{x \in \mathbb{Z}^+ \mid \mathcal{P}(x) \text{ hits } \mathcal{G}\}$. The condition $x \in C$ is equivalent to $\gcd(x, \prod_{p \in S} p) > 1$ for all $S \in \mathcal{G}$. This is a property that depends only on $x \pmod{M}$ where $M = \prod_{p \in \bigcup \mathcal{G}} p$. Thus, $C$ is a union of congruence classes modulo $M$. Let these classes be $r_1 < r_2 < \dots < r_T$ in $\{0, \dots, M-1\}$. The sequence of elements of $C$ in increasing order satisfies $a_{n+T} = a_n + M$ for $n \ge N$.

Finally, since $a_1, \dots, a_{N-1}$ were chosen such that $\mathcal{P}(a_k)$ hits $\mathcal{G}_{k-1}$, and $\mathcal{G}_k$ is a sequence of families where $\mathcal{G}_{k+1}$ is obtained by adding hitting sets and removing supersets, it follows that $\mathcal{P}(a_k)$ also hits $\mathcal{G}$ for all $k \ge 1$. Thus, the sequence $(a_n)_{n \ge 1}$ is exactly the sequence of elements of $C$ in increasing order. Setting $L=M$, we have $a_{n+T} = a_n + L$ for all $n \ge 1$.

\(\square\)
