To find all positive real numbers $r$ such that $n(n+1)r - B(n,r)$ is a multiple of $n$ for all positive integers $n$, where $B(n,r) = \sum_{k=1}^n A(kr)$ and $A(r)$ is the fractional part of $2r$, we proceed as follows.

First, we express $A(r)$ using the fractional part notation $\{x\} = x - \lfloor x \rfloor$. Thus, $A(r) = \{2r\}$. The sum $B(n,r)$ becomes:
$$B(n,r) = \sum_{k=1}^n \{2kr\} = \sum_{k=1}^n (2kr - \lfloor 2kr \rfloor) = 2r \frac{n(n+1)}{2} - \sum_{k=1}^n \lfloor 2kr \rfloor = n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor$$
The condition given is that $C(n,r) = n(n+1)r - B(n,r)$ is a multiple of $n$ for all $n \in \mathbb{Z}^+$. Substituting the expression for $B(n,r)$:
$$C(n,r) = n(n+1)r - \left( n(n+1)r - \sum_{k=1}^n \lfloor 2kr \rfloor \right) = \sum_{k=1}^n \lfloor 2kr \rfloor$$
The requirement is that $S_n = \sum_{k=1}^n \lfloor 2kr \rfloor \equiv 0 \pmod n$ for all $n \ge 1$. Let $x = 2r$. We seek $x > 0$ such that $S_n = \sum_{k=1}^n \lfloor kx \rfloor \equiv 0 \pmod n$ for all $n \ge 1$.
Let $x = m + \alpha$, where $m = \lfloor x \rfloor$ and $0 \le \alpha < 1$. Then:
$$S_n = \sum_{k=1}^n \lfloor k(m+\alpha) \rfloor = \sum_{k=1}^n (km + \lfloor k\alpha \rfloor) = m \frac{n(n+1)}{2} + T_n, \quad \text{where } T_n = \sum_{k=1}^n \lfloor k\alpha \rfloor$$
For any odd integer $n$, $n+1$ is even, so $\frac{n+1}{2}$ is an integer. This implies $m \frac{n(n+1)}{2}$ is a multiple of $n$. Thus, for odd $n$, the condition $S_n \equiv 0 \pmod n$ implies $T_n \equiv 0 \pmod n$.
We examine $T_n$ for small odd $n$:
1. For $n=1$, $T_1 = \lfloor \alpha \rfloor = 0$, which is always true since $0 \le \alpha < 1$.
2. For $n=3$, $T_3 = \lfloor \alpha \rfloor + \lfloor 2\alpha \rfloor + \lfloor 3\alpha \rfloor = \lfloor 2\alpha \rfloor + \lfloor 3\alpha \rfloor$. Since $0 \le \alpha < 1$, $T_3 \in \{0, 1, 2, 3\}$. For $T_3 \equiv 0 \pmod 3$, we must have $T_3 = 0$ (which means $\alpha \in [0, 1/3)$) or $T_3 = 3$ (which means $\alpha \in [2/3, 1)$).

We now prove by induction that for all odd $n \ge 1$, $T_n \equiv 0 \pmod n$ implies $\alpha \in [0, 1/n) \cup [(n-1)/n, 1)$.
The base cases $n=1$ and $n=3$ are shown above. Assume the claim holds for some odd $m \ge 3$. Then $\alpha \in [0, 1/m) \cup [(m-1)/m, 1)$. Consider $n = m+2$.
Case 1: $\alpha \in [0, 1/m)$.
Since $\alpha < 1/m$, we have $\lfloor k\alpha \rfloor = 0$ for all $k < m$. Thus $T_n = \sum_{k=m}^n \lfloor k\alpha \rfloor$. Since $n\alpha < (m+2)/m = 1 + 2/m \le 1 + 2/3 < 2$, we have $\lfloor k\alpha \rfloor \in \{0, 1\}$ for all $k \le n$. Thus $0 \le T_n \le n-m+1 < n$. For $T_n \equiv 0 \pmod n$, we must have $T_n = 0$, which implies $\lfloor n\alpha \rfloor = 0$, so $\alpha \in [0, 1/n)$.
Case 2: $\alpha \in [(m-1)/m, 1)$.
Let $\beta = 1 - \alpha$, so $\beta \in (0, 1/m]$. We have $\lfloor k\alpha \rfloor = k + \lfloor -k\beta \rfloor = k - \lceil k\beta \rceil$.
Then $T_n = \sum_{k=1}^n (k - \lceil k\beta \rceil) = \frac{n(n+1)}{2} - \sum_{k=1}^n \lceil k\beta \rceil$. Since $n$ is odd, $\frac{n(n+1)}{2}$ is a multiple of $n$. Thus $T_n \equiv 0 \pmod n$ implies $U_n = \sum_{k=1}^n \lceil k\beta \rceil \equiv 0 \pmod n$.
Since $0 < \beta \le 1/m$, we have $\lceil k\beta \rceil = 1$ for $k < m$, and since $n\beta \le (m+2)/m < 2$, we have $\lceil k\beta \rceil \in \{1, 2\}$ for all $k \le n$. Thus $n \le U_n \le 2n$. For $U_n \equiv 0 \pmod n$, we must have $U_n = n$ or $U_n = 2n$. $U_n = 2n$ implies $\lceil \beta \rceil = 2$, which is impossible as $\beta \le 1/m \le 1/3$. $U_n = n$ implies $\lceil k\beta \rceil = 1$ for all $k \le n$, so $\lceil n\beta \rceil = 1$, which means $n\beta \le 1$, so $\beta \in (0, 1/n]$. This means $\alpha \in [(n-1)/n, 1)$.

Thus, for all odd $n$, $\alpha \in [0, 1/n) \cup [(n-1)/n, 1)$. If $0 < \alpha < 1$, then for any odd $n > \max(1/\alpha, 1/(1-\alpha))$, we have $1/n < \alpha < (n-1)/n$, which means $\alpha$ is not in the set. Thus, we must have $\alpha = 0$.
If $\alpha = 0$, then $x = m$ is an integer. The condition $S_n \equiv 0 \pmod n$ becomes:
$$m \frac{n(n+1)}{2} \equiv 0 \pmod n \quad \text{for all } n \ge 1$$
For $n=2$, $S_2 = m \frac{2(3)}{2} = 3m$. For $3m$ to be a multiple of 2, $m$ must be even. Let $m = 2k$ for some positive integer $k$. Then $S_n = \frac{2kn(n+1)}{2} = kn(n+1)$, which is always a multiple of $n$.
Thus, $x = 2r = 2k$, which means $r = k$ for any positive integer $k$.

The positive real numbers $r$ that satisfy the condition are all positive integers.
