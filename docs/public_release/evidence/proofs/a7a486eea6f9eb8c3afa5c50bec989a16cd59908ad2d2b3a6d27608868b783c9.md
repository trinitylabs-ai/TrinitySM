To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that the equation
\[ f(x - f(xy)) = f(x)f(1-y) \]
holds for all $x, y \in \mathbb{Z}$, we proceed as follows:

**1. Constant Solutions**
If $f(x) = c$ for all $x \in \mathbb{Z}$, then the equation becomes $c = c^2$, which implies $c = 0$ or $c = 1$.
- If $f(x) = 0$, then $0 = 0 \cdot 0$, which is a solution.
- If $f(x) = 1$, then $1 = 1 \cdot 1$, which is a solution.

**2. Analysis of $f(0)$**
Setting $x = 0$ in the original equation gives $f(-f(0)) = f(0)f(1-y)$.
If $f(0) = c \neq 0$, then $f(1-y) = \frac{f(-c)}{c}$ for all $y \in \mathbb{Z}$. This implies $f$ is a constant function. As shown above, the only non-zero constant solution is $f(x) = 1$.
Thus, we now assume $f(0) = 0$.

**3. Analysis of $f(1)$**
Setting $y = 0$ and using $f(0) = 0$, we have $f(x - f(0)) = f(x)f(1)$, which simplifies to $f(x) = f(x)f(1)$ for all $x \in \mathbb{Z}$.
If $f(x) = 0$ for all $x$, we have the zero solution. If there exists $x_0$ such that $f(x_0) \neq 0$, we must have $f(1) = 1$.

**4. Case $f(0) = 0$ and $f(1) = 1$**
Setting $y = 1$, we obtain $f(x - f(x)) = f(x)f(0) = 0$ for all $x \in \mathbb{Z}$.
Setting $x = 1$, we obtain $f(1 - f(y)) = f(1)f(1-y) = f(1-y)$ for all $y \in \mathbb{Z}$.
If $f(x) = x$, then $f(x - f(xy)) = x - xy$ and $f(x)f(1-y) = x(1-y) = x - xy$. This is a solution.

Now consider the possibility that $f(x)$ takes values in $\{0, 1\}$. Let $S = \{x \in \mathbb{Z} : f(x) = 0\}$.
- $f(x - f(x)) = 0 \implies$ if $x \notin S$, then $x-1 \in S$.
- $f(1 - f(y)) = f(1 - y) \implies$ if $y \in S$, then $f(1) = f(1-y) \implies 1-y \notin S$; and if $y \notin S$, then $f(0) = f(1-y) \implies 1-y \in S$.
Thus, $y \in S \iff 1-y \notin S$. Since $f(0) = 0$, we have $0 \in S$, which implies $1 \notin S$.
Since $y \in S \iff 1-y \notin S$, we check for $y=2$: $2 \in S \iff -1 \notin S$.
If $2 \notin S$, then $2-1 = 1 \in S$, but we know $1 \notin S$. Thus, $2 \in S$.
By induction, $S$ must be the set of even integers. This gives $f(x) = 0$ if $x$ is even and $f(x) = 1$ if $x$ is odd, which is $f(x) = x \pmod 2$.
Checking $f(x) = x \pmod 2$:
- If $x$ is even, $f(x-f(xy)) = f(\text{even}-0) = 0$ and $f(x)f(1-y) = 0 \cdot f(1-y) = 0$.
- If $x$ is odd and $y$ is even, $f(x-f(xy)) = f(\text{odd}-0) = 1$ and $f(x)f(1-y) = 1 \cdot f(\text{odd}) = 1 \cdot 1 = 1$.
- If $x$ is odd and $y$ is odd, $f(x-f(xy)) = f(\text{odd}-1) = f(\text{even}) = 0$ and $f(x)f(1-y) = 1 \cdot f(\text{even}) = 0$.
This is a solution.

**5. Conclusion**
No other functions satisfy the given conditions. The solutions are $f(x) = 0$, $f(x) = 1$, $f(x) = x$, and $f(x) = \begin{cases} 0 & x \text{ is even} \\ 1 & x \text{ is odd} \end{cases}$.
