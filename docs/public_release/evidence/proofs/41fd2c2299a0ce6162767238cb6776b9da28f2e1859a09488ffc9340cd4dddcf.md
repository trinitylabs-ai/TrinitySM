To prove that for any positive integers $k$ and $d$, there exists a positive integer $N$ such that for every odd integer $n > N$, the digits of $n^k$ in base $2n$ are all greater than $d$, we proceed as follows.

Let the base-$2n$ representation of $n^k$ be
$$n^k = a_m(2n)^m + a_{m-1}(2n)^{m-1} + \dots + a_1(2n) + a_0$$
where $0 \le a_i < 2n$ for all $i$. We must show that there exists $N$ such that $a_i > d$ for all $i \in \{0, 1, \dots, m\}$ for all odd $n > N$.

First, we determine $a_0$. Since $a_0 = n^k \pmod{2n}$, and $n$ is odd, let $n = 2p+1$. Then $n^{k-1}$ is also odd, so $n^{k-1} = 2q+1$ for some integer $q$. Thus,
$$n^k = n \cdot n^{k-1} = n(2q+1) = 2qn + n.$$
This implies $a_0 = n$. For $n > d$, we have $a_0 > d$.

Next, we analyze the remaining digits. Since $n^k = \sum_{i=0}^m a_i (2n)^i$, multiplying by $2^k$ gives:
$$(2n)^k = \sum_{i=0}^m 2^k a_i (2n)^i.$$
Because $n^k < (2n)^k$, we must have $m < k$. Let $a_i = 0$ for $i \ge k$. Then the equation becomes:
$$(2n)^k = 2^k a_{k-1}(2n)^{k-1} + 2^k a_{k-2}(2n)^{k-2} + \dots + 2^k a_0.$$
We can treat this as a base $2n$ representation of $(2n)^k$ with "digits" $2^k a_i$. To find the standard digits, we perform carries. Let $q_i$ be the carry from the $i$-th position to the $(i+1)$-th position.
For $i=0$: $2^k a_0 = q_0(2n) + 0 \implies q_0 = \frac{2^k n}{2n} = 2^{k-1}$.
For $i=1$: $2^k a_1 + q_0 = q_1(2n) + 0 \implies 2^k a_1 + 2^{k-1} = q_1(2n)$.
Dividing by $2^{k-1}$, we get $2 a_1 + 1 = \frac{q_1 n}{2^{k-2}}$. Since $n$ is odd, $q_1$ must be a multiple of $2^{k-2}$, say $q_1 = 2^{k-2} m_1$ for some integer $m_1$. Then $2 a_1 + 1 = m_1 n$, so $a_1 = \frac{m_1 n - 1}{2}$.

By induction, for $1 \le j < k$, we have the relation:
$$2^k a_j + q_{j-1} = q_j(2n) + 0.$$
Assuming $q_{j-1} = 2^{k-j} m_{j-1}$, we have $2^k a_j + 2^{k-j} m_{j-1} = q_j(2n)$. Dividing by $2^{k-j}$, we get $2^j a_j + m_{j-1} = \frac{q_j n}{2^{k-j-1}}$. Let $q_j = 2^{k-j-1} m_j$, then:
$$2^j a_j + m_{j-1} = m_j n \implies a_j = \frac{m_j n - m_{j-1}}{2^j}.$$
For the final digit $a_{k-1}$, the equation is $2^k a_{k-1} + q_{k-2} = (2n)^1 \cdot 1 + 0$.
$$2^k a_{k-1} + 2 m_{k-2} = 2n \implies 2^{k-1} a_{k-1} + m_{k-2} = n.$$
This matches the general formula $2^j a_j + m_{j-1} = m_j n$ with $j=k-1$ and $m_{k-1} = 1$.

Since $0 \le a_j < 2n$, we have $m_j n = 2^j a_j + m_{j-1} < 2^j(2n) + m_{j-1}$, so $m_j < 2^{j+1} + \frac{m_{j-1}}{n}$. Since $m_0 = 1$, $m_j$ is bounded by a constant independent of $n$. Furthermore, since $a_j \ge 0$ and $m_{j-1} \ge 1$, we have $m_j n \ge 1$, so $m_j \ge 1$.
Thus, for each $j \in \{1, \dots, k-1\}$:
$$a_j = \frac{m_j n - m_{j-1}}{2^j} \ge \frac{n - m_{j-1}}{2^j}.$$
Since $m_{j-1}$ is bounded, $a_j \to \infty$ as $n \to \infty$. We can choose $N$ large enough such that $a_j > d$ for all $j \in \{0, \dots, k-1\}$. Specifically, taking $N > \max_{j} (2^j(d+1) + m_{j-1})$ suffices.

$\square$
