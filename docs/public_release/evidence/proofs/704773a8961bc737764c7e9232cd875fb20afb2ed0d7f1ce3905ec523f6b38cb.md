To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
$$\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)},$$
we analyze the given inequalities.

**1. Testing a linear candidate:**
Let $f(x) = x + c$ for some constant $c$. For $f$ to map $\mathbb{R}_{>0}$ to $\mathbb{R}_{>0}$, we must have $x + c > 0$ for all $x > 0$, which implies $c \ge 0$. Substituting $f(x) = x + c$ into the inequalities:
- The first inequality is $\sqrt{\frac{x^2 + (y+c)^2}{2}} \ge \frac{x+c+y}{2}$. Squaring both sides:
$$\frac{x^2 + (y+c)^2}{2} \ge \frac{(x+y+c)^2}{4} \iff 2x^2 + 2(y+c)^2 \ge x^2 + (y+c)^2 + 2x(y+c) \iff (x - (y+c))^2 \ge 0.$$
This is always true for all $x, y, c$.
- The second inequality is $\frac{x+c+y}{2} \ge \sqrt{x(y+c)}$. Squaring both sides:
$$\frac{(x+y+c)^2}{4} \ge x(y+c) \iff x^2 + (y+c)^2 + 2x(y+c) \ge 4x(y+c) \iff (x - (y+c))^2 \ge 0.$$
This is also always true for all $x, y, c$.
Thus, $f(x) = x + c$ for any $c \ge 0$ is a solution.

**2. Proving these are the only solutions:**
Let $f(x) = x + c(x)$. The inequalities can be rewritten as:
(i) $f(x) + y \le \sqrt{2x^2 + 2f(y)^2}$
(ii) $f(x) + y \ge 2\sqrt{xf(y)}$

From (i), for any $x, y > 0$:
$$c(x) \le \sqrt{2x^2 + 2f(y)^2} - (x + y).$$
Let $z = f(y) = y + c(y)$. Then $y = z - c(y)$. Substituting this:
$$c(x) \le \sqrt{2x^2 + 2z^2} - (x + z - c(y)) = \sqrt{2x^2 + 2z^2} - (x + z) + c(y).$$
From (ii), $f(x) + y \ge 2\sqrt{xf(y)}$. Substituting $x = f(y) = z$ and $y$ such that $f(y) = z$ (if $f$ is a bijection), we get $f(z) + y \ge 2\sqrt{zf(y)} = 2z$.
More generally, if we substitute $x = f(y) = z$ into the original inequalities, we have:
$\sqrt{\frac{z^2+z^2}{2}} \ge \frac{f(z)+y}{2} \ge \sqrt{zf(y)} \implies z \ge \frac{f(z)+y}{2} \ge \sqrt{zy}$.
Since $y = z - c(y)$, the first part is $z \ge \frac{z+c(z) + z-c(y)}{2} = z + \frac{c(z)-c(y)}{2}$, implying $c(y) \ge c(z)$.
However, if we swap $x$ and $y$ in (i) and add them, we previously found that $c(K(y)) = c(y)$ where $K(y) = y+c(y)$.
Using the bound $c(x) \le c(z) + \sqrt{2x^2 + 2z^2} - (x + z)$ and the fact $c(z) = c(K(y))$, we have:
$$c(x) - c(z) \le \sqrt{2x^2 + 2z^2} - (x + z) = \frac{(x-z)^2}{\sqrt{2x^2+2z^2} + x + z}.$$
As $z \to x$, the right side vanishes as $O((x-z)^2)$. This implies that the derivative $c'(x)$ must be $0$ for all $x$ where it exists. Specifically, for any $\epsilon > 0$:
$$c(x) - c(x+\epsilon) \le \frac{\epsilon^2}{\sqrt{2x^2+2(x+\epsilon)^2} + 2x + \epsilon} \implies \limsup_{\epsilon \to 0^+} \frac{c(x) - c(x+\epsilon)}{\epsilon} \le 0.$$
Similarly, $c(x+\epsilon) - c(x) \le \frac{\epsilon^2}{\dots} \implies \limsup_{\epsilon \to 0^+} \frac{c(x+\epsilon) - c(x)}{\epsilon} \le 0$.
This forces $c'(x) = 0$, so $c(x)$ is a constant $c$. As $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$, $c$ must be $\ge 0$.

The functions are $f(x) = x + c$ for any $c \ge 0$.

\(\square\)
