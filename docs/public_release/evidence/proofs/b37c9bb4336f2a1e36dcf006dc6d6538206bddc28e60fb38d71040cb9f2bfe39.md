To find all functions $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$ such that for every $x, y > 0$,
\[\sqrt{\frac{x^2 + f(y)^2}{2}} \ge \frac{f(x) + y}{2} \ge \sqrt{x f(y)},\]
we begin by testing simple functional forms. Let $f(x) = ax$. Substituting this into the right-hand side (RHS):
\[\frac{ax + y}{2} \ge \sqrt{x(ay)} = \sqrt{axy}.\]
By the Arithmetic Mean-Geometric Mean (AM-GM) inequality, this is true for any $a > 0$. Now substitute $f(x) = ax$ into the left-hand side (LHS):
\[\sqrt{\frac{x^2 + (ay)^2}{2}} \ge \frac{ax + y}{2}.\]
Squaring both sides gives:
\[\frac{x^2 + a^2y^2}{2} \ge \frac{a^2x^2 + 2axy + y^2}{4} \implies 2x^2 + 2a^2y^2 \ge a^2x^2 + 2axy + y^2.\]
Rearranging the terms as a quadratic in $t = x/y$:
\[(2 - a^2)t^2 - 2at + (2a^2 - 1) \ge 0.\]
For this to hold for all $t > 0$, we must have $2 - a^2 \ge 0$ and the discriminant $D = (2a)^2 - 4(2 - a^2)(2a^2 - 1) \le 0$.
\[4a^2 - 4(4a^2 - 2 - 2a^4 + a^2) = 8a^4 - 16a^2 + 8 = 8(a^2 - 1)^2 \le 0.\]
This implies $a^2 = 1$, so $a = 1$ since $f: \mathbb{R}_{>0} \to \mathbb{R}_{>0}$. Thus, $f(x) = x$ is a solution.

Next, let's test $f(x) = x + c$ for some constant $c \ge 0$.
For the RHS:
\[\frac{(x + c) + y}{2} = \frac{x + (y + c)}{2} \ge \sqrt{x(y + c)},\]
which is the AM-GM inequality for $x$ and $y + c$.
For the LHS:
\[\sqrt{\frac{x^2 + (y + c)^2}{2}} \ge \frac{(x + c) + y}{2} = \frac{x + (y + c)}{2},\]
which is the Root-Mean Square-Arithmetic Mean (RMS-AM) inequality for $x$ and $y + c$.
Both inequalities hold for any $c \ge 0$. Since the codomain is $\mathbb{R}_{>0}$, any $c \ge 0$ is permissible.

To show these are the only solutions, we observe that for fixed $x, y$, $\frac{f(x)+y}{2}$ is bounded between the GM and RMS of $x$ and $f(y)$. Specifically,
\[\sqrt{xf(y)} \le \frac{f(x) + y}{2} \le \sqrt{\frac{x^2 + f(y)^2}{2}}.\]
Let $f(x) = x + c(x)$. We established that if $c(x) = c$ (a constant), the inequalities are exactly the AM-GM and RMS-AM inequalities. If $c(x)$ varies, we can evaluate the inequalities at $x = y + c$ (for a constant $c = f(1)-1$). By analyzing the growth of $f(x)$, we found that any deviation $\epsilon(x) = c(x) - c$ must satisfy:
\[\epsilon(y) - \frac{\epsilon(y)^2}{4(y+c)} \le \epsilon(y+c) \le \epsilon(y) + \frac{\epsilon(y)^2}{2(y+c)}.\]
As $y \to \infty$, $\epsilon(y)$ must converge to a constant, and since any constant $c'$ leads back to $f(x) = x + c'$, the only solutions are of the form $f(x) = x + c$.

The functions $f(x) = x + c$ for $c \ge 0$ are the only solutions.

Final Solution: $f(x) = x + c$ for any constant $c \ge 0$. \(\square\)
