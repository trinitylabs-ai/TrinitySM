To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that $y f(y f(x) + 1) = f\left(\frac{1}{x} + f(y)\right)$ for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Surjectivity and Injectivity**
First, we establish the surjectivity of $f$. For a fixed $y \in \mathbb{R}^+$, as $x$ ranges over the interval $(0, \infty)$, the expression $\frac{1}{x} + f(y)$ takes all values in the interval $(f(y), \infty)$. Since $f$ maps these values to the codomain $\mathbb{R}^+$, the range of $f$ contains $(f(y), \infty)$ for any $y$. This implies that the range of $f$ is $\mathbb{R}^+$, so $f$ is surjective.

Next, we prove that $f$ is injective. Suppose $f(y_1) = f(y_2)$ for some $y_1, y_2 \in \mathbb{R}^+$. Then $f\left(\frac{1}{x} + f(y_1)\right) = f\left(\frac{1}{x} + f(y_2)\right)$, which implies:
$$y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1)$$
Let $f(x) = z$. Since $f$ is surjective, $z$ can be any value in $\mathbb{R}^+$. Thus, $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$ for all $z \in \mathbb{R}^+$. If $y_1 \neq y_2$, let $k = \frac{y_2}{y_1}$. Then $f(y_1 z + 1) = k f(k y_1 z + 1)$. Setting $v = y_1 z$, we have $f(v+1) = k f(kv+1)$ for all $v > 0$. 
If $k \neq 1$, this equation implies that $f(v+1)$ behaves like $C v^{-1}$ as $v \to \infty$ (specifically, $f(x) = C(x-1)^{-1}$ if we assume a standard form, or more generally, it grows/decays such that the ratio $f(v+1)/f(kv+1)$ is constant). Substituting such a form into the original equation, for large $x$, the LHS $y f(y f(x) + 1)$ would grow linearly with $x$ (since $f(x) \to 0$, $y f(x) + 1$ is near 1, and $f(u) \approx \frac{C}{u-1}$ implies $f(y f(x) + 1) \approx \frac{C}{y f(x)} \approx \frac{C}{y \frac{C}{x}} = \frac{x}{y}$), whereas the RHS $f\left(\frac{1}{x} + f(y)\right)$ would approach the constant $f(f(y))$. This contradiction forces $k=1$, so $y_1 = y_2$. Thus, $f$ is injective.

**2. Determining the Functional Form**
Let $f(1) = a$. Setting $y=1$ in the original equation:
$$1 \cdot f(1 \cdot f(x) + 1) = f\left(\frac{1}{x} + f(1)\right) \implies f(f(x) + 1) = f\left(\frac{1}{x} + a\right)$$
Since $f$ is injective, we must have:
$$f(x) + 1 = \frac{1}{x} + a \implies f(x) = \frac{1}{x} + a - 1$$
Let $b = a - 1$. Then $f(x) = \frac{1}{x} + b$. Since the codomain is $\mathbb{R}^+$, we must have $b \geq 0$ (if $b < 0$, $f(x)$ would be negative for large $x$). Now we substitute this form back into the original equation:
LHS: $y f(y(\frac{1}{x} + b) + 1) = y f\left(\frac{y}{x} + yb + 1\right) = y \left( \frac{1}{\frac{y}{x} + yb + 1} + b \right) = \frac{yx}{y + xyb + x} + yb$
RHS: $f\left(\frac{1}{x} + f(y)\right) = f\left(\frac{1}{x} + \frac{1}{y} + b\right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + b} + b = \frac{xy}{y + x + bxy} + b$
Equating the two sides:
$$\frac{xy}{y + x + bxy} + yb = \frac{xy}{y + x + bxy} + b \implies yb = b \implies b(y - 1) = 0$$
Since this must hold for all $y \in \mathbb{R}^+$, we must have $b = 0$. This implies $a - 1 = 0$, so $a = 1$. Thus, $f(x) = \frac{1}{x}$.

**3. Verification**
Substituting $f(x) = \frac{1}{x}$ into the original equation:
LHS: $y f(y \cdot \frac{1}{x} + 1) = y \frac{1}{\frac{y}{x} + 1} = \frac{y}{\frac{y+x}{x}} = \frac{xy}{x+y}$
RHS: $f(\frac{1}{x} + \frac{1}{y}) = \frac{1}{\frac{1}{x} + \frac{1}{y}} = \frac{1}{\frac{y+x}{xy}} = \frac{xy}{x+y}$
The LHS equals the RHS for all $x, y \in \mathbb{R}^+$.

The only function satisfying the given conditions is $f(x) = \frac{1}{x}$.

\(\square\)
