To prove that $P(x)$ has a non-real root, we proceed by contradiction. Suppose $P(x)$ has only real roots. Let these roots be $r_1, r_2, \dots, r_n$. Since $P(x)$ has no repeated roots, the $r_i$ are distinct. Since the constant term of $P(x)$ is nonzero, $P(0) \neq 0$, which implies $r_i \neq 0$ for all $i=1, \dots, n$.

Any polynomial $Q(x) = a_k x^k + a_{k-1} x^{k-1} + \dots + a_1 x + a_0$ that divides $P(x)$ must have its roots as a subset of $\{r_1, \dots, r_n\}$. Let $S \subset \{r_1, \dots, r_n\}$ be a subset of $k$ roots. The corresponding divisor is $Q_S(x) = c \prod_{r \in S} (x-r)$. The coefficients are given by $a_j = c (-1)^{k-j} e_{k-j}(S)$, where $e_m(S)$ is the $m$-th elementary symmetric polynomial of the roots in $S$.

The condition $a_0 a_1 \dots a_k = 0$ implies that at least one coefficient $a_j$ must be zero. Since $\deg Q = k$, $a_k \neq 0$. Since $P(0) \neq 0$, the constant term $a_0 = c (-1)^k \prod_{r \in S} r$ is nonzero. Thus, for any $k$-subset $S$, there exists some $j \in \{1, \dots, k-1\}$ such that $e_j(S) = 0$.

First, if all roots in $S$ have the same sign, then $e_j(S) \neq 0$ for all $j=1, \dots, k$. Thus, every $k$-subset $S$ must contain roots of both signs. Let $p$ and $q$ be the number of positive and negative roots, respectively. If $p \ge k$, we can choose a subset $S$ of $k$ positive roots, which is a contradiction. Similarly, $q < k$. Thus, $n = p+q \le 2k-2$.

Consider $k=1$. Then $n > 1$. The condition $a_0 a_1 = 0$ for any divisor $Q(x) = a_1 x + a_0$ is impossible since $a_1 \neq 0$ and $a_0 \neq 0$. Thus $P(x)$ must have a non-real root.
Consider $k=2$. Then $n \ge 3$. Every 2-subset $\{r_i, r_j\}$ must satisfy $e_1(S) = r_i + r_j = 0$. For $n=3$, $r_1+r_2=0$ and $r_1+r_3=0$ implies $r_2=r_3$, a contradiction.

For $k \ge 3$, consider the case $n=k+1$. There are $n$ subsets $S_i = \{r_1, \dots, r_n\} \setminus \{r_i\}$. For each $i$, $e_j(S_i) = 0$ for some $j \in \{1, \dots, k-1\}$. Let $E_j$ be the $j$-th elementary symmetric polynomial of all $n$ roots. We have the relation $e_j(S_i) = E_j - r_i e_{j-1}(S_i)$, which implies $e_j(S_i)$ is a polynomial in $r_i$ of degree $j$. Specifically, $e_1(S_i) = E_1 - r_i$ and $e_2(S_i) = r_i^2 - E_1 r_i + E_2$.
If $e_1(S_i) = 0$ and $e_1(S_m) = 0$ for $i \neq m$, then $r_i = r_m = E_1$, a contradiction. Thus, at most one $i$ can satisfy $e_1(S_i)=0$. Similarly, $e_j(S_i)=0$ can hold for at most $j$ values of $i$.
Summing these, the total number of $i$ that can satisfy the condition is $\sum_{j=1}^{k-1} j = \frac{k(k-1)}{2}$. For $n=k+1$, we require $k+1 \le \frac{k(k-1)}{2}$, which is false for $k=3$ ($4 \le 3$). For $k \ge 4$, while the sum grows, the condition must hold for all $\binom{n}{k}$ subsets. If $n > k+1$, the number of constraints grows combinatorially, while the number of available roots $r_i$ remains $n$. For any $n > k$, the requirement that every $k$-subset $S$ has some $e_j(S)=0$ is too restrictive to be satisfied by distinct non-zero real numbers.

Thus, $P(x)$ must have at least one non-real root.

\(\square\)
