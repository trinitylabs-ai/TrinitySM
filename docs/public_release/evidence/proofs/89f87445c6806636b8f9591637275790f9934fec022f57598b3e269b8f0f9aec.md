To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Preliminary Observations**
If $f(x) = c$ for some constant $c > 0$, then $yc = c$ for all $y \in \mathbb{R}^+$, which is impossible. Thus, $f$ is not constant.
Setting $y=1$ in the original equation, we obtain:
$$f(f(x)+1) = f\left(\frac{1}{x} + f(1)\right) \quad (1)$$
Let $f(1) = a$. Then $f(f(x)+1) = f(1/x + a)$.
Setting $x=1$ in the original equation, we obtain:
$$yf(yf(1)+1) = f(1+f(y)) \implies yf(ay+1) = f(f(y)+1) \quad (2)$$
Combining (1) and (2), we have:
$$f(1/x + a) = x f(ax+1) \quad (3)$$
Replacing $x$ with $1/s$ in (3), we get $f(s+a) = \frac{1}{s} f(a/s + 1)$ for all $s \in \mathbb{R}^+$.

**2. Proving Injectivity**
Suppose $f$ is not injective. Then there exist $x, z \in \mathbb{R}^+$ with $x \neq z$ such that $f(x) = f(z)$.
From the original equation, $f(1/x + f(y)) = y f(y f(x) + 1) = y f(y f(z) + 1) = f(1/z + f(y))$ for all $y \in \mathbb{R}^+$.
Let $S$ be the range of $f$. For any $s \in S$, we have $f(s + 1/x) = f(s + 1/z)$.
Let $\alpha = 1/x$ and $\beta = 1/z$. Assume without loss of generality that $\alpha > \beta$.
Since $f(s+a) \in S$ for all $s \in \mathbb{R}^+$, we have:
$$f(f(s+a) + \alpha) = f(f(s+a) + \beta)$$
Using the identity $f(s+a) = \frac{1}{s} f(a/s + 1)$, we have:
$$f\left(\frac{1}{s} f(a/s + 1) + \alpha\right) = f\left(\frac{1}{s} f(a/s + 1) + \beta\right)$$
Let $k(s) = \frac{1}{s} f(a/s + 1)$. As $s$ varies over $\mathbb{R}^+$, $k(s)$ takes values in some interval $I \subseteq \mathbb{R}^+$. For any $t \in I$, $f(t + \alpha) = f(t + \beta)$.
Since $k(s) \to 0$ as $s \to \infty$ (because $f(a/s+1) \to f(1)=a$) and $k(s) \to \infty$ as $s \to 0$ (because $f(a/s+1) > 0$), the range of $k$ is $(0, \infty)$. Thus, $f(t + \alpha) = f(t + \beta)$ for all $t \in \mathbb{R}^+$.
This implies $f$ is periodic with period $T = \alpha - \beta > 0$.
However, from $f(s+a) = \frac{1}{s} f(a/s + 1)$, we have $f(s+a+T) = \frac{1}{s+T} f(a/(s+T) + 1)$.
Since $f(s+a+T) = f(s+a)$, we have $\frac{1}{s} f(a/s + 1) = \frac{1}{s+T} f(a/(s+T) + 1)$.
As $s \to \infty$, $f(a/s + 1) \to a$, so $\frac{a}{s} \approx \frac{a}{s+T}$, which implies $T=0$, a contradiction.
Thus, $f$ must be injective.

**3. Determining the Function**
Since $f$ is injective, $f(f(x)+1) = f(1/x + a)$ implies:
$$f(x) + 1 = \frac{1}{x} + a \implies f(x) = \frac{1}{x} + a - 1$$
Let $c = a - 1$. Then $f(x) = \frac{1}{x} + c$. Substituting this into the original equation:
$$y \left( \frac{1}{y(\frac{1}{x} + c) + 1} + c \right) = \frac{1}{\frac{1}{x} + \frac{1}{y} + c} + c$$
$$\frac{y}{\frac{y}{x} + yc + 1} + yc = \frac{xy}{x + y + cxy} + c$$
$$\frac{xy}{y + cxy + x} + yc = \frac{xy}{x + y + cxy} + c$$
This simplifies to $yc = c$ for all $y \in \mathbb{R}^+$, which implies $c = 0$.
Thus, $f(x) = \frac{1}{x}$.

**4. Verification**
LHS: $y f(y f(x) + 1) = y f(y/x + 1) = y \frac{1}{y/x + 1} = \frac{xy}{y+x}$.
RHS: $f(1/x + f(y)) = f(1/x + 1/y) = \frac{1}{1/x + 1/y} = \frac{xy}{x+y}$.
LHS = RHS for all $x, y \in \mathbb{R}^+$.

The only function $f: \mathbb{R}^+ \to \mathbb{R}^+$ that satisfies the given equation is $f(x) = \frac{1}{x}$.
