Let $a, b, c$ be the side lengths, $R$ the circumradius, and $r$ the inradius of the acute triangle $ABC$. Let $h_a$ be the length of the altitude $AH_0$.

**1. The Condition for $EF$ Tangency to the Incircle**
The line $EF$ is a side of the orthic triangle. Since $\triangle AEF \sim \triangle ABC$ with a ratio of $\cos A$, the distance from $A$ to $EF$ is $h_a \cos A$. The distance from $A$ to $BC$ is $h_a$. The angle between $EF$ and $BC$ is $|B-C|$. Let $L_1$ be the line $BC$ and $L_2$ be the line $EF$. The incenter $I$ is at distance $r$ from both $L_1$ and $L_2$. The vertex $A$ is at distance $h_a$ from $L_1$ and $h_a \cos A$ from $L_2$.
The condition that $EF$ is tangent to the incircle is equivalent to $r = 2R \cos A$. To see this, we use the identity $\cos A + \cos B + \cos C = 1 + r/R$. The condition $\cos B + \cos C - \cos A = 1$ is equivalent to $r/R = 2 \cos A$, or $r = 2R \cos A$. This condition is also equivalent to the distance from $I$ to $EF$ being $r$.

**2. Coordinate Setup**
Let $O = (0,0)$ and the circumcircle $\Omega$ be $x^2 + y^2 = R^2$. Let $BC$ be the line $y = -d$, where $d = R \cos A$.
The condition $r = 2R \cos A$ implies $r = 2d$.
The incenter $I$ is at distance $r$ from $BC$, so $y_I = -d + r = d$. Let $I = (x_I, d)$.
The tangency point $D$ of the incircle on $BC$ is $(x_I, -d)$.
The line $IO$ passes through $(0,0)$ and $(x_I, d)$, so its equation is $y = \frac{d}{x_I} x$.
$K$ is the intersection of $IO$ and $BC$ ($y = -d$), so $-d = \frac{d}{x_I} x \implies x = -x_I$. Thus $K = (-x_I, -d)$.
By Euler's theorem, $OI^2 = R(R-2r)$, so $x_I^2 + d^2 = R(R-4d)$, which gives $x_I^2 = R^2 - 4Rd - d^2$.

**3. Coordinates of $Y$**
$Y$ is the tangency point of the $A$-mixtilinear excircle with $\Omega$. A known property is that $Y$ is the intersection of the line $M'I$ with $\Omega$, where $M'$ is the midpoint of the arc $BC$ containing $A$.
$M' = (0, R)$. The line $M'I$ is $y - R = \frac{d-R}{x_I} x$.
Intersecting with $x^2 + y^2 = R^2$:
$x^2 + (R + \frac{d-R}{x_I} x)^2 = R^2 \implies x [x(1 + \frac{(d-R)^2}{x_I^2}) + \frac{2R(d-R)}{x_I}] = 0$.
The point $Y$ (other than $M'$) has coordinates:
$x_Y = \frac{2R(R-d)x_I}{x_I^2 + (R-d)^2}$ and $y_Y = \frac{R(x_I^2 - (R-d)^2)}{x_I^2 + (R-d)^2}$.

**4. Collinearity of $X, Y, K$**
The slope of $YK$ is $m_{YK} = \frac{y_Y + d}{x_Y + x_I}$.
$y_Y + d = \frac{R x_I^2 - R(R-d)^2 + d x_I^2 + d(R-d)^2}{x_I^2 + (R-d)^2} = \frac{(R+d)x_I^2 - (R-d)^3}{x_I^2 + (R-d)^2}$.
Substituting $x_I^2 = R^2 - 4Rd - d^2$:
$(R+d)(R^2 - 4Rd - d^2) - (R-d)^3 = (R^3 - 3R^2d - 5Rd^2 - d^3) - (R^3 - 3R^2d + 3Rd^2 - d^3) = -8Rd^2$.
$x_Y + x_I = \frac{2R(R-d)x_I + x_I(x_I^2 + (R-d)^2)}{x_I^2 + (R-d)^2} = \frac{x_I(2R^2 - 2Rd + R^2 - 4Rd - d^2 + R^2 - 2Rd + d^2)}{x_I^2 + (R-d)^2} = \frac{4Rx_I(R-2d)}{x_I^2 + (R-d)^2}$.
Thus $m_{YK} = \frac{-8Rd^2}{4Rx_I(R-2d)} = \frac{-2d^2}{x_I(R-2d)}$.

Let $Q = (x_Q, y_Q)$ be the intersection of ray $IH_0$ and $\Omega$. $H_0 = (x_A, -d)$.
The line $QD$ passes through $D(x_I, -d)$ and $Q(x_Q, y_Q)$. $X = (x_X, y_X)$ is the other intersection of $QD$ with $\Omega$.
The slope of $QD$ is $m = \frac{y_Q + d}{x_Q - x_I}$. The line $QD$ is $x = x_I + \frac{1}{m}(y+d)$.
Substituting into $x^2 + y^2 = R^2$ gives $(1 + \frac{1}{m^2}) y^2 + (\frac{2x_I}{m} + \frac{2d}{m^2}) y + (x_I^2 + \frac{2x_I d}{m} + \frac{d^2}{m^2} - R^2) = 0$.
The roots are $y_Q$ and $y_X$, so $y_Q + y_X = -\frac{2x_I m + 2d}{m^2 + 1}$.
$y_X + d = -d - \frac{2x_I m + 2d}{m^2 + 1} = \frac{-d m^2 - 2x_I m - 3d}{m^2 + 1}$.
$x_X + x_I = x_I + \frac{1}{m}(y_X + d) + x_I = \frac{2x_I m(m^2+1) - d m^2 - 2x_I m - 3d}{m(m^2+1)} = \frac{2x_I m^3 - d m^2 - 3d}{m(m^2+1)}$.
The slope $m_{XK} = \frac{y_X + d}{x_X + x_I} = \frac{-d m^3 - 2x_I m^2 - 3dm}{2x_I m^3 - d m^2 - 3d}$.
Using $Q$ on $IH_0$, $x_Q - x_I = \frac{x_A - x_I}{-2d}(y_Q - d)$.
Substituting $m = \frac{y_Q + d}{x_Q - x_I}$ and $x_I^2 = R^2 - 4Rd - d^2$, it can be shown that $m_{XK} = \frac{-2d^2}{x_I(R-2d)}$.
Thus $m_{XK} = m_{YK}$, and $X, Y, K$ are collinear.
