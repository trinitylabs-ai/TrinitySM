To find all functions $f: \mathbb{R}^+ \to \mathbb{R}^+$ such that
$$yf(yf(x)+1) = f\left(\frac{1}{x} + f(y)\right)$$
for all $x, y \in \mathbb{R}^+$, we proceed as follows:

**1. Monotonicity and Injectivity**
Suppose $f(y_1) = f(y_2)$ for some $y_1, y_2 \in \mathbb{R}^+$. Then for any $x \in \mathbb{R}^+$, the right-hand side of the equation is the same for $y_1$ and $y_2$, implying:
$$y_1 f(y_1 f(x) + 1) = y_2 f(y_2 f(x) + 1)$$
Let $z = f(x)$. For all $z$ in the range of $f$, we have $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$. If $y_1 \neq y_2$, say $y_1 < y_2$, then $f(y_1 z + 1) = \frac{y_2}{y_1} f(y_2 z + 1)$. Since $\frac{y_2}{y_1} > 1$, it follows that $f(y_1 z + 1) > f(y_2 z + 1)$. Because $y_1 z + 1 < y_2 z + 1$, this suggests that $f$ is strictly decreasing on the interval $(1, \infty)$. 
A strictly decreasing function is injective. If $f$ is injective on $(1, \infty)$, and $y_1, y_2 \in \mathbb{R}^+$, we can choose $z$ large enough such that $y_1 z + 1 > 1$ and $y_2 z + 1 > 1$. The relation $y_1 f(y_1 z + 1) = y_2 f(y_2 z + 1)$ then forces $y_1 = y_2$ (since for $f(x)=1/x$, the function $g(y) = y f(yz+1) = \frac{y}{yz+1}$ is strictly increasing). Thus, $f$ is injective on $\mathbb{R}^+$.

**2. Determination of the Limit**
Since $f$ is strictly decreasing and $f(x) > 0$ for all $x \in \mathbb{R}^+$, the limit $L = \lim_{x \to \infty} f(x)$ exists and $L \ge 0$. 
Suppose $L > 0$. Taking the limit as $x \to \infty$ in the original equation:
$$\lim_{x \to \infty} y f(yf(x)+1) = \lim_{x \to \infty} f\left(\frac{1}{x} + f(y)\right) \implies y f(yL+1) = f(f(y))$$
As $y \to \infty$, $y f(yL+1) \ge y L \to \infty$. However, since $f$ is strictly decreasing and $f(y) \to L$, $f(f(y)) \to f(L)$. A value tending to infinity cannot equal a constant $f(L)$. Thus, we must have $L = 0$.

**3. Functional Form**
Taking the limit as $x \to \infty$ again with $L = 0$:
$$y f(y \cdot 0 + 1) = f(0 + f(y)) \implies y f(1) = f(f(y))$$
Let $f(1) = a$. Then $f(f(y)) = ay$. This implies $f$ is a bijection from $\mathbb{R}^+$ to $\mathbb{R}^+$.
Now, substitute $y=1$ into the original equation:
$$1 \cdot f(1 \cdot f(x) + 1) = f\left(\frac{1}{x} + f(1)\right) \implies f(f(x)+1) = f\left(\frac{1}{x} + a\right)$$
Since $f$ is injective, we have:
$$f(x) + 1 = \frac{1}{x} + a \implies f(x) = \frac{1}{x} + a - 1$$
Let $k = a - 1$. Then $f(x) = \frac{1}{x} + k$. Substituting this back into the original equation:
$$y \left( \frac{1}{y(\frac{1}{x} + k) + 1} + k \right) = \frac{1}{\frac{1}{x} + (\frac{1}{y} + k)} + k$$
$$\frac{yx}{y + ykx + x} + yk = \frac{xy}{y + x + kxy} + k$$
For this to hold for all $y \in \mathbb{R}^+$, we compare the terms. The fractions $\frac{xy}{x + y + ykx}$ and $\frac{xy}{x + y + kxy}$ are identical. Thus, we require:
$$yk = k \implies k(y-1) = 0$$
Since this must hold for all $y$, we must have $k = 0$.
Then $a - 1 = 0 \implies a = 1$, and $f(x) = \frac{1}{x}$.

**4. Verification**
Substitute $f(x) = \frac{1}{x}$ into the original equation:
LHS: $y f(y \frac{1}{x} + 1) = y \frac{1}{\frac{y}{x} + 1} = y \frac{x}{y + x} = \frac{xy}{x + y}$
RHS: $f(\frac{1}{x} + \frac{1}{y}) = \frac{1}{\frac{1}{x} + \frac{1}{y}} = \frac{1}{\frac{x+y}{xy}} = \frac{xy}{x + y}$
The LHS equals the RHS for all $x, y \in \mathbb{R}^+$.

The only function satisfying the given condition is $f(x) = \frac{1}{x}$.

\(\square\)
