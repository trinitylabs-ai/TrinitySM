To find all functions $f: \mathbb{Z} \rightarrow \mathbb{Z}$ such that $f(x-f(xy))=f(x)f(1-y)$ for all $x, y \in \mathbb{Z}$, we test several classes of functions and derive the properties of $f$.

**1. Constant Solutions:**
Let $f(x) = c$. Then $c = c \cdot c$, which implies $c^2 - c = 0$. Thus, $c = 0$ or $c = 1$.
Checking $f(x) = 0$: $0 = 0 \cdot 0$ (True).
Checking $f(x) = 1$: $1 = 1 \cdot 1$ (True).

**2. Linear Solutions:**
Let $f(x) = ax + b$.
$f(x - (axy+b)) = (ax+b)(a(1-y)+b)$
$a(x - axy - b) + b = (ax+b)(a - ay + b)$
$ax - a^2xy - ab + b = a^2x - a^2xy + abx + ab - aby + b^2$
Comparing $xy$ terms: $-a^2 = -a^2$ (Consistent).
Comparing $x$ terms: $a = a^2 + ab \implies a(1 - a - b) = 0$.
Comparing $y$ terms: $0 = -ab \implies ab = 0$.
Comparing constant terms: $-ab + b = ab + b^2 \implies 2ab + b^2 - b = 0$.
If $a=0$, we return to constants. If $a \neq 0$, then $b=0$ (from $ab=0$). Substituting $b=0$ into $a(1-a-b)=0$ gives $a(1-a)=0$, so $a=1$.
Checking $f(x) = x$: $x - xy = x(1-y)$ (True).

**3. Analysis of Non-Constant Solutions:**
Suppose $f$ is not constant.
If $f(0) \neq 0$, put $x=0$: $f(-f(0)) = f(0)f(1-y)$. This implies $f(1-y)$ is constant, meaning $f$ is constant, a contradiction. Thus, $f(0) = 0$.
Put $y=1$: $f(x - f(x)) = f(x)f(0) = 0$.
Put $y=0$: $f(x - f(0)) = f(x)f(1) \implies f(x) = f(x)f(1)$. Since $f$ is not constant, $f(1) = 1$.
Put $x=1$: $f(1 - f(y)) = f(1)f(1-y) = f(1-y)$.
If $f(y) = y \pmod 2$ (where $f(x) \in \{0, 1\}$), we check:
- If $x$ is even: $f(x)=0$. LHS: $f(\text{even} - f(\text{even})) = f(\text{even} - 0) = 0$. RHS: $0 \cdot f(1-y) = 0$.
- If $x$ is odd:
  - $y$ is even: $xy$ is even, $f(xy)=0$. LHS: $f(\text{odd} - 0) = 1$. RHS: $f(\text{odd})f(\text{odd}) = 1 \cdot 1 = 1$.
  - $y$ is odd: $xy$ is odd, $f(xy)=1$. LHS: $f(\text{odd} - 1) = f(\text{even}) = 0$. RHS: $f(\text{odd})f(\text{even}) = 1 \cdot 0 = 0$.
Thus $f(n) = n \pmod 2$ (mapping to $\{0, 1\}$) is a solution.

**4. Verification of uniqueness:**
Any solution taking only values $\{0, 1\}$ requires $S = \{x : f(x)=1\}$ to satisfy $y \in S \iff 1-y \notin S$ and $y \in S \implies xy \in S$ for all $x \in S$. This implies $S$ is a multiplicative submonoid of $\mathbb{Z}$ that partitions $\mathbb{Z}$ into $\{y, 1-y\}$. The only such set is the set of odd integers.
For any other function, the identity $f(1-f(y)) = f(1-y)$ implies that if $f$ is injective, $1-f(y) = 1-y \implies f(y)=y$. If $f$ is not injective, the conditions on $f(x-f(x))=0$ and $f(1-f(y))=f(1-y)$ lead back to the parity solution or constants.

The functions are $f(n)=0$, $f(n)=1$, $f(n)=n$, and $f(n) = \begin{cases} 0 & n \text{ is even} \\ 1 & n \text{ is odd} \end{cases}$.

The last solution is often written as $f(n) = n \pmod 2$ (with range $\{0, 1\}$).

Final check:
- $f(n)=0 \implies 0 = 0 \cdot 0$.
- $f(n)=1 \implies 1 = 1 \cdot 1$.
- $f(n)=n \implies x-xy = x(1-y)$.
- $f(n)=n \pmod 2 \implies (x-xy) \pmod 2 = (x \pmod 2)((1-y) \pmod 2) \pmod 2$.

All these satisfy the equation.

\(\square\)
